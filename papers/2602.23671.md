## Summary

1.  Existing recommendation systems often use slow, quadratic attention mechanisms that struggle with long user sequences. The paper introduces FuXi-Linear, a linear-complexity model designed to handle these long sequences more efficiently.
2.  FuXi-Linear addresses key limitations by incorporating a "Temporal Retention Channel" to manage temporal signals separately from semantic ones, preventing interference, and a "Linear Positional Channel" to effectively integrate positional information within linear complexity.
3.  This model demonstrates robust scaling on long sequences and significantly outperforms existing methods on recommendation quality, while achieving substantial speedups (up to 21x) compared to baseline models during inference.

## Technical note

FuXi-Linear is a linear-complexity sequential recommender for ultra-long (thousands of interactions) user histories, replacing quadratic softmax attention with a retention-style linear attention supporting recurrent (O(1) inference), parallel, and chunkwise-recurrent forms. A Temporal Retention Channel computes period-aware query/key attention purely from timestamps to capture behavioral periodicity while avoiding crosstalk between temporal and semantic signals and preserving linear recurrence (which naive temporal coupling breaks). A Linear Positional Channel uses learnable kernels to approximate the expressiveness of relative position encoding—shown to beat RoPE in recsys—without quadratic cost. The model demonstrates power-law scaling at thousand-length sequences (unlike prior shallow, short-sequence linear recsys models) and achieves state-of-the-art quality with up to 10x prefill and 21x decode speedups over baselines.
