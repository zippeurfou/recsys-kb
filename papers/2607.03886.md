## Summary

This paper addresses the challenge of ensuring ad relevance in e-commerce sponsored search by adapting a pretrained Large Language Model (LLM). Specifically, it utilizes Low-Rank Adaptation (LoRA) on the LLAMA2 7B model to create an advanced Ad Relevance Classifier. The resulting system significantly improved search accuracy and operational efficiency while offering better privacy compared to existing models like GPT-4.

## Technical note

Adapts LLaMA2 7B with LoRA into a three-class (Relevant / Partially Relevant / Irrelevant) <query, ad-title> relevance classifier for Walmart sponsored search, trained on 250K annotated query-item pairs with cross-entropy loss. The fine-tuned model reaches 89.43% test accuracy (F1 89.41%), outperforming a Cross-Encoder BERT (86.27%), Bi-Encoder BERT (74.42%), and few-shot GPT-4 (63.02%), and achieves higher NDCG@4/@8 (0.7142/0.6774) than the BERT baselines. LoRA keeps the base weights frozen while only training low-rank q/k/v/o and feed-forward projection adapters, giving lower cost and better data privacy than a GPT-4 API while enabling continuous retraining via auto-labeling.
