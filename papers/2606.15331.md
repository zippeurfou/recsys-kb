## Summary

This paper introduces HoloRec, an innovative generative recommendation model aiming to overcome limitations of standard sequence generation and traditional cascade architectures.

HoloRec features an endogenous chain-of-thought mechanism that embeds reasoning directly into the generation process by creating a hierarchical semantic encoding matrix through multi-granularity nested residual quantization.

The system supports fast prediction or detailed, on-the-fly reasoning without external data annotations. Experiments confirm HoloRec outperforms existing methods across datasets and particularly excels in sparse recommendation scenarios.

## Technical note

HoloRec is an endogenous chain-of-thought generative recommender that unifies item representation, reasoning, and generation. It builds an M x L hierarchical semantic encoding matrix via multi-granularity nested residual quantization (granularities share codebooks per layer) optimized with a holistic reconstruction loss, giving coarse-to-fine semantic IDs suited to multi-step reasoning without needing externally annotated CoT data. It supports a non-thinking mode using lightweight multi-granularity supervised alignment for fast prediction, and a thinking mode that interleaves coarse-to-fine reasoning by injecting coarse semantic embeddings into fine-grained decoding through a gating mechanism, embedding CoT directly into autoregressive generation. Experiments on public datasets show consistent gains over TIGER/P5-style baselines, with especially large improvements in sparse scenarios and modest inference overhead for the thinking mode.
