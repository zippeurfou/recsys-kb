## Summary

This paper addresses the need for recommender systems to optimize beyond just accuracy (diversity, novelty), by integrating structured human knowledge ("human priors" like item taxonomies). It proposes a backbone-agnostic framework that uses lightweight adapter heads during decoding to incorporate these priors directly into end-to-end generative models, helping disentangle user intent. Experiments show this significantly improves both accuracy and beyond-accuracy objectives, while also enabling more effective use of longer context and larger models.

## Technical note

Addresses integrating industrial human priors (item taxonomies, temporal patterns, interaction types) directly into end-to-end generative recommenders instead of applying them as post-hoc ranking adjustments. Proposes a backbone-agnostic framework of lightweight, prior-conditioned residual adapter heads (inspired by Medusa multi-head decoding) that project a shared user state into specialized query vectors, with compatibility masking restricting each head to items matching its prior group. A hierarchical composition strategy organizes adapters into a tree for coarse-to-fine specialization with Bayesian-style shrinkage on rare prior combinations. Experiments on three large-scale datasets show improvements in both accuracy and beyond-accuracy metrics (diversity, personalization) and better use of longer context and larger models.
