## Technical note

This Meta work integrates structured human priors (e.g., item taxonomies, temporal patterns, interaction types) directly into end-to-end training of generative recommenders, instead of applying them as decoupled post-hoc ranking adjustments or discarding them via unsupervised intent learning. Using lightweight prior-conditioned adapter heads inspired by efficient LLM decoding strategies, the backbone-agnostic framework guides the model to disentangle user intent along human-understandable axes (interaction types, long- vs short-term interests), with a hierarchical composition strategy for interactions across prior types. Experiments on three large-scale datasets significantly improve both accuracy and beyond-accuracy objectives (diversity, novelty, personalization) and help the backbone exploit longer context and larger sizes.
