## Summary

Vision-Language 3D Detection with Chain-of-Sight":

Current vision-language models (VLMs) lack the ability to perform multi-object 3D detection, despite being good at 2D vision tasks. The paper introduces LocateAnything3D, a novel VLM-based approach that treats 3D detection as predicting the next token in a Chain-of-Sight sequence, mirroring human reasoning. This method sequentially generates 2D detections and predicts 3D boxes in a near-to-far order, achieving state-of-the-art results on the Omni3D benchmark and demonstrating strong generalization and robustness.

## Technical note

LocateAnything3D casts open-world monocular multi-object 3D detection as next-token prediction inside a VLM using a Chain-of-Sight (CoS) scheme that emits a 2D box before its 3D box per instance. It orders objects near-to-far across instances and factorizes each 3D box as center then size then rotation in the camera frame, with 2D acting as a visual chain-of-thought that anchors 3D and reduces hallucination. Trained on a unified ~1.74M-example camera-centric corpus (SigLIP + Qwen2 backbone) with calibrated negatives, it reaches 38.90 AP3D on Omni3D, +13.98 over prior best even given GT 2D boxes. Ablations show near-to-far ordering, interleaved 2D-then-3D, and center-size-rotation each matter, and 2D pretraining improves data efficiency and convergence.
