## Summary

This paper introduces a system that uses unstructured log data from analytics software to infer user goals and recommend relevant data commands. The core idea is that sequences of commands predict subsequent data actions, so they developed neural network models trained on these sequences. To ensure recommendations align with user goals, the authors introduced a custom loss function and evaluation metric, demonstrating the approach's effectiveness and robustness through offline evaluation.

## Technical note

This paper builds a goal-driven command recommendation system for a web-analytics application, using unstructured user interaction logs to suggest the next 'data command'. Goals are inferred from sessions via Biterm Topic Modeling (chosen over LDA due to short-session sparsity), and provided exogenously as input to steer recommendations. Neural sequence models predict the next data command, and a custom loss function incorporates a per-goal probability distribution to fine-tune goal-specific models from a general pretrained model, following a GPT-style pretrain-then-finetune paradigm. The authors introduce an evaluation metric for degree of goal orientation and show via offline evaluation, including adversarial cases where user activity is misaligned with the stated goal, that the goal-driven models outperform goal-unaware baselines.
