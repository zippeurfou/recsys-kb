## Technical note

Compass-Embedding v4 is a high-efficiency multilingual embedding framework optimized for Southeast Asian e-commerce, where data scarcity, noisy supervision, and production constraints challenge representation learning for low-resource languages. It proposes Class-Aware Masking (CAM), a lightweight modification to the InfoNCE contrastive objective that suppresses invalid in-batch negatives and improves semantic discrimination without altering the base architecture. The resulting embeddings target retrieval, recommendation, and search across SEA markets.
