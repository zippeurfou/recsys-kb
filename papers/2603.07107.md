## Summary

This paper addresses two main challenges in using generative models for personalized reranking in recommenders: balancing high generation quality with low-latency inference, and insufficient user-item interaction. The authors propose the PSAD framework, combining a semi-autoregressive teacher model for efficient generation with online knowledge distillation into a fast-scoring student network. They also introduce a User Profile Network to better capture user intent and dynamics. Extensive experiments show that PSAD significantly improves both ranking performance and inference speed compared to state-of-the-art methods.

## Technical note

PSAD is a generative reranking framework for the final stage of multi-stage recommender systems that models inter-item dependencies within the reranked list. To resolve the quality-latency conflict, a semi-autoregressive teacher generates items block-wise (reducing error accumulation versus fully autoregressive and incoherence versus non-autoregressive), and its ranking knowledge is distilled online into a lightweight scoring student trained jointly from scratch with a shared encoder, avoiding a pretrained teacher. A User Profile Network (UPN) injects user intent via personalized gates that adapt item semantic representations and a personalized position-encoding mechanism modeling per-user interest decay, enabling early user-item feature interaction. Experiments on three large public datasets report simultaneous gains in ranking quality and inference efficiency over discriminative (DLCM, PRM, SetRank) and generative (Seq2Slate, GRN, NAR4Rec) baselines.
