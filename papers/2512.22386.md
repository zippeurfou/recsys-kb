Traditional recommendation systems suffer from inconsistency in multi-stage optimization objectives. Generative Recommendation (GR) mitigates them through an end-to-end framework; however, existing methods still rely on matching mechanisms based on inductive patterns. Although responsive, they lack the ability to uncover complex user intents that require deductive reasoning based on world knowledge. ## Technical note

OxygenREC is an instruction-following unified generative recommendation framework deployed in JD.com's core scenarios. It uses a Fast-Slow Thinking architecture where a near-line LLM pipeline performs slow deductive intent reasoning to produce Contextual Reasoning Instructions, while a high-throughput encoder-decoder backbone does fast real-time generation over multimodal semantic IDs (RQ of contrastive embeddings). A Query-to-Item loss plus Instruction-Guided Retrieval filter noisy long-term history, and multi-scenario alignment via a unified Reward Mapping Service with Soft Adaptive Group Clip Policy Optimization (SA-GCPO) enables train-once-deploy-everywhere. Online A/B tests showed significant gains in order volume and GMV.
