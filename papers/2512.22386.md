## Summary

OxygenREC addresses limitations in existing e-commerce recommendation systems, particularly the inability of generative models to leverage deep reasoning from LLMs effectively and the lack of multi-scenario scalability. It introduces a Fast-Slow Thinking architecture, combining a slow LLM for deep reasoning instruction generation with a fast model for real-time recommendations, and incorporates Instruction-Guided Retrieval to align recommendations with user intent. Finally, OxygenREC achieves unified deployment across scenarios by transforming scenario requirements into instructions and using unified policy optimization.

## Technical note

OxygenREC is a unified instruction-following generative recommender deployed at JD.com that tackles GR's weak deductive reasoning and costly per-scenario models. A near-line LLM pipeline (slow thinking) synthesizes compact Contextual Reasoning Instructions from spatiotemporal, query, and behavior signals, while a high-throughput encoder-decoder backbone (fast thinking) generates multimodal semantic-ID item sequences under latency limits, with a Query-to-Item loss and Instruction-Guided Retrieval to filter user history. Items are tokenized via RQ-KMeans over contrastively trained multimodal embeddings (depth 3, 8192 codes/level). Multi-scenario alignment uses scenario instructions plus a unified reward mapping service and Soft Adaptive Group Clip Policy Optimization (SA-GCPO) for train-once-deploy-everywhere. Online A/B tests showed significant order-volume and GMV gains.
