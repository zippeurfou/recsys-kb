## Summary

1.  Existing Graph Contrastive Learning methods for recommendations often ignore hierarchical item structures, which represent similarities across different levels or resolutions.
2.  HGCL overcomes this limitation by pre-training user/item representations using cross-layer contrastive learning and then constructing a two-hierarchy graph via representation compression clustering to explicitly model these structures.
3.  The paper demonstrates that fine-tuning on this hierarchical graph significantly improves recommendation accuracy, outperforming baseline models across different dataset scales in experiments.

## Technical note

HGCL (Hierarchical Graph Contrastive Learning) augments GCL-based user-item recommendation by explicitly modeling hierarchical item structures (item similarities at multiple resolutions) that existing GCL methods ignore. It first pretrains a GCL module with cross-layer contrastive learning (InfoNCE) plus a BPR recommendation loss to obtain user/item representations, then compresses and clusters item embeddings to construct a two-level user-cluster-item bipartite graph. Finally it fine-tunes on both the original and hierarchical graphs, enabling multi-level recommendation and mitigating data sparsity via information transfer from higher-level categories. On three benchmarks (70K-382K nodes) HGCL beats SGL, SimGCL, and XSimGCL on Recall and NDCG.
