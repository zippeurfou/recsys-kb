## Technical note

HGCL (Hierarchical Graph Contrastive Learning) is an Alibaba GCL recommendation method that explicitly models hierarchical item structures (item similarities across resolutions, e.g. snooker/football videos -> sports videos) missing from methods like SGL and SimGCL. It pre-trains a GCL module with cross-layer contrastive learning to get user/item representations, compresses and clusters item embeddings to build a two-hierarchy user-item bipartite graph, then fine-tunes on both the original and hierarchical graphs for recommendation. On three benchmarks (70K-382K nodes) HGCL outperforms SGL, SimGCL, and XSimGCL on Recall and NDCG, mitigating data sparsity via higher-level category transfer.
