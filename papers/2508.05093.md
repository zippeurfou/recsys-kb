## Technical note

EMER (Kuaishou) is an end-to-end multi-objective ensemble ranking framework for short-video recommendation that replaces manually designed heuristic scalarization formulas with learned modeling. It introduces a Relative Advantage Satisfaction concept implemented via a pairwise ranking loss (since no single ground-truth captures user satisfaction), a multi-dimensional AUC-based auxiliary loss dynamically weighted by an Advantage Evaluator, and a novel Interaction Probability per Unit Time (IPUT) metric that uses the backdoor criterion to remove watch-time confounding from interactions. A Transformer architecture consumes all candidate videos of a request as one aggregated sample to capture comparative relationships. Deployed on Kuaishou's primary scenarios, it increased App Stay Time by 1.39% and 7-day Lifetime (LT7) by 0.196%.
