## Summary

Existing LLM benchmarks are limited by data contamination, single-knowledge-point assessment, and high annotation costs. The paper introduces Encyclo-K, a new benchmark that overcomes these issues by dynamically composing questions from individual knowledge statements extracted from textbooks. This approach provides reliable, multi-knowledge evaluation with significantly reduced annotation requirements, proving to be a substantial challenge for leading models like GPT-5.1 and demonstrating a clear gradient in performance.

## Technical note

Encyclo-K is a statement-based benchmark that curates standalone knowledge statements from 62 authoritative textbooks (43 subfields, 11 disciplines) and dynamically composes evaluation questions by randomly sampling 8-10 statements at test time. This design resists memorization via a vast combinatorial space, enables comprehensive multi-statement assessment, and removes the need for expert annotation since annotators only check formatting. Correct statements are extracted from textbooks (via a vision model on screenshots) while incorrect ones are generated by reasoning models. Over 50 LLMs are evaluated; GPT-5.1 reaches only 62.07% accuracy, model rankings stay stable across random seeds, and no position bias is found.
