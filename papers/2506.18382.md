## Summary

This paper addresses the challenge of multi-scenario recommendation by improving how user preferences are modeled across different situations on online platforms. It introduces PERSCEN, which creates a personalized feature graph using a GNN and extracts scenario-specific preferences via vector quantization techniques. Experiments confirm that PERSCEN outperforms existing methods while effectively balancing performance with computational efficiency for industrial use.

## Technical note

Multi-scenario matching shares models across scenarios to cut costs and ease sparsity, but existing methods focus on shared vs scenario-aware preferences while neglecting fine-grained user-specific modeling. PERSCEN builds a per-user feature graph from user characteristics and applies a lightweight GNN to capture higher-order interaction patterns for personalized shared-preference extraction. It uses vector quantization to distil scenario-aware preferences from behavior sequences within each scenario and a progressive scenario-aware gated linear unit for fine-grained, low-latency fusion. Experiments show PERSCEN outperforms existing methods while balancing accuracy and computational cost for industrial use.
