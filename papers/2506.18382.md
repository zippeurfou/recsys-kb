## Technical note

PERSCEN is Meituan's multi-scenario matching approach that adds user-specific modeling to capture both cross-scenario shared preferences and scenario-aware preferences. It constructs a user-specific feature graph from user characteristics and applies a lightweight graph neural network for higher-order interaction patterns, and uses vector quantization to distill scenario-aware preferences from behavior sequences within each scenario. A progressive scenario-aware gated linear unit enables fine-grained low-latency information fusion; experiments show PERSCEN outperforms existing methods while balancing performance and computational cost for industrial use.
