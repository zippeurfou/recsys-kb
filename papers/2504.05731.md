Recently, the personalization of Large Language Models (LLMs) to generate content that aligns with individual user preferences has garnered widespread attention. Personalized Retrieval-Augmented Generation (RAG), which retrieves relevant documents from the user's history to reflect their preferences and enhance LLM generation, is one commonly used approach for personalization. ## Technical note

CFRAG adapts collaborative filtering to Retrieval-Augmented Generation for personalized text generation, exploiting the insight that histories of similar users (collaborative information) can aid personalization, which existing personalized-RAG methods (retrieving only the current user's history) ignore. Without explicit user-similarity labels, it trains user embeddings with contrastive learning over augmented views of user histories to retrieve similar users, then uses a personalized retriever and reranker to fetch top-k documents from those users' histories, incorporating user preference beyond semantic relevance and fine-tuning both via LLM feedback. On the LaMP personalization benchmark, CFRAG is validated as effective, with analysis confirming the value of collaborative information.
