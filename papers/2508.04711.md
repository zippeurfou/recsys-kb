## Summary

This paper addresses large-scale recommendation systems needing to model high-cardinality user interaction data effectively for accurate predictions. It proposes an extension of context parallelism (CP), typically used in transformer models like LLMs, specifically adapted for HSTU attention layers which handle jagged input tensors common in production ranking systems. This novel approach achieves significant gains by enabling a 5.3x increase in supported user history sequence length and providing a combined 1.55x scaling factor when using Distributed Data Parallelism (DDP), thereby improving the efficiency of generative recommenders with longer sequences.

## Technical note

This paper scales generative recommenders based on Hierarchical Sequential Transducers (HSTU) to much longer user-history sequences, which are activation-memory heavy. It introduces context parallelism (CP) with jagged-tensor support for HSTU attention, adapting LLM-style sequence-dimension sharding to variable-length recommendation inputs by replacing AllGather with AllToAll to cut peak memory (>60%) and boost throughput (~2.7x QPS). It adds load balancing via mini-CP chunking assigned across ranks with custom Triton reordering kernels (+37% throughput) and asynchronous offset copies to avoid device-host sync. On H100 GPUs, CP enables a 5.3x longer supported sequence length (3K to 16K) and a 1.55x scaling factor when combined with DDP.
