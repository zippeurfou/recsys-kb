## Technical note

This work (Meta) scales generative recommenders built on HSTU (Hierarchical Sequential Transducers) to longer user-interaction sequences, whose activation memory becomes the bottleneck. It introduces context parallelism with jagged-tensor support for HSTU attention, adapting the LLM technique of sharding computation along the sequence dimension across GPUs to production ranking models that use variable-length jagged input tensors. The approach enables a 5.3x increase in supported sequence length and a 1.55x scaling factor when combined with Distributed Data Parallelism (DDP).
