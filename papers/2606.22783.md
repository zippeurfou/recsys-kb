## Summary

The paper addresses a fundamental paradox in evaluating LLMs designed for high-entropy exhaustive search: conventional benchmarks penalize models for outperforming humans because creating complete ground truth is impossible. VERITAS solves this by introducing computationally irreducible constraints that force agents to perform true, verifiable traversal of the entire search space. This allows for automatically generated test cases with perfect answers and tight difficulty control, providing a scalable way to accurately benchmark and train these crucial but underdeveloped capabilities without human involvement.

## Technical note

VERITAS is a benchmark framework for evaluating LLM agents on high-entropy exhaustive-search tasks, addressing an evaluation paradox where verifying completeness requires complete ground truth that human annotators cannot create, so agents that find valid items beyond an annotation pool get penalized as hallucinating. The core idea is computationally irreducible constraints: replacing a natural-language filter with a cryptographic hash check H(x)=target that is easy to verify (O(1)) but impossible to optimize semantically because hashes are one-way with an avalanche effect, so no search query can shortcut it. This forces agents to genuinely traverse the entire search space (forced O(N) List-All then Hash-Check over real web domains like discographies or model hubs), makes hash-constrained sparse search computationally equivalent to exhaustive enumeration, and enables virtually unlimited auto-generated test cases with perfect labels and precise difficulty control (parameter k). Empirically, success rates decay exponentially with k matching (T/N)^k predictions, and the framework doubles as a scalable source of training data for systematic-exploration capability.
