## Summary

This paper introduces Sheaf-Cohomological Program Analysis, a novel framework using Čech cohomology to unify tasks like type checking, bug finding, and equivalence verification. It models program semantics via algebraic geometry, assigning refinement types to observation sites and analyzing data-flow restrictions through cohomology groups. The framework yields three key results (counting minimum fixes, providing a sound/complete equivalence condition, and enabling compositional analysis) and is implemented in Deppy, which significantly outperforms existing tools like mypy on Python benchmarks.

## Technical note

This framework casts program analysis (type checking, bug finding, equivalence verification) as computing the Cech cohomology of a semantic presheaf over a program's site category, where the presheaf assigns refinement-type information to observation sites (argument boundaries, branch guards, call results, error sites) and restricts along data-flow morphisms. H^0 is the space of globally consistent typings, while H^1 classifies gluing obstructions—bugs, type errors, equivalence failures—each localized to a disagreeing pair of sites. Three results follow: rank of H^1 over F_2 equals the minimum number of independent fixes; vanishing H^1 for the iso-presheaf is a sound/complete equivalence criterion relative to the cover; and Mayer-Vietoris enables compositional, incremental obstruction counting. Implemented as Deppy (Python) with key metatheorems mechanized in 1,259 lines of Lean 4, it attains 100% bug-detection recall and 99% equivalence accuracy, outperforming mypy and pyright on unannotated code.
