## Summary

Long-form video generation often struggles with maintaining consistent recurring subjects across the entire sequence using standard temporal decomposition methods that don't adequately preserve identity memories.

This paper introduces Memento, a novel framework designed to solve this problem by explicitly treating subject preservation as an identity grounding task. It uses a memory bank and trains next-shot generation alongside reconstructing the subject's appearance from historical memory and story context.

Memento employs a dual-query mechanism to separate long-range evidence retrieval for identity from short-context keyframes needed for shot coherence, along with a specialized data pipeline, resulting in state-of-the-art performance for long-term consistency and visual quality.

## Technical note

Memento treats subject preservation in long-form video generation as an explicit identity grounding problem, premised on the idea that a memory bank faithfully preserving a subject should support reconstructing it from memory alone. It jointly trains autoregressive next-shot generation with a memory-based subject reconstruction objective that recovers target appearances from historical memory and global story captions, converting subject consistency from an implicit expectation into a verifiable target. A dual-query memory mechanism disentangles long-range identity evidence (one query) from short-range continuation cues (another query selecting keyframes). A subject-aware cinematic data pipeline supplies pronoun-free descriptions for reconstruction supervision, and the method reaches state-of-the-art long-term subject consistency, cross-shot coherence, and visual quality.
