## Summary

DemoBot is a learning framework that enables a two-arm robot to learn complex manipulation skills by analyzing just a single unannotated human demonstration video. It achieves this by first extracting structured motion trajectories from the video and then using reinforcement learning with these as priors, refining them through realistic contact interactions without starting from scratch. The framework introduces novel RL techniques like temporal-segment alignment, success-gated resets, and event-driven reward curriculum to effectively learn long-duration tasks, successfully demonstrating bimanual assembly skills learned directly from third-person human videos.

## Technical note

DemoBot learns long-horizon, bimanual dexterous manipulation skills from a single unannotated third-person RGB-D human video, bridging the human-robot embodiment gap and the missing-dynamics modality gap. A data-processing module extracts 3D hand and object trajectories (MANO-based hand representation with task-aware object refinement) and retargets them to full-body robot trajectories used as flexible motion priors rather than strict imitation targets. A corrective residual RL policy outputs deltas added to the priors to master contact-rich dynamics, avoiding learning from scratch. Three techniques enable long-horizon learning: temporal-segment-based RL for alignment, a success-gated reset strategy for exploration, and an event-driven reward curriculum with adaptive thresholds. It succeeds on tasks where behavioral cloning and from-scratch RL fail.
