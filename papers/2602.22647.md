## Summary

1.  Industrial LLM-based recommendation systems often need to restrict output items using business logic (constrained decoding), but standard methods don't support this and existing Trie-based approaches are slow on hardware accelerators like TPUs/GPUs.
2.  To address this, the authors introduce STATIC, a technique that converts the prefix tree (Trie) into a static Compressed Sparse Row (CSR) matrix, transforming the decoding process into vectorized operations for much faster execution on accelerators.
3.  STATIC achieves significant performance gains, including a 948x speedup over CPU-based methods and reduced inference time overhead (0.25%), enabling its deployment at scale and improving cold-start performance for generative retrieval.

## Technical note

STATIC enables efficient strictly-constrained decoding for LLM-based generative retrieval, allowing the output space to be restricted to a business-logic subset (freshness, category, inventory) that standard autoregressive decoding cannot support. It observes that pointer-chasing trie-based constrained decoding is hostile to TPUs/GPUs due to irregular memory access and incompatibility with static XLA computation graphs. STATIC flattens the prefix tree into a static Compressed Sparse Row (CSR) matrix, turning tree traversal into fully vectorized sparse matrix operations with O(1) I/O complexity w.r.t. constraint-set size and a branch-free masking algorithm. Deployed on YouTube's video recommendation platform over ~20M fresh items, it achieves large speedups (up to 948x over CPU trie) with negligible latency overhead and improves cold-start on Amazon Reviews benchmarks.
