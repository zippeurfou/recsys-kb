## Summary

The Science Consultant Agent is a web-based AI tool designed to help practitioners select and implement the most effective modeling strategies for their AI solutions.

It operates through four core components: a Questionnaire to understand requirements, Smart Fill for data handling, Research-Guided Recommendations, and a Prototype Builder.

By combining structured inputs, literature-backed suggestions, and prototype generation, the tool aims to accelerate the development process for roles ranging from Product Managers to Researchers.

## Technical note

The Science Consultant Agent is a web-based tool that guides AI practitioners to select modeling strategies via four components: a structured Questionnaire, Smart Fill for auto-completing fields from project metadata, Research-Guided (evidence-based) Recommendation grounded in arXiv retrieval, and a tool-based Prototype Builder on SageMaker. It generates up to K arXiv search queries from questionnaire responses, filters relevant papers, and constructs context (abstract-only, full-paper, or summaries) to synthesize best-solution and strong-baseline recommendations with citations. Evaluation relied on user surveys and interviews: 82-100% of participants found recommendations aligned with expectations and justifications convincing, though some questionnaire terminology was unclear.
