## Summary

This paper addresses the limitations of traditional recommender system ranking, which often ignores item interactions and user preferences. It proposes a personalized re-ranking model using a transformer architecture that directly considers the global relationships between items and learns personalized encodings for users. Experimental results show significant performance improvements over existing methods.

## Technical note

PRM (Personalized Re-ranking Model) refines an initial ranked list by explicitly modeling mutual influence between items with a Transformer encoder whose self-attention captures pairwise item interactions at O(1) distance, unlike prior RNN-based re-rankers that degrade over encoding distance. It adds a personalization module: a pre-trained user embedding (personalized vector PV) concatenated with item features and position embeddings, so item-pair influence is encoded in a user-specific way. Deployable as a modular follow-up after any base ranker using existing feature vectors, PRM significantly outperforms RNN/DLCM baselines offline and lifts CTR and revenue in online A/B tests; the authors also release a large e-commerce re-ranking dataset.
