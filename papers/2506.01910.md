## Summary

This paper introduces **GLoSS**, a generative recommendation system that enhances sequential suggestions by combining large language models (LLMs) with dense semantic search instead of relying solely on lexical matching like BM25 used in previous methods such as GPT4Rec.

To make this efficient, the authors use a 4-bit quantized version of LLaMA-3 fine-tuned via LoRA, allowing operation on modest hardware. They demonstrate that GLoSS achieves state-of-the-art performance across three Amazon datasets (Beauty, Toys, Sports), significantly outperforming traditional ID-based recommenders and other existing LLM-based approaches in terms of Recall@5 and NDCG@5 metrics.

Furthermore, evaluations with different user segments highlight GLoSS's effectiveness for cold-start users and its benefit from longer interaction histories.

## Technical note

GLoSS is a generate-then-retrieve framework for sequential recommendation that fine-tunes a 4-bit quantized LLaMA-3 (via QLoRA) to generate a natural-language query describing the next item, then retrieves catalog items by dense semantic search (e5 encoders) rather than GPT4Rec's lexical BM25 matching. Evaluated on Amazon Beauty/Toys/Sports with full-catalog leave-last-out metrics, it sets state-of-the-art, improving Recall@5 by 15-53% over ID-based baselines (SASRec, TIGER, ActionPiece) and 4-30% over LLM baselines (P5, GPT4Rec, LlamaRec, E4SRec). Ablations show dense retrieval beats BM25 (largest gains in NDCG@5), and user-segment analysis shows strong cold-start performance on Toys/Sports.
