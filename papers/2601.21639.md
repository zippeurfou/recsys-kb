## Summary

Towards Holistic OCR in End-to-End Vision-Language Models":

1.  Existing OCR methods primarily focus on text-centric images, overlooking vision-centric ones like charts and web pages, which are common and valuable. This paper addresses this gap by introducing OCRVerse, a holistic OCR system designed for end-to-end vision-language models.
2.  OCRVerse tackles both text and vision-centric OCR by using a large, diverse dataset covering various document types and rendered composites, combined with a novel two-stage SFT-RL training method that adapts models to different domain requirements.
3.  The system demonstrates competitive performance across both text and vision-centric data types, showing its effectiveness and suggesting it can rival existing large-scale OCR models.

## Technical note

Existing OCR focuses on text-centric images and neglects vision-centric sources like charts, web pages, and scientific plots that are common and valuable. OCRVerse is presented as the first end-to-end holistic OCR system unifying text-centric and vision-centric recognition, backed by comprehensive data engineering across document types and rendered composites. It uses a two-stage SFT-RL training scheme: SFT mixes cross-domain data for initial knowledge, then RL applies per-domain customized reward strategies to handle differing output formats and avoid data conflicts. OCRVerse achieves competitive results across both data types, comparable to large open- and closed-source models.
