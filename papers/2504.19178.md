## Technical note

RCL (Relative Contrastive Learning) improves contrastive learning for sequential recommendation by using similar sequences (with different target items) as additional weak positive samples to overcome the scarcity of same-target sequences in supervised CL (e.g., ~47.5-52.7% of sequences lack any same-target sequence). It uses a dual-tiered positive selection module (same-target sequences as strong positives, similar sequences chosen via Jaccard/Bigram similarity as weak positives) and a weighted relative contrastive loss that adds a boundary to standard InfoNCE so each sequence is closer to strong than weak positives without pushing weak positives too far. On SASRec and FMLP across six datasets it achieves 4.88% average improvement over state-of-the-art.
