## Technical note

UxSID models ultra-long user behavior sequences (up to ~10k interactions) by introducing a middle path between item-specific search (SIM/TWIN) and item-agnostic compression (MIMN/C-Former): semantic-group shared interest memory keyed by candidate Semantic IDs, so semantically similar items share compressed interest. It uses Item-Agnostic Interest Compression (learnable interest anchors with per-token FFNs and an orthogonality constraint) plus Hierarchical Semantic Probing (a gated SID query over global behaviors and compressed interests), giving constant-time inference with online-offline parity. On public benchmarks UxSID reaches SOTA and a large-scale Kuaishou A/B test delivered a 0.337% advertising revenue lift.
