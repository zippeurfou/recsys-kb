## Summary

OmniSage addresses the challenge of integrating diverse entity representation techniques (graph neural networks, user sequences, content models) into a single large-scale framework. It achieves this unification by employing multiple contrastive learning tasks to effectively process graph data, user behavior sequences, and item content signals simultaneously. The system's efficient infrastructure allows it to handle Pinterest's massive graphs with billions of nodes during training and inference, resulting in significant improvements across various applications like search and recommendations.

## Technical note

Graph, sequence, and content-based representation methods each capture different signals but are rarely unified into one framework serving many applications. OmniSage is Pinterest's large-scale framework that learns universal multi-entity representations by integrating GNNs, user-sequence models, and content-based models via multiple contrastive learning tasks. It is backed by infrastructure that trains and serves graphs with billions of nodes. Deployed across five applications, the universal representations produced roughly a 2.5% sitewide increase in repins (saves), demonstrating the value of unifying representation-learning approaches.
