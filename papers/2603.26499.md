## Summary

AIRA_2 addresses three key performance bottlenecks in AI research agents: synchronous execution limiting throughput, a generalization gap causing performance degradation, and the limitations of single-turn LLM operators. To solve these, the system employs an asynchronous multi-GPU worker pool, a Hidden Consistent Evaluation protocol for reliable assessment, and ReAct agents for dynamic debugging. This combination significantly improves performance on MLE-bench-30, demonstrating necessary architectural changes and clarifying that prior "overfitting" was due to evaluation noise.

## Technical note

AIRA_2 is an AI research agent that targets three structural bottlenecks of prior search-based agents (e.g., AIRA-dojo): synchronous single-GPU throughput, a validation-test generalization gap, and limited fixed single-turn operators. It introduces an asynchronous multi-GPU worker pool with containerization that decouples decision-making from execution and scales throughput roughly linearly (8 GPUs ~ 8x experiments); a Hidden Consistent Evaluation (HCE) protocol that standardizes data splits once, hides evaluation labels, and decouples the search signal from final selection; and ReAct agents replacing all operators to dynamically scope actions and debug interactively. On MLE-bench-30 it reaches mean Percentile Rank 81.5% at 24h and 83.1% at 72h versus 72.7% for the strongest baseline, and exceeds human SOTA on 6/20 AIRS-Bench tasks. Ablations show each component is necessary, performance follows a scaling law transferring across LLM backbones, and prior reported overfitting was driven by evaluation noise rather than memorization.
