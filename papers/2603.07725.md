## Summary

Existing LLM-based recommendation systems using a "reason-then-recommend" approach suffer from unreliable reasoning, known as reasoning degradation, which negatively impacts recommendations.

To address this, the authors propose a new "reason-verify-recommend" paradigm and a system called VRec, which interleaves reasoning with verification using multiple specialized verifiers designed for reliability and multi-dimensionality.

Experiments show that VRec significantly improves recommendation effectiveness and scalability compared to existing methods, while maintaining efficiency.

## Technical note

VRec targets reasoning degradation (homogeneous and error-accumulated reasoning) in LLM-based generative recommendation that follows a reason-then-recommend paradigm without intermediate checks. It proposes a reason-verify-recommend paradigm that interleaves latent-space reasoning steps with verification steps, where each verification refines the reasoning outcome before the next step and item generation. Verifier design follows two principles: reliability, achieved via a proxy prediction objective that approximates reasoning-step quality since latent reasoning lacks natural supervision, and multi-dimensionality, achieved via a mixture of verifiers covering multiple facets of user preference. The final recommendation step autoregressively generates the next item from the verified reasoning outcome. Experiments on four real-world datasets report improved recommendation effectiveness and scalability without sacrificing efficiency.
