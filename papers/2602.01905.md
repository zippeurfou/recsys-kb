## Summary

Self-supervised learning faces a fundamental conflict between achieving high-level semantic understanding and enabling pixel-level image reconstruction. Existing methods either discard spatial information needed for reconstruction or fail to capture complex semantics effectively. The paper introduces STELLAR, a framework that resolves this tension by factorizing visual features into separate semantic concepts and their spatial distributions, allowing both high semantic accuracy (like DINO) and high-quality generative reconstruction (like MAE) using sparse tokens.

## Technical note

STELLAR resolves the self-supervised-learning conflict between semantic understanding (DINO-style invariance) and pixel reconstruction (MAE-style equivariance), which the authors attribute to an 'Invariance Paradox' of the dense feature grid. It factorizes visual features into a low-rank product of a sparse set of semantic 'what' tokens and an equivariant 'where' localization matrix, enabling DINO-style augmentation alignment (via optimal transport) on the semantic tokens while preserving spatial mapping for reconstruction. With as few as 16 sparse tokens it simultaneously reaches 2.60 FID reconstruction and 79.10% ImageNet linear accuracy, and induces region-aware fine-grained semantics without dense supervision.
