## Summary

1.  The paper introduces CoMeT, a novel plug-in module for Large Language Models (LLMs) designed to efficiently process extremely long sequences by overcoming the memory and computational limitations of standard Transformers.
2.  CoMeT uses a dual-memory system (a FIFO queue for recent events and a global memory with gated updates for long-range dependencies) to manage context across sequential data chunks, effectively acting as a dynamic soft prompt.
3.  This approach achieves constant memory usage and linear time complexity, enabling accurate processing of contexts up to a million tokens, matching full-attention performance on benchmarks, and demonstrating practical effectiveness on real-world tasks.

## Technical note

CoMeT is a plug-in memory module that lets pretrained Transformers process arbitrarily long sequences with constant memory and linear time by operating on chunks. It couples a FIFO temporary memory for recent fine-grained context with a gated global memory that shields salient long-range information, feeding both as a dynamic soft prompt to the next chunk. A layer-level pipeline parallelism strategy enables fine-tuning on up to 128k-token contexts with a 2.7x speedup over naive context parallelism. Trained only on 32k contexts, it retrieves passkeys anywhere in 1M tokens with 21x inference speedup and matches full-attention summarization on Scrolls, plus user-behavior QA tasks.
