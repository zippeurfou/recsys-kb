## Summary

This paper introduces an **exposure-based reinforcement learning (RL)** approach for ranking tasks. Standard RL methods struggle with the large action space in LTR settings and suffer from poor efficiency and stability issues during training due to custom gradient computations that clash with auto-differentiation.

The proposed method achieves high sample-efficiency by using baseline corrections and partial marginalization, significantly speeding up convergence compared to existing complex RL techniques for ranking. Crucially, it presents an abstraction placing gradient estimation behind a document-exposure distribution, enabling seamless integration of any differentiable loss function into the RL framework via auto-differentiation.

This simplification allows practitioners to utilize standard deep learning tools without implementing complex custom gradients, leading to faster convergence and higher ranking performance while maintaining stability on GPUs.

## Technical note

This paper reworks reinforcement learning for learning-to-rank to avoid complex custom gradients, focusing instead on variance reduction and GPU-friendly auto-differentiation. It combines baseline corrections with novel partial-marginalization estimators (marginalize-first and marginalize-all) for Plackett-Luce ranking policies, and an exposure-based estimator that places policy-gradient estimation behind the document-exposure distribution so any differentiable exposure-based loss (relevance, fairness-of-exposure, ranking distillation) can be optimized in a few lines via auto-diff. On MSLR-Web30k and Istella-S it converges in ~33% of the epochs of prior methods and reaches higher NDCG@10 (e.g., 0.4812 vs ~0.4789 on MSLR at N>=100), whereas the CPU-oriented PL-Rank custom gradient is numerically unstable in 32-bit float; the extra GPU cost is negligible. A pure ranking-optimization method, not a retrieval-plus-ranking pipeline.
