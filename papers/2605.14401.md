## Technical note

MARS (Memory-Augmented Agentic Recommender System) treats recommendation as a partially observable problem and maintains a structured, hierarchical belief state that abstracts noisy behavioral observations into a compact estimate of user preferences, rather than the flat memory used by prior memory-augmented LLM agents. Its belief state has three tiers: event memory buffering raw signals, preference memory holding fine-grained mutable chunks with explicit strength and evidence tracking, and profile memory distilling stable long-term preferences, with a defined lifecycle governing how memory evolves (e.g. promoting/demoting preference strength over rounds).
