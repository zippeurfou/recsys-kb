## Summary

1.  Existing recommender systems using LLMs often use flat memory, mixing unstable user signals with stable preferences, lacking a structured way to manage memory changes over time.
2.  The paper introduces MARS (Memory-Augmented Agentic Recommender System), which models recommendation as a sequential decision problem and uses a hierarchical belief-state memory organized into three tiers (event, preference, profile) to progressively refine user preferences from raw data.
3.  MARS employs a dynamic memory lifecycle (extraction, reinforcement, weakening, consolidation, forgetting, resynthesis) managed by an LLM planner, significantly outperforming baselines by 26.4% in HR@1 and 10.3% in NDCG@10 across standard recommendation benchmarks.

## Technical note

MARS (Memory-Augmented Agentic Recommender System) frames recommendation as a partially observable problem and maintains a structured belief state that abstracts noisy behavioral observations into a compact preference estimate. Memory is organized into three tiers: an event memory buffering raw signals, a preference memory of fine-grained mutable chunks with explicit strength and evidence tracking, and a profile memory distilling preferences into a natural-language narrative. A complete lifecycle of six operations (extraction, reinforcement, weakening, consolidation, forgetting, resynthesis) is adaptively scheduled by an LLM-based planner rather than fixed-interval heuristics. On four InstructRec domains MARS reports average gains of 26.4% HR@1 and 10.3% NDCG@10 over the strongest baselines, with further improvements from agentic scheduling in evolving settings.
