## Technical note

A/B Agent is a multimodal LLM-based user agent proposed as an alternative to costly online A/B testing for recommender systems. The authors build an IMDB-like movie recommendation sandbox supporting multimodal and multi-page interactions that mirror real user behavior, and design an agent with multimodal information perception, fine-grained preference modeling, profile and action-memory retrieval, and a fatigue system to emulate human decision-making and exploration. They validate the agent as an A/B-testing proxy from model, data, and feature perspectives, release the MM-ML-1M multimodal MovieLens dataset, and show agent-generated feedback data can effectively augment and improve recommendation models.
