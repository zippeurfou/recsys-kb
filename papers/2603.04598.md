## Summary

Researchers created the PinPoint benchmark to address limitations in existing Composed Image Retrieval (CIR) evaluation systems. PinPoint features a large dataset with multiple correct answers, explicit negatives, paraphrased queries, and multi-image compositions, revealing that top CIR methods still struggle with avoiding hard negatives, handling paraphrases, and managing multi-image queries effectively. To improve performance on these specific weaknesses, the authors introduced a simple, training-free reranking technique based on a large multimodal model (MLLM) that can be applied to any existing CIR system.

## Technical note

PinPoint is a large-scale zero-shot composed image retrieval (CIR) benchmark with 7,635 queries and 329K human-verified relevance judgments across 23 categories, adding multiple positives (avg 9.1/query), explicit hard negatives, six instruction paraphrases per query, multi-image compositional queries (13.4%), and demographic metadata (Monk Skin Tone) for fairness. It exposes weaknesses invisible to recall-only benchmarks like CIRR and FashionIQ: top methods still surface hard negatives ~9% of the time, vary 25.1% across paraphrases, and drop 40-70% on multi-image queries, with a text-only GPT baseline beating many specialized CIR systems. CIR methods span dual-encoder CLIP-style composition, learned combiners, and proxy-based retrieval with training-free fusion (weighted sum, SLERP, mean pooling). The authors add a model-agnostic, training-free MLLM reranking stage that consistently improves all systems.
