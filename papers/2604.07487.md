## Summary

1.  Existing large language model agents often struggle with adapting retrieved context from past experiences to fit new situations, placing a heavy reasoning burden on the model.
2.  To address this, the CLEAR framework trains a generative Context Augmentation Model (CAM) using contrastive analysis of past task executions, enabling it to create task-specific context summaries.
3.  Evaluated on benchmarks, CLEAR significantly improves task completion rates and execution rewards compared to strong baselines, demonstrating that generative context tailored to the current task is more effective than relying solely on retrieved past context.

## Technical note

CLEAR trains a lightweight context augmentation model (CAM, from Qwen3-32B) that maps a new task to auxiliary context appended to the execution agent's prompt, without touching the frozen (possibly proprietary) execution LLM's weights. Phase 0 runs each task m=6 times and uses an agentic reflector to contrast trajectories and distill instance-level instructions as SFT data; Phase 1 does SFT; Phase 2 optimizes the CAM with GRPO using the execution agent's outcome reward. Unlike ACE (training-free playbooks) or RAG (nearest-neighbor retrieval of past context), CLEAR shifts adaptation into a trainable generator. It lifts AppWorld TGC from 72.62% to 81.15% and WebShop-40k reward from 0.68 to 0.74, and transfers across execution backbones.
