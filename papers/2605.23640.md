## Summary

CachePrune addresses the trade-off between efficient KV cache sharing for faster LLM inference and privacy risks from cross-user cache reuse. It enables fine-grained sharing by allowing reuse at the token level, overcoming the limitations of existing coarse-grained methods. This approach eliminates leakage through cache reuse while significantly improving inference latency and cache hit rates compared to state-of-the-art alternatives.

## Technical note

CachePrune targets the tension between reusing KV caches across users to speed LLM inference and the privacy leakage that coarse-grained cross-user cache reuse can cause. It enables fine-grained sharing at the token level, pruning cache entries so that reuse eliminates leakage through the cache while still improving cache hit rates. The method reports significant reductions in inference latency versus state-of-the-art prompt/context caching baselines. It draws on named-entity/PII detection and cache side-channel literature to define what is safe to share. This is an LLM-serving systems paper rather than a recommendation paper.
