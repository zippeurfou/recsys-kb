## Technical note

PushGen is an automated LLM framework for generating high-quality push notifications comparable to human-crafted content while maintaining stylistic control and reliable quality assessment. It combines a controllable category prompt technique to steer LLM outputs toward desired styles and a pairwise reward model trained from small-traffic A/B paired comparisons to rank and select candidates pre-launch (better CTR alignment than pointwise scoring). Deployed at Kuaishou serving hundreds of millions of users daily, online A/B tests show +14.080% CTR (with 85.2% content replacement), +4.026% public-domain CTR, and +0.067% unique DAU; a related RAG pipeline using MoE models like DeepSeek V3 671B gave DAU +0.052% and CTR +4.330%.
