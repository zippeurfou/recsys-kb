## Summary

1.  Industrial multi-task recommendation systems often use shared deep learning models for multiple tasks (like user clicks or purchases) to save resources, but this can lead to detrimental effects known as negative transfer where some tasks perform worse than if trained separately.
2.  To address this, researchers propose MultiBalance, a gradient balancing technique designed specifically for large-scale systems, aiming to optimize each task effectively while using shared features.
3.  MultiBalance shows significant performance gains (e.g., +0.738% NE) without negatively impacting system speed (QPS), and is more efficient than prior methods because it only requires gradients from the shared representations rather than all model parameters.

## Technical note

Presents MultiBalance, a gradient-balancing method for industrial-scale multi-task recommendation that mitigates negative transfer without costly grid search over task weights. Unlike prior MGDA-style multi-objective optimization that balances per-task gradients over all shared parameters, MultiBalance balances gradients only with respect to the shared feature representation, drastically cutting compute and memory, and maintains a moving average of stochastic-gradient magnitudes to stabilize training. The paper proves the representation gradient is a good surrogate for parameter gradients and gives conditions for reaching a Pareto stationary point. On Meta's ads and feeds system it improved normalized entropy 0.738% at neutral QPS, versus 70-80% QPS degradation for parameter-gradient methods.
