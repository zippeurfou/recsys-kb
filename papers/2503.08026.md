## Technical note

RMM (Reflective Memory Management) is a memory mechanism for long-term personalized dialogue agents that combines forward- and backward-looking reflection. Prospective Reflection dynamically summarizes interactions across utterance, turn, and session granularities into a topic-based personalized memory bank optimized for future retrieval, while Retrospective Reflection iteratively refines the retriever online via reinforcement learning using the LLM's own cited-evidence attribution signals as unsupervised feedback. This overcomes fixed-granularity and fixed-retriever limitations; experiments on MSC and LongMemEval show consistent gains, including more than 10% accuracy improvement over the no-memory-management baseline on LongMemEval.
