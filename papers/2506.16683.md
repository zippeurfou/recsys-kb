Generative retrieval-based recommendation has emerged as a promising paradigm aiming at directly generating the identifiers of the target candidates. However, in large-scale recommendation systems, this approach becomes increasingly cumbersome due to the redundancy and sheer scale of the token space. ## Technical note

SimCIT (Simple Contrastive Item Tokenization) from Alibaba is an unsupervised deep quantization framework for generative-recommendation semantic tokenization based purely on contrastive learning rather than reconstruction. It argues reconstruction-based RQ-VAE aims to precisely reconstruct each item embedding independently, which conflicts with generative retrieval's goal of differentiating items and causes representation collapse in high-frequency clusters. SimCIT uses a learnable residual quantization module trained contrastively to align signals from multiple item modalities (text, image, geographic knowledge), unifying multi-modal alignment and semantic tokenization; experiments on public and large-scale industrial datasets show effectiveness in LLM-based generative recommendation.
