## Summary

Conversational agents often struggle with initiating dialogue effectively, as users may have unspoken needs before the conversation starts, creating a barrier. To address this, researchers introduced IceBreaker, a system designed to generate personalized starting conversations ("icebreakers") for users. IceBreaker frames this as a two-step process: first, identifying relevant interests (resonance), then generating engaging starters (interaction), using user data even when no explicit query exists, and has been shown to improve user engagement metrics in real-world deployment.

## Technical note

IceBreaker frames proactive conversation initiation as a two-step handshake: Resonance-Aware Interest Distillation (RID) trains a personalized resonance scorer via contrastive loss over interest-revisit positives with intra- and inter-user negatives, then applies activity-aware gated thresholding to distill trigger interests. Interaction-Oriented Starter Generation (ISG) warm-starts a generator (Qwen2.5-7B / Doubao1.5-Lite) with teacher-distilled instruction data, then aligns it with list-wise DPO using hierarchical negatives (utility, diversity, joint-failure) mined by a hybrid utility-diversity reward beam search. A self-reinforced loop re-samples candidates from the latest policy to combat sparse personalized feedback. Deployed A/B tests report +1.84 per-mille active days and +94.25 per-mille CTR.
