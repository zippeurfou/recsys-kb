## Summary

This paper introduces Chart-RL, a novel reinforcement learning framework designed to enhance the visual reasoning capabilities of Vision Language Models (VLMs) for Chart Question Answering (CQA). Addressing limitations in existing VLMs regarding numerical extraction and visual relationship interpretation, Chart-RL uses policy optimization and adaptive rewards to improve performance, while also incorporating Parameter-Efficient Fine-Tuning via Low-Rank Adaptation (LoRA). The framework demonstrates significant improvements, achieving higher accuracy with fewer parameters and reduced latency on the ChartQAPro benchmark dataset compared to baseline models.

## Technical note

Chart-RL is a reinforcement-learning framework that improves vision language models (VLMs) on Chart Question Answering, targeting VLM weaknesses in numerical extraction, implicit visual-relationship interpretation, and spatial attention over charts. It applies policy-optimization RL with adaptive reward functions to jointly refine visual perception and logical inference in a feedback-driven loop, and integrates parameter-efficient fine-tuning via Low-Rank Adaptation (LoRA) so training fits a single GPU. On the ChartQAPro benchmark, an RL-fine-tuned Qwen3-VL-4B-Instruct reaches 0.634 accuracy, beating the 0.580 of the larger Qwen3-VL-8B-Instruct at half the parameters while cutting inference latency from 31s to 9s. It also analyzes chain-of-thought reasoning across models, showing Chart-RL enhances visual reasoning.
