## Technical note

X-Cross (eBay) is a cross-domain sequential-recommendation model that integrates several domain-specific LoRA-fine-tuned language models, dynamically refining each source model's layer-wise representations by weighting knowledge from all others. It casts next-item prediction as a multiple-choice problem over candidate items given a textual user-history prompt. On Amazon datasets it matches LoRA fine-tuning while using only 25% of the additional parameters, and in cross-domain transfer (e.g. Toys to Tools/Electronics/Sports) needs about 50-75% less fine-tuning data than LoRA, outperforming mixture-of-LoRA cross-domain baselines.
