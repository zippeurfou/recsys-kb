## Summary

Generative Recommendation (GR) uses quantized item IDs for sequence modeling, but current methods struggle with leveraging multimodal data to create effective IDs and train models. To address this, the paper introduces MACRec, a method that incorporates multimodal information during ID learning via cross-modal quantization, reducing conflicts, and enhances generative training with multi-aspect cross-modal alignments. Experiments on recommendation datasets show that MACRec effectively improves GR model performance by better utilizing diverse data sources.

## Technical note

MACRec is a multimodal generative recommendation (GR) framework that injects cross-modal information into both semantic-ID learning and generative training. During item quantization it adds cross-modal contrastive learning (via K-means pseudo-labels and InfoNCE) at each RQ-VAE residual layer plus a cross-modal reconstruction alignment, so text and image codebooks reinforce each other, lowering item-ID collision rates and improving codebook usage. For the T5-based GR model it applies multi-aspect alignment: implicit latent-space contrastive alignment of a same item's text/visual semantic IDs and explicit generation tasks (predicting one modality's IDs from the other). On three Amazon datasets it beats TIGER, MQL4GRec and sequential baselines on HR/NDCG, with ablations confirming each alignment loss helps.
