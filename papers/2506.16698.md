## Technical note

For industrial ads-ranking with user sequences of 10^3-10^4 events, injecting content embeddings directly is too costly, so this work uses vector quantization to encode a compact Semantic ID as model input. It introduces VQ-fusion (a multi-task VQ-VAE fusing multiple content embeddings and categorical predictions into one SID), SIDE (a parameter-free SID-to-embedding conversion avoiding lookup tables), and Discrete-PCA (DPCA), a ternary {-1,0,1} generalization of residual quantization. Applied to a large-scale ads-ranking system it achieved 2.4x normalized-entropy gain and 3x reduction in data footprint versus traditional SID methods.
