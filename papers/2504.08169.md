## Summary

1.  The paper explores using Deep Hierarchical Ensemble Networks (DHENs), which combine multiple feature crossing modules, for predicting ad conversion rates (CVR) - the probability of user off-site actions like purchases.
2.  It systematically investigates practical challenges with DHENs by proposing specific architectures using multitask learning and different input sequences (on-site vs. off-site), alongside optimizing hyperparameters to determine the best configuration for CVR prediction.
3.  To tackle data sparsity issues common in CVR, the authors introduce a self-supervised auxiliary loss based on predicting future actions within user sequences. Their optimized approach achieves state-of-the-art performance compared to simpler standalone feature crossing models.

## Technical note

This applied paper from Pinterest studies how to make Deep Hierarchical Ensemble Networks (DHEN), which ensemble multiple feature-crossing modules (MLP, DCN, Transformer), work for web-scale ad conversion-rate (CVR) prediction, where labels are sparse, delayed, and noisy. It builds a multi-task framework with a single DHEN backbone predicting all conversion actions plus an auxiliary CTR head that adds labels and regularizes, and it models both on-site engagement sequences and off-site (matched and attributed) conversion-event sequences end-to-end rather than relying only on pretrained user embeddings. To combat label sparsity it introduces a self-supervised auxiliary loss that predicts future actions within the user sequence. The optimized configuration achieves state-of-the-art performance over standalone feature-crossing models and was deployed in 2024, significantly improving business metrics like Cost-Per-Acquisition.
