## Summary

ReMem-VLA addresses the limitations of existing Vision-Language-Action (VLA) models for robot control, which rely on the Markov assumption and struggle with long-term memory tasks. It introduces a novel recurrent memory mechanism using dual-level queries (frame-level for short-term, chunk-level for long-term) trained end-to-end, along with an auxiliary past observation prediction objective, to implicitly maintain and utilize relevant context over extended periods. This approach significantly enhances memory capabilities, demonstrated through simulations and real-world experiments, where ReMem-VLA outperforms memory-free baselines and surpasses MemoryVLA on memory-dependent tasks.

## Technical note

ReMem-VLA augments vision-language-action models for closed-loop robot control, which normally assume a Markovian single-step context, with a dual-level recurrent memory of learnable queries: frame-level queries propagate short-term context across consecutive frames while chunk-level queries carry long-term context across coarser temporal chunks. Both query sets update through a fixed gradient-free recurrent path (only what to store is learned, not how it propagates), trained end-to-end with an action-diffusion head and a Past Observation Prediction auxiliary objective that reconstructs prior RGB frames to strengthen visual memory. A bidirectional attention transformer connects the frozen VLM backbone to action, hindsight, and memory queries, and a slot-based streaming training scheme processes variable-length episodes in temporal order without cross-episode leakage. It outperforms memory-free baselines (pi-0.5, OpenVLA-OFT) and beats MemoryVLA on spatial, sequential, episodic, temporal, and visual memory tasks.
