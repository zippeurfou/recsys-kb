## Technical note

PTPM (Kuaishou) improves watch-time prediction for short-video recommendation by extending the Tree-based Progressive Regression Model (TPM), which discretizes watch time into ordinal intervals on a binary tree of conditional classifiers. Instead of TPM's fixed full binary tree (equal partitioning) it learns a personalized, context-aware tree per user-item pair via a Tree Structure Learning module that prunes a large global tree, trained with a self-critical objective so the pruned subtree outperforms the global tree; it also adds an unbiased conditional-learning module to counter the selection bias induced by TPM's conditional modeling. Offline results improve watch-time accuracy and online A/B tests validate it; PTPM is fully deployed serving over 400 million daily users.
