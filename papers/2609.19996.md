## Summary

This paper introduces a deep learning architecture for route planning that directly addresses the limitations of classic graph algorithms (no optimality guarantee) and prior data-driven methods (suffers from feedback loops). The core idea is to jointly optimize both the underlying cost function and the route ranking model in an end-to-end differentiable manner, enabling custom routes based on user preferences. To achieve this, the system uses offline multi-objective Dijkstra to find all Pareto optimal routes as candidates, then employs a neural network trained with a novel constrained loss function to produce the optimal routes according to any specified preference. Experiments demonstrate that this approach significantly outperforms existing methods in both route quality and the ability to generate customizable routes.

## Technical note

Amap route planning uses heuristic edge-cost functions, and data-driven methods that treat the user's actual trajectory as ground truth suffer a feedback loop with the navigation service. The paper runs a multi-objective Dijkstra offline to collect each request's Pareto-optimal route set as the complete candidate set, then builds a network that emulates shortest-path search with learnable linear-combination cost functions plus a cascaded MLP route-ranking module, trained end to end with a customizable constrained-optimization loss (optimize one route attribute such as deviation rate while others such as travel time stay under constraints, using unbiased attribute estimators and a batch sampling scheme that keeps constraints locally valid). Offline in Beijing and Shanghai, H-CJRP_R lowers deviation rate from 33.9% to 32.2% and from 35.5% to 33.9% versus the H-Lambda baseline while also reducing ETA and congestion. A three-day online A/B test reduced deviation rate from 36.1% to 35.3% (Beijing) and 38.9% to 38.2% (Shanghai) with travel time roughly held, a smaller gain the authors attribute to a weak deviation-rate estimator.
