## Technical note

This is the 4th-place RecSys Challenge 2025 solution (team ambitious) for building a Universal Behavioral Profile: user embeddings generalizing across six downstream tasks (churn, category, SKU, and three hidden). It ensembles four components concatenated together: a 252M-param heterogeneous causal transformer sequential encoder trained multi-task (Next Event Type, Time Delta, Next URL, and Next Item Prediction with improved logQ-corrected sampled softmax and in-batch+uniform negatives), the TwHIN graph neural network on a user-item cart/purchase graph, a DCN-v2 deep cross network with a contrastive-learning objective over masked-history augmentations, and 300+ handcrafted features over multiple time windows. Ablations show NIP is the most critical sequence objective, contrastive loss helps all tasks, and larger encoders improve results; the entry scored e.g. churn 0.7389 and SKU 0.8041 on the leaderboard.
