## Technical note

OneRec replaces the cascade retrieve-and-rank pipeline with a single unified end-to-end generative recommender. It uses an encoder-decoder architecture with sparse Mixture-of-Experts (MoE) to scale capacity without proportional FLOPs, a session-wise list generation approach (instead of point-by-point next-item prediction), and an Iterative Preference Alignment (IPA) module using Direct Preference Optimization (DPO) with self-hard negative samples drawn from beam-search results and ranked by a personalized reward model. Items are indexed with semantic IDs via balanced residual K-means quantization (avoiding RQ-VAE's hourglass code collapse). Deployed in Kuaishou's main scene (hundreds of millions of DAU), it achieved a 1.6% watch-time increase, the first generative model to surpass well-designed cascade systems.
