## Summary

This paper addresses a trade-off in semantic ID-based generative retrieval, where popular items (head items) are prone to ID collisions and unpopular items (tail/cold-start items) suffer from data sparsity and poor generalization. The proposed SA²CRQ framework tackles these issues using Sequential Adaptive Residual Quantization (SARQ) to assign tailored IDs based on item popularity and entropy, and Anchored Curriculum Residual Quantization (ACRQ) to transfer knowledge from head items to sparser tail items via a frozen semantic manifold. Experimental results demonstrate that SA²CRQ improves retrieval performance, especially in challenging cold-start scenarios, across both industrial and public datasets.

## Technical note

SA2CRQ tackles the head/tail trade-off in semantic-ID generative retrieval, where head items suffer ID collisions and cold-start tail items suffer semantic fragmentation. Built on RQ-VAE, Sequential Adaptive Residual Quantization (SARQ) dynamically sets each item's code depth by evaluating cumulative path entropy against a per-layer information budget, giving head items longer discriminative IDs and tail items shorter generalizable ones. Anchored Curriculum Residual Quantization (ACRQ) first learns hierarchical head codebooks under a monotonically increasing codebook-size curriculum (an Information-Bottleneck-style constraint), then transfers to tail items via a hybrid codebook that freezes the head anchor and trains only an extension via gradient masking, using head path-probability tables as priors. Two-stage head-then-tail training improves retrieval and cold-start coverage over TIGER and RQ-Kmeans on industrial and public data.
