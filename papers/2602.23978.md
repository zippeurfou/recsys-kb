## Technical note

SA2CRQ (Anchored Curriculum with Sequential Adaptive Quantization), from JD, resolves a structural trade-off in semantic-ID generative retrieval under long-tail data (1% of items hold ~79.34% of interactions): head items suffer ID collisions while sparse tail/cold-start items suffer semantic fragmentation into isolated points. Sequential Adaptive Residual Quantization (SARQ) dynamically allocates code length via information-theoretic path entropy against a per-layer budget, giving head items longer discriminative IDs and tail items shorter generalizable ones. Anchored Curriculum Residual Quantization (ACRQ) is a two-stage curriculum that learns a frozen semantic manifold from head items and uses it as a topological anchor to regularize tail/cold-start representation learning. It consistently beats baselines on a large-scale industrial search system and public datasets, especially in cold-start retrieval.
