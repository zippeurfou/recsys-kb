The core component is the item code, generally derived by quantizing collaborative or semantic representations to serve as candidate items identifiers in the context. ## Technical note

UNGER integrates semantic and collaborative knowledge into a single unified item code for generative recommendation, avoiding the cost and complementarity loss of maintaining separate per-modality codes (as in TIGER/EAGER). It adaptively learns an integrated embedding via joint cross-modality alignment and next-item-prediction objectives, then uses an intra-modality knowledge distillation task with the integrated embeddings as supervision to compensate for quantization information loss. On three benchmarks UNGER outperforms existing generative recommenders that rely on separate collaborative or semantic codes.
