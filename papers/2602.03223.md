## Summary

This paper addresses the challenge of embedding streaming numerical features for CTR prediction, where traditional static binning methods cause semantic drift and standard neural embeddings discard distributional information. To overcome these limitations, the authors propose DAES, an end-to-end framework integrating streaming distribution estimation via reservoir sampling and field-aware distribution modulation. DAES significantly outperforms existing methods in offline and online experiments and has been deployed on a major platform.

## Technical note

DAES tackles numerical feature embedding for CTR prediction under streaming (single-pass, non-i.i.d.) training, where static binning causes semantic drift and neural embeddings discard distributional priors. It estimates streaming quantiles via reservoir sampling with a jump-sampling optimization, then encodes values in quantile space and aggregates learnable meta-embeddings. Two field-aware distribution-modulation strategies (a gating network and a parameter generator) inject context-dependent, field-specific semantics without combinatorial blow-up. DAES is end-to-end trainable, outperforms prior methods offline and online, and is deployed on a short-video platform with hundreds of millions of DAU.
