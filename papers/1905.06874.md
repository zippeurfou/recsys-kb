## Summary

BST puts a single-block Transformer encoder over the user behavior sequence (with the target item appended) using a custom time-gap positional embedding, then concatenates the target-position output with other features into an MLP for CTR. Deployed at Taobao.

## Technical note

BST (Alibaba/Taobao, DLP-KDD 2019) stacks a Transformer encoder on top of the WDL Embedding&MLP paradigm to model the user behavior sequence. Each item is represented by item_id+category_id embeddings plus a custom positional feature pos(v_i)=t(v_t)-t(v_i) (recommendation time minus click time), which beat sin/cos encodings. The target item is appended to the sequence so multi-head self-attention (8 heads, scaled dot-product, one block b=1 works best) contextualizes it against history; the target-position output is concatenated with other/user/context/cross features into a 3-layer MLP with sigmoid CTR head. Seq length 20; offline AUC 0.7894 vs DIN 0.7866 / WDL 0.7734, +7.57% online CTR.
