## Summary

This paper introduces methods for efficient large-scale cross-domain sequential recommendations. It addresses a computational bottleneck found when using standard transformer architectures across multiple item domains, as transformers attend to all items regardless of relevance. The proposed solutions include Transition-Aware Positional Embeddings (TAPE) and Dynamic Domain State Representation (DDSR), which restrict attention only within relevant domains during prediction steps, significantly improving efficiency without relying on full inter-domain attention maps.

## Technical note

This work makes autoregressive recommendation models (HSTU-style) efficient for cross-domain sequential recommendation, where full transformer attention over all items across every domain is a quadratic computational bottleneck. It restricts self-attention to intra-domain subsequences and captures inter-domain knowledge via two mechanisms: Transition-Aware Positional Embeddings (TAPE), which add a learnable signal at domain-transition points so the model adapts across domains without full cross-domain attention, and Dynamic Domain State Representation (DDSR), which caches and updates a per-domain state accessed during subsequent token predictions. Domain labels are provided as a prior since they are available commercially. Theory and experiments show reduced computation while preserving strong next-item retrieval performance, validated by ablations separating inter- and intra-domain modeling.
