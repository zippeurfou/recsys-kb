## Technical note

Sherlock is a JD.com framework for e-commerce fraud/risk case investigation that grounds LLM reasoning in structured domain knowledge to avoid spurious zero-shot judgments (e.g., misreading benign IP clustering as bot activity). It distills heterogeneous expertise into a domain Knowledge Base, applies a two-stage retrieval-augmented generation with a Reflect & Refine module, and runs a self-evolving data flywheel combining KB hotfixes with periodic post-training. Online A/B tests achieve an 82% Expert Acceptance Rate and +386.7% daily investigation throughput; a 90-day evaluation shows the flywheel recovers from tactic drift twice, raising the EAR ceiling ~3.5%.
