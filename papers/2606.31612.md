## Summary

Mobile GUI agents face challenges with complex, long-term tasks due to limitations in existing passive memory systems. To address this, the paper introduces Active Task Driving Memory (ATMem), which actively tracks data roles and status during execution. They further propose STR-GRPO, a reinforcement learning method that selectively uses ATMem based on its contribution to task completion, demonstrating its effectiveness using a challenging benchmark.

## Technical note

Mobile GUI agents struggle with long-horizon tasks because existing memory is passive storage: retrieving a value does not reveal whether it is pending, ready, or already used, causing repeated or missed operations. The paper proposes ATMem (Active Task-Driving Memory), an agent-maintained hierarchical execution state (workflow-level phase/constraints plus schema-level item content with remaining/finished/skipped status) injected into the prompt each step, trained via SFT on verifier-gated trajectories and STR-GRPO, an interventional online RL method that contrasts paired memory-ON/memory-OFF rollouts with a memory-cost penalty to learn selective memory use. They also build DataScope, a multi-entry cross-app benchmark with controlled distractor-to-target ratios (1.39x to 3.22x) and new App-Level Progress and Scope-Aware F1 metrics. With an 8B model, ATMem-UI reaches 76.6% success on AndroidWorld, beating UI-TARS-2-230B by 3.3 points and same-size MAI-UI by 5.9, and STR-GRPO improves SR while cutting memory invocation by 16.3 points versus SFT.
