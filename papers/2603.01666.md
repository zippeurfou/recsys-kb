## Summary

This paper addresses the challenge of efficiently retrieving information from visually-rich documents by tackling a storage bottleneck in existing multi-vector retrieval systems. The proposed solution, ColParse, uses a document parsing model to generate compact, layout-aware sub-image embeddings and combines them with a global page vector. Experiments show that this approach reduces storage requirements by over 95% while improving retrieval performance across various benchmarks.

## Technical note

ColParse targets the storage bottleneck of multi-vector (late-interaction) retrieval for visually-rich documents, where grid-based patch tokens are numerous and layout cues are lost under naive pruning or merging. It uses a document parsing model to produce a small set of layout-informed sub-image embeddings, one per structural region, and fuses them with a global page-level vector to form a compact, structurally-aware multi-vector representation. This preserves fine-grained layout signals while drastically shrinking the index. Experiments across numerous Visual Document Retrieval benchmarks and base models show over 95% storage reduction alongside retrieval performance gains, bridging fine-grained accuracy with large-scale deployment feasibility.
