## Technical note

The Differentiable Auditory Loop (DAL) is an open-source ML framework for personalized hearing-aid design that moves beyond fixed frequency-dependent amplification/compression toward correcting the underlying encoding dysfunctions of hearing loss. It ports CARFAC, a differentiable biomimetic cochlear model, to JAX and uses it to compare neural activity patterns (NAPs) and stabilized auditory images from a normal-hearing reference model versus a model fitted to each subject's impairment, defining loss functions on those representations. A SEANet waveform-to-waveform convolutional UNet generator is fine-tuned by gradient descent to denoise input and compensate for the modeled loss, outperforming master-hearing-aid baselines on neural-representation and signal-fidelity metrics, with hardware deployment as future work.
