## Summary

This paper addresses the problem of learning a similarity metric from triplet comparisons in Reproducing Kernel Hilbert Spaces (RKHS), where items are compared to determine relative similarities and dissimilarities. While nonlinear methods using kernels show promise empirically for various applications like image retrieval and recommendations, there was a significant lack of theoretical understanding regarding their performance beyond linear cases (Euclidean space). The authors bridge this gap by developing a general RKHS framework for metric learning and proving novel sample complexity bounds that guarantee how well the learned metric will generalize to unseen data.

## Technical note

The paper provides theory for nonlinear metric learning from triplet comparisons ("is h more similar to i or j?"), a task central to image retrieval and recommendation. It formulates learning a Mahalanobis-style metric via a bounded linear operator in a reproducing kernel Hilbert space (RKHS), generalizing the well-understood linear/Euclidean case. It derives the first generalization-error and sample-complexity guarantees for kernelized triplet metric learning and characterizes how regularization affects those bounds, while removing the linear setting's requirement that item count exceed dimension. Simulations and real-dataset experiments corroborate the theory.
