## Summary

Metric learning from a set of triplet comparisons in the form of "Do you think item h is more similar to item i or item j?", indicating similarity and differences between items, plays a key role in various applications including image retrieval, recommendation systems, and cognitive psychology. ## Technical note

This Amazon theory paper develops a general RKHS framework for nonlinear metric learning from triplet comparisons ('is item h more similar to i or j?'), applicable to image retrieval and recommendation. It establishes the first generalization-error and sample-complexity guarantees for kernelized metric learning (generalizing the linear Mahalanobis case), and characterizes how regularization affects these bounds. Results are validated with simulations and real-dataset experiments, with public code.
