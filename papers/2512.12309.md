## Summary

The paper introduces WeDetect, a novel open-vocabulary object detection system that treats detection as a retrieval problem by matching regions to text prompts in a shared embedding space. WeDetect consists of three main components: a dual-tower detector (WeDetect) achieving real-time performance and state-of-the-art results, a universal proposal generator (WeDetect-Uni) that can retrieve object proposals across categories from historical data, and an LMM-based classifier (WeDetect-Ref) for handling complex referring expressions efficiently. Together, the WeDetect family unifies detection, proposal generation, retrieval, and referring expression comprehension under a retrieval framework, offering high performance and efficiency.

## Technical note

WeDetect casts open-vocabulary object detection as a retrieval problem, matching image regions to text queries in a shared embedding space via a non-fusion dual-tower architecture, avoiding slow cross-modal fusion. WeDetect finetunes a CLIP model with a ConvNeXt backbone and YOLO-World-style region-text contrastive head, trained on a 15M-image/330M-box dataset built by an MLLM-driven data engine with multi-granularity labels. WeDetect-Uni freezes the detector and tunes only an objectness prompt to produce class-specific proposals enabling a new fine-grained object-retrieval task, and WeDetect-Ref uses an LMM classifier to resolve referring expressions in a single forward pass (no next-token decoding). The family hits SOTA across 15 benchmarks with high throughput (e.g., 49.4 AP on LVIS, 13x speedup on RefCOCO).
