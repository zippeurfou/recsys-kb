## Summary

1.  Current retrieval-augmented agents often perform inefficient, exploratory search requiring multiple iterative queries, similar to a novice user navigating a database.
2.  The paper introduces the SuperIntelligent Retrieval Agent (SIRA), designed to perform this complex retrieval task in a single, optimized step by leveraging LLMs to understand both the query and the document corpus deeply.
3.  SIRA achieves significantly better performance than existing methods by formulating a single, validated query using LLM cognition and corpus statistics, leading to faster, more accurate, and more efficient retrieval.

## Technical note

SIRA (Superintelligent Retrieval Agent) compresses multi-round exploratory search into a single corpus-discriminative retrieval action, asking not merely which terms are relevant to a query but which terms separate the desired evidence from corpus-level confusers. Offline, an LLM enriches each document with missing search vocabulary; at query time it predicts evidence vocabulary the query omitted; corpus statistics are used as tool calls to filter proposed terms that are absent, overly common, or unlikely to create retrieval margin. The final step is a single weighted BM25 call combining the original query with the validated expansion, leveraging BM25 transparency, IDF rewarding of rare discriminative terms, and auditability, with no relevance labels or retriever fine-tuning. Across ten BEIR benchmarks SIRA beats dense, learned-sparse, and LLM search-agent baselines, and on NQ/HotpotQA its retrieval-only answer coverage exceeds RL-trained agentic QA systems. The authors also release BrowseComp-Wikipedia (232 hard queries over a 25.6M-document index), where SIRA outperforms multi-round Perplexity agents at every retrieval budget.
