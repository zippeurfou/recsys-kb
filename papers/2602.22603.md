## Summary

Long-running agentic tasks require reasoning across many documents, but standard LLM context (KV cache) becomes dominated by external tokens, rapidly increasing memory usage and slowing down processing.

Existing KV cache compression techniques struggle with the complex reasoning needed in multi-step agentic tasks.

The paper introduces SideQuest, a novel system that uses a separate LRM to *reason* about and actively compress the KV cache during the main task, treating compression as a parallel auxiliary task. This approach significantly reduces peak memory usage (up to 65%) with minimal accuracy loss, outperforming traditional heuristic-based compression methods.

## Technical note

SideQuest frames KV cache compression as an auxiliary task run in a parallel thread that shares the main agent's context, letting the LRM reason about which stale tool responses (cursors) to evict rather than relying on attention-score heuristics like H2O, SnapKV, or StreamingLLM. Eviction targets are learned via hindsight annotation: correct ReAct traces are analyzed to compute each cursor's last-use index, and auxiliary traces teach the model to emit structured deletion commands under a 'memory management mode' trigger. Training jointly optimizes cross-entropy on auxiliary traces and logit-distillation loss on main traces to prevent catastrophic forgetting of reasoning skills. On agentic benchmarks it cuts peak token usage by up to 65% with minimal accuracy loss, outperforming heuristic eviction on dynamic, non-monotonic token utility.
