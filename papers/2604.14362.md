## Summary

Large language models often struggle with maintaining reliable long-term conversational memory, as simple context window expansion or basic retrieval can introduce noise and instability. To address this, the paper introduces APEX-MEM, a system combining a domain-agnostic property graph for event structuring, append-only storage to preserve history, and a retrieval agent that resolves conflicting information to create concise summaries. This approach significantly improves performance, achieving higher accuracy on standard benchmarks than state-of-the-art session-aware methods, demonstrating that structured, temporal memory enhances long-term conversational reasoning.

## Technical note

APEX-MEM is a long-term conversational memory system that structures dialogue as a directed property graph over a domain-agnostic 35-class entity-event ontology (YAGO-like), with facts stored as temporally-grounded subject-property-value assertions anchored to conversational events. It uses append-only storage to preserve the full temporal evolution of information (including contradictions), deferring conflict resolution to query time rather than overwriting. A ReAct-style QnA agent operating over a SQLite-backed graph interleaves reasoning with four tools: SchemaViewer (meta-planning), EntityLookup (RAG-based entity linking/canonicalization), GraphSQL (structured temporal traversal), and hybrid semantic+lexical Search. It reaches 88.88% on LOCOMO QA and 86.2% on LongMemEval, outperforming session-aware baselines.
