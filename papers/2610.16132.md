## Summary

This paper addresses the challenge of incorporating target-side features (like item attributes) into autoregressive generative recommendation models (UniSGR), where these features are unknown during decoding. The proposed TacGR model improves upon this by anticipating a continuous target-side feature vector *before* decoding each semantic-ID token, integrating it with the prefix and user history to directly condition generation and enable final ranking, mitigating the high conditional entropy and feature vacuum issues.

To overcome potential problems like target collapse and noise propagation in the continuous regression, TacGR employs a semantic-anchoring auxiliary tower and a unidirectional visibility mask. It also handles long industrial behavior histories using gated convolutional denoising and adapts the pyramid memory funnel structure to reduce inference cost.

Offline experiments on Lazada data show TacGR significantly outperforms existing models like OneRec, UniRec, and UniSGR. Online A/B testing further confirms its effectiveness, demonstrating improvements in metrics like IPV (0.79%), Order (5.55%), and GMV (3.09%).

## Technical note

Semantic-ID generative recommenders cannot see target-item side features (category, brand, shop) during token-by-token decoding, a target-side feature vacuum that raises conditional entropy at every SID level and removes the target feature crossing discriminative CTR models rely on. TacGR (UniSGR-V2) inserts a prediction token before each of the L=3 SID codes that regresses a continuous 128-d side-feature vector from the decoder hidden states and the previous code embedding (user-history mean pooling for the cold first level), crosses it with the semantic prefix and behavior memory inside a GQA plus SwiGLU-MoE decoder, and feeds the crossed vector both to the per-level code softmax and to a PLE multitask CTR/ATC/CVR head. A training-only anchoring tower that consumes the true side features under the business losses prevents the learnable regression target from collapsing, a unidirectional visibility mask stops prediction noise from reaching semantic tokens, and paired forward passes keep decoding at L passes; a gated depthwise-conv denoiser and a pyramid memory funnel handle 1024-length histories. On 2.42B Lazada samples TacGR beats UniSGR on all retrieval and ranking metrics (CLK HR@100 0.3148 vs 0.3031, PAY HR@500 0.6490 vs 0.6321, pay AUC +0.79%) and UniRec Chain-of-Attribute by 1.5-3.1%, and online A/B lifts IPV +0.79%, orders +5.55% and GMV +3.09%.
