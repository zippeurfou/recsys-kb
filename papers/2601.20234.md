## Summary

Large recommendation models face significant memory overhead due to storing user interaction sequences, a problem exacerbated by the scaling of these systems. To address this gap, the authors introduce MALLOC, a benchmark specifically designed to evaluate memory-aware compression techniques for large sequential recommendation models. MALLOC provides an evaluation platform demonstrating the reliability of these techniques across accuracy, efficiency, and complexity, helping researchers advance memory management in recommendation systems.

## Technical note

MALLOC is a benchmark for memory-aware long-sequence compression in large sequential recommenders, motivated by a 'memory-latency dilemma' where full KV caching of 1000+ length sequences needs ~545 GB while re-computation raises cost ~450x. It classifies memory-management / KV-cache-compression techniques (sequence compression, token merging/pruning, grouped/shared KV heads, low-bit quantization) by memory-allocation granularity and integrates them into SOTA recommenders like HSTU and MARM. Evaluation spans accuracy, compute overhead, and memory occupation, building an accuracy-resource Pareto frontier to give deployment guidelines for scaling recommendation models.
