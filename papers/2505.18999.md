## Summary

This paper introduces LERG (Lightweight Embeddings with Rewired Graph), an extension of their earlier LEGCF model designed specifically for resource-constrained edge devices needed in large-scale recommendation systems. The key challenges addressed are the high storage costs and heavy computation associated with graph propagation using GNNs on these limited devices. LERG improves upon LEGCF by combining quantization techniques to lower embedding storage needs, allowing more meta-embeddings, with a gradient-free pruning method that creates a sparse rewired graph, optimizing computations for faster inference while maintaining strong recommendation performance compared to previous methods and significantly reducing costs.

## Technical note

GNN-based recommenders are costly to deploy on edge devices due to large embedding storage and heavy graph-propagation MACs, and the authors' prior LEGCF degraded under strict storage limits and ignored runtime cost. LERG keeps LEGCF's compositional codebook (dense meta-embeddings plus a sparse fixed assignment matrix initialized via METIS) but applies learned step size quantization (LSQ) to store meta-embeddings as low-bit integers, allowing more meta-embeddings under the same budget and reducing collisions. It pretrains the quantized table on the full graph on servers, then formulates high-contribution entity selection as a binary integer program (relaxed to LP, solved via simplex) using an entity-entity similarity matrix from pretrained embeddings to build a sparse rewired graph, pruning low-contribution nodes from propagation. Experiments on three benchmarks including industrial-scale iFashion show superior recommendation accuracy with dramatically reduced storage and computation for graph propagation.
