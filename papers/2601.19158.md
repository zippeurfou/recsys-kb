## Technical note

CAUSE is a simple categorical user-sequence compression framework for efficient generative recommendation on long histories. It partitions a user's interactions into a recent sequence (for next-item and action prediction) and a distant historical sequence, then condenses the long-term history into a compact set of history tokens using item categorical features, preserving user interests while cutting compute. Training uses an InfoNCE next-item loss with negative sampling plus an optional action-prediction cross-entropy. Compared with the HSTU model on two large-scale datasets, CAUSE achieves up to a 6x reduction in computational cost and up to 39% higher accuracy at comparable sequence length/cost.
