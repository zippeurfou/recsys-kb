## Summary

1.  Recommender systems often suffer from biases in user feedback, leading to poor performance in either predicting actual user behaviour (factual test) or long-term satisfaction (counterfactual test), depending on the debiasing method used.
2.  To address this limitation, the paper introduces BPL (Bias-adaptive Preference Distillation Learning), a novel framework that employs dual distillation strategies during training.
3.  BPL combines knowledge from a biased teacher model (for factual accuracy) and a self-distillation process (for counterfactual generalization) with reliability filtering, ultimately improving performance on both types of tests simultaneously.

## Technical note

BPL (Bias-adaptive Preference Distillation Learning) targets the trade-off in recommender debiasing where methods optimize either factual accuracy (predicting observed behavior) or counterfactual/long-term satisfaction but not both. It uses dual distillation during training: knowledge from a biased teacher model preserves factual accuracy, while a self-distillation process promotes counterfactual generalization, and a reliability-filtering mechanism selects trustworthy signals. By combining these, BPL improves performance simultaneously on factual and counterfactual (missing-not-at-random / uniform-data) test settings rather than sacrificing one for the other, addressing selection bias in user feedback.
