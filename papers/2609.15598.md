## Summary

This paper addresses the challenge of evolving user preferences in generative recommendation systems. The authors propose LION, a novel framework using a sparse Key-Value memory layer to isolate and manage different user behavioral patterns effectively. By activating specific memories and using a consolidation loss, LION prevents dominant patterns from overshadowing less common ones and demonstrates improved performance across various continuous evolution scenarios.

## Technical note

Meta studies continual self-evolution of TIGER-style generative recommenders (T5 encoder-decoder autoregressively emitting semantic-ID token sequences) and identifies evolution conflict: because all users share one autoregressive parameter space, gradients from common and uncommon behavioral patterns conflict (g_c^T g_unc < 0) with strongly asymmetric magnitudes (norm of g_c much larger than g_unc), so period-over-period fine-tuning improves active users while degrading inactive ones and can drop aggregate metrics. LION inserts a sparse Key-Value memory layer into intermediate Transformer layers: N trainable (k_i, v_i) pairs, similarity s_i = h_u^T k_i, Top-K slot selection, min-max normalized weights aggregating values into m_u, added residually as h_tilde = h_u + m_u; crucially the memory query is computed from the user FULL interaction history while the backbone layers only see a recent window. A consolidation loss supervises next-item prediction directly from the memory-enhanced representation, combined as L_rec + lambda L_con. Setup: three Amazon Review datasets (Games, CDs, Toys), each split into five equal-interaction chronological periods with users bucketed into five activity quintiles, inputs of at most 10 prior interactions, beam search with beam 20, Recall/NDCG@10/20 micro-averaged over 4 evaluation periods times 5 groups. Results: vs the TIGER continual fine-tuning baseline, Recall@10 rises +29.8 percent on Games (0.0724 vs 0.0558), +35.5 percent on CDs (0.0449 vs 0.0331) and +15.6 percent on Toys (0.0769 vs 0.0666), beating Replay, SAIL-PIW, PISA, RecICL, LSAT and PESO, with consistently larger gains on inactive groups G3-G5 and stable gains across all four periods. The ablation is the most instructive part: adding the consolidation loss alone actually hurts (Games 0.0532 vs 0.0558) because it re-exposes the shared backbone to the same cross-pattern conflict, and the sparse memory layer alone is roughly neutral; only SML plus full-sequence query plus consolidation delivers the jump. Diagnostics confirm the mechanism: cross-group gradient cosine on the memory layer goes from negative under TIGER to uniformly positive under LION, the same holds for popular (top 60 percent) vs long-tail (tail 40 percent) item gradients, and eval loss converges faster and lower in every period. Parameter cost is 2Nd independent of user population, and Recall@10 stays within 0.4 percent across a 16x range of memory vocabulary (4,096 to 65,536 keys) and 4x range of K. Caveat: public Amazon benchmarks only, no production A/B despite the industry affiliation.
