## Technical note

CAT-ID2 (Meituan) is a document-identifier learning method for e-commerce generative retrieval that integrates native category-tree prior information into semantic IDs, which prior methods ignore. It uses a Hierarchical Class Constraint Loss to inject category information layer-by-layer during quantization, a Cluster Scale Constraint Loss for uniform ID token distribution, and a Dispersion Loss to improve distinctiveness of reconstructed documents, so similar documents get similar IDs while remaining unique. Offline and online A/B tests confirm effectiveness, with +0.33% average orders per thousand users on ambiguous-intent queries and +0.24% on long-tail queries.
