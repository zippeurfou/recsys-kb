## Summary

TokenMinds addresses limitations of traditional dense user embeddings in large recommender systems by combining them with discrete SID-based user tokens generated via a pre-trained LLM-derived system.

The core innovation is an encoder-decoder architecture that produces both types of representations simultaneously, leveraging the semantic grounding of SIDs while retaining compatibility with existing dense embedding models used for downstream tasks like ranking.

This dual-token approach improves user understanding and reduces costs by enabling cross-scenario modeling using a shared SID vocabulary, validated through offline experiments and large-scale live deployments on YouTube platforms.

## Technical note

TokenMinds is an industrial user-modeling system that extends the PLUM generative framework from item retrieval to sequential user modeling, producing both discrete SID-based user tokens (decoder) and dense user embeddings (encoder) from one encoder-decoder model adapted from a pretrained LLM. Videos are represented by hierarchical Semantic IDs from an RQ-VAE (retaining a prefix of L<8 codebook levels for coarser granularity and less memorization); the encoder ingests interleaved SID + engagement/text features, and the decoder autoregressively generates SID tokens for near-future watches via look-ahead sampling of multiple targets weighted by an engagement reward, with the encoder supervised only through cross-attention gradients. The shared SID vocabulary enables cross-scenario modeling of long-form and short-form video via prepended condition tokens and multi-context decoding (one shared encoder pass, scenario-specific decoder prefixes), cutting training compute 50% and serving compute 31%. Deployed on billions of YouTube users via an asynchronous User Behavior Service that decouples representation generation from ranking, it shows dense and discrete representations are complementary, with live gains up to +0.11% core user and +0.62% engagement metrics.
