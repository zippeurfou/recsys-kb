## Summary

LLMs struggle to learn complex reasoning tasks via traditional in-context learning (ICL) due to limitations like high attention costs and poor scaling with longer contexts. To address this, the authors propose ReasonCACHE, which uses Prefix Tuning to distill reasoning knowledge into a fixed key-value cache without modifying the model's weights. This approach allows LLMs to reason efficiently beyond the typical context window, outperforming standard ICL, matching or exceeding in-weight learning methods, and being more efficient in data, inference cost, and trainable parameters.

## Technical note

ReasonCache lets LLMs learn reasoning without weight updates by using prefix tuning to distill many demonstrations into a fixed, learnable key-value cache at each attention layer, keeping the backbone frozen and avoiding the quadratic-context and length-degradation limits of scaling in-context learning. On reasoning benchmarks (GSM8K, MATH, AIME, GPQA-Diamond) it matches or beats in-weight methods like SFT and LoRA while using ~59% less data, ~46% fewer trainable parameters, and generating shorter reasoning chains. The authors prove ReasonCache can be strictly more expressive than low-rank updates by injecting KV directions directly, bypassing an input-dependent 'carrier bottleneck', confirmed by ~20% higher effective rank.
