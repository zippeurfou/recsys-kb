## Technical note

PA-Bridge (Passive-Active Bridge) improves conversation-starter recommendation in LLM conversational search, breaking the closed exposure-click feedback loop (where the top 1% of starters get 70% of exposure) by harnessing users' active free-text queries, which carry open-world intent. It handles the distribution shift between active queries and formulated starters with an adversarial distribution aligner (a discriminator forcing domain-invariant encodings) and, since open text is non-ID-able, a semantic discretizer using RQ-VAE to quantize queries into discrete semantic IDs so popularity-debiasing can run in industrial streaming training. Online A/B tests show a 0.54% Feature Penetration Rate gain and 0.04% User Active Days lift, with a 6.27% offline gain.
