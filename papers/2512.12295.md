## Summary

Personalized recommendation systems using large Deep Learning Recommendation Models (DLRMs) suffer from poor model freshness due to the massive, slow synchronization of petabyte-scale embedding tables, leading to accuracy degradation.

The authors observe significant CPU underutilization in inference nodes and that the necessary model updates possess a low-rank structure, presenting an opportunity for more efficient updates.

They introduce LiveUpdate, a system that performs model updates directly on the inference nodes using Low-Rank Adaptation (LoRA), dynamically adjusting the update complexity and managing resources effectively to eliminate the need for cluster-wide synchronization.

LiveUpdate leverages underused CPU resources to keep models fresh, significantly reducing update costs and latency compared to baseline methods, and achieving higher recommendation accuracy within short time windows.

## Technical note

LiveUpdate resolves the freshness-accuracy tradeoff in petabyte-scale DLRMs, where syncing embedding tables between decoupled training and inference clusters causes multi-minute staleness. Observing that inference-node CPUs are under 20% utilized and that embedding-gradient updates are strongly low-rank (>80% variance in <5% of PCA components), it co-locates LoRA trainers inside inference nodes to compute compact AB updates locally, eliminating inter-cluster synchronization. It adds dynamic rank adaptation via singular-value/PCA monitoring to bound memory to <2% of the embedding tables, and NUMA-aware scheduling with hardware-enforced QoS to keep P99 latency impact <20ms. LiveUpdate cuts update latency 2x versus delta-update baselines and improves accuracy by 0.04-0.24% within tight freshness windows.
