Recently, Large Language Models (LLMs) have been widely employed in Conversational Recommender Systems (CRSs). Unlike traditional language model approaches that focus on training, all existing LLMs-based approaches are mainly centered around how to leverage the summarization and analysis capabilities of LLMs while ignoring the issue of training. ## Technical note

Xiaohongshu's USB-Rec is an integrated training-inference framework improving LLM conversational recommendation at the model level, unlike prior prompt/pipeline-only approaches. It builds a preference-optimization dataset for RL by using a user simulator to score the LLM's multi-sampled responses and replacing labels with higher-scored ones, driving the response distribution closer to target than SFT; at inference a Self-Enhancement Strategy (SES) constructs an internal user simulator from dialogue summaries to score and select the best of multiple sampled responses. Extensive experiments across datasets show USB-Rec consistently outperforms previous state-of-the-art conversational recommender methods.
