## Summary

This paper introduces "Textual User Taste," a system designed to provide natural language descriptions of user music preferences for foundation model recommendation systems. It addresses the issue that traditional behavioral embeddings, while effective, are opaque and difficult to interact with using language models. The approach generates and deploys these textual taste profiles at industrial scale, finding they improve downstream recommendation tasks and offer interpretable steering capabilities, though limitations exist, particularly with handling negation and adapting to short-term changes.

## Technical note

Spotify's Textual User Taste uses a cost-efficient instruction-tuned LLM with input and output guardrails to turn aggregated multi-horizon listening signals, content metadata and optional user-written notes into structured natural-language taste profiles (music, podcast, audiobook and listening-rhythm fields), which it caches and serves to millions of users and to both LLM-based and conventional personalization systems. Prompts went through seven versions scored by LLM judges (factuality 7.70 to 8.57), LLMLingua compression was nearly lossless at 2x but broke at 8x (factuality 3.31, 16.5% valid outputs), and DSPy MIPROv2 with BootstrapFewShot reached an 80.2% composite score at a third of the best hand-written prompt's length. Since no ground-truth profile exists, evaluation pairs seven LLM judges and about 50 stress scenarios with downstream tests: concatenating a 120-d Matryoshka profile embedding with the production behavioral embedding lifts future-track MRR from 0.956 to 0.962 (+0.6%), feeding both to a fine-tuned LM search ranker gives +2.2% SessionNDCG@7 versus +1.7% for the embedding alone, and an LLM ranking five candidate tracks reaches MRR 0.776 with the user's own profile, 0.656 with none and 0.477 with a random user's. Positive steering requests such as 'more jazz' raise Top-20 genre precision from 56% to 74%, but a negated request like 'no electronic music' pulls recommendations toward the negated genre, so the authors position profiles as a steerable complement to behavioral embeddings rather than a replacement.
