## Summary

This paper introduces SimpleDevQA, a benchmark for evaluating Large Language Models (LLMs) on answering natural language questions based on development knowledge. It addresses limitations in existing benchmarks by being derived from real user dialogues and covering a broader scope than just code understanding. Experiments show that specialized code models perform well, knowledge injection via RAG improves performance, LLMs exhibit overconfidence, and strong code generation skills correlate with better Dev Knowledge QA performance.

## Technical note

The paper introduces SimpleDevQA, a multilingual (English/Chinese/Russian) benchmark of 2,740 short-answer QA pairs for development-knowledge question answering, built from real WildChat user-LLM dialogues via a three-stage collection, generation, and filtering pipeline. A preliminary study finds Dev Knowledge QA accounts for 39.6% of developer LLM interactions, motivating a benchmark broader than code understanding. Across 18 LLMs, closed-source and code-specific models outperform peers, RAG-based knowledge injection improves accuracy by 11.3% on average, and models show systematic overconfidence with accuracy correlating to stated confidence. Stronger code-generation ability also correlates with better Dev Knowledge QA performance.
