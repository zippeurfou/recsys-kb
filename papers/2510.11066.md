## Summary

1.  Existing recommendation systems struggle with effectively combining diverse user data (like text, images) with ID-based user and item representations for CTR prediction, as current methods process these modalities separately.
2.  To address this, the paper introduces Decoupled Multimodal Fusion (DMF), which creates 'target-aware' features to bridge the semantic gap between different embedding spaces and uses an optimized attention mechanism to efficiently combine these features with ID-based collaborative representations.
3.  DMF enhances user interest modeling by integrating both separate and combined modeling strategies, leading to significant improvements in CTR and CTCVR metrics (5.30% and 7.43% respectively) on real-world datasets, with minimal computational overhead, and has been successfully deployed on the Lazada platform.

## Technical note

DMF (Decoupled Multimodal Fusion) improves CTR prediction by enabling fine-grained, context-aware fusion of frozen pre-trained multimodal representations with ID-based collaborative embeddings, versus modality-centric methods that process the two in isolation. Decoupled Target Attention (DTA) treats multimodal similarity scores between the target and historical items as side information but avoids recomputing K/V per candidate by reusing target-agnostic ID-derived components and integrating similarity via discretized embedding lookup, giving ~3x higher throughput than early fusion at 1200 candidates. Complementary Modality Modeling (CMM) unifies modality-centric and modality-enriched pathways to balance semantic generalization and behavioral personalization. Deployed on Lazada, DMF improved CTCVR by 5.30% and GMV by 7.43%.
