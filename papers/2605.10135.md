## Summary

This paper introduces ScaleGANN, a system designed to accelerate the construction of large-scale Approximate Nearest Neighbor (ANN) graph indexes. It addresses the inefficiency of CPU-based indexing and the high cost/memory limitations of GPUs by utilizing distributed, low-cost cloud spot instances. Experiments show ScaleGANN significantly reduces index build time (up to 9x faster) while lowering costs (down to 6x cheaper) compared to existing state-of-the-art methods.

## Technical note

ScaleGANN is an end-to-end GPU-CPU hybrid, cloud-native system for building graph-based ANN indexes on billion-scale, high-dimensional datasets cost-effectively using preemptible spot GPU instances only for the one-time index construction, while delegating latency-sensitive query serving to CPUs. It extends a disk-incorporated partition-and-merge design with enhanced selective replication, replicating only the most essential vectors (via pruning) to preserve global graph connectivity while reducing disk I/O, memory, and build time compared to DiskANN's uniform per-point duplication. A spot-instance task scheduler assigns parallel shard-indexing tasks (execution time proportional to shard size) to available GPUs, with a cost model to evaluate spot-instance economics, and integrates the GPU-based CAGRA algorithm. On Laion100M (R=128) it achieves up to 9x faster index build at ~6x lower cost than DiskANN while preserving comparable recall and search quality.
