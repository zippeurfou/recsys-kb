## Summary

(Abstract fallback)

Click-through rate (CTR) prediction serves as a cornerstone of recommender systems. Despite the strong performance of current CTR models based on user behavior modeling, they are still severely limited by interaction sparsity, especially in low-active user scenarios. To address this issue, data augmentation of user behavior is a promising research direction. ## Technical note

Kuaishou's MARS augments sparse behavior for low-active users in CTR prediction by exploiting multimodal item content rather than only collaborative signals. It uses a Stein kernel-based method with joint alignment loss and entropy regularization to embed text and image features into a unified unbiased semantic space, building modality-aligned user embeddings; each low-active user's sequence is then augmented by retrieving, filtering, and concatenating the most similar high-active users' behaviors. Offline experiments and online A/B tests show MARS consistently beats state-of-the-art baselines and lifts core business metrics; it is deployed serving Kuaishou main traffic for hundreds of millions of users.
