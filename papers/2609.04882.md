## Summary

Current agentic recommendation systems often compress user and item details into coarse summaries, making it hard to capture fine-grained preferences and provide interpretable evidence. The proposed AtomRec system addresses this by representing memories as atomic units and building semantic links between them, allowing for evolving collaborative signals. Experiments show AtomRec consistently outperforms existing agentic recommenders by a significant margin, offering better and more explainable recommendations.

## Technical note

Xiaohongshu proposes AtomRec, an LLM agentic recommender whose contribution is the memory substrate rather than the ranker. Instead of a coarse per-user or per-item summary, every memory is an atomic note with structured fields {textual content, timestamp, keyword set, semantic tag set, short context description, dense embedding, link set}, embedded by a frozen Sentence-T5 over the concatenated fields. A memory agent (gpt-4o-mini) performs Semantic Collaborative Link Construction, retrieving the top k_link=20 cosine neighbors and having the LLM emit typed semantic relations (shared topic, complementary preference, intent progression, preference transition, cross-domain transfer) instead of scalar edge weights; dynamic memory evolution then rewrites any neighbor that is either linked or above tau_evo=0.7 cosine, editing keywords, tags, context and links at the field level while freezing the original timestamp so temporal traces survive. At recommendation time retrieval expands h=2 hops along links into a subgraph (k_ret=15), the memory agent synthesizes multi-hop evidence paths, and a second gpt-4o-mini agent ranks candidates from user memory plus collaborative evidence plus item memory. On four instruction-augmented MemRec/InstructRec benchmarks (Amazon Books, Goodreads, MovieTV, Yelp) with candidate size 10, AtomRec beats the strongest baseline MemRec on all 16 metrics with about 8.5 percent average relative gain, e.g. Books H@3 0.7462 vs 0.6786 (+9.96 percent) and N@3 0.6690 vs 0.6078, MovieTV H@5 0.9364 vs 0.8654; it also beats LightGCN, SASRec, P5, vanilla LLM, iAgent, RecBot, AgentCF and i2Agent. Ablation on Books: collapsing atomic notes into coarse summaries is the largest loss (-5.45 percent avg), then removing collaborative links (-3.77 percent), removing keywords/tags (-3.90 percent), embedding-only links (-2.78 percent), append-only memory (-2.56 percent), no link-aware retrieval (-1.92 percent). Relative gain over MemRec grows with a cosine-based preference-drift score computed between early and late history segments. Caveats: public offline benchmarks only with no online A/B, token cost exceeds MemRec (the authors argue memory operations can be cached and run asynchronously), and evolution can over-compress interests into a dominant subtheme, producing semantically adjacent false positives and weakening provenance of collaborative signals.

- LightGCN  is a graph-based collaborative filtering model that simplifies graph convolution by removing feature transformation and nonlinear activation. It learns user and item embeddings through neighborhood aggregation on the user–item interaction graph
- SASRec  is a self-attentive sequential recommender that models user interaction histories with a Transformer-style attention mechanism and predicts the next item from sequential preference patterns
- P5  formulates recommendation as a text-to-text language modeling problem through personalized prompts, allowing a pretrained language model to handle multiple recommendation tasks in a unified format
- Vanilla LLM  directly prompts a large language model to rank candidate items from user history and item descriptions. It does not maintain external memory or construct a collaborative memory graph
- iAgent  uses an LLM agent as an intermediary between the user and recommender system. It relies mainly on user-side instructions and profile information, making it a representative static-memory agentic baseline
- RecBot  maintains and updates user preference memory during recommendation, but its memory is mainly organized around individual user states rather than an atomic collaborative memory graph
- AgentCF  treats users and items as autonomous language agents and simulates user–item interactions for collaborative filtering. It captures collaborative behavior through agent interaction, but does not organize memory as fine-grained atomic notes with semantic links
- MemRec  is the closest baseline to our work. It decouples memory management from recommendation reasoning and maintains a dynamic collaborative memory graph for downstream recommendation. In contrast, AtomRec focuses on the granularity and structure of memory itself: it represents user and item memories as atomic semantic notes, builds semantic links among them, and evolves related historical memories at the field level
