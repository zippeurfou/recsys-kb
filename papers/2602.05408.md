## Summary

This paper introduces the Rich-Media Re-Ranker framework to improve user satisfaction in search systems. It addresses limitations in existing methods by modeling multifaceted user intents more effectively and incorporating richer side information, like visual signals, beyond just text content. The framework uses query planning, VLM-based evaluators, and multi-task reinforcement learning with an LLM re-ranker to consider various ranking factors, demonstrating significant improvements over state-of-the-art methods and successful deployment in an industrial system.

## Technical note

Rich-Media Re-Ranker improves user satisfaction in rich-media search by addressing weak multifaceted intent modeling and neglect of visual side information. A session-aware Query Planner decomposes complex/broad queries into complementary sub-queries with intent dimensions (freshness, authoritativeness, personal experience) to broaden candidate coverage. A VLM-based evaluator grades cover-image relevance and quality, which feed an LLM-based listwise re-ranker that weighs relevance, information gain, novelty, and visual presentation. Both the VLM and LLM are post-trained with multi-task GRPO (using DeepSeek-R1 teacher data), yielding SOTA offline results and online engagement/satisfaction gains in a deployed industrial search system.
