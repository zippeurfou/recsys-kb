## Summary

1.  Existing long video synthesis models struggle with maintaining consistency and narrative coherence over long durations, leading to issues like semantic drift and narrative collapse.
2.  To address this, the authors introduce A$^2$RD, an agentic autoregressive diffusion architecture that uses a cycle (Retrieve-Synthesize-Refine-Update) and three core components (multimodal memory, adaptive generation, hierarchical self-improvement) to decouple creation from consistency checks.
3.  A$^2$RD significantly improves long video synthesis, demonstrated on a new benchmark called LVBench-C, outperforming previous methods by up to 30% in consistency and 20% in coherence, with human evaluations confirming better motion and smoothness.

## Technical note

A2RD is an Agentic Auto-Regressive Diffusion architecture for long video synthesis that decouples creative synthesis from consistency enforcement via a closed-loop Retrieve-Synthesize-Refine-Update cycle operating segment-by-segment. Its three components are Multimodal Video Memory that tracks progression across modalities, Adaptive Segment Generation that switches generation modes for natural progression and visual consistency, and Hierarchical Test-Time Self-Improvement that corrects each segment at frame and video levels to prevent error propagation. The authors also release LVbench-C, a benchmark with non-linear entity and environment transitions to stress-test long-horizon consistency. Across one- to ten-minute videos, A2RD beats state-of-the-art baselines by up to 30% in consistency and 20% in narrative coherence, corroborated by human evaluation.

- MemoryAgentAnalyze (per shot): 1 MLLM call ($\displaystyle L_{M}$) to decide REUSE or CREATE for each entity. For each entity that needs CREATE: 1 TI2I call ($\displaystyle L_{I}$). Let $\displaystyle E_{i}$ = number of new entities in shot $\displaystyle i$, so this costs $\displaystyle L_{M}\text{+}E_{i}L_{I}$ per shot
- VisualizeAgentKeyframe (per shot): 1 MLLM call ($\displaystyle L_{M}$) to build prompts, then 1 TI2I call ($\displaystyle L_{I}$) for the keyframe, then 1 TI2V call ($\displaystyle L_{V}$) for the video. Cost: $\displaystyle L_{M}\text{+}L_{I}\text{+}L_{V}$ per shot
- *Semantic Alignment* is computed using ViCLIP , measuring cosine similarity between video and scene description embeddings
- *Narrative Coherence* is evaluated by an MLLM prompted with the original story and the generated video. See the prompt below
- *Inter-Shot Character and Environment*: we first group $\displaystyle N$ scenes into two types of groups via the MLLM: groups having the same characters with the same states, groups having the same environments with the same states. Once these groups are established, we evaluate the *Inter-Shot Character* and *Inter-Shot Environment* consistency. We use YOLOv8 to segment character and background regions within the keyframes of each scene within each group, extracting their corresponding DINOv3 embeddings. We then compute the pairwise cosine similarities of these embeddings across scenes within each group, and average the results across all groups to obtain the final metrics
- *Inter-Shot Motions*: For each scene, we first identify its previous continuous scene (if exists), see [Section˜E.2.2](#A5.SS2.SSS2). For each couple, we then evaluate the transitions between the two synthesized video segments by extracting the last 10 frames of the preceding video segment and the first 10 frames of the subsequent video segment. We then compute the VBench motion_smoothness score across these boundary frames
- *Intra-shot Consistency*: We use those metrics from VBench
- Character Consistency: Do characters maintain consistent appearance across video?
- Object Consistency: Do objects maintain consistent appearance across video?
- Environment Consistency: Do backgrounds and environments remain consistent across transitions?
- Transition Smoothness: Are the cuts between segments visually and temporally natural?
- Narrative Coherence: Does the story progress logically with meaningful causal relationships?
- Reference Consistency: How faithfully does the generated video adhere to the provided reference images? N/A if no reference images are provided (arXiv:2605.06924)
