## Summary

This paper addresses the challenge of estimating a user's preference *for one website compared to others*, using only data from that single site. Since direct observation or access to users' interactions with other sites is impossible, the authors propose inferring these preferences by analyzing how much time and attention individual users spend on the focal site versus hypothetical alternatives during their online activity periods. They develop a Hierarchical Bayes Model employing Markov Chain Monte Carlo (MCMC) and Stochastic Gradient Langevin Dynamics to estimate the personalized "share of engagement" for each user, validated with an evaluation framework using solely the site's own data.

## Technical note

The paper estimates a user's preference for a focal site relative to other sites, i.e., each user's Personalized Share of Engagement (PSE), using only the focal firm's own interaction logs with no data from competing sites. It proposes a two-part hierarchical Bayes model: an Inter-Engagement Time (IET) distribution (Erlang-2 or Exponential) generates engagement epochs across all sites, and a Markov model allocates which engagements land on the focal firm, letting parameters be estimated from observed focal-site data alone. Estimation is done two ways, MCMC and Stochastic Gradient with Langevin Dynamics (SGLD), the latter enabling mini-batch training. Because no ground truth for unobserved cross-site behavior exists, they introduce an evaluation strategy using only the firm's own data, and results support both the individual-level PSE estimation and the evaluation approach.
