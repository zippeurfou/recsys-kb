## Summary

This paper addresses the challenge of capacity planning for machine learning model serving systems, which often leads to inefficient use of GPUs due to under or over-provisioning. It proposes a framework called `\sys`, an industrial load testing tool that systematically estimates maximum sustainable throughput using an adaptive search strategy based on real-time performance feedback signals. The effectiveness of `\sys` was validated through 14 case studies, showing significant improvements in GPU resource efficiency and operational reliability by reducing under-provisioned incidents, with ML-specific design like workload calibration being crucial for accurate estimation.

## Technical note

Vanguard is an industrial load-testing framework for ML model serving that estimates maximum sustainable throughput under SLO constraints via an adaptive, feedback-driven search using dampening, spike tolerance, and convergence detection, addressing ML-specific challenges (JIT/CUDA warmup, dynamic batching's nonlinear latency-vs-load, architecture heterogeneity, hardware/co-location sensitivity) that general tools like JMeter, Locust, k6, and MLPerf do not handle. Its distributed architecture separates orchestration, a Strategy Engine (pluggable next_rate(metrics) policies), a Load Replayer with open-loop generation to avoid coordinated omission, a Metrics Collector, and a Metrics Health Assessor enforcing sustained-violation multi-metric SLO checks. Evaluated longitudinally across 14 case studies spanning recommendation, ranking, vision, and NLP models, it substantially improved GPU efficiency and reduced under-provisioning incidents. ML-specific design proves critical: workload calibration from recorded traffic cuts estimation error from ~30% to 2-6% and proper warmup handling improves accuracy by 22.2%, with model size and co-location identified as key error factors; six lessons are distilled for practitioners.
