## Summary

This paper addresses a key limitation of Large Language Models (LLMs): their inefficiency in dynamically changing cloud computing environments where resources fluctuate. The authors propose Learning to Allocate (L2A), an end-to-end framework that conditions LLM inference not just on input difficulty, but also on the available resource budget itself.

L2A integrates lightweight gating networks into standard models like Llama-3 and Qwen. These gates adaptively prune computation (layers, heads, tokens) based on real-time budget constraints and are trained jointly to balance accuracy, consistency, and cost savings across three axes: memory/depth pressure, throughput contention, and latency tightening.

The result is a significantly more resource-adaptive system; L2A can achieve up to 34% layer sparsity while maintaining near dense-baseline performance (GSM8K within 0.6%) even on out-of-distribution tasks. This stands in stark contrast to static models which require separate tuning for each environment and incur much larger accuracy drops under tight constraints.

## Technical note

Learning to Allocate (L2A) formulates LLM inference as constrained resource allocation conditioned on both input difficulty and a scalar runtime budget b in [0,1]. Lightweight budget-conditioned gates are inserted into a frozen backbone: a layer-skip gate scales soft-gated residuals (binarized at inference), a head-prune gate handles throughput contention, and a reasoning-stop gate forces the </think><answer> transition to cut reasoning tokens under latency pressure. Gates are trained jointly with LoRA under a unified loss balancing cross-entropy, KL self-distillation toward the dense teacher, and multi-axis compute cost. A single L2A model traces the compute-accuracy Pareto frontier on Llama-3-8B and Qwen-3-4B, staying within 0.6% of dense GSM8K at up to 34% layer sparsity, including zero-shot on OOD tasks.
