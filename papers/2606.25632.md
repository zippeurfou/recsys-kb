## Summary

This paper addresses two main issues in LLM-based book role-playing systems: "Factual Overreach," where characters use facts outside their perspective, and "Stylistic Monotony," where character descriptions become too static. To solve these problems, the authors introduce REVERIEMEM, a novel three-layer memory architecture designed to store first-person memories, visible facts, and situation-dependent behaviors/persuasions.

They created an evaluation benchmark called KBF-QA to test knowledge boundaries and found that their system significantly improves Knowledge Boundary Fidelity compared to previous methods. Furthermore, against the original BOOKWORLD benchmark for narrative quality (which evaluates character-consistency), REVERIEMEM achieved a ~79% win rate on a modified protocol, demonstrating its effectiveness in improving both boundary fidelity and character-driven storytelling.

## Technical note

ReverieMem is a perspective-bounded three-layer memory architecture for book-based role-playing agents that targets two out-of-character failures: Factual Overreach (using facts outside a character's perspective) and Stylistic Monotony (flattening voice). The Episodic Layer stores first-person per-scene summaries (hippocampus-like anchoring), the Semantic Layer stores SPOCV tuples (subject-predicate-object-cause-visibility) as a visibility-tagged knowledge graph where per-character subset F_c bounds retrieval, and the Personality Layer stores situation-dependent behavioural patterns plus emotion-transition records selected at inference. Memory is built offline (LLM scene segmentation, first-person episodic summarization, extract-then-relate KG with four visibility routes, personality clustering into K patterns). Inference runs CLS Memory Collaborative Reasoning (scene anchor + iterative visibility-bounded fact expansion, refusing when F_c lacks an answer) then Fusion Injection of a selected pattern. On the new 4,386-question KBF-QA benchmark over eight novels it improves Knowledge Boundary Fidelity by 34.6 points, and achieves ~79% win rate on BookWorld's five-dimension pairwise protocol.
