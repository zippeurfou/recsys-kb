## Summary

AI agents promise powerful personal assistance but require access to private user data, creating significant security and privacy risks like prompt injection attacks and trust issues with providers.

To address these risks, the paper introduces GAAP, an execution environment that guarantees user data confidentiality by dynamically collecting user permission specifications and enforcing them strictly.

GAAP tracks data flow across execution steps and over multiple tasks, blocking all data disclosure attacks without trusting the AI model and without hindering agent utility, outperforming existing methods.

## Technical note

GAAP (Guaranteed Accounting for Agent Privacy) is an execution environment that deterministically guarantees confidentiality of private user data for AI agents without trusting the AI model or its provider and without assuming prompt-injection-free inputs. It dynamically elicits permission specifications from users describing how their private data may be shared, then enforces that all disclosures, including to the model provider, comply. It augments Information Flow Control with persistent data stores and annotations that track private information flow both across execution steps within one task and across multiple tasks over time. Evaluation shows GAAP blocks all data-disclosure attacks that cause other state-of-the-art systems to leak data, without significantly reducing agent utility. This is an agent-security/privacy systems paper, not a recommendation method.
