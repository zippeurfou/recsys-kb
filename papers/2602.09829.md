## Summary

Large Language Models (LLMs) offer powerful reasoning for recommender systems but suffer from high inference latency when integrating collaborative signals. To overcome this, the authors introduce STAR (Single-agent Trajectory-Aligned Recommender), a system developed using "internalization." This process involves training a multi-agent teacher model that learns complex reasoning and behavioral patterns, then distilling this knowledge into a compact, single-agent STAR model capable of providing recommendations as efficiently as a standard system but with enhanced reasoning capabilities. Experiments show STAR significantly outperforms its teacher model while eliminating the iterative latency, enabling real-time reasoning-enhanced recommendations.

## Technical note

STAR internalizes multi-agent reasoning into a single efficient LLM recommender to keep collaborative-signal reasoning while eliminating iterative multi-turn latency. A training-time teacher (MARS) follows a Plan-Execute-Reflect paradigm with specialized agents (user profile, historical/recent interest, interest divergence, reflector, ranking) and a Collaborative Signal Translation mechanism that traverses a user-item bipartite graph (Item-CF via Item->User->Item and User-CF via User->Item->User) to verbalize co-occurrence statistics into natural-language evidence; this verbalization is precomputed offline as static metadata to avoid serving latency. A Long Sequence Abstractor uses sliding-window iterative summarization to fit long histories. Teacher trajectories are serialized into a linear chain-of-thought (retaining tool_call tokens) and distilled into STAR via SFT then GRPO, so the student learns when to invoke tools and self-reflect in one pass, surpassing the teacher by 8.7%-39.5%.
