## Summary

This paper argues that traditional static fashion recommendation systems struggle with dynamic trends and user preferences. It proposes an Agentic Mixed-Modality Refinement (AMMR) pipeline combining image anchors, text constraints, LLM planning, and retrieval to overcome these challenges. The authors emphasize the need for adaptive, generative approaches that understand stakeholder interplay to improve satisfaction and address fast-changing fashion inventories effectively.

## Technical note

This perspective paper maps the distinctive output space and stakeholder ecosystem (users, brands, platforms, influencers) of industrial fashion recommender systems, arguing static retrieval-only pipelines fail under rapid trend shifts, subjective aesthetics, and high return costs. It charts a research agenda around five tasks (static text, static image, mixed-modality, outfit completion, multi-turn chat) and spotlights mixed-modality refinement as most critical. It proposes AMMR (Agentic Mixed-Modality Refinement), a generative pipeline fusing multimodal encoders, image anchors with textual constraints, dynamic query composition, and an agentic LLM planner with retrieval. The authors advocate moving toward adaptive, generative, stakeholder-aware systems; it is a position/agenda paper rather than an empirical benchmark.
