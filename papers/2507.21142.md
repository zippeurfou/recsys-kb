## Summary

1.  The paper introduces PACT, an embeddings-driven graph system designed to link diverse enterprise artifacts (like code, data, and tool outputs) across different teams and projects into a unified space for better privacy compliance assessment.
2.  PACT addresses the problem that critical information for compliance is scattered throughout heterogeneous resources, each requiring complex extraction methods, making large-scale risk identification difficult due to poor information retrieval.
3.  By using contrastive learning with state-of-the-art DRAGON embeddings and fine-tuning on relevant textual data (metadata, ownership, context), PACT significantly boosts performance metrics like recall and query match rates for AI agents focused on compliance tasks compared to baseline methods.

## Technical note

PACT (Privacy Artifact ConnecTor) is an embeddings-driven semantic graph at Meta that links millions of heterogeneous enterprise artifacts (code paths, teams, products) for privacy compliance. It encodes artifact text with the DRAGON dense retriever and lightly fine-tunes it via an InfoNCE contrastive objective on knowledge-graph links (including multi-hop positive pairs and hard negatives), then builds a KNN graph and a product-quantized VectorDB for ANN semantic search with 20-200ms latency. The search tool is registered in a ReAct-style LLM agent's action space for iterative reasoning and cross-reference following. Fine-tuning raised recall@1 from 18% to 53%, agent query-match rate from 9.6% to 69.7%, and recommender hitrate@1 from 25.7% to 44.9%.
