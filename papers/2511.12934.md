## Technical note

AIF (Asynchronous Inference Framework, Alibaba/Taobao display advertising) restructures DNN pre-ranking to overcome the sequential execution bottleneck where feature fetching and forward computation only begin after retrieval delivers candidates. AIF decouples interaction-independent components (computed within a single user or item) from real-time prediction: user-side computation runs in parallel with retrieval and item-side computation runs nearline, so these parts are computed once before real-time prediction. This eliminates redundant user/item computation and latency, freeing resources to enrich features and model architecture of interaction-independent components, with approximated methods for interaction-dependent parts, and is deployed in Taobao display advertising.
