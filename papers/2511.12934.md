## Summary

Industrial recommendation systems face bottlenecks due to sequential execution, causing redundant computations and increased latency for deep learning-based pre-ranking models. To address this, the Asynchronous Inference Framework (AIF) decouples interaction-independent computations (user/item focused) from the real-time prediction phase, performing user-side work in parallel and item-side work offline. This allows AIF to eliminate redundant calculations, reduce latency, and free resources for enhancing model components, while also employing approximated methods for online predictions, resulting in significant performance gains without increased costs, successfully deployed at Taobao.

## Technical note

AIF (Asynchronous Inference Framework) is a cost-effective serving architecture for industrial DNN pre-ranking that attacks the redundant computation and latency of the standard sequential 'fetch-then-forward' pipeline. It decouples interaction-independent components (user-side and item-side sub-networks) from real-time prediction: user-side computation runs in parallel with the retrieval stage, and item-side computation is precomputed nearline and cached, so each is computed only once. For the unavoidable user-item interaction (only known after candidates arrive), AIF uses approximate interaction between the precomputed user/item tensors plus multimodal long-term sequence modeling. The freed resources let them enlarge the interaction-independent model, yielding gains without extra latency; deployed in Taobao display advertising.
