## Summary

1.  The paper introduces RecGaze, the first comprehensive dataset capturing user interactions (clicks, gazes) with carousel interfaces in movie selection tasks.
2.  This unique dataset includes eye-tracking patterns revealing an F-shaped viewing behaviour ("golden triangle") across various carousels and provides explanations for user selections.
3.  By offering this new data resource focused specifically on the complexities of carousels, RecGaze aims to help researchers build better recommender systems by understanding gaze-driven user interactions empirically.

## Technical note

The paper introduces RecGaze, the first recommendation dataset for carousel/multi-list interfaces that includes eye-tracking gaze data alongside clicks, cursor movements, and selection explanations. It was collected from a controlled Netflix-style user study of 87 participants across 40 carousel screens (free-browsing, semi-free, and direct-search movie-selection tasks), yielding 3,477 interactions. Beyond releasing the data, the authors survey carousel design and provide the first gaze analysis on carousels, finding a golden-triangle / F-pattern browsing behavior. The work aims to enable research on carousel click models and gaze-based recommenders, an interface class with far fewer studies than single ranked lists.
