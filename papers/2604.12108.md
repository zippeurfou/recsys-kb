## Summary

1.  Diagnosing complex integration test failures is difficult due to high log volume, heterogeneity, and cognitive load, leading developers to spend significantly more time on these issues than unit tests.
2.  To address this challenge, Google developed Auto-Diagnose, an LLM-powered tool integrated into their code review system that analyzes failure logs, summarizes key lines, and provides root cause diagnoses.
3.  Case studies show Auto-Diagnose is highly effective, achieving near-perfect accuracy on real-world failures and receiving overwhelmingly positive feedback and usage across Google, demonstrating strong developer acceptance for AI-assisted diagnosis.

## Technical note

Auto-Diagnose is an LLM-based tool that ingests test-driver and system-under-test logs (joined and sorted by timestamp) for hermetic functional integration test failures and produces concise root-cause summaries with the most relevant log lines, surfaced as findings inside Google's Critique code review system. It prompts Gemini 2.5 Flash at temperature 0.1 and top_p 0.8 with guided step-by-step reasoning, strict negative constraints, and precise output formatting, without any fine-tuning on the failure logs. Manual evaluation on 71 real-world failures reached 90.14% root-cause accuracy, and post-deployment it ran across 52,635 distinct failing tests, deemed 'Not helpful' in only 5.8% of cases. The work is a recsys-adjacent LLM-for-software-engineering system rather than a recommendation method.
