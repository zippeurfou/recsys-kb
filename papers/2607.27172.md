## Summary

This paper addresses a limitation in traditional e-commerce search systems that prioritize precise matches over finding substitutes or related items (discoverability), particularly affecting user satisfaction and sales potential in categories like groceries.

The authors propose a scalable "discovery-augmented" search system using intent-conditioned recall expansion, which involves generating implicit user intents to find more relevant candidates. This is achieved through a two-stage hybrid architecture employing large language models (LLMs) for broad queries and small, low-cost LLMs finetuned via efficient methods.

Evaluation shows the system significantly improves discovery coverage across many queries while maintaining relevance, enabling less popular items to gain visibility based on user intent and thus potentially balancing marketplace dynamics.

## Technical note

This work defines discovery-augmented search for grocery/e-commerce: instead of exact-match retrieval, an LLM generates implicit user intents (substitute, complementary, thematic) that expand the recall set via a decoupled generate-then-retrieve pipeline, where the LLM emits carousel titles plus intent terms that are issued to the existing search engine. A two-tier hybrid controls the cost-quality tradeoff: cached closed-weight LLM annotations (GPT-3.5-Turbo, GPT-5.1 teacher) cover about 10k head queries (roughly 60% traffic), and a LoRA-finetuned Qwen3-30B student, distilled from the teacher, extends coverage to about 80% of traffic at roughly 30% of teacher inference cost. Evaluated with a dual framework (session-co-purchase purchase-prediction and a human-validated LLM-as-a-judge), the student matches or exceeds the much larger teacher on tail queries (e.g. F1 0.179 vs 0.168) and improves F1 over the production baseline on head queries (0.184 vs 0.173), with notable intent-novelty gains. It is positioned as a marketplace-balancing mechanism for long-tail supply exposure; generation is decoupled from retrieval/ranking, so it is not a unified pipeline.
