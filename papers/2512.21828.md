## Summary

1.  LLM-based ASR performs well generally but struggles with recognizing specific named entities and hotwords from large vocabularies.
2.  To address this, the paper introduces a two-stage framework: first retrieving a compact set of hotword candidates using an enhanced GLCLAP model, then injecting these candidates into the LLM-ASR and fine-tuning it with Reinforcement Learning (GRPO) to improve hotword recognition.
3.  Experiments demonstrate that this approach significantly reduces keyword error rates (KER) for hotwords while maintaining overall transcription accuracy on standard benchmarks, proving its effectiveness for large-vocabulary contextual biasing.

## Technical note

This work improves contextual biasing for LLM-based ASR on named entities and hotwords under large vocabularies. Stage one extends a Global-Local Contrastive Language-Audio model (GLCLAP) with robustness-aware data augmentation and fuzzy matching to retrieve a compact top-k hotword set (shrinking a 600k vocabulary to 98k); stage two injects candidates as prompts into a Conformer-MoE + LLM ASR model fine-tuned with GRPO using a joint hotword-match and WER-based reward. On Media and Medical test sets, KER drops substantially (e.g., 22.63 to 8.29 on Media) while general-task sentence accuracy is preserved, with top-2 retrieval found optimal.
