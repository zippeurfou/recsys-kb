## Summary

This paper addresses two challenges in federated learning for multimodal brain tumor segmentation: intermodal heterogeneity (when participants lack all imaging modalities) and the need for personalized models. The proposed FedMEPD framework uses modality-specific encoders for each imaging type and employs a mechanism based on parameter discrepancies to partially personalize the fusion decoders. Validation on standard datasets shows FedMEPD outperforms existing methods, effectively handling missing data through cross-attention mechanisms and providing personalized predictions.

## Technical note

FedMEPD is a federated learning framework for multimodal brain tumor segmentation that tackles intermodal heterogeneity (clients holding only subsets of MRI modalities) and the need for personalized models. It uses a fully federated modality-specific encoder per MRI sequence (T1, T1c, T2, FLAIR) and a fusion decoder that is partially personalized at the filter level, federating only parameters whose global-vs-local updates consistently agree. A full-modal server extracts multiple anchors from the fused representation and distributes them so incomplete-modality clients calibrate missing-modal features via scaled dot-product cross-attention. Validated on BraTS 2018/2020, it produces both an optimal full-modal server model and personalized client models, outperforming prior multimodal and personalized FL methods. Not a recommender-systems paper.
