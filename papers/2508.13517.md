## Summary

This paper addresses two key challenges in user recommendation systems: maximizing information spread and accounting for user interaction willingness. It introduces HeteroIR (Heterogeneous Interaction-aware Recommendation) to estimate the potential spread impact of recommendations using a two-stage framework, thereby bridging these traditionally separate objectives. Additionally, it proposes HeteroIM (Heterogeneous Influence Maximization), which incrementally selects influential users based on reverse reachable sets and reranks them considering both their influence and interaction readiness. Both models significantly outperform existing baselines in experiments, with real-world validation showing an 8.5% improvement in Tencent's online gaming platforms using HeteroIR.

## Technical note

Tencent bridges user recommendation and influence maximization for inviter->invitee interactions (e.g., friend/team suggestions in online gaming). HeteroIR uses a two-stage framework to estimate the spread profit of recommendations, unifying interaction willingness with dissemination potential. HeteroIM incrementally selects and reranks the most influential invitees based on the number of reverse reachable (RR) sets containing both inviters and invitees, jointly weighing influence and interaction readiness. Both models beat state-of-the-art baselines (p<0.05); deployed on Tencent's online gaming platforms, HeteroIR and HeteroIM achieved 8.5% and 10% online A/B improvements respectively.
