## Technical note

PCL (Prompt-based Continual Learning) targets universal user modeling in e-commerce, where multi-task learning suffers optimization imbalance and full-retraining cost while continual learning risks catastrophic forgetting. PCL uses position-wise prompts as per-task external memory to preserve knowledge, plus contextual prompts to capture inter-task relationships during prompt tuning. Experiments on Tenrec and MovieLens show it mitigates forgetting, is robust to task order, and improves downstream fine-tuning on cold-start items while generating universal user representations for unseen models/tasks.
