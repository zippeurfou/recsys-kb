## Summary

1.  Large-scale recommendation models face scaling challenges due to high computational costs from existing sparse activation methods, limiting personalization.
2.  To address this, the paper introduces MSN, a framework that dynamically retrieves personalized representations from a large memory using a Product-Key Memory mechanism for efficient sub-linear access.
3.  MSN integrates these retrieved representations into the model, enabling fine-grained personalization with low computational overhead, and has been successfully deployed in Douyin's Search Ranking System, improving performance over existing models.

## Technical note

MSN scales industrial CTR models via sparse parameter retrieval instead of sparse computation like SMoE, dynamically fetching personalized value representations from a large parameterized memory and fusing them into feature-interaction modules through a memory gating mechanism. It adopts Product-Key Memory (PKM) to factorize the memory index into two sub-key spaces, reducing retrieval complexity from O(nd) to O(sqrt(n)d) so the memory can scale to hundreds of thousands of entries. To prevent memory retrieval collapse and load imbalance, it applies LayerNorm and learning-rate warm-up on query/key vectors plus a SimVQ-style key over-parameterization strategy, and uses custom Sparse-Gather and AirTopK operators for efficiency. MSN acts as a model-agnostic plug-in and was deployed on Douyin Search Ranking with offline and online A/B gains over SMoE baselines.
