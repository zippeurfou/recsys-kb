## Summary

FlyRoute addresses the issue of static agent profiles in enterprise routers, which fail to adapt as agents evolve, by creating a self-updating system that uses real user traffic to build and refine capability evidence for each agent. This system, called a "data flywheel," periodically distills collected evidence into descriptions and uses them alongside retrieved successes in an LLM router, improving routing accuracy. By leveraging targeted exploration and a flywheel of live data, FlyRoute significantly boosts routing performance, achieving near-human accuracy with minimal initial input, even for previously unseen agents.

## Technical note

FlyRoute is a self-evolving profiling framework that routes queries to expert agents in enterprise multi-agent systems, replacing static developer-written descriptions with capability evidence grown from live traffic. Each agent keeps a seed description, a distilled learned description, and a BM25-indexed success store of quality-gated (query, response) pairs scored by an LLM-as-judge. A relevance-gated, novelty-reweighted exploration policy (profile uncertainty U scaled by BM25 relevance and a 1-R non-redundancy term) allocates a bounded per-query dispatch budget to under-profiled agents. On a proprietary enterprise support dataset the flywheel lifts a same-backbone zero-shot LLM router from 72.57% to 78.04% at cold start (5 seeds/agent) and to 89.83% after streaming 7,211 labeled queries.
