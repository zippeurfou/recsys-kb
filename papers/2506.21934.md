## Summary

This paper addresses automated content-aware layout design, an under-explored problem in AI. It introduces CAL-RAG, a novel framework combining multimodal retrieval with multiple specialized LLM agents for generating layouts. The system retrieves relevant examples and collaboratively reasons through generation and refinement stages using dedicated agents, achieving state-of-the-art results on standard benchmarks by improving semantic alignment, visual coherence, and layout fidelity compared to existing methods like LayoutPrompter.

## Technical note

CAL-RAG addresses automated content-aware layout design (placing text, logos, underlays on a poster canvas). It combines multimodal retrieval of similar layout exemplars (via CLIP image embeddings and cosine similarity over the PKU PosterLayout dataset) with a multi-agent LLM system: a layout recommender proposes bounding boxes from few-shot references, a vision-language grader scores geometric/visual metrics, and a feedback agent drives iterative correction, all orchestrated in LangGraph. On PKU PosterLayout it achieves state-of-the-art underlay effectiveness, alignment, and overlap, outperforming baselines like LayoutPrompter and RALF.
