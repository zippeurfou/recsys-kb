## Technical note

WeWrite is a personalized demand-aware query rewriting framework for WeChat video search that decides when and how to rewrite. It mines high-quality training samples via a posterior-feedback strategy that identifies when personalization is strictly necessary (mitigating intent drift), and combines SFT with GRPO to align LLM output style with the retrieval index using retrieval-oriented rewards (Index Hit Rate and CTR). A parallel 'Lightweight Recall' architecture decouples LLM inference for low latency. Offline it improves rewriting accuracy by over 27% vs Qwen3-32B; online it raised Click-Through Video Volume (VV>10s) by 1.07% and cut Query Reformulation Rate by 2.97%.
