## Summary

This paper introduces PEARL, a novel generative framework for personalized sticker retrieval. It addresses the lack of personalization in existing methods by incorporating user-specific sticker preferences learned from personal information and click history, and by generating stickers aligned with query intent using an intent-aware objective. Empirical results demonstrate that PEARL significantly outperforms state-of-the-art methods in both offline and online evaluations.

## Technical note

PEARL is a generative framework for personalized sticker retrieval, adapting autoregressive generative retrieval (which typically lacks personalization) to match diverse user expectations on platforms like WeChat. To encode preferences, it groups users by age and gender and trains a discriminative user-group representation model on three auxiliary tasks (user click, intent, and interest prediction) from click logs, feeding the group representation with the query into the generative model. For decoding, each sticker property (character IP, OCR text, visual style, entity, meaning) is assigned a product-quantization property identifier, and an intent-aware loss reweights query-property relevance using an intent ranking inferred via LLM chain-of-thought reasoning, prioritizing higher-ranked intents. Offline and online tests show large gains over SOTA (about +15% MRR@10, +18.3% Recall@10, +7.12% CTR).
