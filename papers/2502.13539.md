## Summary

This paper addresses the filter bubble effect in recommender systems caused by biased training data, which reduces user satisfaction. It proposes SERAL, a new framework using large language models to overcome this challenge through three stages: generating multi-level cognition profiles from user behavior, aligning serendipity judgments with human preferences, and efficiently integrating into existing recommendation pipelines.

The solution leverages LLMs' extensive knowledge for "surprise" recommendations. It tackles alignment issues, long sequence handling, and latency constraints specific to industrial systems like Taobao's recommender platform.

Online experiments show SERAL significantly improves user engagement metrics (clicks on serendipitous items by 29.56%) while also increasing exposure ratio (PVR) for these unexpected suggestions and proving feasible for deployment in real-world e-commerce applications, without negatively impacting overall revenue.

## Technical note

SERAL is a Taobao framework that uses aligned LLMs to break filter bubbles and boost serendipity recommendations, which are hurt by biased training data. It has three stages: generating multi-level cognition profiles from user behavior to compress long histories, aligning the LLM's serendipity judgments with human preferences via preference optimization (IPO, compared against DPO/KTO/SimPO), and distilling the LLM signal into the existing pipeline to meet latency constraints. It directly tackles alignment, long-sequence handling, and industrial latency for large-scale e-commerce. Online experiments show a 29.56% increase in clicks on serendipitous items plus higher exposure ratio (PVR) without hurting overall revenue, demonstrating feasible deployment.
