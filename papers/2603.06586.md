## Technical note

This Uber Eats paper describes a production semantic-retrieval system unifying retrieval across stores, dishes, and grocery/retail items with a single multilingual, multi-vertical two-tower model. It fine-tunes a gte-Qwen2 decoder-only LLM backbone into distinct query and document encoders using hundreds of millions of click/add-to-cart interactions, trained with InfoNCE on in-batch negatives for domain adaptation plus triplet-NCE loss on LLM-mined hard negatives. Matryoshka Representation Learning (MRL) serves multiple embedding sizes from one model for cost-latency trade-offs, and documents use a structured JSON input format. The system achieves substantial recall gains over a strong baseline across six markets and three verticals.
