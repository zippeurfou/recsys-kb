## Summary

World Knowledge-Augmented Generative Next POI Recommendation":

1.  Generative POI recommendation using LLMs is effective but limited by fixed world knowledge, preventing adaptation to real-world changes like events or trends.
2.  To overcome this, the authors propose AWARE, which uses an LLM agent to generate personalized location-time narratives incorporating relevant external context and grounding it in the user's specific behavior patterns.
3.  Experiments show AWARE significantly outperforms other methods, achieving up to 12.4% better results by effectively integrating dynamic world knowledge with personalized user context.

## Technical note

AWARE (Agent-based World-knowledge Augmented REcommendation) addresses the fact that generative next-POI recommenders built on LLMs freeze their world knowledge at training time and cannot perceive evolving conditions (local events, cultural trends, seasonal shifts) that drive user mobility. An LLM agent synthesizes location- and time-aware contextual narratives (hotspot text) describing regional culture, seasonal trends, and ongoing events, and, unlike RAG that returns pre-indexed documents irrespective of user, anchors these narratives in each user's behavioral context such as frequently visited POIs and habitual spatial transitions. The pretrained generative-recommendation backbone (equipped with compositional Semantic IDs that encode POI facets and are shared across POIs) is then fine-tuned with this injected personalized world knowledge to generate the next POI. On three real-world datasets AWARE outperforms competitive baselines by up to 12.4% relative improvement.
