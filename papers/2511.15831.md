## Summary

Towards Universal Virtual Try-on with MLLM-Guided Semantic Alignment":

UniFit presents a novel universal virtual try-on framework addressing two main challenges: the semantic gap between text instructions and reference images, and data scarcity in complex tasks. It leverages a Multimodal Large Language Model (MLLM) and introduces the MLLM-Guided Semantic Alignment Module (MGSA), which uses learnable queries and semantic alignment loss to provide explicit guidance for garment synthesis. Additionally, UniFit employs a two-stage progressive training strategy to effectively learn from limited data, enabling it to handle diverse tasks like multi-garment try-on and model-to-model try-on, while achieving state-of-the-art results.

## Technical note

UniFit is a universal image-based virtual try-on (VTON) framework that couples a multimodal LLM (Qwen2-VL) with a Diffusion Transformer to overcome the semantic gap between text instructions and reference images and data scarcity for complex tasks. Its MLLM-Guided Semantic Alignment Module (MGSA) uses learnable queries plus a token-wise cosine semantic-alignment loss (against frozen ViT target tokens) to distill coherent explicit guidance for the DiT, while a spatial attention focusing loss regularizes cross-attention to relevant garment regions. A two-stage progressive training strategy with a self-synthesis pipeline generates pseudo-paired data for advanced tasks, letting UniFit handle single/multi-garment, multi-view, and model-to-model try-on at SOTA quality.
