## Technical note

ScalingEval (Walmart) is a large-scale benchmarking study evaluating 36 LLMs (GPT, Gemini, Claude, Llama) as judges for complementary-item recommendation using a consensus-driven protocol without human annotation. A multi-agent framework decomposes evaluation into audit agents whose pattern audits and issue codes are aggregated into ground-truth labels via scalable majority voting. Key findings: Claude-3.5-sonnet has highest decision confidence, Gemini-1.5-pro best overall performance, GPT-4o best latency-accuracy-cost trade-off, and GPT-OSS-20B leads open-source models; structured domains (Electronics, Sports) show strong consensus while lifestyle categories (Clothing, Food) show persistent disagreement.
