Training recommender systems for next-item recommendation often requires unique embeddings to be learned for each item, which may take up most of the trainable parameters for a model. ## Technical note

This paper shows the benefit of content-based semantic IDs for next-item music recommendation, replacing per-item learned embeddings (which dominate model parameters) with shared content-derived IDs to shrink model size while allowing more model complexity. On two music datasets, trained semantic IDs outperform randomly-generated IDs when replacing song embeddings (though not when extra song metadata is already used), improving recommendation accuracy and diversity. Results are confirmed with an online A/B test on a music streaming service.
