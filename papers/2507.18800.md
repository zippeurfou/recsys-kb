## Summary

Training recommender systems for next-item recommendations often requires unique embeddings for each item, consuming most trainable parameters. This paper proposes using shared content-based features ('semantic IDs') to reduce memory usage by representing items with common semantic information derived from metadata like genre and mood. Experiments on two music recommendation datasets demonstrate that this approach improves recommendation accuracy and diversity while significantly decreasing model size, including positive results from an online A/B test on a streaming service.

## Technical note

This paper studies using content-based semantic IDs to replace per-item embeddings in a SASRec-style next-item music recommender, cutting the dominant embedding parameter count. Semantic IDs are 4-tuple codewords generated by a residual RQ-VAE over audio/content features (plus a tie-breaking dimension), compared against randomly assigned IDs. On Spotify and Pandora datasets, trained semantic IDs match or beat the full-embedding baseline while reducing trainable parameters by ~75-99%, and increasing the codebook size helps more than adding hidden dimensions. Benefits in accuracy and diversity are largest for low-feedback users, confirmed by an online A/B test on Pandora.
