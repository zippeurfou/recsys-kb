## Summary

This paper addresses the challenge of visual analogy learning, where users manipulate images using example transformations rather than text. Existing methods using a single LoRA module struggle with generalizing across diverse transformations. The authors introduce LoRWeB, which dynamically composes visual transformations by selecting and weighting a basis of specialized LoRA modules learned from data, enabling more flexible and accurate image manipulations, including achieving state-of-the-art results.

## Technical note

LoRWeB tackles visual analogy learning (given triplet a:a'::b:b', generate b') for image editing by demonstration rather than text. Instead of a single LoRA module that struggles to cover diverse transformations, it learns a basis of specialized LoRA modules and a lightweight encoder that dynamically weights the basis for each analogy in a single inference pass, effectively selecting a point in a 'space of LoRAs'. It draws on prior findings that domain-constrained LoRAs form interpolatable semantic weight spaces, avoiding the training instability of hypernetworks that generate task-specific LoRAs. The full analogy triplet is fed to the diffusion backbone through extended attention for fine-detail preservation, while CLIP/SigLIP encodings are reserved specifically for LoRA selection. Evaluations report state-of-the-art results and improved generalization to unseen transformations over single-LoRA baselines. (Note: this is an image-editing/generative-modeling paper, not recommender systems.)
