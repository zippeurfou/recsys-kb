## Summary

Recommendation systems often require text summarization (like titles) for grouped items, but standard large language model approaches struggle with ensuring relevance and adhering to strict word limits under real-world constraints.

To address this, researchers propose CARTS: a multi-agent framework leveraging Large Language Models specifically designed for structured recommendation textual summarization. It breaks down the task into stages involving feature extraction from items, iterative refinement of candidate titles based on feedback loops (GAG), and collaborative arbitration to select the final output.

Experiments on e-commerce data demonstrate that CARTS significantly outperforms existing single-pass or chain-of-thought LLM baselines by generating more relevant titles within constraints and showing improved user engagement metrics through A/B testing.

## Technical note

CARTS is a multi-agent LLM framework for generating concise, constrained titles for grouped recommendation displays (e.g., e-commerce product carousels), where generic summarizers fail to balance item relevance, coverage, and strict length limits. It decomposes the task into Generation Augmented Generation (extract salient item features and draft candidate titles), a Refinement Circle where feedback agents critique relevance/length iteratively, and an Arbitration stage that selects the final title; the authors frame it as constrained coverage optimization with approximation guarantees on refinement steps. On large-scale e-commerce data and live A/B tests, CARTS beats single-pass and chain-of-thought baselines, lifting title relevance plus CTR, add-to-cart rate, and GMV.
