## Summary

This paper addresses the issue of "embedding staleness" in recommendation systems caused by long retraining cycles. It introduces mutable sketches using a KP-tree structure to store user preferences compactly and updates embeddings continuously as new ratings arrive, eliminating the need for periodic model retraining. The system guarantees that recommendations only become stricter with each update (Theorem 1), improves speed significantly (8x faster per-batch), offers instant personalization (<1ms after first rating), and provides better item coverage on sparse data through norm-proportional sampling within its KP-tree structure.

## Technical note

Mutable sketches attack embedding staleness in two-stage recommendation by decoupling data freshness from model freshness: each user's preference vector lives in a KP-tree (a sparse segment tree with sum aggregation supporting O(log n) sample/query/update), a low-rank projection V_k is fit once via truncated SVD on a sublinear row/column sketch, and user embeddings are recomputed on-the-fly by projecting fresh ratings through the fixed V_k - no gradients, no retraining. The authors prove a monotonic-improvement guarantee (Theorem 2: each observed rating tightens the projected-error envelope), a property FunkSVD and eALS lack, and use norm-proportional KP-tree sampling that stays consistent under mutation. On KuaiRec it reaches 0.810 RMSE reading only 1.8% of the matrix (vs ALS 0.822 at 100%) with ~8x faster per-batch updates, and a brand-new user gets a personalized recommendation in <1 ms (0.49 ms P50) after a single rating via FAISS ANN retrieval. Norm-proportional sampling gives 40-130% better item coverage below ~1% density, with a crossover to uniform sampling around 5%, and bias correction (per-item means) helps on moderately sparse data.
