## Technical note

LSRP is a leader-subordinate retrieval framework for privacy-preserving cloud-device collaboration, where an on-cloud LLM acts as leader generating task-specific guidelines and an on-device SLM acts as subordinate processing private user data locally. It introduces user-to-user retrieval-augmented generation (U-U-RAG) to dynamically select the best leadership strategy per user-task, and small-model-feedback DPO (SMFB-DPO) where the SLM labels two cloud-generated guidelines as prefer/reject to fine-tune the cloud LLM. Experiments on two datasets show LSRP consistently outperforms state-of-the-art baselines on question-answer relevance and personalization while preserving privacy via on-device retrieval.
