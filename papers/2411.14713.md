## Summary

This paper introduces LIBER, a system designed to improve recommender systems by effectively leveraging Large Language Models (LLMs). It addresses two main limitations: efficiently processing long user behavior sequences and capturing dynamic user interests. The approach uses three modules for incremental sequence partitioning, interest inference with LLMs, and comprehensive representation integration.

## Technical note

Tackles the 'lifelong user behavior incomprehension' problem where LLMs degrade on long textual behavior sequences and incur high recompute cost per update. LIBER splits behavior into a short-term cache and partitioned long-term memory (User Behavior Streaming Partition), runs an LLM once per fixed partition in a cascading way to infer intra-block interest summaries and inter-block interest shifts (User Interest Learning), then fuses the textual outputs via a knowledge encoder and attention layer (User Interest Fusion). The resulting representation plugs into any recommendation model. Deployed on Huawei's music service, it lifted play count 3.01% and play time 7.69%.
