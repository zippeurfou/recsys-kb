## Summary

1.  The paper addresses the challenge of enabling AI agents to effectively support the entire business decision-making cycle (from ideation to evaluation and learning) by filling a gap in existing experimentation platforms.
2.  The proposed solution is a comprehensive software framework combining mathematical complexity management with software design focused on orchestration, safety, and efficiency, allowing AI agents to analyze diverse experiments.
3.  This framework enriches standard causal analysis with advanced techniques like heterogeneous effects and mediation, providing a unified, safe software interface usable by AI, and demonstrates improved performance and code efficiency compared to baseline methods.

## Technical note

This paper presents a software framework that lets AI agents close the business decision loop from experiment reporting to insight and next ideation, going beyond difference-in-means treatment effects. It combines mathematical reductions that unify many causal-inference models (regression, instrumental variables, heterogeneous treatment effects, mediation, policy algorithms, forecasts) into a single composable interface, with software design targeting orchestration, safety, and multiplicity for agent use. It further enriches analysis with variance reduction and anytime-valid inference to tighten the iteration loop, and enforces causal-inference principles so agents do not return correlational estimates or wrong-signed effects. Evaluated on experiment-analysis objectives, the framework improves code correctness, reduces lines of code, and outperforms a vanilla-agent baseline in performance.
