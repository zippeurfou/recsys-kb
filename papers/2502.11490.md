## Summary

1.  The paper addresses the challenge of efficiently providing relevant recommendations on large web scales, tackling both accuracy (due to fragmented user-item relationships) and speed/bottleneck issues in graph-based approximate nearest neighbor searches under high concurrency.
2.  It introduces GMP-GR, a GPU-accelerated framework designed for multi-relational parallel graph retrieval that aims to improve recommendation effectiveness while boosting search efficiency.
3.  This system achieves higher accuracy through unified relevance metrics and significantly increases throughput via hierarchical parallel ANNS on GPUs, handling billions of users efficiently; it has been successfully deployed at Baidu across multiple applications.

## Technical note

GMP-GR is a Baidu GPU-accelerated framework for multi-relational parallel graph retrieval in web-scale recommendation, addressing both accuracy loss from fragmented user-item relationships and throughput bottlenecks in graph-based approximate nearest neighbor search under high concurrency. It improves retrieval effectiveness through unified relevance metrics that integrate multiple relation types, and increases efficiency via hierarchical parallel ANNS executed on GPUs. The system scales to billions of users and has been deployed at Baidu across multiple applications, achieving both higher accuracy and substantially higher retrieval throughput.
