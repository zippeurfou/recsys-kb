## Summary

1.  Existing retrieval models for recommendations often fail to capture dynamic user preferences effectively due to their single-round inference approach.
2.  To address this, the paper introduces Ada-Retrieval, an adaptive multi-round paradigm that iteratively refines user and item representations using model-agnostic adapters.
3.  Ada-Retrieval significantly improves recommendation performance across different datasets and backbone models, demonstrating the benefits of its iterative refinement process.

## Technical note

Ada-Retrieval introduces an adaptive multi-round retrieval paradigm for sequential recommenders, replacing single-round inference where a fixed user representation confines the top-k search to a static region of item space. It splits retrieving k items into n rounds, refining the user representation each round using previously retrieved items as feedback so later rounds can search different regions. Two model-agnostic modules do this: an item representation adapter (learnable filter layer plus context-aware attention) adjusts history item embeddings, and a user representation adapter (GRU plus MLP) fuses prior-round user context into the current representation. Across three public datasets and five sequential backbones (e.g., SASRec, FMLPRec), it yields consistent gains, e.g., +8.55% NDCG@50 for SASRec on Beauty.
