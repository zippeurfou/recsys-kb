## Technical note

HyWA is a speaker-conditioning method for personalized voice activity detection (PVAD) that uses a hypernetwork to generate user-specific VAD weights from a speaker embedding, reparameterizing personalized weights as a shared base plus a speaker-specific residual. Unlike FiLM/concatenation input-conditioning or per-user PEFT adapters, HyWA modifies only a subset of VAD layers via a single hypernetwork forward pass at enrollment, requiring no architectural change to the base VAD. Trained with cross-entropy over ternary labels (non-speech / target-speaker / non-target-speaker), HyWA outperforms existing speaker-conditioning baselines (e.g. concatenation) in mean average precision across clean and noisy conditions.
