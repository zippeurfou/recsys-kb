## Summary

Current LLM agent skill ecosystems, despite growing, don't necessarily improve performance; in fact, focused skill sets often work better, and too many skills can hinder execution due to poor orchestration.

To address this, the paper introduces GraSP, a novel architecture that structures skills into typed directed acyclic graphs (DAGs) with explicit dependencies, adding a compilation layer between retrieval and execution.

GraSP executes these skill graphs with node-level verification and local repair, significantly improving performance (+19 points reward, 41% fewer steps) and efficiency over flat skill baselines and other methods across complex tasks, confirming that structured skill composition is crucial for reliable agent execution.

## Technical note

GraSP inserts a compilation stage between skill retrieval and execution for LLM agents, transforming flat skill sets into a typed DAG with state/data (hard) and order (soft) precondition-effect edges. Memory-conditioned retrieval fuses a direct semantic distribution with a memory-induced distribution weighted by skill frequency in successful trajectories, plus a calibrated confidence for routing. Execution traverses in topological order with per-node pre/postcondition verification; failures trigger five typed local repair operators (Rebind, InsertPrereq, Substitute, Rewire, Bypass) bounded to an h-hop neighborhood, reducing replanning from O(N) to O(d^h). Confidence-based routing falls back to ReAct when retrieval confidence is low. Across ALFWorld, ScienceWorld, WebShop, InterCode and eight LLM backbones, GraSP wins every configuration (up to +19 reward, up to 41% fewer steps) and is robust to skill over-retrieval and quality degradation.
