## Summary

RoboEarth was an early cloud robotics framework using hand-crafted, standardized knowledge graphs (OWL ontologies) for robots. The authors argue that Large Language Models (LLMs) can automate knowledge acquisition, proposing RecipeMasterLLM, a system that generates OWL action ontologies based on user prompts. This system uses a fine-tuned LLM combined with Retrieval-Augmented Generation (RAG) to provide contextual environmental knowledge, improving the accuracy of generated action descriptions consistent with RoboEarth standards.

## Technical note

RecipeMasterLLM revisits the RoboEarth cloud-robotics framework by automating the previously hand-crafted generation of OWL action ontologies (action recipes) with LLMs. A CodeLLaMa-13B model is QLoRA-fine-tuned on 350 curated action recipes (some GPT-4-generated, i.e. distilled from a larger teacher) in the RoboEarth standard, then augmented at inference with Retrieval-Augmented Generation over environment digital-twin knowledge via LlamaIndex and bge-small-en-v1.5 embeddings. Generated recipes are asserted into the RoboEarth Knowledge Graph (RDF/OWL) and queried with SWI-Prolog by the robot control executive; experiments in an O3DE/ROS2 simulation show the system can turn vague prompts like 'serve me a drink' into valid, grounded long-horizon plans.
