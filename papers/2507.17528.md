## Summary

This paper introduces a novel algorithmic framework for matrix contextual bandits, aiming to improve sequential decision-making in scenarios like online advertising where user/item data has inherent low-rank structure but also additional graph information exists. The core contribution is integrating both structures—low-rank via nuclear norm regularization and similar relationships via graph connectivity (matrix Laplacian)—within a generalized UCB algorithm for the first time. This unified approach effectively reduces cumulative regret compared to existing methods by leveraging richer data, incorporating findings from synthetic and real-world experiments.

## Technical note

The paper studies contextual bandits where the reward parameter matrix is low-rank and additional user/item similarity graphs are available. It proposes GG-ESTT (Graph-Generalized Explore Subspace Then Transform), which estimates row/column subspaces using a nuclear-norm plus a dual-graph matrix Laplacian regularizer under a generalized linear model, then acts in a transformed low-dimensional space. Theoretically it derives a tighter cumulative regret bound that improves with more graph information and is independent of the number of actions. Synthetic and real experiments (cancer treatment, movie recommendation, ad search) show lower regret and higher optimal-action hit rate than single-aspect baselines.
