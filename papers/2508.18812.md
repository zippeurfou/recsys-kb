## Technical note

STARec (Huawei) is a slow-thinking augmented agent framework endowing recommenders with deliberative reasoning, modeling each user as an agent with dual-process cognition (fast ranking + slow chain-of-thought reasoning). It uses anchored reinforcement training: stage 1 distills structured knowledge and CoT rationales from a teacher reasoning model (DeepSeek-R1), stage 2 applies RL with a ranking-oriented, preference-aligned reward through simulated feedback loops. On MovieLens-1M and Amazon CDs it surpasses state-of-the-art baselines while using only 0.4% of the full training data.
