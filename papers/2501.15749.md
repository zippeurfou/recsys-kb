## Technical note

Introduces GenMentor, an LLM-powered multi-agent framework for goal-oriented personalized learning in Intelligent Tutoring Systems. It fine-tunes an LLM skill identifier on a custom CoT-augmented goal-to-skill dataset, maintains a dynamic learner profile (cognitive status, preferences, behavior), schedules an evolvable learning path refined by an LLM learner simulator, and generates content via an exploration-drafting-integration mechanism with RAG. With GPT-4o, GenMentor reaches Recall 0.67 / Precision 0.63 / Goal-Alignment 4.28 on goal-to-skill mapping, plus top learning-path (Progression 4.56, Engagement 4.71) and content (Content Quality 4.86, Personalization 4.17) scores, beating direct- and CoT-prompt baselines. Deployed in Microsoft's AIEP platform; a 20-participant human study reported strong goal-alignment and usability ratings (4.3-4.6).
