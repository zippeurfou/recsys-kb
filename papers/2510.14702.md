## Summary

(Abstract fallback)

The next point-of-interest (POI) recommendation task aims to predict the users' immediate next destinations based on their preferences and historical check-ins, holding significant value in location-based services. Recently, large language models (LLMs) have shown great potential in recommender systems, which treat the next POI prediction in a generative manner. ## Technical note

CoAST (Cognitive-Aligned Spatio-Temporal LLM) is an LLM framework for next-POI prediction that uses natural language as an interface to inject world knowledge, spatio-temporal trajectory patterns, user profiles, and situational context (season, weather, holidays). It has two stages: continued pretraining on enriched, tokenized spatio-temporal trajectory sequences to learn mobility patterns, then cognitive alignment via SFT plus a reinforcement-learning phase to make recommendations cognitively plausible to users. Deployed in AMAP's 'Guess Where You Go' homepage feature, long-term online A/B tests show +4.23% P-CTR and +4.59% U-CTR versus the traditional cascade ranking system.
