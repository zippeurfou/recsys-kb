Large language models (LLMs) have advanced conversational AI assistants. However, systematically evaluating how well these assistants apply personalization--adapting to individual user preferences while completing tasks--remains challenging. ## Technical note

Amazon introduces PersonaLens, a benchmark for evaluating personalization in task-oriented conversational AI assistants, spanning over 100 tasks across 20 domains with diverse user profiles carrying rich preferences and interaction histories. It uses two LLM-based agents: a user agent that engages in realistic task-oriented dialogues and a judge agent using the LLM-as-a-Judge paradigm to score personalization, response quality, and task success. Experiments across current LLM assistants reveal substantial variability in personalization ability, with high agreement between the judge and human evaluations.
