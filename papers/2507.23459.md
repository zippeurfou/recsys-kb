## Technical note

KLAN (Kuaishou Landing-page Adaptive Navigator) defines Personalized Landing Page Modeling (PLPM): proactively selecting the best landing page for a user on app entry to optimize the short-term Page Drop-off Ratio (PDR) and long-term engagement, distinct from the usual in-page sequential recommendation stage. KLAN is hierarchical with three components: KLAN-ISP for inter-day static page preference, KLAN-IIT for intra-day dynamic interest transitions, and KLAN-AM to adaptively integrate them for the navigation decision. Deployed at full traffic serving hundreds of millions of users, online experiments showed +0.205% Daily Active Users and +0.192% user Lifetime.
