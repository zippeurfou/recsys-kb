## Summary

Traditional faceted search systems struggle with dynamic catalogs and user intent, often relying on static or statistical methods. GenFacet introduces an end-to-end generative framework using a large language model, comprising two tasks: Context-Aware Facet Generation for dynamic navigation options and Intent-Driven Query Rewriting for precise user query translation. This system, validated on JD.com via offline and online testing, significantly improved user engagement, boosting facet click-through rate by 42.0% and user conversion rate by 2.0%.

## Technical note

GenFacet is an industrial end-to-end generative faceted-search framework deployed at JD.com that reframes faceted search as two coupled generative tasks within one LLM: Context-Aware Facet Generation, which dynamically synthesizes trend-responsive navigation options from query, user profile, session behavior, a product knowledge graph, and real-time web content, and Intent-Driven Query Rewriting, which turns a user's facet click (treated as explicit relevance feedback) into an optimized retrieval query to close the retrieval loop. This addresses three limitations of rule-based/statistical facet systems: poor timeliness for emerging vocabulary, a persistent vocabulary gap between colloquial queries and structured attributes, and cascading disconnection between facet selection and downstream retrieval in traditional three-stage pipelines. Rather than applying facets as rigid Boolean filters (which cause zero-recall on long-tail queries), it rewrites the retrieval query itself. Training is a multi-task pipeline combining teacher-student distillation (from reasoning models like DeepSeek-R1), multi-task SFT, and GRPO to directly optimize downstream search satisfaction. Online A/B at JD Search shows +42.0% facet CTR and +2.0% user conversion rate.
