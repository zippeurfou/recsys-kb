## Summary

This paper introduces DiRecGNN, an attention-enhanced framework for recommending which attributes to monitor for cloud services. It addresses the challenge of capturing long-range dependencies in heterogeneous graphs, which existing methods struggle with. By using transformer-inspired attention mechanisms and specialized loss functions, DiRecGNN significantly improved recommendation quality (MRR increase) and was well-received by product teams.

## Technical note

DiRecGNN frames selecting which dimensions a cloud-service monitor should track as an entity-recommendation problem over a heterogeneous 'monitor entity graph' of monitors, metrics, and dimensions, which is heavy-tailed and sparse. The model uses transformer-style graph convolutions with multi-head attention over heterogeneous neighbors and their attributes, and attends to paths sampled via random walks with restart to capture long-range dependencies that standard message passing misses. A multi-faceted attention-alignment loss handles the data sparsity. On the production monitor dataset it improves MRR by 43.1% over baselines, and deployed at CompanyX service owners rated the recommendations 4.5/5, with the paper reporting deployment lessons on serving recommendations at scale.
