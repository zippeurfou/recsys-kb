## Summary

This paper introduces a payload optimization method for Federated Recommender Systems (FRS) that tackles the challenge of large model sizes transmitted during FL. The solution uses a multi-armed bandit approach guided by a novel reward function to selectively transmit parts of the global model to users. Experiments show this method can achieve a significant 90% reduction in model payload while incurring only a small 4-8% loss in recommendation accuracy, particularly on sparse datasets.

## Technical note

The paper tackles the communication payload problem in federated recommender systems, where the global item-factor matrix transmitted each round grows linearly with the item count and can exceed 1GB. The authors formulate item selection as a multi-armed bandit (FCF-BTS) using Bayesian Thompson Sampling with Gaussian priors and a novel reward derived from the gradient feedback of selected items, so only a subset of the global model is sent per round. This is presented as the first method to address item-dependent payloads in federated collaborative filtering. Evaluated on MovieLens, Last-FM, and MIND, it achieves up to 90% payload reduction with only ~4-8% recommendation performance loss on highly sparse datasets and outperforms non-bandit selection baselines.
