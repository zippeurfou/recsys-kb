## Technical note

JAM (Just Ask for Music, Criteo/Deezer) is a lightweight framework for natural-language, personalized music recommendation that avoids costly LLM inference. Inspired by TransE knowledge-graph embeddings, it models user-query-item interactions as vector translations in a shared latent space (u + q approx t), and aggregates multimodal item features (collaborative-filtering signals, audio, lyrics) via cross-attention and sparse mixture-of-experts while explicitly encoding long-term user tastes. It introduces JAMSessions, a dataset of over 100k user-query-item triples with anonymized embeddings combining conversational queries and long-term preferences, and shows accurate, interpretable recommendations that integrate with existing music stacks.
