## Summary

Large language models (LLMs) often struggle to solve competitive programming problems correctly on the first attempt. To improve this, researchers developed Agentic Verifier, an execution-based agent that actively searches for specific test inputs to expose flaws in candidate code solutions, replacing inefficient random sampling. This verifier learns through a combination of data synthesis, fine-tuning, and reinforcement learning, leading to significant gains in accuracy (up to +10-15%) across benchmarks, demonstrating clear test-time scaling benefits beyond just re-ranking solutions.

## Technical note

This paper improves LLM competitive-coding accuracy with Agentic Verifier, an execution-based agent that actively searches for specific test inputs to expose flaws in candidate solutions instead of random sampling. The verifier is trained through a combination of data synthesis, supervised fine-tuning, and reinforcement learning. It yields accuracy gains of up to +10-15% across coding benchmarks and shows clear test-time scaling benefits beyond simple re-ranking of solutions. The approach demonstrates that learned adversarial test generation is a stronger verification signal than resampling.
