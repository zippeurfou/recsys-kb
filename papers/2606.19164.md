## Summary

The paper introduces **Essential Subspace Merging** as a method for combining capabilities of multiple fine-tuned models originating from the same pre-trained checkpoint into a single multi-task model. This addresses challenges caused by **inter-task interference**, which arises when accumulated task-specific parameter updates negatively impact performance during merging. The authors propose decomposing each task update based on its principal component activation shifts to identify and orthogonalize essential directions, while proposing static (ESM) and dynamic (ESM++) training-free merging techniques that effectively preserve the merged model's knowledge across tasks by reducing interference.

## Technical note

This paper tackles inter-task interference in training-free model merging of checkpoints fine-tuned from a shared pre-trained model. It observes that a task update's output activation-shift energy concentrates in a few principal directions (the essential subspace), while abundant low-energy directions accumulate across tasks to cause severe interference. Essential Subspace Decomposition (ESD) runs PCA on output activation shifts and truncates by functional energy -- provably lower truncation error than SVD, which ranks by parameter-space energy. ESM is a static training-free method that orthogonalizes and fuses essential components into a compact multi-task model, and ESM++ extends it dynamically by storing per-task residuals as low-rank experts selected at inference via prototype-based routing. Experiments across vision models, discriminative and generative language models, and multiple scales show state-of-the-art merging performance.
