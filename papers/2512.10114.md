## Summary

1.  Large Language Models (LLMs) often provide inaccurate agricultural advice due to contextual "hallucinations," failing to account for region-specific factors like climate and soil.
2.  To address this, the paper introduces AgriRegion, a Retrieval-Augmented Generation (RAG) framework that prioritizes local accuracy by incorporating geospatial metadata, restricting the knowledge base to verified local sources, and using region-prioritized re-ranking.
3.  Evaluated using a new benchmark dataset, AgriRegion significantly reduces hallucinations (by 10-20%) and improves user trust compared to state-of-the-art LLMs for agricultural advisory tasks.

## Technical note

AgriRegion is a region-aware RAG framework for agricultural advisory that mitigates 'contextual hallucination', where advice is scientifically sound in one region but wrong in another. Beyond semantic similarity, it adds a geospatial metadata injection layer and a region-prioritized re-ranking step, restricting the knowledge base to verified local extension documents and enforcing geo-spatial constraints during retrieval. The pipeline embeds document chunks with Ada v2 into a Chroma vector store using HNSW-based ANN search with metadata filtering. Evaluated on a new AgriRegion-Eval benchmark of 160 questions across 12 subfields, it reduces hallucinations by 10-20% versus state-of-the-art LLM systems and improves trust scores.
