## Summary

1.  **Problem:** Generative user simulation faces two main challenges: (i) the stochastic nature of user behavior, where identical inputs can lead to different realistic browsing trajectories, and (ii) the sparsity of key events (like clicks) compared to common browsing actions, making them less effective training targets in standard stepwise simulators.
2.  **Solution:** The paper introduces BrowseFlow, a conditional discrete flow matching method specifically designed for generative user simulation. It models browsing by predicting the extent (total time) and the sequence of sparse key events directly, using techniques like random event retention and transition rate matching.
3.  **Validation:** BrowseFlow uses the energy score and Wasserstein distance for evaluation, demonstrating superior distributional performance compared to existing methods across multiple datasets, including the newly proposed TaobaoBrowse benchmark with real recommendation contexts and detailed user trajectories.

## Technical note

Generative user simulators must model stochastic browsing responses (the same user and feed yield different trajectories, so matching one logged trajectory is the wrong target) and sparse key events (clicks/likes are 1.5-6% of exposures, so dense stepwise simulators under-supervise them). BrowseFlow (Alibaba/Taobao) represents a response as a browsing extent D plus an ordered sequence of key events, predicts a categorical distribution over D from session and history Transformers, then generates events conditioned on D with discrete flow matching: a continuous-time Markov chain over partial event sequences whose insertion rate factorizes into intensity x (gap, depth, mark), trained by conditional rate matching where random event retention defines the probability path and a generalized-KL loss fits the rates. Evaluation uses the energy score (a proper scoring rule over K sampled responses) and Wasserstein-1 between observed and generated key-event count distributions, on a new TaobaoBrowse benchmark of 130K real Taobao recommendation sessions plus KuaiRand-Like and AdSERP. Against UBM, DBN, RL4RS-DIEN, UserSim, KuaiSim and CaseRec, BrowseFlow has the best ES and Count W1 on all three datasets (TaobaoBrowse ES 0.0726 vs 0.1085 for the best baseline, Count W1 0.070 vs 0.260) and better first-click placement and extent recovery on long sessions, while its pointwise click AUC is slightly below local predictors; ablations show the sparse representation and insertion-based flow matching each help and dense insertion hurts.
