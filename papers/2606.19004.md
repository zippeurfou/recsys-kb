## Summary

Synergizing Seed Exploration and Spot GPUs for DiT RL Post-Training":

1.  Training Diffusion Transformers (DiTs) using Reinforcement Learning (RL) post-training is extremely expensive, typically requiring thousands of high-end GPUs due to slow convergence from seed exploration and the inability to efficiently use cheaper "spot" GPUs which often finish tasks nearly simultaneously.
2. The paper introduces Spotlight, a system that combines two key innovations: it shows RL can tolerate using stale model weights for selection if they preserve relative ranking, allowing exploration on idle spot GPUs; and it enables faster reconfiguration of Sequence Parallelism (SP) groups to reuse node state effectively upon preemption or resizing.
3. Resulting in three main techniques – a bandit-based planner, elastic sequence parallelism, and a preemption-aware scheduler – Spotlight significantly speeds up training by 4x on average and reduces costs by 1.4-6.4 times while improving image quality compared to baseline methods using both seed exploration and spot GPUs for DiT RL post-training.

## Technical note

Spotlight is the first system to harvest cheap preemptible spot GPUs for RL post-training of Diffusion Transformers (DiTs), which is otherwise prohibitively expensive because DiT rollouts finish nearly simultaneously (no stragglers to pipeline) and spot preemptions fragment Sequence Parallelism (SP) groups. Its first insight is that seed exploration tolerates stale model weights -- using the previous iteration's weights preserves relative reward ranking of seeds -- so exploration can be offloaded to otherwise-idle spot GPUs during training while preserving on-policy semantics. Its second insight is that SP reconfiguration can reuse on-node state (persistent CPU schedulers plus intra-node NVLink weight copying), cutting recovery from minutes to sub-second. It combines a bandit-based exploration planner maximizing reward variance within the time budget, elastic sequence parallelism, and a preemption-aware pull-based request scheduler; on Qwen-Image it reaches target validation 4x faster and cuts cost 1.4-6.4x while improving image quality.
