## Summary

This paper addresses cross-domain sequential recommendation by reevaluating standard transformer self-attention mechanisms. It proposes AutoCDSR, an approach enhancing the core attention mechanism through multi-objective optimization where both recommendations and cross-domain relevance are balanced. The method effectively transfers knowledge across domains automatically without extra complexity or hyperparameter tuning and demonstrates significant performance improvements on existing models like SASRec and Bert4Rec.

## Technical note

Cross-domain sequential recommendation (CDSR) suffers from negative transfer when behaviors from multiple domains are naively stitched into one sequence, and prior fixes add heavy domain-specific modules. AutoCDSR instead optimizes the existing transformer self-attention directly, framing training as a multi-objective problem that minimizes cross-domain attention scores alongside the recommendation loss and finds a preference-aware Pareto-optimal solution via multiple gradient descent, so cross-domain attention rises only when it helps prediction. AutoCDSR+ adds information-bottleneck tokens that channel cross-domain communication through a dedicated small token set. As a lightweight plug-and-play module it improves Recall@10 for SASRec and Bert4Rec by 9.8% and 16.0% (NDCG@10 by 12.0% and 16.7%) on average, matching SOTA CDSR models at ~4x lower cost with <20% extra overhead.
