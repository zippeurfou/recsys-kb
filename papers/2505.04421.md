## Summary

This paper introduces LONGER, an optimized transformer architecture designed specifically for handling ultra-long user behavior sequences in industrial recommender systems. Key innovations include a global token mechanism to stabilize attention across vast contexts and a token merge module using lightweight inner models plus hybrid attention to significantly reduce computational complexity (quadratic cost). The authors also detail engineering optimizations like mixed-precision training, KV cache techniques, and a synchronous framework that enable efficient GPU-based deployment at massive scale.

## Technical note

LONGER is a GPU-efficient transformer for end-to-end ultra-long user behavior sequence modeling (up to 10,000 events) in industrial recommenders, avoiding the upstream-downstream inconsistency of two-stage retrieval or pre-trained user-embedding approaches. It introduces global tokens (target/UID anchors that get full attention receptive field and mitigate attention-sink), a Token Merge module with lightweight InnerTransformers plus a hybrid cross-causal/self-causal attention design to cut quadratic attention cost (~50% FLOPs reduction, nearly lossless), and system optimizations: fully synchronous GPU dense/sparse training, mixed-precision with activation recompute, and M-FALCON-style KV cache serving. On a 5.2B-sample Douyin Ads CVR dataset it reaches AUC 0.85290 (+1.57% over base, +0.21% over vanilla Transformer), and online A/B tests show gains such as +2.1% ADVV (Short Video ads) and +7.9% Order/U and +6.5% GMV/U in Douyin e-commerce live streaming. Ablations show Recent-100 query selection beats learnable/uniform sampling and performance follows power-law scaling in sequence length, FLOPs, and parameters.
