## Technical note

MaRI is a matrix re-parameterized inference framework that losslessly accelerates coarse- and fine-ranking model inference in large-scale RecSys, complementing lightweighting and knowledge distillation which sacrifice accuracy. Motivated by redundancy in user-side computation of the feature-fusion matrix multiplication, it applies structural reparameterization and a graph coloring algorithm (GCA) to automate implementation, noting a neat input layout is critical (fragmented layout degrades performance by ~38%). Online A/B tests on a real large-scale recommendation system show up to 1.3x speedup with no accuracy loss and 5.9% coarse-ranking resource reduction.
