## Technical note

MVP-RAG (Alibaba/Xianyu) addresses Product Attribute Value Identification (PAVI) on second-hand e-commerce by combining retrieval, generation, and classification. It frames PAVI as a retrieval-generation task where the product title is the query and both products and attribute values form a multi-level corpus: TACLR retrieves candidate attribute values, a BGE model retrieves similar products, and an LLM generates standardized values, with OOD values added to training. This multi-level retrieval reduces hallucination from irrelevant products and handles OOD attributes, outperforming state-of-the-art baselines and deployed in a real industrial environment.
