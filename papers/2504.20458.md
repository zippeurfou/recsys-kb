## Summary

Conversational Recommendation Systems (CRSs) face difficulty accurately understanding complex user preferences during multi-turn conversations, which limits their recommendation quality despite external knowledge being available. To overcome this challenge and avoid poor user experience from direct interaction, researchers propose GRSU, an automated simulated user based on generative reward models that provides detailed feedback to the CRS. This system integrates coarse-grained item scoring and fine-grained attribute critiques through instruction tuning on synthetic data, using beam search for efficient multi-turn interactions, further enhanced by a candidate ranking method, proving effective and transferable across datasets.

## Technical note

GRSU builds a label-free simulated user, based on generative reward models, that automatically interacts with conversational recommender systems to help them uncover complex, multifaceted user preferences without frequent real-user involvement. The simulated user provides two feedback actions inspired by generative reward models: generative item scoring (coarse-grained, reward as the probability of a Yes/No token) and attribute-based item critiquing (fine-grained), unified into an instruction format and trained via instruction tuning on synthesized data. To balance effectiveness and efficiency, the multi-turn interaction is run with reward-guided beam search, followed by an efficient candidate-ranking method to derive the final list. On public datasets, untuned LLM CRSs equipped with the simulated user beat trained baselines (e.g., on INSPIRED with a single interaction round) and the simulator transfers from high- to low-resource datasets.
