## Summary

1.  Automated patch porting between similar codebases is crucial, but current tools fail to handle complex, non-local "implicit inconsistencies" that require cross-codebase mapping knowledge.
2.  To address these challenges, the paper introduces MIP, a system leveraging an LLM, compiler, and code analysis, using different strategies based on whether source identifiers exist in the target codebase.
3.  Experiments and a user study demonstrate that MIP significantly outperforms existing methods, successfully resolving more than twice the number of patches and proving its practical effectiveness.

## Technical note

This work addresses automated patch porting between similar codebases, focusing on non-local 'implicit inconsistencies' that require cross-codebase mapping knowledge that current tools fail to handle. It introduces MIP, a system that combines an LLM with a compiler and code analysis, selecting different porting strategies depending on whether source identifiers already exist in the target codebase. A user study and experiments show MIP resolves more than twice as many patches as existing methods. The approach demonstrates practical effectiveness for real-world patch adaptation across divergent codebases.
