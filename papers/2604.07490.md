## Summary

Geospatial foundation models create dense embeddings of complex data, but integrating them effectively with Large Language Models (LLMs) for reasoning was challenging due to inefficiencies in existing text-based methods. To address this, the authors introduced DFR-Gemma, a framework that aligns these high-dimensional embeddings directly with the LLM's latent space using a lightweight projector. This allows LLMs to reason intrinsically over the spatial features represented by the embeddings, eliminating the need for intermediate text conversion and significantly improving efficiency and accuracy across various geospatial tasks in zero-shot settings.

## Technical note

DFR-Gemma injects PDFM geospatial embeddings into a frozen Gemma/Qwen LLM by projecting each 330-d embedding into N soft tokens via a two-layer GELU MLP, trained only with cross-entropy language-modeling loss while keeping the backbone frozen. Interleaved text and soft tokens use dynamic positional re-indexing so RoPE attention resolves spatial-textual relations. Using N=4 tokens with a shared multi-task projector beats N=1 and task-specific projectors on multi-embedding queries, giving the model latent bandwidth for selective attention. It outperforms textual-serialization and RAG baselines on accuracy and token efficiency, and stays robust to linguistic-style and postal-code-to-county distribution shifts where MLP/LightGBM baselines degrade.
