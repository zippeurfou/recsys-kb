## Summary

Modern recommendation systems require large-scale deep learning models with massive embedding tables, but traditional inference servers cannot efficiently handle this scale. This paper introduces HugeCTR Hierarchical Parameter Server (HPS), a distributed GPU framework designed specifically for recommendation model inference. HPS significantly reduces end-to-end latency and increases throughput by using a GPU-accelerated hierarchical storage system for fast embedding lookups, along with other features like online training support and easy APIs.

## Technical note

NVIDIA introduces the HugeCTR Hierarchical Parameter Server (HPS), a distributed GPU inference framework for large-scale deep recommendation models with terabyte-scale embedding tables that cannot fit on standalone inference servers. HPS combines a high-bandwidth GPU embedding cache with a redundant hierarchical storage architecture to serve low-latency embedding lookups for online inference, and adds online training support plus lightweight APIs for integration into existing workflows. Studies on synthetic and public datasets show 5-62x end-to-end latency speedup over CPU baselines depending on batch size, and multi-GPU concurrent deployment further increases inference QPS.
