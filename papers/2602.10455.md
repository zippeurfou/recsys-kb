## Technical note

UG-Sep (User-Group Separation, ByteDance) is the first framework to make user-side computation reusable in TokenMixer-based dense feature-interaction models (RankMixer/TokenMixer-Large), where user and candidate features are entangled across layers and prevent KV-cache-style reuse. It disentangles U-tokens (pure user info) from G-tokens via a separation mask so per-token FFN computations on U-tokens can be shared across candidates via user-level aggregation, adds an Information Compensation strategy to recover masked user-item interactions, and applies W8A16 weight-only quantization to relieve the resulting memory-bound bottleneck. Deployed on Douyin Feed, Hongguo Feed, Chuanshanjia Ads, and Qianchuan Ads, UG-Sep cuts inference latency by up to 20% with stable online metrics.
