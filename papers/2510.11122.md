## Technical note

DyKnow-RAG (Taobao) is an RL framework teaching LLMs to dynamically trust and utilize noisy external context for e-commerce query-item relevance under strict production latency. Built on Group Relative Policy Optimization (GRPO), it uses a dual-group rollout strategy (parametric-only vs with-context) and a posterior-driven inter-group advantage scaling mechanism to optimize context utilization without human process labels or extra inference passes, deciding within a single pass whether to adopt/partially adopt/ignore retrieved context. It integrates structured CoT and an uncertainty-prioritized RL pool with optional DPO warm-start. Deployed on Taobao serving billions of daily requests, it lifts business metrics (GSB, Item Goodrate) at p99 latency under 400ms.
