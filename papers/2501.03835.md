## Technical note

Product Attribute Value Identification (PAVI) must infer implicit and out-of-distribution values and emit normalized outputs, but classification methods can't handle OOD values and LLM generation methods are uncontrollable and slow. Alibaba proposes TACLR (Taxonomy-Aware Contrastive Learning Retrieval), the first retrieval-based PAVI method: a CLIP-inspired shared encoder embeds the product (query) and taxonomy values (corpus), trained with contrastive loss using taxonomy-aware hard negatives (same category/attribute) plus a learnable null value, and served via FAISS with an adaptive dynamic threshold derived from the null value's score. On Xianyu-PAVI (8,803 categories, 6.3M category-attribute-value tuples) TACLR reaches 86.2% micro-F1@1, beating fine-tuned Llama3.1 (84.7%) and RAG (63.2%), with 12.7 ms/sample and 630 samples/sec (vs >100 ms for LLM baselines); taxonomy-aware negatives lift F1 from 53.3% (in-batch) to 86.2%, and it is deployed on Xianyu processing millions of listings daily.
