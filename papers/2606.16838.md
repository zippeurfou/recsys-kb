## Technical note

OneRank is a Transformer-native multi-task ranking framework that removes the conventional encoder-predictor split (G(Z=F(X))), which causes a task-agnostic information bottleneck, seesaw gradient interference, and a dataflow mismatch between attention-based encoding and static MLP prediction. In the forward pass OneRank builds task-private channels alongside shared pathways via task-specific tokens with mutual invisibility, candidate-aware contextualization, and controlled cross-task relational attention; in the backward pass strategic cross-task gradient detachment isolates task-private updates (turning cross-task attention into read-only memory) to prevent negative transfer. It replaces static MLP scorers with a dynamic inner-product matching formulation for context-aware ranking. Offline and online A/B experiments on large-scale industrial data show significant multi-task ranking gains with maintained efficiency.
