## Technical note

EMLoC lets users fine-tune large foundation models within the same memory budget as inference. It builds a task-specific lightweight emulator via activation-aware SVD (SVD-LLM) on a small downstream calibration set, fine-tunes it with LoRA, then applies a novel LoRA correction algorithm to compensate for the misalignment between the compressed emulator and the original model before merging for inference. EMLoC enables fine-tuning a 38B model (originally 95GB) on a single 24GB consumer GPU and outperforms baselines across datasets and modalities; recsys relevance is only via personalization framing (best-effort).
