## Summary

This paper addresses two main challenges in cross-domain sequential recommendation: data isolation due to business constraints and user heterogeneity (many users lacking cross-domain activity). To overcome these, it proposes a framework that exclusively transfers learned user representations between domains, avoiding raw data sharing. This method integrates source representations via a lightweight adapter with the target domain's sequence and seamlessly defaults to a target-only recommender when source data is unavailable, demonstrating consistent performance improvements across different experimental setups.

## Technical note

Cross-domain sequential recommendation methods usually pool raw interactions or item embeddings across domains and assume full user overlap, which business data-isolation constraints and users active in only one domain rule out. FLADRec transfers only a fixed-dimensional source-domain user representation from a pretrained SASRec encoder: a LayerNorm+MLP fusing layer projects it into the target item-embedding space and adds it element-wise to every target item embedding before the target SASRec encoder, and the fusion step is simply skipped for users without source history, who still benefit from the jointly trained target encoder. Training follows a vertical federated learning protocol in which the target loss gradient w.r.t. the transferred embedding is sent back to fine-tune the source encoder, so raw sequences and item IDs never leave their domain; large catalogs use the Scalable Cross-Entropy loss. On Amazon Food-Kitchen, Beauty-Electronics and Movie-Book, FLADRec beats all disjoint-data baselines (CD-SASRec, FedDCSR, CD-ASR) on nearly every metric (Kitchen NDCG@10 0.1926 vs 0.1107) and stays competitive with pooled-data ABXI while training 3.7-11.6x faster; under full-catalog ranking, strict temporal splits and 50% user overlap on TenRec and Zvuk&MegaMarket it improves NDCG@10 by +24.1% and +7.4% over SASRec, and ablations show a frozen source encoder or random injected embeddings lose most of the gain.
