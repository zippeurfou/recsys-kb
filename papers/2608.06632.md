## Summary

An LLM-based Agentic System for Conversational Recommendation":

1.  Current industrial recommendation systems primarily rely on passive ranking using implicit user behavior data (like clicks), failing to effectively capture and utilize explicit user intent expressed through natural language.
2.  To bridge this gap, Shape Your Feed (SYF) introduces an agentic system powered by Large Language Models (LLMs). It features a three-tier architecture: capturing fine-grained intent, re-ranking content in real-time based on evolving Semantic Profiles, and learning from human feedback.
3.  Offline tests show high accuracy for SYF's alignment scoring module compared to baselines, while large-scale online A/B tests confirm it improves feed relevance significantly and enhances user sentiment towards the service.

## Technical note

Meta's Shape Your Feed (SYF) layers an LLM agent on top of a passive production feed ranker so users can steer it in real time with text, voice, or UI feedback pills. Three flows: a Perception Flow that parses multi-modal interactions into a persistent semi-structured Semantic Profile S_t via intent detection and preference synthesis (de-duplication, strengthening, conflict resolution, semantic expansion) plus asynchronous candidate sourcing into a Candidate Cache; a Serving Flow that verbalizes item features into a prompt, list-wise scores the augmented candidate pool in one inference step, hard-prunes anything below threshold tau, and re-ranks with s_final = alpha * y_hat(v|S_t) + (1-alpha) * y_hat(u,v); and a Self-Evolution Flow that SFTs a Llama3-8B alignment scorer on LLM-judge labels (Llama 4 Maverick / Qwen3-VL-235B ensemble, 96% agreement with humans) then applies DPO on real user actions. Offline, the scorer goes from 83.84% accuracy / 53.00 F1 (few-shot Llama3-8B, 650ms) to 98.21%/76.97 (SFT, 325ms) to 98.85%/79.51 (SFT+DPO, 323ms), and 95.8% accuracy on a 1,029-sample human golden set; production P(Show Less)/P(Show More) signals fail to separate profile-matched from mismatched content (P90 0.208 vs 0.199) where the LLM scorer reaches 0.794/0.994. Online A/B on US/Canada 18+ traffic over several months: post dismiss -1.70%, post dislike -2.74%, new-interest consumption +0.16%, with context-aware pills capturing 76.02% of feedback interactions; an ablation shows pills alone drive +3.30% UI clicks but no significant feed-quality gain, so the serving flow supplies the actual improvement. Overhead is +0.043% critical-path and +0.412% direct-tier latency.
