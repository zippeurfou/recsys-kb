## Summary

Generative recommendation using semantic IDs (SIDs) shows promise but relies on slow, sequential autoregressive modeling for item prediction. To address this inefficiency, the authors propose using masked diffusion, which models the sequence distribution by learning to fill in masked SIDs given unmasked ones, enabling parallel decoding. Experiments demonstrate that this masked diffusion approach significantly outperforms the autoregressive baseline, especially in data-limited scenarios, and allows for faster inference by generating multiple items simultaneously.

## Technical note

MaskGR replaces the standard autoregressive decoder in generative recommendation with semantic IDs by modeling the user's SID sequence with masked diffusion, which corrupts tokens with masking noise and reconstructs them, treating masked tokens as conditionally independent to enable parallel decoding. This yields exponentially more training targets per sequence and better captures global item relationships than next-token prediction. Across sequential-recommendation benchmarks MaskGR consistently beats the autoregressive TIGER baseline, with the largest gains on coarse-grained recall and in data-constrained settings, while allowing an inference speed/quality tradeoff by choosing the number of denoising steps; it is also compatible with dense-retrieval fusion.
