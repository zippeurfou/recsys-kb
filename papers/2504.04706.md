## Summary

1.  Existing Knowledge Tracing models perform poorly due to two main issues: their single-step training doesn't match the multi-step inference process of real tutoring systems (causing error accumulation), and they suffer from data sparsity problems, especially affecting recommendation accuracy.
2.  To address these challenges, researchers propose AdvKT, a novel adversarial multi-step training framework specifically designed for Knowledge Tracing tasks that require multiple steps in simulation.
3.  AdvKT uses an adversarial learning approach (generator mimics good responses to reduce error, discriminator provides feedback) combined with specialized data augmentation techniques to effectively mitigate both error accumulation and sparse data problems across the multi-step process, validated by superior performance on real-world datasets compared to existing methods.

## Technical note

AdvKT is an adversarial multi-step training framework for knowledge tracing (KT), motivated by the mismatch between conventional single-step KT training (assuming ground-truth response history) and the multi-step inference required when KT models act as student simulators, which causes error accumulation over recommended question sequences. It uses a generator-discriminator adversarial setup where the generator mimics high-reward student responses to reduce compounding error across steps and the discriminator provides feedback to produce synthetic data, formalizing the multi-step KT task for the first time. Specialized data-augmentation techniques enrich sparse tutoring data with realistic variations to improve generalization. Experiments on four real-world datasets show AdvKT achieves state-of-the-art performance under multi-step inference while alleviating data sparsity.
