## Technical note

GSID (Generative Semantic InDexing, Alibaba) generates data-driven structured product representations for C2C second-hand e-commerce, replacing manually-curated Category-Property-Values that poorly cover long-tail products. Built on GenRet document tokenization with a T5 encoder-decoder, it does domain-adaptive pretraining on unstructured product metadata then progressively generates hierarchical semantic IDs guided by user search queries. GSID lifts cluster coverage from 23.02% (CPV) to 78.81% at comparable accuracy (~97%), and improves downstream search and recommendation, deployed on a real-world platform.
