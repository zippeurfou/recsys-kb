## Summary

Current image-based e-commerce AI assistants often struggle because single images can trigger diverse user intents (like search or recommendations), each requiring specific responses and knowledge that large language models (LLMs) cannot adequately distinguish without tailored constraints.

To solve this, researchers introduced SkillChain, an automated framework managing skill evolution by addressing three key stages: creating the initial skill from specifications, optimizing intent routing to ensure correct skill activation, and iteratively refining a skill's response format using dual LLM evaluations based on user trajectories.

SkillChain was deployed effectively in production; it significantly improved overall AI performance concerning structural compliance and content quality metrics, as validated by extensive A/B testing over a week showing substantial boosts in user engagement, consumption time, and long-term retention.

## Technical note

SkillChain automates the lifecycle of declarative per-intent 'Skills' for a production e-commerce image assistant where one uploaded image may trigger product search, style recommendation, encyclopedia lookup, or tool calls. It has three stages: a Skill Creator that bootstraps Skills from task specs and user trajectories, a Route Optimizer that mines routing failures to align intent-to-specification mappings under distribution shift, and a Body Refiner that iteratively refines Skill bodies via dual-path LLM-Judge evaluation. This closes the production feedback loop against specification decay, routing drift, and missing per-intent behavioral constraints. Deployment improves aggregate response quality (strongest on structural compliance and content quality), and a one-week online A/B test shows significant gains in engagement, content consumption, and long-term retention.
