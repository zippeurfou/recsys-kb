## Summary

This paper introduces the "Individual Turing Test," using a decade-long personal dataset to evaluate how well Large Language Models (LLMs) can simulate a specific individual. It systematically compares various LLM simulation methods, including fine-tuning, retrieval-augmented generation (RAG), and memory-based approaches, finding that current techniques fail to fool acquaintances but perform better on strangers. The study reveals a fundamental trade-off, showing that fine-tuning excels in simulating daily conversation style, while RAG and memory methods are superior for questions requiring personal opinions and preferences.

## Technical note

The paper proposes an 'Individual Turing Test' using a decade-long personal dataset to measure how faithfully LLMs can simulate a specific individual. It systematically compares fine-tuning (including LoRA), retrieval-augmented generation, and memory-based approaches under both acquaintance and stranger judges. Current methods fail to fool acquaintances but pass more often with strangers. A key finding is a trade-off: fine-tuning best reproduces daily conversational style, while RAG and memory methods better answer questions requiring personal opinions and preferences.
