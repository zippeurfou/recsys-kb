## Summary

This paper introduces LoRA-generating hypernetworks to personalize large language models (LLMs) running directly on mobile devices. The core idea is to train a hypernetwork that maps user-specific context tokens to a tailored LoRA (low-rank adaptation) module, which is then synthesized on the user's device based on their input. This approach offers efficient on-device personalization by requiring only forward passes for the user-specific LoRA generation and leveraging the base LLM's weights, combining benefits of both in-context learning (ICL) and parameter-efficient fine-tuning (PEFT). It is shown to be particularly effective for mobile constraints, outperforming baselines on challenging long-form text generation tasks while avoiding the downsides of extending input sequences typical of ICL and offering less storage overhead than PEFT.

## Technical note

On-device LLMs are compute-limited but used in predictable per-user patterns, so personalization is high-value. The paper trains a hypernetwork that maps a user's context tokens to a user-specific LoRA; after the shared artifacts ship to devices, each device synthesizes its personalized LoRA with forward passes only (like ICL, unlike PEFT) while changing weights rather than lengthening the prompt (like PEFT, unlike ICL, avoiding added latency), and the hypernetwork partly reuses the target LLM's own weights to minimize storage. Hypernetwork training is envisioned via federated learning with trusted execution environments, optionally with differential privacy. On long-form personalization tasks (LongLaMP-3 Amazon review writing, LongLaMP-4 Reddit post writing, LaMP-5 scholarly titles) it equals or surpasses ICL and PEFT baselines; the authors caution that out-of-distribution users are better served by fine-tuning.
