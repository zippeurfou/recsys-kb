## Summary

Recommender systems often need to balance maximizing a primary goal while ensuring secondary "guardrails" meet minimum thresholds, especially during system changes. Maintaining these guardrails automatically without extensive manual hyperparameter tuning has been challenging. The ACT framework addresses this by using offline analysis on unbiased data to find minimal hyperparameter adjustments required and then continuously retraining to adapt those settings over time.

This summary captures the core problem (balancing primary/secondary objectives), the gap in current methods (lack of automated constraint handling), and describes the proposed solution (ACT) along with its key mechanisms.

## Technical note

ACT (Automated Constraint Targeting) automatically finds the minimal set of ranking-formula hyperparameter changes needed to keep secondary 'guardrail' metrics above thresholds while maximizing a primary objective. It casts the task as minimizing the L2 norm of weights subject to secondary-metric constraints, solved via a grouped grid search with block coordinate descent, using an unbiased pairwise offline estimator built from randomized item-pair data. It retrains recurrently to adapt to system and user-behavior changes and sets weights to zero when guardrails are already met. Deployed at YouTube, ACT counteracts metric drops (e.g. -13.4% to -2.25%) and its offline estimator correlates with online movements at Pearson 0.82.
