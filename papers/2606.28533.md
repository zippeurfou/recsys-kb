## Summary

Constructive Multi-Sequence Learning for Recommendation Systems":

Current recommendation systems using single, long user sequences often struggle with context pollution, as unrelated past behaviors dilute attention and hinder identifying meaningful patterns. The authors argue that user histories are inherently multi-faceted but lack coherence like a single sentence in language models (LLMs). To address this limitation, they propose CMSL, which actively decomposes the user's history into multiple coherent latent sequences before applying linear attention to model them more effectively for recommendations.

## Technical note

CMSL (Constructive Multi-Sequence Learning), deployed across four surfaces at Meta, targets 'context pollution' in sequential recommenders, where a single monolithic user-history sequence forces unrelated intents to compete for the same self-attention budget and dilutes high-intent signal. Instead of ingesting one chronological sequence, a learnable Sequence Construction Module uses cross-attention (with intent-disentangled non-sequence features as keys/values and the history as query) to build K coherent latent sequences that are each self-attended separately, then summarized via Pooling-by-Multi-head-Attention (PMA) and compressed to avoid sequence-count explosion across layers. To scale, it uses a linear-time attention that approximates Meta's HSTU SiLU attention via a degree-2 polynomial kernel plus a sparse large-entry kernel. On ranking it improves Normalized Entropy by 0.3-0.6% (e.g., -0.62% eval NE on Comment, where >0.03% is significant), the two-stage user-model variant adds -0.06 to -0.13% NE on three more surfaces, and U2U retrieval A/B lifts four engagement metrics by +0.09% to +0.17%.
