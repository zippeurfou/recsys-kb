## Summary

Current recommendation models often treat user history as a single coherent sequence, leading to "context pollution" where unrelated behaviors dilute relevant signals and limit effectiveness. This limitation arises because user histories are inherently multi-faceted with weaker coherence than assumed by standard sequence modeling techniques. The authors propose CMSL (Constructive Multi-Sequence Learning), which actively disentangles user history into multiple pure thematic sequences using a learnable module, allowing more efficient context modeling via linear attention and demonstrating practical deployment success at Meta.

## Technical note

CMSL (Constructive Multi-Sequence Learning), deployed across four surfaces at Meta, argues single-sequence transformer recommenders suffer 'context pollution' where unrelated behaviors dilute attention. A learnable Sequence Construction Module disentangles user history into multiple 'pure' thematic strands, then a linear attention mechanism models them efficiently at scale. Trained on 30-50B examples on 128 H100s; evaluated via Normalized Entropy for ranking and online A/B for retrieval, showing gains over monolithic-sequence baselines for both CTR/CVR ranking and retrieval.
