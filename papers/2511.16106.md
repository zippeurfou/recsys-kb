## Summary

This paper enhances the ColBERT retrieval model, which uses multi-vector document representations and computes query-document similarity via a Chamfer distance based on token-level interactions. The key improvement involves weighting the token contributions in the Chamfer distance calculation using token importance scores (specifically, IDF weights). This simple modification, requiring only token-weight training while keeping document vectors fixed, improves retrieval performance, achieving significant gains in Recall@10 on the BEIR benchmark through both zero-shot and few-shot settings.

## Technical note

The paper improves ColBERT-style late-interaction multi-vector retrieval by generalizing the Chamfer/MaxSim aggregation into a Weighted Chamfer distance that scales each query token's contribution by a learned token-importance weight, analogous to BM25 term weighting. Weights are set either zero-shot from corpus IDF statistics or few-shot by training only the token weights (document vectors frozen) with an iterative hard-negative contrastive loss shown to be convex. On BEIR re-ranking it improves Recall@10 by an average 1.28% (IDF, zero-shot) and 3.66% (few-shot), adding negligible inference latency. They also provide sample-complexity and VC-based generalization bounds for learning the weights.
