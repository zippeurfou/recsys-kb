## Summary

This paper introduces ABot-N0, a unified Vision-Language-Action (VLA) foundation model designed for versatile embodied navigation, consolidating performance across five different task types. Utilizing a hierarchical Brain-Action architecture with LLM reasoning and Flow Matching for actions, ABot-N0 is trained on massive datasets (16.9M trajectories, 5.0M reasoning samples) to achieve state-of-the-art results across benchmarks. The paper also presents an agentic navigation system built on ABot-N0, enabling robust long-horizon missions in dynamic environments.

## Technical note

ABot-N0 is a unified Vision-Language-Action foundation model that handles five navigation tasks (Point-Goal, Object-Goal, Instruction-Following, POI-Goal, Person-Following) in a single hierarchical Brain-Action architecture. An LLM-based Cognitive Brain performs semantic and spatial reasoning while a Flow Matching Action Expert generates continuous multi-modal trajectory distributions, fed by a universal multi-modal encoder that unifies RGB views, geometric goals, and text goals as tokens. Training uses a data engine of 16.9M expert trajectories and 5.0M reasoning samples across 7,802 3D scenes. An agentic layer adds chain-of-thought planning and hierarchical topological Map-as-Memory, deployed on a Unitree Go2 with 2Hz VLA inference and 10Hz control.
