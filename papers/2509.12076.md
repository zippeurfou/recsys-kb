## Summary

This paper introduces **Adaptive Early Feature Selection (AEFS)**, which aims to combine the benefits of early feature selection with the adaptability of late feature selection for Deep Recommender Systems. The main issue addressed is that current adaptive late feature selection methods are inefficient due to a massive embedding layer created by considering all ID-type features.

AEFS achieves this through a **dual-model architecture**: an auxiliary model selects relevant features per instance, guiding a simpler main prediction model. It incorporates two collaborative training loss constraints between the models for effective alignment and uses the feature selections from the auxiliary model directly in the embedding layer activation of the main model.

Extensive experiments show that AEFS effectively reduces the number of activated parameters by 37.5% compared to baseline early selection, while matching the performance level of existing adaptive late feature selection methods on benchmark datasets.

## Technical note

AEFS proposes adaptive early feature selection for deep recommender systems, combining the accuracy of late (post-embedding) adaptive selection with the parameter efficiency of early (pre-embedding) selection. A small auxiliary model (mini-AdaFS/mini-MvFS with a much smaller embedding size) computes per-instance feature importance and selects the top-k feature fields before the main model's embedding lookup. Two collaborative training losses (embedding alignment and prediction alignment, akin to distillation) align the auxiliary and main models. On Avazu, Criteo, and KDD12 it matches state-of-the-art adaptive late selection (AdaFS/MvFS) with no significant AUC difference while cutting activated embedding-layer parameters by 37.5%.
