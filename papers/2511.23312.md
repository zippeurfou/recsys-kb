## Summary

This paper addresses the challenge of evaluating recommender systems using Cranfield-style methods, which traditionally require expensive manual relevance judgments. It investigates whether Large Language Models (LLMs) can serve as reliable automatic "judges" for this purpose. The study finds that LLM-judges achieve high agreement (Kendall's tau = 0.87) with human relevance labels when provided with richer item metadata and longer user histories, demonstrating a viable and scalable approach for recommender system evaluation, validated through an industrial case study.

## Technical note

The paper studies whether LLMs can replace costly manual relevance judgments in Cranfield-style offline evaluation of recommender systems, using the ML-32M-ext movie collection and GPT-5 as judge. It shows that adding richer item metadata and longer user histories raises alignment with human labels, and that LLM-judge rankings of 22 RecBole models reach Kendall's tau = 0.87 with human-derived rankings. An industrial podcast case study confirms LLM-judge is useful for pre-A/B model selection, offering a scalable alternative to interaction-log splits that suffer from low judged-item coverage and unreliable rankings.
