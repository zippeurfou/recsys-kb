## Summary

This paper introduces LIGE-GR, a generative recommendation framework inspired by Large Language Models (LLMs), specifically designed for listwise generation and evaluation. It tackles the challenge of integrating generative capabilities into mature, complex recommendation systems by generalizing the existing pointwise system rather than replacing it entirely. Validation on Instagram Reels and Facebook Video shows that LIGE-GR improves user engagement slightly while adding only modest computational overhead.

## Technical note

Rather than rebuilding mature itemwise ranking stacks, LIGE-GR (listwise generation and evaluation) generalizes an existing pointwise recommender into a listwise generative one: a context-aware module sits on top of existing ranking models, the itemwise value model is upgraded to a listwise value model, and itemwise greedy decoding is replaced by an RL-based sequential decoder, preserving compatibility with existing models, value functions, serving infrastructure and team ownership. On Instagram Reels and Facebook Video the base configuration improves time spent by +1.14% and +0.72% (p<0.001), sessions +0.11%/+0.07%, likes/reactions +2.65%/+1.59% and reshares +1.77%/+0.99%, with modest additional inference cost. Wider beam decoding (b=6) adds further likes and reshares gains on Reels.
