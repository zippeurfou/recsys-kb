## Summary

The paper identifies a fundamental gap in recommendation systems where tokenizers for generating recommendations are trained separately from ranking models, preventing effective personalization. It proposes DIG, which embeds the tokenizer within a discriminative ranking model for end-to-end training, effectively making the ranker a retrieval model. DIG uses a feature assignment taxonomy and distillation to unify ranking and retrieval objectives, improving both ranking performance and retrieval quality on various datasets.

## Technical note

DIG (Discrimination Is Generation) argues generative retrieval lags discriminative ranking because Semantic ID tokenizers are trained independently with retrieval objectives, so user-item cross features never shape codebook construction and each item gets the same SID regardless of user match. It reframes ranking (argmax in item space) and retrieval (argmax in token space) as the same problem at different granularities and embeds the tokenizer inside a discriminative ranker for end-to-end joint training, yielding both models from one run. Organized around a feature-assignment taxonomy: item-intrinsic static features are quantized (via balanced K-Means VQ) into SIDs, u2i cross features implicitly push codebook boundaries toward decision boundaries, and an MLP u2t distillation module approximates u2i at token level for inference. On three public and two industrial datasets DIG improves recall, ranking AUC, and unified quality.
