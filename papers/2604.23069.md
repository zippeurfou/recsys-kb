## Summary

Selective and Dependency-Structured Memory Construction for LLM Agents":

1.  LLM agents often struggle with long interactions due to poor context management, as existing methods like sliding windows or simple retrieval miss crucial dependencies needed for multi-step reasoning.
2.  ContextWeaver addresses this by structuring the interaction history into a graph of reasoning steps, linking each step to its dependencies, summarizing paths compactly, and incorporating execution feedback, all to provide a more stable and efficient memory mechanism.
3.  This approach improves agent performance (e.g., higher pass@1 success rate) while reducing reasoning steps and token usage, demonstrating its scalability for LLM agents using tools.

## Technical note

ContextWeaver is a selective, dependency-structured memory framework for tool-using LLM agents that preserves causal and logical structure lost by sliding-window, prompt-compression, and similarity-based retrieval approaches. It converts each reasoning step into a graph node storing action/observation summaries and links it to the earlier steps it depends on, forming a dependency graph reflecting reasoning flow rather than recency. A Dependency Summarizer condenses root-to-step paths into compact reusable units, and a lightweight Validation Layer annotates nodes with execution-outcome reliability signals to filter unreliable ones. The weaved context includes only validated nodes and their supporting dependencies under strict token budgets. On SWE-Bench Verified and Lite it improves pass@1 over a sliding-window baseline while reducing reasoning steps and token usage.
