## Summary

This paper introduces **CollabBench**, a new benchmark designed specifically to evaluate and train large language model (LLM) agents' collaborative abilities within realistic cooperative game environments.

To address this, CollabBench features a pipeline simulating diverse human player profiles and uses a unique training paradigm called Collaborative Agentic Training. This involves unifying reasoning, communication, and action using agentic rollouts optimized with hybrid rewards focusing on task efficiency and affective adaptation.

Experiments show that models trained using this new framework significantly outperform base LLMs, demonstrating higher task completion efficiency (19.5%) and better emotional/affective interaction performance (+24.4%). The study also identifies key limitations in existing collaborative methods.

## Technical note

CollabBench benchmarks and trains LLM agents for grounded collaboration in cooperative game environments (extended to CWAH-MultiPlayer and Cook-MultiPlayer). It contributes a Diverse Player Profile Simulation pipeline that models varied partner personalities and a Collaborative Agentic Training paradigm that unifies reasoning, communication, and action via agentic rollouts optimized with a hybrid reward balancing task efficiency and affective adaptation. Trained models beat base LLMs by 19.5% on efficiency and 24.4% on affective performance. Evaluation surfaces collaborative limitations of existing models; the work concerns multi-agent/RL collaboration rather than recommender systems.
