## Summary

Large-scale recommendation systems often use Approximate Nearest Neighbor (ANN) search for retrieval, but this method suffers from suboptimal performance for new items and high computational cost per query. To address these limitations, the authors introduce the MultiFaceted Learnable Index (MFLI), a unified system that co-trains item embeddings and hierarchical indices in real-time, eliminating the need for expensive ANN searches at query time. Extensive experiments on real-world data and subsequent production deployment demonstrate that MFLI significantly improves retrieval quality (recall and relevance), reduces popularity bias, and enhances serving efficiency compared to existing state-of-the-art methods.

## Technical note

MFLI (MultiFaceted Learnable Index) is a retrieval paradigm that replaces ANN search at serving time by co-training item embeddings with a multifaceted hierarchical codebook built via residual quantization, mapping each item to multiple sub-codebooks in parallel. It addresses two ANN limitations: staleness from decoupled offline indexing (hurting new items) and per-query compute cost at billion scale. System contributions include index-balancing with a split-and-merge procedure to keep cluster sizes bounded, a compact unified multifaceted-index storage for fast lookup, and a delta-update pipeline (main stream syncing all items periodically, fast stream indexing fresh items in real time). On real-world data with billions of users, MFLI improves engagement recall by up to 11.8%, cold-content delivery by up to 57.29%, and semantic relevance by 13.5%, and online deployment reduces popularity bias while improving serving efficiency.
