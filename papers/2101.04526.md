## Summary

This paper introduces a simulation framework to measure recommender system effects by isolating the system's influence from user preferences. The framework allows evaluating system performance over time and identifying extreme user experiences caused by biases like popularity. Two case studies demonstrate how these biases manifest through repeated recommendations, showing their long-term impact.

## Technical note

This paper proposes a simulation framework to measure a recommender system's longitudinal impact on users, disentangling effects caused by the system from those driven by user preferences over repeated interactions. It designs a set of simple, deliberately atypical test users to probe both average and extreme experiences, plus evaluation metrics over the simulated trajectories. As case studies it examines popularity bias in a matrix-factorization recommender trained on MovieLens and in a large-scale production system, showing how popularity bias is reinforced over time. The framework is positioned as complementary to observational metrics, enabling auditing of rare but harmful outcomes and isolating the recommender's own contribution.
