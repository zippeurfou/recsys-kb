## Technical note

This eBay work builds a data pipeline that mines large-scale buyer query logs to extract fine-grained intent signals from explicit interactions and implicit behavioral cues, using sequence mining and supervised learning to construct an intent-rich dataset for adaptive query reformulation. It operationalizes queries into canonical intent classes (transactional, navigational, informational) and defines three intent-aligned transformation types (Same, Similar, Inspired Intent) derived from in-session and cross-session query trajectories, grounding rewrites in inferred intent rather than lexical signals. Applications include recall enhancement in low-inventory/cold-start cases, related-search query recommendation, and bottom-of-SRP item recommendations, with empirical gains in precision-oriented relevance metrics across verticals.
