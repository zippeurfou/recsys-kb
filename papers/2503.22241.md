## Summary

(Abstract fallback)

Personalized multiple clustering aims to generate diverse partitions of a dataset based on different user-specific aspects, rather than a single clustering. It has recently drawn research interest for accommodating varying user preferences. Recent approaches primarily use CLIP embeddings with proxy learning to extract representations biased toward user clustering preferences. However, CLIP primarily focuses on coarse image-text alignment, lacking a deep contextual understanding of user interests...

## Technical note

This paper proposes an agent-centric framework for personalized multiple clustering that uses multi-modal LLMs (MLLMs) as agents to traverse a relational graph and form clusters aligned with user-specified interests, overcoming CLIP's coarse image-text alignment. MLLMs generate user-interest-biased image embeddings whose similarities define a weighted graph; weak edges are pruned to shorten agent traversal, agents grow clusters from highest-degree nodes, and a global review agent merges redundant clusters. It is the first multiple-clustering method built on MLLMs, achieving NMI scores of 0.9667 and 0.9481 on the Card Order and Card Suits benchmarks, over 140% above the prior state of the art.
