## Summary

This paper introduces Memory Grafting, a method to scale language model pre-training using external conditional memory, addressing the high cost of training large memory tables in methods like Engram. Memory Grafting pre-fills memory by running a pretrained "grafting model" offline to store final hidden states, which the recipient model then retrieves via lookup and adapts using lightweight gates and projections. Experiments show Memory Grafting improves performance over MoE and Engram baselines significantly across different model scales, demonstrating that pretrained models can serve as reusable constructors of external latent memory for efficient scaling.

## Technical note

Memory Grafting is a conditional-memory scaling method for language models that reuses frozen hidden states from a separate 'grafting' model as conditional n-gram memory instead of learning a large memory table from scratch (as in Engram). Frequent local n-grams are run through the grafting model offline, final-token hidden representations are stored as memory values, and the recipient retrieves them via exact longest-match suffix lookup with expected O(1) cost, using a hash-based Engram fallback for unmatched contexts. Retrieved memories are adapted with lightweight projections and gates. At 2.8B scale it raises average benchmark score to 53.86 versus 51.95 (MoE) and 52.43 (vanilla Engram). This is an LLM-architecture paper, not a recommendation paper.
