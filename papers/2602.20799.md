## Summary

LLMs struggle with newly released software frameworks due to insufficient exposure during training, leading to hallucinations and poor reasoning. Existing data synthesis methods for unseen codebases are inadequate as they lack sufficient high-quality usage data derived from source code alone. To address this, the paper introduces UCD-Training, a two-stage framework that builds a code graph from unseen codebases and uses dependency-preserving pretraining and supervised fine-tuning on synthesized data with explicit reasoning traces, validated on a new benchmark called UnseenCodeBench.

## Technical note

UCD-Training is a two-stage framework that injects unseen-codebase knowledge into code LLMs via reasoning-aware data synthesis grounded in a code graph parsed from source (files, classes, functions, methods, globals as nodes; call/include/dependency relations as edges). Stage one, dependency-preserving continued pretraining (CPT), performs DFS traversal over the file-level dependency DAG so truly dependent files co-occur within context windows via sliding-window truncation, mixed with general-domain data. Stage two, graph-grounded SFT, synthesizes three data types-single-hop relation reasoning, compositional API reasoning from internal test cases, and codebase-utilization tasks-each augmented with LLM-generated reasoning traces via rejection sampling against ground-truth context and two-stage LLM/rule-based (tree-sitter) filtering. It also introduces UnseenCodeBench (C++/Python) evaluated with compilation@k and pass@k; UCD-Training beats RAG and OSS-Instruct/COTTON baselines, with an 8B model exceeding RAG SOTA and scaling across languages, sizes, and model families.
