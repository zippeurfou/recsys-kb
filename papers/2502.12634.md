Lifelong sequential modeling (LSM) is becoming increasingly critical in social media recommendation systems for predicting the click-through rate (CTR) of items presented to users. Central to this process is the attention mechanism, which extracts interest representations with respect to candidate items from the user sequence. ## Technical note

CAIN (Context-Aware Interest Network) improves lifelong sequential CTR prediction by making attention context-aware rather than point-wise. It uses a Temporal Convolutional Network to build context-aware item representations from the lifelong sequence, a Multi-Scope Interest Aggregator (multiple TCN layers + attention) to capture interests across context scopes, and a Personalized Extractor Generation module that generates per-user convolution filters from profile features. On a public dataset and an industrial WeChat Channels dataset, CAIN outperforms existing methods in offline accuracy and online metrics.
