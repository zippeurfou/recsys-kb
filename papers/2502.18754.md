## Summary

The AgentSociety Challenge introduced an international competition focused on using LLM agents for user modeling and recommendation system enhancement. Teams competed in two tracks, analyzing data from Yelp, Amazon, and Goodreads within an interactive simulation environment. The challenge achieved significant results with 295 teams submitting over 1400 entries, demonstrating notable performance improvements across both tracks while providing open-source benchmark tools.

## Technical note

This paper describes the AgentSociety Challenge, the first Web Conference competition on using LLM agents for user behavior modeling and recommendation, with a User Modeling Track (simulate reviews and star ratings) and a Recommendation Track (personalized ranking). Participants build agents over a combined Yelp/Amazon/Goodreads dataset and an InteractionTool simulator that controls retrieval actions, evaluated by MAE and review-quality metrics for Track 1 and top-N hit rate for Track 2, using mixed simulated and real ground truth to prevent overfitting. The challenge drew 295 teams and 1,400+ submissions, with winning agents improving performance by up to ~21.9% and 20.3% in development and 9.1%/15.9% in the final phase. Notably, agent-based recommenders generally outperformed traditional deep models like NCF, and the benchmark environment is open-sourced.
