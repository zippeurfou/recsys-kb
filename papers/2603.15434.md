## Summary

Current dialogue systems often rely on simple, sparse scalar rewards, which fail to explain failures or adapt to users effectively. This paper introduces RAPO, a framework that optimizes based on user reactions during dialogue, treating it as a reaction-driven process. RAPO uses three components to generate dense feedback from user interactions, enabling fine-grained improvement, and significantly outperforms standard RL methods on dialogue benchmarks.

## Technical note

RAPO optimizes emotional-support dialogue agents over simulated user reactions rather than static expert rubric scores, addressing scalar-reward sparsity and 'hallucinated empathy'. It has three components: Hindsight Dialogue Selection (GPT-4o filters pivotal turns), Generative Hindsight Feedback (a user simulator plus a generative reward model produce group-wise contrastive rankings and natural-language critiques), and Scalar-Verbal Hybrid Policy Optimization coupling GRPO on ranking rewards with on-policy self-distillation of critique-conditioned predictions on the lowest-reward rollout. The final objective is J_GRPO minus a self-distillation loss using top-K logit distillation with stop-gradient teacher. On ESConv, EmoHarbor, ESC-Eval and Sotopia it outperforms GRPO/CPO/PPO baselines, with ablations confirming user-reaction modeling and verbal self-distillation contribute complementary signals.
