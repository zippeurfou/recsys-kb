## Summary

Recommender systems face issues like information cocoons due to how user interactions and content preferences are forced into a single vector space, making it hard to identify systemic biases. The paper introduces RecBundle, a novel geometric approach using differential geometry's fiber bundles, which decouples the system into two hierarchical layers: a base manifold for user interactions and fibers for dynamic preferences. This framework provides a more mechanistic way to understand and potentially mitigate problems like bias and information cocoons, with empirical validation on real datasets confirming its effectiveness.

## Technical note

RecBundle introduces fiber bundle theory as a geometric analysis paradigm for recommenders, decoupling the system into a base manifold of the user interaction graph and per-user fibers carrying dynamic preferences. Collaborative aggregation (e.g. GNN neighbor aggregation) is formalized as parallel transport with a learned connection, while long-term preference evolution over feedback loops is modeled as a holonomy transformation whose spectral contraction quantifies information-cocoon degradation via a proposed Geometric Bias Index. Connection curvature approximated from feature-alignment residuals explains GNN over-smoothing on tail users, and empirically BERT4Rec shows higher curvature than SASRec under sparse data. The paper is largely a theoretical framework validated on MovieLens and Amazon Beauty, proposing curvature/holonomy regularizers and a fiber-bundle fast-slow LLM reasoning architecture as future directions rather than a deployed system.
