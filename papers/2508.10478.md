## Technical note

Studies how to construct Semantic IDs that work well for both search and recommendation within a single unified generative model. Comparing task-specific vs cross-task embedding sources and shared vs task-specific ID tokens, it finds a fundamental trade-off: embeddings fine-tuned for one task degrade the other. The recommended solution is a bi-encoder fine-tuned jointly on both search and recommendation to produce item embeddings, from which a single unified Semantic ID space is built, giving strong performance on both tasks with minimal per-task loss. This challenges using task-specific embedding spaces as priors for ID generation in unified generative recommenders (Spotify).
