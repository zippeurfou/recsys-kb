## Summary

The paper investigates methods for representing items in a unified system using LLMs to handle both recommendation and search effectively. It finds that relying solely on task-specific embeddings hinders generalization across these related functions. The key solution involves combining fine-tuning on both tasks with cross-task embedding learning to create Semantic IDs, providing strong performance for both applications within a single model framework.

## Technical note

This paper studies how to construct Semantic IDs (discrete codes from item embeddings) that work well in a unified generative model serving both search and recommendation. It compares content-based, search-tuned, recommendation-tuned, and cross-task embedding sources, and whether tasks should share or separate ID tokens. The key finding is a fundamental trade-off: task-specific embeddings boost their own task but degrade the other, whereas a bi-encoder fine-tuned jointly on search and recommendation yields a unified Semantic ID space that generalizes across both with minimal per-task loss. This challenges the prevailing use of per-task ID spaces and argues for generalizable, semantically grounded ID schemes in unified generative recommenders.
