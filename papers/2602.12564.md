Large-scale industrial recommender systems commonly adopt multi-channel retrieval for candidate generation, combining direct user-to-item (U2I) retrieval with two-hop user-to-item-to-item (U2I2I) pipelines. In U2I2I, the system selects a small set of historical interactions as triggers to seed downstream item-to-item (I2I) retrieval across multiple channels. ## Technical note

CAPTS reframes multi-channel U2I2I trigger selection (choosing historical interactions as seeds for item-to-item retrieval) as a learnable routing problem, addressing biased value attribution and uncoordinated channel routing. A Value Attribution Module (VAM) provides look-ahead supervision by crediting each trigger with the downstream engagement generated by items it retrieves per I2I channel, while Channel-Adaptive Trigger Routing (CATR) coordinates trigger-to-channel assignment to maximize overall retrieval value and reduce cross-channel overlap. On Kwai (Kuaishou's international short-video platform), offline experiments improve multi-channel recall and online A/B tests deliver a +0.351% lift in average time spent per device.
