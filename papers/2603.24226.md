## Summary

Current scaling research for search systems often focuses solely on model architecture, ignoring the crucial interaction with data. This paper introduces UniScale, a co-design framework addressing this gap by jointly optimizing both data and model architecture for better performance and scalability. UniScale combines a data system (ES³) that expands training signals with a novel architecture (HHSFT) specifically designed to handle complex data distributions, demonstrating significant improvements and scaling benefits on real-world e-commerce search data.

## Technical note

UniScale is a co-design framework for e-commerce search ranking arguing that pure parameter scaling yields diminishing returns because of limited training-data information capacity, so data and architecture must scale jointly. ES3 (Entire-Space Sample System) expands the training set with intra-domain unexposed candidates via uniform sampling, a Hierarchical Label Attribution mechanism that propagates feedback to unexposed samples, and Cross-domain Sample Searchification that converts non-search interactions into schema-aligned pseudo-search samples to mitigate selection/exposure bias and negative transfer. HHSFT (Heterogeneous Hierarchical Sample Fusion Transformer) tokenizes features into semantic blocks with independent embeddings, fuses them via multi-head self-attention plus block-specific FFNs, and adds a Domain-Routed Expert Fusion layer with Domain-Aware Personalized Gated Attention to inject cross-domain interests. Deployed in Taobao Search with feature pre-hashing, kernel fusion, RDMA, and fp16, it lifted user purchase by 1.70% and GMV by 2.04%.
