## Technical note

DMQN addresses the relevance-distribution discrepancy in two-stage long-behavior CTR models (SIM/ETA/SDIM/TWIN) that first retrieve ~100 items then apply target attention. Instead it processes the full long behavior sequence end-to-end by quantizing it into ~100 learnable codewords via multiple independent codebooks (Gumbel-softmax assignment), uses HSTU to let codeword sequences interact, then applies cluster-aware target attention against the candidate. Codeword representations are candidate-agnostic and cached for low-latency serving. Meituan A/B test shows +3.5% CTR and +2.0% RPM.
