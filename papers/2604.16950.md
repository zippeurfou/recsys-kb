## Technical note

AutoPKG is a multi-agent LLM framework that builds and continually evolves a Product-attribute Knowledge Graph from multimodal listings, inducing product types and type-specific attribute keys on demand and extracting values from text and images. A centralized Knowledge Graph Decision agent (KGD) is the sole write interface, resolving upstream proposals via a constrained ADD/MERGE/REPLACE/DISCARD action space to keep a canonical graph. On a Lazada catalog it reaches 0.953 WKE for product types, 0.724 WKE for attribute keys, and 0.531 edge-level F1 for multimodal extraction; online A/B tests show GMV lifts in Badge (+3.81%), Search (+5.32%), and Recommendation (+7.89%).
