## Summary

This paper introduces OPSAI, an architecture designed to create transparent and accessible Open Player Models (OPMs) for Game-Based Learning (GBL). OPSAI decouples analytics from the game engine, automatically deriving insights from gameplay data to provide reflective prompts and recommendations. It features three layers (Frontend, Backend, Log Storage) and demonstrates how feeding analytics back into the game enhances the learning experience, validated through a deployment in the Parallel GBL environment.

## Technical note

OPSAI (Open Player Socially Analytical Intelligence) is a concrete architecture operationalizing transparent, real-time Open Player Models (OPMs) for Game-Based Learning beyond conceptual frameworks. It decouples gameplay telemetry and analytics from the game engine via three logical layers: a Frontend delivering the game experience and collecting instrumentation, a stateless Backend hosting transparent analytics services that produce reflective prompts, recommendations, and visualization guides, and a two-tier Log Storage balancing heavy raw gameplay data against lightweight reference indices for low-latency queries. By feeding analytics back into the game interface, it closes the play-learning feedback loop for teachers, researchers, and learners. The design is grounded in Self-Determination Theory and demonstrated with a full deployment on the Parallel GBL environment featuring live play traces, peer comparisons, and personalized suggestions.
