## Summary

The paper introduces Gated DeltaNet-2, a model for linear attention that tackles the challenge of efficiently managing a compressed memory state. It improves upon previous models (Gated DeltaNet and Kimi Delta Attention) by decoupling the erase and write operations, using separate channel-wise gates for each action rather than a single scalar gate. This innovation, combined with efficient computation techniques, results in better performance, especially on long-context tasks requiring multi-key retrieval.

## Technical note

Gated DeltaNet-2 is a linear-attention layer that decouples the erase and write operations of the delta rule, which prior models (Gated DeltaNet, Kimi Delta Attention) tie to a single scalar gate. It keeps KDA's channel-wise decay but adds a channel-wise erase gate on the key axis and a channel-wise write gate on the value axis, reducing to KDA when the two gates collapse to one scalar and to Gated DeltaNet when the decay also collapses. The authors derive a fast-weight update view and a chunkwise WY algorithm that absorbs cumulative channel-wise decay into asymmetric rank-one erase factors, plus a gate-aware backward pass preserving efficient parallel training. At 1.3B parameters on 100B FineWeb-Edu tokens it outperforms Mamba-2, Gated DeltaNet, KDA, and Mamba-3 variants, with the clearest gains on long-context RULER multi-key needle-in-a-haystack retrieval.
