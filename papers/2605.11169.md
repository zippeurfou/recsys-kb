## Summary

Large language model (LLM) agents used for sequential decision-making often accumulate errors during deployment due to suboptimal action selection. Existing inference-time adaptation methods (like prompting) lack explicit action adaptation and uncertainty estimates. The paper introduces OLIVIA, which models the LLM's action selection as a contextual linear bandit, allowing direct adaptation with uncertainty estimates and online learning from action feedback, leading to improved performance over existing baselines.

## Technical note

OLIVIA models the final action-selection layer of a frozen ReAct-style LLM agent as a contextual linear bandit over candidate actions, using last-layer hidden states as decision contexts. It uses upper-confidence-bound exploration to update action preferences online from step-level feedback without retraining the base model, modifying prompts, or storing retrieval memory. This provides an explicit, uncertainty-aware decision layer that adapts sample-efficiently across a stream of related tasks with low variance compared to policy-gradient or episodic updates. On four tool-use benchmarks it consistently improves over static ReAct and prompt-based inference-time adaptation baselines.
