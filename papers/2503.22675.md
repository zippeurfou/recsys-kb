## Summary

(Abstract fallback)

Sequential Recommendation (SeqRec) aims to predict the next item by capturing sequential patterns from users' historical interactions, playing a crucial role in many real-world recommender systems. However, existing approaches predominantly adopt a direct forward computation paradigm, where the final hidden state of the sequence encoder serves as the user representation. ## Technical note

ReaRec is the first inference-time computing framework for sequential recommendation, enhancing user representations via implicit multi-step latent reasoning. It autoregressively feeds the sequence encoder's last hidden state back in, using special reasoning position embeddings to separate item-encoding space from reasoning space, and proposes two learning strategies: Ensemble Reasoning Learning (ERL) and Progressive Reasoning Learning (PRL). Across five datasets and multiple SeqRec backbones (e.g., SASRec, UniSRec) it delivers ~7.49% average gains with only 3.51% extra latency, and post-hoc optimal-step analysis shows it raises backbone performance ceilings by roughly 30-50%, especially for long-tail users and unpopular items.
