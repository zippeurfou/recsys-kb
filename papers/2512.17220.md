## Summary

Current retrieval-augmented generation (RAG) systems struggle with understanding and reasoning over long texts because they lack a holistic semantic understanding of the entire document.

The paper introduces Mindscape-Aware RAG (MiA-RAG), which creates an explicit "mindscape" through hierarchical summarization to represent the global context.

MiA-RAG uses this mindscape to guide both the retrieval of relevant information and the generation process, enabling better evidence integration and coherent reasoning, outperforming existing baselines.

## Technical note

MiA-RAG (Mindscape-Aware RAG) addresses RAG's weakness on long-context tasks where systems retrieve and reason only on local, evidence-level signals and lack a holistic global view. It builds an explicit 'mindscape' via bottom-up hierarchical summarization and conditions both retrieval and generation on this global semantic representation: a specially trained embedding model (MiA-Emb) fuses the mindscape into query embeddings for selective retrieval, and the generator is conditioned on the same memory for integrative reasoning. Trained with silver-standard evidence alignments auto-extended from NarrativeQA, MiA-RAG outperforms baselines across English/Chinese long-context benchmarks, with a 14B variant surpassing a vanilla 72B system.
