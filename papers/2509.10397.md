## Summary

RecoWorld creates simulated environments specifically for training agentic recommendation systems to improve their performance without risking real users' experience.

These virtual worlds use a dual-view architecture where a simulated user interacts with the recommender agent over multiple turns, learning from feedback loops designed to maximize engagement and retention.

Leveraging large language models (LLMs), RecoWorld supports diverse content representations like text, multimodal, or semantic IDs and enables multi-agent simulations to test different user populations.

## Technical note

RecoWorld is a blueprint (no experiments) for building LLM-based simulated environments to train and evaluate agentic recommender systems without impacting real users. It uses a dual-view architecture where an LLM user simulator reviews recommended items, updates its mindset, and issues reflective instructions when about to disengage, while an agentic recommender adapts recommendations in a multi-turn loop optimizing long-term retention. It explores three engagement-history representations (text, multimodal, semantic ID), dynamic memory and evolving-preference modeling, and casts interaction as an MDP trained with PPO/DPO using trajectory-level rewards. It also supports multi-agent population simulation for creators and proposes a shared Gym-like leaderboard for agentic RecSys.
