## Summary

1.  Recommendation system performance relies heavily on training data quality, but using data from multiple auxiliary domains to address data scarcity often fails due to inherent domain differences causing poor performance.
2.  Existing complex, model-centric architectures struggle to effectively learn subtle sequence dependencies across these different domains.
3.  To overcome these limitations, the paper introduces Taesar, a data-centric framework using contrastive decoding to adaptively regenerate target-domain sequences, enabling standard models to capture complex dependencies without complex fusion architectures, and it demonstrates superior results.

## Technical note

Taesar is a data-centric framework for cross-domain sequential recommendation (CDSR) that regenerates mixed-domain interaction sequences into target-domain-only sequences before training, avoiding complex model-centric fusion architectures. It trains a base model on mixed sequences to capture transferable cross-domain patterns, then derives domain-specific expert models via a Domain-Specific Prediction strategy. Its Adaptive Contrastive Decoding contrasts predictions from the source expert, target expert, and base model to decide whether and how to replace each non-target item with a plausible target-domain item, using global and local contrastive scores with information-theoretic adaptive weights. Because it preserves item-ID structure and temporal order, the regenerated data plugs into standard sequential recommenders without architectural changes, mitigating negative transfer and data sparsity.
