## Technical note

Taesar (Huawei) is a data-centric framework for cross-domain sequential recommendation (CDSR) that, instead of complex model-level fusion architectures, regenerates mixed-domain sequences into target-domain-only sequences to eliminate the domain semantic gap before training and proactively mitigate negative transfer. It trains a base model on mixed sequences for global patterns, derives domain-specific expert models via a Domain-Specific Prediction strategy, then uses Adaptive Contrastive Decoding — contrasting source-expert, target-expert, and base-model predictions with information-theoretic adaptive weights — to decide whether/how to replace each non-target item with a plausible target-domain item while preserving temporal order and item-ID structure. Because output keeps the original ID structure, Taesar plugs into any sequential recommender without architectural changes and outperforms model-centric CDSR baselines across backbones.
