## Summary

Current billion-scale LLM recommendation systems are inefficient because they use an iterative "Text-to-Judgment" method that evaluates each user-item pair separately. This limits performance, especially during cold-start when few items have interaction data.

To overcome this, researchers propose FilterLLM and its novel "Text-to-Distribution" paradigm, which predicts the probability distribution of item interactions for a whole user set in one LLM inference pass.

FilterLLM achieves significant efficiency gains (over 30x) by using tailored distribution prediction and an efficient billion-scale user vocabulary structure, enabling effective cold-start recommendations at large scale on platforms like Alibaba.

## Technical note

FilterLLM tackles the computational bottleneck of LLM-based cold-start recommendation, where the prevailing Text-to-Judgment paradigm scores user-item pairs one at a time and must pre-filter to a few hundred candidates. It introduces a Text-to-Distribution paradigm that predicts an item's interaction probability distribution over the entire billion-scale user set in a single LLM forward pass, using an efficient user-vocabulary structure to represent, train, and store user embeddings by extending next-word prediction. Predicted distributions are then used to refine cold item embeddings, with tailored training objectives for distribution prediction and vocabulary construction. Deployed on Alibaba for two months over one billion cold items, FilterLLM outperforms state-of-the-art cold-start methods and achieves over 30x higher efficiency than ColdLLM, validated by online A/B tests.
