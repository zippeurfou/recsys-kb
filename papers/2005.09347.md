## Summary

Traditional sequential recommendation models often use a single user embedding, failing to capture a user's potentially diverse interests over time. This paper introduces ComiRec, a novel framework that explicitly models and extracts multiple distinct user interests from their behavior sequences. ComiRec then uses a controllable mechanism to balance recommendation accuracy and diversity when aggregating these interests into final item recommendations, significantly improving performance on real-world datasets and being successfully deployed.

## Technical note

ComiRec is a controllable multi-interest framework for sequential recommendation that argues a single user embedding cannot represent a user's simultaneous multiple interests. A multi-interest extraction module (implemented via either capsule-network dynamic routing or self-attention) produces several interest embeddings from a user's behavior sequence, each independently retrieving candidate items from a large-scale pool. An aggregation module then combines these candidates using a controllable factor that trades off recommendation accuracy against diversity to output the final top-N list. On the Amazon and Taobao datasets it significantly outperforms state-of-the-art sequential models, and it has been deployed on Alibaba's distributed cloud platform with billion-scale results confirming effectiveness and efficiency.
