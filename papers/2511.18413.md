## Summary

Traditional agentic recommendation systems often underuse user-item interaction data, leading to poor recommendations. To address this, the paper introduces the Multi-Agent Collaborative Filtering (MACF) framework, which treats users and items as specialized LLM agents. A central orchestrator manages dynamic collaboration between these agents, providing personalized instructions and recruiting relevant participants based on the target user's query. Experimental results across different domains demonstrate that MACF significantly outperforms existing agentic recommendation baselines.

## Technical note

MACF (Multi-Agent Collaborative Filtering) casts agentic recommendation as an analogy to collaborative filtering by instantiating similar users and query-relevant history items as LLM agents with profiles and retrieval tools. A central orchestrator agent performs dynamic agent recruitment and issues personalized collaboration instructions across multi-round discussions, aggregating candidates into a ranked list with a sufficiency test. On Amazon Clothing/Beauty/Music with a gpt-4o backbone and BGE-M3 embeddings, MACF beats retrieval, CF, and agentic baselines (e.g., ReAct, TAIRA) on HitRatio@10 and NDCG@10. Ablations confirm personalized collaboration instruction, dynamic agent recruitment, and adaptive tool use each contribute.
