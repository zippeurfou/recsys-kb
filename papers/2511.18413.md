## Summary

(Abstract fallback)

Agentic recommendations cast recommenders as large language model (LLM) agents that can plan, reason, use tools, and interact with users of varying preferences in web applications. However, most existing agentic recommender systems focus on generic single-agent plan-execute workflows or multi-agent task decomposition pipelines. Without recommendation-oriented design, they often underuse the collaborative signals in the user-item interaction history, leading to unsatisfying recommendation results...

## Technical note

MACF (Multi-Agent Collaborative Filtering, Adobe) casts agentic recommendation as an analogy to classic collaborative filtering: given a target user and query, it instantiates similar users and relevant items as LLM agents with unique profiles that call retrieval tools, suggest candidates, and message each other. Unlike static preference aggregation in traditional CF, a central orchestrator agent adaptively manages collaboration via dynamic agent recruitment and personalized collaboration instructions across multi-round discussion. Experiments on datasets from three domains show MACF outperforms strong agentic recommendation baselines by better exploiting neighborhood collaborative signals.
