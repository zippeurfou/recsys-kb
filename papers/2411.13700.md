## Summary

This paper addresses limitations in scaling recommendation models for CTR prediction by proposing Collaborative Ensemble Training Network (CETNet). Instead of relying solely on increasing model size, CETNet combines multiple smaller models with distinct embedding tables. The framework enhances performance through collaborative learning where models iteratively refine predictions using a confidence-based fusion mechanism that balances contributions based on negated entropy scores.

## Technical note

Proposes CETNet, a collaborative ensemble training network for CTR prediction that scales via multiple models with distinct embedding tables rather than naive size increases that cause embedding collapse. Models iteratively refine predictions through collaborative learning aligned by a symmetric KL divergence loss, and a confidence-based fusion (softmax over negative-entropy confidence) dynamically weights each model's contribution. In Meta's deployment it ensembles InterFormer and DHEN to capture complementary sequential and hierarchical interactions. It outperforms individual models and the multi-embedding paradigm on Amazon, TaobaoAds, KuaiVideo, Criteo, and Avazu while using smaller embeddings.
