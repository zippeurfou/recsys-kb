## Summary

1.  Existing generative recommendation methods often struggle with effectively modeling both the full history and recent user behavior, and with providing personalized adaptation during item generation.
2.  To overcome these limitations, the authors propose MV-Thinker, a framework that first creates coordinated, complementary user contexts from different temporal views and then adaptively transforms these contexts using hierarchical residual adapters before generating item sequences.
3.  Extensive testing on public datasets shows MV-Thinker significantly outperforms other strong baselines, and its implementation code is available online.

## Technical note

Problem: SID-based generative recommenders (TIGER / LETTER style T5 encoder-decoders) either dilute recent cues by encoding the whole history as one sequence or fail to coordinate full and recent history when they are modeled as separate streams, and they apply one fixed output-side transformation to decoder states for every user and instance. Method: MV-Thinker adds Multi-View Temporal Thinking, two learnable <think> query tokens placed after the decoder start token that read the full-history and the recent (last w=5 items, a suffix of the same encoder states) views through separate cross-attention readers with a learnable residual scale before SID generation, and Hierarchical Residual Adaptation, four nested bottleneck adapters (dim 32, alpha 0.2) before the shared vocabulary projection, trained with loss-aware roulette sampling (softmax over negative per-path loss at tau=1, stop-gradient on shallower adapters, a load-balancing term gamma) and selected once per user at inference by the highest first-token log-probability, then fixed across SID positions and beam descendants; training is staged (base GR, then queries+HRA, then readers with the backbone frozen) and decoding uses constrained beam search with beam 20. Results on Amazon Instruments / Beauty / Games and Yelp (leave-one-out, 3 seeds, hidden 128, 4 layers): best H@K and N@K on every dataset under both TIGER and LETTER backbones, e.g. Instruments+LETTER H@20 0.1404 vs 0.1369 (IBA) and Beauty+TIGER N@5 0.0275 vs 0.0266 (GEMs), all significant over CARE, APAO, Latte, GEMs and IBA; SID catalog coverage at K=20 rises from 19.56% (TIGER) to 25.50%, removing the thinking queries hurts most, Only-Full beats Only-Recent but both trail the full model, and HRA routes 40.6 / 18.1 / 26.3 / 15.0% of Beauty users to depths 1-4. Public datasets only, no online test.
