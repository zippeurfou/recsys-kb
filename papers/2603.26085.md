## Technical note

AutoModel is an agentic architecture for the full lifecycle of industrial recommenders, replacing the fixed recall-ranking pipeline with interacting evolution agents that have long-term memory and self-improvement. It instantiates three core agents -- AutoTrain (model design, training, offline comparison), AutoFeature (data analysis and feature evolution), and AutoPerf (performance, deployment, online experimentation) -- coordinated by a shared knowledge layer recording decisions, configs, and outcomes. A case study shows AutoTrain automating paper-driven model reproduction end-to-end (method parsing to code generation, large-scale training, and offline comparison), reducing manual effort under the ARS principles of closed-loop functionality, independent evaluation, and evolvable decision space.
