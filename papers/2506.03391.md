## Technical note

This Huawei position paper introduces DTIRS (Dataset- and Task-Independent Recommender System), a framework to maximize recommender-system reusability and lower barriers to entry, inspired by LLMs' single-model task generalization. Rather than achieving direct task generalization, DTIRS eliminates the need to rebuild pipelines for each new dataset or task via a novel Dataset Description Language (DsDL) enabling standardized dataset descriptions and explicit task definitions for autonomous feature engineering, model selection, and optimization. It lays out a roadmap from Level-1 automation (dataset-agnostic but task-specific) to Level-2 (fully dataset- and task-independent) and discusses generalization-vs-specialization, compute overhead, and scalability trade-offs; it is conceptual with no headline empirical result.
