## Summary

This paper introduces ML-Tool-Bench, a comprehensive benchmark designed to evaluate autonomous ML agents by testing their planning and tool usage capabilities across complex ML tasks. The benchmark features 61 specialized tools and 15 Kaggle challenges, incorporating an "in-memory" system for managing intermediate results. Standard planning methods (like ReAct) and tree search struggled significantly with the planning complexity, leading the authors to propose simpler improvements like structured feedback and task decomposition, which substantially increased the validity of agent trajectories and improved performance on the benchmark using GPT-4o.

## Technical note

ML-Tool-Bench is the first benchmark for long-horizon tool-augmented planning on end-to-end ML tasks, with 61 specialized tools and 15 tabular Kaggle challenges requiring 20+ sequential tool calls and persistence of complex artifacts (dataframes, fitted models) via a scratchpad of named objects. It shows ReAct and LATS (MCTS with LLM value estimation) fail to produce valid long trajectories as context and artifacts accumulate. The authors propose shaped rewards with stage-wise textual feedback and hierarchical task decomposition with tool masking, which with GPT-4o improve over ReAct by 16.52 percentile positions, showing structured guidance is critical.
