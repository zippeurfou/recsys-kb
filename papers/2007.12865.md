## Summary

Google CIKM'21 SSL framework for two-tower retrieval: augment item features by masking (Correlated Feature Masking via mutual information) + feature-value dropout, encode two augmented views, and add an InfoNCE contrastive auxiliary loss jointly with the main batch-softmax task. Improves long-tail/cold-start item slices.

## Technical note

Yao et al. (Google, CIKM 2021) add a self-supervised auxiliary task to two-tower retrieval to fight long-tail/cold-start sparsity. Item features are augmented into two views by MASKING a subset of fields (Correlated Feature Masking: pick a seed field and its top-n mutual-information neighbors, n=floor(k/2), complementary split; masked fields use a default embedding) followed by per-value dropout (~0.3 optimal), each view encoded by the shared item tower, and an InfoNCE/batch-softmax CONTRASTIVE loss L_self pulls the two views of the same item together and pushes different items apart. The joint loss is L_main + alpha*L_self with SSL items sampled UNIFORMLY (not power-law) — heterogeneous sampling is critical. On AAI, tail Recall@10 improves ~51% vs ~8.6% head; gains grow as data gets sparser. Note: the objective is contrastive, not a per-field reconstruction/MFP loss.
