## Summary

Current LLM-based agents, while versatile, suffer from high computational costs during training and produce uninterpretable policies, hindering their adaptation and refinement. To address this, the paper introduces BREW (Bootstrapping expeRientially-learned Environmental knoWledge), a framework that creates and refines a structured knowledge base (KB) from the agent's experiences, replacing complex model training. BREW partitions memory for efficient retrieval, uses task graders and search for learning, and achieves significant empirical improvements in precision, reduced API calls, faster execution, and computational efficiency on benchmarks, establishing a transparent and modular substrate for agent optimization.

## Technical note

BREW optimizes LLM agents by constructing and refining a structured, natural-language knowledge base from past interaction trajectories instead of costly weight optimization (PPO/GRPO). Reflector and Integrator agents distill concept-level insights from rollouts graded by task-specific graders and human-validated behavior rubrics, and an Expand-and-Gather MCTS searches for the best KB configuration under a reward signal. Partitioning memory into concept documents enables fine-grained retrieval and transparent inspection. On OSWorld, tau2-Bench, and SpreadsheetBench, BREW gives 10-20% task-precision gains and 10-15% fewer tool/API calls at compute cost comparable to base models.
