## Summary

Personalization systems often struggle to effectively combine interpretable user textual profiles and effective latent embedding representations. To bridge this gap, the paper introduces BLUE, a reinforcement learning framework that uses a Large Language Model (LLM) to generate user profiles, guiding them with embedding-based reward signals towards better recommendation performance. Experiments show BLUE consistently outperforms other methods, especially in cross-domain settings and for providing personalized context, demonstrating the effectiveness of unifying textual profiles with latent embeddings.

## Technical note

BLUE is an RL framework that unifies interpretable textual user profiles with discriminative latent user embeddings for personalization. A profiler LLM generates candidate natural-language profiles from a user's history; a frozen embedding model encodes profile-plus-history into a user representation, and a latent-space contrastive reward (closer to positive items, farther from negatives) trains the profiler via GRPO without any ground-truth profiles. A text-space next-item multiple-choice signal keeps profiles semantically meaningful. Evaluated zero-shot on Amazon Reviews 2023 and Google Local Reviews (train on Clothing, test out-of-domain), BLUE beats strong baselines under both frozen and trainable embeddings, with notable cross-domain transfer gains, and its profiles serve as superior personalized context for question answering.
