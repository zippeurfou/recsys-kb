## Summary

Airbnb historically relied on structured data due to difficulties processing unstructured text and image information effectively. However, with advancements in representation learning like embeddings, leveraging these modalities became more feasible.

The proposed BiListing system tackles this challenge by automatically aligning diverse text (title, description) and images within each listing using large language models and language-image models, creating richer single representations per listing that capture all unstructured data coherently.

This alignment enables powerful features like zero-shot inventory search in user-friendly terms, overcomes the cold start problem for new listings lacking structured data, improves existing ranking models by combining both text and image information effectively into one unified vector.

## Technical note

BiListing aligns the multiple images and multiple text documents (title, description, reviews) of an Airbnb listing into a single embedding per listing and modality, avoiding the information loss of naively averaging heterogeneous embeddings. It adapts the CLIP contrastive-learning framework beyond single photo-caption pairs to complex multimodal entities, using large language models and pretrained language-image models to overcome CLIP limitations (single pair, 77-token context, caption-style text) for long, multi-aspect listings. The resulting bimodal embeddings enable zero-shot free-text inventory search in natural semantics, address cold-start for listings lacking structured data, and support listing-to-listing search along one or both modalities. Used as features in the Airbnb search ranking model, offline and online tests showed a +0.425% NDCG gain and drove a booking lift in production.
