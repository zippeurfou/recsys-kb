## Summary

1.  Recommender systems trained on biased (observational) data create filter bubbles that negatively impact long-term user engagement by narrowing interests.
2.  While using unbiased data for debiasing is promising, current methods are impractical for industry due to ignoring factual recommendation performance or requiring too much computational overhead.
3.  ConAlign proposes a novel framework addressing these issues via selective knowledge transfer from the biased component to the unbiased one in real-time, supported by offline validation and online A/B tests showing significant engagement improvements with minimal latency impact.

## Technical note

Industrial recommenders trained on biased logged feedback create filter bubbles that collapse user interests and hurt long-term engagement. ConAlign uses a dual-tower architecture, a biased tower on large-scale logged data and an unbiased tower on a small permanent stream of missing-at-random random-intervention traffic, coupled by a conditional cross-tower alignment loss that distills the biased tower's penultimate representation into the unbiased tower only on instances where the biased tower has lower loss (discrete gating with stop-gradient). It trains online in a streaming fashion, serves only the unbiased tower's score at negligible latency, and beats InterD/AutoDebias on Coat/Yahoo! R3/KuaiRand at a fraction of the training cost. Deployed at Kuaishou, it lifted LT7 retention +0.029%, DAU +0.069%, interest diversity (VIN) +0.097%, and completion plays +0.277%.
