## Summary

Recommendation systems face "Memory Wall" bottlenecks due to large, dense embedding tables needed for user-item interactions. This paper proposes Dual-purpose Semantic IDs (DSIDs), inspired by data compression techniques, as a solution that performs both collaborative ID tasks and context reconstruction using learnable embeddings condensed into discrete tokens via hierarchical quantization. DSIDs replace the need for storing massive dense vector tables with on-demand token-based embedding approximation using a lightweight decoder, significantly reducing system overhead and achieving LLM-level I/O efficiency while maintaining content richness in production systems.

## Technical note

Dual-purpose Semantic IDs attack the recommendation Memory Wall / I-O bottleneck by hierarchically quantizing high-dimensional content embeddings (RQ-VAE, inspired by VQ-VAE/VQGAN) into roughly 50-100x smaller discrete token sequences that serve two roles at once: a learnable collaborative identity (unigram/bigram/nested n-gram/SentencePiece token embeddings) and on-the-fly content reconstruction via a lightweight Semantic Decoder (SiDec) that regenerates the dense content embedding inside the model graph instead of logging/joining float vectors. Deployed at a major video platform (YouTube) for both ranking and retrieval, adding the SiDec stream lifted online satisfied engagement (e.g. +0.80% Watchpage, +0.22% Homepage) and disproportionately helped cold-start/long-tail items while mitigating popularity bias. Offline, decoding SIDs matched raw-embedding Hit Rate@100 (about 0.287-0.291) while recovering roughly 20-28% of training throughput lost to dense-embedding I-O. The theme is 'tokens are all you need': replace continuous-feature I-O with discrete tokens plus on-demand reconstruction.
