## Summary

1.  Personal language models often make data-sharing decisions, but basing these solely on general privacy norms is insufficient for personalization.
2.  Directly using the model's own reasoning via In-context Learning to infer user privacy preferences is unreliable and hard for users to understand.
3.  To solve this, the authors propose ARIEL, a framework combining language models with logical entailment rules, showing it significantly improves the accuracy (F1 score) of personalized privacy judgments compared to standard model reasoning.

## Technical note

The paper addresses personalizing data-sharing decisions for LLM agents, showing that general privacy norms and in-context learning over prior user judgments give unreliable, opaque personalization. It proposes ARIEL, which frames a personalized privacy judgment as logical entailment: whether a user's prior decision entails the same decision for a new request. An LLM generates ontologies (e.g., data-sensitivity hierarchies) from prior judgments, and a rule-based component performs the entailment, escalating to the user when no decision can be inferred. Across GPT-5, Gemini 2.5 Pro, Claude Sonnet 4.5, and Gemma 3 4B on smart-home and educational datasets, ARIEL cuts the appropriate-judgment F1 error by up to 40.6% versus ICL, with larger gains on smaller models and as few as 20 prior requests.
