## Summary

1. Current memory systems often passively feed evidence into conversational agents, but researchers propose an alternative approach where long-term user memory becomes an *active*, structured action space for the agent to navigate strategically.
2. The NapMem framework organizes chat history hierarchically (into a "memory pyramid") with linked components like raw conversations and typed records, allowing the agent to be trained via reinforcement learning to select specific memories or granularities relevant to answering questions.
3. Experiments show that using these memory tools through active navigation significantly improves performance on tasks needing long-term user knowledge without impacting general reasoning abilities, suggesting structured memory access is beneficial for personalized agents.

## Technical note

NapMem reframes long-term user memory from passive retrieval into a structured action space by organizing user history into a four-level memory pyramid (raw conversations, typed memory records, topic tracks, user profile) linked by provenance, exposed through five memory tools (search/get conversations and records, plus read_file). A single conversational agent (Qwen3.5-9B) is trained with Group Relative Policy Optimization (GRPO) using a rule-based terminal reward over format, correctness, and memory-tool usage under a 4-step tool budget, learning to pick the right memory granularity and stop when evidence suffices. The RL-trained 9B model reaches 62.74 average across LoCoMo, LongMemEval, and PersonaMem-v2, beating Mem0, Zep, MemOS, MemoryOS, AgeMem and even untrained 397B variants (59.85), while cutting unnecessary memory calls on GPQA-D from 34.51% to 6.90% and preserving non-memory reasoning/tool-use ability.
