## Technical note

UMC (Unconstrained Monotonic Calibration) calibrates deep-ranking predictions so absolute values (e.g. pCTR for ad bidding) match true probabilities, replacing fixed-form order-preserving transforms (binning, isotonic regression, scaling, piece-wise linear networks) that lack expressiveness. It implements the calibrator with an Unconstrained Monotonic Neural Network (UMNN) that learns arbitrary feature-conditioned monotonic functions, imposing only conditional monotonicity so different samples get distinct transforms without excessively distorting predictions. It adds a Smooth Calibration Loss (SCLoss) that groups samples by prediction and minimizes squared differences between average predictions and labels per group. Offline experiments show superior calibration; deployed in Kuaishou's video search system serving hundreds of millions of users, A/B tests improved multiple business metrics.
