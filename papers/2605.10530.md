## Summary

Current deep research agents using LLMs, while automating discovery, often use a static retrieval approach, failing to adapt to a user's specific expertise or interests, resulting in reports that aren't tailored for either experts or novices.

To solve this, the authors introduce Personalized Deep Research (PDR), a framework that integrates dynamic user context directly into the core retrieval and reasoning loop, aligning research goals with user intent and optimizing evidence collection for the user.

PDR unifies user profiling with query development and retrieval, includes a public/private retrieval strategy, and uses context-aware synthesis. To evaluate it, they release a new dataset and propose a hybrid evaluation method, showing PDR significantly improves report relevance compared to existing systems.

## Technical note

Personalized Deep Research (PDR) integrates dynamic user context directly into the retrieval-reasoning loop of LLM deep-research agents, rather than treating personalization as post-hoc formatting, to avoid one-size-fits-all reports that are redundant for experts or too dense for novices. The four-stage pipeline is Profile Extraction (a reasoning LLM with auxiliary tools structures heterogeneous user data into a schema of demographics, traits, and preferences), Personalized Question Development (profile-conditioned decomposition of the query into intent-aware sub-queries), Dynamic Dual-Stage Retrieval (a decision agent iteratively queries both private user repositories and public corpora, issuing gap queries), and Personalized Report Generation. The authors release a PDR dataset over four realistic tasks and a hybrid PDR-Eval protocol combining lexical metrics with LLM-as-judge, showing gains in retrieval utility and report relevance over iterative RAG and commercial systems.
