## Summary

1.  The authors propose FACTER, a framework designed to make LLM-based recommender systems more fair by detecting and mitigating bias automatically.
2.  FACTER uses an adaptive semantic variance threshold that tightens fairness constraints when biased patterns are detected, along with a mechanism triggered by violations.
3.  They enhance this detection with an adversarial prompt generator that learns from historical biases to reduce demographic unfairness without needing LLM retraining, and experiments on standard datasets show it significantly reduces bias (up to 95.5%) while preserving accuracy.

## Technical note

LLMs used as zero-shot recommenders can amplify demographic biases, and black-box APIs preclude parameter-level debiasing. FACTER couples conformal prediction with dynamic prompt engineering: it calibrates an adaptive semantic-variance threshold on embeddings to flag fairness violations with statistical coverage guarantees, then uses a violation-triggered adversarial prompt generator to insert 'avoid' examples that repair the system prompt without retraining. Fairness is defined via minimal-attribute-change distance plus group metrics (SNSV, SNSR, CFR). On MovieLens and Amazon it cuts fairness violations by up to 95.5% while preserving accuracy.
