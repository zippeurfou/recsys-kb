## Technical note

DS4RS is a community-driven, explainable dataset search engine for recommender-systems research, addressing scattered sources and inconsistent metadata that make finding task/domain-appropriate datasets hard. It supports semantic search across dataset attributes (names, descriptions, recommendation domain) and explains search relevance for transparency, with an interactive interface for exploration, metadata inspection, and download links. Users contribute standardized dataset metadata via a public repository to improve discoverability and reproducibility. It is publicly available at ds4rs.com.
