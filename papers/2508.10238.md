## Summary

This paper introduces **DS4RS**, a dataset search engine designed specifically for recommender system research to solve the problem of finding suitable datasets amidst scattered sources and inconsistent metadata.

The core idea is that DS4RS enables users to perform semantic searches across multiple attributes like names, descriptions, and domains, while providing explanations for relevance results.

Furthermore, it encourages community participation by allowing researchers to contribute standardized dataset metadata back to a public repository, thereby improving dataset discoverability and search interpretability.

## Technical note

DS4RS is a community-driven, explainable dataset search engine for recommender-systems research, addressing scattered dataset sources and inconsistent metadata. Contributors submit standardized JSON metadata (recommendation task, domain, size, description, example records) to a public repository, which an offline pipeline validates and encodes with Sentence-BERT (all-mpnet-base-v2). Online, a query is embedded in the same space and matched via cosine similarity across metadata fields, taking the max-field similarity as relevance and surfacing which fields contributed for explainability. The system (publicly hosted at ds4rs.com) aims to improve dataset discoverability, transparency, and research reproducibility.
