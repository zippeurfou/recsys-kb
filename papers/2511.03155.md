## Technical note

GAMER (Generative Augmentation and Multi-lEvel behavior modeling for Recommendation) is a decoder-only generative framework for multi-behavior sequential recommendation, aimed at guiding users toward sparse high-value conversions using auxiliary behaviors (clicks, likes, shares). It addresses inadequate cross-level sequence modeling and the lack of non-e-commerce multi-behavior datasets with side information for semantic ID generation. Across multiple metrics (HR@K, NDCG@K) it consistently outperforms discriminative and generative baselines; sequential models beat graph-based multi-behavior models, and SID tokenization beats content-ID (CID) on behavior-specific item prediction.
