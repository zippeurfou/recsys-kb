## Summary

Enterprise IT support struggles with diverse devices, changing policies, and rare failures, making central solutions inadequate. VIGIL addresses these challenges by deploying desktop agents that perform local diagnosis, access enterprise knowledge, and execute policy-based fixes, all with user consent and full observability. A pilot showed VIGIL significantly reduced diagnosis time and interaction rounds, achieved high self-service rates, and gained high user trust, particularly valuing its transparency and on-device diagnostic capability even without prior knowledge matches.

## Technical note

VIGIL is an edge-extended agentic system deploying desktop-resident LLM agents (planner, diagnosis, knowledge, remediation) that run a diagnose-retrieve-remediate loop directly on endpoints, grounding diagnosis in enterprise knowledge via RAG. State-changing actions pass through a deterministic Open Policy Agent engine classifying commands into allow/warn/deny tiers, with moderate-risk actions gated by user consent. Evaluated in a 10-week pilot on 100 Windows endpoints, it cut interaction rounds 39%, achieved at least 4x faster diagnosis, and estimated 82% self-service resolution over 826 case-matched sessions. User studies (n=23) reported SUS 86.2, high trust, and low NASA-TLX workload, with higher ratings when no historical match existed, indicating situated diagnosis adds value beyond knowledge-base retrieval. The self-improvement loop refines prompts/memory/policies without model retraining but was left as future work.
