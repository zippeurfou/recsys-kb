## Summary

Traditional recommender systems using large language models often rely on fixed reasoning workflows, which struggle with diverse user contexts like cold-starts or changing interests. ChainRec addresses this by introducing an agentic approach where a trainable planner dynamically selects from a library of specialized "tool agents" to gather relevant evidence and formulate recommendations. This system significantly outperforms existing baselines, especially in challenging scenarios involving new users or evolving user tastes, demonstrating the benefits of adaptive, tool-based reasoning.

## Technical note

ChainRec is an agentic recommender that replaces fixed reasoning workflows with dynamic, state-aware tool routing for interactive recommendation on AgentRecBench (Amazon, Goodreads, Yelp). Offline it mines expert chain-of-thought traces, normalizes and k-means-clusters recurring reasoning steps, and encapsulates them into a standardized Tool Agent Library with unified I/O. A planner is trained via SFT (behavior cloning of expert tool-call trajectories) then DPO (preferring higher-utility tool chains under a step budget), formulating recommendation as a finite-horizon MDP with observe-decide-act loop and terminal HR-based reward. It improves Avg HR@{1,3,5} over agentic baselines with the largest gains in cold-start and evolving-interest scenarios; ablations show state-aware routing (not longer plans) drives the gains.
