## Summary

Self-Evolving User Policy Skills for Recommendation Agent":

1.  Existing LLM recommendation agents personalize user memories but use a static, shared reasoning system prompt for all users, creating a bottleneck where failed recommendations aren't analyzed or improved.
2.  SAGER addresses this by giving each user a personalized "policy skill," a natural language document encoding evolving decision rules, using a specialized architecture that decouples evolution from inference.
3.  SAGER improves recommendations by dynamically diagnosing reasoning flaws and using the evolving skill for better item discrimination, achieving state-of-the-art results independent of pure memory accumulation.

## Technical note

Sager equips each user with a self-evolving 'policy skill', a structured natural-language document of personalized decision principles, distinguishing policy evolution (how the agent reasons) from memory evolution (what it knows) and model evolution. It uses a two-representation architecture in which a ~1500-char full skill repository is distilled to a ~30-token slim injection to respect a 'Cognitive Injection Boundary', beyond which attention dilution degrades quality. An incremental contrastive chain-of-thought engine emits structured diffs (Reinforce, Discover, Weaken) contrasting accepted versus unchosen items to preserve accumulated priors under sparse feedback. Skill-augmented listwise reasoning forces strict total orderings so the slim skill acts as a soft tie-breaker, yielding state-of-the-art results on four benchmarks with gains orthogonal to memory accumulation.

- Vanilla LLM (Zero-Shot Prompting) : This baseline represents the direct application of a powerful instruction-tuned LLM (e.g., GPT-4o-mini) via API calls. For each prediction, the user’s entire sequence of historical interactions is converted into a natural language string and fed into the LLM as a static context prompt. The model performs zero-shot selection from candidate items based solely on this provided raw history, serving as a baseline to measure the LLM’s inherent capabilities independent of designed memory architectures
- iAgent : An LLM-based autonomous agent designed for recommendation. It employs a static profile for each user, constructed from their historical interactions and available descriptive data. This fixed profile is fed into the LLM as context to generate recommendations. The key characteristic is that its understanding of the user does not adapt over time after initial construction
- i^2Agent : An extension of iAgent that introduces a "reflection" mechanism. After recommendations, the agent can reflect on user feedback to refine its internal state or strategy for future interactions. While dynamic, these reflections are confined to the individual agent’s experience with a specific user
- AgentCF : An agent-based collaborative filtering framework that simulates user-item interactions. Agents representing users and items can autonomously interact, learn from these interactions, and update their own preferences or characteristics. The memory update is dynamic but remains localized to the individual agents involved in the direct interaction
- RecBot : A conversational recommender system that uses an LLM to engage with users. It maintains a dynamic dialogue history and can update its understanding of user preferences based on the ongoing conversation. This dynamic memory allows for multi-turn interactions but is limited to the context of the current user session
- MemRec : A memory-augmented LLM agent for personalized recommendation that serves as our primary baseline. MemRec retrieves user context via semantic similarity and collaborative signals from a user-item interaction graph, and synthesizes structured memory facets for re-ranking. It operates with a universal, static reasoning policy. Sager extends this backbone by introducing a per-user self-evolving policy skill that personalizes not only what the agent knows, but how it reasons
