## Technical note

MixLM (LinkedIn) is an LLM-based ranking framework that cuts input context length while preserving cross-encoder semantic interaction. It pre-encodes each item description into a small number of learned embedding tokens stored in a nearline cache, then mixes these with the user query text in a ranker LLM, replacing thousands of item text tokens with a few embeddings and amortizing prefill compute. Joint encoder-ranker training with distillation losses transfers knowledge from a full-text LLM ranker. Under a fixed latency budget with comparable relevance, MixLM improves throughput 10.0x over strong baselines and 75.9x over full-text LLM rerankers, enabling full-traffic deployment in LinkedIn Job Search and a +0.47% DAU lift.
