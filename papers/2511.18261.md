## Summary

Large Language Models (LLMs) offer a solution to the difficult cold-start problem in recommendation systems, where traditional methods struggle due to sparse user data. This paper proposes novel reasoning strategies using LLMs specifically for the Netflix domain, exploring different fine-tuning techniques like supervised and reinforcement learning to infer user preferences for new or rarely seen items. Extensive experiments show that these reasoning-based, fine-tuned LLM models significantly outperform Netflix's existing production model, achieving up to 8% better performance in some cold-start scenarios.

## Technical note

This work develops LLM reasoning strategies for cold-start item re-ranking in the Netflix domain, where classic collaborative filtering fails due to sparse interactions and items post-date the LLM training cutoff. It proposes Structural Reasoning (decomposing user history into weighted preference-factor reasoning paths with match scores) and Soft Self-Consistency (softly summarizing multiple reasoning paths instead of majority voting). It systematically compares supervised fine-tuning (QLoRA on Qwen2.5-32B), RL fine-tuning with GRPO, and SFT+GRPO. SFT boosts AnyPlay while GRPO favors Discovery; in warm-start settings SFT+GRPO exceeded the Netflix production model by ~8% on Discovery despite far fewer training samples.
