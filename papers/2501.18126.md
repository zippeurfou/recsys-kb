Modern recommendation systems can be broadly divided into two key stages: the ranking stage, where the system predicts various user engagements (e.g., click-through rate, like rate, follow rate, watch time), and the value model stage, which aggregates these predictive scores through a function (e.g., a linear combination defined by a weight vector) to measure the value of each content by a single numerical score. ## Technical note

HyperZero is an end-to-end auto-tuning system for the value-model stage of industrial recommenders, which linearly combines ranking predictions (pCTR, like, follow, watch time) via a weight vector that traditionally takes 2-3 weeks to tune. It converges in 2-3 days by operating on hourly feedback: a semi-i.i.d. delta signal (test/base metric ratio, with mean/variance via high-order Taylor approximation) decorrelates noisy non-i.i.d. hourly data, and a zeroth-order constrained optimizer combines Gaussian-process estimation with Thompson sampling plus a candidate-proposal subroutine and asynchronous parallel exploration to handle delayed feedback. On synthetic data HyperZero reaches 4.95% objective gain with ~0.001 constraint violation vs ~2.1% gain and 0.59 violation for constrained/penalized Bayesian optimization; in production it beats BoTorch (1.2% vs 0.8% mean view-count gain, doubling gains when candidate proposals are enabled).
