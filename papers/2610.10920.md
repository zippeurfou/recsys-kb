## Summary

1.  E-commerce search pages, which increasingly feature secondary "stacks" for product recommendations, rely heavily on effective layout design to maintain user engagement and browsing flow, but evaluating these layout changes offline without costly online A/B tests is difficult.
2.  The paper explores using large language models (LLMs) as an offline evaluation tool specifically for deciding whether to insert a secondary stack at a particular position, comparing different ways the LLMs can be prompted or utilized.
3.  It finds that representation-based methods, which use the LM to deeply understand the context and semantics of the entire page layout, significantly outperform simpler prompt-based approaches, offering a reliable way to predict user engagement benefits from page-level changes using LLMs.

## Technical note

Walmart studies offline evaluation of page-level layout decisions on e-commerce search pages, specifically whether inserting a secondary recommendation stack (carousel) at a given position helps the user, since such changes otherwise need costly online A/B tests. Labels come from 11,000 logged Walmart.com requests using a top-to-bottom scroll model: add-to-cart on the stack is positive, add-to-cart on a primary result below the stack is negative, and the rest are discarded. Three LM-based evaluators are compared: direct prompting of Mistral-7B-Instruct (DP) and a rubric-decomposed variant (PDJ), linear/XGBoost/shallow-NN classifiers on PDJ's decomposed scores plus explicit layout features (PFC), and a shallow classifier on frozen ModernBERT embeddings of the page-context prompt (REC). REC-Snn dominates with ROC-AUC 0.853 vs 0.740 for the best PFC and 0.673 for PDJ (DP labeled every instance positive, AUC 0.596); adding explicit features to REC changes AUC by only +0.002 while removing them from PFC drops AUC by 0.02-0.05, indicating the embedding already encodes them.
