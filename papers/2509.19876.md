## Technical note

Kuaishou's Contextual Diffusion Purifier (CDP) models user behavior sequences as noisy 'contaminated observations' eroded by exposure bias, category drift, and context noise, rather than assuming behaviors equal ground-truth interest. CDP first category-filters behaviors, then applies forward noising and conditional reverse denoising guided by cross-interaction features (Query x User x Item x Context), with an MoE-based multi-condition fusion, to generate pure, context-adaptive interest representations that evolve with scenarios. It integrates into existing ranking architectures without structural change; offline and online experiments show superiority over state-of-the-art attention (DIN, DIEN, SASRec) and generative (HSTU) baselines.
