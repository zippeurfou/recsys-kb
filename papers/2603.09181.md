## Summary

1.  Existing industrial index tuners like Microsoft DTA, which rely on query optimizer cost estimations, can produce suboptimal recommendations due to estimation inaccuracies.
2.  This paper evaluates LLM-driven index tuning, comparing it to DTA using benchmarks and real workloads, finding that while DTA is generally more reliable, LLMs can often find significantly better-performing index configurations, especially with repeated use, highlighting their potential as a complementary tool.
3.  However, LLM-driven tuning faces challenges including substantial performance variance, difficulties in direct integration with DTA, and high validation costs, though the study provides insights and motivation for future LLM-driven index tuning research.

## Technical note

The paper empirically evaluates pre-trained LLMs for SQL index tuning against Microsoft's Database Tuning Advisor (DTA) using both TPC-H and four real enterprise customer workloads, measuring actual query execution time rather than optimizer-estimated cost. LLMs find configurations that substantially beat DTA in a meaningful fraction of cases, especially where DTA is misled by inaccurate what-if cost estimates, often proposing fewer indexes while remaining effective. However LLM output has high variance across runs and workloads, sometimes causing severe query performance regressions, and directly expanding DTA's candidate pool with LLM-suggested indexes tends to degrade performance. The authors distill LLM reasoning into a simple rule-based tuner and note that performance validation via materialization is prohibitively expensive, dominated by index-creation cost.
