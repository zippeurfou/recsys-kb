## Summary

1.  Existing industrial navigation systems face challenges balancing efficient route calculation with personalized and diverse routing options in large networks, leading the authors to propose GenMRP.
2.  GenMRP uses a novel "skeleton-to-capillary" approach to dynamically create a smaller relevant sub-network, enabling efficient route generation through iterative refinement using the Dijkstra algorithm and updating road costs based on features, history, and previously generated routes.
3.  Evaluated extensively, GenMRP achieves state-of-the-art performance with high efficiency in both offline and online settings, demonstrating its effectiveness and being successfully deployed in a real-world navigation application.

## Technical note

GenMRP is a generative multi-route planning framework for real-time industrial navigation that balances efficient computation with personalized, diverse routing. It uses a skeleton-to-capillary approach to dynamically construct a smaller relevant sub-network, then generates routes iteratively with Dijkstra while updating road costs from features, travel history, and previously generated routes to encourage diversity. It achieves state-of-the-art performance with high efficiency in both offline and online settings. The system is deployed in a real-world navigation application.
