## Technical note

Large Memory Network (LMN) compresses and stores user history behavior in a large-scale, million-scale memory block, addressing spatial (cross-user interest sharing) and temporal (forgetting long-term interests) limitations of sequential modeling, and enabling parameter scaling without the cost of two-stage search-based long-sequence methods (SIM/TWIN) or full long-sequence attention. With an online deployment strategy the memory scales cheaply. Offline comparisons, memory scaling experiments, and an online A/B test on Douyin E-Commerce Search validate LMN, which is fully deployed serving millions of users daily.
