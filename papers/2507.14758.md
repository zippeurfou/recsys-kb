## Technical note

GRACE is a generative framework for multi-behavior sequential recommendation that improves on TIGER/MBGen-style semantic tokenization. It uses a hybrid Chain-of-Thought tokenization encoding user-item interactions with explicit product-knowledge-graph attributes (category, brand, price) on top of RQ-VAE semantic tokens for interpretable, behavior-aligned generation, plus a Journey-Aware Sparse Attention that attends only to compressed intra-, inter-, and current-context segments to cut quadratic attention cost. On two real datasets GRACE improves HR@10/NDCG@10 by up to +106.9%/+106.7% on Home and +22.1% HR@10 on Electronics while reducing attention computation by up to 48% on long sequences.
