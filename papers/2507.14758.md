## Summary

This paper introduces GRACE (Generative Recommendation via Journey-Aware Sparse Attention on Chain-of-Thought Tokenization), designed to overcome limitations in generative recommendation systems dealing with multiple user behaviors and long sequences, primarily addressing inefficiency due to dense token representations and quadratic attention complexity. GRACE utilizes a novel hybrid CoT tokenization that incorporates explicit item attributes from knowledge graphs into the sequence generation process. Additionally, it employs a Journey-Aware Sparse Attention (JSA) mechanism for efficient processing by selectively attending only relevant parts of these compressed sequences. Experiments show GRACE significantly improves recommendation accuracy compared to state-of-the-art methods and achieves substantial computational savings with long user histories.

## Technical note

GRACE is a generative framework for multi-behavior sequential recommendation addressing the lack of explicit token semantics, quadratic attention cost, and weak multi-scale modeling in prior generative recommenders like TIGER and MBGen. It uses hybrid Chain-of-Thought tokenization that interleaves behavior tokens, coarse-to-fine product-knowledge-graph attribute tokens (category, brand, price), and RQ-VAE semantic IDs, forming an interpretable reasoning path toward the target item. Its Journey-Aware Sparse Attention (inspired by DeepSeek's NSA) gates four scopes—block compression, top-N intra-journey selection, inter-journey coarse traversal, and a current-context window. On two real datasets GRACE beats SOTA baselines by up to +106.9% HR@10 (Home) and +22.1% HR@10 (Electronics) while cutting attention compute up to 48%.
