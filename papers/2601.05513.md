## Technical note

LEAPS (LLM-Empowered Adaptive Plugin in Taobao AI Search) is a non-intrusive 'Broaden-and-Refine' plugin that handles conversational-style, multi-constraint natural-language queries without overhauling the existing search engine. Upstream, a Query Expander generates adaptive complementary query combinations to avoid zero-result outcomes, trained in three stages: inverse data augmentation, posterior-knowledge SFT, and diversity-aware RL (with a diversity-aware reward enforcing per-rewrite precision and set complementarity). Downstream, a Relevance Verifier prunes noise using multi-source signals (OCR text, reviews, sales) with internalized chain-of-thought reasoning. Fully deployed on Taobao AI Search since August 2025, LEAPS serves hundreds of millions of users monthly and improves the conversational shopping experience while preserving short-query performance.
