## Technical note

HGIB is a model-agnostic Hierarchical Graph Information Bottleneck framework for multi-behavior recommendation, using auxiliary behaviors (view, cart) to improve prediction of a target behavior (buy) despite distribution disparities and negative transfer from noisy auxiliary behaviors. Following information-bottleneck principles it learns compact-yet-sufficient representations preserving target-relevant information, and adds a Graph Refinement Encoder (GRE) that prunes redundant edges via learnable edge dropout. Experiments on three public datasets plus industrial scenarios and an online A/B test show significant improvements.
