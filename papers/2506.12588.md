## Technical note

This position/extended-abstract critiques evaluation protocols for Temporal Link Prediction (TLP) on temporal graphs, transferring known pitfalls from the recommender-systems community. It identifies three issues: inconsistent sampled ranking metrics (sampled MRR/AP not consistent under sampling, unlike AUC), reliance on hard negative sampling that can reverse model rankings, and combining edge predictions across source nodes which assumes equal base probabilities and is dominated by hub nodes under power-law degree distributions. Using heuristic baselines on datasets like Yelp/TGB it shows a Simpson's paradox between local and global heuristics and negative Spearman correlations across sampling strategies, motivating debiased evaluation.
