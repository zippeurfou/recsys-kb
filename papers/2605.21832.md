## Summary

FLUID addresses the challenge of recommending live streams where unique IDs lead to poor performance for short-lived rooms due to insufficient collaborative data. It replaces the ID-based system with a framework that generates discrete hierarchical semantic codes (LUCID) from multimodal data, eliminating the need for candidate IDs. This ID-free approach, combined with online training, significantly improves recommendation quality and cold-start performance in large-scale livestreaming systems.

## Technical note

FLUID is the first production livestreaming ranker to fully retire the candidate-side item ID, which never converges given a ~40-minute median room lifetime that keeps ID embeddings in persistent cold-start. It trains a single-tower cross-domain multimodal encoder (SigLIP2 ViT + Qwen3-Embedding) jointly on short videos and livestreams with an InfoNCE Q2I objective, then discretizes the 128-d slice embedding via RQ-KMeans (4 levels, N=64) into hierarchical codes called LUCID, using RQ-KMeans over RQ-VAE to avoid codebook collapse under streaming retraining. A prefix n-gram embedding scheme conditions each level's lookup on the full quantization prefix path, and a staged warmup first adds cold slice-level LUCID as an independent token then replaces the ID with warm room-level LUCID. Deployed at billion-user scale it delivers +0.55% Quality Watch Duration and +2.05% Cold-Start Room Views.
