## Technical note

FLUID is the first framework to fully retire the candidate-side item ID from a production livestreaming ranker, addressing the persistent cold-start of ID embeddings when live rooms broadcast only ~40 minutes (embedding norm never converges). It uses a cross-domain multimodal encoder (SigLIP2 ViT + Qwen3-Embedding) jointly trained on short videos and livestreams to produce discrete hierarchical semantic codes called LUCID via RQ-KMeans, then a staged warmup that first adds cold slice-level LUCID as an independent token beside the ID embedding and later replaces the ID embedding with warm room-level LUCID before online incremental training. Deployed across platforms with over one billion users, FLUID delivers +0.55% Quality Watch Duration, +2.05% Cold-Start Room Views, and +0.05% Active Hours.
