## Summary

This paper introduces URecJPQ, a Joint Product Quantization method designed to reduce the memory requirements of large-scale multimodal recommendation models.

The core innovation is representing users and items through shared sub-embeddings concatenated with modal-specific information instead of unique ID embeddings.

Experiments show significant reductions in model size (86% to 99%) with minimal accuracy loss (average 15% reduction) on standard metrics, even achieving slight performance improvements in some cases.

## Technical note

URecJPQ extends RecJPQ's Joint Product Quantization from sequential next-item prediction to large-scale multimodal top-k recommendation by quantizing both user and item ID embeddings rather than items only. Instead of learning a unique full embedding per entity, each user/item is represented as a concatenation of shared learned sub-embeddings drawn from per-subspace codebooks (typically 256 codes per subspace, one byte each), with non-differentiable sub-ID assignment done before backbone training so the model trains end-to-end without ever materializing full embeddings, drastically cutting trainable parameters and backprop-time gradient memory. For multimodal settings the shared sub-embeddings are concatenated with modality-specific information. Across movies, baby, and sports datasets, large-scale scenarios show 86-98% checkpoint-size reduction and 98-99% fewer trainable parameters with only marginal accuracy loss (avg ~8.5% recall, ~16% NDCG), and occasional improvements (up to 85% in the baby domain).
