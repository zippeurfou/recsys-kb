## Summary

This paper addresses the challenge of effectively fusing heterogeneous multimodal signals (images, text, user behaviour) in Taobao Shangou's food delivery recommendation system. Existing two-stage approaches often fail to align semantic understanding from image-text pretraining with downstream ranking models driven by user behaviour.

The authors propose GALA, an innovative three-stage pipeline that includes a unique "generative RL alignment" stage refining multimodal embeddings using reward-driven optimization (GRPO) based on conversion metrics, bridging the gap between initial pretraining and fine-tuning for better adaptation to evolving user intent.

GALA has been successfully deployed in production, serving billions of users daily. It demonstrates significant improvements over state-of-the-art methods through offline evaluation (+0.12/+0.20 AUC) and substantial online validation (A/B tests show +0.55% order volume increase).

## Technical note

Taobao Shangou food-delivery ranking suffers a pretraining-fine-tuning gap: frozen CLIP-style multimodal shop embeddings are content-aligned but not behavior-aligned, and long-accumulated ID features dominate the ranker. GALA is a three-stage pipeline: (1) domain-adaptive alignment of a GME-backbone joint encoder on 8M merchant image-text pairs plus 14M query-image-text triplets mined from search-to-purchase logs, using MoCo-style in-batch-negative contrastive losses weighted 0.3/0.3/0.4 over query-text, query-image and query-fusion (a T5 cross-attention fusion beats MLP); (2) a generative RL alignment stage where a Qwen2.5-7B-Instruct decoder ingests fused shop embeddings as placeholder tokens and emits reasoning tokens plus an index token selecting the purchased shop from the deliverable candidate set - SFT warm-up on 1M Qwen-72B-generated rationales, then GRPO (clip eps=0.2, KL beta=0.001) with a binary conversion reward, jointly updating the decoder, the index embedding matrix, and the shop embeddings; (3) the resulting frozen 128-d embeddings enter the production ranker through an ID-conditioned sigmoid gate h_f = g*h_id + (1-g)*h_m plus an auxiliary cross-entropy head on the multimodal branch (lambda=0.01, stop-grad on ID) that prevents gating collapse. Retrieval Recall@K reaches 0.877 vs 0.843 for 1536-d GME, and ranking reaches 0.7263 CTR-AUC / 0.8193 CVR-AUC vs 0.7251/0.8171 for the LUM baseline, with PCOC moving from 1.0409/1.0608 to 1.0212/1.0276; the learned gate shifts weight toward multimodal for tail (L1) shops. Deployed since Nov 2024 at 200M DAU, online A/B shows +0.55% order volume (95% CI [0.342%, 0.756%], p<0.01) and +0.5% shop exposure width at a cost of +1.7 ms P99 latency (15.9 -> 17.6 ms).
