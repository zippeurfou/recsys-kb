## Technical note

AdaSID is an adaptive Semantic ID learning framework that tackles SID collisions (different items sharing confusable codes) via two-stage adaptive overlap regulation instead of static overlap penalties. Stage one (semantic-adaptive overlap relaxation) uses a depth-aware similarity threshold to decide whether an observed overlap keeps receiving margin-based repulsion or is preserved as admissible sharing; stage two allocates pressure spatially (load-adaptive collision strengthening on congested SID neighborhoods) and temporally (progress-adaptive objective rebalancing). On two public benchmarks AdaSID improves Recall and NDCG by ~4.5% on average while improving codebook utilization and SID diversity, and an online A/B test on Kuaishou e-commerce short-video retrieval showed gains.
