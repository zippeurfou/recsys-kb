## Summary

The paper introduces Memory-Integrated Reconfigurable Adapters (MIRA), inspired by biological systems, to tackle the challenge of catastrophic forgetting in deep learning when handling multiple tasks or domains. MIRA integrates associative memory modules on top of a shared backbone, using learned keys to retrieve specific "adapter" updates for each task or domain. This unified framework demonstrates state-of-the-art performance on domain generalization benchmarks and outperforms specialized continual learning methods, enabling rapid task switching and strong knowledge retention in a single architecture.

## Technical note

MIRA is a biologically-inspired unified architecture that integrates Hopfield-style associative memory modules on top of a frozen ViT backbone to jointly handle domain generalization, class-incremental and domain-incremental learning. Instead of storing raw data, each per-layer Universal Hopfield Network stores LoRA adapter-weight updates as values and retrieves affine combinations of them via keys that are learned post-hoc and aligned to preceding-layer activations. By changing only task-specific objectives, MIRA achieves SoTA out-of-distribution accuracy in DG and outperforms specialized continual-learning methods, enabling rapid task switching and strong retention; ablations confirm both memory storage and post-hoc key learning are necessary.
