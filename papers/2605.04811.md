## Summary

Existing methods for assigning credit in multi-agent memory systems for LLMs either use a single, coarse final reward for all agents or require task-specific annotations for individual agent rewards. The paper introduces TreeMem, a system that converts the final reward into specific credit for each agent by expanding the multi-agent pipeline into a tree structure and estimating credit via Monte Carlo averaging over subsequent branches. Experiments show that TreeMem effectively improves memory system performance by providing specialized optimization signals to heterogeneous agents without needing task-specific annotations.

## Technical note

TreeMem addresses credit assignment in multi-agent LLM memory pipelines (builder-summarizer-retrieval) trained with RL, where uniform final-reward supervision is too coarse and task-specific rewards require costly annotations and risk reward hacking. It expands each agent's sampled outputs into multiple subsequent branches, forming a tree of candidate trajectories, and estimates each agent's contribution via Monte Carlo averaging over its downstream branches. This converts the coarse final downstream reward into agent-specific optimization signals used to update all agent policies simultaneously, enabling heterogeneous agents to specialize without task-specific annotations. On long-horizon memory benchmarks, TreeMem outperforms uniform-reward and task-specific-reward baselines.
