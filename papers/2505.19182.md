## Summary

(Abstract fallback)

Click-through rate (CTR) prediction is a critical task in online advertising and recommender systems, relying on effective modeling of feature interactions. Explicit interactions capture predefined relationships, such as inner products, but often suffer from data sparsity, while implicit interactions excel at learning complex patterns through non-linear transformations but lack inductive biases for efficient low-order modeling. ## Technical note

DLF (Dynamic Low-Order-Aware Fusion) is a CTR-prediction framework (Huawei) that fixes two-stream explicit/implicit feature-interaction models where streams share little information, suffer gradient imbalance, and lose low-order signals in sparse data. It combines a Residual-Aware Low-Order Interaction Network (RLI) that preserves low-order signals while cutting residual-connection redundancy, and a Network-Aware Attention Fusion module (NAF) that dynamically integrates explicit and implicit representations at each layer to improve information sharing and balance gradients. On public datasets DLF achieves state-of-the-art CTR performance versus models like FM, DeepFM, DCN, and xDeepFM; code is released.
