## Summary

1.  **Problem:** Standard Direct Preference Optimization (DPO) aligns Large Language Models (LLMs) using pairwise preferences, but recommender systems typically receive set-wise user feedback involving multiple positive items and an implicit negative pool without prescribed ordering.
2.  **Proposed Solution:** The authors introduce Mult-DPO, a novel DPO objective function designed for this set-wise preference data in recommenders. It uses a tractable multinomial surrogate likelihood over the observed set events, defined on the same Plackett-Luce reward space as standard DPO but enabling direct classification-based alignment.
3.  **Key Contribution:** Mult-DPO provides a computationally feasible way to align LLMs using set-wise data by proving its loss is an upper bound on the complex marginalized version of the underlying PL model's loss, and further extends this approach to handle multiple preference levels.

## Technical note

Mult-DPO extends Direct Preference Optimization to LLM-based recommenders where feedback is set-wise: multiple positives should each outrank all negatives with no order among positives or negatives. A faithful Plackett-Luce extension requires marginalizing over all positive orderings, which is combinatorial (k! terms, reducible to 2^k), so the authors propose a tractable multinomial (MN) surrogate defined on the same reward-induced weight space that admits a closed-form, classification-style DPO objective computable in O(k). They prove the MN likelihood lower-bounds the marginalized PL likelihood, so minimizing MN-DPO optimizes a tractable upper bound on PL-DPO, with a bound-tightness characterization in terms of positive-vs-negative total weight that motivates harder negatives. A sequential-multinomial variant extends to multiple preference levels, and it outperforms DPO baselines on general and conversational recommendation.
