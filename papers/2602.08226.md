## Summary

ByteHouse is a new cloud-native OLAP engine designed to tackle the challenges of efficient, multimodal, and cost-effective data analytics, particularly in environments like ByteDance's where existing systems struggle with I/O inefficiency, rigid query optimization, and performance degradation from resource disaggregation.

Its architecture integrates a unified storage layer featuring a two-tier logical abstraction, a shared SSD-backed cache called CrossCache, and a virtual file system called NexusFS, all optimized for fast local access on compute nodes.

The compute and control layers support various execution modes, hybrid query optimizations, and an AI-assisted optimizer using historical data, enabling significant performance improvements over existing systems for real-time multimodal analytics.

## Technical note

ByteHouse is a cloud-native, shared-storage OLAP data warehouse for real-time multimodal analytics addressing I/O-inefficient multimodal storage, inflexible query optimization, and locality loss from resource disaggregation in ByteDance production. Its storage layer combines a unified table engine with a self-describing columnar format (Sniffer), an SSD-backed cluster-scale cache (CrossCache), and a virtual filesystem (NexusFS) for fast local access; the compute layer offers analytic, staged-batch, and incremental execution modes plus hybrid retrieval operators (RANK_FUSION), scalar-predicate-aware optimization, and tiered vector indexes. The control layer adds history-based optimization (HBO) reusing runtime statistics and AI-assisted plan selection for predicate pushdown and join-side choice. Evaluations show over 25% lower ClickBench latency and over 50% higher multimodal throughput on Cohere/C4 versus existing systems.
