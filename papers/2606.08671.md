## Summary

Existing task-specific language model agents struggle to evolve effectively because they often discard valuable prior decision history after each run, losing crucial context for revisions.

SkillHone addresses this by introducing a system that pairs skill evaluations with persistent evidence from previous decisions. It uses role-separated subagents to handle evaluation and refinement based on past structured histories of diagnoses, outcomes, and rejected alternatives.

This approach allows agents to learn continuously across sessions without rehashing old reasoning, demonstrated effectively in open-web deep-research benchmarks where it outperformed both a commercial retrieval agent and prior skill methods when using Qwen3.6-35B-A3B as the backbone.

## Technical note

SkillHone is an agent-facing harness for continual evolution of agent skills (loadable bundles of task-specific procedures, scripts, and references) that preserves persistent decision history rather than only the final artifact. It records structured histories of diagnoses, proposed revisions, evaluation evidence, and outcomes, so later agents understand why prior revisions were made and avoid repeating obsolete repairs as APIs and environments change. Optimization proceeds via role-bounded subagent dispatches rather than a fixed multi-agent system: evaluation subagents run candidate skills on practice probes and return only redacted evidence, while optimization subagents use that evidence plus prior decision records to form diagnoses and draft revisions without accessing hidden probe targets or validators, keeping the harness portable across runtimes (Claude Code, Codex, Hermes). On open-web deep-research benchmarks it beats a commercially backed deep-research agent by 15.8 points on GAIA and 3.2 on WebWalkerQA-EN, transfers to a different backbone without re-optimization, and improves internal tool-use scenarios by an average of 18.8 points.
