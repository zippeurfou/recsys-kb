## Technical note

Kuaishou's UniSearch is an end-to-end generative search framework that replaces the cascaded recall/pre-ranking/ranking pipeline, addressing the objective inconsistency of prior two-step (encode-then-generate) generative approaches. It jointly trains a Search Generator (encoder-decoder autoregressively producing item semantic IDs from query+user features) and a Video Encoder (VQ-VAE discretizing multimodal embeddings), using residual contrastive learning for query-video alignment, plus Search Preference Optimization (SPO) with a reward model and real user feedback and Trie-constrained inference. Offline and online A/B tests in Kuaishou live and short-video search confirm effectiveness, with the live-search deployment delivering the largest single-experiment gain in the product's recent history.
