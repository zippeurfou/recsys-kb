## Technical note

RecoChain unifies generative retrieval and ranking inside a single Transformer backbone to close the gap where OneRec-style generative recommenders beam out candidate Semantic IDs but cannot rank them well (e.g. picking top-10 from beam-256). At inference it first autoregressively generates candidate items via hierarchical Semantic ID prediction, then re-invokes the same backbone in a target-aware SIM-based mode to estimate per-candidate click probability, adding the target-aware searched-sequence modeling absent from prior GR models while sharing the KV cache. Experiments on large-scale real-world TAOBAO-MM data show improved Top-K accuracy while retaining generative capability.
