## Technical note

TSRec (Temporal and Sequential repeat-aware Recommendation) from Alibaba enhances repeat-aware recommendation by modeling repeat consumption from temporal and sequential aspects. It has three modules: a User-specific Temporal Representation Module using target attention to encode a user's historical repeat time intervals, an Item-specific Temporal Representation Module using CNN/pooling over a Repeat Time Interval Matrix to add cross-user item interval information as side information for sparsity, and a Sequential Repeat-Aware Module with a hierarchical Bi-GRU that matches the current sequence against the last repeat sequence. Data analysis shows repeat consumption follows fixed time intervals and high sequence overlap (45-60% Jaccard); TSRec outperforms state-of-the-art methods on three public benchmarks.
