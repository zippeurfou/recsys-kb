## Summary

1.  The paper introduces **TSRec**, a novel recommendation system designed specifically for predicting repeat interactions (like repurchasing or replaying items) by users.
2.  TSRec enhances this prediction by analyzing two aspects of user behavior sequences: the temporal relationships between repeated actions and the sequential patterns within those repetitions, encoding both types of information effectively.
3.  The model consists of three modules – UTRM for user-specific repeats, ITRM for item-level time info to address data sparsity, and SRAM for sequence similarity – and demonstrates superior performance on standard benchmarks compared to existing methods.

## Technical note

Repeat consumption (repurchasing, relistening) is common but poorly captured by methods that model only new-item preferences or add supervised repeat labels. TSRec enhances repeat-aware recommendation using both temporal and sequential signals from the user behavior sequence. It combines a User-specific Temporal Representation Module encoding historical repeat time intervals, an Item-specific Temporal Representation Module that uses item time-interval side information to mitigate sparsity, and a Sequential Repeat-Aware Module measuring similarity between current and last repeat sequences. On three public benchmarks TSRec outperforms state-of-the-art repeat-aware baselines.
