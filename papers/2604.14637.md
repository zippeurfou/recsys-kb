## Summary

Existing assistive navigation tools primarily offer real-time guidance for Blind and Low-Vision (BLV) users, overlooking the need for building a pre-travel cognitive map of unfamiliar environments. This gap motivated the development of Touching Space, a novel system designed to retrieve map data and allow BLV users to explore it holistically. Through a combination of audio and haptic feedback, users interact with the map via touch and spoken dialogue with a conversational agent, enabling the construction of spatial knowledge on standard hardware.

## Technical note

Touching Space is a macOS system that helps blind and low-vision users build pre-travel cognitive maps by combining vibrotactile trackpad feedback with a multimodal LLM conversational agent. A backend retrieves OpenStreetMap data via the Overpass API (400 m radius), processes polygons with OSMnx into touchable haptic zones over Apple Maps tiles; distinct Core Haptics vibration patterns encode buildings, parks, and water. The agent answers open-ended spatial questions from a multimodal prompt fusing a map screenshot, structured nearby-zone directions/distances, a sliding window of up to 20 conversation turns, and the query, responding in egocentric terms anchored to the cursor. Two pipelines were compared: a Gemini Live voice-streaming path (more natural, variable latency) and a text-mediated path (Gemini Flash or Qwen3-VL, more stable latency). This is an accessibility/HCI system, not a recsys method.
