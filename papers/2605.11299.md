## Summary

Current code generation models primarily learn from sparse execution feedback (like pass/fail) during training. This paper proposes using a "dual judgment" space, where models compare the correctness of multiple generated candidates at test time, to create a richer training signal. The DuST framework leverages this by sampling candidates, judging them via execution, and training the model to rank them discriminatively, showing that focusing on relative correctness improves both the model's ability to judge and generate correct code.

## Technical note

DuST (Dual Self-Training) turns the comparative information exposed by test-time scaling, normally discarded after inference, into a dense training signal for code generation. Where primal-space RL gives only a sparse pass/fail bit per sample, the dual judgment space over N candidates yields up to O(N^2) pairwise correct-vs-incorrect contrasts. DuST samples candidate programs from the model's own distribution, labels them via sandbox execution, keeps mixed groups containing both successes and failures, and trains the same model to rank candidates by execution correctness using GRPO; the objective is purely discriminative and never directly rewards generating correct code. Across five models (two families, 4B-30B), it consistently improves Best-of-4 on LiveCodeBench (e.g., Qwen3-30B-Thinking: +6.2 NDCG judgment, +3.1 pass@1, +4.1 Best-of-4). SFT on the same ranking data improves judgment but not generation, showing on-policy RL is the mechanism transferring dual-space learning back into primal generation.
