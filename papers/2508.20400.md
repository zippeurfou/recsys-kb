## Technical note

Kuaishou's MPFormer is a dynamic multi-task Transformer retriever addressing the misalignment between multi-objective ranking and single-objective retrieval, replacing costly parallel multi-path single-objective retrieval. It uses an objective-conditioned transformer that jointly encodes behavior sequences and multi-task semantics via learnable attention modulation, plus dynamic quota allocation adjusting recall quotas per target from real-time context, and personalization injected into token representations. Deployed on Kuaishou serving 400M+ DAU, it cut multi-task training overhead 63%, raised recall exposure +12.71% and multi-objective exposure +21.8%, and reduced GPU memory 31% versus multi-model baselines.
