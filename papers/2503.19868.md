## Technical note

GENIUS is a universal generative retrieval framework that generates discrete item IDs across modalities and tasks, offering an alternative to embedding-based ANN retrieval. Its core is modality-decoupled semantic quantization: an RQ-VAE-style residual quantization trained with contrastive learning encodes the first code as modality and subsequent codes as semantics, and a query-augmentation strategy interpolates between query and target embeddings to improve generalization; inference uses Trie-constrained beam search with optional embedding re-ranking. On the M-BEIR benchmark GENIUS surpasses the best prior generative retrieval method by 28.6 Recall@5 on COCO text-to-image retrieval and maintains near-constant retrieval speed across database sizes.
