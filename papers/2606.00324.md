## Technical note

This Pinterest paper argues Semantic IDs are a distinct modality whose token meaning is prefix-dependent, so LLMs should use a dedicated encoder rather than just adding SID tokens to the vocabulary. It proposes PrefixMem, a lightweight SID encoder built on prefix n-gram memory tables that provides prefix-conditioned representations at SID positions and can be pre-trained independently then attached to any LLM for joint training. On large-scale Pinterest data across multiple LLM families, PrefixMem improves deepest-level SID accuracy by up to 46% relative and full-SID retrieval recall by up to 22% relative at matched compute, with up to 77% relative gains on hard examples where greedy decoding fails.
