## Summary

E-commerce search struggles with long-tail, knowledge-intensive queries due to diverse language, lack of purchase intent, and insufficient training data, hindering recall and user experience. To address this, the authors developed a data synthesis framework leveraging powerful LLM-based query rewriting models, effectively creating a large set of curated query-product pairs offline. This synthetic data, when incorporated into retrieval model training, demonstrably improves recall and user experience for these challenging queries without requiring additional model adjustments.

## Technical note

This paper improves recall for long-tail, knowledge-intensive e-commerce queries by synthesizing query-product training pairs, implicitly distilling a strong offline query-rewriting LLM into the online dense retriever. A multi-candidate rewriting model is trained SFT-then-RL (REINFORCE++) with three continuous rewards: Query Semantic Relevance from an LLM binary classifier's yes-probability, Product-side Distribution Alignment via inverse perplexity under a product-domain continued-pretrained LLM, and n-gram-overlap Diversity across the candidate rewrites. An offline retrieval pipeline mirroring production (a 3B LLM dense retriever over ANN, top-200, plus a 42B MoE relevance model with additional general-semantic filtering) generates and scores query-product pairs, with a lightweight rewrite classifier pruning irrelevant candidates to control data explosion. Adding the curated synthetic data to retriever training raised online Query Goodrate by up to 8.62 points.
