## Technical note

ARAG is Walmart's agentic Retrieval-Augmented Generation framework for personalized recommendation that adds multi-agent collaboration to the RAG pipeline. Four specialized LLM agents cooperate: a User Understanding Agent summarizing long-term and session preferences, an NLI Agent scoring semantic alignment of RAG-retrieved candidates against inferred intent, a Context Summary Agent condensing the evidence, and an Item Ranker Agent producing the final ranking. Across three datasets ARAG significantly outperforms standard RAG and recency-based baselines, achieving up to 42.1% improvement in NDCG@5 and 35.5% in Hit@5, with an ablation confirming each component's contribution.
