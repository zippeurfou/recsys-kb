## Summary

ARAG introduces a novel agentic framework to enhance personalized recommendations using Retrieval-Augmented Generation (RAG), addressing the limitations of static RAG methods in capturing dynamic user preferences. This system integrates four specialized LLM agents – for understanding user preferences, evaluating semantic alignment, summarizing context, and ranking items – into the RAG pipeline. Experimental results across three datasets demonstrate that ARAG significantly outperforms standard RAG and baselines, achieving substantial improvements (up to 42.1% in NDCG@5 and 35.5% in Hit@5), highlighting the effectiveness of multi-agent reasoning for LLM-based recommendation.

## Technical note

Introduces ARAG, an agentic RAG framework for personalized recommendation that refines an embedding-retrieved candidate set through four coordinated LLM agents on a shared blackboard: a User Understanding Agent summarizing long-term and session preferences, an NLI Agent scoring semantic alignment of each candidate's metadata to inferred intent, a Context Summary Agent condensing the NLI-filtered evidence, and an Item Ranker Agent producing the final ranking. On three Amazon Review categories it beats vanilla RAG and recency baselines by up to 42.1% NDCG@5 and 35.5% Hit@5. Ablations show the User Summary and Context Summary agents each add incremental gains, confirming that decomposed agentic reasoning improves over static cosine-similarity retrieval.
