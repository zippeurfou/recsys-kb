## Summary

The authors present ARAG (Agentic Retrieval-Augmented Generation), an improved recommendation system framework built upon standard RAG by adding specialized agents. This multi-agent approach dynamically understands nuanced user preferences across long-term and session contexts, evaluates candidate item relevance against inferred intent, summarizes findings, and ultimately ranks recommendations for better personalization. Experiments show ARAG significantly outperforms traditional RAG methods and recency-based baselines (achieving up to 42% improvement in NDCG@5), demonstrating the effectiveness of incorporating agentic reasoning into recommendation generation.

## Technical note

ARAG augments RAG-based recommendation with a multi-agent LLM workflow to overcome static cosine-similarity retrieval. After an initial embedding-based recall, an NLI Agent scores each candidate's textual metadata against inferred user intent, a Context Summary Agent condenses the aligned items, a User Understanding Agent summarizes long-term and session preferences, and an Item Ranker Agent fuses these signals into a final ranking. Across three datasets ARAG beats standard RAG and recency baselines, with up to 42.1% NDCG@5 and 35.5% Hit@5 improvements, validated by an ablation of each agent.
