## Summary

This paper addresses the challenge of recommending photos on platforms like Flickr and 500px, where users seek photos sharing specific aesthetic qualities rather than just content. The authors propose two methods for extracting these aesthetic features, one based on color space and the other using deep style transfer embeddings. Their evaluation shows that using the deep style transfer embeddings with collaborative filtering significantly improves the performance of personalized photo recommendations.

## Technical note

Studies personalized photo recommendation for photography-enthusiast sites where users seek a photographic 'aesthetic' rather than content, proposing two annotation-free aesthetic feature extractors. The first builds HSV/RGB color histograms; the second extracts deep style embeddings as the vectorized Gram matrix from a chosen VGG-19 layer (layer 8, Euclidean distance found best). These features are used as side information in an item-item nearest-neighbor collaborative filter, blended with interaction similarity by a tuned weight. On a 500px dataset of ~226K users and 300K photos, color and explicit metadata side information did not help over plain I-NN, but deep style embeddings (I-NN-Style) gave a substantial boost (Precision@10 0.059 vs 0.048), showing style features matter for aesthetic photo recommendation.
