## Summary

This paper introduces **Contrastive Reflection**, an iterative framework for optimizing prompts controlling agentic information retrieval systems (LLMs acting as judges). It aims to make prompt debugging more effective by using structured traces from successful QA agents and scores/rationales from grading agents. Unlike blind search methods like comparison-instruction optimization, Contrastive Reflection identifies specific error slices, adds nearby correct examples, proposes targeted edits based on rationales, ensuring performance improvements without regressions.

## Technical note

Optimizing prompts for LLM agents in IR is often less like blind search and more like debugging, but existing optimizers act mainly on scalar validation metrics without explaining which behavior changed. The paper proposes Contrastive Reflection, an iterative loop that uses task-centric structured traces to find error-anchored behavioral slices, adds nearby successful examples to form a contrastive slice, asks a Teacher LLM for a targeted prompt edit, and accepts it only if validation improves (optionally under regression checks); it is instantiated with an entropy-based decision-tree slice selector. On a HotpotQA retrieval-augmented QA setup, one tree-selected contrastive repair raises held-out exact-match from 51.4% to 60.4% (fixing 54 examples while breaking 9), beating failure-only and random-contrastive variants on cleaner repair profiles. It is competitive with modern optimizers (MIPROv2 59.4%, GEPA 57.0%), and LinkedIn-derived grading workflows report ~+12pp gains as motivating (non-public) evidence.
