## Summary

This paper introduces HBayes, a novel hierarchical Bayesian learning framework designed for personalized recommendation systems. It aims to leverage the inherent hierarchical structure of items and user feedback to improve recommendations. The HBayes framework, coupled with a variational inference algorithm, learns both the hierarchical structure and user preferences, achieving state-of-the-art performance on real-world datasets and demonstrating faster convergence.

## Technical note

HBayes is a hierarchical Bayesian framework that exploits the natural tree structure of items (e.g., item, brand, latent style) to improve personalized recommendation. It defines a generative process with Gaussian priors over users and latent styles and Dirichlet-distributed style mixtures per brand, encoding hierarchical relations as conditional independences in a graphical model. A variational inference algorithm learns both the structure and latent factors with fast empirical convergence. Evaluated on real apparel and music datasets, HBayes outperforms state-of-the-art baselines on precision, recall, and NDCG.
