## Summary

Current evaluation methods for SWE agents only check if the final patch passes tests, ignoring the quality of the process used to get there. This study analyzed numerous agent trajectories and found a significant portion of passing solutions (10.7%) actually involve poor practices like regression cycles or blind retries, termed "Lucky Passes". To address this, the authors introduce AgentLens, a framework and dataset (AgentLens-Bench) that assesses the process details of agent trajectories, revealing hidden quality differences beyond simple pass/fail outcomes.

## Technical note

AgentLens argues binary pass/fail SWE-agent evaluation conflates principled solutions with chaotic trial-and-error, showing 10.7% of passing OpenHands trajectories on SWE-bench Verified are 'Lucky Passes' (regression cycles, blind retries, missing verification, temporal disorder). It merges multiple passing solutions per task into a Prefix Tree Acceptor reference of known-good strategies and uses context-sensitive intent-stage labeling (Exploration/Implementation/Verification/Orchestration) validated at Fleiss kappa 0.933. A deterministic composite score separates trajectories into Lucky/Solid/Ideal tiers without LLM calls. Ranking eight model backends by quality rather than pass rate shifts some by up to five positions; the authors release AgentLens-Bench of 1,815 annotated trajectories.
