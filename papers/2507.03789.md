## Summary

1.  While transformer-based models effectively predict next items in sequences, they face challenges integrating "query context" (like user browsing categories), which is crucial for improving relevance and engagement but often misaligned with item sequences or unavailable during prediction.
2.  This paper proposes a new method that integrates query context into transformers by fusing it with the item sequence within the attention mechanism itself, addressing these integration difficulties.
3.  Offline and online experiments demonstrate that this approach significantly improves model ranking quality in terms of both relevance and diversity compared to baselines, providing an effective solution for sequential recommendation using query context.

## Technical note

This paper integrates query context (e.g., the browse category under which an interaction occurs) into transformer-based sequential recommenders, a strong intent signal that is hard to add because historical query context is temporally misaligned with the item sequence and often unavailable at inference. It compares strategies for injecting context into a causal-language-modeling transformer and proposes fusing the item sequence with query context inside the attention mechanism itself, avoiding train-serve mismatch. Offline and online experiments on a large-scale platform (Zalando) and open datasets show the method improves ranking quality in both relevance and diversity over baselines that treat context as side information.
