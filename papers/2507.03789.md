## Technical note

This paper studies how to incorporate query context (e.g., browse category signaling user intent) into transformer-based sequential recommenders trained with causal language modeling, where historical query context is misaligned with item sequences and may be missing at inference. It analyzes several integration strategies and proposes a new method that fuses the item sequence with query context inside the attention mechanism. Extensive offline and online experiments on a large-scale platform and open datasets show it improves ranking quality in both relevance and diversity.
