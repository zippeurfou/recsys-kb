## Summary

1.  The paper introduces **MTmixAtt**, a novel unified architecture combining Mixture-of-Experts (MoE) and Multi-Mix Attention specifically for large-scale recommendation systems.
2.  MTmixAtt features two key components: **AutoToken**, which automatically clusters features into tokens, and **MTmixAttBlock**, which efficiently handles token interactions using dense and scenario-aware sparse experts.
3.  Extensive experiments and large-scale online A/B tests demonstrate that MTmixAtt significantly outperforms state-of-the-art models on industrial datasets, achieving better CTR/CTCVR metrics and improving real-world business outcomes like payment views and revenue.

## Technical note

MTmixAtt is a unified Mixture-of-Experts ranking architecture for large-scale recommendation that removes reliance on manual feature engineering and scenario-specific architectures. Its AutoToken module automatically clusters heterogeneous features (user profiles, item attributes, interaction histories) into semantically coherent tokens, eliminating human-defined feature groups. The MTmixAttBlock enables token interaction via a learnable mixing matrix combined with shared dense experts (global patterns) and scenario-aware sparse experts (scenario-specific behavior) in an attention-like formulation, supporting multi-head and multi-scenario modeling. On Meituan's TRec dataset it beats Transformer, WuKong, HiFormer, MLP-Mixer, and RankMixer at comparable scale, with monotonic gains scaling to 1B parameters; online A/B tests lifted Homepage Payment PV +3.62% and payment GTV +2.54%.
