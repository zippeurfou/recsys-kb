## Technical note

MTmixAtt (Meituan) is a unified Mixture-of-Experts ranking architecture with Multi-Mix Attention for large-scale recommendation. Its AutoToken module automatically clusters heterogeneous features into semantically coherent tokens, removing manual feature grouping; the MTmixAttBlock enables token interaction via a learnable mixing matrix with shared dense experts (global patterns) and scenario-aware sparse experts (scenario-specific behavior). On Meituan's TRec dataset it outperforms Transformer, WuKong, HiFormer, MLP-Mixer, and RankMixer, with monotonic gains scaling to MTmixAtt-1B. Online A/B in the Homepage scenario lifted Payment PV +3.62% and Actual Payment GTV +2.54%.
