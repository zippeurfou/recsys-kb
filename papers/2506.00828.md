## Summary

In single-slot recommendation systems where users only see one item per interaction, modeling user preferences directly often leads to models learning intrinsic tendencies (shortcut biases) from abundant user-side data rather than the specific interactions with items. This shortcut bias can overshadow the most relevant user-item preferences. The Breaker model addresses this by integrating a multi-tower architecture with delayed parameter updates and auxiliary user representation clustering, forcing cluster-specific preference modeling and effectively eliminating these inherent biases for better item ranking accuracy.

## Technical note

In single-slot recommendation only pointwise modeling is possible, and because user-side features vastly outnumber item-side features, DNNs take a shortcut of learning users' intrinsic click tendency instead of the desired user-item preferences (the top item feature ranks only 7th in LightGBM importance). Breaker adds an unsupervised user-representation clustering auxiliary task (deep embedding clustering with a Student-t kernel and squared-normalized pseudo-labels via KL loss) and a cluster-specific multi-tower module whose per-tower outputs are weighted by cluster-assignment probabilities, so users within a cluster share intrinsic tendencies and the model is forced to learn item preferences. A delayed parameter-update mechanism (target network refreshed every M steps) stabilizes joint training of the clustering and classification tasks. On two Meituan Payment RCT datasets Breaker beats FRNet/DCN-V2 baselines (e.g. +7.05% Recall@1 in Scenario A) with ~40% faster inference, and online A/B lifted conversion 4.93% and 7.15%; it serves tens of millions of users daily.
