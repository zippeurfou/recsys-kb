## Summary

(Abstract fallback)

Graphical user interface (GUI) agents have advanced rapidly but still struggle with complex tasks involving novel UI elements, long-horizon actions, and personalized trajectories. In this work, we introduce Instruction Agent, a GUI agent that leverages expert demonstrations to solve such tasks, enabling completion of otherwise difficult workflows. Given a single demonstration, the agent extracts step-by-step instructions and executes them by strictly following the trajectory intended by the user...

## Technical note

Instruction Agent (Microsoft) is a training-free, test-time GUI agent that solves complex tasks by strictly following a single expert demonstration. An Instructor model extracts a step-by-step action plan and UI grounding hints from the demonstration, and an Actor model executes it with verifier and backtracker modules to handle interruptions like pop-ups. It achieves a 60% success rate on OSWorld tasks that all top-ranked agents previously failed. Not a recsys paper (GUI automation agent); best-effort from fulltext.
