## Summary

HyTRec addresses the challenge of recommending based on long user behavior sequences, where standard attention mechanisms struggle with efficiency or computational cost. The solution is a Hybrid Attention architecture that separates long-term stable preferences from short-term intent spikes, using linear attention for historical data and softmax attention for recent interactions. This approach, combined with a Temporal-Aware Delta Network to handle changing interests, maintains fast inference while significantly improving recommendation accuracy, especially for users with very long interaction histories.

## Technical note

HyTRec is a generative next-item recommender for ultra-long behavior sequences that decouples stable long-term preferences from short-term intent. It splits each sequence into a short-term subsequence handled by standard multi-head self-attention and a long-term subsequence processed by a hybrid attention stack that interleaves a small proportion of softmax attention layers (~7:1) into a predominantly linear-attention (DeltaNet-style) backbone, restoring retrieval precision at near-linear cost. To counter linear attention's lag on rapid interest drifts, the Temporal-Aware Delta Network (TADN) uses an exponential temporal-decay factor and a gating mechanism that fuses short-term delta features with a static long-term gate to upweight fresh signals and suppress historical noise. On e-commerce datasets it reports ~5.8% NDCG and over 8% Hit Rate improvements for long-sequence users while keeping linear inference speed.
