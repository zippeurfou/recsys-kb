## Summary

This paper addresses challenges in using large language models (LLMs) for reranking recommendations, focusing on improving personalization by effectively handling user preferences. The main issues identified are the heavy reliance on manually crafted prompts which hinder scalability and difficulty processing unstructured item metadata to infer user tastes accurately. To tackle these limitations, the authors introduce AGP (Auto-Guided Prompt Refinement), a framework that automatically optimizes prompts for generating personalized user profiles by incorporating position-aware feedback for precise ranking adjustments and batched training techniques using aggregated data to enhance model generalization abilities.

## Technical note

LLM-based reranking relies on hand-crafted prompts that don't scale and struggle with noisy item metadata. AGP (Auto-Guided Prompt Refinement) automatically optimizes a shared user-profile-generation prompt (rather than the rerank prompt) so the LLM better infers preferences from item-title histories, using position-based feedback that pinpoints item-level ranking misalignments and batched training that aggregates feedback across users to prevent overfitting, updating the prompt in a gradient-like manner. On Amazon Movies, Yelp, and Goodreads reranking over LightGCN and SASRec baselines, AGP improves NDCG@10 by 5.61-20.68% with only 100 training users, helping graph-based LightGCN most. Ablations show summarization curbs overfitting and position-based feedback consistently improves ranking.
