## Summary

1.  Existing recommender system models struggle with efficiently handling both sequential user behavior data and non-sequential item features, often treating them separately or inefficiently using standard self-attention.
2.  To address this, the paper introduces HiRank, a unified model that jointly processes these heterogeneous features by scaling their effective-ranks and fuses sequential and non-sequential information bidirectionally within a shared structure.
3.  HiRank improves recommendation performance by using scenario-aware aggregation and learned projections to create compact, uniform representations, enabling more effective high-order self-attention and demonstrating significant gains on large datasets and in online A/B tests.

## Technical note

Industrial rankers typically encode the behavior sequence first and only then cross it with non-sequential features, and homogeneous self-attention over all tokens is wasteful when sequential and non-sequential signals have different effective ranks; HiRank (Taobao homepage CVR, with add-to-cart as auxiliary task, trained on platform-wide multi-scenario data) unifies both in one backbone. Each block applies HSTU-style gated attention to the main sequence with candidate cross-attention sharing the K/V, retrieves from several long-term memories (click/cart/purchase) with both main-sequence-derived interest queries and candidate-conditioned queries, then mixes sequence, retrieval, feature and candidate tokens via RankMixer-style head-wise token mixing plus per-token SwiGLU; a High-Rank Attention head compresses the token bank with scenario-aware queries and Hiformer-style composite projections before task towers, and an optional user-item decoupled variant supports request-level batching. On 2.4B daily impressions, HiRank reaches Homepage AUC 0.9163 / GAUC 0.7801 vs 0.9154 / 0.7592 for OneTrans (best baseline) and 0.9136 / 0.7294 for the DCNv2+DIN production baseline, with the best PCOC, at 299M dense params; sequence length is the most effective scaling axis (T=96: +0.23pp AUC). A Taobao Homepage A/B test showed +2.27% orders per user (p<0.01), +2.86% GMV per user and +2.13% daily purchasers.
