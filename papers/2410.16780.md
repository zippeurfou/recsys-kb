## Summary

This paper introduces a new dataset, REGEN, which enriches Amazon reviews with user narratives to evaluate natural language generation in conversational recommendation systems. It also proposes a fusion architecture combining collaborative filtering (CF) embeddings and item content data as the first model specifically designed for this narrative generation task within recommenders. Experiments show that using both CF and content embeddings together significantly improves LLM-generated recommendations, achieving performance gains of 4-12% over individual approaches on their new benchmarks.

## Technical note

Moves conversational recommender systems beyond retrieval toward generating natural-language narratives, and releases REGEN, a dataset enriching Amazon reviews with user narratives to evaluate narrative generation. It proposes a fusion architecture that combines collaborative-filtering embeddings with item content data, presented as the first model designed for narrative generation within recommenders. Experiments show that jointly using CF and content embeddings significantly improves LLM-generated recommendations, with 4-12% gains over individual approaches on the new benchmarks.
