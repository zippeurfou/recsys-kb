## Summary

1.  The paper introduces a new task called Instruction-Following Table Retrieval (IFTR), moving beyond traditional topic-based table retrieval to an approach driven by specific user instructions and requiring adherence to content and schema constraints.
2.  To evaluate this new task, the authors created the FollowTable benchmark, the first large-scale dataset for IFTR, along with a new metric, the Instruction Responsiveness Score, to measure how well retrieval models follow instructions.
3.  Their evaluation shows that existing retrieval models struggle significantly with IFTR, often prioritizing surface-level topics over explicit instruction details and failing to properly handle schema-based requirements.

## Technical note

The paper defines Instruction-Following Table Retrieval (IFTR), extending traditional topic-based table retrieval to retrieval driven by explicit user instructions that impose content and schema constraints. To evaluate IFTR it introduces FollowTable, described as the first large-scale IFTR benchmark, together with an Instruction Responsiveness Score metric measuring how well retrieval models actually adhere to instructions rather than surface topic. Benchmarking existing retrieval models shows they struggle with IFTR, tending to prioritize surface-level topical similarity over instruction details and failing to properly satisfy schema-based requirements. The work frames instruction adherence and schema constraint satisfaction as key open challenges for table retrieval systems.
