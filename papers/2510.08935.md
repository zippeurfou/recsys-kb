## Summary

Current retrieval methods for AI assistants often use uniform query expansion, failing to capture user-specific intent and expression styles, which limits personalization. This paper introduces the Personalize Before Retrieve (PBR) framework, which generates personalized query representations using user history (P-PRF) and adapts the query structure to the user's data (P-Anchor) before retrieval. Experiments demonstrate that PBR significantly improves retrieval performance on personalized benchmarks, achieving up to 10% gains compared to standard methods.

## Technical note

Personalize Before Retrieve (PBR) injects user-specific signals into query expansion prior to retrieval for personalized RAG, arguing that identical queries carry different intent across users. It has two components: P-PRF, which extracts a user's linguistic/expression style from history to generate stylistically aligned pseudo-relevance-feedback utterances and reasoning paths, and P-Anchor, which encodes user history as a semantic graph and applies personalized PageRank to find anchor points that ground the expanded query in the user's corpus structure. Combining stylistic and structural personalization produces query representations aligned to individual intent and corpus heterogeneity. On two personalized benchmarks PBR outperforms strong baselines, with up to 10% gains on PersonaBench across retrievers.
