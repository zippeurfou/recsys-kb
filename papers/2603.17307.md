## Technical note

Symphony is a cognitively-inspired centralized multi-agent system for long-form video understanding (LVU), where MLLM agents degrade on high-information-density, long-temporal-span tasks. It decomposes LVU into fine-grained subtasks via a planning agent that delegates to dedicated agents with iterative evidence accumulation, a reflection agent that decides whether to answer or refine the reasoning chain, and a grounding agent combining an LLM for query decomposition/intent recognition with a VLM to assess video-query relevance. Symphony reaches state-of-the-art on LVBench, LongVideoBench, VideoMME and MLVU, with a 5.0% improvement over the prior SOTA on LVBench. Note: this is a video-understanding/agent paper, only loosely related to recsys.
