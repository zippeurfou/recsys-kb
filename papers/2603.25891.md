## Summary

This paper introduces the FSIR-BD dataset and the FSIR task, addressing the limitations of current vision-language models in handling complex, out-of-distribution text queries for image retrieval. The benchmark features 38k images and focuses on challenging compositional and OOD retrieval scenarios. To tackle these challenges, the authors propose two optimization methods that use reference examples to significantly improve retrieval accuracy, measured by higher mean Average Precision (mAP), and are compatible with existing pre-trained models.

## Technical note

The paper defines the Few-Shot Text-to-Image Retrieval (FSIR) task, where a few reference exemplars refine a text query, and releases FSIR-BD (38,353 images, 303 queries) targeting compositional and OOD retrieval with many positives and hard negatives per query. Two encoder-agnostic optimization methods are proposed: FSIR-PL, a multimodal prompt-learning approach that generates query-specific prompts from few-shot examples using a fixed CLIP text/image encoder, and FSIR-CTR, which uses an MLLM to align generated search embeddings to an external image encoder's latent space. Both leave the pre-trained encoder intact—avoiding catastrophic forgetting and re-encoding of stored image vectors—and improve mAP over baselines. The design exploits the asymmetry between a lightweight dual-encoder ingestion phase and a heavier MLLM search phase in production cloud image-management deployments.
