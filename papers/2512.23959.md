## Summary

1.  Existing multi-step RAG systems use memory modules to store facts, but these are often static and fail to effectively capture complex relationships between facts, limiting their ability to support deep reasoning across multiple steps.
2.  To overcome this limitation, the paper introduces HGMem, a hypergraph-based memory mechanism that dynamically represents facts and their relationships, allowing for the progressive formation of complex interactions and connections relevant to the current reasoning task.
3.  HGMem significantly improves multi-step RAG performance, as shown by extensive experiments on challenging datasets, consistently outperforming strong baseline systems by providing a richer, evolving knowledge structure for the LLM.

## Technical note

HGMem is a hypergraph-based working memory system for multi-step retrieval-augmented generation that moves memory from passive fact storage to a dynamic structure supporting complex relational reasoning. Memory is a hypergraph whose hyperedges are memory units capturing distinct perspectives; starting from low-order primitive facts, high-order n-ary correlations progressively emerge via update, insertion, and merging operations as the LLM interacts. At each step the LLM inspects current memory to generate subqueries for local investigation or global exploration, retrieving evidence through graph indexing and vector matching. On global sense-making benchmarks HGMem consistently beats strong multi-step RAG baselines, with a Qwen2.5-32B variant matching or exceeding GPT-4o-based baselines.
