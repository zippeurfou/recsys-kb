## Technical note

CASE (Cadence-Aware Set Encoding) addresses next-basket repurchase recommendation where basket-index sequence models cannot represent elapsed calendar time or refresh scores between purchases. It encodes each item's history as a binary T-day calendar signal, applies shared multi-scale Conv1d filters (weekly/biweekly/monthly/seasonal/trend) to learn population-wide cadence embeddings, and models cross-item dependencies with Induced Set Attention Blocks (ISAB) at O(nK) instead of O(n^2), needing no per-user parameters. Across three public benchmarks and a proprietary dataset it improves precision/recall/NDCG, and in production over tens of millions of users achieves up to 8.6% relative precision and 9.9% recall lift at top-5.
