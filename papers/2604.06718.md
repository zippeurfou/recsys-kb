## Summary

Cadence-Aware Set Encoding for Large-Scale Next Basket Repurchase Recommendation":

1.  Existing next-basket recommendation models often fail to account for the distinct purchase timing patterns (item-specific cadences) between user visits, limiting their accuracy.
2.  The paper introduces CASE, a system that models each item's historical purchase rhythm as a calendar-time signal and efficiently captures cross-item dependencies using set attention, decoupling these two aspects.
3.  CASE consistently improves recommendation metrics like Precision, Recall, and NDCG across benchmarks and achieves significant production-scale performance gains, demonstrating the value of explicitly modeling purchase cadences.

## Technical note

CASE (Cadence-Aware Set Encoding) targets next-basket repurchase recommendation by representing each item's history as a binary T-day calendar-time signal instead of basket-index sequences, so predictions can reflect elapsed time and item-specific replenishment cadence. Shared multi-scale Conv1d filters at weekly/biweekly/monthly/seasonal/trend kernels (non-overlapping strides) learn population-wide recurring patterns, and Induced Set Attention Blocks (ISAB) model cross-item dependencies at O(nK) rather than O(n^2), avoiding per-user parameters and TIFUKNN-style user-to-user retrieval. Across TaFeng, DC, Instacart, and a proprietary grocery dataset CASE matches or beats TIFUKNN, DNNTSP, BERT4NBR, and PIETSP, with the largest gains in sparse settings; ablation shows the temporal CNN is the dominant component. Production evaluation on tens of millions of users yielded up to +8.6% precision and +9.9% recall at top-5 over a deployed LTR model.
