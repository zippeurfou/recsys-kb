## Summary

This paper presents a method for enhancing Pinterest Ads recommendation by integrating both onsite user activity graphs and opt-in offsite conversion data into a single large-scale heterogeneous graph representation.

A novel Knowledge Graph Embedding (KGE) model called TransRA was developed to efficiently learn embeddings from this combined graph structure. However, directly incorporating the standard KGE output into existing Ads models proved difficult initially.

To overcome integration challenges, two key innovations were introduced: a Large ID Embedding Table technique and an attention-based finetuning approach for KGE vectors within the Ad ranking system. These techniques led to significant offline performance gains measured by AUC lifts, and upon deployment resulted in a substantial 2.69% increase in Click-Through Rate (CTR) while improving overall ad efficiency.

## Technical note

The paper builds a billion-scale heterogeneous graph over Pinterest onsite ad engagement and opt-in offsite conversions to learn entity representations for offsite entities that lack reliable metadata. It introduces TransRA (TransR with Anchors), a translation-based KGE that designates one entity space as an anchor so non-anchor spaces transform into it, easing downstream integration versus TransE (near-zero metrics) and plain TransR (separate spaces). To inject KGE into tabular ranking models, pretrained embeddings are loaded into large ID embedding tables and fine-tuned with a self-attention layer over looked-up embeddings to mimic graph interactions. Deployed in Pinterest's Ads Engagement Model, it delivered a 2.69% CTR lift and 1.34% CPC reduction.
