## Summary

This paper argues that long-horizon agentic tasks (like code generation or scientific discovery) produce structured "experience graphs" containing artifacts, tool outputs, rewards, comparisons, and causal lineage. Current systems treat this experience as disposable state, but the authors propose Trellis: a database foundation that treats the experience graph itself as first-class data objects with queryable access patterns. By doing so, Trellis enables agents to become "stateless compute," providing benefits like crash recovery, horizontal scaling for parallel execution, and allowing agent training loops to use the experience graphs themselves as reusable training data.

## Technical note

Trellis (Meta) argues long-horizon agentic search produces a structured 'experience graph'—executable artifacts, tool outputs, objective rewards, sibling comparisons, mutable search statistics, and causal lineage—that current frameworks discard as ephemeral JSON logs. The core insight is that search over experience graphs is a database access pattern: frontier selection is a query, cross-session reuse is vector-seeded graph retrieval, training-data extraction is a materialized view, and reconstructing past agent state is a time-travel query. Making the experience graph first-class, governed, queryable state turns agents into stateless/serverless compute, so crash recovery, horizontal scaling, and a closed-loop training flywheel emerge as byproducts. Grounded in KernelEvolve (MCTS + evolutionary kernel optimization), cross-session reuse reaches target speedups ~10x faster at 52% lower token cost per valid solution.
