## Technical note

DrunkAgent is the first black-box adversarial attack targeting the memory module of LLM-powered recommender agents. It crafts low-perplexity adversarial textual triggers embedded in target-item descriptions and corrupts agents' memory updates during interaction, optimizing triggers and strategies on a surrogate agentic RS for transferability and stealthiness. Experiments across agentic RSs built on collaborative filtering, retrieval augmentation, and sequential recommendation show DrunkAgent promotes target items and outperforms state-of-the-art black-box attacks while evading defenses. The work exposes the agent memory as a critical, previously underexplored attack surface.
