## Summary

This paper explores vulnerabilities in Agent4RSs (recommender systems using large language model-based agents with memory). It introduces DrunkAgent, a novel attack framework that generates textual triggers to manipulate agent memories and disrupt their learning. The goal is to uncover these limitations by proposing practical attacks under black-box conditions, ultimately providing insights for building safer and more resilient AI recommender systems.

## Technical note

The paper presents the first systematic study of memory-based vulnerabilities in LLM-powered agentic recommender systems and proposes DrunkAgent, a black-box attack that promotes a target item by corrupting the item agent's evolving memory. It crafts low-perplexity adversarial description triggers via a greedy search algorithm and a strategy module (fake task responses, context switching, malicious task injection) that prevents the target agent from updating its memory, all optimized on a surrogate agentic RS for transferability. Across AgentCF, AgentRAG, and AgentSEQ on Amazon and Yelp data, DrunkAgent greatly outperforms character/word/sentence-level attack baselines in hit ratio and NDCG while remaining stealthy under perplexity metrics. It also resists paraphrasing defenses, exposing blind spots in current countermeasures.
