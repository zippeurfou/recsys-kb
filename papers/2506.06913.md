## Technical note

OneSug (Kuaishou) is the first end-to-end generative framework for e-commerce query suggestion, replacing the recall/pre-ranking/ranking multi-stage cascade. It has a Prefix2query Representation Enhancement module that enriches short ambiguous prefixes using RQ-VAE hierarchical semantic codes over related queries, a unified encoder-decoder generative model, and a Reward-Weighted Ranking strategy that extends DPO from pairwise to list-wise over six behavior-level interaction weights. Deployed on full Kuaishou e-commerce search traffic for over a month, it improved user top click position (-9.33%), CTR (+2.01%), Order (+2.04%), and Revenue (+1.69%) while cutting system response time ~43% versus the online multi-stage baseline.
