## Summary

This paper introduces an LLM-based framework for generating natural language, real-time user interest personas directly on a billion-user scale commercial video platform. The core novelty lies in dynamically combining existing interests with novel topics during serving to address the exploration-exploitation trade-off and improve semantic understanding compared to traditional methods using structured IDs or offline processing. By employing knowledge distillation, asynchronous inference, and input optimization via clustered representations, the system overcomes high LLM inference costs. Evaluations show significant improvements in viewer value metrics through enhanced recommendations and user-facing explainability.

## Technical note

This paper presents a real-time LLM-based user-understanding service for a billion-user commercial video recommendation platform, generating natural-language user interest personas that combine summarized existing interests (exploitation) with novel related topics (exploration) to counter feedback-loop narrowing. It adopts a hierarchical planning paradigm: an LLM produces a high-level language policy (textual next-interest description) and a transformer sequential model plus restricted nearest-neighbor search grounds it in item space, confining candidate exposure to items semantically related to the generated interests. User histories are structured via Infinite Concept Personalized Clustering over salient-term embeddings, which outperforms perceptual embedding clusters for persona quality. To meet latency and cost budgets, a large teacher (Gemini 1.5 Pro) is distilled into an efficient student, served asynchronously with quantization. A/B tests show significant viewer-value gains.
