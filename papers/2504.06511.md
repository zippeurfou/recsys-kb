## Technical note

GTS-LUM is Huawei's large user-behavior model for telecommunications, using a multi-modal encoder-adapter-LLM-decoder architecture to model long-term, periodic user sequences with heterogeneous labels (churn, package upgrades/downgrades, campaign acceptance). It adds telecom-specific innovations: a timestamp method dividing days into semantic-text intervals plus fine-grained marks, multi-modal encoders for tables and behavior co-occurrence graphs aligned to spectral-clustering semantic tokens via a Q-former (trained with sequence-text matching, contrastive, and grounded-generation tasks), and a front-placed target-aware mechanism (unlike HSTU's interleaving). Experiments on an industrial dataset show GTS-LUM outperforms popular LLM4Rec approaches.
