## Summary

This paper introduces GTS-LUM, a novel end-to-end framework designed specifically for modeling complex user behavior sequences in the telecommunications industry. Its core innovation is an architecture integrating multimodal data inputs (tables and graphs) with large language models (LLMs), featuring specialized components like advanced timestamp processing to handle varying time granularities.

GTS-LUM's structure uses a tokenizer enhanced by Q-former, coupled with an encoder-adapter-LLM decoder setup. It uniquely incorporates a front-placed target-aware mechanism that prioritizes relevant historical behaviors for the prediction task at hand.

Extensive experiments on real telecom data demonstrate GTS-LUM's effectiveness significantly surpassing standard LLM4Rec approaches, providing a powerful and generalizable solution for user behavior analysis crucial for package design and marketing.

## Technical note

GTS-LUM is an end-to-end user-behavior model for the telecom industry that adapts the LLM4Rec paradigm to long-term, periodic behavior sequences with diverse time granularities, multimodal inputs, and heterogeneous targets (churn, plan upgrades/downgrades, campaign acceptance). It uses an encoder-adapter-LLM-decoder architecture with a telecom-specific timestamp process that partitions days into semantically labeled intervals, generates behavior semantic IDs via text-embedding spectral clustering, and encodes tabular and co-occurrence-graph data (TableGPT2, Node2Vec). A Q-former aligns and fuses semantic tokens with business/multimodal embeddings (trained with contrastive, matching, and generation tasks at both behavior and sequence level), and a front-placed target-aware mechanism positions the target at the start of the sequence so causal attention iteratively refines the user embedding. On an industrial dataset GTS-LUM outperforms popular LLM4Rec approaches.
