## Technical note

LongRetriever brings ultra-long (lifelong) user behavior sequences into the retrieval stage, which prior work mostly used only for ranking. It defines mutually exclusive item categories as interpretable interests, uses a search-based mechanism to filter relevant subsequences per interest, and represents users as multiple dense vectors under shared parameters. Novel in-context training and multi-context serving inject user-candidate interaction and ensure training-serving consistency under the search-based paradigm. Deployed on a billion-user e-commerce platform, online A/B tests show statistically significant gains.
