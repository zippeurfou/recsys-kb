## Summary

This paper addresses challenges faced by recommendation systems due to difficulties incorporating diverse contextual signals into their ranking pipelines. It introduces a novel LLM-powered agentic system designed for Connected TV content discovery that leverages large language models' reasoning capabilities to naturally process various inputs without manual integration.

Recognizing limitations of pure LLM solutions in areas like retrieval efficiency, personalization precision, and scalability (especially inference latency), the authors adopted an agentic architecture. This hybrid approach orchestrates specialized components optimized for specific sub-tasks within the recommendation pipeline, combining the flexibility of LLMs with traditional ML techniques.

The main contribution is their engineering methodology demonstrating how to successfully overcome these practical limitations, particularly concerning LLM inference speed, paving the way for more effective CTV recommendations by intelligently integrating different methods.

## Technical note

To incorporate heterogeneous, unstructured context (trending events, breaking news, cross-surface activity) that fixed-schema multi-stage and unified generative recommenders cannot handle, this Connected-TV system uses an LLM-agentic architecture: an orchestrator coordinates a topic retrieval agent (instruction-tuned Llama-3 70B), a media retrieval-and-ranking agent, and a topic ranking agent, letting LLMs do contextual reasoning while a traditional multi-task multi-label (MTML) model handles latency-sensitive late-stage ranking. The retrieval component, MediaBrain, is a Llama-3.2-1B generative retrieval model that maps natural-language topics to media via 4-layer semantic IDs (RQ-kMeans, codebook size 1024) using beam search plus prefix lookup. The engineering focus is inference latency: removing LLM inference from the critical path via async per-component caching and cursor-anchored token persistence, plus vLLM/beam-search fixes that raise throughput from 2 to 200 QPS per A100 (100x speedup) at neutral user-facing latency. MediaBrain niche-entity relevance improved from 0.15 to 0.50 across data iterations, and SID-topic dispersion (HHI) correlated 0.25 (Spearman) with relevance, exposing an SID bottleneck for fine-grained concepts.
