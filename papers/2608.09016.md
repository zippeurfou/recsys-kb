## Summary

Node ranking, crucial for graph-based applications like influence analysis and recommendations, requires scalable solutions due to prohibitive computation costs of exact methods. Existing Graph Neural Network approaches either need task-specific retraining or have pre-trained models misaligned with ranking objectives, limiting transferability and efficiency. The authors propose PreGress, a novel framework combining native pre-training (using degree centrality prediction and attribute reconstruction) with prompting modules, to create a frozen backbone model adaptable across diverse node ranking tasks without full retraining on each task-specific dataset or criterion.

## Technical note

Huawei's PreGress is a ranking-native pre-training and prompting framework for node ranking: instead of retraining a GNN per ranking criterion, it extracts 2-hop ego networks, pre-trains a 5-layer subgraph neural network (sum pooling, 128-d output) on two label-free continuous objectives -- degree centrality prediction via a self-attention head and masked node-attribute reconstruction via a cross-attention head -- then freezes the backbone and adapts with lightweight task-specific prompts (a learnable vector for betweenness, a 3-layer prompt GNN over the pattern graph for local subgraph counting) plus a shared projection head. Across six graphs (web-spam, indochina-2004, brightkite, socfb-OR, Flickr, youtube) it gives the best or near-best NDCG@10/20 on betweenness (e.g. Flickr 0.6667/0.5737 vs 0.5902/0.5054 for SimGRACE and ~0.10-0.18 for vanilla GCN/GAT/GraphSAGE/GIN) and on local subgraph counting (youtube 0.2275/0.2254 vs 0.1597/0.1589 for the exact DISC engine), and transfers to link prediction (best MRR on all six, e.g. socfb-OR 0.748 vs 0.689 AdapterGNN). On a real query-to-item recommendation test, PreGress-CNA matches SimGCL on Yelp2018 (Recall@20 0.0636 vs 0.0638, NDCG@20 0.0523 vs 0.0524, gaps <0.30%) while tuning 4,417 parameters in 8.94s versus 4.46M parameters and 349.42s -- 99.9% less trainable state and a 39.1x downstream-training speedup -- but the authors report a negative boundary on MovieLens, where identity pre-training (PreGress-ID, 0.7474 Recall@20) is needed and PreGress-CNA is statistically indistinguishable from LightGCN (p=0.633). Ablations show prompt tuning, the subgraph backbone, and ego-net extraction are each necessary, and node-level pretext tasks (PageRank, eigenvector, k-core, degree) beat link prediction as pre-training signal.
