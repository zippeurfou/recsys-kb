## Technical note

UniRec closes the expressive gap between generative recommendation (autoregressive decoding over Semantic IDs without item-side signal) and discriminative models (direct feature access) via Chain-of-Attribute (CoA), which prefixes each SID sequence with structured attribute tokens (category, seller, brand) before decoding, recovering user-item feature crossing and yielding per-step entropy reduction that stabilizes beam search. It adds exposure-weighted capacity penalties in residual quantization to suppress token collapse/Matthew effect, and a Conditional Decoding Context (Task-Conditioned BOS plus hash-based content summaries), aligned to business goals via joint RFT and DPO. UniRec beats the strongest baseline by +22.6% HR@50 (+15.5% on high-value orders), with significant PVCTR gains in Shopee A/B tests.
