## Summary

1.  Semi-structured documents, containing diverse elements like tables and text, pose challenges for natural language question answering due to issues like fragmented OCR output, difficulties capturing hierarchical structure and layout, and the need to align scattered information.
2.  To address these challenges, the authors propose MoDora, an LLM-powered system that converts OCR elements into layout-aware components, models their hierarchical relationships and layout differences using a Component-Correlation Tree (CCTree), and retrieves relevant information efficiently.
3.  Experiments show MoDora significantly outperforms existing methods (by 5.97%-61.07% in accuracy), demonstrating its effectiveness in analyzing complex semi-structured documents and answering questions over them.

## Technical note

MoDora is an LLM-powered system for natural-language question answering over semi-structured documents (tables, charts, hierarchical text in irregular layouts). It uses a local-alignment aggregation strategy to convert fragmented OCR elements into self-contained, layout-aware components, extracting semantic triples for non-text elements and detecting title hierarchies. It builds a Component-Correlation Tree (CCTree) via bottom-up cascade summarization to model inter-component relations and layout distinctions (e.g., sidebars vs. main content). A question-type-aware retrieval mechanism combines layout-based grid partitioning for location queries with LLM-guided pruning and embedding fallback for semantic queries, plus an LLM verifier. It reports 5.97%-61.07% accuracy gains over baselines. This is document-QA/RAG, not recommendation.
