## Summary

Linear attention LLMs use a state matrix to compress context, but its runtime dynamics were previously unclear. This study discovers "State Rank Stratification," where attention heads split into consistently low-rank and high-rank groups during inference, regardless of input. Crucially, low-rank heads are essential for reasoning, while high-rank heads are functionally redundant, leading to the authors proposing "Joint Rank-Norm Pruning" which significantly reduces KV-cache overhead without harming model accuracy.

## Technical note

This study analyzes the runtime dynamics of the fixed-size state matrix in linear-attention LLMs (e.g. Qwen3-Next) and uncovers 'State Rank Stratification': heads bifurcate into stable low-rank and high-rank groups that are an intrinsic pre-training property, invariant across time and input data. Diagnostic probes show low-rank heads are indispensable for reasoning and long-context retrieval while saturated high-rank heads are largely redundant, with theory explaining rank saturation and norm accumulation. Leveraging this, Joint Rank-Norm Pruning is a training-free, zero-shot strategy that prunes redundant high-rank heads for a 38.9% KV-cache overhead reduction while maintaining accuracy.
