Traditional ID-based recommender systems often struggle with cold-start and generalization challenges. Multimodal recommendation systems, which leverage textual and visual data, offer a promising solution to mitigate these issues. ## Technical note

LEMUR (ByteDance) is presented as the first large-scale multimodal recommender trained end-to-end from raw data, jointly optimizing multimodal and recommendation components to fix the misalignment of the standard two-stage paradigm (pretrain multimodal, then use frozen embeddings). To make constructing multimodal sequential representations from user history tractable, it introduces a memory bank that incrementally accumulates historical multimodal representations during training, enabling real-time parameter updates. After one month in Douyin Search it reduced query change rate decay by 0.843% and improved QAUC by 0.81%, with additional offline gains for Douyin Advertisement, validating end-to-end multimodal recommendation industrially.
