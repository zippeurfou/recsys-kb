## Summary

Plug-and-Play Memory for Time Series Foundation Models":

1.  Time Series Foundation Models (TSFMs) are powerful but hard to adapt to new data distributions (distribution shift) without facing trade-offs between catastrophic forgetting (parametric adaptation) or high latency (non-parametric retrieval).
2.  The paper introduces TS-Memory, a lightweight memory adapter that augments frozen TSFMs, addressing this challenge by distilling knowledge from a confidence-aware kNN teacher into the memory via confidence-gated supervision during pre-training.
3.  TS-Memory achieves significant improvements in forecasting accuracy across different TSFMs and benchmarks, while enabling constant-time inference comparable to just using the frozen backbone model.

## Technical note

TS-Memory introduces Parametric Memory Distillation to adapt frozen Time Series Foundation Models under distribution shift without the forgetting of fine-tuning or the latency of retrieval. In an offline stage it builds a retrieval-leakage-safe kNN teacher that aggregates retrieved future trajectories into confidence-aware quantile targets. A lightweight parametric memory adapter is then trained to predict these teacher quantiles from input context via confidence-gated distillation that transfers knowledge only when retrieval is reliable. At inference the memory fuses with the backbone forecast by linear interpolation at constant O(1) overhead, keeping the backbone frozen. It improves point and probabilistic forecasting across TSFMs while matching backbone-only latency.
