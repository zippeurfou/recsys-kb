## Technical note

TADT-CSA (Kuaishou) is a lightweight generative-recommendation model based on the Decision Transformer for sequential recommendation, addressing DT's poor trajectory stitching and hard-to-learn state representations in huge sparse recommendation state spaces. It augments the Return-To-Go signal with a novel Temporal Advantage (TA) signal capturing sequential return trends and adds a pairwise ranking loss to escape pure behavior cloning. A Contrastive State Abstraction module with TA-conditioned State Vector Quantization (codebooks) plus reward-prediction and contrastive-transition-prediction networks learns expressive states preserving reward and transition information. Offline, online-simulation, and online A/B tests show it outperforms baselines.
