## Summary

This paper introduces **Agent4SR**, a novel framework for low-knowledge shilling attacks on recommender systems (RS) that utilizes Large Language Models (LLMs). Unlike traditional methods often relying on heuristics or internal data, Agent4SR creates realistic fake user profiles and generates both ratings and reviews to manipulate the system without deep RS knowledge. The authors demonstrate through extensive experiments that their LLM-based approach significantly outperforms existing low-knowledge baselines in effectiveness and stealth, revealing a new threat amplified by advanced text generation capabilities for shilling attacks.

## Technical note

Agent4SR is a low-knowledge shilling-attack framework that uses LLM-based user agents to manipulate recommender systems through both ratings and reviews, without needing internal RS data unlike GAN-based attacks. Each fake agent has a profile module that infers and validates personality traits from the target item with diversity mechanisms, a memory module using relevance- and recency-aware hybrid retrieval, and an action module that assigns ratings and crafts reviews via a target-feature-propagation strategy spreading target-item features across unrelated reviews to amplify manipulation. Across multiple datasets and RS architectures, Agent4SR outperforms existing low-knowledge attacks in effectiveness and stealth, resisting detection, and reveals an emergent LLM-agent threat class requiring stronger defenses.
