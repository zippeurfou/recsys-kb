## Technical note

SearchLLM is presented as the first LLM for open-ended generative search on large content platforms (deployed in RedNote's AI search entry), moving from item-centric ranking to grounded answer synthesis under noisy retrieval and strict safety. It uses a hierarchical multi-dimensional reward system separating non-negotiable bottom-line constraints (factual grounding, safety, format) from behavior-optimization objectives (robustness to noisy evidence, alignment with user needs), scored by rule-based checks plus human-calibrated LLM judges, and a Gated Aggregation Strategy feeding Group Relative Policy Optimization (GRPO). Online A/B tests increase Valid Consumption Rate by 1.03% and reduce Re-search Rate by 2.81%.

- Pointwise Evaluation: Annotators first evaluate each response independently against our bottom-line constraints, scoring specific dimensions such as factual grounding, safety, and format compliance
- Pairwise Ranking: After individual scoring, annotators perform a side-by-side comparison of candidate responses to provide holistic preference signals, which are closely correlated with the remaining reward dimensions
- Reward Training Dataset ($\mathcal{D}_{\text{RM-Train}}$): Comprising 40,000 samples, this dataset facilitates the calibration of our hybrid evaluation stack and the training of baseline reward modeling methods. Constructed via stratified sampling of random logs and ”hard samples” (historical failure cases), it adopts distinct formats: pairwise comparisons $\{(x,y_{w},y_{l})\}$ for subjective preference criteria, and pointwise instances $\{(x,y,s)\}$ with binary expert labels ($s\in\{0,1\}$) for objective constraints
- Dimension-Specific Test Set ($\mathcal{D}_{\text{Eval-Dim}}$): Designed to address RQ1, this held-out diagnostic set features samples explicitly tagged with specific quality issues (e.g., hallucination, formatting errors). Containing 800 to 3,600 examples per dimension, it allows us to evaluate the alignment with human judgment on individual criteria
- Holistic Preference Test Set ($\mathcal{D}_{\text{Eval-Holistic}}$): Also serving RQ1, this dataset comprises 2,800 pairwise comparisons sourced from historical model checkpoints and human writing. It utilizes general ”win/loss” labels to assess the holistic preference alignment of the reward system
- RL Optimization Dataset ($\mathcal{D}_{\text{RL}}$): Comprising 500,000 unlabeled tuples $(q,h,E)$, this dataset supports policy optimization (RQ2–4). The training set mixes random traffic with user complaint queries to enhance robustness
- Accuracy (ACC): Measures the agreement between reward signals and expert labels on binary constraint reward dimensions (e.g., Factuality, Format Compliance)
- Area Under the Curve (AUC): Evaluates the pairwise ranking capability on subjective preference dimensions (e.g., Richness, Usability). Given $N$ pairs $(y_{w},y_{l})$ where $y_{w}$ is the preferred response, and reward score $s(\cdot)$, the AUC is computed as:
- Valid Consumption Rate (VCR): The percentage of sessions where users dwell on the generated answer for a meaningful duration ($>5$s), indicating high utility
- Skip Rate (SR): The percentage of sessions where the answer is scrolled past immediately ($<1.5$s), serving as a proxy for irrelevance or poor formatting
- Re-search Rate (RR): The frequency with which users issue a reformulated query immediately after viewing the result, indicating dissatisfaction
- Bad Case Rate (BCR): The percentage of responses containing severe bottom-line violations (e.g., safety risks, obvious hallucinations). This metric is estimated via a daily human audit of sampled logs (arXiv:2603.10473)
