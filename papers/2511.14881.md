## Technical note

SilverTorch (Meta) is a unified model-based GPU serving system for large-scale DLRM retrieval that replaces standalone CPU ANN indexing and feature-filtering services with model layers. It introduces a model-based GPU Bloom index for feature filtering and a fused Int8 ANN kernel for nearest-neighbor search, co-designing ANN search with filtering to cut GPU memory and eliminate redundant computation, and adds an OverArch scoring layer plus multi-task retrieval with a Value Model to support complex learned similarities. On industry-scale datasets it achieves up to 23.7x higher throughput than state-of-the-art and is 13.35x more cost-efficient than CPU-based solutions while improving accuracy via serving more complex models.
