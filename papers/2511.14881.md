## Summary

1.  Existing recommendation systems using CPU-based services for item retrieval are inefficient and struggle with complex models. To address this, the paper introduces SilverTorch, a GPU-based system that unifies model serving by incorporating indexing and filtering directly into the recommendation model layers.
2.  SilverTorch replaces CPU-based services with dedicated GPU layers, including a Bloom filter algorithm for efficient feature filtering and a specialized Int8 ANN search kernel for fast nearest neighbor lookups, while co-designing these components to optimize memory usage and computation.
3.  This approach significantly boosts performance, achieving lower latency and higher throughput compared to existing methods, while being more cost-effective than CPU-based solutions. It also supports complex model architectures and is deployed at scale in production.

## Technical note

The paper targets efficient large-scale DLRM retrieval serving, where CPU-based ANN indexing and feature-filtering services are costly, hard to co-design, and cause versioning inconsistencies. It presents SilverTorch, a PyTorch model-based system that redefines ANN search and filtering as in-model GPU tensor layers, introducing a GPU Bloom index for feature filtering, a fused Int8 IVF ANN kernel, and a co-designed index that fuses the two to cut GPU memory and computation. On top it adds an OverArch learned-similarity re-ranking layer and multi-task Value Model with cached item embeddings. On 10M- and 80M-item industry datasets it reaches up to 23.7x higher throughput, >5.6% recall gains, and 13.35x better cost efficiency than CPU baselines.
