## Summary

During cold-start recommendations, new items lack collaborative data, leading to the "Matthew effect" (popular items get better recommendations). Existing methods struggle to balance semantic information (useful for new items) and collaborative signals (better for popular items). The paper introduces GateSID, a framework using an adaptive gating network to dynamically balance these signals based on item maturity, improving recommendations for cold-start items while preserving accuracy for popular ones, as validated by extensive experiments.

## Technical note

GateSID addresses the collaborative-semantic trade-off in cold-start recommendation, where collaborative signals help popular items but degrade on new items (worsening the Matthew effect) while over-reliance on semantics erases behavioral differences. It discretizes Qwen-VL multimodal embeddings into hierarchical Semantic IDs via a 4-layer RQ-VAE (codebook size 256), then applies Gating-Fused Shared Attention: a gating network produces item-level weight w from item embeddings and statistical features (exposure, clicks, online duration) to fuse intra-modal SID and collaborative attention distributions. Gate-Regulated Contrastive Alignment uses the gate weights to enforce stronger semantic-behavior alignment for cold-start items while relaxing constraints for popular items. Online A/B tests report GMV +2.6%, CTR +1.1%, and Order +1.6% with under 5 ms added latency.
