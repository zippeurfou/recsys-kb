## Summary

Modern recommender systems are often optimized manually by engineers, which is slow and lacks accumulated expertise. LLM-based agents automate some parts but don't retain methodology or explore new structural ideas effectively. The EvoRec framework addresses this by using multiple agents to co-evolve the recommendation model itself alongside its optimization techniques, improving both offline metrics and online revenue through A/B testing.

## Technical note

EvoRec is a multi-agent framework that co-evolves both the recommendation model and its optimization methodology. Four collaborating agents (Orchestrator, Research Agent, Code Agent, Skill Evolver) run a dual-track loop: per-round model edits plus periodic distillation of reusable 'skills' from a persistent Memory of past experiments. On a public benchmark and one large industrial dataset it improves offline metrics by up to 5.54% over the strongest baseline, and an online A/B test delivers a 1.85% revenue lift and 1.02% CTR gain.
