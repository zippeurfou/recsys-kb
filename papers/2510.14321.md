## Summary

(Abstract fallback)

In modern e-commerce search systems, dense retrieval has become an indispensable component. By computing similarities between query and item (product) embeddings, it efficiently selects candidate products from large-scale repositories. With the breakthroughs in large language models (LLMs), mainstream embedding models have gradually shifted from BERT to LLMs for more accurate text modeling. ## Technical note

LREM (Large Reasoning Embedding Model) (Taobao/Alibaba) integrates explicit reasoning into representation learning for e-commerce dense retrieval, addressing direct-embedding LLM retrievers that rely on contrastive learning and fail on difficult queries with lexical disparity from target items. For difficult queries, LREM first generates a compact chain-of-thought (keyword list) to deeply understand the query, then produces a reasoning-augmented query embedding bridging the query-item semantic gap. Training is two-stage: SFT + InfoNCE on ~75M Query-CoT-Item triplets, then RL to refine reasoning trajectories. It is deployed on China's largest e-commerce platform since August 2025.
