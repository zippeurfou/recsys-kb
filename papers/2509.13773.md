## Technical note

MIRA (Huawei) is a framework for task-instruction recommendation enabling one-touch AI tasking on smartphones, where users long-press an image or text object to get contextually relevant instructions. It combines an MLLM-based pipeline with structured reasoning to extract entities, infer user intent, and generate instructions; a template-augmented reasoning mechanism that integrates high-level reasoning templates; and a prefix-tree-based constrained decoding strategy restricting outputs to predefined instruction candidates. Real-world annotated datasets and a user study show substantial improvements in instruction-recommendation accuracy.
