## Summary

This paper introduces MIRA (Multimodal Instruction Recommendation Assistant), a framework designed to simplify access to generative AI tasks on smartphones by enabling users to long-press objects and receive recommended instructions directly.

MIRA's core innovation is a multimodal large language model-based system that uses structured reasoning, template augmentation for better task understanding, and constrained decoding via prefix trees to generate precise and contextually relevant instruction suggestions efficiently.

Evaluations using real-world datasets and user studies confirmed MIRA significantly improves the accuracy of these recommendations, offering users a more intuitive, seamless, and efficient way to interact with AI services through one-touch functionality.

## Technical note

MIRA is a multimodal-LLM agent for one-touch AI task instruction recommendation on smartphones, where long-pressing an image or text trigger yields contextually relevant predefined instructions. It fine-tunes MLLMs with a three-step structured chain-of-thought (entity extraction, contextual relevance, instruction generation) using teacher-forced reasoning traces, then augments inference with a retrieved reasoning-template library (~80 templates, threshold delta~0.6) to reduce hallucination, and enforces valid outputs via prefix-tree constrained decoding. On a 1000-user annotated dataset it substantially beats zero-shot and vanilla SFT (F1 up to 0.92, HR@3 up to 0.96), outperforms GPT-4V/Qwen2.5VL-Max with ~7x fewer tokens, and reaches 93-95% validity in a user study.
