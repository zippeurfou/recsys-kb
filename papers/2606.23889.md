## Summary

Intent-aware Neural Sponsored Product Retrieval for E-commerce":

1.  Walmart faces challenges in sponsored search within its large grocery ecommerce market due to short, ambiguous user queries often failing to match advertiser intent accurately.
2.  To address this, they propose INSPIRE (Intent-aware Neural Sponsored Search), a framework that converts both explicit and implicit user intent into structured product attributes for better matching with relevant food/beverage items.
3.  The system uses weak supervision via a large language model ("teacher") generating annotations, which are then distilled to train a smaller "student" LLM model within a biencoder structure to predict these intents from queries and products more effectively.

## Technical note

INSPIRE is a Walmart grocery sponsored-search retrieval framework that models structured intent (brand, flavor, dietary preference, ingredient, cuisine type, product subtype, size) for both queries and items to capture implicit signals (e.g., 'chickpea pasta' -> gluten-free). A weakly-supervised pipeline uses three teacher LLMs (Gemma3-27B, LLaMA-3.1-8B, Qwen3-8B) to generate JSON intent annotations, applies cross-model consensus (token-overlap >=0.5, embedding cosine >=0.3, retain fields agreed by >=2 models), then GPT-4.1 verification and manual spot-checks. These consensus labels distill a lightweight student LLM via LoRA-based supervised fine-tuning to predict intents at catalog scale. Predicted intents are injected into query and product representations in a bi-encoder dense retriever, improving NDCG@K and Precision@K especially for implicit-intent queries. Relevance labels for failure mining come from a cascade of Gemma-1B/2B and LLaMA-3-8B with confidence-based early exit; the student is served via a vLLM inference API for low-latency, high-throughput deployment.
