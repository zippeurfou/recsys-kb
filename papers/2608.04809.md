## Summary

1.  Existing recommendation system re-ranking approaches struggle for effectiveness gains when provided low-quality upstream sequences, failing to adapt properly due to fixed data constraints.
2.  To address this, the authors propose DEGR (Dual Exploration-Driven Generative Re-Ranking), combining supervised learning with reinforcement optimization using an adaptive exploratory reward model that balances immediate and future browsing potential.
3.  DEGR integrates three components: standard supervision, exploration diversity constraint, and adaptive reward-weighted ORPO preference learning, demonstrating significant offline and online performance improvements (up to +1.22% UCTR) compared to state-of-the-art methods in the JD E-commerce system.

## Technical note

Re-ranking is capped by fixed upstream supply, so when the candidate set is weak no permutation recovers much immediate value. DEGR (JD) argues the re-ranker should instead buy exploratory value: a JD study across 15 equal-frequency Max-pCTR buckets shows Max-pCTR correlates with sequence CTR but is essentially uncorrelated with the Next Click Ratio, so exposure depth is cheap to buy under bad supply. Its exploratory reward model takes DIN item embeddings plus sinusoidal positions through sequence self-attention, then predicts item-wise immediate value with MMoE and a sequence-level exploratory value with an MLP, trained on five behavior tiers A-E (terminate / invalid explore / potential interest / instant match / deep explore) with class-C weight boosted as w_C=(4-3*log2(1+Max-pCTR))*w_C' and class B masked when Max-pCTR<=0.01; the composite reward mixes both with position decay delta_j=1-log_{M+1}(j). The generator is an encoder-decoder (DIN + self-attention encoder, incremental decoder) with MEDUSA/MTP-style multi-head decoding cohorts predicting K positions per step (O(M) -> O(M/K)), trained with supervised learning plus an intra-cohort diversity constraint plus Adaptive Reward-weighted ORPO, which builds preference lists instead of pairs and uses rewards as soft weights (quantile S=3 best). On JD production data DEGR reaches GAUC 0.6486 / MAP@2 0.5951, with ablations giving +0.25pp MAP@2 to the exploratory reward, +0.16pp to AR-ORPO over plain ORPO and +0.11pp to the diversity constraint. A 7-day JD homepage A/B with only the generator deployed yields +1.22% UCTR and +0.20% PV (only +0.72% UCTR without the diversity constraint) at +3.2 ms TP99, versus +7.8 ms without parallel decoding.
