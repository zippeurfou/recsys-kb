## Summary

Foundation recommender models often see degraded performance when Chain-of-Thought (CoT) reasoning is added, a problem we identify as "textual inertia" where verbose reasoning dominates and neglects critical semantic ID information. We propose a training-free solution called Inference-Time Subspace Alignment, which compresses reasoning chains and uses bias-subtracted contrastive decoding to counteract this "reasoning shift". Experiments show this framework effectively allows models to leverage reasoning without sacrificing ID-grounded accuracy.

## Technical note

The paper diagnoses why enabling chain-of-thought 'thinking mode' in foundation recommender models (e.g. OpenOneRec) that predict target items as hierarchical Semantic IDs can degrade recommendation quality by up to 25%. It identifies 'Linguistic Inertia': inserting a textual CoT segment before SID generation makes the model over-rely on natural-language context and underuse historical SID evidence, an effect amplified by reduced history access and longer CoT length. The proposed fix, Linguistic-Inertia-Calibrated Decoding (LICD), is training-free and combines Reasoning-Chain Compression (distilling verbose CoT into a single structured preference statement to build an Expert context) with Bias-Subtracted Contrastive Inference (weakening history to build an Amateur context and subtracting its normalized score). Across three large-scale benchmarks LICD outperforms both no-thinking and original-thinking baselines.
