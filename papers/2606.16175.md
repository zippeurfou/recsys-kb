## Summary

This paper introduces PAL-Bench, a new benchmark for reconstructing personal profiles from complex longitudinal albums. It addresses the challenge of testing real-world profile reconstruction by creating synthetic data that carefully mimics private album structures and generates audited public records while protecting sensitive information like identity bindings. Evaluation shows significant gaps between system capabilities in summarizing owner facts versus accurately reconstructing identities, events, and citing evidence within these personal archives.

## Technical note

PAL-Bench is a controlled benchmark for evidence-grounded owner-profile and social-catalog reconstruction from longitudinal personal albums treated as weak-schema multimodal databases, where key facts require joins across faces, OCR text, timestamps, locations, and repeated events. Because complete ground truth (owner profiles, social graphs, face-name maps, evidence provenance) is exactly the private state real albums cannot release, an Evidence Compiler builds latent private worlds, programs target-level evidence paths, renders album pixels, re-measures them through perception pipelines, and exports audited public/private views so agents see only perception-derived public records. It contains 50 synthetic users, 36,659 public records, and 2,799 targets, with a 10-participant privacy-preserving audit confirming the controlled evidence structures occur in real albums. Across seven system classes, results reveal a gap between plausible profile summarization and faithful social reconstruction; the reference framework PAL-TRACE, which freezes identity bindings before owner-fact mining, performs best but leaves hard identity resolution unsolved.
