## Summary

The paper introduces **Mobile-VTON**, a privacy-preserving virtual try-on system designed to run entirely offline directly on mobile devices. To achieve this, it employs a novel **modular TGT architecture (TeacherNet-GarmentNet-TryonNet)** optimized for on-device performance, combining knowledge distillation, specialized garment processing, and efficient garment-person alignment. This framework demonstrates that high-fidelity virtual try-on matching cloud-based quality is feasible on commodity phones, offering a secure and practical alternative by eliminating the need to upload personal images.

## Technical note

Mobile-VTON is a privacy-preserving virtual try-on system that runs fully offline on commodity phones using only a person image and a garment image. Its modular TeacherNet-GarmentNet-TryonNet architecture distills a frozen Stable Diffusion 3.5 Large teacher into lightweight student U-Nets via Feature-Guided Adversarial (FGA) Distillation, combining DMD2-style score matching with an adversarial realism loss. GarmentNet uses a trajectory-consistency objective to prevent garment semantic drift across diffusion steps, and TryonNet uses latent concatenation plus a DINOv2-based Light-Adapter (IP-Adapter cross-attention) for garment-to-person alignment without large-scale pretraining. At 1024x768 it matches or beats server baselines on LPIPS, SSIM, and CLIP-I.
