## Summary

This paper introduces REGEN (Reviews Enhanced with Generative Narratives), an innovative dataset built upon Amazon reviews by adding natural language critiques and narratives specifically designed to benchmark LLM conversational recommendation capabilities. The dataset inpaints user "steering" queries and rich purchase explanations or summaries, validated through auto-rating techniques, showing its quality enhances learning over existing data. They also present the LUMEN framework using an LLM backbone for multi-tasking recommendations with critiques and narratives, demonstrating that models trained on REGEN improve recommendation quality by leveraging language understanding and achieve performance comparable to state-of-the-art methods.

## Technical note

REGEN is a dataset that augments Amazon Product Reviews with LLM-inpainted natural-language features for conversational recommendation: user critiques (steering feedback between similar adjacent items) and rich narratives (endorsements, purchase reasons, user summaries), generated by Gemini 1.5 Flash and quality-checked with an auto-rater. The authors define an end-to-end single-turn conversational task where a model must jointly produce the next-item recommendation and a consistent narrative conditioned on item history plus critiques. They propose LUMEN, a unified multi-task LLM-backbone model that integrates collaborative-filtering signals, item content, and critique inputs for critiquing, retrieval, and generation. Experiments show critiques improve recommendation quality and that LUMEN generates recommendations and narratives comparable to state-of-the-art recommenders and language models.
