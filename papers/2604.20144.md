## Summary

Complex analytical tasks performed by LLM agents require selecting the right data sources from potentially vast and semantically complex datasets, but this selection is difficult. To address this challenge, the authors introduce the Metadata Reasoner, an autonomous agentic system designed to identify minimal and sufficient data sources by leveraging table-search engines and analyzing metadata. Evaluated on real-world and synthetic benchmarks, the Metadata Reasoner significantly outperformed baselines (F1-score increase of 32 points) and demonstrated high robustness against noisy data, achieving high accuracy and perfect reliability in avoiding low-quality data.

## Technical note

The Metadata Reasoner is an agentic system that selects a sufficient and minimal set of data-lake tables for an analytical task, addressing the failure of ranking-based retrieval (BM25 + vector search + reranking) to return joinable combinations of tables. It takes a task plus a comprehensive metadata catalog (schemas, descriptions, lineage, quality, usage, glossaries/ontologies) and, instead of dumping all metadata into context (which causes attention dilution), autonomously fetches metadata per step via a table-search engine and specialized tools (e.g., data_finder for value existence, joinability_check for relational bridges). It decomposes queries into multi-faceted search plans, verifies entity coverage and valid semantic join paths, and emits a natural-language justification. On KramaBench it reaches 83.16% F1 (vs 50.77% vector search, 45.12% Pneuma), stays at 85.5% F1 on noise-injected BIRD lakes with 99% low-quality-table avoidance, and lifts downstream text-to-SQL execution accuracy to 71.28%.
