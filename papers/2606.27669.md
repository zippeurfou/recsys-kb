## Summary

1.  Existing benchmarks evaluate LLM-powered search agents under the assumption of clear, explicit user queries, but real-world searches often involve ambiguous or incorrect requests requiring multi-step reasoning.
2.  To bridge this gap, DiscoBench introduces a new benchmark with diverse samples and ambiguity instances across various domains, specifically designed to test if search agents can detect problems and ask effective clarification questions for better task utility.
3.  This paper evaluates LLM performance on these tasks using measures of ambiguity detection, interaction strategy quality, and cost efficiency, finding that direct guessing often performs worse than seeking clarification, highlighting a key deficiency in current search agent capabilities.

## Technical note

DiscoBench (Tencent) benchmarks whether LLM deep-search agents can proactively detect ambiguity and ask clarification rather than assuming explicit queries. Each question is decomposed into ordered checkpoints labeled Unambi or Ambi (four injected ambiguity types), and agents choose among Search/Ask/Answer actions; a user simulator progressively reveals discriminative clues on Ask. The dataset has 211 samples and 463 ambiguity instances across 11 domains, evaluated on task utility, ambiguity detection (TP/FN/FP/TN over checkpoints), interaction strategy, and cost. Key findings: ambiguity detection and effective clarification are distinct capabilities, and a dominant failure mode is repeatedly searching (SearchHeavyGuess) instead of asking, which performs worse than direct guessing—exposing a gap between retrieval ability and interactive problem-solving.
