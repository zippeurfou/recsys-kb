## Summary

This paper addresses **Zero-Observation User Reactivation (ZOR)**, where recommender systems must effectively resurface recommendations for users who have been inactive for long periods (`Delta t`), as traditional sequential recommendation models struggle without recent behavioral data.

The authors propose **DeltaGate**, a novel lightweight plugin technique. DeltaGate keeps the underlying SR model frozen and introduces learnable gate parameters per representation dimension, routing information between the user's historical sequence (from their pre-gap period) and a zero-initialized global prior based on `Delta t`.

Their experiments show that DeltaGate significantly improves recommendation accuracy compared to standard models like SASRec or BERT4Rec when users return after long gaps (`>365 days`), with gains over 19% and >80%, respectively, while using minimal trainable parameters (2-4%). End-to-end training achieved higher absolute accuracy but altered the backbone embeddings.

## Technical note

DeltaGate defines Zero-Observation Reactivation -- a returning user with a substantial pre-gap history but no interactions during a long macro-gap of duration delta-t -- and documents monotonic Hit@10 decay across gap buckets (worst beyond 365 days) for GRU4Rec, SASRec, and BERT4Rec on three Amazon categories. It proposes a frozen-backbone output-layer plugin that computes a dimension-wise gate from log(delta-t) and the personalized representation, interpolating each latent dimension between the user history and a learned zero-initialized global prior (66K params, 2-4% overhead). In the >365d Video Games bucket DG-SASRec reaches 0.047 Hit@10 vs 0.031 for SASRec and DG-BERT4Rec 0.046 vs 0.025, with zero backbone drift and ~40x fewer trainable parameters than end-to-end retraining (which is more accurate but induces 139.7% embedding drift). Not a retrieval-plus-ranking pipeline.
