## Summary

1.  The paper addresses the problem that prior distillation methods often rely on log-likelihood scores (like perplexity) to evaluate model quality, which inaccurately measures autoregressive generation performance.
2.  It introduces a new hybrid architecture called Hybrid Kimi Delta Attention and a distillation pipeline called GenDistill, which uses generation-based evaluation throughout the design process to accurately measure generation quality.
3.  The best model developed using this approach achieves high accuracy (86-90%) on knowledge benchmarks while significantly reducing KV cache memory usage (up to 75%) and improving time-to-first-token generation speed (2-4x faster).

## Technical note

This work shows that perplexity/log-likelihood evaluation systematically underestimates generation quality in cross-architecture distillation of Transformers into efficient hybrid models: a 7B student matching its teacher within 0.2pp under log-likelihood falls 20.8pp behind under autoregressive generation, and PPL can even reverse the ranking of design choices. It proposes Hybrid Kimi Delta Attention (Hybrid-KDA) paired with GenDistill, a multi-stage distillation pipeline using beam-search-based attention-layer selection and a generation-focused recipe, with generation-based evaluation (EvalScope) guiding every decision. Ablating six design axes on Qwen3-0.6B, the largest gains come from dataset selection, completion-only loss masking, and freezing attention layers during post-training. The best Hybrid-KDA model retains 86-90% of teacher accuracy on knowledge benchmarks while cutting KV-cache memory up to 75% and improving time-to-first-token 2-4x at 128K-token contexts.
