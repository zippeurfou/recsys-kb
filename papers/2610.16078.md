## Summary

The paper introduces HACE (Heterogeneous Agentic CoEvolution) to solve the challenge of improving specialized foundation models, which typically lack self-improvement capabilities despite being expert systems. HACE uses a joint framework where a learning agent and a specialist model improve each other reciprocally: the agent learns from the specialist's performance via reinforcement, while the specialist gets direct supervision, and their performance informs each other's training data. The authors demonstrate that HACE significantly outperforms existing self-improving methods across three different domains like recommendation systems and protein function prediction.

## Technical note

Specialized foundation models (SASRec, HSTU and Wukong recommenders; ESM-2 and ProtT5 protein models; CHGNet) plateau under their supervised recipe and depend on humans to find the next improvement. HACE (Meta) coevolves a specialist with an LLM agent (Gemma4-E4B by default): the agent is prompted with an instance and the specialist predictions and proposes a ranking; responses whose task quality beats the specialist on that instance are verified and used for on-policy reinforced self-training of the agent, agent exploration selects which labeled instances the specialist is fine-tuned on under a curriculum, and an evolutionary search over the interaction harness (what the agent sees, how responses are parsed, how experience is selected) keeps a proposal only if cross-fitted joint specialist-plus-agent validation quality improves. Final predictions fuse the specialist score with a lambda-weighted 1/log2(rank+1) agent score. On ML-1M and four Amazon categories across all three architectures HACE has the best HR@10 in all 15 settings, +2.9% to +18.5% over the converged base (mean +12.1%, e.g. HSTU ML-1M 0.2604 to 0.2685) and ahead of ReST-EM, Meta-Harness, OpenEvolve, DGM and TTT-Discover, with similar gains on CAFA (NDCG 0.6285 to 0.6745) and WBM. Ablations show every component matters (removing agent optimization drops Toys HR@10 from 0.0706 to 0.0622) and a 26B-A4B agent helps less than the 4B one.
