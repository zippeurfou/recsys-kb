## Summary

Netflix developed GenPage, an end-to-end generative transformer model replacing their traditional multi-stage recommender system for homepage construction. It treats user context as input and autoregressively generates the entire structured homepage layout in response. The model was trained by initially pretraining on production data and then refining it via either weighted binary classification or reinforcement learning; importantly, the WBC variant demonstrated a statistically significant positive lift (+0.24%) in core engagement metrics against their existing system while reducing latency by 20%, despite RL increasing diversity without explicit optimization for it being noted as an interesting offline finding.

## Technical note

Netflix homepage construction traditionally uses a multi-stage recommender stack (candidate generation, ranking, re-ranking) with many specialized models, complicating whole-page optimization. GenPage replaces this with a single ~200M-parameter decoder-only transformer that treats user/request context as a prompt and autoregressively generates the entire structured multi-row homepage, using a domain-specific tokenizer (one token per row/entity), pretraining on positively-engaged pages, then post-training via weighted binary classification (WBC, per-token value estimation) or reinforcement learning (Dr. GRPO against a page-level reward model with KL penalty). Production techniques address entity cold-start (context injection, semantic embedding fusion), freshness (multi-cadence incremental training), business rules (constrained decoding), and latency (hybrid row decoding). In an online A/B test the WBC variant delivered a +0.24% lift on the core engagement metric (p<0.001) while cutting serving latency 20%; offline, enriching the prompt (~6.9% loss reduction) beats scaling capacity (~1.3% from 120M to 900M), and RL post-training increases page diversity despite diversity not being in the objective.
