Prompting LLMs offers an efficient way to guide output generation without explicit model training. In the e-commerce domain, prompting-based applications are widely used for tasks such as query understanding, recommender systems, and customer support. ## Technical note

EaP (Examples as the Prompt) is a framework that improves LLM prompts for e-commerce tasks by automatically selecting the most representative labeled examples (both global task-representative and local input-similar) to maximize few-shot in-context learning, in an unsupervised manner adaptive to data distribution shifts. Its variant EaP_lite entirely replaces the natural-language system prompt with labeled examples, improving LLM inference speed by up to 70% without performance loss. Validated on four production use cases, EaP matches or beats expert hand-crafted prompts, and online A/B testing of EaP/EaP_lite for data labeling shows a 0.06% composite revenue gain.
