## Summary

This paper addresses limitations in retrieval-augmented generation (RAG) for complex reasoning by introducing Bi-RAR. Bi-RAR evaluates intermediate reasoning steps using a novel bidirectional information distance metric, approximated via language model probabilities, to assess both progress towards the answer and information completeness. To optimize reasoning based on these forward and backward signals, the authors employ a multi-objective reinforcement learning framework with a cascading reward structure, emphasizing early trajectory alignment. Empirical results on multiple benchmarks demonstrate that Bi-RAR outperforms previous methods and effectively enables iterative reasoning with search engines.

## Technical note

Bi-RAR is a retrieval-augmented reasoning framework that supervises each intermediate reasoning step in both forward and backward directions, rather than relying on outcome-only rewards that induce reward hacking and bloated chains. It introduces a bidirectional information distance, grounded in Kolmogorov complexity and approximated via LLM generation probabilities, that measures both how far the current reasoning is from the answer and how completely it addresses the question. A multi-objective reinforcement learning setup with a cascading reward structure emphasizes early trajectory alignment when optimizing under these bidirectional signals. Across seven QA benchmarks Bi-RAR surpasses prior methods and enables efficient iterative reasoning with a search engine at training and inference.
