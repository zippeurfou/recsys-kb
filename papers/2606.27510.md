## Summary

This paper argues that activation patching, a key technique for interpreting neural network components by estimating their natural indirect effect (NIE), actually also measures interaction effects (INT) between components. It demonstrates that these INTs are not nuisance errors but significant factors contributing to the instability and prompt-dependence seen in standard faithfulness scores. The authors conclude that recognizing and analyzing INT magnitudes provides crucial diagnostic information for mechanistic interpretability studies, revealing scenarios where simple component rankings based on NIE may miss underlying mechanisms requiring combinatorial analysis.

## Technical note

This Adobe paper re-derives the activation-patching estimand from causal mediation analysis and proves the natural indirect effect (NIE) is not a pure component effect: NIE = PIE + INT, where INT is an interaction effect measuring how a component's causal effect depends on the state of other components. The transformer residual stream's skip connection makes every mediator a recanting witness, guaranteeing INT. INT scales with the clean-vs-patched activation distance, vanishes when the downstream map is locally affine (small in Tracr and near-identical prompts), and decomposes combinatorially into pairwise and higher-order terms whose variance explains documented faithfulness-score instability. On GPT-2 IOI, backup name-mover heads appear as negative INT while PIE-only ranking zeroes out context-dependent heads—so INT is a diagnostic for when NIE rankings are prompt-dependent, not a nuisance to remove.
