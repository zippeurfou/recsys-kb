## Summary

In-Context Agentic Reinforcement Learning for Skill Internalization":

1.  Current methods of adding skills to LLM agents at runtime are limited by noise, token inefficiency, and the model never truly learning the knowledge.
2.  SKILL0 proposes "skill internalization," training models during development to autonomously use skills without needing to retrieve them during inference, using a specific in-context RL curriculum.
3.  This curriculum gradually removes skill context during training while evaluating effectiveness, leading to significant performance improvements (+9.7% and +6.6% on benchmarks) while maintaining a highly efficient context window.

## Technical note

Skill0 is an in-context reinforcement learning framework that internalizes agent skills into model parameters so no skill retrieval is needed at inference, addressing retrieval noise, token overhead, and the fact that prompted skills are followed rather than learned. Skills are grouped offline by category and rendered with interaction history into a compact context during training rollouts, then removed at inference so RL drives the transition from context-dependent execution to autonomous behavior. A Dynamic Curriculum evaluates each skill file's on-policy helpfulness on matched validation sub-tasks and withdraws a skill only when the current policy no longer benefits, under a linearly decaying budget. It reports gains over an RL baseline (+9.7% ALFWorld, +6.6% Search-QA, +10.1% WebShop) while keeping context under 0.5k tokens per step.
