## Summary

1. The paper introduces LLM-EMF (LLM-Enhanced Multimodal Fusion), combining Large Language Models with visual and textual data to improve cross-domain sequential recommendation (CDSR).
2. This approach enriches item representations using frozen CLIP embeddings for both text and images, while a multiple attention mechanism learns complex user preferences across domains.
3. Experiments on four e-commerce datasets show that LLM-EMF significantly outperforms existing methods by effectively modeling cross-domain user interests through multimodal integration.

## Technical note

Cross-Domain Sequential Recommendation (CDSR) transfers user behavior across domains but existing methods underexploit inter-domain relations, underuse multimodal data, and ignore domain imbalance. LLM-EMF enriches item text via prompt-designed LLM augmentation, unifies visual, textual, and ID embeddings through multimodal fusion, and uses a domain-balanced hierarchical multi-attention mechanism to jointly learn single-domain and cross-domain preferences while preventing high-frequency domains from dominating. Unlike prior LLM- or fusion-based CDSR methods, it systematically combines LLM-generated text knowledge with multimodal fusion and explicit domain balance. On four e-commerce datasets it outperforms existing cross-domain baselines.
