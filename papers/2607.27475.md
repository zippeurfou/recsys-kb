## Summary

In large-scale recommendation systems, retrieval faces a conflict between needing efficient indexing (based on item similarity) and accurate ranking based on user behavior. Existing methods often use separate objectives for these tasks, limiting performance due to structural misalignment.

The paper introduces OneShot, an end-to-end framework that integrates index learning directly with the neural scoring model used for ranking during training. This joint optimization aims to bridge the gap between traditional proximity-based indexing and modern ranking objectives.

OneShot significantly improves both user engagement metrics and system recall gain while also achieving a 10-fold efficiency improvement over operational systems, proving its effectiveness in Instagram's short-video recommendation application at scale.

## Technical note

Industrial retrieval trains a two-tower model under a ranking loss and then builds its ANN index (k-means, HNSW, NANN) in a separate proximity-based step, so index learning is misaligned with the ranking objective and user-item interaction is stuck at a dot product; Streaming VQ adds in-model VQ but updates codebooks by EMA rather than end-to-end. OneShot makes indexing an in-model, end-to-end-trained component: each of L layers holds a trainable codebook, the item embedding is argmax-assigned to a one-hot code with a straight-through estimator (softmax probabilities p carry the backward pass), and each layer's cumulative logit sum gets its own contrastive sampled-softmax loss with logQ correction, turning the layers into a logit-level residual boosting stack that is decoded at serving time by beam search over code paths. Because per-layer code embeddings are split off (via stop-grad) from a dense embedding v_d that carries no quantization error, arbitrary neural scoring NN_l(u, v_c) and NN_d(u, v_d) replaces the dot product, with a segment-wise multi-head matmul (d'=256, m=12, n=1) avoiding O(B^2) pairwise MLP cost; widening/deepening NN_d from m=3,K=0 to m=24,K=2 raises recall 0.4016 to 0.4613. Index collapse is prevented by a global balancing regularizer derived from stochastic compositional optimization: the scalar surrogate <p_i, log stop-grad(q_hat)>, whose autodiff gradient is exactly the SCGD direction for KL(E_j[e_j] || Unif(N)) with q_hat tracking corpus-level hard-assignment frequencies. Trained on one day (70B impression rows) at Instagram, a 1-layer 16384-code OneShot raises impression recall at the 1% ranking-volume operating point from 0.3414 to 0.4128 (+20%) and a 2-layer (2048, 1024) index matches k-means ANN recall with 90% fewer items ranked (10x efficiency); the KL balancer beats spherical k-means, VQ-VAE EMA + dead-code revival and Streaming VQ small-cluster boost (recall 0.4679 vs 0.3820 / 0.1589 / 0.4279, max/mean cluster size 10.2 vs an unbalanced baseline's 1281), learned Engagement IDs beat frozen semantic IDs (recall 0.4308 vs 0.1354), and global deployment yielded +0.035% sessions, +0.136% time-spent, +0.251% likes and +61.6% retrieval source rate.
