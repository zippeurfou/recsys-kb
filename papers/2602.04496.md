## Summary

Large language models struggle with complex scientific reasoning tasks, particularly those requiring tool use and multi-agent coordination. To address this, the paper introduces ReThinker, a confidence-aware framework using a dynamic Solver-Critic-Selector architecture that adapts its process based on model confidence, enabling efficient tool use and reflection. ReThinker achieves state-of-the-art performance on expert benchmarks by incorporating novel data synthesis and trajectory recycling techniques for scalable training, outperforming existing models and deep research systems.

## Technical note

ReThinker targets complex scientific reasoning tasks that require tool use and multi-agent coordination, where LLMs typically underperform. It uses a confidence-aware dynamic Solver-Critic-Selector architecture that adapts its reasoning and reflection process based on model confidence, enabling efficient tool invocation. Scalable training is supported by novel data synthesis and trajectory-recycling techniques that reuse partial reasoning trajectories. ReThinker reaches state-of-the-art results on expert scientific benchmarks, outperforming prior models and deep-research systems.
