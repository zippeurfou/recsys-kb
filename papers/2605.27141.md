## Summary

This paper introduces **VitaBench 2.0**, a new benchmark designed to evaluate large language model (LLM) agents in realistic, long-term interactions. Unlike previous benchmarks, VitaBench 2.0 focuses specifically on the challenges of **inferring and acting upon user preferences** embedded within fragmented, long-term user interactions, requiring agents to be both personalized and proactive. The authors found that **even state-of-the-art LLMs struggle significantly** with the real-world challenges of personalization and proactive behavior, highlighting substantial gaps between current capabilities and practical requirements.

## Technical note

VitaBench 2.0 is an interactive agent benchmark evaluating personalized and proactive behavior over long-term user interactions across delivery, in-store, and travel domains with 66 tools, 56 curated users, and 2000+ fine-grained preferences. Tasks are temporally ordered POMDP sequences where preferences are embedded in fragmented dialogue and behavior logs, and agents must extract, utilize, and update preferences (including addition/deletion/modification drift), plus proactively query for missing information. An extensible memory interface with Update and Retrieve operations enables controlled comparison of full-context, agentic memory, and RAG memory. Across frontier models the best Avg@4 is ~0.5; memory settings usually degrade performance versus full context, and reasoning/thinking modes do not reliably help. Failure analysis shows personalization, not tool use, is the dominant bottleneck.
