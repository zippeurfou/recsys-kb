## Technical note

RGAlign-Rec targets proactive 'zero-query' intent prediction in e-commerce chatbots, bridging the semantic gap between discrete user features and text-rich knowledge-base intents and the misalignment between general LLM outputs and ranking utilities. An LLM reasoner infers a latent query consumed by a Query-Enhanced three-tower ranking model (QE-Rec); the trained QE-Rec then serves as a reward model for Ranking-Guided Alignment (RGA), using best-of-N selection over teacher models (GPT, Gemini, CompassMax) for RG-SFT plus in-batch contrastive learning (RG-CL). On Shopee data it achieves 0.12% GAUC gain and +0.56% Recall@3; online A/B tests show QE-Rec +0.98% CTR and RGA an additional +0.13%.
