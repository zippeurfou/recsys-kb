## Summary

(Abstract fallback)

As the core algorithm in recommendation systems, collaborative filtering (CF) algorithms inevitably face the problem of data sparsity. Since CF captures similar users and items for recommendations, it is effective to augment the lacking user-user and item-item homogeneous linkages. However, existing methods are typically limited to connecting through overlapping interacted neighbors or through similar attributes and contents. These approaches are constrained by coarse-grained, sparse attributes ...

## Technical note

DQRec augments collaborative filtering under data sparsity by extracting user/item behavior patterns jointly from interaction sequences and attributes. Its proposed DQ-VAE (Decomposition-based Quantized VAE) decomposes pre-trained representation embeddings into distinct dimensions and quantizes them into disentangled multi-aspect semantic ID sequences, which are then used both as features and to build homogeneous user-user/item-item linkages that improve information diffusion. Experiments on three public datasets show DQRec outperforms CF, GNN, and sequential baselines, with ablations confirming each augmentation component.
