## Summary

This paper demonstrates that the effect of changing context in modern transformer models can be mathematically represented as specific, rank-1 updates to the model's MLP weights and a scaling update to its normalization layer. This finding is generalized across various transformer architectures (like Gemma-style, pre/post-norm, gating, MoE) by introducing the concepts of input and output controllability, proving that these parameter updates perfectly capture the context shift. The work provides a unified framework showing how prompts effectively translate into specific parameter adjustments, offering a simpler way to understand how transformers process different inputs.

## Technical note

This theory paper generalizes the result that a transformer block's context can be represented as an implicit rank-1 patch to its MLP weights from vanilla transformers to modern architectures. It gives a constructive proof for a Gemma-style block (rank-1 patches on gate/up projections plus an RMSNorm scale patch), extends it inductively to multi-layer models with an algorithm, and unifies findings via two properties: input controllability (inner function) and output controllability (outer function). The framework covers gating, pre/post-norm, MoE, and parallel blocks (Gemma, Llama, Mistral, GPT-J). Experiments on Gemma 3 show the patched no-context model matches the original with-context model's logits and generated tokens in float32.
