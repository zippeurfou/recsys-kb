## Summary

Recasting Learning Signals for Reinforcement Learning in Generative Recommendation":

1.  Generative recommendation systems often suffer from sparse, unlearnable rollout groups in standard RL, so the authors introduce ReCast to address this specific problem.
2.  ReCast first ensures even "all-zero" groups are minimally learnable and then replaces standard reward normalization with a contrastive update focusing on the best positives and hardest negatives within groups.
3.  This approach significantly improves recommendation performance (e.g., up to 36.6% improvement in Pass@1) and efficiency, requiring much less rollout budget and offering system-level benefits like faster updates and reduced memory usage, demonstrating a more effective way to construct learnable optimization events.

## Technical note

ReCast is a repair-then-contrast learning-signal framework for RL post-training of generative recommenders under sparse-hit, single-target supervision, where ~85% of sampled GRPO groups stay all-zero and thus unlearnable. It modifies only within-group signal construction: rollout repair injects a valid positive anchor to restore minimal learnability for all-zero groups, then a boundary contrastive update replaces full-group reward normalization by updating only the strongest positive and hardest negative. This reduces actor-side update width from O(G) to O(1), partially decoupling rollout search width from update cost while leaving the outer RL objective unchanged. Across generative recommendation tasks it beats OpenOneRec-RL by up to 36.6% relative Pass@1 and matches baseline performance with only 4.1% of the rollout budget, also cutting actor update time 16.6x, peak memory 16.5%, and raising MFU 14.2%.
