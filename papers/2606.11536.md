## Summary

VIPIR presents a GPU framework designed to accelerate private information retrieval (PIR) protocols by overcoming their traditional bottlenecks of high computation, memory usage, and bandwidth requirements. It achieves this by combining techniques from two distinct PIR protocol categories using an innovative data compression method called expansion-based ring packing (ExpPack), which provides significant parallelism. Further optimizations like number-theoretic transforms (NTTs) and specialized tensor-core use for database multiplication enhance performance, while memory-efficient scheduling allows VIPIR to achieve dramatically higher throughput than previous systems, making large-scale PIR feasible by minimizing communication overheads and enabling multi-GPU scaling.

## Technical note

VIPIR is a versatile GPU framework that co-designs single-server private information retrieval (PIR) protocols with GPU execution. A unified analytic model classifies existing PIR into scalar-HE (high client-server communication) and poly-HE (database bloating) approaches, and VIPIR derives new hybrid and double-packing protocols that combine techniques across both classes. Central is expansion-based ring packing (ExpPack), a GPU-friendly homomorphic compression that shrinks ciphertexts to ~0.16% of size, trading communication for computation with high parallelism. Core operations are optimized via number-theoretic transforms and GEMMs, including a tensor-core execution of database multiplication interpreted as a mixed-integer-type GEMM, plus memory-efficient scheduling that minimizes intermediate buffers and enables multi-GPU scaling under HBM capacity limits. Overall it achieves orders-of-magnitude higher throughput than prior CPU-based PIR while cutting communication and memory overhead, making large-scale PIR practical.
