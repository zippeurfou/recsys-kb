## Summary

Agent memory systems struggle to balance the need for high-level abstraction to manage growing data with the need for low-level specificity for effective reasoning. To address this, the paper introduces Memora, a novel memory representation that harmoniously combines abstract concepts with concrete details by indexing specific values and consolidating related updates into unified entries. Memora's structure, coupled with a retrieval policy leveraging "cue anchors," allows for context-aware information retrieval beyond simple similarity matching, and it is shown both theoretically (as encompassing standard RAG/KG methods) and empirically (on benchmarks) to significantly improve retrieval and reasoning performance as memory scales.

## Technical note

Memora is a harmonic agent-memory representation that balances abstraction and specificity to scale long-horizon agent memory. Each memory entry pairs a primary abstraction (canonical identity that consolidates related updates) with a memory value, augmented by cue anchors that form many-to-many links and an implicit memory graph. A policy-guided retriever formulated as an MDP with Refine/Expand/Stop actions (optionally trained via GRPO) navigates beyond semantic similarity to capture multi-hop dependencies. It shows RAG and KG memory are special cases and sets SOTA on LoCoMo (86.3%) and LongMemEval (87.4%) while cutting tokens up to 98% versus full context.
