## Summary

This paper introduces LikeBench, a new benchmark designed to evaluate the subjective likability of Large Language Models (LLMs) during personalized interactions. Unlike existing benchmarks focused solely on memory and task accuracy, LikeBench measures how well LLMs adapt over time to a user's evolving preferences to provide more likable responses. The authors demonstrate that high memory accuracy does not guarantee high likability, showing that models like DeepSeek R1 can outperform models like Qwen3 despite lower memory scores, highlighting the importance of likability metrics for effective personalization.

## Technical note

LikeBench is a multi-session, dynamic benchmark that measures the subjective likability of personalized LLMs rather than only memory recall/adherence. LLMs converse with a simulated user instantiated from fine-grained, psychologically grounded personas (Big Five/HEXACO/humor styles, conversation-style dimensions) and are scored per turn on seven diagnostic likability dimensions (emotional adaptation, formality matching, knowledge adaptation, reference understanding, length fit, humor fit, callback), plus adaptability (improvement rate via OLS over sessions) and memory accuracy. Results show strong memory does not guarantee likability: DeepSeek R1 beats Qwen3 by 28% on likability despite lower memory accuracy, and even GPT-5 shows limited robustness in long, noisy interactions.
