## Summary

Neural Recommendation with Personalized Attention":

Existing review-based recommendation systems use a single model for all users and items, failing to account for varying preferences and item characteristics, meaning the same review can have different importance. To address this, the paper introduces NRPA, a neural recommendation approach that learns personalized representations for users and items using reviews. It achieves this by incorporating a personalized attention mechanism that selects different relevant words and reviews for different users and items during the learning process. Experiments on multiple datasets demonstrate that this method significantly improves recommendation performance compared to standard models.

## Technical note

NRPA (Neural Recommendation with Personalized Attention) learns personalized user and item representations from textual reviews, arguing that the same words/reviews carry different informativeness for different users and items. It uses a CNN-based review encoder over word embeddings and a hierarchical personalized attention mechanism: word-level and review-level attention vectors are generated per user/item from their ID embeddings via MLPs, so important words and reviews are selected individually. The combined user and target-item representations are fed to a Factorization Machine layer to predict the rating. Experiments on five benchmark datasets validate that the personalized attention improves neural recommendation performance.
