## Summary

This paper introduces a new graph-based approximate nearest neighbor search framework using random walks to address the challenge of efficiently deleting points from existing graph structures. Current methods, like HNSW, either lack deletion support or negatively impact performance when deletions occur. The authors developed a deterministic deletion algorithm based on their random walk framework, demonstrating through experiments that it effectively maintains query performance and recall while offering better overall tradeoffs with lower deletion times and memory usage compared to prior approaches.

## Technical note

The paper tackles deletion in graph-based approximate nearest neighbor search (ANN), which HNSW does not natively support and where prior patching methods trade off recall, query latency, deletion time, or memory. It introduces a theoretical framework recasting greedy HNSW search as a 'softmax walk' random walk on a query-weighted graph, then derives SPatch, a deletion procedure that patches the deleted node's neighborhood via a star-mesh (Schur complement) transform and sparsifies the induced clique by sampling edges by squared row norm, provably approximating the walk's hitting time. Experiments in the mass-deletion setting show SPatch achieves a better simultaneous tradeoff across recall, query speed, deletion time, and memory than tombstone, no-patch, local, FreshDiskANN, and global-reconnect baselines.
