## Summary

1.  The paper addresses challenges in auto-bidding due to difficulties in constructing effective advertiser profiles, highlighting issues with extraction, modeling common and private information, and adaptation.
2.  It introduces ADAPT, a novel auto-bidding framework employing disentangled advertiser profiles (separating common and private traits) and crucially supports training-free adaptation.
3.  ADAPT uses a two-stage training process (contrastive learning for extraction, joint conditioning for strategy) to build bidding strategies conditioned on both disentangled and static profiles, and allows updating these profiles for existing advertisers or creating them for new ones without retraining the entire model. Experiments show ADAPT consistently outperforms existing methods on benchmarks.

## Technical note

Auto-bidding policies rarely personalize to advertisers because pure profiles are hard to extract, shared and advertiser-specific patterns are entangled, and profiles must be refreshed and bootstrapped for new advertisers. ADAPT learns static profiles (from advertiser categories) and dynamic profiles (from historical bidding trajectories) via contrastive learning over an advertiser memory bank, then disentangles the dynamic profile into common and private components that jointly condition a Decision Transformer bidding policy; once trained, it builds profiles for new advertisers and updates existing ones without retraining. On the AuctionNet benchmark (dense and sparse variants) ADAPT beats all baselines at every budget scale, e.g. +2.23% and +2.77% score over the strongest baseline GAS at 100% budget, and the full profile set lifts score by 11.55% and conversions by 11.26% over a no-profile DT. No online test is reported.
