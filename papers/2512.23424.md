## Summary

Modern AI models face significant kernel development challenges due to hardware diversity, complex architectures, and the need for optimization techniques like quantization, which manual methods struggle to address efficiently.

To tackle this, the paper introduces AKG kernel agent, a multi-agent system designed to automate kernel generation, migration, and tuning across various hardware platforms.

AKG kernel agent supports multiple domain-specific languages and demonstrates effectiveness by achieving an average 1.46x speedup over PyTorch implementations on benchmark tasks, significantly accelerating kernel development for AI workloads.

## Technical note

AKG kernel agent is a multi-agent system that automates high-performance kernel generation, migration, and tuning across hardware backends, addressing the bottleneck that manual optimization cannot keep pace with model and hardware diversity. Four specialized agents (Designer, Coder, Verifier, Conductor) collaborate: the Designer produces a DSL-agnostic Unified Sketch capturing parallelization, data flow, and memory access; the Coder emits code in Triton, TileLang, CPP, or CUDA-C; the Verifier checks correctness and profiles; the Conductor reroutes errors. On KernelBench with Triton across GPU and NPU backends it achieves an average 1.46x speedup over PyTorch Eager baselines.
