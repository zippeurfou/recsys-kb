## Summary

1.  Vision-Language Models (VLMs) often overestimate the importance of dominant visual or textual cues while underestimating crucial but sparse geographic context variables when predicting user preferences for ads across different markets.
2.  To address this "Contextual Variable Overestimation" issue, researchers created GeoReward, a specialized reward model incorporating three novel mechanisms (Market-Aware Retrieval, Visual Modulation, Selective Loss) to better capture and weigh regional information during training.
3.  Experiments show that GeoReward successfully reduces the overestimation bias in VLMs for cross-market preference prediction and can guide fine-tuning processes to generate more effective, geographically-aware advertising creatives.

## Technical note

VLMs asked which of two ad creatives will win higher CTR in a given country collapse to a market-invariant answer: dense image patches and verbose product text swamp the single sparse country token, a failure the authors name Contextual Variable Overestimation (CVE). They release MACP -- 823K train / 180K test pairs of two images of the same product with per-country CTR across 10 balanced markets, keeping only pairs whose relative CTR gap is >= 0.1 -- and propose GeoReward (Alibaba International Digital Commerce), a triple-gated reward model over Qwen2-VL-7B: Market-Aware Retrieval Augmentation does a two-stage per-country retrieval (product-text nearest neighbors, then image-feature CTR lookup) injected as an augmented choice (Pearson 0.67 with the label, pre-computed offline, 76 ms/sample if run online); Context-Guided Visual Modulation is a light adapter that modulates visual features with the textual country embedding; and a Selective Sensitivity Loss penalizes errors more when the model under-attends the critical country token. Naive fine-tuning collapses to 44.61% accuracy / 20.82% sensitivity, an FC-head baseline gets 55.60/36.73, and full GeoReward reaches 60.37/40.84 -- super-additive over the single-component variants (56.0-56.1 accuracy) and the pairwise ones (56.8-58.0). Used as the reward to RL-fine-tune a Design Generation Model whose background prompts feed SDXL, it raises GeoReward-judged accuracy from 56.04 to 59.60, and a one-week online A/B on the cross-border e-commerce platform with 6M+ impressions gives +1.1% CTR on average (+0.7% to +1.4% per market). A simulated cold-start on Chile retains over 85% of full-data accuracy (52.84% vs 61.12%) using only 30% of that market's training data.

- $P(\mathbf{z}\mid T)$: Identify and separate the sparse-critical variable $\mathbf{z}$ from the text T. This corresponds to high-level evidence extraction
- $P(\mathbf{x}\mid V,T,\mathbf{z})$: Re-interpret the low-level evidence $\mathbf{x}$ conditioned on the high-level intent $\mathbf{z}$. This is context-guided modulation of perception
- $P(y\mid\mathbf{z},\mathbf{x})$: Make the final decision based on the integrated hierarchical evidence
- $Q_{\phi_{z}}(\mathbf{z}\mid T)$: A module that extracts the critical variable $\mathbf{z}$ from text. This can be implemented as a light-weight parser or a retrieval gate
- $Q_{\phi_{x}}(\mathbf{x}\mid V,T,\mathbf{z})$: A module that generates the low-level representation conditioned on $\mathbf{z}$. This directly instantiates the context-guided visual modulation
- It updates the predictor $P_{\theta}$
- It flows into the modulation network $Q_{\phi_{x}}$, adjusting the gating mechanism $\mathbf{g}$
- Crucially, it also flows into the extractor $Q_{\phi_{z}}$, reinforcing or correcting the identification of $\mathbf{z}$
- Market-Aware RAG Module $\approx$ Implements the prior $P(\mathbf{z})$ and aids the approximate posterior $Q_{\phi_{z}}(\mathbf{z}\mid T)$ by retrieving relevant, market-specific evidence
- Context-Guided Visual Modulation $\equiv$ The physical implementation of the conditional distribution $Q_{\phi_{x}}(\mathbf{x}\mid V,T,\mathbf{z})$, where the adaptive gating occurs
- Selective Sensitivity Loss $\equiv$ The combined effect of the prediction loss and the KL divergence terms within the ELBO framework, which differentially penalizes errors based on the inferred importance of $\mathbf{z}$ and drives the adaptive learning of the gates (arXiv:2608.04504)
- The Selective Sensitivity Loss (SSL) can naturally be extended to calculate separate penalties for inattention to multiple specified critical tokens (e.g., “young person” and “France”), encouraging the model to attend to all simultaneously
- For highly complex, multi-factorial decisions, an ensemble approach could be employed. Specialized reward models (e.g., AgeReward, GeoReward), each finetuned to be sensitive to a specific type of sparse variable using our framework, could provide intermediate rewards. These signals could then be aggregated for a final decision via an ensemble strategy

- Data-level amplification (MA-RAG): By retrieving and injecting click-through preferences aligned with the target market, MA-RAG directly amplifies the signal of the critical country variable. It provides an external, market-aware prior that forces the model to prioritize localized relevance, counteracting the dominance of generic high-volume features
- Feature-level adaptation (CGVM): Operating inside the vision encoder, CGVM dynamically modulates visual representations using learned country embeddings. This ensures that the sparse critical variable actively conditions perceptual processing, preventing visual features from being treated uniformly and enabling fine-grained adaptation to market-specific visual preferences
- Optimization-level regularization (SSL): During training, SSL penalizes the model when it makes errors while under-attending to the tokens corresponding to critical variables (country, product, image). It acts as a focus-driven regularizer, explicitly encouraging balanced attention allocation and reinforcing the importance of sparse variables in the decision process (arXiv:2608.04504)
