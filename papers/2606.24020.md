## Summary

The paper reveals that public benchmark scores across AI models are highly predictable using just two factors, as shown by a large matrix of model performances where these factors explain over 90% of the variance on shared benchmarks.

Researchers developed BenchPress, an efficient logit-space matrix completion technique leveraging this rank-2 structure. It can predict unseen benchmark scores for a model with high accuracy (within ~4 points) using only a small subset of known results from as few as four to five carefully selected tests.

The authors provide the public score matrix and release BenchPress code, allowing users to input minimal data about a new model and confidently estimate its performance across all benchmarks.

## Technical note

BenchPress compiles an 84-model x 133-benchmark public score matrix (23.3% filled) and shows it is effectively rank-2 via both Soft-Impute held-out error minimization at rank 2 and SVD showing two factors explain >90% of variance. The default predictor is a logit-space bias-decomposed rank-2 ALS (global + model offset + benchmark offset + low-rank residual) chosen for full coverage, reaching 4.6-point median absolute error on held-out cells. Greedy probe-set selection finds five benchmarks (GPQA-D, HLE, Codeforces, MMLU-Pro, ARC-AGI-1) that recover a full scorecard to within 3.93 points, leaning heavily on reasoning/math benchmarks. Predictions preserve 92.1% of pairwise model rankings at a 5-point margin, and a conformal + ensemble-spread confidence layer produces trust probabilities and calibrated 90% intervals. Scope is snapshot-specific and mixes heterogeneous vendor/third-party scores.
