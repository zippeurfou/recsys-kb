## Summary

1.  Existing benchmarks for LLM-based agents often use synthetic data, failing to capture the complexity and efficiency needs of real-world cloud service interactions.
2.  To address this gap, the paper introduces CirrusBench, an evaluation framework based on real-world cloud service tickets, preserving complex multi-turn interactions and tool dependencies.
3.  CirrusBench moves beyond simple correctness, using customer-centric metrics like efficiency and latency, revealing that current top models struggle with complex, multi-turn tasks needed for effective customer service.

## Technical note

CirrusBench is an LLM-agent evaluation framework built from authentic cloud-service support tickets (1,500 no-tool tasks and 425 tool-call tasks across 20 service categories), preserving realistic multi-turn logical chains and tool dependencies rather than synthetic role-play. Beyond correctness metrics like success rate and Task Progression Rate, it introduces Customer-Centric Metrics—Logical Jump, Normalized Efficiency Index, Single-Turn Latency, and Multi-Turn Latency—to quantify resolution efficiency and service quality. Experiments show SOTA models reason well but fail on complex long-horizon multi-turn tasks, with tool-integration bottlenecks and error accumulation. 'Thinking' models incur high latency without proportional accuracy gains, and agents exhibit premature closure, failing to ask necessary clarifying questions.
