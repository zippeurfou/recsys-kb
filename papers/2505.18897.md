## Technical note

This eBay system performs document-side semantic keyword expansion for search advertising, broadening token-based ad matching without altering user queries. It embeds ad keywords with a pre-trained two-tower siamese model (micro-BERT trained with contrastive learning on eBay titles) and finds semantically similar variants via FAISS nearest-neighbor search, controlling precision with a cluster-based adaptive thresholding mechanism (k-means clusters get per-cluster quantile similarity cutoffs by local density). A GBDT relevance model is adapted to the expanded keyword space via incremental learning with a few added shallow trees. The pipeline supports daily refreshes and improves both relevance and CTR at production scale.
