## Summary

Large-scale recommendation models are powerful but challenging to deploy efficiently due to their size, often relying on quick-win solutions that don't fully utilize their potential. This paper proposes learning a hierarchical index structure directly within these large retrieval models, combining cross-attention and residual quantization, to enable more efficient search by reducing retrieval costs while preserving accuracy. The proposed method, deployed successfully at Meta for billions of users, discovers that intermediate index nodes correspond to high-quality data, and fine-tuning on this data significantly improves performance, demonstrating test-time training in recommendations.

## Technical note

HILL jointly learns a hierarchical index over the memory of Meta's Modular Neural Network (MoNN) foundation retrieval model (User/Item/Interaction towers plus a DHEN/Wukong OverArch trained with multi-task supervised + semi-supervised distillation losses). Using cross-attention and residual quantization co-trained with the retrieval model, HILL builds an exactness-aware tree so beam search prunes the search space and cuts retrieval cost while preserving accuracy, versus quick-win alternatives (offline cached retrieval sets or distilling to small models). A key finding: intermediate index nodes correspond to a small high-quality data source, and fine-tuning MoNN on it yields a test-time-training inference upgrade. Deployed for daily Facebook/Instagram ad recommendation to billions of users, validated on internal and public datasets.
