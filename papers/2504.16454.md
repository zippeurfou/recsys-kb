## Summary

(Abstract fallback)

In recommendation systems, the traditional multi-stage paradigm, which includes retrieval and ranking, often suffers from information loss between stages and diminishes performance. Recent advances in generative models, inspired by natural language processing, suggest the potential for unifying these stages to mitigate such loss. ## Technical note

UniGRF (Unified Generative Recommendation Framework) integrates the retrieval and ranking stages into a single model-agnostic generative model by casting both as sequence-generation tasks distinguished by output position, enabling information sharing without extra compute and addressing inter-stage information loss. It adds a ranking-driven enhancer module that uses the ranking stage's precision to generate high-quality samples for retrieval (an enhancement loop via parameter sharing), and a gradient-guided adaptive weighter that dynamically balances the differing loss magnitudes and convergence rates of the two stages for synchronized optimization. This Huawei work is the first to unify both stages in generative recommendation and significantly outperforms existing models on benchmark datasets.
