## Summary

This paper addresses the challenge of running powerful neural session-based recommendation models efficiently on resource-constrained mobile devices. Current compression methods using tensor decomposition, while reducing memory, significantly increase inference time due to complex calculations, hindering real-time recommendations. To overcome this, the authors propose learning compact item representations using compositional encoding and a bidirectional self-supervised knowledge distillation framework for effective compression. Their method achieves an 8x inference speedup with large compression ratios while maintaining recommendation performance, demonstrating a practical solution for efficient on-device recommendation.

## Technical note

This work targets ultra-compact, low-latency on-device session-based recommendation, improving on the authors' prior OD-Rec which used semi-tensor/tensor-train decomposition that slowed inference. It replaces decomposition with compositional code learning: each item is an M-dimensional discrete code whose codeword embeddings from M small codebooks are summed to form the item embedding, learned by regressing to a well-trained uncompressed embedding jointly with the recommendation task. A bidirectional self-supervised knowledge distillation framework lets the SASRec-based teacher and student mutually improve rather than assuming teacher superiority. On two benchmarks it achieves an 8x inference speedup with a large compression ratio while surpassing prior methods on recommendation accuracy.
