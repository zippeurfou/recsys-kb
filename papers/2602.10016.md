## Technical note

Kunlun (Meta) is a scalable CTR architecture that establishes the first predictable power-law scaling laws for jointly modeling sequential user behavior and non-sequential context features, identifying poor scaling efficiency (low Model FLOPs Utilization) as the barrier. Each layer stacks a Kunlun Transformer Block (Generalized Dot-Product Attention-enhanced personalized FFN, multi-head self-attention, Sliding Window Attention for linear complexity) and a Kunlun Interaction Block (personalized weight generation, Hierarchical Seed Pooling, global feature interaction), plus high-level Computation Skip and Event-level Personalization for adaptive resource allocation. These raise MFU from 17% to 37% on NVIDIA B200 GPUs and double scaling efficiency over SOTA; deployed in major Meta Ads models, Kunlun delivered 1.2% topline improvement. Uses Normalized Entropy as the primary metric.
