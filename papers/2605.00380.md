## Summary

This paper introduces **ResRL**, a novel method to enhance LLM reasoning. It addresses the trade-off between improved reasoning and generation diversity found in existing RLVR approaches. ResRL achieves this by projecting negative token representations onto a low-rank positive subspace, using the residuals to guide conservative negative gradient weighting, thereby improving reasoning while preserving diversity and outperforming baselines, particularly in mathematical tasks.

## Technical note

ResRL is a reinforcement-learning method for boosting LLM reasoning that addresses the trade-off in RLVR approaches between improved reasoning accuracy and collapsed generation diversity. It projects negative-sample token representations onto a low-rank positive subspace and uses the resulting projection residuals to guide conservative, per-token weighting of the negative gradient. By down-weighting negative gradients according to how much a negative token aligns with the positive subspace, ResRL preserves exploration and diversity while still learning from negatives, mitigating the likelihood-displacement / diversity-collapse failure modes seen in GRPO-style training. Experiments report improved reasoning performance while preserving diversity, with particularly strong gains on mathematical reasoning tasks over baselines.
