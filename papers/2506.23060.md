## Summary

The retrieval stage in recommendation systems struggles to cover diverse user interests effectively due to limitations of traditional models.

Pinterest's new multi-embedding framework tackles this by creating multiple user embeddings conditioned on both their implicit (captured via a Differentiable Clustering Module) and explicit (modeled via Conditional Retrieval) interests.

This approach generates more relevant candidate items, leading to significant improvements in user engagement metrics and feed diversity, showing it effectively complements existing retrieval methods.

## Technical note

Pinterest addresses the retrieval stage's failure to cover diverse and long-tail user interests, where vanilla two-tower models over-amplify dominant interests. Their multi-embedding framework generates several user embeddings conditioned on both implicit interests (extracted from user history via a Differentiable Clustering Module) and explicit interests such as followed topics (modeled via Conditional Retrieval with a learned topic embedding table). Framed as conditional representation learning with condition construction and association, the two models complement each other across user segments; deployed on Pinterest home feed, it produced significant online engagement and feed-diversity gains.
