Industrial recommendation systems are typically composed of multiple stages, including retrieval, ranking, and blending. The retrieval stage plays a critical role in generating a high-recall set of candidate items that covers a wide range of diverse user interests. ## Technical note

Pinterest proposes a multi-embedding retrieval framework for home-feed candidate generation that overcomes vanilla two-tower models' failure to cover diverse, long-tail user interests. It generates multiple user embeddings conditioned on implicit interests (via a Differentiable Clustering Module over user history) and explicit interests such as followed topics (via Conditional Retrieval), framed as conditioned representation learning with condition construction and condition-item association. Implicit modeling adapts to real-time engagement and benefits active users, while explicit conditional retrieval replenishes long-term/forgotten interests and serves new low-signal users; the deployed system significantly improved home-feed engagement and diversity metrics in A/B tests.
