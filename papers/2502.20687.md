## Technical note

T2Diff overcomes the 'late interaction' limitation of two-tower matching models, where separate user/item towers cannot model user-item feature interaction until the final dot product. Instead of collapsing to a single tower (COLD) or augmenting inputs with the other tower (DAT), T2Diff uses a diffusion module inside the user tower to reconstruct the user's next positive-intention item representation, and a mixed-attention module to enable comprehensive user-item cross-interaction, explicitly extracting temporal drift in behavior sequences. It uses a KL-divergence diffusion loss for stable, low-latency reconstruction. On two real-world and one industrial dataset it significantly outperforms SOTA two-tower models while retaining inference efficiency.
