## Summary

This paper identifies that large-scale, high-dimensional vector similarity search using on-disk graph-based indexes is compute-bound, not I/O-bound, contrary to previous assumptions. To address this, the authors propose AlayaLaser, a new index system that leverages the roofline model to analyze performance and employs a novel data layout and optimizations like SIMD instructions, node caching, and early dispatch to reduce computational overhead. Experiments show AlayaLaser significantly outperforms existing on-disk systems and matches or exceeds in-memory systems.

## Technical note

AlayaLaser is an on-disk graph-based ANN search system that challenges the assumption that such systems are I/O-bound, showing via an adapted roofline model that they become compute-bound as vector dimensionality grows to hundreds/thousands. It introduces a novel on-disk data layout that exploits SIMD instructions on modern CPUs to relieve the compute bottleneck in distance computation. Additional optimizations include degree-based node caching, cluster-based entry-point selection, and an early-dispatch strategy. Positioned against DiskANN, Starling, and PipeANN, AlayaLaser matches or exceeds in-memory index performance while retaining the memory savings of on-disk indexes. Relevant to large-scale retrieval infrastructure for recommendation and RAG.
