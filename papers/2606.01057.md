## Summary

This paper introduces **3DCodeBench**, a benchmark designed to evaluate how effectively vision-language models (VLMs) can generate procedural code for 3D modeling software. Recognizing that automated metrics don't fully capture visual quality, they built **3DCodeArena** using human pairwise comparisons on generated 3D outputs. Evaluations show VLMs struggle mainly with API mismatches and often produce disconnected geometry, but performance improves significantly with larger thinking budgets and multi-turn refinement prompts.

The key points are:

1.  The paper presents a benchmark (**3DCodeBench**) for evaluating VLMs as procedural 3D modelers via code generation.
2.  It includes a human-centric ranking platform (**3DCodeArena**) to assess the quality of generated 3D shapes more accurately than automated methods alone.
3.  Findings indicate that while current VLMs perform better with larger thinking budgets and iterative refinement, failures often stem from API errors or disconnected geometry in successful renders, highlighting the need for high-quality procedural code datasets.

## Technical note

3DCodeBench evaluates VLM agents as procedural 3D modelers that translate text/image prompts into executable Blender Python code, backed by a 26K prompt-code-mesh triplet dataset over 212 categories curated through an agentic human-in-the-loop pipeline. Scoring combines binary executability, mesh similarity (Chamfer, Uni3D), perceptual view similarity (SigLIP-2, DINOv3), and 3DCodeArena, a public pairwise-human-preference Elo arena. Across 12 VLMs, failures stem mostly from API mismatches, and successful renders still show disconnected or floating geometry, making physical plausibility the main bottleneck beyond executability. Test-time scaling via higher thinking budgets and multi-turn refinement with execution feedback consistently improves results; the paper is unrelated to recommendation.
