## Summary

1.  Traditional Advanced Planning Systems (APS) are difficult and expensive for many businesses due to high customization costs often requiring consultants.
2.  To address this gap, the paper introduces SMARTAPS, an AI-powered conversational system built on tool-augmented Large Language Models (LLMs).
3.  This allows supply chain planners to interact with planning tools using natural language queries for information, analysis, recommendations, and scenario exploration without needing coding expertise or constant consultant support.

## Technical note

SMARTAPS is a conversational, agentic system that lets operations planners query and manipulate advanced planning system (APS) plans in natural language, reducing dependence on OR consultants. It comprises three LLM-driven modules: a conversation manager (intent detection + response refinement), a tool retriever that embeds queries with BGE-large and does semantic similarity search over an API-contract catalog in ChromaDB, and a tool manager that extracts parameters and executes tools (including an optimization solver). Tools cover query-plan, why-not, what-if, compare-plan, and display-plan analyses, with a human-in-the-loop path for unsupported queries. A production-planning user study reported analysis turnaround dropping from 1-2 days to a few hours.
