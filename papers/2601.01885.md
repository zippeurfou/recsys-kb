## Summary

1.  Large LLM agents struggle with long tasks due to limited context, often because long-term (LTM) and short-term (STM) memory are managed separately using heuristics, limiting adaptability.
2.  This paper introduces Agentic Memory (AgeMem), a unified framework that integrates LTM and STM management directly into the LLM agent's decision-making process, treating memory operations as actions the agent can autonomously perform.
3.  AgeMem trains these combined memory behaviors effectively using reinforcement learning, leading to significantly better task performance, higher-quality memories, and more efficient context usage across various LLM backbones compared to standard memory-augmented methods.

## Technical note

Agentic Memory (AgeMem) unifies long-term (LTM) and short-term (STM) memory management inside an LLM agent's policy instead of using separate heuristic modules or auxiliary controllers. It exposes memory operations (store, retrieve, update, summarize, discard) as tool-based actions the agent autonomously invokes for both LTM and STM. Training uses a three-stage progressive RL curriculum (first LTM storage, then STM context management, then joint coordination) and a step-wise GRPO that back-propagates output rewards to prior memory decisions to handle sparse, discontinuous memory-operation rewards. Across five long-horizon benchmarks and multiple LLM backbones, AgeMem outperforms strong memory-augmented baselines in task performance, memory quality, and context efficiency.
