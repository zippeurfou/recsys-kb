## Summary

Existing conversational agents use memory as a passive tool, triggered by specific queries, leading to inefficiencies. MemCog proposes treating memory as an active cognitive component, integrating retrieval into the agent's reasoning process. By structuring memory with links and enabling proactive exploration, MemCog significantly improves both standard and proactive memory-based tasks.

## Technical note

MemCog reframes agent memory from a Memory-as-Tool paradigm—single-query, one-shot flat retrieval—to Memory-as-Cognition, making memory access an integral part of the reasoning process. It identifies three limitations of prior systems: an invocation bottleneck (memory only fires on explicit tool calls), reasoning-retrieval decoupling (one-shot retrieval preventing dynamic re-planning), and structural mismatch (top-k fragments lacking navigational information). MemCog organizes user knowledge as a Navigable Memory Store with associative link graphs, exposes a Cross-Dimensional Navigation Interface of multi-granularity actions inside a ReAct loop, and uses a Proactive Reasoning Protocol that spontaneously initiates memory exploration from conversational context. It also introduces ProactiveMemBench, the first benchmark for proactive memory triggering (500 instances, five domains, 98.4% human acceptance), and achieves state-of-the-art on passive QA (92.98 LoCoMo, 95.8 LongMemEval) while substantially outperforming baselines on proactive triggering.
