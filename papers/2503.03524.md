## Summary

(Abstract fallback)

In recommender systems, the patterns of user behaviors (e.g., purchase, click) may vary greatly in different contexts (e.g., time and location). This is because user behavior is jointly determined by two types of factors: intrinsic factors, which reflect consistent user preference, and extrinsic factors, which reflect external incentives that may vary in different contexts. ## Technical note

IEDR (Intrinsic-Extrinsic Disentangled Recommendation) is a generic framework that differentiates a user's stable intrinsic factors from context-dependent extrinsic factors while considering the interplay of multiple contexts simultaneously, unlike prior work limited to a single predefined context. It combines a recommendation-prediction module that builds a complete graph over contexts for graph learning with a context-invariant contrastive learning component (for intrinsic factors) and a disentanglement component (for extrinsic factors). On real-world datasets it learns disentangled factors and improves recommendation accuracy by up to 4% in NDCG.
