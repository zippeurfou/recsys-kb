## Technical note

DOVA (Deep Orchestrated Versatile Agent) is a multi-agent platform for autonomous research automation introducing three innovations: deliberation-first orchestration where explicit meta-reasoning precedes tool invocation, informed by a persistent user model and entity-aware conversation context; hybrid collaborative reasoning, a composable three-phase pipeline unifying ensemble diversity, blackboard transparency, and iterative refinement; and adaptive multi-tiered thinking, a six-level token-budget allocation that cuts inference cost by 40-60% on simple tasks while preserving deep reasoning. The paper formalizes the core algorithms and runs an architectural ablation across seven configurations analyzing answer confidence, source coverage, and token efficiency.
