## Technical note

Identifies the 'lifelong sequential behavior incomprehension' problem: LLM4Rec CTR models stop benefiting from longer user sequences (AUC peaks at K=15) even well within the context window, unlike conventional models like SIM. ReLLaX offers full-stack optimization: Semantic User Behavior Retrieval (SUBR) replaces recent items with top-K semantically relevant items (LLM embeddings + PCA) to lower sequence heterogeneity; Soft Prompt Augmentation (SPA) projects pretrained CRM item ID embeddings into soft prompt tokens injecting collaborative knowledge; and Component Fully-interactive LoRA (CFLoRA) inserts a CRM-generated interaction matrix W between LoRA's A and B (BWA), which is theoretically shown to generalize prior LoRA-based LLM4Rec methods (identity/block-diagonal W special cases). Experiments on three public datasets show ReLLaX outperforms ReLLa, CoLLM, iLoRA, TALLRec and conventional CTR baselines.

- SIM . The number of attention layers and DNN layers are both determined from {1, 2, 3}. The DNN hidden size is selected from {32, 64} on the BookCrossing dataset and from {64, 128, 256} on the MovieLens-1M and MovieLens-25M datasets
- CTR-BERT . A two-tower architecture based on the BERT  model is utilized to encode user and item information separately. The training process involves 10 epochs. The batch size is fixed at 1024. The learning rate is set to $5\times 10^{-5}$, which decays linearly. The warmup ratio is 0.05
- P5  is a unified sequence-to-sequence framework that employs T5  as the backbone pretrained language model for various recommendation tasks. In this study, P5 is applied solely for CTR prediction. The training consists of 10 epochs with a batch size of 32. The learning rate is chosen from $\{5\times 10^{-4},1\times 10^{-3}\}$ and decays linearly. The warmup ratio is 0.05. In line with the official P5 implementation, gradient clipping is performed with a threshold of 1.0
- PTab  follows a pretrain-finetune approach based on the BERT  model. Initially, PTab further pretrains the BERT model using the masked language modeling objective on textualized CTR data. Subsequently, BERT is finetuned for CTR prediction as a text classification task. Consistent with the original paper, BERT is pretrained for 10 epochs with a batch size of 1024. The pretraining learning rate is $5\times 10^{-5}$, which decays linearly. The warmup ratio is 0.05. For finetuning, the process spans 10 epochs with a batch size of 1024. The finetuning learning rate starts at $5\times 10^{-5}$ and decays linearly. The warmup ratio is 0.01
- TALLRec  adopts the simple instruction tuning on pure textual prompts with LoRA. We use the same hyperparameter configurations for TALLRec and ReLLaX, *e.g.* the learning rate, the LoRA rank and dropout rate. The prompt template is shown in Figure 9, where the user behavior sequence is constructed by the most recent $K$ items
- CoLLM . We keep the pretrained traditional CTR model and LoRA configurations for CoLLM the same as ReLLaX. Other training configurations, *e.g.* learning rate and epoch, are also searched in the same range as ReLLaX
- iLoRA . Following the original paper , we set the number of LoRA experts to 4. The other configurations, *e.g.* the pretrained traditional CTR model, LoRA rank and training hyperparameters, are kept the same as ReLLaX. The prompt template is shown in Figure 9
- ReLLa . We maintain the configurations of ReLLa used in the original paper , and we directly use the results of the original paper in this journal manuscript
