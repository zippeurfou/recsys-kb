## Technical note

Gensors is a Google interactive system that lets end-users author personalized visual sensors from natural-language descriptions (e.g., 'alert if my toddler is getting into mischief') using multimodal LLMs that reason over a camera feed. It scaffolds sensor creation with MLLM-generated and user-uploaded test images, automatically decomposed sub-criteria users can edit, and reasoning traces that explain each classification and surface disagreements. In a 12-participant user study, Gensors outperformed a baseline prompting interface on sense of control, ease of criteria definition, aligning the sensor to user intuition, and reducing false triggers. This is an HCI/MLLM paper only loosely related to recsys, contributing personalization and criteria-refinement techniques rather than a recommender.
