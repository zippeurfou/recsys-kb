## Summary

This paper presents an LLM-based framework designed for improved query understanding in online job matching systems, addressing the limitations of traditional brittle and expensive approaches that rely on task-specific Named Entity Recognition models.

The core innovation is a unified system that jointly analyzes user queries with contextual information like profile attributes to generate more structured interpretations driving better recommendations.

Results show this approach significantly improves relevance quality through A/B testing while substantially reducing operational complexity and overhead, providing a scalable foundation for dynamic web applications.

## Technical note

This LinkedIn paper replaces multiple task-specific NER models with a single unified LLM for query understanding in billion-scale job search. One fine-tuned Qwen2.5-1.5B handles a query planner (routing to criteria/self-reference/non-job/trust-violation), generative facet tagging, profile-based query rewriting, and facet suggestion, jointly modeling intent and structured extraction. It uses multi-task instruction tuning with homogeneous (single-task) batching to reduce gradient interference, choosing SFT over DPO for strict JSON-schema control, served via vLLM/gRPC under a 600ms P95 constraint. The fine-tuned model beats legacy NER on location/company precision-recall, and online A/B testing shows +33% NDCG, -59% poor matches in top-10, and >75% less maintenance overhead.
