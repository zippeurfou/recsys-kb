Multi-interest recommendation has gained attention, especially in industrial retrieval stage. Unlike classical dual-tower methods, it generates multiple user representations instead of a single one to model comprehensive user interests. ## Technical note

Xiaohongshu's GemiRec is a framework-level refinement for multi-interest retrieval addressing interest collapse (homogenized representations) and weak interest-evolution modeling. It uses interest quantization to enforce structural, non-overlapping item clustering via a shared quantized Interest Dictionary (proven to induce a Voronoi partition giving a lower bound on interest separation, stronger than soft-constraint regularization), plus a generative model decoupled from the user tower that explicitly learns future interests through an independent next-interest prediction task. Its three modules (IDMM dictionary maintenance, MIPDM posterior distribution, MIRM multi-interest retrieval) outperform MIND/ComiRec-style baselines; deployed in production since March 2025.
