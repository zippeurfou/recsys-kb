## Technical note

S2GR (Stepwise Semantic-Guided Reasoning in latent space) is a reasoning-enhanced generative recommendation framework that fixes two flaws of prior reasoning-GR: imbalanced compute across hierarchical SID codes and uninterpretable, unverifiable reasoning vectors. It first optimizes the RQ-VAE codebook using item co-occurrence plus load-balancing and uniformity objectives to reinforce coarse-to-fine hierarchy, then inserts a thinking token before each SID generation step whose coarse-grained semantics are supervised via contrastive learning against ground-truth codebook cluster distributions. On Amazon Beauty and a large industrial dataset it beats SOTA on HR@K/NDCG@K, and a 7-day online A/B test against TIGER at a large short-video platform showed significant gains (e.g. app usage duration +0.092%).
