## Technical note

IterQR is an iterative LLM-based query-rewrite framework deployed in Meituan Delivery's location-based search. Each iteration runs three stages: rewrite generation using domain knowledge via RAG plus query understanding via Chain-of-Thought; online signal collection with automatic positive-rewrite updates; and multi-task post-training of the LLM using the collected positives as labels to seed the next iteration. It self-corrects and continually updates rewrites (handling typos, abbreviations, local dishes) and reports significant improvements in the deployed food-delivery search system.
