## Summary

Generative Retrieval (GR), used in e-commerce search, faces challenges aligning complex user preferences using Direct Preference Optimization (DPO) on structured Semantic IDs (SIDs). RAD-DPO addresses three key DPO limitations: protecting shared prefixes, mitigating noisy pseudo-negatives, and alleviating a "squeezing effect" for multi-label queries. It introduces token-level gradient detachment, similarity-based reward weighting, and a global contrastive objective, demonstrating significant improvements in ranking quality and training efficiency through extensive offline and online testing.

## Technical note

RAD-DPO adapts Direct Preference Optimization to autoregressive semantic-ID generative retrieval, fixing three failure modes when DPO meets hierarchical SIDs. Token-Level Gradient Detachment applies stop-gradient over the longest common prefix shared by positive and negative SIDs, removing 'push-pull' gradient conflict on shared category tokens while preserving forward likelihood. Representation-based Dynamic Reward Weighting softens penalties on noisy exposed-but-unclicked pseudo-negatives via semantic similarity. Multi-label Global Contrast replaces pairwise DPO with a reference-free, length-normalized (SimPO-style) log-sum-exp objective plus a global SFT term over all session positives, implemented with a block-diagonal attention mask and aligned position IDs so all candidates are scored in one forward pass, cutting GPU memory ~50%. Offline and JD.com online A/B tests show gains in retrieval precision and training efficiency.
