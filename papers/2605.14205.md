## Technical note

SimPersona learns discrete buyer types from raw e-commerce clickstreams and exposes them to LLM-based web agents as compact persona tokens, replacing brittle hand-crafted prompt personas. A behavior-aware VQ-VAE induces a discrete buyer-type space capturing merchant-specific population distributions; each learned type is mapped to a dedicated persona token in the agent vocabulary and the agent is fine-tuned on real browsing traces, with population-level simulation done by sampling types from each merchant's empirical codebook distribution. Evaluated on 8.37M buyers across 42 held-out live storefronts, SimPersona reaches 78% conversion-rate alignment with real buyers, shows interpretable behavioral variation, and beats a baseline with 8x more parameters on goal-oriented shopping tasks.
