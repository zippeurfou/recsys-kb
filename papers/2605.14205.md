## Summary

Existing large language model (LLM) web agents for e-commerce often use a single, average buyer persona, failing to capture the diversity of real shoppers. The paper introduces SimPersona, a framework that automatically discovers distinct buyer types (personas) from historical clickstream data using a behavior-aware VQ-VAE model. These learned personas are then integrated into LLM agents as dedicated tokens, allowing the agents to simulate different buyer types, maintain real-world population distributions, and personalize their interactions, significantly improving conversion rates and task performance.

## Technical note

SimPersona learns discrete buyer types from historical e-commerce traffic and exposes them to LLM-based web agents as compact persona tokens, addressing the tendency of such agents to collapse to a single average-buyer policy. A behavior-aware VQ-VAE encodes each buyer's clickstream (a 403-dim vector of 16 behavioral scalars plus PCA-reduced product embeddings) into one of K codebook entries, each mapped one-to-one to a new trainable token in the LLM vocabulary. A two-stage supervised fine-tuning grounds tokens in agent behavior (token warm-up with frozen backbone, then full fine-tuning on replayed browsing traces), decoupling what a token means from how to act on it. Sampling buyer types from each merchant's empirical codebook distribution reconstructs population-level traffic; evaluated on 8.37M buyers across 42 held-out storefronts it achieves 78% conversion-rate alignment.
