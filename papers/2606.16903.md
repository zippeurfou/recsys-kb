## Summary

This paper addresses the limitation of vector databases treating metadata as flat attributes instead of incorporating hierarchical directory semantics natively, commonly used in code repositories and documents.

The authors propose two operators, Directory-Semantic Query (DSQ) for scoped retrieval and Directory-Semantic Maintenance (DSM), along with three implementation strategies: query-time path expansion (PE-Online), ingestion-time path expansion (PE-Offline), and a Trie-based Hierarchical Index (TrieHI).

Analysis reveals that expansion methods have significant drawbacks, including high recursive latency or unscalable write amplification during updates. In contrast, the TrieHI approach stores directories as native prefix trees, enabling efficient recursive queries through tree traversal while minimizing maintenance costs by manipulating directory nodes directly.

## Technical note

This paper makes hierarchical directory semantics a first-class capability in vector databases, formalizing two operators: Directory-Semantic Query (DSQ) for hierarchically scoped retrieval (recursive subtree confinement, non-recursive access, branch exclusion) and Directory-Semantic Maintenance (DSM) for structural moves and merges. It compares query-time path expansion (PE-Online), ingestion-time path expansion (PE-Offline), and a Trie-based Hierarchical Index (TrieHI) that keeps the directory topology as a native prefix tree decoupled from the ANN index. Expansion strategies flatten the hierarchy, incurring high recursive-query latency (PE-Online) or heavy write amplification under structural changes (both), whereas TrieHI enables recursive retrieval via tree traversal and cheap topological node manipulation. Evaluated in ByteDance's Viking engine with released WIKI-Dir and ARXIV-Dir datasets, TrieHI is integrated into the OpenViking context database for filesystem-style agent memory and directory-recursive retrieval.
