## Technical note

CHIME (Compressive Framework for Holistic Interest Modeling) models complete long-term user behavior sequences (lengths reaching tens of thousands) without the signal loss of search-based two-stage (GSU/ESU) methods that discard most behaviors. It uses adapted pretrained LLMs as an Interest Representation Module with multi-layer causal attention, an Interest Adaptation Module to ingest heterogeneous inputs, and an Interest Compression Module using residual vector quantization to produce compact codebook-histogram embeddings; multi-granular contrastive learning captures persistent and transient interests via holistic and immediate losses, with a sample-construction strategy computing thousands of losses per forward pass. Pretrained-LLM initialization consistently beats training from scratch. It improves ranking (CTR/CVR) across short-video, e-commerce, and news datasets.
