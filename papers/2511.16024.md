## Summary

This paper addresses the challenge of real-world image super-resolution (Real-ISR) by integrating sparse Mixture-of-Experts (MoE) architectures, specifically a new Mixture-of-Ranks (MoR) design. MoR treats each LoRA rank as an independent expert, allowing flexible knowledge recombination, while using shared experts to preserve common features. To select the appropriate experts, the paper introduces a degradation estimation module based on CLIP embeddings and proposes a degradation-aware load-balancing loss to dynamically allocate computational resources, leading to state-of-the-art performance.

## Technical note

The paper integrates sparse Mixture-of-Experts into one-step real-world image super-resolution (Real-ISR) via a Mixture-of-Ranks (MoR) design that treats each LoRA rank as an independent expert, isolating fixed-position ranks as shared experts to preserve common features and cut routing redundancy. A degradation estimation module uses CLIP cross-modal similarity between the LR image and predefined positive/negative quality prompts to produce degradation scores that drive expert routing. Zero-expert slots plus a degradation-aware load-balancing loss dynamically scale the number of active experts with degradation severity. Trained with reconstruction, variational score distillation, and GAN losses, MoR-DASR reaches SOTA quality with a single diffusion step and ~40x speedup over multi-step SeeSR.
