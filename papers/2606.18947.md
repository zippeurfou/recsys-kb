## Summary

This paper introduces Decoupled Search Grounding (DSG), an architecture designed to separate real-time search functionality from large language model (LLM) reasoning. The core issue addressed is that current systems tightly couple these components with specific providers, hindering flexibility and control.

DSG acts as a vendor-agnostic gateway, offering explicit first-class controls over the search process like routing, caching, and context rendering independent of the LLM. This decoupling exposes previously hidden aspects of grounding integration.

The results demonstrate that DSG nearly matches native accuracy while significantly reducing search costs (91% lower) and latency (68% lower), preserves concise output contracts, and provides substantial performance improvements in production environments like e-commerce query understanding when compared to standard LLM-integrated search methods.

## Technical note

Decoupled Search Grounding (DSG) moves real-time search grounding out of the reasoning LLM into a vendor-agnostic, MCP-compatible gateway, exposing provider routing, source-aware context rendering, configured fallback, retrieval-depth control, and exact plus semantic caching as first-class controls while keeping the reasoning model interchangeable. It identifies Search-Induced Verbosity, an interface-specific failure where native search breaks strict output contracts (e.g., answer-only prompts) despite explicit instructions, which harms downstream parsers. Across five frontier models on SimpleQA, FreshQA, and HotpotQA, native search leads on recency-sensitive FreshQA, but DSG nearly matches native SimpleQA accuracy (86.1% vs 87.7%) at 91% lower search cost with a 99.4% warm-cache hit rate and 68% lower latency. Deployed as a shared production grounding layer for an e-commerce query-intent-understanding workload, it matches or exceeds native accuracy while cutting search cost over 98%.
