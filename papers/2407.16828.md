## Summary

This paper introduces MultiTRON, a transformer-based recommender system designed for multi-objective session-based recommendations. It leverages Pareto front approximation to manage trade-offs between metrics like click-through and conversion rates, achieved by training the model on various preference vectors. After training, the system can be adapted for different stakeholder needs by adjusting an input vector to select specific points along the Pareto front, offering flexible recommendations. The model's effectiveness was validated through extensive offline and online testing, and its source code is publicly available.

## Technical note

MultiTRON adapts Pareto front approximation to multi-objective session-based recommendation by extending the Transformer-based TRON model. Instead of training a separate model per Pareto point, it samples preference vectors from a Dirichlet distribution during training and feeds them as input features, so a single trained model can access the whole Pareto front at inference by adjusting the objective-weighting input vector. A non-uniformity KL-based regularization term improves diversity and coverage of the front, preventing collapse while keeping training efficient. It balances competing objectives such as click-through and conversion rates, validated through extensive offline evaluation and online A/B testing on e-commerce (OTTO) data, with source code released.
