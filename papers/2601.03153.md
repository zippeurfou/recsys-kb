## Summary

1.  Existing sequential recommendation models struggle with sparse user data and often rely on deep, single reasoning paths, which become less effective as the depth increases.
2.  To overcome this, the authors introduce Parallel Latent Reasoning (PLR), a new framework that explores multiple diverse reasoning paths simultaneously within a continuous latent space, using learnable triggers and regularization.
3.  PLR significantly outperforms previous state-of-the-art methods on real datasets and maintains fast inference speed, demonstrating that parallel reasoning enhances recommendation quality and generalization beyond traditional depth-based scaling.

## Technical note

Tackles the diminishing returns of depth-only latent reasoning in sequential recommendation over sparse user behavior sequences. It proposes Parallel Latent Reasoning (PLR), which adds width-level scaling by spawning multiple diverse reasoning trajectories via learnable trigger tokens in continuous latent space. Global reasoning regularization prevents stream homogeneity, and a mixture-of-reasoning-streams module adaptively aggregates outputs while a contrastive objective improves robustness. On three real-world datasets PLR outperforms state-of-the-art baselines while preserving real-time inference efficiency.
