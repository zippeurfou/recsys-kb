## Technical note

Applies generative retrieval (GR) to book search, where books carry multi-faceted, hierarchically structured content (metadata, outline, main text) that strains standard docid generation. GBS combines (i) data augmentation: coverage-promoting book identifier augmentation building hierarchical book/chapter/section identifiers (chapter/section semantic numbers via hierarchical K-means, akin to semantic IDs) mapped from five content granularities, and diversity-enhanced LLM-generated pseudo-queries (single- vs multi-chapter); and (ii) outline-oriented book encoding for length extrapolation via bi-level positional encoding (absolute section-level + rotary chapter-level) and outline-oriented retentive attention (a linear-attention memory module gated with standard MHA). Trained with MLE multi-task indexing+retrieval and prefix-tree constrained decoding; on a proprietary Baidu dataset GBS beats the SOTA GR baseline RIPOR by 9.8% MRR@20, with robustness confirmed on the public WhatsThatBook dataset.
