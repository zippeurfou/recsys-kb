## Summary

Multi-Agent Grounded Reasoning for 3D Understanding":

Vision-language models (VLMs) struggle with complex, grounded 3D reasoning tasks, often requiring specific training or custom pipelines for limited environments. To address this limitation, the authors introduce MAG-3D, a novel, training-free framework utilizing multiple expert agents. MAG-3D dynamically coordinates a planning agent (for task decomposition), a grounding agent (for identifying relevant scene parts), and a coding agent (for geometric reasoning and verification) using standard VLMs, enabling flexible, zero-shot 3D understanding across diverse scenes.

## Technical note

MAG-3D is a training-free multi-agent framework for grounded 3D reasoning with off-the-shelf VLMs (Seed-1.6, GPT-4o). A Planning Agent decomposes queries and orchestrates a Grounding Agent (open-vocabulary 3D instance identification via SAM3 masks lifted with VGGT depth/pose, plus mirror-aware filtering and volumetric visual-memory frame retrieval) and a Coding Agent (multi-round Python execution for geometric computation and verification). Agents share a scene memory enabling iterative grounding-verification. On Beacon3D it improves case-level QA by +6.4/+4.8 over GPT-4o/Seed-1.6 and beats the trained SceneCOT baseline; ablations show grounding-agent backbone matters more than coding, and 3D volumetric visual memory beats 2D mask-area frame selection.
