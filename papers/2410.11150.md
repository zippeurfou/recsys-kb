## Summary

1.  This paper introduces Sequential Masked Modeling (SMM), a novel technique designed to enhance encoder-only transformer models specifically for session-based recommendation, where predicting the next item must be done without relying on long historical sequences.
2.  SMM combines window sliding data augmentation with masking tokens at the very end of each input sequence, aiming to capture relevant sequential dependencies more effectively within a single session.
3.  Evaluated against various state-of-the-art methods on three standard datasets (Yoochoose 1/64, Diginetica, and Tmall), the Transformer-SMM models showed significantly improved next-item prediction performance, even competing favorably with approaches using longer user histories.

## Technical note

Session-based recommendation must predict the next item from a single anonymous session without user history, where transformers borrowed from NLP underperform strong GNN baselines. The authors introduce Sequential Masked Modeling (SMM) for encoder-only transformers, combining sliding-window data augmentation with a penultimate-token masking strategy to better capture sequential dependencies. They evaluate BERT and DeBERTa encoders (plus a GPT decoder) on Yoochoose 1/64, Diginetica, and Tmall. Transformer-SMM consistently beats models using the same information budget and rivals cross-session methods that access more user history.
