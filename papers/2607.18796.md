## Summary

1.  Existing generative retrieval systems for e-commerce searches like Taobao primarily focus on semantic matching, ignoring the business value (relevance and commercial impact) of items during ranking, which often misses or degrades high-value results.
2.  The paper introduces TSGR, a unified framework that incorporates item business value into both its SID construction process using Query-aware Parallel SIDs (QP-SID) derived from query statistics and the actual items' value rankings, and into candidate ranking via a Value-aware Ranking Module (VRM).
3.  By jointly training within this value-conscious system, TSGR significantly improves search relevance metrics and crucially boosts business KPIs like click-through rate potential (HR), leading to measurable increases in key online indicators such as IPV (+0.43%), Transaction Count (+1.12%), and GMV (+1.64%).

## Technical note

TSGR is a production generative-retrieval framework for Taobao Search that injects business-value awareness into a single autoregressive model generating item Semantic IDs. Query-aware Parallel SID (QP-SID) builds category/cluster semantic codebooks (RQ-KMeans) plus query-conditioned efficiency codebooks that assign higher-value, query-relevant items earlier token indices, while a Value-aware Ranking Module (VRM) fuses backbone-derived user representations with item side-info via cross-attention and PV/CTR/CVR heads. Crucially VRM is jointly optimized with the generation objective so one model serves as BOTH retriever and pre-ranker -- an explicit unification that collapses the traditional retrieval to pre-ranking cascade into a single-stage generative pipeline, skipping the dedicated pre-ranking stage. It achieves +9.16% HR@1000 offline and online A/B gains of +0.43% IPV, +1.12% Transaction Count, and +1.64% GMV (backbone Qwen2.5-0.5B; GRPO RL explored but VRM adopted), and is fully deployed.
