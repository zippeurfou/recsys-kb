## Summary

This paper addresses the limitations of separating recall and ranking stages in recommendation systems by proposing UniR², an integrated Transformer model combining generative recall and multi-objective ranking into a single sequence using heterogeneous data like user context and item features.

UniR² employs dual-query prefix-causal attention to manage task-specific information visibility within its unified architecture, allowing both functionalities while preserving the underlying shared structure of base attention weights.

The key innovation is retaining separate optimization boundaries for each task without compromising the generative backbone. Experiments on large-scale data show UniR² improves both effectiveness and efficiency, with positive online results validating its practicality in industrial settings.

## Technical note

UniR^2 unifies generative recall and multi-objective ranking in a single decoder-only Transformer to remove the recall-then-ranking cascade's objective inconsistency, candidate hand-off information loss, and redundant user-context computation. It arranges user context, an autoregressively generated SID trajectory (3-layer Res-Kmeans, codebook 8129), and item-feature tokens in one heterogeneous sequence where the SID trajectory bridges the two tasks; Dual-Query Prefix-Causal Attention gives the generative query prefix-causal visibility and the ranking query bidirectional feature-fusion visibility over shared base attention weights, while ranking-side LoRA plus stop-gradient isolate ranking gradients from the generative backbone (MMoE ranking towers). On Kuaishou live-streaming logs it beats generative-recall baselines (OneRec/OneLive/PROMISE) by about +3-5% HR/MRR and improves ranking AUC/UAUC over the deployed MMoE ranker, with single-service KV-cache reuse cutting latency; online A/B (June 2026, 5% traffic) lifted play +1.18%, like +2.56%, and gifting amount +2.57%. This is an explicit unified single-stage generative pipeline (one model, one forward pass, one service) that collapses candidate generation and ranking.
