## Summary

Multi-Behavior User Profiling for Enhanced Candidate Generation in Recommender Systems":

Online platforms gather diverse user feedback, but traditional recommender systems limit users to single behavior vectors, restricting recommendations and struggling with cold-starts. The Tricolore framework addresses this by learning multiple distinct user preference vectors simultaneously, capturing a broader range of interests during candidate generation. It employs an adaptive multi-task structure combined with specialized fusion modules for different sparse behaviors and balances diversity with popularity, effectively improving recommendation quality across various platforms like e-commerce and short videos.

## Technical note

Tricolore is a multi-behavior candidate-generation framework that represents users with multiple behavior-class vectors instead of a single embedding, avoiding rigid predefined behavior sequences. It groups K feedback types into C correlation-based classes (strong/moderate/weak), learns per-class embeddings plus a shared base embedding, and fuses them via a gate-controlled behavior-wise multi-view module that lets sparse behaviors borrow from the global base. An allied multi-task prediction scheme softly chains behaviors, and a popularity-balanced negative sampling scheme mitigates popularity bias while trading off accuracy and diversity. Experiments on short-video and e-commerce datasets show gains over state-of-the-art MBRS models, especially for cold-start users via the shared base embedding.
