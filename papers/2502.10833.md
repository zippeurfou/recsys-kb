Leveraging Large Language Models (LLMs) for generative recommendation has attracted significant research interest, where item tokenization is a critical step. It involves assigning item identifiers for LLMs to encode user history and generate the next item. ## Technical note

SETRec introduces an order-agnostic set-identifier paradigm for LLM-based generative recommendation, avoiding both token-sequence identifiers (beam-search local optima, slow step-by-step decoding) and single-token identifiers (weak semantics/CF). Each item is a set of order-agnostic tokens produced by CF and semantic tokenizers; a sparse attention mask encodes user history and a query-guided mechanism enables simultaneous token generation. Instantiated on T5 and Qwen (1.5B-7B), across four datasets it improves full/warm/cold-start ranking and efficiency, with promising cold-start scalability as model size grows.
