## Summary

This paper addresses the challenge of using ultra-long user history sequences (up to one million items) in recommendation systems, which causes significant latency and cost issues. The authors propose VISTA, a novel two-stage framework that summarizes the entire user history into a fixed number of hundreds of tokens, effectively decoupling the summarization from the attention process. VISTA caches these summary tokens, allowing downstream models to operate efficiently regardless of the user history length, enabling lifelong recommendations at scale while keeping costs fixed, and has been successfully deployed in industry.

## Technical note

VISTA (Virtual Sequential Target Attention) tackles the cost of modeling ultra-long (up to one million item) user histories by decomposing target attention into two stages: first summarize the user history into a few hundred summarization tokens, then compute candidate-item attention only against those cached tokens. The summarization stage runs only during foundational model training and its embeddings are cached in storage, so downstream training and inference cost stays fixed regardless of history length, trading GPU compute for cheaper storage. The method contributes a quasi-linear attention formulation for recommendation and a generative sequential reconstruction loss, plus an embedding delivery system. Deployed on an industrial platform serving billions of users, it delivers significant offline and online metric gains.
