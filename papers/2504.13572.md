## Technical note

Spotify proposes a pipeline that uses LLMs to enrich audiobook metadata against a hand-built 10-type descriptor taxonomy (genres, moods, themes, tropes, etc.), then generates personalized 'descriptive shelves' (e.g. 'Uplifting Women's Fiction') over two-tower candidate sets by ranking, diversifying, and filtering descriptors as shelf titles. This addresses the audiobook cold-start problem where user reviews/tags are unavailable. A second A/B test on Spotify's audiobook home subfeed showed large gains over editor-curated shelves: +35.25% impression-to-click, +86.96% impression-to-stream, and >600% more distinct audiobooks impressed/interacted, improving both engagement and discovery.
