## Summary

This paper identifies feature extraction from raw user data as a significant bottleneck for on-device machine learning model latency. To address this, the authors introduce AutoFeature, an automated engine that optimizes the extraction process through graph-based workflow analysis, redundant operation fusion, and efficient caching. Their system prototype, integrated into real-world mobile services, achieves substantial end-to-end latency reductions, demonstrating effective acceleration without sacrificing inference accuracy.

## Technical note

AutoFeature identifies feature extraction from raw app logs (not model inference) as the dominant bottleneck in on-device ML pipelines, accounting for 61-86% of execution latency because user-behavior features require repeated resource-intensive operations. It represents each model's feature extraction as a directed acyclic FE-graph where operation nodes correspond to orthogonal filtering conditions over raw logs. Graph optimization detects and fuses redundant operation nodes across features within one inference (inter-feature) via intersection of filtering conditions, and efficient caching reuses intermediate results on overlapping raw data across consecutive inferences (cross-execution). Deployed across five industrial mobile services (search, video, e-commerce), it reduces end-to-end latency by 1.33x-3.93x during daytime and up to 4.53x at night without changing inference accuracy.
