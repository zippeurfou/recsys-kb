## Summary

CiteRadar is an open-source platform designed to analyze a researcher's citation impact and geographic reach by providing detailed data and interactive visualizations. It addresses the lack of accessible tools by automatically gathering publication and citation information from various sources and integrating them into a structured output, including citation statistics and a world map showing author locations. Key technical contributions include advanced parsing, author disambiguation, location data retrieval, and a specialized visualization method.

## Technical note

CiteRadar is an open-source CLI tool that takes a Google Scholar user ID and runs a five-stage pipeline: scraping the publication list, following 'Cited by' links to collect citing papers, resolving per-author metadata via a priority cascade over OpenAlex, Semantic Scholar, and CrossRef, building two ranked author tables (by citation count and by h-index), and rendering an interactive Folium world map. A two-stage author disambiguation step uses stop-word-filtered institution-name similarity to prevent same-name entity merging, reportedly eliminating h-index attribution errors up to 9x. A Scholar meta-string parser handles Unicode non-breaking-space separators that silently corrupt venue/year fields, and an OpenAlex web-URL to API-URL fix raises city-level location coverage from 0% to about 60%. Anti-ban mitigations include realistic browser fingerprints, request pacing, and 429 backoff, and each stage writes JSON output to enable restart after interruption.
