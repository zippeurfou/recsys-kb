## Summary

This paper introduces **ConvRec-R1**, a two-stage framework for training LLM-based conversational recommender systems. The first stage uses a pipeline to create high-quality demonstrations for behavioral cloning. The second stage proposes **Rank-GRPO**, a specialized reinforcement learning method treating each recommendation rank as a unit to improve ranking quality and policy stability. Experiments on Reddit-v2 show that ConvRec-R1 achieves faster convergence and higher recommendation metrics compared to baseline methods.

## Technical note

ConvRec-R1 is a two-stage framework for training LLM-based conversational recommenders that generate natural-language item lists rather than ID tokens. Stage 1 builds a behavioral-cloning SFT dataset via a Remap-Reflect-Adjust pipeline that distills a teacher LLM's zero-shot lists into catalog-grounded demonstrations, correcting out-of-catalog items, formatting, and popularity bias. Stage 2 introduces Rank-GRPO, an extension of GRPO that treats each rank position (not token or full sequence) as the credit-assignment unit, masking rewards to avoid non-causal assignment and using a rank-level importance ratio from the geometric mean of rank-wise token probabilities. On the public Reddit-v2 dataset ConvRec-R1 converges faster and achieves higher Recall and NDCG than GRPO-style baselines.
