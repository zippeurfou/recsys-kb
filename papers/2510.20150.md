## Technical note

ConvRec-R1 (Netflix) is a two-stage framework for training LLM-based conversational recommenders that generate items in natural language. Stage 1 builds a behavior-cloning SFT dataset via a Remap-Reflect-Adjust pipeline that turns a blackbox teacher LLM's zero-shot lists into catalog-grounded, well-formatted, popularity-debiased demonstrations. Stage 2 introduces Rank-GRPO, an extension of group relative policy optimization treating each rank (not token or full sequence) as the unit, with reward masking to remove non-causal credit assignment and a rank-level importance ratio (geometric mean of rank-wise token probabilities). On Reddit-v2 it converges faster and achieves higher Recall and NDCG than GRPO-style baselines.

- For out-of-catalog (OOC) or hallucinated items. Since these items are recommended by the LLM, it can still generate plausible metadata crucial for mapping them back to the catalog
- For in-catalog items unknown to the LLM (e.g., niche or recent items), we employ retrieval augmented generation (RAG) and in-context learning (ICL). We retrieve external information about the item via [Google Search API](https://developers.google.com/custom-search/v1/) on [Wikipedia](https://www.wikipedia.org/), [IMDb](https://www.imdb.com/news/top/), and [Rotten Tomatoes](https://www.rottentomatoes.com/) and provide it to the LLM along with few-shot examples to guide the generation
- Item-Item Similarity ($\bm{S}_{\text{item-item}}$): We calculate the content-based semantic similarity between every item in the teacher’s space $\mathcal{C}_{\Theta}$ and every item in the target catalog $\mathcal{C}$. The generated metadata are embedded using a pre-trained sentence-transformer model (we use [NovaSearch/stella_en_400M_v5](https://huggingface.co/NovaSearch/stella_en_400M_v5) in this paper). The cosine similarity between these embeddings forms the item-item similarity matrix $\bm{S}_{\text{item-item}}\in\mathbb{R}^{|\mathcal{C}_{\Theta}|\times|\mathcal{C}|}$
- Conversation-Item Similarity ($\bm{s}_{\text{context}}$): To further enhance the contextual relevance, we compute the similarity between the conversation $x^{\text{SFT}}_{i}$ and each item in the catalog $\mathcal{C}$. We embed $x^{\text{SFT}}_{i}$ with the same Stella model and its cosine similarity with each catalog item’s metadata embedding is calculated, resulting in a context vector $\bm{s}_{\text{context}}\in\mathbb{R}^{|\mathcal{C}|}$
