## Summary

Recommender systems face a problem called behavioral intensity imbalance, where highly active users skew training data, leading to biased recommendations. To address this, the paper introduces PEARL, a novel contrastive learning framework that models relative user preferences instead of absolute engagement counts, providing an unbiased estimation of percentile-based preferences. PEARL directly approximates percentile relationships using pairwise comparisons and includes mechanisms for handling sparse feedback, demonstrating significant improvements in recommendation quality and real-world deployment success.

## Technical note

PEARL addresses behavioral-intensity imbalance, where highly active or high-spending users dominate feedback signals and distort learned preferences, by predicting relative user-wise percentiles F_u(y) instead of raw watch-time or interaction magnitudes. It is a nonparametric contrastive framework that approximates percentile relationships directly from naturally occurring pairwise interaction comparisons trained with a (multi-sample) binary cross-entropy loss, avoiding the auxiliary distribution-estimation model used by prior relative-advantage debiasing (RAD). A user-keyed reservoir pool (N=50) maintains an unbiased historical distribution, and extensions add prediction-based bootstrapping for sparse discrete feedback, a value-weighted formulation, and a co-training strategy. Deployed on a billion-user livestream platform it yields +2.10% Watch Duration, +0.80% Consumption Amount, +1.49% Interaction Rate, and -6.91% Report Rate.
