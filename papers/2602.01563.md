## Summary

This paper introduces AdNanny, a unified large language model (LLM) designed to handle multiple offline advertising tasks collectively. It consolidates various specialized LLMs by fine-tuning a massive base model using a unique training system and reasoning-augmented data, enabling it to perform diverse tasks consistently. AdNanny significantly improves accuracy and reduces manual effort across multiple advertising tasks and is successfully deployed in Bing Ads.

## Technical note

AdNanny is a single reasoning-centric LLM that consolidates many task-specific offline ads models (query-ad and ad-user relevance labeling, keyword query generation, user profile generation) into one backbone for Bing Ads. It fine-tunes a 671B DeepSeek-R1 hybrid dense-MoE checkpoint using a custom Megatron trainer, on corpora that pair structured supervision with step-by-step natural-language explanations. Training uses multi-task supervised fine-tuning with adaptive task- and instance-level reweighting, followed by an RL stage that aligns outputs with downstream ads metrics via offline evaluators as rewards. Deployed in production, it cut manual labeling effort and improved accuracy, letting the team retire a zoo of small task-specific models whose signals were previously distilled.
