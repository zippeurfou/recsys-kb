## Summary

This paper addresses the challenge of generative query suggestion, where systems recommend follow-up queries that cover distinct user intents while ensuring each individual query is useful. It introduces an Intent-Driven Framework with two stages: first, it creates intent-aligned data and uses a diversity reward to optimize for broad intent coverage during training. Second, it employs a method called query-level credit assignment to specifically evaluate and improve the quality of each individual query within the recommended slate. Experiments on large-scale datasets demonstrate that this approach improves user engagement metrics like click-through rate and query quality.

## Technical note

LLM-generated follow-up query slates for an assistant must be individually useful and cover distinct intents. The framework builds intent-aligned SFT data with an Intent-Aware Diversity Reward, then applies query-level credit assignment in RL: each query's quality advantage is routed only to that query's tokens while a slate-level intent-coverage advantage is shared across the slate in one policy update, on a Qwen3-30B-A3B base. In a one-week user-bucketed online A/B test, relative to a prompt-engineering arm, SFT gives +27.06% CTR, PPO +35.29%, GRPO +43.53% and the proposed method +48.24% (+16.7% vs the incumbent SFT arm, p=0.003; +3.25% vs GRPO, p=0.02), with paired gains in GSB, intent coverage and LLM-critic scores. On Qwen3-235B-A22B offline, LLM-critic and intent coverage rise from 0.57/0.58 to 0.92/0.94.
