## Summary

Current memory systems for LLM agents often lose critical context due to lossy vector storage. To address this, the paper introduces D-Mem, a dual-process system combining fast vector retrieval with a high-fidelity Full Deliberation module. D-Mem uses a quality gating policy to decide which queries need the more thorough deliberation, achieving significantly better performance (higher F1 score) than baseline methods while remaining computationally efficient.

## Technical note

D-Mem is a dual-process memory system for LLM agents that addresses lossy abstraction in incremental, query-agnostic memory compression, where continuously extracting and updating conversational memories into vector databases strips contextual nuance needed for temporal logic and multi-hop dependencies. It keeps a fast System 1 (Mem0*) doing low-cost Top-K static retrieval over compressed memory, and adds a System 2 Full Deliberation module that bypasses compression to process the raw dialogue history with a query-guided temporal scan, scoring chunks 0-10 and applying multi-stage filtering to synthesize a high-fidelity answer. A Multi-dimensional Quality Gating policy dynamically routes queries between the two processes to achieve cognitive economy. On LoCoMo with GPT-4o-mini the gating policy scores F1 53.5, beating the static Mem0* baseline (51.2) and recovering 96.7% of Full Deliberation's performance (55.3) at substantially lower cost; it is also evaluated on RealTalk with Qwen3-235B-Instruct.
