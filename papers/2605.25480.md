## Summary

Current Retrieval-Augmented Generation (RAG) systems treat external knowledge as static chunks, poorly supporting agents that need to reason. To address this, the paper introduces LLM-Wiki, an agent-native retrieval system that organizes knowledge into compilable, composable Wiki pages with bidirectional links and self-correction mechanisms. LLM-Wiki significantly outperforms existing RAG baselines on various reasoning tasks, demonstrating that structured knowledge organization is more effective than simple retrieval for agent reasoning.

## Technical note

LLM-Wiki compiles raw documents into interlinked, human-readable Wiki pages with metadata, aliases, tags, and bidirectional wikilinks, replacing flat-chunk vector retrieval with agent-planned search, read, and link-following operations. It formalizes three principles—compilability, composability, and evolvability—and exposes wiki_search and wiki_read tools so a ReAct-style agent iteratively traverses evidence and checks sufficiency before answering. An Error Book provides persistent self-correction by detecting recurring structural errors (dangling links dominate at 29-64%) and semantic errors, attributing root causes, and driving two-layer deterministic and LLM-based repair. It reaches state-of-the-art on HotpotQA, MuSiQue, and 2WikiMultiHopQA, beating HippoRAG 2, LightRAG, and GraphRAG by 2.0-8.1 F1, with gains growing as hop count increases.

- Direct Retrieval: For single-entity factual queries, the agent issues one wiki_search, reads the target page, and extracts the answer directly, often completing the task in one or two tool calls
- Link-Following Traversal: For multi-hop bridge queries, the agent reads entity pages and follows explicit links_to pointers. Each hop is guided by structured links rather than probabilistic retrieval alone
- Browse & Aggregation: For open-ended or comparative queries, the agent reads directory index pages (_index.md) to obtain a structured overview and then selectively batch-reads relevant pages. This strategy mirrors how humans browse a table of contents before focusing on relevant pages
