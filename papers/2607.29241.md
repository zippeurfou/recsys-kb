## Summary

1.  RecHarness automates the optimization process for complex recommender systems by using a bandit router to select modification directions based on historical feedback and an LLM to generate hypotheses and code edits within that direction.
2.  It addresses instability issues often found in pure LLM-based search under limited experimental budgets by structuring this two-step selection-hypothesis generation workflow, resulting in more stable performance improvements.
3.  To ensure long-term exploration and prevent stagnation from local edits, RecHarness employs a jump-basin mechanism that activates structural changes when further refinement within an area no longer yields benefits, effectively using trial budgets better than LLM-reasoning alone across various tasks.

## Technical note

Automated recommender-model iteration with LLM MLE agents is unstable because letting the LLM both choose the modification direction and write the patch searches an open space where every trial costs a full train-validate cycle. RecHarness decouples the two: a Thompson-sampling router maintains a Beta(alpha_a, beta_a) posterior per human-defined edit arm (learning-rate schedule, dropout/weight decay, embedding dim, layer or head count, sequence pooling, added features, loss function) and picks the top-G sampled arms each round, while a frozen LLM conditioned on the incumbent, execution logs and a distilled textual Experiment Skill memory produces the concrete hypothesis and executable code mutation inside the selected arm. Arm rewards are binary: a trial counts as a success only if it is valid, beats the group-normalized advantage (A_hat > 0) and is at least the historical incumbent score, and a basin-aware jump mechanism admits structural jump arms once the W-round improvement rate falls below tau, accepting a jump only if it exceeds the pre-jump incumbent by delta after up to R local retuning rounds. Under a fixed 43,200s GPU budget, RecHarness lifts average HR@10 across four Amazon Reviews datasets by 85.85% on GRU4Rec (0.2685 to 0.4990) and 12.58% on HSTU (0.4723 to 0.5317), beating published results for all five sequential backbones, and on KuaiRec cuts TPM WT-MAE by 26.37% and WR-MAE by 26.41% while improving all four watch-time / watch-ratio metrics for D2Q, TPM and GR. SASRec ablations show routing is the main driver: 47.92% of RecHarness trials refresh the round-start best validation score versus 22.45% for random routing, 21.74% for LLM-chosen arms and 41.67% for no-bandit free search (max gain 24.00% vs 10.16%); in production the router escalated to a sequence_encoder_upgrade jump arm that applied self-attention to each of six real-time behavior sequences (32-dim each, concatenated to 192-dim into a shared-bottom ranker), giving +0.09% offline AUC and, in a 7-day 10%-traffic A/B test on a short-video ad platform, +2.084% ADVV, +0.534% revenue and +0.559% exposure.
