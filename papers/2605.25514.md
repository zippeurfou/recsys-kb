## Summary

This paper introduces Query-Conditioned Generative Search (QGS), a generative model designed for search ranking that specifically handles query-driven user interactions. QGS overcomes limitations of existing methods by encoding interactions as (query, item) pairs and training with a query-conditioned objective, preventing the mixing of different query intents. It also addresses computational challenges with a Linear HSTU encoder for linear complexity and proposes HFG-Attention to integrate traditional hand-crafted search features into the generative framework, achieving significant online performance improvements.

## Technical note

QGS (Query-Conditioned Generative Search) adapts generative recommendation to query-driven search ranking in Quark, encoding user interactions as (query, item) pairs and training with a query-conditioned objective so different query intents are not mixed. To keep it efficient it uses a Linear HSTU encoder with linear complexity in sequence length. It also proposes HFG-Attention to fold traditional hand-crafted search features into the generative framework. The method reports significant online performance improvements, extending item-only generative recommenders (HSTU/generative retrieval) to the query-item search setting.
