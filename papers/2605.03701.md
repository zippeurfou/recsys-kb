## Summary

SERE is a framework designed to enhance Large Language Models' (LLMs) performance in Event Causality Identification (ECI), a task where LLMs often overpredict causal relationships. It achieves this by retrieving relevant structural examples based on three metrics: ConceptNet edit distance, syntactic tree edit distance, and LLM-filtered causal patterns. Experiments show SERE improves ECI accuracy by providing more focused guidance for causal reasoning.

## Technical note

SERE (Structural Example Retrieval) is a framework that improves LLMs on Event Causality Identification (ECI), a task where LLMs tend to over-predict causal relations. It retrieves structurally relevant in-context demonstrations using three complementary metrics: ConceptNet edit distance between event concepts, syntactic tree edit distance, and LLM-filtered causal patterns. By selecting examples that structurally match the query event pair rather than generic few-shot examples, SERE provides more focused guidance for causal reasoning and reduces spurious causal predictions. Experiments show SERE improves ECI accuracy over baselines.
