## Summary

This paper addresses the challenge of optimizing memory usage for large-scale Deep Learning Recommendation Models (DLRMs) in tiered memory systems. The proposed solution, RecMG, uses machine learning to predict embedding vector accesses and guide caching and prefetching strategies. RecMG significantly reduces on-demand memory fetches and end-to-end inference time for DLRM models.

## Technical note

Addresses serving terabyte-scale DLRM embedding tables on tiered memory, where LRU-style caching fails for embedding vectors with long reuse distances or few reuses, causing costly on-demand fetches. RecMG uses two separate ML models—one for caching (framed as binary keep-in-cache classification to solve the data-labeling explosion) and one for prefetching a sequence of embedding-vector indices with a novel differentiable loss that narrows the huge prediction search space. It learns implicit, cross-user embedding access correlations that traditional delta-based prefetchers cannot capture. Against state-of-the-art temporal, spatial, and ML prefetchers it cuts on-demand fetches by 2.2x/2.8x/1.5x and reduces end-to-end industrial DLRM inference time by up to 43%.
