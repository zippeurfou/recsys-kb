## Technical note

BBQRec (Behavior-Bind multi-modal Quantization for Sequential Recommendation) addresses two limitations in multi-modal generative sequential recommendation: fragmented quantization where modalities map to semantic spaces misaligned with behavioral objectives, and over-reliance on semantic IDs that disrupts inter-modal coherence. A behavior-semantic alignment module uses mutual-information minimization plus contrastive codebook learning to disentangle modality-agnostic behavioral patterns from modality-specific noise, tying semantic IDs to the recommendation task. A discretized similarity-reweighting mechanism dynamically adjusts self-attention scores using quantized semantic relationships, preserving multi-modal synergies non-invasively. Across four real-world benchmarks BBQRec outperforms state-of-the-art sequential recommendation baselines.
