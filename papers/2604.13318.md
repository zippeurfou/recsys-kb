## Summary

Autonomous web agents often struggle with long tasks due to a "grounding gap" in their skills. Existing skills are either purely executable code (opaque) or natural language instructions (non-executable). The paper introduces WebXSkill, a framework that creates executable skills combining parameterized action programs with natural language guidance, allowing direct execution and agent understanding.

WebXSkill operates through three stages: extracting reusable skills from synthetic agent data, organizing them into a URL-based graph for context-aware retrieval, and deploying them in two modes (fully automated or guided step-by-step execution). This approach significantly improves task success rates on standard benchmarks compared to the baseline.

The core innovation of WebXSkill is bridging the gap by providing skills that are both directly executable and offer step-level natural language guidance for error recovery and adaptation, making complex web workflows more manageable for autonomous agents.

## Technical note

WebXSkill equips LLM web agents with executable skills that pair a parameterized action program (click/type/navigate) with step-level natural-language guidance, bridging the grounding gap between non-executable textual workflows (AWM) and opaque code-based skills (SkillWeaver, WALT, ASI). Its three-stage pipeline mines reusable action subsequences from low-cost synthetic agent trajectories (avoiding test-time data leakage), abstracts them into parameterized skills via LLM generalization, indexes them in a URL-based skill graph for context-aware retrieval, and deploys them in two modes: grounded mode (atomic tool call auto-executing the sequence) and guided mode (step-by-step instructions the agent follows with native actions for adaptation/recovery). It improves task success by up to 9.8 points on WebArena and 12.9 on WebVoyager, with deployment mode adaptively selected by model strength.
