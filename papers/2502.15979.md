## Technical note

ViOC-AG is a cross-modal zero-shot product attribute-value (aspect) generation framework built on CLIP that requires only a product image as input, sparing sellers from typing descriptions. It uses a text-only training process: a task-customized text decoder with a projection layer is trained on the frozen CLIP text encoder to alleviate the modality gap and task disconnection; at inference the frozen CLIP image encoder feeds the trained decoder. OCR tokens and outputs from a frozen prompt-based LLM correct decoded outputs and mitigate object hallucination for out-of-domain values. On the MAVE dataset it significantly outperforms fine-tuned vision-language models for zero-shot attribute value extraction.
