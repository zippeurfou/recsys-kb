## Summary

This paper introduces **ConsRec**, a novel sequential recommendation system designed to address noise in user interaction histories. The core idea is that genuine preferences form connected clusters within the items users interact with; thus, ConsRec uses these user-interacted item graphs and their text representations to extract dense subgraphs (**denoising**) representing stable preferences. Experimental results on Yelp and Amazon datasets show that this approach significantly improves recommendation accuracy (13% over baselines) by effectively filtering out noisy or irrelevant items from the history, leading to more relevant suggestions for users.

The main contribution of ConsRec is its user-consistent preference modeling technique combined with a graph-based denoising strategy. It works by constructing an item interaction graph per user based on their interactions, calculating item similarities using text embeddings (like BERT), and then identifying the densest connected subgraph (**coreference**) which serves as the filtered set of items for generating recommendations. This core-set filtering aims to capture stable preferences while ignoring noise in sequential data.

The paper demonstrates that ConsRec outperforms baseline models by incorporating denoising into a standard recommendation framework. By focusing on densely connected, semantically tight clusters within user interaction histories derived from text representations, ConsRec provides cleaner input for subsequent recommendation generation steps, resulting in more accurate and relevant suggestions compared to methods using raw or noisy sequences.

## Technical note

Sequential recommendation histories contain noisy incidental clicks that dilute genuine user preferences. LISRec learns task-agnostic semantic item representations by instruction-tuning a T5 encoder on item text, then builds a per-user personalized semantic graph connecting items whose cosine similarity exceeds a threshold and extracts the maximal connected component as denoised 'semantic shortcuts' for preference modeling. On Amazon Beauty/Sports/Toys and Yelp it improves up to 13% over baselines and ~4.7% over dedicated denoising methods (DSAN, HSD, DCRec) using a Bert4Rec backbone. Ablations show even a zero-shot filter helps, the trained filter (with threshold tau=0.7) yields the largest gains, and the approach generalizes across ID-based and text-based backbones.
