## Summary

CTR prediction models face challenges due to the vast heterogeneity of features, ranging from extremely sparse to dense ones. Current models often mix all features together during interaction, leading to noise and poor performance as low-information features overwhelm the model. To address this, the paper introduces MGDIN, a framework that adaptively groups features by information density and gradually introduces them into the interaction process, allowing the model to learn effectively from high-quality features first.

## Technical note

MGDIN (Multi-Granularity Information-Aware Deferred Interaction Network) addresses feature heterogeneity in CTR prediction, where extremely sparse features (e.g., item IDs) mixed with dense numeric features under a uniform one-size-fits-all interaction strategy inject noise and cause representation collapse. Its first stage applies a multi-granularity feature grouping that partitions raw features into groups of more homogeneous information density at multiple granularities. Its second stage uses an information-aware deferred interaction: a hierarchical masking strategy masks low-information groups in early layers and progressively unmasks them as the network deepens, so the model first builds robust representations from high-information features before incorporating sparser ones. It replaces raw item IDs with dense semantic IDs from multimodal content plus behavior, and offline plus online A/B experiments confirm gains over state-of-the-art baselines.
