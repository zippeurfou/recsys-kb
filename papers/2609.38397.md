## Summary

1.  The paper addresses the challenge of obtaining large-scale, detailed, and privacy-compliant user interaction logs for online applications like A/B testing and user modeling.
2.  It introduces SimTrace, a framework that generates synthetic, fine-grained, multimodal user trajectories by anonymizing real interactions and creating simulated "twins" of web environments based on real data patterns.
3.  Evaluated on e-commerce tasks, SimTrace produces high-fidelity synthetic data that achieves comparable results to real data for tasks like purchase prediction and recommendation, and improves accuracy for predicting the next user action when combined with real data, all while being released as open-source.

## Technical note

SimTrace generates privacy-preserving, fine-grained multimodal clickstreams for training user-behavior and virtual-client models: it greedily selects sessions that maximize product coverage balanced across browse-only, cart-abandonment and checkout outcomes, maps raw events to a 9-action semantic taxonomy, hashes identifiers with keyed HMAC-SHA-256 and infers a persona and intent per session. A coding agent (Pi harness with GPT-5.5, about $60 per site) builds a simulated twin of each store that must pass visual-fidelity and action-replay verifiers, and an LLM teacher agent replays every anonymized trajectory in the twin through an outer plan-act-reflect loop and an inner per-action verifier (executability, trajectory consistency, realism), logging action, rationale, HTML and screenshot at each step; the released dataset has 1,513 sessions across five stores and four languages. SimTrace wins 7 of 8 fidelity metrics against persona and trajectory prompting and UXAgent (outcome JSD 8.0e-5 vs 1.9e-3 for UXAgent), and models trained only on synthetic sessions match real-data training within confidence intervals for purchase prediction (QLoRA Qwen3.5-4B, F1 65.5 vs 64.4) and session-based recommendation (RAIN, DIMO). For low-resource next-action prediction with 50 real OPeRA sessions, adding synthetic data to Qwen3.5-9B SFT improves the three metrics by 1.5 to 8.5 points (11.0% relative accuracy gain), and a GDPO RL stage with a partial-credit hierarchical target reward adds 1.7 to 5.0% and removes malformed JSON outputs.
