## Summary

This paper addresses the challenge of efficiently setting batch sizes for optimizers like Signum and Muon (based on ℓ∞ and S∞ norms). It introduces non-Euclidean gradient noise scales specifically derived for these optimizers, matching their unique geometries. Experiments show that using these adaptive batch sizes significantly reduces training steps by up to 66% compared to constant batch sizes, while achieving similar performance.

## Technical note

The paper derives gradient noise scales (GNS) for non-Euclidean optimizers, addressing the mismatch between existing GNS theory (built on SGD's Euclidean geometry and the critical batch size) and popular generalized-norm optimizers like signSGD/Signum (l-infinity) and stochastic spectral descent/Muon (S-infinity). It derives GNS that emerge naturally from each optimizer's dual-norm geometry and proposes an efficient variance-estimation procedure that reuses local mini-batch gradients across ranks in distributed data-parallel systems. Using these non-Euclidean GNS to set adaptive batch sizes, it matches the validation loss of constant-batch baselines while cutting training steps by up to 66% for Signum and Muon on a 160M-parameter Llama model.
