## Technical note

This Adobe paper presents an agentic observability framework for automated alert triage in Adobe's e-commerce infrastructure, using a ReAct-paradigm LLM agent to reduce mean time to recovery. On alert detection the agent identifies the affected service, retrieves and analyzes correlated logs across distributed systems, and plans context-dependent actions such as handbook consultation, runbook execution, or retrieval-augmented analysis of recently deployed code. In production it achieved a 90% reduction in mean time to insight versus manual triage while maintaining comparable diagnostic accuracy. (Ops/observability paper, tangential to core recsys.)
