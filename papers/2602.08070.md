## Summary

Current static benchmarks for RAG systems suffer from rapid obsolescence and require heavy manual effort to ensure robustness. To address this, the paper introduces IRB, an automated framework for generating factuality benchmarks using a structured pipeline with factual and algorithmic scaffolds. Evaluations show that IRB significantly challenges state-of-the-art LLMs and retrievers, especially in closed-book settings, suggesting that improving retrieval is a more cost-effective path to RAG correctness than scaling the generator models.

## Technical note

The paper addresses rapid saturation and manual maintenance cost of static RAG factuality benchmarks by introducing IRB, a framework that automatically generates benchmarks via two scaffolds. A factual scaffold derives grounded QA from human-written Wikipedia citing sentences (with citations as retrieval ground truth and an LLM groundedness check), and an algorithmic scaffold converts each fact into a knowledge graph to programmatically produce single-hop, multi-hop, and false-premise question variants. Using IRB the authors build IRB1K and evaluate frontier LLMs and retrievers, finding the closed-book setting is very challenging, reasoning models are more reliable in adversarial cases, and retrieval acts as an equalizer across LLMs. They conclude improving the retriever is a more cost-effective path to RAG correctness than scaling the generator.
