## Summary

This paper introduces RecGPT-Mobile, a system designed to predict user intent for better recommendations in mobile e-commerce (like Taobao). It addresses the high costs of using large language models (LLMs) on cloud servers by deploying a lightweight LLM directly onto the user's mobile device. This on-device approach allows for faster, real-time understanding of evolving user interests and significantly improves recommendation accuracy, as validated by extensive offline and online experiments.

## Technical note

RecGPT-Mobile deploys a lightweight LLM-based intent agent directly on mobile devices for next-query prediction in e-commerce, avoiding cloud round-trip latency and capturing rapidly evolving user intent in real time. The intent agent translates implicit local user behaviors into explicit intent queries that drive an item-retrieval module, with a frequency-control mechanism to reduce redundant on-device inference. Deployment relies on model compression (quantization, pruning, knowledge distillation) plus preference-based optimization and supervised fine-tuning of the LLM. Offline analyses and online A/B experiments on Mobile Taobao (millions of users) show significant gains in recommendation relevance and interpretability.
