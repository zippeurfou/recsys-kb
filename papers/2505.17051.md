## Technical note

Embedding-to-Prefix (E2P) is a parameter-efficient method that personalizes a frozen LLM by injecting a pre-computed user/context embedding into the model's hidden space via a learned projection to a single soft-token prefix, avoiding costly fine-tuning or token-heavy prompting and only retraining if the input embedding distribution shifts. It leverages dense user representations already available in recommendation systems and is robust to gradual embedding drift versus discrete semantic-ID approaches that need re-quantization. Across Persona-Chat dialogue personalization, PENS contextual headline generation, and large-scale Spotify music/podcast recommendation, E2P preserves contextual signals and outperforms non-personalized baselines with minimal overhead.
