## Technical note

HLLM-Creator generates personalized advertising titles using a hierarchical LLM: an Item LLM encodes ad titles and a User LLM aggregates clicked-ad representations into a user embedding, which conditions a Creative LLM that rewrites titles autoregressively under ad-side factual constraints to avoid hallucination. For industrial scale it clusters user embeddings and uses an ad-user matching model to generate titles only for top-matched clusters, and builds training data via a chain-of-thought pipeline. On Douyin Search Ads, online A/B testing increases Adss by 0.476%.
