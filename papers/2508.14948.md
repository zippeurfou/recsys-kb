## Summary

(Abstract fallback)

Online advertising relies on accurate recommendation models, with recent advances using pre-trained large-scale foundation models (LFMs) to capture users' general interests across multiple scenarios and tasks. However, existing methods have critical limitations: they extract and transfer only user representations (URs), ignoring valuable item representations (IRs) and user-item cross representations (CRs); and they simply use a UR as a feature in downstream applications, which fails to bridge up...

## Technical note

LFM4Ads (Tencent) is an All-Representation Multi-Granularity transfer framework for ads recommendation that, unlike prior work transferring only user representations, transfers user, item, and user-item cross representations from a pretrained foundation model. It identifies the optimal cross-representation extraction layer, aggregates them into coarse-grained transferable forms, and adds multi-granularity mechanisms: non-linear adapters (feature-level), an Isomorphic Interaction Module (module-level), and Standalone Retrieval (model-level). Deployed on Tencent's platform (Weixin Moments/Channels) since Q4 2024 with 10+ launches, it achieved an overall 2.45% GMV lift.
