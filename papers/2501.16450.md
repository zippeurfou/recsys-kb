## Summary

Current ranking and recommendation systems are complex, requiring many specialized models and extensive feature engineering, which creates technical debt and hinders innovation. To address these challenges, the authors propose **360Brew**, a large decoder-only foundation model using a natural language interface. This single model can handle multiple ranking and recommendation tasks across LinkedIn, matching or exceeding the performance of existing specialized systems without needing task-specific training or complex feature engineering.

## Technical note

360Brew is LinkedIn's decoder-only foundation model (~150B parameters) that performs ranking and recommendation through a natural-language text interface instead of ID-based features and hand-crafted DAGs of models. It reframes recommendation as many-shot in-context learning: conditioning on a member's profile and verbalized interaction history, the model predicts future interactions across surfaces via task instructions in the prompt, eliminating per-item/member feature engineering and time-horizon-specific count features. A single model handles over 30 predictive tasks and generalizes zero-shot to new surfaces and out-of-domain tasks, naturally addressing cold-start and domain-generalization limits of ID-based systems. Trained/fine-tuned on first-party data over 9 months, it matches or exceeds specialized production models on offline metrics, with more historical context improving performance (trading feature engineering for compute/context scaling).
