## Summary

Composed Image Retrieval (CIR) prioritizes semantic matching but often struggles with retrieving specific user-designated image instances, a problem the authors address by introducing Object-Anchored Composed Image Retrieval (OACIR), which requires strict instance-level consistency.

To support this new task, they created the OACIRR benchmark containing over 160K query-image pairs with bounding boxes anchoring specific objects, along with challenging candidate galleries.

They then proposed AdaFocal, a model using Context-Aware Attention Modulation to focus on the anchored instance while considering the context, significantly outperforming existing CIR models and establishing a baseline for instance-aware retrieval.

## Technical note

This paper introduces Object-Anchored Composed Image Retrieval (OACIR), extending composed image retrieval (reference image + modification text) with a bounding box that anchors a specific instance, mandating strict instance-level consistency rather than only semantic matching. It contributes OACIRR, the first large-scale multi-domain benchmark (~161K real-world quadruples, 127K train / 33.4K eval across Fashion, Car, Product, Landmark) built via a four-stage pipeline (pair collection from fine-grained datasets, similarity/diversity filtering, semi-automatic MLLM+grounding-model quadruple annotation, and galleries enriched with 26.6K hard-negative instance distractors). The proposed AdaFocal model adds a lightweight Context-Aware Attention Modulator that predicts a modulation scalar to adaptively intensify visual attention on the anchored instance region during feature fusion, dynamically balancing instance preservation against compositional reasoning and outperforming existing CIR models on instance fidelity.
