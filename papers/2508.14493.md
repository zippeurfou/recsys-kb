## Summary

This paper introduces GSVR, a novel Variational Representation Learning Framework designed for e-commerce recommendations across diverse scenarios (like search or browsing). The core challenge addressed is the difficulty existing methods face in learning unique scenario-specific user/item representations due to data sparsity. By employing probabilistic distributions learned via variational inference and incorporating global knowledge priors, GSVR helps overcome these sparsity issues, allowing collaborative filtering models to better adapt recommendations based on specific contexts like search or casual browsing.

## Technical note

GSVR is a global-distribution-aware, scenario-specific variational representation framework that plugs into existing multi-scenario e-commerce recommenders, whose shared bottom representations fail to capture per-scenario uniqueness under data sparsity. It models each user and item in each scenario as a probabilistic distribution estimated via variational inference, using the distribution's expectation as the prediction to reduce uncertainty from limited samples. To combat sparsity, it introduces global-knowledge-aware priors: a behavior-mode-aware multinomial prior (from a shared/scenario-specific mixture-of-experts over user sequences) constrains posterior user distributions, and a neural prior over item side-information constrains item distributions, with a standard-normal prior guarding against overfitting. Experiments confirm GSVR helps existing multi-scenario methods learn more robust scenario-specific representations.
