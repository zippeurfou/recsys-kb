## Summary

1.  Query-based recommendation aims to separate user needs from item matching but struggles when interaction logs lack explicit query annotations.
2.  R2QRec addresses this by using a fixed retrieval system to automatically generate query supervision signals from item interactions and retrieval feedback, eliminating the need for manual annotations or learned reward models.
3.  It trains a query generator in two stages (verification and policy refinement) to first imitate successful query patterns and then improve overall query-set ranking performance, achieving state-of-the-art results on standard recommendation datasets without modifying the fixed retriever or index.

## Technical note

Kuaishou's R2QRec learns an LLM query generator for query-based recommendation (express the user history as several natural-language retrieval requests, retrieve with a frozen dense encoder, fuse the lists) when logs contain items but no query annotations. Stage one, item-verified supervision, has the base Qwen2.5-7B generate M candidate queries per training pair and keeps those whose frozen all-MiniLM-L6-v2 retrieval ranks the observed next item within a threshold tau as SFT targets (LoRA r=16); stage two, fusion-aware refinement, samples G=4 sets of K=5 queries, rewards each set by -log(1+rank) of the target in the reciprocal-rank-fused list, and applies GRPO with a KL penalty toward the SFT reference, with no learned reward model and the retriever and index untouched. On Yelp, MovieTV and Amazon Books over the full catalog it is best in 23 of 24 dataset-metric cells, with NDCG@10 gains over the strongest baseline (GPT4Rec, BIGRec, QueryAgent-R1) of 68.7%, 3.5% and 42.1% (Books NDCG@10 7.66 vs 5.39). MovieTV ablations show retrieval verification (5.07 vs 4.03 NDCG@10 without it), GRPO over SFT-only (+0.74 points), the KL term, multi-query inference (K=1 gives 4.75) and log-rank over binary hit feedback (6.4% vs 88% zero-gradient steps) all matter, and generators transfer across domains, even beating in-domain training on Books.
