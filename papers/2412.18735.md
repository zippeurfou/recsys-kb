## Summary

This paper introduces **Adaptive Self-Supervised Learning for Social Recommendations** (**AdasRec**) as a solution to improve recommendation systems. It addresses the issue of existing methods relying too much on expert-designed auxiliary tasks, which can be sub-optimal and not adaptive enough across different datasets.

The core contribution is an **adaptive weighting mechanism**, learned via meta-learning optimization, that automatically assigns varying importance weights to different self-supervised auxiliary tasks based on their specific relevance to enhancing social recommendation performance. This allows the system to adaptively balance these tasks without needing extensive domain knowledge for task design.

Comprehensive experiments on real-world datasets demonstrate that AdasRec is effective at improving recommendation accuracy by leveraging diverse SSL tasks with learned adaptive weights, unlike previous fixed-weight approaches.

## Technical note

Self-supervised social recommenders rely on expert-designed auxiliary tasks with fixed weights, which are sub-optimal and don't adapt across datasets. AdasRec introduces an adaptive weighting mechanism, learned via meta-learning (bi-level) optimization, that automatically assigns importance weights to different self-supervised auxiliary tasks based on their relevance to social-recommendation performance. This balances diverse SSL tasks without extensive domain knowledge for task design. Experiments on real-world datasets show AdasRec improves recommendation accuracy over fixed-weight SSL approaches.
