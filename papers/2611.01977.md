## Summary

EvoRec proposes a novel agentic recommendation system that overcomes the limitations of fixed pipelines by combining autonomous decision-making with reflection-driven self-evolution. It utilizes three main agents (Need, Planning, Acting Executor) and a Dynamic Reflection Tree to infer user needs, adaptively allocate retrieval resources, execute plans, and systematically identify and correct failures based on user feedback. These self-updating repair strategies, derived from feedback and distilled across users, improve performance without retraining parameters, as validated by significant offline and online experimental results demonstrating better recommendations and increased advertising revenue.

## Technical note

Cascaded recommenders cannot re-plan per user or attribute a missed conversion to the decision that caused it, and earlier agentic recommenders cover isolated stages. EvoRec (Kuaishou local-services ads) has a Qwen3-4B Need Agent infer structured needs from long-term, short-term and working memory, a Planning Agent split a 3,000-candidate retrieval budget between Behavior Continuation and Need Satisfaction, choose tools (Item-CF, User-CF, embedding retrieval, BM25, OneLatent) and the SASRec-vs-Two-Tower fusion weight from a 0.1-0.9 grid, and a deterministic Acting Executor merge tool outputs by snake-order interleaving and fuse the base, SASRec and Two-Tower rankings with weighted RRF. After feedback, a Qwen3-32B Reflection Agent localizes failures to ERROR-NEED, ERROR-PLAN or ERROR-MEMORY in a Dynamic Reflection Tree, generates personalized repair strategies that are verified by replaying the decision, injects them into the agents' prompts as working memory, and abstracts verified repairs into shared system-level nodes (merge/split/reparent), so the system improves without updating any model parameters. On 28,227 users ranking a shared 355,163-item pool against next-day conversions, EvoRec reaches Hit@50 24.48% vs 21.16% for InteRecAgent (+15.7%) and beats SASRec, UltraGCN, TIGER, OneRec, LLMRank, MACRec and ToolRec; a static ensemble of the same tools loses 13.4% Hit@50, per-user fusion weights beat fixed ones, and reflection adds 13.1% Hit@50 on the 18.5% of users who received working memory (verification and personalization each matter 5-8%). Deployed nearline with LLM inference off the request path (needs, plans and query vectors precomputed, candidates pushed via Kafka as an extra retrieval channel into the shared online ranker, reflection limited to the 11.3% high-intent users), a 7-day 5%-traffic A/B test raised ad revenue 4.6% and CTCVR 3.5%, and revenue 14.5% among high-intent users.
