## Summary

1.  Current state-of-the-art temporal link prediction (TLP) models rely on memory modules storing node information seen during training, which prevents direct transfer to new graphs at test time.
2.  This paper introduces a novel method using structural mapping modules that learn relationships between graph topological features and memory embeddings, improving transferability without requiring pre-stored memories for all nodes.
3.  The approach leads to more effective foundation models for TLP tasks across different entirely new graphs, paving the way for reusable systems in dynamic link prediction scenarios.

## Technical note

The paper studies transfer learning for temporal link prediction, where state-of-the-art Temporal Graph Networks (TGNs) store node memory embeddings that are specific to training-graph nodes (over 90% of parameters), preventing direct transfer to entirely new graphs. The authors show TGN memory parameters scale as O(N) with training nodes and are inherently non-transferable. They propose a structural mapping module that learns a function from deterministic node topological features (degree, centrality) to memory embeddings during training, then applies it at test time to initialize memory for unseen nodes, enabling a zero-shot alternative to naive fine-tuning. This paves the way toward a memory-free foundation model for temporal link prediction, evaluated on TGB-style benchmark graphs.
