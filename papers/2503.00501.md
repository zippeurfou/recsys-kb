## Technical note

Qilin is a multimodal information-retrieval dataset collected from Xiaohongshu (300M+ MAU, 70%+ search penetration) to advance search-and-recommendation (S&R) research. It provides APP-level user sessions with heterogeneous results (image-text notes, video notes, commercial notes, direct answers) plus rich contextual signals and genuine user feedback for modeling satisfaction and long-term retention. Notably it includes user-favored answers and their referred results for Deep Query Answering (DQA) requests, enabling training/evaluation of a Retrieval-Augmented Generation (RAG) pipeline and study of how such a module affects search behavior. Analysis and experiments provide insights for improving multimodal S&R systems.
