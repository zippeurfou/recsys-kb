## Summary

Modern multimodal retrieval relies heavily on vector search using inverted file (IVF) methods, which are efficient but suffer from high query latency due to scanning many clusters and their vectors.

This paper introduces CLIP, a novel pruning technique leveraging cosine-law-based lower bounds, enabling both inter- and intra-cluster access elimination with minimal overhead.

CLIP allows for two IVF variants: IVF-CLIP integrated into flat indexing, and HIVF-CLIP using hierarchical clustering. Furthermore, an LSM-inspired design (LSM-IVF) uses CLIP to handle dynamic updates efficiently without degrading query performance, demonstrating substantial speedups over existing static and dynamic baselines.

## Technical note

IVF-based approximate nearest neighbor search is limited by having to probe many clusters and exhaustively scan all their vectors, causing high query latency. The paper proposes CLIP, a cosine-law-based lower-bound pruning method that supports both inter-cluster pruning (skipping a whole cluster in O(1) via a min lower bound) and intra-cluster pruning (locating a contiguous valid segment in sorted lists via two binary searches in O(2 log l)), with negligible extra storage (~4n bytes). It integrates CLIP into IVFFlat (IVF-CLIP) and hierarchical IVF (HIVF-CLIP with adaptive sub-cluster probing), plus LSM-IVF, an LSM-inspired design for efficient dynamic updates and unified multi-level querying. Experiments on six datasets show up to 78% pruning and 69% higher query efficiency over static IVF baselines, and up to 141% throughput improvement over dynamic IVF baselines (SPFresh, Quake) at comparable update efficiency.
