## Summary

This paper introduces CRAG (Collaborative Retrieval Augmented Generation), the first system combining large language models (LLMs) with classical collaborative filtering techniques to enhance conversational recommender systems. LLMs are typically poor at leveraging user behavioral data, so CRAG inserts a retrieval-based step into the generation process before providing recommendations within dialogue interactions.

The key innovation is integrating state-of-the-art LLMs with CF to overcome this limitation and improve performance on interactive movie recommendation tasks. Experiments conducted on two movie-specific datasets demonstrate that CRAG significantly outperforms several baseline conversational recommender systems, achieving better item coverage and higher accuracy, particularly for recently released movies.

The authors provide the code and data used in their experiments online, allowing others to replicate and build upon their work.

## Technical note

CRAG (Collaborative Retrieval Augmented Generation) combines LLMs with classical collaborative filtering to improve LLM-based conversational recommender systems, which typically underuse user behavioral data. It inserts a collaborative retrieval step into the generation process so the LLM grounds its in-dialogue movie recommendations on CF signals before responding. On two movie conversational datasets, CRAG significantly outperforms baseline conversational recommenders in both accuracy and item coverage, with particular gains for recently released movies. The authors release code and data for reproducibility.
