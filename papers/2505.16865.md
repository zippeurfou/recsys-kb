## Summary

Latent Reasoning for Sequential Recommendation":

1.  Current sequential recommendation systems lack reasoning capabilities, limiting their ability to capture complex user preferences effectively.
2.  The LARES framework introduces depth-recurrent latent reasoning within existing models, boosting their representation power by processing all input tokens repeatedly at each step without adding parameters or harming scalability.
3.  It employs a two-phase training strategy: first using self-supervised learning with trajectory and step alignment objectives to learn reasoning patterns from data itself, then refining these capabilities via reinforcement learning, leading to superior recommendation performance on standard benchmarks.

## Technical note

LARES adds latent (non-verbalized) reasoning to sequential recommenders, arguing that sparse item-ID spaces make explicit chain-of-thought reasoning infeasible and that parameter scaling alone fails in recommendation. It uses a depth-recurrent architecture (a pre-block plus an iteratively applied core-block of Transformer layers) that refines all input tokens at each step, increasing computation density and enabling arbitrary test-time reasoning depth without adding parameters. Training is two-phase: self-supervised pretraining with trajectory-level and step-level alignment objectives to learn recommendation-oriented reasoning patterns, followed by reinforcement post-training to refine reasoning. It improves performance on real-world benchmarks and is compatible with existing models, boosting them further.
