## Summary

This paper explores using "halting heads" in looped language models to predict token stopping points and save compute. It finds that standard pretraining methods without a strong penalty for stopping iterations don't effectively encourage early termination, requiring tokens to run almost every iteration anyway. Additionally, the common metric of average iterations saved can overstate actual compute reductions when sequences are generated in batches, as the batch run time is determined by the slowest token. The authors recommend reporting actual iterations saved along with the stopping threshold and batch size, and suggest a pre-training test to estimate the potential gain of a halting head.

## Technical note

Looped LMs reuse one block of layers for up to T iterations and add a halting head (ACT or PonderNet style) so easy tokens can exit early, with savings usually reported as expected halting steps per token. Pretraining 140M to 1.3B looped models on FineWeb-Edu and Common Corpus, Apple shows that heads trained with the mixture loss (coda reads the probability-weighted mixture of all iteration states) predict about 3.7 of 8 iterations yet under the standard 90% cumulative-probability exit rule tokens run 7.6-7.9 iterations, because the loss never scores the single state an exit hands to the coda (reading one state costs about 0.2 BPB); the per-step PonderNet loss fixes this only with a strong geometric prior (beta=0.1), after which it beats a sampled-depth baseline at matched realized steps (e.g. -0.022 BPB at 2.8 steps). Batched generation over 32 sequences runs until the deepest token stops (about 4.4 paid iterations), which erases most of the lead for their models and for the released Ouro model, and single-sequence decoding keeps the lead only if stopped tokens' keys and values are reused; even then a specialist trained at 3 iterations is not beaten. They recommend reporting expected, realized and batch-paid iterations plus the exit threshold and batch size, and give a pre-training specialist test that bounds a head's possible gain (about 0.02 BPB at 140M).
