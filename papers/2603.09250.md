## Summary

Existing LLM personalization methods either use all user data (inefficient) or simple similarity searches (inadequate). This paper proposes RF-Mem, a system that adapts its memory retrieval based on how familiar the user is with a query. RF-Mem uses two paths (Familiarity and Recollection) and switches between them based on calculated uncertainty, simulating human memory retrieval for better, more efficient personalization. Experiments show RF-Mem outperforms both simple retrieval and full-context methods under resource constraints.

## Technical note

RF-Mem is a familiarity-uncertainty-guided dual-path memory retriever for personalizing LLMs, motivated by cognitive science's dual-process view of memory (fast coarse Familiarity vs. deliberate chain-like Recollection). It measures a familiarity signal from the mean retrieval score and entropy: high familiarity routes to a direct top-K Familiarity path, while low familiarity activates a Recollection path that clusters candidate memories and applies alpha-mix expansion with the query to iteratively grow evidence in embedding space. This adaptive switching avoids both full-context overhead and shallow one-shot similarity matching. Across three benchmarks and corpus scales it outperforms one-shot retrieval and full-context reasoning under fixed budget and latency constraints.
