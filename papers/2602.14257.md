## Technical note

AD-Bench (Tencent) is a real-world, trajectory-aware benchmark for LLM agents doing advertising/marketing analytics, built from 2,000 native user requests curated to 225 instances across three difficulty tiers (L1-L3). Its two designs address ground-truth obsolescence and trajectory evaluation: a dynamic ground-truth pipeline replays expert tool-call trajectories to regenerate answers against the current environment, and evaluation jointly measures end-to-end Pass@k plus trajectory coverage (reproducing the expert reference tool sequence). Testing a 9-tool ReAct agent across ten models, Claude-Opus-4.7 leads at 76.9% Pass@1 / 80.4% Pass@3 but drops sharply on L3 (61.4% Pass@1, 69.9% coverage); trajectory coverage correlates strongly with Pass@1 (r=0.994 overall), and tool/parameter errors dominate failures. Benchmark-guided iteration raised a production agent's user satisfaction from 65.55% to 88.37%.
