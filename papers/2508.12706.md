## Summary

Standard recommendation systems often use symmetric diffusion models with Gaussian noise in continuous space, but real-world data (like user-item interactions) is discrete, leading to potential corruption and suboptimal performance. This research introduces Asymmetric Diffusion Recommendation Model (AsymDiffRec), which learns a generalized forward process simulating missing features specifically from the discrete recommendation domain. The model then performs an asymmetric reverse denoising in this learned feature space while using a task-oriented strategy to preserve personalized information, resulting in improved online and offline performance (+0.13-0.17%) for user engagement metrics like active days and app duration.

## Technical note

AsymDiffRec adapts diffusion-based representation learning to industrial recommendation, arguing that standard symmetric Gaussian-noise diffusion is ill-suited to the discrete data space and corrupts personalized information. Its forward process uses a discrete operation (feature dropout, dropping one feature per step) to simulate real-world missing features, and an asymmetric reverse process reconstructs the clean latent representation as 'feature completion,' with a task-oriented auxiliary loss to preserve personalization. Unlike prior diffusion recommenders used only for auxiliary training, it also applies the reverse process at serving time, treating incoming samples with missing features as noisy inputs to denoise. Deployed in the Douyin Music App, online A/B tests report +0.131% active days and +0.166% app usage duration.
