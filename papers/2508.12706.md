## Technical note

AsymDiffRec argues standard symmetric Gaussian-noise diffusion is ill-suited to recommendation because its data is discrete and Gaussian noise corrupts personalized information. It defines an asymmetric forward/reverse process: the forward process adds noise via discrete feature dropout (simulating missing features in real samples) and the reverse process reconstructs the latent representation in an asymmetric feature space ('feature completion'), with a task-oriented auxiliary loss preserving personalization. Uniquely the diffusion module is used at serving time too, treating each raw sample as noisy with T missing features. Deployed in Douyin Music App, online A/B tests gain +0.131% active days and +0.166% app usage duration.
