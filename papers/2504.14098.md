## Summary

This paper introduces an AI system for enhancing math learning within a Learning Management System (LMS). It generates deep embeddings of math questions using Meta's Llama model to enable intelligent similarity detection. The authors evaluate three recommendation methods—cosine similarity, Self-Organizing Maps (SOM), and Gaussian Mixture Models (GMM)—finding cosine provides precise matches while SOM offers higher user satisfaction despite potentially less variety, with GMM generally underperforming.

## Technical note

This paper compares three methods for recommending similar math questions in an LMS using 4096-dim embeddings from Meta's Llama-3.2-11B-Vision-Instruct (mean-pooled token states). Cosine similarity finds nearest neighbors directly; SOM projects embeddings onto a 5x8 grid and ranks intra-neuron by Euclidean distance; GMM builds per-question posterior probability vectors and ranks by KL divergence. Evaluated on 1,855 randomized quiz sessions (durations, ratings, correctness, wrong-answer streaks), cosine gives near-identical matches, SOM yields the highest user satisfaction by balancing similarity and novelty, and GMM underperforms because KL divergence poorly captured pedagogical similarity. The authors conclude the representation and similarity metric must jointly match the task.
