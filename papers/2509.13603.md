## Technical note

Meta modernizes Facebook Group Scoped Search by blending legacy keyword retrieval (Unicorn inverted index) with embedding-based retrieval via a 12-layer 200M-parameter Search Semantic Retriever whose query embeddings run ANN search over a precomputed Faiss index. Retrieved candidates are fused with lexical (TF-IDF, BM25) and semantic (cosine) features in a multi-stage ranking pipeline optimizing click/share/comment. A novel LLM-as-a-Judge evaluation framework (Llama 3) automates relevance assessment in build-verification tests; online metrics and LLM evaluation confirm improved engagement and search quality.
