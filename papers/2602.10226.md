## Summary

This paper introduces a self-evolving recommendation system that uses LLMs (like Gemini) to autonomously optimize models. It consists of an Offline Agent generating complex model changes using proxy metrics and an Online Agent validating them against real business metrics in production. The system, shown to outperform traditional methods at YouTube, automates the roles of Machine Learning Engineers, significantly speeding up development and improving model performance.

## Technical note

The paper describes a self-evolving recommendation system at YouTube where Gemini-based LLM agents act as ML engineers that autonomously propose optimizer, architecture, and reward-function changes to a value-based RL ranking model. It is structured as a bi-level optimization: an inner Offline Agent generates and prunes hypotheses using cheap offline proxy metrics in a Think-Code-Verify loop, and an outer Online Agent validates survivors against delayed north-star business metrics via live A/B tests. Agents perform semantic discovery beyond AutoML/NAS search spaces, inventing new interaction layers and multi-objective reward logic aligned with long-term engagement. Safety guardrails cap production regressions to prevent reward hacking, and several launches surpassed hand-tuned baselines.
