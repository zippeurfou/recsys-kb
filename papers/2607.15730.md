## Summary

Feedback-Driven Streaming Semantic User Profiles for Short-Video Recommendation":

1.  Current short-video recommendation systems often convert complex user histories into simple profiles without using feedback from recommendations, leading to potential inaccuracies.
2.  RECAP addresses this by proposing an offline closed-loop framework that specifically trains profile updates using historical recommendation feedback, combining bounded structured memory with LLM-based semantic refinement.
3.  This approach significantly improves recommendation effectiveness (measured by uAUC and Recall@2000) on real data like Kuaishou's and also shows positive online results in increasing user engagement time.

## Technical note

RECAP tackles optimizing streaming, bounded structured LLM-based semantic user profiles from logged implicit feedback in Kuaishou short-video recommendation. It maintains each profile as a bounded memory via an LLM semantic-diff updater plus a deterministic state machine (lifecycle and capacity control), and constructs a recommendation-aligned reward by LLM-judge label-consistency filtering of behavior pairs and a frozen dual-tower evaluator (BCE plus InfoNCE in-batch-negative contrastive heads) used as a GRPO proxy reward over a Qwen3-4B policy warm-started by SFT on Claude Sonnet 4.5 demonstrations. On held-out Kuaishou data it lifts cleaned-eval uAUC from 0.7519 to 0.7603 (+0.0084) and Recall@2000 by about 4.9%, and a seven-day online A/B test gives a statistically significant +0.139% average application usage time per user.
