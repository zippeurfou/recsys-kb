## Summary

This paper addresses the challenge of efficiently discovering database query rewrite rules, which is hindered by large search spaces and redundancy in existing methods. The proposed system, SLER, tackles this by using standardized templates to represent query structures and a learning-to-rank model to prioritize potential rule pairs during generation. Evaluated on real-world queries, SLER successfully built a massive repository of over one million rules, demonstrating unprecedented scalability and enabling the discovery of complex transformations for advanced database optimizers.

## Technical note

SLER discovers database query-rewrite rules efficiently by combining standardized template enumeration with a learning-to-rank ranker, overcoming WeTune's exponential search space and heavy redundancy. Standardized templates abstract query plans (operator structure kept, data details removed) to eliminate structural redundancy, while a learning-to-rank model pre-filters the most promising template pairs to avoid costly Z3/SMT equivalence checks. A Reduced-by-Template-Pair deduplicator prunes redundant rules via normalization and checksum comparison. Trained on 11,000+ real-world SQL queries, SLER built a repository exceeding one million validated rules, supporting plan templates far beyond the four-node limit of prior methods.
