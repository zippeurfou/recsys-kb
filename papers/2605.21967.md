## Technical note

RPORec is a reinforced preference optimization framework that couples an LLM backbone's chain-of-thought reasoning with a dedicated recommendation head (Rechead) via textual outputs rather than hidden-state coupling, avoiding semantic mismatch and preserving reasoning integrity. Stage one (Reasoning-Augmented Recommendation Modeling) freezes the LLM and trains the Rechead to use generated CoTs and answers as auxiliary signals for retrieval-based next-item prediction; stage two (Advanced Reasoning Refinement and Alignment) freezes the Rechead and uses it as a verifiable reward source to fine-tune the LLM backbone via RLVR/GRPO-style RL. Experiments on public benchmarks and a global online deployment show RPORec outperforms SOTA LLM-based recommendation methods.
