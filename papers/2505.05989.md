## Summary

This paper presents a new multi-hop path-aware recommendation framework designed to model complex user preferences in heterogeneous information networks by analyzing longer chains (paths) involving various entities and relations.

The method operates through three stages: first filtering out noisy or redundant paths, then jointly encoding the sequence of entities and relations while preserving semantic dependencies, and finally using an attention mechanism to assign weights to different paths for generating a comprehensive user interest representation.

Experiments on real-world datasets demonstrate that this approach significantly improves recommendation accuracy compared to existing models by effectively capturing high-order interaction semantics embedded in multi-hop paths.

## Technical note

This work models user preferences in heterogeneous information networks via multi-hop paths (e.g. user-item-category) through a three-stage framework: path screening using path frequency and local mutual information to drop noisy paths, GRU-based sequential encoding of entity-relation sequences to preserve semantic dependencies, and attention-based fusion that weights paths into a global user-interest vector, trained with binary cross-entropy. On Amazon-Book it outperforms MF, NeuMF, GCN-Rec, and HIN-PathRank on HR@10/Recall@10/Precision@10. A path-length study finds performance peaks at L=4 hops and degrades at L=5 due to noise/semantic dilution.
