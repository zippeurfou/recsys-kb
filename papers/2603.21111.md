## Summary

This paper introduces **Free Sinewich**, a novel parameter-efficient multi-task learning framework designed to overcome the limitations of current single-task adaptation methods. It achieves this by combining low-rank factors and convolutional priors into a single kernel, which is then modulated elementwise via a sinusoidal transformation for task-specific weights. A Clock Net produces stabilizing frequencies, and the method demonstrates state-of-the-art performance-efficiency trade-offs on dense prediction benchmarks, using significantly fewer trainable parameters than single-task fine-tuning.

## Technical note

Free Sinewich is a parameter-efficient multi-task learning (PEFT-MTL) framework that reuses a single shared parameter set across tasks via a frequency-switching mechanism, inspired by thalamocortical oscillatory multiplexing. Its Sine-AWB (Sinewich) layer combines LoRA-style low-rank factors and convolutional priors into one kernel, then modulates it elementwise with a task-specific sinusoidal transformation to produce specialized weights without adding parameters. A lightweight Clock Net produces bounded frequencies that stabilize modulation during training; theoretically, sine modulation raises the effective rank of the low-rank adapter while frequency separation decorrelates task weights to mitigate task conflict/negative transfer. On dense prediction benchmarks it reaches state-of-the-art accuracy-efficiency trade-offs, e.g., up to +5.39% over single-task fine-tuning with only 6.53M trainable parameters.
