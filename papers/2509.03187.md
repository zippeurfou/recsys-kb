## Technical note

Kuaishou's CCSS is a model-agnostic contrastive learning framework with counterfactual sample synthesizing that enforces monotonicity between a neural network's output and numerical features, important for interpretability and accuracy in recommenders. A Counterfactual Samples Synthesizer perturbs a single numerical feature (chosen by feature importance) to create factual/counterfactual pairs, and a contrastive objective learns to rank the model outputs of original vs synthesized samples end-to-end, working even when numerical features are used both as dense values and discretized embeddings. Experiments on a public benchmark and a large industrial dataset show effectiveness, and CCSS is deployed serving hundreds of millions of users.
