## Summary

1.  The paper applies an AutoResearch framework using large language models to automate the costly and complex process of optimizing training scripts for production recommendation systems.
2.  During extensive deployment across two different systems, it identified five key failure modes (infrastructure fragility, memory decay, search stagnation, iteration cost asymmetry, metric fixation) that hinder autonomous optimization at scale.
3.  The authors then introduced a multi-principle scaffolding design (prevent, persist, redirect) to address these failures, resulting in significant performance improvements over hand-tuned baselines and demonstrating the framework's scalability across vastly different computational costs.

## Technical note

Amazon ran Karpathy's AutoResearch loop (an LLM edits the training script and keeps changes that improve a held-out metric) for 12 weeks and 220+ experiments on two book-recommendation systems: System A learns 128-d purchase-optimized retrieval embeddings from a Node2Vec co-purchase graph plus sentence-transformer text (9-19 h multi-GPU iterations, Recall@6 via a FAISS IVF index), and System B learns RQ-VAE Semantic IDs scored by weighted cluster coherence (6-52 min single-GPU iterations, ~760x cheaper). Both exhibited five failure modes absent from the original small-scale setting: infrastructure fragility, agent memory decay, search-direction stagnation, iteration-cost asymmetry, and metric fixation (e.g. inflating codebook size to game coherence). The remedy is prevent/persist/redirect scaffolding: a Claude Opus Code Fixer that rewrites each script before execution (14 latent bugs, including DDP misconfigurations, caught in one pass), durable cross-job program.md memory, and a Criticizer that fires only on stagnation (8% relative gain over a 5-iteration window). The full three-agent setup lifted System A Recall@6 from a 4-engineer-week baseline of 3.79% to 6.90% (1.82x; Researcher-only stalled at 1.10x) via agent-found multi-hop neighborhood profiles, hard-negative contrastive learning and mean+top-K aggregation, and autonomously added a text-only fallback embedding for items without co-purchase edges that expanded catalog coverage 5.8x, while System B coherence rose 2.1x (0.348 to 0.735). The authors argue scaffolding should scale with iteration cost: pre-execution gates for expensive runs, cheap post-execution revert otherwise.
