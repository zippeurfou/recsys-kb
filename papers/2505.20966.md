## Technical note

LaD (Kuaishou search) is a generative query auto-completion model that captures hierarchical personalized interests plus adaptive detoxification. It represents users hierarchically: coarse-grained sentence-level embeddings for long-term interests and fine-grained token-level embeddings for short-term interests, fed with the prefix into an encoder-decoder to enable online real-time generation. Adaptive detoxification uses a special [Reject] token inserted during training by a Detoxification Expert and an online Reject Preference Optimization (RPO) objective, so any completion ranked below [Reject] is discarded and sensitive prefixes return no output while staying relevant. Online A/B tests delivered the largest single-experiment metric gain in nearly two years, improving CTR and search penetration, and it serves Kuaishou search's primary traffic.
