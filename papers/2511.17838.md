## Summary

Tensor compilers use graph rewrites to optimize deep learning computations, but verifying these rewrites for tensors of any rank and size has been challenging. The paper introduces TensorRight, an automated verification system designed for this purpose. TensorRight uses a novel DSL with aggregated-axes and translates the problem into verifying a finite number of bounded cases, leveraging an SMT solver, successfully proving the correctness of 115 rules from XLA's simplifier against the limitations of existing bounded-verification methods.

## Technical note

TensorRight is the first automated system to verify tensor graph rewrite rules for input tensors of arbitrary rank and size, closing a gap where prior tools only handled tensors of concrete rank. It defines a core DSL with a novel aggregated-axis construct to reason about an unbounded number of axes, and proves that a computable bound on tensor rank exists such that bounded verification of all instances implies unbounded correctness. Using denotational semantics it derives the bound, generates a finite set of bounded proof obligations, and dispatches them to an SMT solver via symbolic execution. Evaluated on XLA's algebraic simplifier, it proves 115 of 175 rules in full generality, versus 18 expressible by the closest bounded-verification system.
