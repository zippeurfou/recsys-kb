## Technical note

Fints is an inference-time personalization framework for LLMs that dynamically generates fine-grained, sample-level interference (steering) vectors from user data and injects them into a mid-layer activation of a frozen base model. This avoids the low adaptability and data inefficiency of personalized parameter-efficient fine-tuning / LoRA and reward-modeling methods under dynamic user patterns and sparse data, with zero gradient storage, zero per-user checkpoints, and light latency. It outperforms all prompt-based and personalized-LoRA baselines, showing strong robustness in fast-changing and data-sparse settings, beating LoRA by up to 3% absolute Rouge with fewer than 10 personalized user logs.
