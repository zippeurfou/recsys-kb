## Summary

This paper introduces a novel data-centric RAG workflow, moving beyond the standard retrieve-then-read by incorporating a prepare-rewrite-retrieve-read sequence. The system enhances understanding by generating metadata and synthetic QA for documents and creating Meta Knowledge Summaries for document clusters, enabling personalized query augmentation. This approach significantly improves RAG performance, demonstrating that queries augmented with synthetic questions perform better than traditional chunk-based RAG, and that meta-knowledge further boosts retrieval precision and the quality of final answers.

## Technical note

This paper introduces a data-centric RAG workflow that replaces retrieve-then-read with a prepare-then-rewrite-then-retrieve-then-read pipeline. For each document it uses an LLM (Claude 3 Haiku, chain-of-thought) to generate metadata plus synthetic question-answer pairs, encoding only the synthetic questions for retrieval to reduce information loss from document chunking. It also builds Meta Knowledge Summaries over metadata-defined document clusters, which condition personalized augmentation of a user query into multiple targeted sub-queries. Using LLM evaluators on 2000 arXiv papers, augmented queries with synthetic-question matching significantly beat chunk-based RAG (p<0.01), and meta-knowledge augmentation further improves retrieval precision/recall and answer depth, breadth, relevancy, and specificity, all for under $20 of processing.
