## Summary

1.  The paper addresses the labor-intensive task of adding sound effects to radio stories by proposing an automatic retrieval system.
2.  It introduces a hybrid model combining retrieval with semantic inference to overcome ambiguity issues in direct tag-based approaches, using carefully designed features from candidate triggers.
3.  Evaluated on newly created datasets, the system shows promise for automating sound effect addition, with discussions on feature importance and heuristic rules for balancing retrieval precision and recall.

## Technical note

The paper automates adding sound effects to radio stories by retrieving sound effects for text triggers, addressing the high false-positive rate of naive tag/keyword retrieval (over 40% of retrieved triggers should not get a sound). It hybridizes a BM25-style tag-based retriever with a semantic inference model that uses fine-designed contextual features to decide whether a candidate trigger truly warrants a sound effect, focusing on the hardest scene-triggered category. Two story-dubbing datasets were collected via crowdsourcing to analyze the task and train/test the models. Ablations quantify feature importance and heuristic rules trade off precision against recall, yielding a promising pipeline that, with TTS, can produce radio stories automatically.
