## Technical note

TransAct V2 is Pinterest's production Homefeed ranking model that integrates both real-time and lifelong user action sequences (O(10^4)) into a CTR-prediction framework, overcoming prior models' reliance on short sequences (O(10^2)). Its three innovations are leveraging very long user sequences, a Next Action Loss that adds next-action forecasting to the point-wise ranking task to improve predictive accuracy and diversity, and scalable low-latency deployment via efficient data-processing and model-serving optimizations for storage/latency constraints. Serving over 500 million users in production, extensive offline and online A/B experiments confirm major gains in engagement volume and recommendation diversity.
