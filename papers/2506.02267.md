## Summary

This paper introduces **TransAct V2**, an improved recommendation system model for Pinterest's Homefeed. It addresses limitations by using much longer user action sequences than typical industry models, which helps capture more comprehensive long-term behavior patterns. The key innovations are: (1) incorporating very long sequences into CTR prediction, (2) adding a "Next Action" loss function to better predict future user actions directly from past ones, and (3) developing efficient deployment solutions required for handling these extensive sequence data at scale in production.

## Technical note

Industrial CTR models restrict user sequences to O(100) recent actions, missing long-term behavior and lacking a next-action objective, while serving lifelong sequences is prohibitively costly. TransAct V2 integrates real-time and lifelong (O(10^4)) sequences into Pinterest Homefeed ranking by using the candidate Pin as an anchor for on-device nearest-neighbor search over PinSage embeddings, adds a Next Action Loss (sampled-softmax contrastive task with a causal mask) trained with impression-based negatives, and logs only NN features (reducing storage from O(L) to O(1)). Serving is made feasible via request-level de-duplication, fused int8 dequantization, a single-kernel unified transformer (SKUT) in Triton (6.6x faster forward), and a pinned memory arena. Offline it improves HIT@3/repin by 13.31% and reduces hides by 11.25%; online A/B raises Homefeed Repin Volume 6.35%, cuts Hide Volume 12.80%, and improves diversity, with end-to-end p99 latency reduced ~250x.
