## Summary

This paper introduces SAGE ("Strategy-Aware Parameter-Efficient Adaptation for LLM-based Auto-Bidding"), which tackles challenges in using Large Language Models (LLMs) for dynamic ad auction bidding. Existing methods require expensive fine-tuning, but SAGE proposes three efficient components: a position augmentation module captures temporal dynamics, a text alignment module efficiently fuses data with gated cross-attention, and a constraint-gated LoRA module adapts the frozen LLM only where needed based on input constraints. Experiments show SAGE significantly outperforms baseline methods while using far fewer trainable parameters than full fine-tuning, demonstrating effective parameter-efficient adaptation for constrained bidding environments.

## Technical note

SAGE is a strategy-aware, parameter-efficient framework for LLM-based auto-bidding, which frames advertiser bidding as constrained sequential decision-making (maximize conversions under CPA and budget). Over a frozen Qwen2.5-0.5B it adds three modules: position augmentation (disentangled sinusoidal temporal plus learned semantic positional embeddings for return-to-go/state/action tokens), text alignment (gated cross-attention fusing trajectory queries with the task-description text while keeping trajectory length fixed), and constraint-gated LoRA (a mixture-of-experts of LoRA adapters routed by the advertiser's constraint prompt for adaptive strategy selection). On Alibaba's AuctionNet (dense/sparse) it beats offline RL (CQL/BCQ/IQL), Decision-Transformer variants (+4.49%/+7.83% over DT-score at 100% budget), and LLM baselines (+6.40%/+10.15% over LLM-DT) while training under 10% (91.70% fewer) of full-fine-tuning parameters. An advertising auto-bidding decision model, not a recommendation retrieval/ranking pipeline.
