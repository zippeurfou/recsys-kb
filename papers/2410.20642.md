## Summary

1.  Existing LLM-based recommender systems primarily use text data, but often ignore valuable collaborative signals and task interconnections when handling multiple recommendation tasks simultaneously (multi-task).
2.  To address this gap, the authors propose Collaborative Knowledge Fusion (CKF), an innovative framework that integrates traditional collaborative filtering models into LLMs to create personalized collaborative embeddings for each user.
3.  These embeddings are then used with a parameter-efficient technique called Multi-Lora within carefully crafted prompts to power the LLM, enabling distinct task adaptation while allowing knowledge transfer between related recommendation tasks and demonstrating superior performance through extensive experiments.

## Technical note

Introduces CKF (Collaborative Knowledge Fusion), a framework that boosts multi-task LLM-based recommendation by injecting traditional collaborative signals into LLMs. It generates collaborative embeddings from a CF model and uses a meta-network to build per-user personalized mapping bridges, then inserts the mapped embeddings into designed prompt templates fed to the LLM to represent user interests. To exploit task interrelatedness it proposes Multi-Lora, a parameter-efficient method that separates task-shared and task-specific information for multi-task optimization and mutual knowledge transfer. Experiments across four recommendation tasks on four public datasets confirm effectiveness and robustness.
