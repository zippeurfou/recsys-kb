## Summary

This paper introduces PersonaMem-v2, a large dataset simulating user interactions to train Large Language Models (LLMs) for personalized intelligence. It demonstrates that while current frontier models struggle with understanding implicit user preferences, reinforcement fine-tuning can significantly improve performance, as shown by Qwen3-4B outperforming GPT-5 in this task. The authors also propose an "agentic memory" framework that stores a concise, evolving user profile, achieving state-of-the-art accuracy using significantly fewer input tokens than full conversation histories.

## Technical note

PersonaMem-v2 targets implicit LLM personalization, providing a benchmark of 1,000 personas, 20,000+ preferences and 128k-token histories where preferences are revealed only implicitly through everyday tasks. Frontier LLMs achieve only 37-48% accuracy, showing reasoning (not context length) is the bottleneck for implicit personalization. Using reinforcement fine-tuning with GRPO and verifiable rewards, the authors train Qwen3-4B to reach 53% (surpassing GPT-5), and an agentic-memory framework that distills history into a capped 2k-token human-readable memory achieves 55% accuracy while using 16x fewer input tokens.
