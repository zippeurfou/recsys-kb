## Summary

This paper addresses a problem in multimodal knowledge-based visual question answering (MKB-VQA) where models can exploit "visual shortcuts," using image content alone instead of integrating text and vision, because the query image usually matches the primary subject in the document.

To combat this, the authors introduce the RETINA benchmark, created using an LLM pipeline, featuring queries about secondary (related) entities paired with images of those entities, thereby eliminating the shortcut.

Furthermore, they propose MIMIR, a model that uses multiple related entity images to enrich document embeddings, effectively handling the RETINA benchmark and demonstrating the limitations of existing models reliant on visual shortcuts.

## Technical note

This paper shows that multimodal knowledge-based VQA (MKB-VQA) benchmarks contain a 'visual shortcut' because the query image usually matches the target document's primary entity, letting models retrieve using vision alone. It introduces RETINA, an LLM-driven, knowledge-graph-guided benchmark (120k train, 2k human-verified test) whose queries reference secondary/related entities paired with images of those entities, eliminating the shortcut and sharply degrading existing single-image retrievers. It proposes MIMIR, a Multi-Image Multimodal Retriever that enriches each document embedding with images of multiple related entities extracted from the document text. Experiments confirm the benchmark bias and MIMIR's effectiveness with and without shortcuts.
