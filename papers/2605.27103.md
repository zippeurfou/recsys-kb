## Summary

Current music discovery platforms, like Douyin Music, primarily use passive recommendation feeds, limiting users' ability to express specific musical intents naturally. MuChator addresses this by enabling active music discovery through conversational interactions powered by a specialized MusicLLM, incorporating three key components for better understanding and personalization. The system has been deployed on Douyin Music and shown significant improvement in user engagement, increasing active user days by 46.49% in an A/B test.

## Technical note

MuChator is a deployed MusicLLM assistant for active, colloquial music discovery on Douyin Music, using a three-stage curriculum Music Knowledge Pre-training that injects objective knowledge (metadata, encyclopedia, lyric descriptions), subjective knowledge (comments, playlists, CF relations and music KGs), and personalized preference (user profiles and behavior sequences). A next-behavior-prediction paradigm interleaves item and feedback tokens in one autoregressive sequence for denser supervision than next-item prediction. Context-aware instruction tuning synthesizes User-Query-to-Item (UQ2I) triplets via semantic clustering, candidate retrieval, and personalization-guided filtering. Preference alignment uses GRPO with hybrid rewards: model-based relevance (binarized LLM judge) and personalization (online multi-objective ranker) plus rule-based format and factuality rewards. It beats Gemini-3-Pro offline and lifts user active days by 46.49% in online A/B.
