## Technical note

Neural learning-to-rank re-rankers for query autocomplete (QAC) are trained on engagement logs that suffer presentation bias, since prior suggestions influence which query users select. The authors mitigate this with synthetic prefixes: they take full queries from general search sessions where autocomplete was inactive, sample realistic prefixes via a length distribution, and mix these unbiased examples with real QAC engagement data. They deploy a shallow feed-forward ranker under strict latency using query-popularity, seasonality, fuzzy-match, and contextual features (category alignment, device type), and exploit the single-positive-per-prefix structure to reduce listwise loss from O(n^2) to O(n). In a large-scale e-commerce production A/B test the neural ranker improved MRR by over 1% versus the linear baseline.
