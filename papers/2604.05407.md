## Summary

Current LLM-based code agents treat code as unstructured text, leading to brittle edits that often fail. The paper introduces CODESTRUCT, a framework using a structured action space and syntax-validated edits on AST entities. This approach significantly improves code agent accuracy (by 1.2-5.0%) and reduces costs (by up to 33%) across various LLMs, particularly benefiting models that struggle with text-based editing.

## Technical note

CodeStruct reframes a repository as a structured action space over named AST entities (e.g., file.py::Class::method) rather than unstructured text spans, addressing brittleness of string-matching edits. It exposes two primitives: readCode retrieves complete syntactic units (or structural summaries) via deterministic name-based selectors, and editCode applies insertion/replacement/removal transformations to AST nodes with automatic scope/indentation handling and pre-commit syntax validation, exposed via the Model Context Protocol. On SWE-Bench Verified across six LLMs it improves Pass@1 by 1.2-5.0% while cutting tokens 12-38% and cost up to 33%; the biggest gain is GPT-5-nano (+20.8pp) as empty-patch failures drop from 46.6% to 7.2%. Ablations show readCode drives accuracy (removing it causes the largest degradation and inflates exploration) while editCode chiefly reduces cost; gains are largest when text-interface brittleness, not reasoning capacity, is the dominant failure mode.
