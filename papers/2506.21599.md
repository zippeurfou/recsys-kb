## Summary

Large Language Models (LLMs) have been used for POI recommendation, but existing methods face challenges: prompt-based models offer flexibility at lower accuracy, while supervised fine-tuning (SFT) models prioritize exact matches over top-k recommendations. Refine-POI addresses this by using reinforcement learning to train LLMs with custom rewards derived from generated lists and relevance feedback, enabling them to output high-quality top-k suggestions effectively. Experiments show that Refine-POI significantly improves recommendation accuracy compared to standard SFT approaches on real-world datasets.

## Technical note

Refine-POI adapts LLMs for next point-of-interest recommendation, addressing two problems: topology-blind semantic IDs and SFT's fixation on single top-1 targets. It generates topology-aware semantic IDs via a hierarchical self-organizing map so that codebook coordinate proximity reflects semantic similarity, then replaces label imitation with reinforcement fine-tuning using policy gradients and recommendation-driven rewards (inclusion, rank position, diversity) to produce native top-k lists with reasoning. Experiments on three real-world location-based social network datasets show state-of-the-art performance over SFT and prompt-based baselines.
