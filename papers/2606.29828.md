## Summary

1. The paper introduces **HomeDiffusion**, a method aiming to generate customized objects (like furniture or clothes) realistically placed within specific areas in indoor scenes, without any training examples (zero-shot).
2. Existing zero-shot techniques using diffusion models often fail to accurately reconstruct details like patterns and curves from reference objects, especially when the object is asymmetrical or needs to fit complex backgrounds.
3. To overcome these issues, HomeDiffusion uses a novel multi-angle dataset for furniture and rooms, combined with training that focuses on preserving high-fidelity details through cross-attention during diffusion, resulting in superior customization quality compared to existing zero-shot and few-shot methods.

## Technical note

HomeDiffusion (Alibaba) is a zero-shot object-customization framework that inserts a reference object (e.g., furniture) into a designated region of an indoor scene with harmonious perspective and preserved detail. It builds a multi-angle furniture/room dataset and trains in two stages: Multi-view Object Representation Learning (MORL) uses self-generative training where the model predicts another viewpoint of an object from multiple input views, and Background-driven Object Customization Learning (BOCL) inserts the reference into the scene. A high-resolution HD visual encoder extracts global and local object details, and pixel-aligned cross-attention between a composited reference-plus-scene image and the noise latents in the latent space preserves high-fidelity patterns/curves despite perspective deviation. It outperforms prior zero- and few-shot methods on ZOC-Indoor-Eval and VITON-HD.
