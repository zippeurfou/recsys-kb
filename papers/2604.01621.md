## Summary

Existing LLM inference methods using multi-GPU systems face performance issues due to layer-wise synchronization caused by workload imbalance. The paper introduces DWDP (Distributed Weight Data Parallelism), a new parallelization strategy that avoids this synchronization by allowing each GPU to execute independently and fetching expert weights on demand. DWDP, implemented in TensorRT-LLM, achieves an 8.8% improvement in end-to-end output tokens-per-second-per-GPU (TPS/GPU) while maintaining comparable performance from a user's perspective.

## Technical note

DWDP (Distributed Weight Data Parallelism) is an LLM inference parallelization strategy that preserves data-parallel execution while offloading mixture-of-experts weights across peer GPUs and fetching missing experts on demand. By eliminating collective layer-wise inter-rank synchronization, it lets each GPU progress independently, removing the sensitivity of end-to-end performance to workload imbalance. Two optimizations handle the resulting overheads: split-weight management and asynchronous remote-weight prefetch. Implemented in TensorRT-LLM and evaluated with DeepSeek-R1 on GB200 NVL72, DWDP improves end-to-end output TPS/GPU by 8.8% at comparable TPS/user in the 20-100 TPS/user range under 8K input and 1K output lengths.

- NVLink traffic is not the dominant source of slowdown. Using publicly available profiling tools such as Nsight Systems and Nsight Compute, we monitored NVLink utilization and found that the instantaneous NVLink throughput does not show noticeable fluctuation when communication overlaps with the attention kernel. In other words, overlapping with the attention kernel does not significantly perturb the NVLink transfer rate; instead, the effective NVLink bandwidth is still primarily determined by system frequency. This observation suggests that NVLink or NoC contention is not the dominant cause of the slowdown
