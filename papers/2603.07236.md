## Summary

Foundation models need to adapt over time (continual learning/personalization), but current methods often overwrite shared weights, leading to degradation or compromise. We propose HY-WU, a functional neural memory framework that generates instance-specific operators for adaptation. HY-WU synthesizes weight updates dynamically from the instance condition, avoiding shared weight overwriting and enabling more effective personalization and adaptation.

## Technical note

HY-WU (Weight Unleashing) is a memory-first adaptation framework that replaces static single-point weight updates with a generator g_phi that synthesizes instance-specific weight updates Delta-theta(x) on the fly from the instance condition, giving operators f_{theta+Delta-theta(x)} without test-time optimization. It frames adaptation as a feasibility problem: heterogeneous objectives induce separated feasible regions, so shared LoRA/SFT updates cause compromise or interference while per-domain adapters over-specialize. Technically it introduces an end-to-end on-the-fly training objective optimized directly from downstream loss (avoiding checkpoint collection that limits prior hypernetworks), and a rank-anchored 2D parameter tokenization with factorized attention to scale weight generation to large backbones. Instantiated for text-guided image editing, it ranks #1 on GEdit-Bench and #2 on ImgEdit-Bench among open-source models, supporting continual learning and personalization without corrupting the shared base.
