## Summary

1.  Existing benchmarks for specialized fields like Scanning Probe Microscopy (SPM) are inadequate due to data issues and high costs, so the authors created SPM-Bench, a rigorous multimodal benchmark at a PhD level.
2.  SPM-Bench uses a novel, fully automated data synthesis pipeline involving the Anchor-Gated Sieve (AGS) technology and a hybrid cloud-local architecture to efficiently extract and crop high-value image-text pairs from recent scientific papers, saving tokens while ensuring data quality.
3.  To evaluate LLMs rigorously on SPM-Bench, the authors introduced the Strict Imperfection Penalty F1 (SIP-F1) score, which not only ranks performance but also correlates with model confidence to reveal true reasoning limits in complex physical scenarios.

## Technical note

SPM-Bench is a PhD-level multimodal benchmark for scanning probe and electron microscopy (STM, AFM, SEM, TEM) evaluating MLLM scientific reasoning. It proposes a fully automated data-synthesis pipeline using Anchor-Gated Sieve (AGS) filtering to extract relevant image-text pairs from arXiv and journal papers, with a hybrid cloud-local architecture where VLMs return only bounding-box coordinates for high-fidelity local cropping to cut token/API cost. It introduces the Strict Imperfection Penalty F1 (SIP-F1) metric that penalizes speculative answers, establishing a capability hierarchy and characterizing model 'personalities' (Conservative, Aggressive, Gambler, Wise). Results are correlated with model-reported confidence and perceived difficulty. Not a recommender-systems paper.
