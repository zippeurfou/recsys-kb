## Summary

1.  E-commerce platforms like Taobao need recommendation systems that generate ordered item lists optimizing multiple business goals (clicks, conversions, GMV), but existing methods focus too much on single-item accuracy and neglect user intent or inter-item interactions in the list.
2.  To address this limitation for **list-level** multi-objective optimization during re-ranking, researchers propose SORT-Gen, a novel end-to-end generative model combining a Transformer-based ordered regression component for estimating multiple objectives simultaneously across variable-length sub-lists with an efficient generation algorithm.
3.  SORT-Gen provides significantly faster list generation (using a Mask-Driven Fast Generation Algorithm) while maintaining item diversity and optimizing business metrics, demonstrated by online experiments showing +4.13% clicks and +8.10% GMV improvement for one specific Taobao mini-app, where it has since been deployed successfully across various scenarios.

## Technical note

E-commerce recommenders must optimize multiple business objectives (clicks, conversions, GMV) but traditional formula/LTR approaches operate at item level with static weights, ignoring dynamic user intent and inter-item context, while existing re-rankers focus on accuracy and neglect list-level multi-objective optimization. Taobao proposes SORT-Gen, an end-to-end generative re-ranking model combining a Sequential Ordered Regression Transformer (causal-masked Transformer that estimates multi-objective values for variable-length sub-lists via ordered-regression cross-entropy losses) with a Mask-Driven Fast Generation Algorithm that selects items across multi-objective candidate queues in a single forward pass using tensor/mask operations and integrates MMR for diversity. It reaches 19ms latency (on par with ranking) and in online A/B tests on the Baiyibutie mini-app delivers +4.13% clicks and +8.10% GMV over the FFT-context+fastDPP baseline, and is deployed across multiple Taobao scenarios.
