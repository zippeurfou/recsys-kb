## Summary

1.  Spotify developed GLIDE, a generative recommender system using Large Language Models (LLMs) to improve podcast discovery, recognizing the need for recommendations that balance stable user preferences with evolving intent.
2.  GLIDE addresses production challenges by grounding LLM generations to a large podcast catalog using Semantic IDs, conditioning outputs on recent listening history and lightweight user context, and incorporating long-term preferences via embeddings.
3.  Evaluated extensively and deployed at scale, GLIDE significantly increased the discovery of new podcasts and non-habitual streaming while meeting crucial production constraints like latency and cost.

## Technical note

GLIDE is a production generative recommender for podcast discovery at Spotify that frames recommendation as an instruction-following task over a catalog discretized into content-based Semantic IDs (Residual K-Means, K=256, M=4 giving 1024 SID tokens, 4 tokens per episode) to enable grounded generation and cold-start coverage over a fast-changing catalog. It conditions on recent-history SIDs and lightweight natural-language user context, and injects a long-term collaborative-filtering user embedding as a projected soft prompt to capture stable preferences without inflating context. Training decouples catalog grounding (bidirectional SID<->text translation with frozen backbone then LoRA) from instruction tuning, and uses multi-task learning with a control token to steer between non-habitual-familiar and non-habitual-unfamiliar discovery objectives. Built on a compact ~1B open-weight LLM, online A/B tests over millions of users raised non-habitual streaming up to 5.4% and new-show discovery up to 14.3% within latency/cost constraints.
