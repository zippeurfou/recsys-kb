## Summary

This paper addresses the challenge of improving long-term user retention in large-scale recommender systems like Pinterest. The core difficulty lies in accurately attributing user revisits to specific actions and managing the vast historical data involved. The authors propose a lightweight framework linking saved items to subsequent revisits, enabling scalable analysis and enhancing the recommendation system's focus on retention, which significantly increased active users when deployed.

## Technical note

This Pinterest work models revisitation (users returning to previously saved Pins) as a surrogate reward for long-term retention, addressing attribution noise and multi-day scale. It defines a surrogate attribution linking save (repin) events to subsequent same-day and 7-day revisitation grid-clicks/impressions, builds a scalable cross-surface, cross-session data pipeline, and adds a revisitation head plus Pin-perf revisitation features to an existing multi-task ranking model (transformer user-sequence + DCNv2 + MMoE). Offline the revisitation head gained 20-40% ranking lift; a two-month A/B test on Related Pins over 24M users lifted active users by 0.1% with no added serving cost. Analysis shows aesthetic topics are revisited more.
