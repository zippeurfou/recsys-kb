## Summary

1.  The paper addresses challenges in conversational search systems under distributional shift (changes in query patterns), proposing RCEM which embeds conversational context-awareness into dense retrieval models without needing explicit multi-turn query rewriting during inference.
2.  RCEM distills the query reformulation ability of large language models directly into its embedding function, effectively aligning embeddings of original conversation queries with those of potentially rewritten ones derived from LLM skills, enhancing relevance for complex user needs.
3.  This approach significantly improves retrieval robustness compared to existing methods under distributional shift and outperforms baselines in standard evaluation metrics, while crucially enabling a single model to handle both standalone and conversational queries against the same document index without modification or retraining.

## Technical note

RCEM is a robust conversational search embedder that distills an LLM's query-reformulation capability into a dense retriever while preserving the base embedder's original embedding space. Rather than learning direct conversation-to-passage matching, it aligns a conversation (prepended with a special token) to the LLM-rewritten standalone query embedded by a frozen original embedder, so the unchanged embedding space automatically maps to relevant passages. This design reduces overfitting by simplifying alignment from long passages to short rewritten queries, removes the need for conversation-to-passage relevance labels, and lets conversational queries run against indexes built by the original embedder without rebuilding. Experiments show up to 30% improvement under distributional shift, with a single model handling both standalone and conversational queries.
