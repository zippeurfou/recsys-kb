## Summary

Unsupervised dense retrievers, while scalable via contrastive learning on unlabeled data, struggle with retrieving temporally relevant documents from collections spanning multiple time periods (Temporal Ambiguity). To address this lack of learned temporal alignment, researchers developed TPOUR ("Temporal Preference Optimization for Unsupervised Retrieval"), utilizing a novel training method called Temporal Retrieval Preference Optimization (TRPO) which guides the model to prefer temporally aligned content. This approach further allows generalization across unseen time periods using interpolation in a learned time embedding and consistently outperforms both unsupervised and supervised baselines on standard temporal information retrieval benchmarks.

## Technical note

TPOUR embeds temporal relevance into unsupervised dense retrieval via Temporal Retrieval Preference Optimization (TRPO), which reinterprets DPO-style preference learning in the temporal dimension: preference pairs are constructed from document corpora across time periods and the retriever learns to prefer temporally aligned over semantically-similar-but-misaligned documents, using embedding similarity instead of log-likelihoods and requiring only corpus-level (not explicit-timestamp) supervision. Training combines TRPO with MoCo-based contrastive learning to preserve semantic similarity while adding temporal awareness for both explicit (in 2019) and implicit (this year) queries. It extends time-vector extraction from generative LMs to encoder retrievers, enabling continuous temporal generalization to unseen intermediate and future periods via interpolation without retraining. Despite being ~72.7x smaller than Qwen-Embedding-8B, TPOUR Contriever improves average nDCG@5 by +4.04 (explicit) and +4.98 (implicit).
