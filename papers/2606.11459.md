## Summary

1.  Large Language Models (LLMs) are highly sensitive to how prompts are formulated, requiring optimization techniques for effective use. Current evolutionary algorithms used for prompt engineering waste compute by evaluating static datasets with uninformative data points.
2.  This paper introduces APEX, a framework that optimizes both the LLM prompt *and* the selection of test data simultaneously within an evolutionary algorithm search process. It dynamically divides the dataset into tiers (Easy, Hard, Mixed) based on the evolving search candidates.
3.  By strategically focusing evaluations mainly on the 'Mixed' tier – where performance is uncertain and potentially most informative for further improvement – APEX achieves better prompt quality than existing methods using fewer LLM calls, demonstrating that data efficiency is crucial for effective optimization.

## Technical note

APEX is an automatic prompt-optimization framework that targets the data-efficiency bottleneck in genetic/evolutionary prompt search, where treating the dev set as a static benchmark wastes compute on uninformative points. Maintaining a lineage of prompt performance in a sparse score matrix, APEX dynamically stratifies datapoints into Easy, Hard, and Mixed tiers and concentrates compute on the Mixed tier, which yields the addressable frontier (volatile errors good for mutation) and the rank-sensitive frontier (ambiguous cases that discriminate candidate quality). This optimizes both the prompt and the data usage within the evolutionary loop, using stratified sampling for selection and mutation history to explore unvisited prompt space, with incremental evaluation that skips previously scored points. Under a fixed 5,000-call budget it improves over the initial prompt by 11.2% on Gemini 2.5 Flash and 6.8% on Gemma 3 27B across IFBench, SimpleQA Verified, and FACTS Grounding, in a fully automated black-box setting.
