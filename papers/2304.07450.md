## Summary

1.  Recommender systems often use ranking ensembles, combining item lists from different models, but existing methods struggle when these lists have different objectives (user intents) relevant to a single user visit.
2.  This paper introduces the Intent-aware ranking Ensemble Learning (IntEL) model, which learns personalized weights for items based on detected user intents to effectively fuse multiple item lists with varying objectives.
3.  The IntEL model's effectiveness is theoretically proven and empirically validated on large datasets, showing significant improvements in recommending for multiple concurrent user behaviors compared to previous ensemble methods.

## Technical note

IntEL fuses multiple heterogeneous single-objective ranking lists (e.g., click, favorite, buy models) into one list that satisfies concurrent user intents, learning item-level ensemble weights rather than list-level ones. The authors theoretically prove via a generalized error-ambiguity (EA) decomposition that item-level weighted ensembles achieve loss below any base list under pointwise (MSE), pairwise (BPR), and listwise (Plackett-Luce) objectives, yielding an ambiguity term maximized during training. A sequential intent predictor produces a distribution over (behavior, item-category) pairs, and an ensemble module combines base scores, item categories, and intents via self- and cross-attention to output the weights. On Tmall and a LifeData dataset IntEL significantly outperforms unsupervised (Borda, RRA) and supervised (lambdaRank, ERA, aWELv) baselines across all behavior objectives simultaneously.
