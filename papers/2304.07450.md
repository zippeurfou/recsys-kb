## Summary

This paper addresses the challenge of integrating multiple single-objective ranking lists (each optimized for a different user intent, like clicking or buying) into a unified recommendation list. To solve this, the authors propose the Intent-aware ranking Ensemble Learning (IntEL) model, which learns personalized item-level weights considering various user intents. Experiments on real datasets demonstrate that IntEL significantly improves recommendation performance across multiple behavior objectives compared to existing methods.

## Technical note

IntEL (Intent-aware ranking Ensemble Learning) fuses multiple heterogeneous single-objective ranking lists (e.g., click vs. purchase models) into one personalized list, unlike prior rank aggregation that assumes homogeneous same-objective lists. It learns item-level ensemble weights conditioned on predicted user intents (behavior plus item category), using a sequential model to infer intents and an ensemble module integrating basic-list scores, item categories, and intents. The authors prove via error-ambiguity decomposition that item-level ensembling can achieve lower loss than any base model under pointwise, pairwise, and listwise losses, deriving an ambiguity term used in optimization. Experiments on two large-scale datasets show significant simultaneous improvements across multiple behavior objectives.
