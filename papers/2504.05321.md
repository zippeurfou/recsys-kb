## Summary

Query-to-bidword(i.e., bidding keyword) rewriting is fundamental to sponsored search, transforming noisy user queries into semantically relevant and commercially valuable keywords. Recent advances in large language models (LLMs) improve semantic relevance through generative retrieval frameworks, but they rarely encode the commercial value of keywords. ## Technical note

VALUE is a value-aware LLM query-to-bidword rewriting framework for sponsored search that injects commercial value into generation. It introduces a Weighted Trie storing real-time per-token value signals to adjust the LLM's decoding probabilities toward high-value rewrites, plus a fine-grained preference-learning alignment stage that emphasizes stable high-value differences and down-weights transient fluctuations to reduce overfitting. Offline it beats baselines on semantic and value metrics; online A/B lifted Revenue Per Mille (RPM) by 1.64%, and it has served Alibaba's Double Eleven promotions since October 2024.
