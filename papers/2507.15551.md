## Summary

RankMixer addresses two main challenges in scaling recommendation systems: meeting strict latency requirements (low serving cost) and improving feature-interaction efficiency (high MFU). It introduces a hardware-aware architecture combining transformer parallelism with multi-head token mixing for efficient self-attention, along with per-token FFNs to handle distinct features and their interactions. Experiments demonstrate that RankMixer significantly boosts scalability by increasing model parameters 100x while maintaining latency on a production dataset, leading to measurable improvements in user engagement metrics through online A/B tests.

## Technical note

RankMixer is a hardware-aware ranking architecture that scales industrial DLRMs while respecting GPU efficiency and latency limits. It replaces quadratic self-attention with a parameter-free multi-head token-mixing module and uses per-token FFNs so distinct feature subspaces get isolated parameters, avoiding high-frequency-field domination; a Sparse-MoE variant with dynamic routing extends it to 1B parameters. On a trillion-scale Douyin dataset it lifts model FLOPs utilization from 4.5% to 45% and scales parameters ~100x at roughly constant inference latency. The deployed 1B dense model improved user active days by 0.3% and in-app usage duration by 1.08%.
