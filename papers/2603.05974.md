## Summary

This paper introduces MCCom, a framework for line-level code completion that balances latency and accuracy. It combines a fast local small language model (SLM) with a more accurate cloud-based large language model (LLM) using user actions as a trigger for the LLM, significantly reducing cloud usage. Additionally, MCCom includes a lightweight model and collaboration strategies, achieving notable speed improvements and performance gains over existing methods.

## Technical note

MCCom cascades a locally-deployed 121M small language model with a cloud LLM for line-level code completion, running the small model by default and escalating only when needed. Escalation is triggered by the small model's first-three-token confidence plus implicit user-action signals (skipping/deleting a suggestion), reducing cloud usage by ~46%. Two-stage speculative decoding reuses the rejected small-model output as a speculative draft for the large model, and iterative retrieval refines the RAG query using that rejected output to enrich cloud-model context. The authors introduce StmtEval, a benchmark defining a completion target as a full statement rather than a single syntactic line, alongside RepoEval. Reported gains include up to 47.9% latency reduction and 8.9% average exact-match improvement over always calling the large model.
