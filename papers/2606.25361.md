## Summary

This paper argues that memory roles significantly shape conversational agents' responses beyond just their storage and retrieval mechanisms. It introduces a fine-grained taxonomy classifying retrieved memories into functional types (like clarifying or irrelevant) to understand different impacts on response quality under various contexts. Through user-centric evaluations, the study demonstrates specific effects of these memory roles, showing that they can improve accuracy and personalization but also degrade relevance, highlighting ways to leverage memory for better agent performance even with powerful LLMs.

## Technical note

This work argues that the functional role of a retrieved memory, not just how memory is stored and retrieved, shapes conversational-agent responses in RAG-based long-term dialogue. It introduces a fine-grained taxonomy classifying retrieved memories into role types (e.g., clarifying, informative, distracting, irrelevant) and a user-centric, reference-free evaluation framework that simulates user perspectives. Comparative experiments on long-term dialogue datasets with frontier LLMs show differentiated effects: clarifying memory improves factual accuracy, constraint awareness, and personalization, while irrelevant memory lowers topic relevance and degrades constraint awareness. Findings suggest deliberately leveraging memory types for more personalized responses even with strong LLMs; relevance to recommendation is indirect (personalization/RAG).
