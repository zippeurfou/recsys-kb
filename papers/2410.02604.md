## Summary

This paper addresses the challenge of handling long user behavior sequences in recommendation systems. It identifies a key limitation where standard embeddings interfere with both attention selection and representation learning processes. To overcome this, the authors introduce DARE (Decoupled Attention and Representation Embeddings), which uses separate embedding tables to fully decouple these functions.

Extensive experiments demonstrate that DARE provides more accurate identification of relevant user behaviors for recommendation. Furthermore, by separating the embeddings, it allows reduction in dimensionality, significantly speeding up the attention computation process without sacrificing performance.

The work highlights a unique need within recommendation models and shows how decoupling embedding spaces leads to improved accuracy and efficiency on both public datasets and industry platforms.

## Technical note

Long-sequence CTR models use a two-stage search-then-modeling paradigm where an attention module retrieves relevant behaviors and a representation module builds the prediction embedding. The authors show, via MTL gradient analysis, that sharing one embedding table for both roles causes interference: gradients are dominated by representation and conflict with attention, so key behaviors get filtered out during search. Their DARE model uses two separately learned embedding tables to fully decouple attention from representation. DARE improves retrieval accuracy and AUC (up to 9 permille) on public data and Tencent's ad platform, and lets the attention embedding dimension be halved to speed search ~50% with little quality loss.

Basing on the original TWIN model, whenever the gradient is back propagated to the embedding (we have demonstrated in Section 2.2 that gradient from representation is about five times larger than that from attention), we manually scale the gradient from attention to make its 2-norm the same as representation, which can solve the problem of domination (arXiv:2410.02604)
- On Taobao dataset, TWIN must retrieve more than 15 behaviors to fulfill its potential, while DARE can achieve best performance when retrieving more than 10 behaviors. This indicates that DARE can retrieve those important behaviors more accurately, while TWIN must retrieve more behaviors to avoid missing important ones
- DARE consistently outperforms TWIN across all settings, especially with fewer retrieval numbers. On Taobao dataset, when retrieving only one behavior, DARE can outperform TWIN with an AUC increase of 5.7% (even a 0.1% AUC increase is considered significant)
- In all our other experiments, the retrieve number is set to 20 to ensure all models perform at their best. Our advantage over TWIN would only be more obvious in some other settings (arXiv:2410.02604)
- Reduced advantage with shorter sequences: DARE’s advantage over TWIN diminishes as the sequence length decreases. Shorter sequences make it easier to model user history, reducing the impact of inaccuracies in measuring behavior importance. Under these conditions, TWIN achieves performance comparable to DARE
- Superior performance with longer sequences: DARE excels with longer sequences. On the Tmall dataset with embedding dimension=16, however, TWIN performs worse with a sequence length of 200 compared to 120. This suggests that DARE effectively captures the importance of each behavior and leverages long user histories at any setting, while TWIN relies heavily on embedding dimension and would struggle with an abundance of historical behaviors when embedding dimension is small (arXiv:2410.02604)
