## Summary

1. Large Recommendation Models (LRMs), powerful tools for industry-scale recommendations built on transformers, struggle with effectively integrating traditional recommendation signals without significant drawbacks.
2. Current methods to adapt these non-textual signals often involve long prompts or discrete item representations, leading to inefficient memory use and high computational costs due to excessive length.
3. To address this, the authors introduce Token Factory, a framework that converts diverse input features into specialized "soft tokens" which can be efficiently processed by LRMs, enabling better integration without prompt inflation and improving overall performance in production settings.

## Technical note

Token Factory integrates heterogeneous traditional signals (dense, sparse, sequence features) into transformer-based Large Recommendation Models by transforming them into learnable 'soft tokens' -- embeddings placed directly in the model's input space -- instead of textualizing them or emitting long Semantic ID token sequences. Modular Token Makers (watch-history, query, candidate) project concatenated features through MLPs into a fixed, deterministic number of soft tokens, enabling sequence compression (MLP over the sequence dimension or attention pooling), longer histories, and prefix caching of static query/user tokens for serving. Built on the PLUM/Gemini-derived MoE LRM, it matches baseline ranking ROC-AUC at ~30% of the prompt length (~200% faster training), and for YouTube Homepage generative retrieval yields +2.0% Recall@10 offline and +16.8% Unique Impressions online (+67.1% for one-day-fresh videos). Ablations show soft tokens beat textual SIDs under a fixed context budget by fitting more history.
