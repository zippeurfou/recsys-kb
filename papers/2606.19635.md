## Summary

Large Recommendation Models (LRMs) are effective for industry tasks but face challenges integrating traditional data signals efficiently, often due to excessively long prompts caused by standard methods like direct text conversion or discrete item lists.

To solve this, the authors introduced Token Factory, a framework transforming diverse input features into "soft tokens" that LRMs can process directly within their architecture.

This approach allows for efficient integration and compression of multiple signal types without increasing prompt length, leading to reduced memory use and computational cost while potentially improving recommendation performance.

## Technical note

Token Factory (Google) integrates traditional dense/sparse recommendation signals into transformer-based Large Recommendation Models by converting heterogeneous features into 'soft tokens' (embedding representations) rather than textualizing them, which avoids prompt-length explosion, memory blowup, and compute overhead. Evaluated on production next-video prediction, it achieves on-par or superior ranking/retrieval quality versus long-prompt baselines while delivering significant efficiency improvements, and complements Semantic ID generation and continual pre-training in LRM pipelines.
