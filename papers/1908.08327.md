## Summary

This paper introduces a personalized, session-based algorithm called ZSF-c for recommending complementary fashion items. It addresses the challenge of recommending outfit components by proposing a sampling strategy for building the training set, useful when user interaction data is poor or unavailable. The algorithm significantly outperformed standard collaborative filtering (CF), achieving an 8.2% offline uplift in orders recall and a 3.24% increase in purchased products in a large-scale online A/B test.

## Technical note

ZSF-c is a personalized, session-based complementary-item recommender for fashion e-commerce (Zalando), built on the STAMP short-term-attention session model and extended with order events plus category and image embeddings. To handle poor or unavailable interaction data, the authors design a sampling strategy for constructing the training set from complementary relationships. Against the incumbent collaborative-filtering complementary recommender (CF-c), ZSF-c delivers an 8.2% relative offline uplift in Orders Recall@5 and a 3.24% increase in purchased products in a large-scale online A/B test on a platform with 28 million active customers.
