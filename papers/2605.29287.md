## Technical note

UniNote is a unified multimodal embedding model for industrial item-to-item (I2I) retrieval at Xiaohongshu that jointly handles global content representation, fine-grained local-to-global retrieval, and relevance ranking in a single MLLM-based model (last-token-as-embedding). It uses two-stage training: contrastive supervised fine-tuning with hard-negative mining to build base embeddings, then Relative Reranking via GRPO with a hierarchical reward over ranking positions and hard negatives to optimize list-wise relevance in one pass without a separate generative reranker. Defining ten I2I task categories, UniNote achieves SOTA across all of them; deployed with Matryoshka Representation Learning it improves retrieval quality and cost efficiency at scale.
