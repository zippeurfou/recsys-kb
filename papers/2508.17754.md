## Technical note

Kuaishou's DiffusionGS improves personalized search ranking by using the user query as an explicit intent anchor to extract immediate interests from long, noisy behavior sequences. It formulates interest extraction as a query-conditioned diffusion denoising process built on a GRM (transformer) backbone, and introduces a User-aware Denoising Layer (UDL) that folds user profiles into the attention distribution over past actions, while retaining 'irrelevant' items as useful profile signals. Extensive offline and online experiments show DiffusionGS outperforms state-of-the-art DLRM (e.g. QIN) and GRM baselines at capturing dynamic user interest shifts.
