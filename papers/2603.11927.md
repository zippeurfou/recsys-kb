## Summary

CogSearch is a novel multi-agent framework designed to transform passive e-commerce search into an active decision support system, addressing user overwhelm by mimicking human cognitive processes. It achieves this through four specialized agents that decompose user intents and fuse knowledge to provide actionable insights. Offline and online testing on JD.com demonstrated its effectiveness, reducing decision costs by 5% and boosting conversions, particularly for complex queries, representing a shift towards collaborative decision intelligence.

## Technical note

CogSearch reframes e-commerce search from a passive retrieve-and-rank pipeline into a proactive decision-support system using four cooperating LLM agents aligned to Simon's decision model: a Planner that decomposes user intent into a task-graph DAG (product search, web search, tool invocation via MCP), an Executor for multi-source retrieval, a Guider that generates dynamic filters and follow-up questions for demand convergence, and a Decider that synthesizes signals into structured purchase recommendations. A Memory System stores contextual memories, agent states, and the task graph across dialogue turns. On JD.com, online A/B tests reduced decision cost by 5%, lifted overall UCVR by 0.41%, and boosted conversion for decision-heavy queries by roughly 30%. The paper contrasts this with conventional stack components like BM25/LSI retrieval, RocketQA dense matching, and DIN attention ranking.
