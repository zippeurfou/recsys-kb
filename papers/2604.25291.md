## Technical note

GloRank reframes list-wise reranking from selecting local candidate indices (a position-dependent, semantically inconsistent action space that inflates output-layer gradient variance) to generating global item identifiers via Semantic IDs, mapping million-scale corpora into a compact fixed vocabulary. It uses a two-stage pipeline: supervised pre-training on high-quality reference lists followed by RL post-training to maximize list-wise utility, plus constrained decoding with generation trees for valid non-duplicated outputs. The paper gives a theoretical variance analysis showing global identifiers remove mapping-induced gradient variance. Experiments on two public benchmarks, a large-scale industrial dataset, and online A/B tests show GloRank outperforms SOTA baselines with superior cold-start robustness.
