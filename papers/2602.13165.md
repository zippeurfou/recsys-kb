## Summary

This paper addresses the challenge of semantic caching in LLM architectures, where a single similarity threshold for static/dynamic caches creates a difficult trade-off between reuse and correctness. The proposed solution, Krites, operates asynchronously: it checks borderline queries using an LLM judge, and if approved, promotes static answers to the dynamic cache, expanding reuse opportunities. Krites significantly increases the use of static responses (up to 3.9x) without increasing latency, by safely extending the reach of the static cache.

## Technical note

Krites is an asynchronous verified semantic caching policy for tiered static-dynamic LLM caches, where a single embedding-similarity threshold otherwise forces a hit-rate versus error-rate tradeoff. On the critical path it behaves exactly like a standard threshold policy, but when a prompt's nearest static neighbor falls in the similarity grey zone just below threshold, it schedules an off-path LLM judge to verify equivalence. Approved matches trigger an auxiliary overwrite that upserts the static response into the dynamic cache under the new key, turning the dynamic cache into a mutable pointer layer over curated static answers. In trace-driven simulations on conversational and search workloads it raises static-origin hits up to 3.9x at fixed error rate with unchanged critical-path latency, elevating reliability by serving vetted answers.
