## Summary

This paper addresses the challenge of predicting conversion rates (CVR) in e-commerce recommendation systems where item discounts significantly impact user purchasing but are often overlooked. To overcome this, authors introduced DANet, a discount-aware network incorporating three key components: a time-frequency analysis module using Fourier transforms to understand discount trends, a distribution de-bias module to handle selection biases from different purchase contexts and promotions, and a supervised regression auxiliary task providing explicit item discount labels.

DANet specifically models the relationship between known item price reductions (discount rates) and CVR prediction accuracy. Their experimental results demonstrate that DANet consistently outperforms existing methods on real datasets, achieving notable improvements in offline evaluation metrics like AUC and showing significant positive effects online through increased pCVR (+3.63%) and Gross Merchandise Value (+2.23%). The model has been successfully deployed by Alibaba Tmall, with its source code publicly available for other researchers and practitioners to utilize.

## Technical note

Addresses post-click conversion rate (CVR) prediction by modeling item Discount Rate (DR) as a substitute for raw price, a factor prior CVR work underexplored despite data sparsity, sample selection bias, and delayed feedback. The Discount-Aware Network (DANet) pairs an Interest-Prefer Net (multi-head target attention over behavior sequences) with a Discount-Prefer Net comprising a Time-Frequency Transformation Module (FFT/IFFT to extract long-term DR trends), a Distribution Correction Module (DCM-User attribute-attention plus PEPNet-style DCM-Context gating to debias user sensitivity and promotion-period effects), and a supervised MSE regression auxiliary task on explicit DR labels. Offline AUC improves 1.61% (0.8479 vs 0.8345 base), with the TFTM module the largest contributor. Deployed on Alibaba Tmall, online A/B tests show pCVR +3.63% and GMV +2.23% at under 5% added response time.
