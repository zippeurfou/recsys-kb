## Summary

This paper introduces AMemGym, an interactive benchmarking environment designed to evaluate and optimize the memory management of large language model (LLM) assistants during long conversations. It addresses the limitations of existing static benchmarks by using LLM-simulated users in a structured environment that dynamically generates realistic, state-consistent interactions based on predefined user profiles and goals. AMemGym provides comprehensive metrics to assess memory performance and identify gaps, enabling more effective comparison and potential self-improvement of memory systems.

## Technical note

AMemGym is an interactive environment for on-policy evaluation and optimization of LLM-assistant memory in long-horizon conversations, addressing the reuse bias of static off-policy memory benchmarks. It uses a schema-based structured data sampling approach that predefines user profiles, state-dependent questions, and state-evolution trajectories, then has LLM-simulated users expose these latent states through role-play while maintaining structured state consistency. Evaluation combines overall metrics (accuracy, normalized memory score) with diagnostic metrics decomposed by memory operation (write, read, utilization). Experiments benchmark RAG-based, long-context, and agentic memory systems, empirically demonstrate off-policy reuse bias, and provide a proof of concept where an agent uses environmental feedback to autonomously refine its memory-management policy (self-evolution).
