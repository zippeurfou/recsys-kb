## Summary

This paper introduces **ADORE**, a new framework for e-commerce search relevance modeling. It addresses challenges like semantic gaps and data scarcity by combining three innovations: a rule-aware module generating intent-aligned data using LLMs, an error-aware module synthesizing adversarial examples, and a knowledge distillation module incorporating domain attributes. The system automates data generation and training, proving effective through experiments and establishing a resource-efficient paradigm for industry.

## Technical note

ADORE is a self-sustaining framework for e-commerce search relevance that addresses domain-specific hard-sample scarcity and weak reasoning of lightweight online models. It combines a rule-aware relevance discrimination module (a CoT-tuned LLaMA-3 aligned to user purchasing behavior via KTO to generate hard samples), an error-type-aware data synthesis module producing adversarial examples with GPT-4o few-shot prompting, and a key-attribute-enhanced knowledge distillation module that injects CoT-mined attributes into a deep cross-encoder BERT teacher distilled into a shallow BERT-Mini student. Offline tests on 3.2M JD query-product pairs and online A/B tests show F1 gains and improvements in CTR, ad revenue, and human-judged relevance.
