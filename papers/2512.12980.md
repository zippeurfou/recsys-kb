## Summary

Vector Similarity Search (VSS), crucial for AI and databases, is often evaluated poorly using only distance metrics and ignoring downstream task performance. This paper introduces Iceberg, a new benchmark designed to assess VSS in realistic application contexts by focusing on task outcomes. Iceberg identifies key pitfalls like poor embeddings or index sensitivity, benchmarks leading methods across diverse datasets, and provides guidelines for selecting the right VSS approach based on specific application needs.

## Technical note

Iceberg is a task-centric benchmark for vector similarity search (VSS) arguing that traditional recall-latency evaluation against distance-defined ground truth misleads because it ignores downstream task performance. It introduces the three-layer Information Loss Funnel (embedding loss, metric misuse, distribution sensitivity) and benchmarks 13 SOTA ANNS/MIPS methods over eight datasets (1M-100M vectors) spanning image classification, face recognition, text retrieval, and recommendation using label recall@K, hit@K, and matching score@K. Rankings deviate substantially from distance-only leaderboards; the authors derive interpretable meta-features (clustering tightness, norm distribution, angular separation, distance contrast) and a decision-tree toolkit to guide practitioners in selecting and tuning VSS methods.
