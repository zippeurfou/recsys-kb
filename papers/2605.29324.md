## Summary

This paper introduces STAMP, a framework designed to train mobile GUI agents to explicitly use memory for long-horizon tasks. The core issue addressed is that current agents lack sufficient memory due to limited context windows and inadequate training data. STAMP solves this by programmatically injecting memory variables into a controllable virtual environment to teach agents what, when, and how to memorize and retrieve information, leading to a state-of-the-art agent on a new benchmark.

## Technical note

STAMP trains explicit memory in mobile GUI agents to overcome the conflict between limited context windows and token-heavy screenshots, where discarding old visual history permanently loses transient details (codes, prices). It programmatically synthesizes memory-intensive tasks in controllable virtual environments, injecting deterministic memory variables that specify what to memorize, when it appears, and when it must be retrieved, yielding automatically verifiable step-level supervision. The agent outputs a triple (reasoning c_t, action a_t, memory m_t), externalizing critical information before the source screenshot is dropped. Training combines step-balanced supervised fine-tuning (upweighting sparse memory steps, with a critic masking noisy labels) and online reinforcement learning with task, format, and memory rewards judged against reference memory traces. The resulting Stamp-GUI sets state-of-the-art on the new Memory-World benchmark while retaining general navigation.
