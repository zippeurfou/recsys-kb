## Summary

1.  Existing reinforcement learning methods for query optimization struggle with complex user queries needing multiple search strategies, facing issues of expanded search space and unstable training.
2.  To address these challenges, the paper introduces ACQO, a novel RL framework featuring an Adaptive Query Reformulation module (for query decomposition) and a Rank-Score Fusion module (for result merging and stable rewards), combined with Curriculum Reinforcement Learning for training stability.
3.  Experiments show that ACQO achieves state-of-the-art performance on complex query benchmarks, demonstrating significant improvements over baselines, computational efficiency gains, and broad applicability for next-generation RAG systems.

## Technical note

RL-based query optimization for RAG mostly rewrites a single query and struggles with complex queries needing parallel/sequential sub-queries, causing expanded search space and unstable training. ACQO adds an Adaptive Query Reformulation module that decides when to decompose a query into sub-queries and a Rank-Score Fusion module that robustly merges retrieved results and yields stable reward signals. Curriculum Reinforcement Learning stabilizes training by progressively introducing harder queries in two stages. ACQO reaches state-of-the-art on three complex-query benchmarks with improved computational efficiency and broad compatibility across retrieval architectures.
