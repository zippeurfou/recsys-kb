## Summary

This paper introduces "RecoReward," an approach to train multimodal large language models (MLLMs) specifically for recommendation tasks while keeping the inference phase content-only and user-independent. Conventional methods don't effectively use downstream user signals during training or rely too heavily on specific user data at generation time. RecoReward uses proxy rewards derived from historical engagement and non-target user behavior to guide MLLM description learning, enabling better semantic feature extraction for recommendations without requiring user information. Experiments show that the trained MLLMs significantly improve recommendation performance across various metrics both offline and online.

## Technical note

Multimodal LLMs can turn item content into semantic descriptions for recommendation, but content-only generation ignores downstream user signals while user-conditioned generation breaks reusable item caching and requires user data at inference. RecoReward injects user supervision only through a training-time reward and keeps content-only inference: a frozen behavior-trained two-tower DSSM scores candidate descriptions, and the Recommender Affinity Score (RAS) contrasts affinity with historically engaged target users against broadly shared non-target affinity, used as a sequence-level reward for GRPO/DAPO policy optimization. On Kuaishou live-stream data, RecoReward-9B leads all seven recall metrics, improving 31.7-40.4% over its Qwen3.5-9B base, with non-target subtraction coefficient lambda=2 and rollout count G=12 as best settings. A one-week online A/B test raised key-page effective-user penetration +0.265% and outflow exposure/users +0.791%/+0.740%.
