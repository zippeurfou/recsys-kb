## Summary

Existing language model benchmarks often yield saturated scores, making it difficult to reliably rank models using standard metrics. The paper introduces SEAL (Seeded Elimination with Adaptive LLM-as-a-Meta-Judge), a protocol that improves ranking accuracy on these saturated benchmarks by using LLMs to evaluate candidate outputs against evolving criteria. SEAL significantly boosts ranking accuracy, matching full pairwise judging results, while requiring far fewer LLM calls (12 vs. 28) than standard methods.

## Technical note

SEAL (Seeded Elimination with Adaptive LLM-as-a-Meta-Judge) recovers latent ranking signal from saturated benchmarks by re-ranking a fixed set of candidate outputs rather than building harder tasks. A cheap listwise judge seeds candidates into a single-elimination bracket; each pairwise match is judged under fixed task-level principles plus rank-adaptive checklist items generated by a meta-judge that refines only the checklist layer (coarser early, finer in later rounds) while keeping aggregation semantics stable. Task-level rankings aggregate to benchmark level via normalized Borda score with principle-margin tie-breaking. Across HumanEval, GSM8K, MMLU, and BFCL-v2, SEAL attains 0.83-1.00 Spearman agreement with exhaustive pairwise judging and 4/4 top-1 agreement using ~11.89 calls/task versus 28 for full pairwise, giving a better accuracy-latency trade-off than pointwise, listwise, and fixed-bracket baselines.
