## Summary

This paper addresses the challenge of content freshness in web search, where static time filters often fail to match user intent. It introduces a novel framework using LLMs to predict a query-specific "validity horizon," dynamically determining when information becomes semantically obsolete. Deployed at Baidu, this system improves search freshness and user experience through offline and online validation.

## Technical note

Deployed in Baidu search, this framework reformulates timeliness as query-aware dynamic content expiration prediction, replacing static time-window bucketing. A temporal information extraction module segments documents into time-anchored focused chunks scored by a composite of keyword and temporal relevance (with exponential recency decay when queries lack explicit time constraints). An LLM then infers a query-specific validity horizon via structured prompting, with a Contrastive Forward-Backward Chain-of-Thought consistency check for hallucination mitigation. LLM judgments are compressed to binary 0/1 flags for low-latency integration into the core ranking model, delivering offline and online A/B gains in freshness and engagement.
