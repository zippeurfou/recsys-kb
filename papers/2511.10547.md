## Summary

This paper addresses the problem of evaluating diversity in text-to-image models, which often produce homogeneous results despite improving quality. It introduces a novel human evaluation framework using specific prompts and a template designed to assess various factors of variation (like object color or style) across diverse concepts. This methodology allows for ranking models based on human annotations and identifying specific diversity weaknesses, providing a robust benchmark for future model development.

## Technical note

The paper introduces a framework to rigorously measure per-attribute diversity in text-to-image (T2I) models, arguing that diversity must be assessed by specifying both a concept and a factor of variation (e.g., apple/color) to avoid ambiguity. It contributes a human-evaluation template that splits judgment into counting and count-comparison subtasks, a curated prompt set of 86 concept-factor pairs, and a binomial-test methodology for model comparison. Collecting 24,591 human annotations across five models (Imagen 3, Imagen 2.5, Muse 2.2, DALLE3, Flux 1.1), it ranks models (Imagen 3 and Flux 1.1 top) and evaluates automatic metrics, finding the Vendi Score reaches ~65% agreement with humans (80% for very different pairs) when using an appropriate embedding space.
