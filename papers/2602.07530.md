## Summary

Conformal prediction provides reliable uncertainty estimates but often produces excessively large prediction sets, especially in complex domains like routing. To address this, the paper introduces "graph-based conformal compression", a method that finds the smallest subgraph containing a desired probability mass, effectively shrinking the prediction set while preserving its statistical validity. They achieve this by solving a specific densest k-subgraph problem with unique properties (ensuring nestedness) and proving efficient algorithms exist, validated through simulations on trip planning.

## Technical note

This mostly theoretical paper introduces graph-based conformal compression: summarizing a large conformal prediction set over structured outputs (routes, itineraries) into a compact subgraph that retains a prescribed probability mass while preserving distribution-free marginal coverage. It reduces the problem to a weighted densest-k-subgraph selection in hypergraphs in the high-coverage regime, and gives a bicriteria constant-factor approximation via LP rounding that scales to exponentially many hyperedges via sampling. Crucially, it proves the approximation is monotone (nested subgraphs across coverage levels) by reinterpreting it through parametric minimum cuts, which yields quadratic running time and guarantees valid conformal calibration. Applications include trip planning and navigation where the conformal set is otherwise too large; recommendation is noted only as an analogous setting.
