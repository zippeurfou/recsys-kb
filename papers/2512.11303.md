## Summary

Large Language Model agents struggle with adapting to new tasks due to limited tool availability and inefficient experience reuse across different tasks. The paper introduces SMITH, a cognitive architecture designed to overcome these issues by integrating dynamic tool creation and cross-task experience sharing through a hierarchical memory system (procedural, semantic, episodic). SMITH creates tools via iterative code generation in sandboxes and shares experiences using semantic matching on episodic memories, significantly improving task performance, as demonstrated by its 81.8% Pass@1 accuracy on the GAIA benchmark, exceeding state-of-the-art alternatives.

## Technical note

SMITH (Shared Memory Integrated Tool Hub) is a unified cognitive architecture for LLM agents that integrates dynamic tool creation with cross-task experience sharing via a hierarchical memory (procedural, semantic, episodic). Tool creation is formalized as iterative code generation and debugging inside a controlled sandbox, with successful trajectories cached as reusable tools, while experience sharing retrieves top-k prior episodic trajectories by embedding-based semantic similarity to guide action sampling. A curriculum-learning strategy reranks tasks by agent-ensemble difficulty re-estimation rather than human labels. On the GAIA benchmark SMITH reaches 81.8% Pass@1, outperforming Alita (75.2%) and Memento (70.9%).
