## Summary

Existing route recommendation systems using a multi-stage pipeline face issues with offline training not matching online performance, rigid rule-based redundancy removal, and sub-optimal separation between ranking stages.

To address these, SCASRec proposes a unified generative model that integrates ranking and redundancy elimination into a single end-to-end process.

SCASRec uses a stepwise corrective reward for list-wise refinement and a learnable termination token, achieving state-of-the-art results both offline and online, and being successfully deployed in a real-world navigation app.

## Technical note

SCASRec addresses list-wise route recommendation, where two-stage fine-ranking/re-ranking pipelines suffer offline-online metric misalignment, rigid handcrafted redundancy rules, and fragmented optimization. It unifies ranking and redundancy elimination in a single encoder-decoder generative model, using a Stepwise Corrective Reward (based on list coverage rate gap) to weight supervised loss and a learnable End-of-Recommendation token for adaptive stopping. Trained end-to-end with supervised learning rather than RL, it reaches SOTA on two route datasets and, when deployed in a navigation app, cuts low-diversity ratio by 39.6% and redundant-route ratio by 50.7%.
