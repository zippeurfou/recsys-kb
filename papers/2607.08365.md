## Technical note

Industrial multi-stage cascade retrieval-ranking pipelines suffer objective inconsistency and error propagation, while end-to-end generative retrieval (e.g., TIGER, OneRec) has prohibitive auto-regressive decoding latency. DaV-Gen reformulates generative retrieval as a Draft-and-Verify mechanism inspired by speculative decoding: it builds a hybrid sparse-dense item embedding fusing RQ-VAE dense content vectors with contextualized Semantic IDs, and trains a single model with a composite loss (in-batch contrastive drafting loss + token-level generative loss + fusion-based pairwise ranking loss). At inference it drafts candidates via ANN/MIPS search then verifies them in one parallel forward pass using broadcasted prefix caching. On Amazon Beauty/Sports/Yelp it beats OneRec by +2.5-3.4% Recall@10/NDCG@10; on a 100M-item industrial video search it reaches Recall@50 77.4% vs 44.7% for a dense retriever and lifts NDCG@10 0.569->0.589 and MRR@10 0.895->0.942; online A/B gives +2.09% avg time spent and +0.47% conversion, at ~70ms latency (2.5x faster than the cascade).
