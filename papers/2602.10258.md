## Summary

Modern vector search systems face challenges with filtered nearest neighbor search, where existing algorithms often fail to generalize well across different query selectivities and filter types. To solve this, the paper introduces JAG (Joint Attribute Graphs), a novel graph-based algorithm that transforms filter constraints into continuous guidance for navigation. JAG constructs a graph optimizing both vector similarity and attribute proximity, preventing dead-ends and consistently outperforming prior methods across various filters and selectivities, as demonstrated by experiments.

## Technical note

JAG (Joint Attribute Graphs) is a filter-agnostic graph-based index for filtered nearest-neighbor search that stays robust across the full query-selectivity spectrum and diverse filter types (label, range, subset, boolean). It introduces attribute distance (build-time, semantic proximity of metadata) and filter distance (query-time proxy for how far an attribute is from satisfying a filter), turning binary filter constraints into continuous navigational gradients that prevent dead-ends. A capped attribute distance with multiple thresholds produces a hierarchy of navigational edges in a single index, and a lexicographic unified comparison rule (filter/attribute distance first, vector distance as tiebreak) guides GreedySearch, Insert, and a JointRobustPrune that buckets the degree budget per threshold. Across five datasets JAG dominates all filter-agnostic baselines, matches range-specialized iRangeGraph, and reaches up to 10x higher QPS at recall 0.9; Threshold-JAG is recommended over Weight-JAG for robustness.
