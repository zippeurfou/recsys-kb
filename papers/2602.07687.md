## Summary

This paper introduces a low-rank Koopman operator formulation for accelerating deformable subspace simulations by replacing sequential time integration with efficient matrix evaluations, achieving log-linear scaling in time steps. Using Dynamic Mode Decomposition, the method learns the temporal evolution and predicts future states, significantly speeding up simulations, particularly advantageous for optimization tasks like control and initial-state estimation where the final configuration is critical. To broaden Koopman-based reduced-order models in graphics, the authors also present a discretization-agnostic extension that learns shared dynamics across different shapes and mesh resolutions, enabling fast shape optimization that was previously impractical for DMD models.

## Technical note

This computer-graphics paper accelerates deformable subspace simulation by learning a low-rank Koopman operator, parameterized via Dynamic Mode Decomposition (DMD), that replaces sequential numerical time integration with matrix exponentiation of a small operator, giving log-linear scaling in the number of time steps. Unlike fluid DMD (velocity only) or spatial-only ROMs, it constructs a joint displacement-velocity state to capture elastic dynamics faithfully. A discretization-agnostic neural extension learns shared dynamics across shapes and mesh resolutions (2.5k-500k vertices), enabling fast shape optimization impractical for numerical DMD. The efficient long-horizon time stepping is especially useful for inverse/optimization tasks like control-force estimation and initial-state estimation where the objective depends on the final configuration. This paper is off-domain for recommender systems.
