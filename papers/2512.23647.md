## Summary

Current information-seeking agents are limited in their ability to use web browsers effectively. This restricts them to API calls and simple page fetching, missing out on richer deep-web information. The paper introduces NestBrowse, a framework that simplifies browser interaction through nested structures, allowing agents to perform complex web tasks more efficiently and effectively.

## Technical note

NestBrowse enables information-seeking LLM agents to move beyond API-snippet and static URL fetching to real browser interaction for deep-web content. It defines a minimal but complete browser toolkit (search, visit, click, fill) and a Nested Browser-Use Framework that decouples an outer tool-integrated reasoning loop from an inner intra-page exploration loop, controlling redundant page content under context limits. A multi-task imitation-learning formulation jointly trains outer reasoning and inner evidence extraction. Trained models NestBrowse-4B and NestBrowse-30B-A3B perform strongly across four challenging English/Chinese deep IS benchmarks, showing small agents can acquire effective browser-use skills.
