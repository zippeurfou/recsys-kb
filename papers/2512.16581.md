## Technical note

Abacus is a self-supervised, counting-aligned pretraining pretext task for sequential user modeling in display advertising, targeting sparse positive events and irregular timing that cause severe class imbalance. Instead of hand-crafted counter features, it trains a sequential encoder to predict the empirical event-type distribution within a user timeline, and mixes this with masked modeling and Barlow Twins in a hybrid objective. On a large private dataset it improves downstream AUC by up to +6.1% over a scratch-trained GRU encoder (smaller gains on public Taobao), with a warm-start effect and faster convergence.
