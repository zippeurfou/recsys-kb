## Summary

Multi-turn agent interactions are challenging due to evolving states and unclear intents. To address this, the paper introduces SIT-Graph, which builds upon tool graphs by integrating state summaries from past interactions, mimicking human episodic and procedural memory. Experiments demonstrate that SIT-Graph significantly improves tool selection and experience transfer across various benchmarks compared to existing methods.

## Technical note

H-EPM (SIT-Graph) addresses multi-turn tool-use agents whose decision context shifts as intents unfold, where full-trajectory reuse is too specific and tool-level reuse ignores context. It induces a tool graph from accumulated trajectories where edges capture recurring tool-to-tool procedural dependencies, and augments each edge with compact episodic state summaries so the agent can adaptively balance episodic recall and procedural execution at inference. It also adds a memory-guided RL paradigm that biases exploration toward historically successful tool transitions, yielding up to 50%+ inference gains and up to 40%+ improvement on out-of-distribution tasks.
