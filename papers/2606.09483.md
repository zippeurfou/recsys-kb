## Summary

Current LLM agent memory systems are limited because they merge various cognitive functions and struggle with updating beliefs to personalize the experience over time, viewing memory simply as recall.

To address this, researchers propose DCPM (Dual-Process Memory Model), which organizes an agent's memory hierarchically from facts upwards through belief trajectories, identity, schemas, and patterns, inspired by dual-process theory.

DCPM employs two systems: a fast daytime process for logging updates and a slow nighttime process that builds knowledge structures and detects cross-domain links. Experiments show DCPM significantly improves benchmarks rewarding long-term inference while slightly harming simpler recall tasks.

## Technical note

DCPM reorganizes long-term LLM-agent memory along a cognitive capability hierarchy ascending from raw inputs and atomic facts, through diachronic belief trajectories and user identity, to within-domain schemas, latent intentions, and cross-domain core schemas, arguing current systems collapse belief revision, causal coupling, and cross-domain abstraction into one recall-tuned surface. It instantiates dual-process theory with two coupled processes over a shared store: a synchronous daytime writer (System 1) that reconciles each turn (ADD/SUPERSEDE/UPDATE) and records belief revisions as doubly linked Supersedes/SupersededBy chains over a flat vector store, and an asynchronous nighttime engine (System 2) that clusters fresh facts via two-stage DBSCAN, induces schemas and intentions with a tool-using agent, and sweeps for cross-domain collisions (high behavioral but low semantic cosine similarity) to induce higher-level core schemas. The read path traverses vector store, pointers, and graph deterministically without LLM calls. On LongMemEval, PersonaMem, and PersonaMem-v2, System 2 contributes most on implicit cross-session inference (up to +5.20 on PersonaMem-v2) and least on span recall.
