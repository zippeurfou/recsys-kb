## Summary

Modern recommender systems often use a Generator-Evaluator framework for re-ranking, where evaluators score entire candidate item lists by simply adding up individual item scores. This approach is flawed for sequential platforms (like short-video apps), as it fails to account for users' continuous consumption habits and the dynamic, session-level context that influences their engagement. To address this, the paper introduces SWIM (Step-Wise Integrated Measure), a novel list evaluator that models user behavior as a survival process, predicting how long users will stay engaged within the session given the list so far, thereby capturing crucial session dynamics and improving recommendation engagement.

## Technical note

Kuaishou SWIM is a list-level evaluator for generator-evaluator re-ranking on a sequential short-video feed, addressing evaluators that sum point-wise item values and ignore session continuity (users keep scrolling across request boundaries, so a list's value depends on whether the user reaches it and how far they go). It defines the session-wise contribution of a request list as sum_t (prod_{i<t} q_i) r_t: a boundary survival term q_0 = P(request reached | session prefix), step-wise in-list continuation probabilities q_t, and reached-position conditional rewards r_t (binary heads for view/click/like/follow/share; play time via B ordered buckets with expected-value reconstruction). All quantities come from a single causally-masked Transformer pass over [prefix token; T items], trained only with masked BCE on continuation labels (valid at reached positions, y=0 for a sampled terminal request) plus reward losses on reached positions; at serving q_0 is fixed to 1. Theorem 5.1 shows any request-only evaluator has irreducible squared error E[(V_req)^2 Var(q_0 | c)] against the session-wise target, and Theorem 5.2 shows CAVE's Weibull-restricted exit prior cannot represent arbitrary finite-horizon survival curves. Offline on RecFlow (120 candidates -> 6) and KuaiRand (6-to-6 reorder), with 20 generator lists from DNN/Seq2Slate/PRM/NAR4Rec, SWIM reaches NDCG@6 0.2031 / AUC 0.7185 on RecFlow vs CAVE 0.1957 / 0.7083 (ablations: w/o survival 0.1952, w/o prefix 0.1975, w/o boundary 0.2014); a 7-day 5% A/B replacing CAVE with SWIM on Kuaishou main feed (>400M DAU) gives +0.351% app stay time [0.27%, 0.42%] and +0.048% LT7 [0.01%, 0.09%]. No off-policy or counterfactual evaluation of evaluator-preferred lists is reported; the authors name that as future work.
