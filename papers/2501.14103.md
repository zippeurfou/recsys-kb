## Technical note

Personalized Interpolation (Meta) enables ads conversion (CVR) estimation for arbitrary advertiser-specific optimization windows without training a model per window. It frames flexible-optimization-window (FOW) estimation as approximating the conversion-time CDF and interpolates at the event level between a short-window (1-day) and long-window (7-day) prediction from an existing multi-task multi-label (MTML) model, using a single interpolation factor alpha parameterized by linear, rational, or exponential functions exploiting the CDF's monotone-concave shape. An inference-time interpolation layer adds no training cost. On 40 days of real ad impression data, all three variants match the six-model Dedicated Models baseline in normalized-entropy (NE) and approach the No-Delay Upper Bound, beating a 7-TaskHead model by >0.2% NE while requiring only one lightweight model; the rational function gives the best calibration.
