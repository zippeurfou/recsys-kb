## Summary

This paper introduces "Sample Is Feature" (SIF), a method designed to improve recommender models by addressing two key limitations: inefficient use of sample history and difficulty handling different feature types within Transformer models.

SIF directly encodes entire raw historical samples into sequence tokens via a "Sample Tokenizer" using hierarchical quantization, preserving more sample context, and then uses a "SIF-Mixer" to deeply interact these sample representations, overcoming feature heterogeneity.

Extensive experiments and industrial deployment (Meituan) show SIF effectively enhances recommendation performance by fully utilizing sample-level information and representational capacity.

## Technical note

SIF (Sample Is Feature) elevates each historical sequence token from item-level to sample-level by encoding the entire raw historical sample (user, item, context, and pre-computed cross features) into a sequence token, exploiting the full request record already stored in training logs. Its Sample Tokenizer compresses each raw sample offline into discrete codebook indices via hierarchical group-adaptive quantization (group-wise RVQ over four semantic groups) jointly trained with the ranking objective, so per-token serving cost matches a standard item embedding lookup. The resulting homogeneous Token Samples eliminate the sequential/non-sequential feature heterogeneity that constrains unified-Transformer models, and a SIF-Mixer performs token-level and sample-level mixing to capture intra- and inter-sample interactions. On a large-scale industrial dataset it gains up to +0.88% GAUC offline and +2.03% CTR / +1.21% CVR online, deployed on Meituan's food delivery platform.
