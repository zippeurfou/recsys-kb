## Summary

Towards On-Policy Context Extension":

Existing long-context LLM training methods struggle due to limited data and suffer from an "off-policy gap" because they rely on a fixed model for data selection, causing training distribution misalignment. PolicyLong solves this by iteratively re-screening data using the *current* evolving model during training, ensuring the training data aligns with the model's growing capabilities and creating a self-updating curriculum. This on-policy data selection consistently improves long-context performance (+2.54 at 128K on RULER, for example) compared to off-policy methods, showing significant gains increase with longer contexts.

## Technical note

PolicyLong extends LLM context windows by replacing single-pass offline long-context data synthesis with an on-policy closed loop, motivated by an 'off-policy gap' where data screened by a fixed base model drifts out of alignment as the model improves (median entropy of selected positions falls from 6.63 to 5.34 across stages). Building on EntropyLong's information-theoretic verification (prepending a candidate context should reduce predictive entropy at high-uncertainty target positions), PolicyLong partitions training into T stages and re-executes entropy computation, retrieval, and verification with the current model M_t, producing an emergent self-curriculum. Both positive contexts and semantically similar hard negatives are drawn from the current model's entropy landscape, co-evolving what it exploits and resists. On RULER, HELMET, and LongBench-v2 with Qwen2.5-3B it beats EntropyLong and NExtLong, with gains growing at longer contexts (+2.54 at 128K on RULER).
