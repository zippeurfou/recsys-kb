## Technical note

PerFusion is a personalized group-level preference alignment framework for text-to-image diffusion models, deployed at Alibaba to enable 'sell it before you make it' AI-generated fashion items (AIGI). It first builds PerFusionRM, a CLIP-based reward model with a feature-crossing personalized plug-in injected into each Transformer layer, then trains PerFusion with a personalized adaptive network and a group-level preference optimization objective that models comparative choices over multiple candidate images rather than pairwise. Online, AI-generated items achieve over 13% relative improvement in both click-through rate and conversion rate and a 7.9% decrease in return rate versus human-designed items.
