## Summary

1.  The paper introduces DeepMTL2R, an open-source deep learning framework designed for **Multi-task Learning to Rank (MTL2R)**, which optimizes multiple ranking objectives simultaneously.
2.  DeepMTL2R integrates diverse relevance signals using transformer architectures and self-attention mechanisms, supporting 21 state-of-the-art MTL algorithms and facilitating multi-objective optimization to find Pareto-optimal models.
3.  The framework offers a scalable solution for complex ranking tasks and enables comparisons across different MTL strategies, with its effectiveness demonstrated on a public dataset.

## Technical note

DeepMTL2R is an open-source transformer-based framework for Multi-task Learning to Rank (MTL2R), optimizing multiple, potentially conflicting relevance criteria (clicks, streams, sales, dwell time, ratings) jointly. It uses self-attention to model list-level context and long-range item/label dependencies, learning a unified scoring function with task-specific listwise losses. The framework integrates 21 multi-task/multi-objective optimization algorithms (e.g. Linear Scalarization, MGDA) to identify Pareto-optimal ranking models and characterize trade-offs across objectives. It is positioned as a benchmarking toolkit with modular data-processing, training, evaluation, and visualization components. Effectiveness and the resulting Pareto front are demonstrated on the public WEB30K (Yahoo/MSLR-style LETOR) dataset.
