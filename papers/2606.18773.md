## Summary

This paper explores improving differential privacy in regression tasks where data contains public features alongside sensitive targets or features. It introduces Cond-DP, which modifies standard DP-SGD by incorporating a matrix derived from the public features before applying noise during gradient computation. By conditioning on these feature structures and specifically leveraging their rapidly decaying spectra, Cond-DP achieves faster convergence rates for private linear regression compared to traditional methods without adding extra privacy costs.

## Technical note

This paper studies differentially private regression where samples include public non-sensitive features alongside sensitive labels/features (label DP and semi-sensitive settings), a case common in recommendation and advertising but underexplored versus classification. It proposes Cond-DP, a conditioned variant of DP-SGD that uses a data-driven conditioning matrix constructed from the public feature matrix to reshape the optimization landscape, motivated by the observation that public features often exhibit rapidly decaying spectra where isotropic DP-SGD noise gives low signal-to-noise ratio along low-spectrum directions. It provides convergence guarantees for convex, strongly convex, and non-convex objectives, recovering standard DP-SGD when the conditioning matrix is the identity, and proves provably faster convergence for private linear regression with no additional privacy cost. Empirically Cond-DP outperforms state-of-the-art baselines across datasets and architectures under label DP.
