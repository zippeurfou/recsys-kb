## Summary

(Abstract fallback)

Reranking models solve the final recommendation lists that best fulfill users' demands. While existing solutions focus on finding parametric models that approximate optimal policies, recent approaches find that it is better to generate multiple lists to compete for a ``pass'' ticket from an evaluator, where the evaluator serves as the supervisor who accurately estimates the performance of the candidate lists. In this work, we show that we can achieve a more efficient and effective list proposal ...

## Technical note

This work improves list-level reranking by extending the generator-evaluator (G-E) framework to a multi-generator-evaluator (MG-E) framework, where multiple generators collaboratively propose valuable, diverse candidate lists that an evaluator scores — avoiding both the exhaustive permutation search and the local optima of a single generator. It introduces a List Comprehensiveness (LC) metric quantifying how different generated lists are, showing a generator's effectiveness depends on how much it complements others' views, and designs an automatic complementary-generator-finding framework that learns a policy aligning user preferences while maximizing list comprehensiveness. Experiments on two public datasets and online A/B tests show the framework further improves multi-generator reranking performance.
