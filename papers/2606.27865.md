## Technical note

GLAN (Generative Landing-page Adaptive Navigator) tackles Personalized Landing Page Modeling - choosing which functional page to show on app entry - which Kuaishou's prior KLAN handled with Conservative Q-Learning. GLAN argues CQL fails due to the Markov assumption (real user behavior is non-Markovian) and TD-bootstrapping errors under delayed rewards over long horizons, and instead uses a Decision Transformer over full trajectories conditioned on Returns-to-Go. It adds an L-RTG module capturing inter-day consumption dynamics for global per-day guidance (solving the RTG initialization dilemma) and an HRM module decomposing session-level feedback into fine-grained signals for precise local supervision of each page assignment. Online experiments on Kuaishou show +0.158% DAU and +0.108% user Lifetime.
