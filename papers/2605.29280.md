## Technical note

LoopFM addresses the diminishing transfer ratio of scalar knowledge distillation from trillion-parameter foundation models (FMs) to compact vertical models (VMs) by materializing FM intermediate embeddings as structured VM input features via extraction, compression (autoencoder + INT4), and structuring into user-keyed temporal sequences, using only historical embeddings so no real-time FM inference is needed. Theoretically its information gain decomposes into temporal, cross-feature, and compression-loss terms with a transfer-ratio lower bound growing with the FM-VM feature gap. On public benchmarks it gains 6%+ AUC on TaobaoAd, and in production it roughly doubles the KD transfer ratio, delivering +0.5%, +1.03%, and +1.22% conversion improvements across launches.
