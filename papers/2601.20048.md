## Technical note

Insight Agents (IA) is an LLM-backed conversational multi-agent data-insight system deployed for Amazon sellers in the US to answer descriptive analytics and diagnostic analysis questions about their business. Built on a plan-and-execute paradigm with a hierarchical manager-worker structure, the manager agent uses a lightweight encoder-decoder Out-of-Domain detector plus a BERT-based routing classifier (run in parallel for low latency), and two worker agents (data presenter and insight generator) built on RAG with an API-based tabular data model that decomposes queries into granular components and injects domain knowledge dynamically. IA achieves 90% accuracy by human evaluation with P90 latency below 15s.
