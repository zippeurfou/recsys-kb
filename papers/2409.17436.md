## Summary

This paper addresses the high costs associated with A/B testing new recommender system policies, especially during user onboarding when experiments are limited to one-time use. It introduces a simulation-based evaluation method as an alternative, specifically applied to assess preference elicitation algorithms for YouTube Music users. By developing robust models of user behavior that mirror real-world outcomes (counterfactual prediction), this approach allows reliable estimation of a policy's performance before live deployment, reducing reliance on costly experiments.

## Technical note

Evaluating recommender policies via live A/B tests is the gold standard but costly, especially for new-user onboarding which happens only once. The authors build a user-simulation methodology with counterfactually robust user-behavior models coupled to production infrastructure via a simulation service. They apply it to evaluate preference-elicitation algorithms that adaptively ask YouTube Music new users about preferred artists during onboarding. The simulator reliably predicts live-metric performance, letting them reduce reliance on expensive live experiments.
