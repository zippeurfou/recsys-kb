## Summary

1.  The paper addresses the high token overhead and computational costs of multi-modal multi-agent retrieval-augmented generation (mRAG) systems.
2.  To improve efficiency, the authors introduce M$^3$Prune, a hierarchical communication graph pruning framework that selectively removes redundant inter- and intra-modality communication edges.
3.  Experiments show that M$^3$Prune significantly reduces token consumption while consistently outperforming both single-agent and robust multi-agent mRAG systems across various benchmarks.

## Technical note

M3Prune reduces the token overhead of multi-agent multimodal RAG by pruning redundant edges in the agent communication graph. It first performs intra-modal graph sparsification within text and visual modalities via spatio-temporal message passing, scoring edges by response quality and topology. It then builds an inter-modal communication topology from the sparse intra-modal graphs with a modality-alignment loss, and progressively prunes invalid cross-modal edges. On Vidoseek, MultimodalQA, and ScienceQA it improves accuracy by 9.4% while cutting token consumption by 15.7% versus strong multi-agent mRAG baselines.
