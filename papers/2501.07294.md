## Technical note

Building recommenders typically requires dataset-specific feature engineering, hyperparameter tuning, and configuration, hurting reusability and reproducibility. This position paper proposes Dataset-Agnostic Recommender Systems (DAReS) centered on a Dataset Description Language (DsDL), an EBNF/YAML-specified metadata format describing feature types, IDs, timestamps, and labels so a single codebase can autonomously drive feature selection, missing-value imputation, noise removal, model selection, and hyperparameter optimization across datasets without fine-tuning. It defines level-1 automation (dataset-agnostic but task-specific, e.g. CTR/rating/Top-N) versus level-2 (task-agnostic and dataset-agnostic), and contrasts DAReS with AutoML which still needs per-dataset configuration. No empirical benchmarks are reported; the paper acknowledges trade-offs of computational overhead and reduced dataset-specific optimization.
