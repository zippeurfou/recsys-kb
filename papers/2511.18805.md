## Summary

Ranking models face significant challenges scaling due to high-cardinality features causing sparse representations and computational bottlenecks from too many tokens.

To address these issues, the authors introduce STORE, a token-based framework incorporating three key innovations: Semantic Tokenization handles feature sparsity and heterogeneity, Orthogonal Rotation enhances feature interactions, and Efficient Attention filters out less important tokens.

STORE consistently improves both prediction accuracy (e.g., +2.71% CTR online) and training efficiency (1.84x throughput) across various experiments, demonstrating effective scalability for ranking models.

## Technical note

STORE is a token-based ranking framework addressing representation and computational bottlenecks that prevent scaling of CTR ranking models. Semantic Tokenization maps high-cardinality sparse features (e.g., item IDs) into compact semantic IDs via an orthogonal parallel multi-expert quantization network; Orthogonal Rotation Transformation rotates subspaces of low-cardinality static features for richer interactions; and Efficient Attention (MoBA-style block routing) prunes low-contributing tokens to cut quadratic cost. It combats the One-Epoch and Interaction-Collapse problems, improving AUC by ~1.195% and training throughput by 1.84x offline, with +2.71% CTR in a 15-day e-commerce online A/B test.
