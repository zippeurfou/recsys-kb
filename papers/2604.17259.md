User behavior in the real world is diverse, cross-domain, and spans long time horizons. Existing user modeling benchmarks however remain narrow, focusing mainly on short sessions and next-item prediction within a single domain. Such limitations hinder progress toward robust and generalizable user models. We present HORIZON, a new benchmark that reformulates user modeling along three axes i.e. dataset, task, and evaluation. ## Technical note

HORIZON is an open-source benchmark for cross-domain, long-horizon user modeling, built by consolidating Amazon Reviews 2023 across all categories into 54.5M users and 34.5M items with timestamps. It replaces leave-one-out/ratio splits with a temporally grounded protocol disentangling seen vs. unseen users and temporally close vs. distant windows. Benchmarking sequential architectures and LLM baselines shows BERT4Rec is strong in-distribution but degrades for out-of-distribution users while staying competitive in long-range extrapolation (Recall@50/@100), and LLMs do not consistently outperform specialized sequential models.
