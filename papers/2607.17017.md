## Summary

WHALE is a novel recommendation system architecture designed to address scalability issues by combining two powerful components: Wukong for modeling complex non-sequence features (like user/item interactions) and HSTU for handling long user behavior sequences. Its core innovation involves integrating these backbones layer-by-layer, allowing the high-order feature representations from Wukong to dynamically query relevant fine-grained sequence information from HSTU through attention-based fusion. This approach significantly improves recommendation performance on large datasets while being deployed using efficient Triton kernels suitable for industrial use.

## Technical note

WHALE unifies Wukong-style non-sequence feature-interaction modeling and HSTU-style long user-behavior sequence modeling in a single scalable industrial ranker. Each recursive WHALE layer runs a Wukong module (stacked FM interaction), an HSTU module, and an attention-based fusion where Wukong interaction representations query HSTU behavior keys/values, enabling progressive cross-branch exchange; deployment uses custom Triton kernels (shared KV, shape-aware asymmetric backward), a shared-gate SwiGLU FFN, BF16 mixed precision, and torch.compile/AOTInductor. It beats Wukong-only and HSTU-only baselines on normalized entropy (NE) and scales with sequence length (to 15k), depth (to 8 layers), and width (to 512). A 14-day online A/B test lifts the primary metric +0.113% (Metric1 +0.824%, Metric2 +1.820%) at a modest -5% inference QPS, with training/inference throughput improved +30%/+22% by the optimizations.
