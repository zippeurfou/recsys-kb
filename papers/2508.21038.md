## Summary

Vector embeddings have been tasked with an ever-increasing set of retrieval tasks over the years, with a nascent rise in using them for reasoning, instruction-following, coding, and more. These new benchmarks push embeddings to work for any query and any notion of relevance that could be given. ## Technical note

Connects learning theory to neural IR to show a fundamental limit of single-vector embeddings: the number of top-k document subsets realizable by any query is bounded by the embedding dimension d (binom(n,k) <= (1+1/gamma)^d). Even with free embeddings optimized directly on the test set, there is a critical corpus size per dimension beyond which not all combinations can be represented, and the relation fits a polynomial. They build LIMIT, a deliberately simple natural-language dataset, and show state-of-the-art MTEB embedders fail on it. They argue for cross-encoders, multi-vector, or more expressive similarity when handling arbitrary instruction queries.
