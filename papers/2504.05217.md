## Technical note

LARM (LLM-Alignment Live-Streaming Recommendation) uses multi-modal LLMs to handle the temporal dynamics of live-streaming, where the same stream gives different experiences depending on when a user watches, and where naively injecting LLM-generated embeddings yielded only marginal gains due to a mismatch between the LLM's vision-language space and the RecSys's user-item interaction space. LARM fine-tunes an open-source LLM on live-streaming data for context-aware embeddings, aligns them with RecSys ID embeddings by projecting into a unified space via a gated mechanism, and transforms aligned embeddings into learnable semantic code features enriching retrieval and ranking. Experiments show LARM significantly outperforms baselines, with ablations validating each component in industrial settings.
