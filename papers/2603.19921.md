## Summary

Modern automatic machine translation (MT) evaluation has advanced significantly, moving beyond simple scores to detect specific errors, but no standard method exists to reliably evaluate these error detection systems themselves. This paper investigates different ways to measure error detection at the "span" level (individual words or phrases) and finds that small changes in calculation can lead to vastly different results and rankings. To address this, the authors propose a robust method called "Match with Partial Overlap and Partial Credit" (MPP) using micro-averaging, and demonstrate its effectiveness by using it to assess the current state of MT error detection.

## Technical note

This work studies span-level meta-evaluation for machine translation error detection, i.e. how to reliably measure auto-evaluators that locate translation errors as character spans rather than emit scalar scores. It formulates error detection as structured prediction and computes precision/recall/F-score by selecting the one-to-one matching between hypothesis and ground-truth spans that maximizes F-score, then defines a family of variants: exact match (em), match with partial overlap (mp, requiring at least tau overlapping characters), and match with partial overlap and partial credit (mpp). The authors show that seemingly similar implementations conceal arbitrary methodological choices that produce drastically different rankings, and that some widely used techniques are unsuitable for MT error detection. They recommend mpp paired with micro-averaging across samples as a robust strategy, release code (amazon-science/span-mt-metaeval), and use it to reassess the state of the art in MT error detection.
