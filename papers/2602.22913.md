## Technical note

SIGMA is an instruction-driven generative multi-task recommender deployed at AliExpress on a Qwen3-0.6B/4B backbone. It first grounds items in a unified latent space via multi-view alignment (semantic, visual, knowledge, collaborative) trained with InfoNCE contrastive loss plus a KL-divergence knowledge-distillation from the online ranking model's ID embeddings, then uses hybrid item tokenization combining RQ-VAE SID prefixes with per-item ID tokens. A large multi-task SFT dataset (seven task types) enables instruction-following, and a three-step generation (beam-search SID prefixes -> ANN retrieval -> Adaptive Probabilistic Fusion that modulates precision/diversity by beam-score std) yields the final list. SIGMA outperforms GR(SID)/GR(ID) baselines and, in a 2-week AliExpress A/B test, delivered +2.80% Order Volume, +3.84% Conversion Rate, +7.84% GMV.
