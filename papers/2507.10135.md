## Summary

This paper addresses a gap in understanding how users interact with carousel recommenders compared to traditional single-list interfaces. It provides the first extensive eye-tracking analysis of browsing behavior under free-browsing conditions by investigating where users start viewing items, their transitions between them (within and across carousels), and the influence of genre preference on these transitions.

The study's key findings offer empirical insights into user navigation patterns unique to carousels, particularly highlighting specific behaviors observed through eye tracking. Based on this analysis, it suggests reordering recommended item positions within a carousel after swiping as crucial advice for system designers aiming to align recommendations with actual user exploration flows.

Ultimately, the research contributes not only practical design suggestions but also encourages the development of new user models and evaluation metrics tailored specifically for the complexities of carousel interfaces.

## Technical note

This work provides the first extensive eye-tracking analysis of free-browsing behavior on carousel (multi-list) recommender interfaces, using a 87-user movie-selection dataset. Analyzing fixation transitions across carousel rows and item columns, it finds users start top-left (F-pattern), browse rows top-down with a strong top-2-row bias, rarely skip rows, and after swiping browse right-to-left starting from the previously fixated position. Genre preference significantly shifts transitions toward preferred/top/higher-rated carousels despite randomized ordering. The authors translate these findings into design takeaways, notably reordering ranked items right-to-left within swiped sets and accounting for position bias specific to carousels.
