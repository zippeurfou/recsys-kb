## Summary

This paper addresses the difficulty of adapting existing visualization code examples for new datasets, a process currently tedious due to required manual understanding of both code structure and necessary data transformations. It proposes leveraging Large Language Models (LLMs) for automatic retargeting via two methods: direct code generation from prompts or guiding code construction with structural information. However, evaluation on diverse datasets reveals that both approaches face significant issues if the input data itself hasn't been properly transformed to fit the example's requirements and specifications.

## Technical note

This paper studies LLM-assisted visualization retargeting: adapting an existing chart's code implementation to a new dataset, which normally requires understanding both the example code and needed data transformations. It compares two approaches, directly prompting the LLM to generate/adapt code as text versus a constrained program-synthesis pipeline where the LLM supplies structural metadata (visual encodings, scales, transforms) to guide construction, evaluating across datasets and charts of varying complexity with failures categorized by type and severity. Surprisingly, the structured pipeline underperforms the baseline (likely due to error propagation), and both fail to retarget most charts unless the input data has been adequately transformed and filtered beforehand; the authors offer design recommendations for future systems.
