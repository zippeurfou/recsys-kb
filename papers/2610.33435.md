## Summary

PinGER is a generative retrieval system for Pinterest that improves upon traditional methods by using a single token (Semantic ID) per item in the input history, allowing significantly more items to be considered within a fixed context window. The core technical innovations include an attention mask preventing redundant token processing, methods for controlling the generative decoding, and an optimized serving stack for efficient retrieval. These changes result in tangible benefits, including a 3.60% lift in relevant Pins saved and reduced nearest-neighbor search costs, while also improving the surface's latency.

## Technical note

SID-based generative retrievers such as TIGER spend L tokens per history item, so a fixed context holds L times fewer items than one dense token per item, while dense-embedding GR (PinRec) still needs an ANN index and beam search collapses onto a few prefixes (11.9 distinct level-1 codes among 100 beams). PinGER interleaves each item's L=5 RQ-VAE SID tokens (from PinCLIP, distilling OmniSage) with one dense token under an asymmetric mask where dense tokens attend only to earlier dense tokens and SID tokens read dense history plus their own shallower codes, so training supervises every SID position with custom sparsity-aware kernels (+94% throughput over TIGER) while serving drops past SID tokens and reads one token per item, computing the identical function. Generation is steered by goal conditioning on action, surface and time, a hierarchical prefix-diversity penalty in beam selection, and level-wise DPO post-training on preference pairs taken from the production ranker's logged utilities anchored by the next-token loss; serving uses cascade decode (history read once per request, 10.9-32x faster than paged attention, 12.6x less KV memory), trie-constrained decoding and a host-local SID-to-item index. Offline PinGER matches TIGER Recall@100 with 6x fewer serving tokens and beats it by 9.5% at equal tokens (3.9x PinRec); on Related Pins it lifts saves +0.62%, grid clicks +0.94% and saves of Pins under 28 days +3.60%, with end-to-end latency down 0.7% and the ANN search removed.
