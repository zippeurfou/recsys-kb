## Summary

This paper introduces NEO, a unified language model designed to handle multiple tasks like recommendation, search, and reasoning across large catalogs without relying on external tools. NEO generates responses by interleaving natural language with typed item identifiers (SIDs), representing catalog items this way and training the model to understand and use them effectively. Evaluated extensively on a massive catalog, NEO consistently outperformed specialized baselines and demonstrated cross-task capabilities, offering a promising approach to consolidate large-scale discovery functionalities into a single generative model.

## Technical note

NEO adapts a pre-trained decoder-only LLM into a single tool-free, catalog-grounded generator that interleaves natural language with typed Semantic ID item references across recommendation, search, and item-grounded generation over a >10M-item heterogeneous catalog. Items are discretized via residual quantization into SID tokens (with per-type quantizers for heterogeneous entities) added to a unified vocabulary and emitted only within [SID] spans so constrained decoding guarantees catalog-valid items without restricting free text; natural-language prompts control task, entity type, and output format (this is termed language-steerability). Treating SIDs as a distinct modality inspired by multimodal LLMs, NEO uses a staged recipe: Stage 1 SID construction, Stage 2 bidirectional SID<->text alignment (SID->text, text->SID, SID->type) with frozen backbone, and Stage 3 multi-task instruction tuning across recommendation, retrieval, recs-planation, and user understanding. Offline it outperforms strong task-specific baselines and shows positive cross-task transfer, and a capability table positions it against generative SID retrieval, tool-based LLMs, PLUM, and TalkPlay.
