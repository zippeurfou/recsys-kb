## Summary

This paper introduces Chameleon, an accelerator designed for on-device learning at the edge using Temporal Convolutional Networks (TCNs). Its main goal is to enable efficient few-shot and continual learning directly from sequential data while maintaining low power consumption.

Chameleon achieves this by employing a unique dual-mode compute array that avoids matrix multiplications entirely, significantly boosting peak performance while only adding minimal area overhead for supporting learning. This allows it to handle complex tasks like 16-kHz raw audio inference efficiently with very low energy use.

The fabricated accelerator sets new accuracy records for end-to-end on-chip few-shot and continual learning using real-world sequential data, demonstrating its effectiveness in challenging edge scenarios despite the power constraints typically associated with such applications.

## Technical note

Chameleon is a 40-nm CMOS accelerator for end-to-end on-chip few-shot learning (FSL) and continual learning (CL) from sequential data at the extreme edge. It reformulates prototypical networks as an equivalent fully-connected layer so gradient-free learning reuses the inference datapath at only 0.5% area overhead, uses temporal convolutional networks (TCNs) with a greedy dilation-aware execution and residual-aware register-file dataflow to expand the receptive field 160x while cutting activation memory (up to 76x vs prior TCN accelerators), and a dual-mode MatMul-free PE array with 4-bit signed log2 weights (bit-shifts instead of multipliers) plus power gating. It sets new on-chip records on Omniglot (96.8% 5-way 1-shot FSL; 82.2% final accuracy for 250-class CL with 10 shots) and sustains 93.3% accuracy on 12-class Google Speech Commands at 3.1 uW for real-time keyword spotting, being the first to demonstrate end-to-end on-chip FSL/CL on sequential data and inference on 16-kHz raw audio.
