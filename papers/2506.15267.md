## Technical note

Next-User Retrieval is ByteDance's generative next-user modeling framework for item cold-start recommendation on Douyin, inspired by lookalike algorithms. It defines sequential users with the same sparse positive interactions (likes, comments) as lookalike users and uses a transformer with causal attention to model unidirectional relationships and generate the next user most likely to interact with a cold item, with item features injected as prefix prompt embeddings and a learnable [CLS] token bridging the feature-domain gap. Trained with contrastive, cross-entropy, and auxiliary losses to integrate into an HNSW-based retrieval system, it achieves +0.0142% daily active users and +0.1144% publications in online A/B tests on Douyin.
