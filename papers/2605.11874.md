## Summary

Current recommender systems using LLM agents primarily rely on single-dimensional rewards, ignoring important intermediate capabilities like instruction following and complex intent understanding. To address this gap, the paper introduces RecRM-Bench, the largest benchmark for agentic recommenders, evaluating models across four dimensions including instruction following, relevance, and user behavior. RecRM-Bench provides the data and a framework for developing more sophisticated multi-dimensional reward models to improve agent performance.

## Technical note

RecRM-Bench is a large benchmark (over 1.1 million structured entries built from real Meituan interaction logs) for training and evaluating reward models in agentic recommender systems, motivated by the observation that current RL for LLM recommendation agents relies on single-dimensional outcome rewards tied to final clicks/ratings. It covers four dimensions: instruction following, factual consistency, query-item relevance, and fine-grained user behavior prediction (including item ranking), addressing reward sparsity and credit-assignment problems in long multi-step agent decision processes. The paper also proposes a standardized training paradigm and prompt framework for constructing multi-dimensional reward models and an integrative hybrid reward function that combines holistic feedback to reduce training variance. Compared to prior benchmarks (JDSearch, Qilin, RecBench+, KuaiSearch, RecIFBench), it is the only one covering all four evaluation dimensions.
