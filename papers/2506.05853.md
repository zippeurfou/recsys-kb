## Technical note

LLM-PM is a training-free framework that steers a cost-based SQL optimizer by embedding a query's default execution plan with a frozen LLM (OpenAI text-embedding-3-large) and transferring optimizer hintsets from its nearest neighbors. It votes among the N=16 nearest default-plan neighbors to pick a candidate hintset (over 7 binary operator knobs), then applies a two-K-neighborhood consistency check (K=16) comparing average runtimes before adopting it, with an adaptive timeout-pruned search over the 128 hintsets as fallback. On JOB-CEB (IMDB, openGauss) it delivers a 21.1% aggregate latency reduction (max achievable 62.5%); an ablation shows Levenshtein string matching instead slows the workload by 64.4% with 87 timeouts, confirming the learned embeddings capture real plan structure.
