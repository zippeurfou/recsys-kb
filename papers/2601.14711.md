## Technical note

DARA is a dual-phase LLM framework for few-shot budget allocation in online advertising under the AI-Generated Bidding (AIGB) paradigm, where advertisers have personalized objectives but limited historical data. It decomposes decision-making into a Few-shot Reasoner that generates initial budget plans via in-context prompting and a Fine-grained Optimizer that refines them through feedback-driven reasoning, combining LLMs' in-context generalization with the numerical precision RL provides. It introduces GRPO-Adaptive, which periodically updates the reference policy during training for more flexible improvement, and uses a dual real-world + polynomial-simulation environment for robustness. DARA consistently outperforms baselines in cumulative advertiser value under budget constraints.
