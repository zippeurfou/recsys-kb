## Summary

This paper introduces "Orthogonal Alignment" as a new phenomenon observed in cross-attention layers within multi-modal recommendation models, contrasting with the previously held view that they perform "residual alignment." It finds that when user behavior sequences from different domains are orthogonal at input to the cross-attention layer, model performance significantly improves across many experiments. The authors argue this natural occurrence enhances scaling laws, allowing baselines using cross-attention to achieve better accuracy per parameter compared to other models of similar size.

## Technical note

Cross-domain sequential recommendation (CDSR) widely uses cross-attention to fuse heterogeneous behavior sequences, usually interpreted as residual alignment that filters redundant information from the query using another domain. This paper identifies Orthogonal Alignment: gated cross-attention (GCA) often produces outputs orthogonal to the query input, discovering complementary information not present in the query rather than merely reinforcing it. Across 300+ experimental configurations (varied initializations, GCA variants, three CDSR algorithms, four dataset combinations), they find a robust negative correlation between query-output cosine similarity and ranking performance, and this orthogonality emerges without any explicit regularization. The key explanation is that orthogonal updates occupy new subspaces, granting representational capacity without added parameters, so GCA-augmented baselines beat parameter-matched baselines, pointing to a mechanism for parameter-efficient scaling.
