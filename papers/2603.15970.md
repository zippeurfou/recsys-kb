## Summary

This paper addresses the high cost and latency of AI queries (like LLM-based filters and rankings) in databases. It introduces an approach using lightweight proxy models operating on embeddings to approximate these expensive AI operations. The key findings show this proxy method provides over 100x cost and latency reduction while preserving or even improving accuracy, and it can be integrated efficiently into database systems like BigQuery and AlloyDB.

## Technical note

This paper evaluates approximating expensive LLM-based SQL AI operators (semantic filter AI.IF and semantic rank AI.RANK) with lightweight non-LLM proxy models, namely logistic regression over text embeddings labeled by a small LLM-labeled sample. Semantic filtering and ranking are reformulated as classification tasks; an adaptive selection mechanism deploys the proxy only when its accuracy is within a threshold of the LLM baseline, otherwise falling back to the LLM. Deployed on BigQuery (online-trained proxies for OLAP) and AlloyDB (offline-trained proxies for HTAP), it reports up to ~100x-728x cost savings and large latency gains on a 10M-row table while preserving or occasionally improving F1 relative accuracy. Class-imbalance is handled with weighted training (class_weight=balanced) and SMOTE fallback; ranking uses top-K embedding pre-filtering, and proxies fail when relevant documents per query are too few (e.g. SciFact, FIQA) forcing LLM fallback.
