## Summary

This paper introduces RSRCC, a new benchmark for remote sensing change question-answering. It aims to address the gap in explaining fine-grained, localized changes by providing 126k question-answer pairs requiring detailed semantic reasoning. The dataset was constructed using a hierarchical semi-supervised pipeline involving candidate filtering from segmentation masks and retrieval-augmented Best-of-N ranking to ensure high-quality, change-specific questions.

## Technical note

RSRCC is a 126k-question benchmark for fine-grained, region-localized remote sensing change question answering, built on LEVIR-CD. Its hierarchical semi-supervised curation pipeline localizes candidate change regions via transformer segmentation (ViT-L encoder, Dice loss) plus connected-component analysis over semantic mask differences, screens them with a remote-sensing-tuned SigLIP image-text encoder, and resolves ambiguous cases with retrieval-augmented Best-of-N ranking. An LLM judge scores candidate hypotheses conditioned on retrieved in-distribution annotated examples; Best-of-N selection is framed as an inference-time surrogate for KL-regularized preference-weighted selection (optimal policy proportional to reference times exp(reward/beta)). Retrieval constrains judgments to local semantic neighborhoods, reducing decision variance for near-boundary no-change false positives.
