## Summary

1.  News apps require effective personalization, but standard RNN-based sequential recommendation methods struggle to capture the societal influences shaping news consumption (like following trending, group-specific topics).
2.  To address this, the authors propose CSRN (Collaborative Sequential Recommendation Networks), combining RNN-based sequential modeling with fine-grained user similarities learned from collaborative filtering.
3.  CSRN learns user representations using RNNs and captures topic-specific user similarities via a co-reading network, then recommends news based on both the user's own state and the summarized state of similar users, significantly outperforming existing methods in experiments.

## Technical note

CSRN (Collaborative Sequential Recommendation Networks) integrates RNN-based sequential recommendation with user-based collaborative filtering to capture the social/societal influence in news reading that pure RNN histories miss. It first builds a directed news co-reading network from early browsing history, using SVD to place users in a vector space that yields fine-grained, topic-specific similarities beyond a single scalar UserCF metric. The model encodes each user's recent history with RNNs, then attends dynamically over neighbors to summarize what similar users are currently reading, recommending news from both the target user's state and the summarized neighbor state. It significantly outperforms state-of-the-art baselines on two public datasets and is the first to fuse UserCF into a neural sequential recommender.
