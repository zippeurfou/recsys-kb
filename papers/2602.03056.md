## Technical note

ALPBench is a benchmark for attribution-level long-term personal behavior understanding that reformulates recommendation evaluation as predicting a user's interested attribute combinations rather than a specific item, decoupling stable interests from transient factors like popularity and cold-start dynamics. User histories are represented as natural-language sequences over eight product categories with contexts up to ~340k tokens across 3-month, 6-month and 1-year windows. Evaluating SOTA LLMs (Claude, Qwen, GLM, Kimi, Gemini, GPT, DouBao-seed, Minimax, Deepseek), it finds that despite strong general capabilities, current LLMs still struggle to exploit long behavioral sequences for personalized attribute prediction.
