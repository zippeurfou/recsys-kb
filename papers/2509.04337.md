## Technical note

Pinterest introduces a decoupled upstream-downstream framework learning user and Pin (item) embeddings from diverse data sources for ads retrieval and ranking. Upstream models use complex multi-tower architectures (with a specialized overtower for interaction features to keep core embeddings stable) trained on rich signals; embeddings are pre-computed and regularly refreshed for asynchronous serving, then fed as features into downstream ANN retrieval and CTR/CVR ranking models. Deployed in Pinterest's production ad ranking, it delivers notable offline and online metric gains across downstream tasks.
