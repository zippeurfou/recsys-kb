## Technical note

CCN (Comprehensive Comparison Network) targets route recommendation, where routes cannot get unique IDs and standard item-correlation attention misses contrastive cues between routes. CCN builds comparison-level features by comparing non-overlapping segments between route pairs, enabling difference learning without infinite ID-embedding scalability, and a Comprehensive Comparison Block (CCB) achieves cross-interaction between routes over these comparative features. An interpretable Pair Scoring Network (PSN) explains recommendations via segment analysis, and the authors release a richer route-recommendation benchmark with coverage-rate metrics. CCN outperforms prior methods offline and online and has been deployed in AMAP for over a year.
