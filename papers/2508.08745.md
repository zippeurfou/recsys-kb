## Summary

This paper introduces the Comprehensive Comparison Network (CCN) for route recommendation within Baidu Maps. It addresses the need to consider local road quality and allow direct comparisons between candidate routes by incorporating novel comparison-level features describing non-overlapping segments, unlike traditional methods focusing only on query or item level. The core CCN component is the Comprehensive Comparison Block (CCB), which enables route comparison using a specific operator and multi-scenario MLPs to update representations. By stacking CCBs, CCN determines optimal routes based on comprehensive comparisons while ensuring interpretability for online deployment through a pair scoring network; this model has been successfully deployed over a year and shown significant performance improvements.

## Technical note

CCN (Comprehensive Comparison Network) reframes map route recommendation, where routes can't get unique IDs and conventional attention captures correlation rather than the contrastive cues needed to pick between routes. CCN builds comparison-level features from the non-overlapping segments between route pairs, avoiding the infinite-scalability problem of segment ID embeddings, and processes them with a Comprehensive Comparison Block (CCB) that performs cross-interaction across routes, stacked to produce final scores. An interpretable Pair Scoring Network gives users segment-level explanations for the chosen route. Evaluated with a coverage-rate metric on a new richer benchmark, CCN outperforms prior methods and has run in AMAP (Baidu/Amap navigation) for over a year.
