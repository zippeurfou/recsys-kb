## Summary

Large language models (LLMs) face performance degradation in long conversations due to growing context length and memory/computation costs. This paper introduces an adaptive context compression framework addressing this by integrating importance-aware memory selection, coherence-sensitive filtering, and dynamic budget allocation. Experiments on various benchmarks show the proposed method improves conversational stability and retrieval performance, reduces token usage and inference latency, effectively balancing long-term memory retention with computational efficiency.

## Technical note

The paper proposes an adaptive context-compression framework for long-running LLM interactions that integrates importance-aware memory selection, coherence-sensitive filtering, and dynamic budget allocation to retain essential conversational information while curbing context growth. Unlike static truncation or fixed summarization, it adjusts context representation based on interaction complexity and memory relevance, jointly modeling relevance and coherence to mitigate context decay. It is evaluated on LOCOMO, LOCCO, and LongBench for answer quality, retrieval accuracy, coherence preservation, and efficiency. Reported results show improved conversational stability and retrieval performance with reduced token usage and inference latency versus memory- and compression-based baselines, positioning adaptive compression as a better trade-off than simply extending context windows.
