## Summary

This paper addresses the challenge of using large language models (LLMs) for recommendation by proposing RecLoRA. It tackles three main limitations: insufficient user-specific personalization in standard LoRA adaptation, the inefficiency of processing long user history sequences, and scalability issues with large datasets when fine-tuning LLMs. RecLoRA introduces a personalized LoRA module, a Long-Short Modality Retriever for efficient history handling, and a Few2Many Learning Strategy, demonstrating significant improvements over existing methods on public datasets.

## Technical note

RecLoRA adapts LLMs for recommendation while fixing three limitations of prior LoRA-based methods: a single shared LoRA lacks per-user personalization, long lifelong behavior sequences hurt LLM efficiency/effectiveness, and training on only a small data fraction limits exposure. It introduces a personalized LoRA module that maintains multiple parallel meta-LoRA weights aggregated per user via soft routing guided by a sequential conventional recommendation model (CRM). A Long-Short Modality Retriever assigns longer history to the CRM rather than the prompt, improving performance with negligible cost, and a Few2Many Learning Strategy uses the full-space-pretrained CRM as a 'magnifier' so few-shot LLM tuning perceives the whole training space. The personalized LoRA is a plug-in for any LoRA-based LLM recommender, and experiments on three public datasets show consistent gains over strong baselines like SASRec, DIN, TALLRec, and ReLLa.
