## Summary

This paper introduces MODF-SIR, a multi-agent framework designed for efficient Social Intelligence Reasoning (SIR) by leveraging knowledge distillation across both training and inference stages to build upon lightweight Multimodal Large Language Models (MLLMs). A core innovation is its ability to explicitly extract and format long-tail social events from multi-modal data, preventing them from being lost in tokenization alongside more common head events. The framework integrates Test-Time Adaptation with LoRA fine-tuning for instance-level reasoning, demonstrating state-of-the-art performance on benchmarks using a significantly reduced training dataset (around 30% of the full IntentTrain set).

## Technical note

MODF-SIR is a lightweight multimodal-LLM multi-agent framework for social-intelligence reasoning over long audio-visual streams, distillation-augmented in both training and inference. Inspired by dual-process theory, an ELT Retriever Agent (System 1) scans omni-modal input and textualizes long-tail social events so they are not drowned out during tokenization, an AKD Router Agent routes between direct reasoning and grounded reasoning, and a GRPO-trained Grounder Agent localizes query-relevant segments to shrink the search space. An OMLT Reasoner Agent (System 2) performs Chain-of-Thought reasoning, while a TTA Reviser Agent applies instance-level test-time adaptation via episodic LoRA updates that are discarded after inference to prevent catastrophic forgetting, exploiting the generation-evaluation gap. With ~30% of IntentTrain data it reaches state-of-the-art on IntentBench, Daily-Omni, and WorldSense, surpassing GPT-4o and Gemini-2.5-Pro.
