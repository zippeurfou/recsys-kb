## Summary

1.  The paper introduces **Life-Bench**, a new, comprehensive benchmark for advanced multimodal personalization, created through synthetic data simulating user digital footprints, to address the lack of suitable evaluation tools.
2.  Alongside the benchmark, the authors propose **LifeGraph**, a framework that structures personal context into a knowledge graph to enable more effective retrieval and reasoning for complex personalization tasks.
3.  Experiments on Life-Bench reveal significant performance gaps in existing methods, particularly for complex reasoning tasks, demonstrating that while LifeGraph shows promise, advanced multimodal personalization remains a critical open challenge.

## Technical note

This paper targets advanced multimodal personalization with Vision Language Models via two artifacts. Life-Bench is a fully synthetic multimodal benchmark of 16,000+ questions over simulated user 'virtual accounts' (social network of personal concepts plus timestamped multimodal life logs), spanning 10 tasks from concept identification and persona/preference to multi-hop relational, temporal-sequential, and aggregative reasoning; synthetic generation seeded by public captions preserves privacy while adding realism and quality controls. LifeGraph is a training-free retrieval-enhanced framework that organizes personal context into a knowledge graph with indexed links to source multimodal data and retrieves via an algorithm adapted from Think-on-Graph. Experiments show existing RAG methods excel at direct-matching tasks but fail on complex temporal/aggregative reasoning, that LifeGraph closes much of this gap, and that larger retrieval context does not guarantee better performance.

- Text Concept QA: This task evaluates reasoning over the visual and persona attributes of personal concepts from a text-only query. Answering requires retrieving the concept’s visual and textual profile. Medium-level questions involves multi-hop relationship traversal
- Visual Concept Recognition: This task assesses the model’s ability to recognize the presence of a personal concept within a given image. This requires retrieving the concept’s visual profile for comparison and can involve resolving multi-hop relationships to first identify the target concept
- Concept VQA: This task requires answering questions about a specific concept’s actions, appearance, or state within a provided image. It combines concept recognition with fine-grained visual reasoning and may also involve resolving multi-hop relationships
- Scene and Activity: This task evaluates the ability to understand the holistic context of a specific historical event. It requires retrieving data from a given date and reasoning about the overall scene, key activities, and notable objects
- Direct Person-Centric: This task probes for fine-grained details about a concept’s involvement in a historical event. It requires retrieving the event context and identifying the reletive concepts to answer questions about their appearance, actions, and interactions
- Relational Person-Centric: This task requires reasoning about an concept’s involvement in a historical event, where the target individual is identified through a relational description. It involves a multi-hop traversal of the social network to identify the correct concept then analyze their appearance, actions, and interactions within the event
- Fine-Grained Scene: This task presents highly contextualized, compositional queries about a specific moment within an event. Answering requires locating a precise scene based on a described interaction and then reasoning about the concurrent actions or spatial relationships of other concepts within that frame
- Preference and Persona: This task evaluates the ability to infer a concept’s persona and preferences. Answering requires either retrieving explicit information from the concept’s profile or aggregating and synthesizing patterns from their historical activities
- Frequency and Counting: This task assesses the model’s ability to perform quantitative aggregation over the entire historical timeline. It requires retrieving all events that satisfy a specific set of conditions (e.g., involving certain people and activities) and counting the number of unique occurrences
- Relational Temporal Reasoning: This task evaluates multi-step reasoning that combines event retrieval and chronological navigation. It requires first identifying an anchor event based on its content and then navigating the timeline to a subsequent or preceding event to answer a question about it
- PersonAnimal: Represents core personal concepts
- Event: Represents a specific occurrence in the user’s history, typically associated with a date and one or more images
- Date: Represents a specific date or timestamp
- Location: Represents a geographical place associated with an Event or PersonAnimal 
- Activity: Represents an action or occasion occurring within an Event
- Object: Any other descriptive facts related to a concept or event will be covered by Object (arXiv:2602.19001)
