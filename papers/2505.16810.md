## Technical note

DeepRec (Tencent) is an LLM-based recommender enabling autonomous multi-turn interactions between an LLM and a traditional recommendation model (TRM) for deep exploration of the item space, combining LLM world knowledge/reasoning with TRM recommendation-specific efficiency. Each turn the LLM reasons over user preferences and queries a preference-aware TRM to retrieve candidates, then ranks retrieved items after multiple turns. Optimized via RL with recommendation-model-based data rollout, hierarchical process- and outcome-level rewards, and a two-stage training strategy, DeepRec significantly outperforms both traditional and LLM-based baselines on public datasets; code is released.
