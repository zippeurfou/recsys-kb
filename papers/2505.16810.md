## Summary

1.  Existing LLM-based recommendation systems often fail to fully leverage item knowledge, so this work introduces **DeepRec**, which uses large language models (LLMs) specifically for deep exploration into the "item space" rather than just enhancing general recommenders.
2.  DeepRec facilitates autonomous multi-turn conversations between an LLM and a traditional recommender model (TRM), where each turn involves reasoning about user preferences followed by collaborative item retrieval, culminating in final ranking based on the dialogue's outcome.
3.  To optimize this interaction process effectively, the authors employ reinforcement learning with tailored designs like preference-aware data generation and hierarchical rewards, demonstrating that DeepRec significantly outperforms both standard recommenders and other LLM-based systems across various datasets.

## Technical note

DeepRec is an LLM-based recommender that enables autonomous multi-turn interaction between an LLM and a traditional recommendation model (TRM) to deeply explore the item space, rather than restricting the LLM to a single TRM-retrieved candidate set. Each turn has the LLM reason over user preferences and query the TRM to retrieve candidates, with final ranking produced from the accumulated dialogue. It is optimized with reinforcement learning featuring three designs: recommendation-model-based data rollout using a preference-aware TRM to build trajectories, a hierarchical reward function combining process-level and outcome-level rewards, and a two-stage RL strategy (first learn to interact, then improve performance). Experiments show DeepRec significantly outperforms both traditional and LLM-based baselines.
