## Summary

Traditional AI companions in cooperative games use simple hotkeys, limiting complex commands and immersion. The paper introduces F.A.C.U.L., the first real-time language system allowing players to give detailed tactical instructions to AI partners using natural commands like "clear the second floor". This system, using advanced language processing and environmental awareness, provides complex command support, real-time feedback, and seamless collaboration, effectively enhancing gameplay compared to rule-based methods.

## Technical note

F.A.C.U.L. is a real-time natural-language AI companion system for cooperative FPS games (Arena Breakout: Infinite) that replaces hotkey commands with spoken tactical instructions. Speech is transcribed by ASR, then a confidence-based reasoning module (BERT-FID, a multi-task BERT doing command segmentation, hierarchical intent classification, and NER with CRF) handles high-confidence commands directly and routes low-confidence 'fuzzy' ones to a larger LLM, balancing latency and accuracy. A multimodal image-text (CLIP-style) entity retrieval module matches commands to in-game 3D objects using real-time attributes like distance and orientation, and parsed actions execute via behavior trees with voice feedback. User studies show higher reliability and immersion than rule-based companions.
