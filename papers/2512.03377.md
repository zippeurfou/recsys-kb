## Summary

1.  Standard transformers use self-attention, but this mechanism struggles to capture complex, multi-step relationships efficiently due to a low-rank limitation.
2.  To address this, the paper introduces Nexus, a recursive architecture where Query and Key vectors are themselves outputs of inner attention loops, allowing tokens to incorporate global context before the final attention computation.
3.  Nexus dynamically refines token representations using nested attention mechanisms and uses weight sharing to maintain parameter efficiency, effectively breaking the standard attention's linear bottleneck and outperforming standard Transformers on benchmarks.

## Technical note

Nexus is a higher-order attention mechanism that addresses the low-rank/rank-collapse bottleneck of standard first-order self-attention, which struggles to capture multi-hop relationships in a single layer. Instead of static linear projections, Nexus recursively refines Query and Key vectors through nested inner self-attention loops so tokens aggregate global context before the final attention, and uses a weight-sharing strategy to add only O(1) extra parameters. The authors theoretically show it breaks the linear bottleneck and empirically outperform standard Transformers, including retrofitting existing LLMs like Qwen2.5 to boost mathematical reasoning.
