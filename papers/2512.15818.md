## Summary

This paper introduces the **Attribute Misbinding Attack**, which exploits flaws in identity-preserving models' attention mechanisms to generate NSFW content by misassigning harmful attributes to target identities using seemingly benign prompts.

To study this threat, the authors created the **Misbinding Prompt evaluation set**, which assesses content generation risks across dimensions like pornography and violence, achieving a significantly higher bypass rate on text filters than existing benchmarks.

They also propose the **Attribute Binding Safety Score (ABSS)**, a novel metric that evaluates both content fidelity and safety compliance simultaneously, enabling more comprehensive model safety assessment.

## Technical note

The paper unveils the Attribute Misbinding Attack against identity-preserving text-to-image models, which exploits flawed attribute binding and a subject-centric cross-attention bias to leak harmful attributes onto a target identity using benign-looking prompts that evade text filters. The authors build a Misbinding Prompt evaluation set covering pornography, violence, discrimination, and illegality by expanding sensitive terms and applying misbinding strategies, achieving a 5.28% higher text-filter bypass rate (including against GPT-4o) than existing sets. They also propose the Attribute Binding Safety Score (ABSS), which uses an MLLM/VQA to jointly assess prompt-image alignment fidelity and safety compliance across foundational T2I and identity-preserving models.
