## Summary

Traditional query recommendation methods in e-commerce suffer from limitations like shallow semantics and poor cold-start performance due to reliance on ID-based matching and co-click heuristics. To address these challenges, researchers introduced AIGQ, the first end-to-end generative framework for this task, built on three core innovations: a novel list-level supervised fine-tuning method (IL-SFT), a new policy gradient algorithm (IL-GRPO) optimizing query relevance and list properties, and a hybrid offline-online deployment architecture (AIGQ-Direct and AIGQ-Think). Extensive offline and online evaluations demonstrate that AIGQ significantly improves key business metrics like user engagement and platform effectiveness compared to existing methods.

## Technical note

AIGQ (AI-Generated Query architecture) is the first end-to-end generative framework deployed for Taobao's HintQ pre-search query recommendation, which generates personalized queries from a user's historical behavior sequence and profile without any current-query trigger, overcoming shallow semantics, poor cold-start, and low serendipity of ID-matching and co-click heuristics. It operates entirely in natural-language space (not semantic IDs) and formulates the task as interest-aware list generation to avoid online beam search. Interest-Aware List Supervised Fine-Tuning (IL-SFT) builds samples via session-aware behavior aggregation and interest-guided re-ranking, and Interest-aware List GRPO (IL-GRPO) does per-query advantage estimation with a dual-component reward combining local query relevance with a global list-level reward for coherence/coverage/diversity, plus a model-based reward from the online CTR ranker. A hybrid offline-online architecture serves lightweight AIGQ-Direct for nearline user-to-query generation and reasoning-enhanced AIGQ-Think for offline trigger-to-query mappings; context is compressed via special tokens and instruction pruning. Online A/B tests on Taobao show substantial engagement and platform-effectiveness gains.
