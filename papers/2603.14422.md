## Technical note

MBD (Model-Based Debiasing) is a framework that converts biased behavioral signals (watch time favoring long-form, loop rate favoring short-form, etc.) into personalized, adaptive unbiased signals for a recommendation value model. Instead of point-wise engagement estimates, MBD conditions on a flexible partial feature set to jointly estimate the contextual mean and variance of the engagement distribution for arbitrary cohorts, enabling calibrated higher-level signals such as percentiles and z-scores; it is implemented as a lightweight built-in branch of the existing multi-task multi-label ranking model with no separate serving infrastructure. Deployed on two billion-user short-video apps, online A/B tests show significant long-term retention and engagement gains (Time Spent, Sessions) by decoupling preferences from ecosystem biases.
