## Summary

This paper explores whether using a single Large Language Model (LLM) for both search and recommendation tasks, rather than separate specialized models, can improve performance in either function. It proposes two hypotheses: that joint training reduces bias towards popular items learned by recommenders alone, and that it captures item representations better by combining content-based information from the search task with collaborative-filtering data from the recommendation task. The authors' extensive experiments on simulated and real-world datasets support both hypotheses, showing significant effectiveness improvements for the unified generative retrieval model compared to single-task models.

## Technical note

Investigates whether a single generative-retrieval LLM trained jointly on search and recommendation helps either task versus separate specialized models. It advances two hypotheses: joint training reduces the popularity bias recommenders learn alone, and it yields better item representations by combining content-based signals from search with collaborative-filtering signals from recommendation. Extensive experiments on simulated and real-world datasets support both hypotheses. The unified generative-retrieval model significantly outperforms single-task counterparts on effectiveness.
