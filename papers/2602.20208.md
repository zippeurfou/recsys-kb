## Summary

1.  The paper addresses the challenge of merging multiple fine-tuned models derived from a shared pre-trained base into a single multi-task model, with task interference being a major obstacle.
2.  It introduces ESM (Essential Subspace Merging), which identifies task-specific essential subspaces using low-rank decomposition via PCA on feature shifts and then fuses these subspaces.
3.  ESM further improves performance with a multi-level polarized scaling strategy to prioritize critical knowledge and suppress redundancies, demonstrating state-of-the-art results in multi-task model merging.

## Technical note

ESM (Essential Subspace Merging) merges multiple task-specific fine-tuned models from a shared checkpoint without retraining, targeting inter-task interference. Instead of SVD on task vectors, it runs PCA on the activation/feature shifts induced by each parameter-update matrix to form an 'essential subspace' aligned with the output feature space, giving lower truncation error and higher knowledge concentration. Each task update is projected onto its essential subspace for low-rank decomposition before fusion. A multi-level polarized scaling mechanism rescales updates across layers, tasks, and dimensions to amplify high-norm critical parameters and suppress low-norm noise. This paper is generic multi-task model merging rather than recommendation-specific.
