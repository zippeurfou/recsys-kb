## Summary

The paper introduces **SynerGen**, a generative recommender model designed to overcome the limitations of traditional "retrieve-then-rank" systems and existing generative models that only handle either search or recommendation. SynerGen uses a single decoder-only Transformer backbone trained jointly on both tasks, combining InfoNCE loss for retrieval with a hybrid ranking loss, and includes time-aware embeddings. This unified approach significantly improves performance on both recommendation and search benchmarks, demonstrating the viability of a single generative model for industrial-scale unified information access.

## Technical note

SynerGen is a decoder-only generative recommender that unifies query-aware search and query-free recommendation while jointly handling retrieval and ranking in one backbone, resolving the trade-off where semantic and collaborative signals compete. It trains on behavioral sequences with InfoNCE (in-batch plus mined hard negatives) for retrieval and a hybrid pointwise-pairwise loss for ranking, fusing frozen LLM semantic embeddings, learned collaborative ID embeddings, and temporal signals before the first Transformer layer. Task tokens (context, retrieval, ranking) switch modes within the same sequence, and a novel time-aware rotary positional embedding injects time into attention. It outperforms strong generative and joint search/recommendation baselines on standard benchmarks.
