## Summary

1.  Current recommender systems using a split "retrieve-then-rank" approach suffer from performance issues due to different objectives for retrieval and ranking, and existing generative models often only handle one task (search or recommendation) effectively.
2.  This paper introduces SynerGen, a novel generative model using a decoder-only Transformer that unifies both personalized search and recommendation into a single generative backbone, addressing this gap.
3.  SynerGen excels at both tasks by jointly optimizing retrieval with InfoNCE and ranking with a hybrid loss, and incorporates time information effectively, outperforming strong baseline models on standard recommendation and search benchmarks.

## Technical note

SynerGen is a single decoder-only Transformer that unifies query-aware personalized search and query-free recommendation while jointly performing retrieval and ranking, avoiding the misalignment of two-stage cascades. It fuses frozen LLM semantic embeddings, learned collaborative ID embeddings, action, and time signals before the first layer, and uses task tokens (context/retrieval/ranking) plus a task-specific attention mask to switch behaviors. Retrieval is trained with InfoNCE using in-batch and impressed-but-not-clicked hard negatives; ranking uses a hybrid pointwise (BCE) plus pairwise loss for calibrated click probabilities; a novel time-aware RoPE applied to Unix timestamps encodes irregular temporal gaps. It outperforms SASRec, BERT4Rec, HSTU, HLLM, UniSAR and others on Book Review, eBook Search Sessions, and a large industrial Session-US benchmark.
