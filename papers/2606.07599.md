## Technical note

DiffoR reformulates ordinal regression as Continuous Generative Ordinal Regression to escape quantization artifacts and lack of global ordinal topology in prior discretization/rank-based/discrete-generative paradigms. It uses a diffusion model to recover continuous ordinal values via iterative denoising, learning soft non-stationary semantic transitions, with a Dual-Decoupling Strategy: Multi-scale Increment Aggregation decomposes targets into hierarchical continuous increments jointly generated across dedicated Transformer attention heads, and Dynamic Denoising Perception synchronizes denoising steps with feature frequencies for coarse-to-fine refinement. Across 12 benchmarks in four domains (including recommendation preference ranking and facial age estimation) DiffoR consistently outperforms SOTA methods, positioned as a general-purpose universal ordinal-regression solution.
