## Technical note

Pailitao-VL (Alibaba) is a unified multimodal retrieval+rerank system for instance-level industrial search, built on a 3B MLLM2vec backbone. Pailitao-VL-Embedding abandons pure contrastive learning for absolute ID-recognition: an agent-driven 'Plan-Propose-Organize-Review' pipeline curates a billion-scale semantic-prototype library, and a three-stage pipeline (MRL contrastive pretraining -> prototype-initialized global identification head -> end-to-end additive-angular-margin classification with KNN-sparse similarity) yields fine-grained embeddings. Pailitao-VL-Reranker evolves from pointwise binary Yes/No scoring to a listwise 'compare-and-calibrate' policy combining chunkwise pairwise ranking with a calibrated 4-level absolute relevance score (reasoning model cold-started via Gemini CoT then GRPO), enabling parallel chunks at 67ms/76ms latency. Online A/B on Alibaba delivered +2% GMV (embedding), +6% (reranker in standardized categories), and up to +20% GMV in SKU-price-comparison AI search.
