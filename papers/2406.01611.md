## Summary

This paper argues that recommendation platforms often misinterpret user engagement signals like clicks or views as indicators of genuine interest or "utility," when these signals can actually reflect impulsive, low-utility actions ("System-1"). To address this confusion between utility-driven and impulse-driven behavior, the authors propose using a model based on temporal point processes (specifically Hawkes processes) to analyze user return probabilities. Their approach suggests that distinguishing true System-2 utility from fleeting System-1 engagement by examining long-term return patterns can lead to better recommender systems optimized for actual user satisfaction rather than just short-term activity.

## Technical note

The paper argues that engagement signals (likes, shares, watch time) are a poor proxy for true user utility because impulsive System-1 behavior confounds utility-driven System-2 behavior, causing misaligned recommendations. It proposes inferring utility from users' return probability to the platform instead, on the intuition that genuine utility drives long-term return while impulse-driven engagement fades quickly. They build a generative model where past content interactions modulate user arrival rates via a self-exciting Hawkes process, with a long-lasting utility-driven (System-2) intensity and a rapidly decaying gratification-driven (System-1) intensity. The authors prove that these two processes are analytically disentangleable from samples, enabling utility estimation, and synthetic experiments show utility-based optimization outperforms engagement optimization.
