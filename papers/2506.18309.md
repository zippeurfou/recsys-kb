## Summary

Traditional user profiling in recommendation systems often uses embeddings, which lack interpretability and adaptability to capture diverse behaviors. The "LettinGo" framework addresses this by employing multiple large language models (LLMs) without rigid supervised training constraints, instead aligning them using Direct Preference Optimization based on downstream task performance feedback. Experimental results show that LettinGo significantly improves recommendation accuracy while also enhancing flexibility and contextual awareness compared to existing methods.

## Technical note

Embedding-based user profiles lack interpretability and adaptability, and LLM text profiles often use fixed formats that miss behavioral diversity. LettinGo generates diverse, adaptive user profiles by using LLMs and aligning the generator with downstream recommendation performance via Direct Preference Optimization (DPO) rather than rigid supervised fine-tuning. It operates in three stages: exploring diverse profiles with multiple LLMs, evaluating profile quality by recommendation impact, and aligning generation using pairwise preference data derived from task performance. Experiments show improved recommendation accuracy, flexibility, and contextual awareness.
