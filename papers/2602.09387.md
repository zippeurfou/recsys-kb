## Technical note

HeMix (AMAP/AutoNavi) is a scalable CTR ranking model unifying adaptive sequence tokenization and heterogeneous feature interaction. Its Query-Mixed Interest Extraction tokenizer uses non-sequential features as dynamic queries plus learnable fixed interest vectors, jointly attending to global (long-term) and real-time behavior sequences via Mixed Hetero Attention to capture both context-aware and context-independent user interests. For interaction it replaces self-attention with the HeteroMixer block (multi-token fusion, heterogeneous mixed-token interaction, group-aligned reconstruction), enabling efficient multi-granularity cross-feature interactions that scale with block depth/embedding size. HeMix outperforms strong DLRM/Transformer baselines and, deployed on the billion-user AMAP platform, delivered +3.61% GMV, +2.78% PV_CTR, and +2.12% UV_CVR over DLRM.
