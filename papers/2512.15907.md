## Summary

Tabular Referenceless eXplainable Evaluation":

1.  Existing table generation evaluation methods either ignore table structure or rely on fixed references, which limits their usefulness. This creates a challenge for assessing LLM-generated tables effectively.
2.  To address this, the paper introduces TabReX, a novel framework that converts both source text and generated tables into knowledge graphs, aligns them using an LLM, and computes scores based on specific quality properties, offering structural and factual fidelity assessments without needing a fixed reference.
3.  TabReX is shown to highly correlate with expert evaluations, remains robust under various perturbations, and provides detailed error traces, establishing a benchmark (TabReX-Bench) and a new paradigm for trustworthy, explainable evaluation of table-generating systems.

## Technical note

TabReX is a reference-less, property-driven framework for evaluating LLM-generated tables that overcomes metrics which flatten tables to text or require fixed references. It converts both source text and generated tables into canonical knowledge-graph triplets (via LLM-based Text2Graph and rule-based Table2Graph), aligns them through an LLM-guided two-step matching, and computes interpretable table- and cell-level penalties whose weights tune sensitivity (coverage) vs specificity (hallucination control). The authors also release TabReX-Bench, spanning six domains with twelve planner-driven perturbation types across three difficulty tiers; TabReX achieves the highest correlation with expert rankings and remains robust under harder perturbations while giving cell-level error traces.
