## Summary

AdaptJobRec introduces an innovative conversational job recommendation system powered by LLM-based agentic tools to handle complex queries more effectively than basic retrieval-augmented approaches. To overcome response latency issues common with agentic systems, AdaptJobRec dynamically determines if a query is simple or complex and routes it accordingly: fast direct tool use for simple ones, involving memory filtering, task planning, and sequential execution of personalized recommendation tools for complex ones. This adaptive approach significantly reduces average response time by 53.3% compared to baselines while improving the accuracy of job recommendations in real-world scenarios like Walmart's career advice chatbot.

## Technical note

AdaptJobRec is an agentic conversational job-recommendation system that balances complex-query reasoning against the response latency that plagues agentic CRS. A query-complexity identification mechanism (via a customized system prompt) routes simple queries to direct tool calls for fast answers, while complex queries invoke a few-shot memory-processing module that filters relevant chat history, an intelligent task-decomposition planner producing nested/asynchronous sub-task lists, and personalized recommendation tools backed by Walmart's People.AI knowledge graph (1.6M nodes, 83M edges). This avoids running heavyweight planning/memory modules on trivial queries. On Walmart's real-world career-recommendation scenarios it cuts average response latency by up to 53.3% versus competitive baselines while improving recommendation accuracy.
