## Technical note

AdaptJobRec is a conversational job/career recommendation system built on an autonomous LLM agent that integrates personalized recommendation tools over Walmart's People.AI knowledge graph (1.6M nodes, 83M edges). A query-complexity identification mechanism routes simple queries directly to a tool for fast responses, while complex queries trigger a few-shot memory-processing module and an intelligent task-decomposition planner (grouping asynchronous sub-tasks). Compared to fine-tuned LLM and agentic baselines (ReAct, Plan-and-Execute), it reduces average response latency by up to 53.3% while improving recommendation accuracy.
