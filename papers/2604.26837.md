## Summary

This paper addresses the challenge of serving large language models (LLMs) with long context, where the cost of processing vast key-value (KV) caches becomes a major bottleneck. It introduces SPIN, a unified framework combining sparse attention techniques with hierarchical KV storage management, designed to overcome previous implementation hurdles and system bottlenecks. SPIN significantly improves performance, achieving higher throughput, lower latency, and reduced total processing overhead compared to existing systems and sparse attention implementations.

## Technical note

Spin is a sparse-attention-aware LLM inference framework that co-designs the execution pipeline with hierarchical GPU-CPU KV storage to make dynamic sparse attention's theoretical savings materialize at the system level. It abstracts diverse sparse algorithms into a common five-operation pipeline (Index, Select, Attention as algorithm-specific compute; Offload, Retrieve as shared data management) and introduces a 'partition' logical unit that maps different sparsity granularities (blocks, clusters) onto a shared page-based KV substrate. A locality-aware KV cache manager dynamically sizes per-request HBM budgets and uses a GPU-friendly bucketed LRU policy to cut PCIe round-trips caused by irregular scattered KV retrieval, exploiting temporal locality of critical tokens across decoding steps. A two-level OS-style hierarchical metadata layout scales with the active working set rather than worst-case address space. Built on vLLM with three sparse-attention algorithms, Spin reports 1.66-5.66x higher end-to-end throughput, 7-9x lower TTFT, and up to 58% TPOT reduction over the original implementations.
