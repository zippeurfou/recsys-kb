## Summary

1.  Current deep models excel at click-through rate (CTR) prediction but face challenges in efficient scaling by simply stacking layers or using standard Mixture-of-Experts (MoE) approaches that lack hierarchical structure.
2.  To overcome these limitations, the authors propose HiLoMoE, a novel framework combining vertical layer stacking with horizontal MoE scaling via Low-Rank Adaptation (LoRA), enabling parallel execution and capturing complex hierarchies in recommendation tasks.
3.  Experiments on multiple datasets demonstrate that HiLoMoE significantly improves both model performance (increasing AUC) and computational efficiency (reducing FLOPs compared to non-MoE baselines).

## Technical note

HiLoMoE combines vertical (layer stacking) and horizontal (MoE) scaling for Transformer-based CTR models in a parameter-efficient way. Each expert is a rank-1 LoRA-style perturbation of a shared base weight, letting the number of experts grow without inflating model size, and stacked MoE layers use hierarchical routing where each layer's expert selection conditions on prior-layer routing scores rather than outputs, enabling combinatorially diverse expert paths that still execute in parallel. A three-stage training pipeline with auxiliary losses stabilizes optimization and encourages balanced, specialized experts. On four public datasets it improves AUC by an average 0.20% while cutting FLOPs 18.5% versus non-MoE baselines, and scales monotonically in depth and width.
