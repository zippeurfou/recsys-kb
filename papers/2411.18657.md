## Summary

1.  **Problem:** Current automated visualization recommendation (vis-rec) models are too slow to handle large datasets because they depend on calculating many computationally expensive statistics before generating recommendations.
2.  **Solution:** The authors propose ScaleViz, an RL-based framework that identifies a minimal set of crucial input statistics needed by any given vis-rec model to make effective recommendations within a specified user time budget (or computational limit).
3.  **Result:** Experiments show ScaleViz can significantly accelerate visualization recommendation on large datasets, achieving about 10 times the speed improvement of baseline methods while maintaining accuracy levels similar for both tested models and three real-world data sets.

## Technical note

The paper tackles the scalability bottleneck of automated visualization recommendation (Vis-Rec) models, which compute up to ~1000 expensive statistics per column and become infeasible on large datasets. ScaleViz profiles the computational cost of each statistic on small samples, uses regression to extrapolate cost to full-dataset size, then applies a budget-aware reinforcement-learning method to identify the most crucial statistical features for a specific target dataset under a user time budget. Only the selected statistics are computed on the full data before running the given Vis-Rec model. Applied to two SOTA models (MLVR, VizML) across four large real-world datasets, ScaleViz achieves up to 10x speedup in time-to-visualize while retaining accurate insights.
