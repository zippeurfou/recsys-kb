## Summary

Personalization Aware LLMs for Recommendation":

1.  This paper addresses the challenge of using large language models (LLMs) for recommender systems, proposing a new framework called PALR that combines user history with LLMs to generate personalized recommendations.
2.  PALR first retrieves relevant candidate items based on user interactions and then uses a fine-tuned, 7-billion-parameter LLM to rank these candidates, explicitly instructing it to select from the input list.
3.  By leveraging a larger LLM fine-tuned specifically for ranking and reasoning over user-relevant item descriptions, PALR outperforms existing recommendation models on sequential recommendation tasks.

## Technical note

Amazon Alexa AI proposes PALR (Personalization Aware LLMs for Recommendation), a retrieve-then-rank framework that fuses user interaction history with LLMs. User/item interactions guide candidate retrieval, then a fine-tuned 7B-parameter LLM ranks the candidates, taking retrieval candidates in natural-language format with instructions explicitly requiring selection from the input list. Unlike prior work using zero/few-shot general-purpose LLMs or sub-1B models, PALR fine-tunes a larger LLM to elicit reasoning and leverage item side parametric knowledge, and represents items as text to enable inductive learning without per-item pre-trained embeddings. It outperforms state-of-the-art baselines on sequential recommendation tasks.
