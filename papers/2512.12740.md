## Summary

Existing sequential recommendation systems using Transformer architectures often suffer from high computational costs due to inefficient memory access and dense attention mechanisms over long sequences.

To address this, the paper introduces FuXi-$γ$, a novel framework featuring two key innovations: (1) an exponential-power temporal encoder that models time intervals using a flexible decay function, enabling efficient encoding with continuous memory access, and (2) a diagonal-sparse positional mechanism that prunes low-value attention calculations.

These architectural improvements allow FuXi-$γ$ to achieve state-of-the-art recommendation quality while significantly accelerating training (up to 4.74x) and inference (up to 6.18x) on long user sequences.

## Technical note

FuXi-gamma is an efficient sequential/generative recommendation framework using a decoder-only Transformer that attacks two efficiency bottlenecks in prior models (HSTU, FuXi-alpha/beta): discontinuous memory access in temporal encoding and dense positional attention over long sequences. It introduces an exponential-power temporal encoder, inspired by the Ebbinghaus forgetting curve, that models relative time intervals with a tunable decay via pure matrix operations and contiguous memory access, and a diagonal-sparse positional mechanism that prunes low-contribution attention blocks using the persymmetry of Toeplitz matrices. On four datasets it achieves SOTA quality while accelerating training up to 4.74x and inference up to 6.18x, with 25.06% HR@10 and 42.86% NDCG@10 gains on an industrial music dataset.
