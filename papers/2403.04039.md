## Summary

This paper addresses sample size planning for estimating conditional counterfactual mean outcomes in a K-armed randomized experiment, specifically focusing on targeted subgroups defined by feature partitioning algorithms. It proposes determining the minimum required sample size by transforming the goal into a simultaneous inference problem across these data-driven subgroups, accounting for increased estimation error risk with more complex partitions or finer binning. The authors validate their nominal guarantees through experiments using policy trees and publicly available data sets.

## Technical note

The paper derives how to compute a sufficient sample size for a K-armed randomized experiment when the goal is estimating conditional counterfactual expectations (and CATE) within data-driven subgroups defined by any feature-space partition, such as a policy or causal regression tree. The key idea is to treat estimation across the partition as a simultaneous-inference problem, so the required sample size scales with the number of inferences (arms times leaves) needed to hit a target confidence level and margin of error, using honest prediction to avoid bias. Given a fixed sample-size budget, the result can be inverted to bound the feasible number of treatment arms or partition complexity (tree leaves). They validate the nominal guarantees empirically on a large publicly available randomized-experiment dataset using policy trees.
