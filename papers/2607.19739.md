## Summary

1.  Large Language Models (LLMs) offer powerful reasoning for recommenders but suffer from hallucinations and context limits, making them unsuitable for full-ranking recommendations.
2.  To overcome these issues architecturally, the authors propose PRTA: an LLM-based central planner that interacts with specialized traditional recommendation models ("tools") to perform detailed scoring, selecting the best tool for each user based on their profile via reflection mechanisms.
3.  Extensive experiments show PRTA outperforms both standard recommenders and simpler LLM-based approaches by significantly improving full-ranking recommendation accuracy through this intelligent tool selection strategy.

## Technical note

PRTA is an agent-based full-ranking recommender that circumvents LLM hallucination and context-length limits by architecture rather than fine-tuning: an LLM (quantized Phi-4) acts as a planner performing personalized tool selection over multiple traditional recommenders (LightGCN, SASRec, SimpleX) that do the actual full-catalog scoring. A per-user Personalized Tool (PT) memory weights each tool's ranked list via a weighted sum, optimized by three reflection mechanisms (local tool evaluation, global tool comparison, rank-based comparison), followed by a lightweight LLM contextual reranking of the top items. On Amazon, Yelp, and Goodreads under full ranking it beats all tool and LLM baselines (BM25, LLMRank, RAG variants), with improvements up to ~60-69% R@10. It decouples behavioral scoring from LLM reasoning rather than unifying retrieval and ranking into one generative model.
