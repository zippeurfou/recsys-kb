## Summary

This paper addresses the challenge of learning embeddings for categorical features in an online setting with a constantly evolving vocabulary. Standard deterministic hashing/embedding methods are shown to be sensitive to data arrival order and suffer from forgetting old categories. To overcome these issues, the authors propose Probabilistic Hash Embeddings (PHE), a model that treats hash embeddings as stochastic and uses Bayesian online learning, enabling it to handle evolving vocabularies, adapt to new data, prevent forgetting, and maintain memory efficiency.

## Technical note

The paper addresses learning categorical-feature embeddings in streaming settings where the vocabulary grows unboundedly, showing deterministic hash embeddings are order-sensitive and suffer catastrophic forgetting online. It proposes Probabilistic Hash Embedding (PHE), which treats hash embeddings as random variables and uses Bayesian online updates to adapt to new items without forgetting old ones, with a bounded parameter set and order invariance. A scalable variational inference algorithm learns parameters and updates posteriors, and PHE serves as a plug-in for models like Deep Kalman Filters and neural collaborative filtering. Experiments on classification, sequence modeling, and recommendation show superior accuracy while using as little as 2-4% of a one-hot embedding table's memory.
