## Summary

This paper addresses the challenge of making recommendations "incremental" by preventing users from clicking recommended content they would have encountered anyway. They achieved this by modifying a production recommendation model using existing holdback data. The key innovation is a dual-threshold targeting policy that prioritizes recommendations only for users highly likely to engage with the promoted content and unlikely to discover it organically, despite differing attribution windows between treated and holdback groups.

## Technical note

Spotify Home recommendations are wasted on always-takers who would stream the content organically, so the paper extends the production multi-task shared-trunk stream model into a Deep Twin Network (DragonNet-style, no propensity head) by adding a holdback head trained on routinely collected randomized holdback data, with a partitioned BCE loss so treated and holdback examples update only their own head but share the trunk. Because treated streams are attributed in a minutes-to-hours window while holdback organic streams use a two-day window (plus a ~30% serving-vs-impression distribution gap), p1-p0 is not a valid CATE; instead a dual-threshold policy serves only when p1(treated stream) >= theta1 and p0(organic stream) <= theta0, with thresholds tuned offline on randomized data under non-inferiority constraints. In a two-week A/B test on millions of users, Treatment-Causal vs Treatment-Model cut recommendation impressions by 7.1% [-7.2%,-6.9%] with recommended-content consumption -0.37% [-0.86%,+0.21%] (not significant), implying ~93% of production impressions were already incremental. Joint training with holdback data also improved calibration of the treated head, especially at high predicted probabilities, which the authors read as evidence that causal training learns more generalizable representations.
