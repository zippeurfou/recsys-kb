## Summary

This paper introduces MTGR (Meituan Generative Recommendation), an industrial-scale framework designed to scale recommendation models while retaining deep learning features like cross-networks traditionally used for effectiveness. To achieve this balance and efficient scaling, it employs user-level input compression alongside novel techniques including Group-Layer Normalization and dynamic masking during training/inference. The result is a highly performant model with significant computational efficiency gains (65x FLOPs reduction), surpassing traditional DLRM performance metrics by nearly two years offline/online, now powering Meituan's main traffic as their primary recommendation system.

## Technical note

Generative recommendation models scale well but require abandoning the handcrafted cross features that make traditional DLRMs effective, and scaling cannot recover the resulting performance loss. MTGR (Meituan Generative Recommendation) is built on the HSTU architecture but retains all DLRM features including cross features by reorganizing user/candidate features into tokens, aggregating candidates per user for training and per request for inference to achieve sub-linear inference cost. It introduces Group-Layer Normalization to align heterogeneous token domains and a dynamic masking strategy (full attention for static features, causal for real-time, self-only for candidates) to prevent information leakage, plus a TorchRec-based framework with dynamic hash tables (1.6x-2.4x throughput). MTGR-large delivers 65x FLOPs/sample vs DLRM, +1.31% CTR and +1.22% conversions online with unchanged training cost and 12% lower inference cost, and is deployed on Meituan's main traffic; ablations confirm cross features, GLN, and dynamic masking are each critical.
