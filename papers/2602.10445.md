## Technical note

UniSID (Tencent) is a unified end-to-end Semantic ID generation framework for generative ad recommendation that breaks from the standard two-stage cascade (pretrained embeddings -> Residual Quantization), which suffers objective misalignment, semantic degradation, and RQ error accumulation. UniSID jointly learns SIDs and embeddings directly from raw advertising data via an advertisement-enhanced input schema (linearizing instructions, images, text, attributes plus learnable SID tokens), predicts every SID layer from the same full context (avoiding layer-wise residual compression), and adds multi-granularity contrastive learning plus a summary-based ad reconstruction objective. It outperforms SOTA SID methods, with up to +2.14% SID quality, +4.01% next-advertisement prediction, +45.46% advertisement retrieval, and +11.83% next-item prediction (Hit Rate) over the strongest baseline.
