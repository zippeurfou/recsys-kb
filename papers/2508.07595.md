## Summary

Recommender systems have become increasingly ubiquitous in daily life. While traditional recommendation approaches primarily rely on ID-based representations or item-side content features, they often fall short in capturing the underlying semantics aligned with user preferences (e.g., recommendation reasons for items), leading to a semantic-collaborative gap. ## Technical note

CURec (Kuaishou) generates collaborative-aligned content features via LLMs to close the semantic-collaborative gap left by ID-based or item-side-content recommenders. It first aligns an LLM with recommendation objectives through pretraining for instruction-following and chain-of-thought reasoning, then builds a reward model inspired by traditional recommendation architectures to score the quality of generated per-item recommendation reasons given a user's interest pattern. Using the reward signal it fine-tunes the LLM via reinforcement learning with chronological CoT correction to produce accurate, personalized reasons, which the reward model (itself a recommender) integrates downstream. Experiments on public benchmarks show CURec outperforms existing methods with more comprehensible recommendations.
