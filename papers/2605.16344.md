## Technical note

PRL-PUTS is a production-ready, ranker-independent RL framework for personalized utility-weight tuning that casts weight selection as a one-step value-based RL problem: given request context an agent picks a utility-weight vector re-weighting the ranker's multi-objective predictions to maximize request-level engagement reward, running alongside ranking inference with no added serving latency. It exposes an inference-time scalarization parameter to sweep a Pareto frontier from a single trained model, producing a governance artifact for operating-policy selection and rollback. Validated offline with unbiased exploration logs and online on Pinterest Homefeed, it lifts successful sessions by +0.13% with gains attributed to contextual weight personalization rather than a shifted global weight vector.
