## Summary

This paper introduces the IAT (Instance-As-Token) framework to address limitations in historical user sequence modeling for recommender systems. IAT works by compressing each historical interaction into a single, informative instance embedding, effectively treating each interaction as a token for downstream modeling. The framework significantly outperforms existing methods and has been successfully deployed in real-world industrial recommender systems, improving key business metrics.

## Technical note

Instance-As-Token (IAT) is a two-stage sequence-feature-engineering framework that replaces hand-crafted sequential features with dense instance embeddings (InsEmb). Stage I compresses all thousands of features of each historical training instance into a compact InsEmb via a compression/decompression bottleneck on a base ranking model; a user-order source model adds a Source Instance Transformer (SIT) with a causal mask so each instance attends to the same user's past instances, boosting source performance and endowing InsEmb with sequence-modeling ability. Stage II retrieves timestamp-truncated InsEmb as instance tokens for a downstream LONGER/Transformer sequence model predicting CTR/CVR with BCE loss. It shows strong in-domain and cross-domain transfer and is deployed across Tencent e-commerce advertising, mall marketing, and live-streaming with online metric gains.
