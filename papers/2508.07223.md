## Technical note

KSER (Kuaishou) is a Knowledge Selection & Exploitation Recommendation framework that selects high-quality knowledge from LLMs to augment discriminative recommenders, countering hallucination, redundancy, and homogenization that degrade performance when LLM response embeddings are naively fed in. It has an Embedding Selection Filter Network (ESFNet) assigning adaptive weights to knowledge chunks across fields and an attention-based embedding-space alignment module aligning LLM semantic embeddings with the recommender's feature space. Two training strategies (all-parameters and extractor-only) adapt to different tasks, with extractor-only offering an efficient knowledge-augmentation perspective. Experiments validate the necessity of both filtering and alignment modules for CTR/CVR tasks.
