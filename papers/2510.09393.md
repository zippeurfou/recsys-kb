## Summary

Semantic User Grouping via LLMs for Conversion Rate Prediction of Low-activity Users":

1.  Predicting conversions for low-activity users in e-commerce recommenders is difficult due to unreliable data, sparse interactions, and training biases towards active users.
2.  To address these challenges, the paper introduces ChoirRec, an LLM-based framework that constructs semantic user groups via a dual-channel architecture.
3.  By filtering noisy signals, enriching sparse embeddings with group knowledge, and enabling effective cross-user learning, ChoirRec significantly improves CVR prediction for low-activity users, as shown by offline and online experiments on Taobao achieving notable performance gains.

## Technical note

ChoirRec improves CVR prediction for low-activity (long-tail) users in Taobao, where the top 18% of users generate 90% of clicks and sparse users get under-trained embeddings. It uses an LLM to generate semantic user profiles that are clustered via RQ-KMeans into cross-activity semantic groups, forming a reliable knowledge source that filters noise. A group-aware hierarchical representation module enriches sparse user embeddings with group-level priors (hierarchical group ID embeddings, aggregated profiles, group behavioral sequences), and a dual-channel module learns individual and group representations separately, transferring knowledge via asymmetric information injection plus gated knowledge distillation so group signals are not overshadowed by individual noise. It lifted GAUC 1.16% offline and order volume 7.24% in online A/B tests.
