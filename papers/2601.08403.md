## Technical note

OSPO (Owen-Shapley Policy Optimization), from Amazon, is a critic-free RL framework for LLM-based recommendation/generative search that fixes GRPO's sparse sequence-level credit-assignment gap, where a single scalar advantage is spread uniformly across all tokens. OSPO forms coalitions of semantically coherent segments (phrases/sentences), queries a black-box retriever/reward model with partial sequences to estimate each segment's marginal contribution (Owen-Shapley value via Monte Carlo coalition sampling), and redistributes sequence-level advantages to tokens proportionally, using potential-based reward shaping to preserve the optimal policy without a value model. On Amazon ESCI and H&M Fashion it gives consistent gains and OOD-retriever robustness, reaching 85% NDCG in ~400 steps vs GRPO's ~800.
