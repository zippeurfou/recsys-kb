## Summary

This paper introduces **VILLAIN**, a multimodal fact-checking system designed to verify claims combining images and text. VILLAIN utilizes **prompt-based multi-agent collaboration**, employing specialized vision-language model agents across distinct stages of verification: evidence retrieval, information analysis, and verdict prediction. The system achieved **first place** on the AVerImaTeC leaderboard across all evaluation metrics.

## Technical note

VILLAIN is a multimodal fact-checking system for verifying claims that combine images and text, entered in the AVerImaTeC shared task. It uses prompt-based multi-agent collaboration in which specialized vision-language model agents handle distinct stages: evidence retrieval, information analysis, and verdict prediction. Retrieval leverages multimodal embedding and reranking models (e.g., mxbai and Ops-MM embeddings) with Qwen3-VL and Gemini agents for analysis. The system placed first on the AVerImaTeC leaderboard across all evaluation metrics.
