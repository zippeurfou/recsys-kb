## Summary

Large-scale recommendation systems face a critical problem with embedding collisions in hash tables, which degrades model performance. To solve this, the authors introduce MPZCH, a linear probing-based indexing method that effectively eliminates collisions entirely with minimal overhead. MPZCH also significantly improves the freshness of embeddings by retiring obsolete IDs and resetting slots, preventing the inheritance of stale feature information.

## Technical note

Introduces Multi-Probe Zero Collision Hash (MPZCH), a GPU embedding-indexing mechanism that resolves hash collisions via linear probing over the embedding table plus two auxiliary tensors (identities and metadata) implemented as high-performance CUDA kernels. A two-pass (discovery then action) probe guarantees existing IDs are prioritized over new allocations, achieving zero collisions when table size exceeds ID cardinality with sufficient probe depth. Configurable TTL and LRU eviction reset both embedding weights and optimizer state on eviction, preventing stale-embedding inheritance (negative transfer) and improving freshness. It integrates with TorchRec via row-wise co-sharding of auxiliary tensors and supports streaming delta updates; production A/B tests show NE gains on user embeddings and higher new-video impressions plus tighter intra-creator embedding clustering for item embeddings.
