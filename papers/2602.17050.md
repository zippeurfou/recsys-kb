## Technical note

MPZCH (Multi-Probe Zero Collision Hash, Meta) is an embedding-table indexing mechanism based on linear probing that mitigates (often eliminates) hash collisions and stale-embedding inheritance in large-scale recommenders. Traditional hashing forces distinct high-cardinality IDs (users, items) to share embedding rows and lets new IDs inherit obsolete embeddings; MPZCH uses auxiliary identities and metadata (TTL) tensors with high-performance CUDA kernels implementing configurable probing plus active eviction, retiring obsolete IDs and resetting reassigned slots so new features learn from scratch. Despite collision-mitigation overhead it keeps training QPS and inference latency comparable to existing methods, and online experiments show zero collisions for user embeddings and improved item embedding freshness/quality; it is released in the open-source TorchRec library.
