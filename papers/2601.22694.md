## Summary

Current large ranking models face scaling challenges because they rely on item IDs, which are difficult to maintain as items constantly change, limiting model training and performance. This paper introduces TRM, a framework using semantic tokens instead of IDs, which significantly reduces storage requirements and improves model performance as it scales. Extensive experiments show TRM outperforms existing models on larger scales and has been successfully deployed, yielding measurable positive results in user engagement.

## Technical note

TRM (Token-based Recommendation Model) replaces unstable item-ID embeddings with semantic tokens to unlock the scaling potential of large ranking models, arguing (theoretically and empirically) that the closed, stable token set scales dense parameters better than drifting IDs. Naive token substitution hurts performance, so TRM integrates user-action collaborative signals into the vision-language tokenizer, learns per-item combinatorial knowledge to balance memorization vs generalization, and jointly optimizes discriminative and generative objectives to exploit token-sequence structure. Applied to RankMixer it gives 0.65-0.85% AUC gains, 33% sparse-storage reduction, and deployed A/B lifts of +0.26% user active days.
