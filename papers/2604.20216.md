## Summary

This paper addresses the challenge of predicting full conditional distributions using LLMs, moving beyond single point estimates. The authors introduce Quantile Token Regression, incorporating dedicated quantile tokens into the input sequence to enable direct attention between inputs and specific quantiles, addressing a lack of local grounding. They further enhance this by adding neighbor context retrieval, pulling in similar instances and their quantiles. Experiments show this method significantly improves distributional predictions, consistently outperforming baselines by reducing MAPE and narrowing prediction intervals, especially on smaller datasets.

## Technical note

This work predicts full conditional distributions from text with LLMs under empirical-quantile supervision (targets interpolated to a 99-quantile grid). Quantile Token Regression appends dedicated learnable tokens <Q_tau> to the input so each quantile attends directly to inputs via self-attention, replacing the shared-representation bottleneck of multiple linear heads over one hidden state and giving direct input-output pathways plus attention interpretability. Retrieval augmentation adds top-K semantically similar neighbors, each carrying its full empirical distribution (not a single point label), grounding dispersion and tail estimates. A theoretical analysis clarifies loss objectives: L1/L2 on empirical quantiles approximate 1D W1/W2 Wasserstein matching, versus mismatched pinball. On Inside Airbnb and StackSample with Qwen3 1.7B-14B, quantile tokens plus neighbors cut MAPE ~4 points and narrow prediction intervals up to 6x, especially on smaller/harder datasets.
