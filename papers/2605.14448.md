## Summary

Multimodal large language models (MLLMs) often use chain-of-thought (CoT) reasoning to improve embeddings, but this approach is inefficient and sometimes detrimental, especially for simple inputs. To address this, the authors propose Think When Needed (TWN), a unified framework that uses a shared frozen backbone with dual adapters (for reasoning and embedding) and an adaptive mechanism to decide per input whether CoT generation is needed. TWN achieves state-of-the-art embedding quality on benchmark tasks while being significantly more efficient than existing generative methods, requiring fewer additional parameters and reasoning tokens.

## Technical note

Think When Needed (TWN) is a unified multimodal embedding framework that conditionally invokes chain-of-thought reasoning only when it improves retrieval, avoiding wasted decoding on simple inputs where discriminative embeddings suffice. It uses a dual-LoRA architecture attaching separate reasoning and embedding adapters to a shared frozen MLLM backbone, with gradient detachment at their interface to mitigate the gradient conflict between autoregressive and contrastive objectives. An adaptive-think routing gate decides per input whether to generate CoT, and an embedding-guided RL stage freezes the embedding adapter as a stationary reward environment with a global embedding cache. On MMEB-V2's 78 tasks TWN reaches SOTA embedding quality while adding only 3-5% parameters and using up to 50% fewer reasoning tokens than full generative mode.
