## Summary

1.  Current LLM-based user simulators for sequential recommendation suffer from inaccurate profiles due to static construction and unrealistic interactions limited to single rounds.
2.  The authors propose DGDPO, a framework that dynamically optimizes user profiles through an iterative process using specialized diagnostic modules (to identify flaws) and treatment modules (to refine based on diagnosis), all driven by LLMs.
3.  This novel integration allows user profiles and recommendation strategies to co-evolve over multiple rounds of interaction, enhancing realism compared to existing single-round simulators.

## Technical note

DGDPO is an LLM-based user-simulator framework that replaces static single-step profile construction with an iterative diagnostic-guided optimization loop to improve simulation fidelity. A specialized diagnostic LLM (Qwen3-0.6B, trained via domain-adaptive pre-training plus defect-specific fine-tuning on synthetic inaccurate/incomplete profiles) identifies profile defects at ~92% accuracy, then a general-purpose treatment LLM (gpt-4o-mini) generates targeted refinements while traversing the user's interaction history. It is the first to couple such a simulator with sequential recommenders (FPMC, NARM, SASRec, LRURec) to enable bidirectional co-evolution of user profiles and recommendation strategies over multi-round interactions. On ML-1M, Amazon Books, and Movies&TV it beats Agent4Rec, RAH, AgentCF and KuaiSim by ~15-19% average, with the largest gains in Precision.
