## Technical note

DGDPO (Diagnostic-Guided Dynamic Profile Optimization) improves LLM-based user simulators for recommender systems, which suffer from static single-step profile construction and unrealistic single-round interaction. Each optimization loop uses a specialized diagnostic LLM (trained via domain-adaptive pre-training and defect-specific fine-tuning, reaching 92.20% profile-defect accuracy vs 62.78% for a prompted general LLM) to identify profile defects, then a treatment LLM generates targeted refinements while traversing interaction history step by step. It is the first to integrate the simulator with sequential recommenders, enabling bidirectional co-evolution of user profiles and recommendation strategies over multiple rounds; experiments on three real datasets confirm effectiveness.
