## Summary

Modern code review, despite evolving from simple peer checks to complex pull request workflows, remains a manual and demanding process struggling under the increased code volume generated by AI coding tools. This paper proposes a vision for "agentic code review," suggesting a framework combining specialized AI agents with human oversight across five key stages (PR creation to retrospective). The authors identify major challenges for responsible AI adoption in code review and outline a research agenda for improving human-AI collaboration in this domain.

## Technical note

This vision paper argues that AI coding assistants increase code-production velocity but amplify the code-review bottleneck, and that stage-scoped tools cannot deliver effective review across the full PR lifecycle. It proposes agentic code review: a framework of five coordinated stages (PR Creation, PR Augmentation, Reviewer Selection, AI-Assisted Code Review, PR Retrospective) that carries context across stage boundaries while retaining humans at key decision points for judgment and accountability. It reviews the historical evolution of code review across five eras, from ad hoc inspection to LLM/agent-assisted workflows, situating the shift driven by large language models and agentic systems. The authors identify open challenges for responsible adoption—reliability, bias, privacy, automation bias, transparency, and evaluation—and outline a research agenda for human-AI collaboration in software engineering.
