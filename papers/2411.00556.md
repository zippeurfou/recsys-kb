## Summary

LLM-KT is a model-agnostic framework designed for knowledge transfer from Large Language Models (LLMs) into Collaborative Filtering systems by injecting and leveraging internally reconstructed LLM-generated features. This approach avoids direct input changes, making it adaptable across various CF models without requiring architectural modifications on the existing recommendation infrastructure. Experiments demonstrate that LLM-KT consistently improves baseline CF performance and offers competitive results in context-aware settings while having broader applicability than current specialized methods.

## Technical note

Introduces LLM-KT, a model-agnostic framework that injects LLM-generated features into an intermediate layer of any collaborative filtering model rather than passing them as direct inputs, broadening applicability beyond context-aware CF. An LLM generates per-user textual preference 'profiles' that a text embedding model (ada-002) encodes; the CF model is trained with an auxiliary pretext task to reconstruct these profile embeddings at a chosen internal layer via a weighted combination of the model loss and a reconstruction (RMSE) loss, with UMAP aligning dimensions. This enriches learned user representations without architectural changes. On MovieLens and Amazon it improves baseline CF models by up to +21% NDCG@10 and matches SOTA KAR in the context-aware setting.
