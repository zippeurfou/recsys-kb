## Summary

This paper addresses the challenge in sequential CTR prediction of determining the optimal interaction granularity between the target item and the user sequence. Existing models either score items directly (brittle for sparse data) or use latent queries (diluting target control). The authors propose LENS, combining a query gate and position bias module, along with QueryPos, which enhances performance across various backbones and datasets, and identifies a density-dependent conditioning rule for different item densities.

## Technical note

LENS is a staged design that addresses how to choose interaction granularity between the target item and the user behavior sequence in sequential CTR prediction. Existing models either score items directly (brittle under sparse data) or use latent queries (which dilute target control); LENS combines a query gate and a position-bias module, plus a QueryPos component, to balance these. It improves performance across multiple backbones and datasets and identifies a density-dependent conditioning rule that selects behavior differently for high- versus low-density item settings. The work is framed around target-attention-style user-interest modeling for ranking.
