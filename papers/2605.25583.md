## Summary

(Abstract fallback)

In sequential CTR prediction, a central design question is at what granularity the target should interact with the user behaviour sequence. Existing models mainly follow two routes. Raw-item architectures such as DIN let the target score each item in the sequence directly. This relies on well-trained item embeddings and becomes brittle for sparse items. Latent-query architectures such as HyFormer, MixFormer, and OneTrans build query representations by combining the target with other information....

## Technical note

LENS studies interaction granularity in sequential CTR—how the target should interact with user history—contrasting raw-item architectures like DIN (fine-grained but brittle for sparse items) with latent-query backbones (HyFormer, MixFormer, OneTrans; robust but dilute target-specific control). It restores target control via a staged design: QueryPos, a per-query learnable position prior, plus zero-initialized residual modules TCQG (Target-Conditioned Query Gate) and TCPB (Target-Conditioned Position Bias). Across three latent-query backbones and four datasets (dense to ~1.1 samples/item), QueryPos+LENS gives positive total-gain point estimates in all twelve backbone-dataset cells, and the optimal condition source shifts from item-only to item+sequence as item density falls (crossover near ~50 samples/item).
