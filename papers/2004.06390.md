## Summary

This paper addresses the lack of diversity in recommender system top-N lists, which are generated by optimizing item accuracy independently. The authors propose a personalized re-ranking model using Determinental Point Processes (DPP) that can be easily added after existing ranking systems. This model models the user-specific trade-off between accuracy and diversity, improving recommendation diversity while considering individual user preferences, as validated offline and online.

## Technical note

Proposes personalized DPP (pDPP), a re-ranking component deployable after any ranker to improve recommendation-list diversity while respecting each user's individual diversity propensity, unlike standard DPP which assumes a single global trade-off parameter. The per-user weight alpha_u is factorized into a shared tunable alpha_0 times a user factor f_u derived from the Shannon entropy of the user's interaction-category history, adding no extra hyperparameters. Kernel matrices are computed on-the-fly and Fast Greedy MAP inference keeps latency acceptable. On MovieLens-1M and a company App Store dataset pDPP improves the precision/ILD balance over BASE and DPP, and online A/B testing shows +6.52% download ratio, +3.54% downloads-per-user, and +4.32% ILD over baseline.
