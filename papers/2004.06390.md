## Summary

1.  Industrial recommender systems often use top-N lists generated by ranking algorithms optimized for individual item accuracy, which unfortunately neglects diversity and the interactions between items, leading to suboptimal recommendations.
2.  To address this, the paper introduces a personalized re-ranking model that can be added after any existing ranking function, using a tailored Determinental Point Process (DPP) to model the trade-off between accuracy and diversity for each specific user.
3.  This personalized DPP model was successfully deployed and tested both offline and online, demonstrating its effectiveness in improving recommendation diversity while maintaining performance in a large-scale industrial system.

## Technical note

The paper proposes pDPP, a personalized re-ranking model that improves recommendation-list diversity by personalizing the relevance-diversity trade-off per individual user rather than assuming a shared propensity as in standard DPP. It factorizes the user-specific DPP trade-off hyperparameter into a shared tunable term times a user factor derived from the Shannon entropy of the user's interaction-category history (via parameterized min-max normalization), avoiding per-user hyperparameter search. Re-ranking uses the efficient Fast Greedy MAP inference over a relevance-plus-similarity kernel, deployable as a follow-up after any ranker. Offline and live A/B experiments show simultaneous diversity and accuracy gains over DPP/MMR baselines.
