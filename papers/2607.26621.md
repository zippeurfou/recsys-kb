## Summary

Large foundation recommendation models (FRMs) using LLMs often rely on explicit Chain-of-Thought rationales, which are slow and rigid due to autoregressive generation. To address these issues, WhisperRec proposes an alternative approach by compressing teacher-generated CoT reasoning into learnable latent tokens within a FRM backbone. This allows the model to perform efficient internal reasoning without producing verbose text, significantly improving inference speed while maintaining recommendation accuracy.

## Technical note

WhisperRec is a latent-reasoning framework for LLM-based foundation recommendation models (Kuaishou) that compresses explicit chain-of-thought into a few learnable latent reasoning tokens, enabling a Latent-Reason-then-Answer paradigm without generating verbose rationales. It builds Multi-View Adaptive CoT (Exploration/Evaluation/Attribution teacher traces with instance-adaptive complexity), a three-stage Latent Reasoning Alignment that distills those traces into latent tokens on a Qwen3.5-0.8B plus Semantic-ID backbone, then curriculum-based post-training from high- to low-activity users. Over OneReason's explicit-CoT Think and No-Think variants it improves SID@64 by 17.44% and 9.33% respectively while delivering about 10x higher inference throughput, using three latent tokens by default. It also shows latent reasoning degrades general (MMLU) ability less than explicit CoT while retaining semantically aligned reasoning.
