## Summary

This paper addresses the challenge of transferring large-scale sequential recommender systems between different domains where user and item groups are disjoint. It proposes MetaRec, a novel approach leveraging Vector Quantized meta learning by mapping heterogeneous item embeddings from multiple source domains into a shared feature space. This enables knowledge transfer guided by limited target data through an adaptive process that rescales gradients based on domain similarity, consistently outperforming baseline methods on benchmark datasets.

## Technical note

Proposes MetaRec for transferable sequential recommendation in an ID-only, non-overlapping, multi-source setting with fully disjoint user/item groups and no shared side information. Vector quantization maps heterogeneous item embeddings into a shared feature space, reusing the target embedding table as the codebook to avoid extra parameters. A meta-transfer paradigm 'learns to transfer' by computing meta-gradients on target data and rescaling them by source-target gradient similarity to selectively transfer from multiple sources and avoid negative transfer. Extensive experiments across source-target selections show consistent gains over baselines.
