## Summary

This paper introduces the Neuron-Activated Graph (NAG) framework for selecting training data during target-oriented language model pretraining. Instead of using complex black-box methods, NAG identifies high-impact "neurons" within an existing LLM and uses their activation patterns to rank and select relevant pretraining data based on a target example. Experiments show that this training-free, interpretable method significantly improves performance on target tasks compared to random selection and existing baselines, and it remains effective even when multiple targets are present. The analysis confirms that NAG captures a sparse set of crucial neurons essential for the target task, demonstrating its effectiveness.

## Technical note

Neuron-Activated Graph (NAG) Ranking is a training-free, interpretable framework for target-oriented LM pretraining data selection that characterizes each input by a sparse set of high-impact neurons in an off-the-shelf LLM rather than by black-box embeddings. It quantifies per-neuron impact during inference, organizes the most influential neurons across layers into a compact graph, and ranks candidate corpus samples by NAG similarity to target examples, prioritizing data that triggers similar neuron patterns. Across six benchmarks it improves target pretraining by 4.9% over random sampling and beats SOTA baselines by 5.3% on HellaSwag, remaining effective in multi-target settings. Ablations show deactivating the NAG-selected neurons (0.12% of all) causes a 23.5% collapse, indicating a sparse functional backbone for target features.
