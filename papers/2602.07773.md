## Summary

1.  Current search agents excel at reasoning but are often trained using only outcome-based supervision, ignoring the quality of their intermediate steps.
2.  To address this, the paper introduces SRR-Judge, a framework that provides detailed, step-by-step evaluation of reasoning and search actions, enabling more targeted training.
3.  Using SRR-Judge for fine-tuning significantly improves the performance of search agents, achieving over a 10% average improvement on benchmarks compared to standard training methods.

## Technical note

SRR-Judge is a generative step-level evaluator that scores each thought-action pair in a search agent's ReAct trajectory on clarity, logical structure, query appropriateness, and coverage, then refines low-quality steps. Training data is annotated by a larger teacher (DeepSeek-V3.1) with five-run majority-vote self-consistency, then quality-filtered using a 0.7 point-biserial correlation threshold between averaged step ratings and verifiable final-answer correctness. The judge (fine-tuned from QwQ-32B via SFT) is embedded in a rate-and-refine inference loop enabling step-level best-of-N sampling, and the resulting high-quality trajectories drive iterative rejection-sampling fine-tuning of the base agent. This offline alignment avoids costly online RL (GRPO/PPO) and yields over 10% absolute pass@1 gains on BrowseComp and XBench-DeepSearch.
