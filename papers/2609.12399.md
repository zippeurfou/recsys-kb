## Summary

This paper introduces OneLA, a framework designed to improve the efficiency of large-beam decoding in generative recommendation systems that use linear attention. Existing methods either require storing a full recurrent state for every beam or force beams to replay shared history, leading to high memory and data transfer costs. OneLA addresses this by sharing a single state derived from the prompt and using compact, append-only records for divergent parts, along with a fused GPU kernel, to significantly reduce memory usage and accelerate decoding speed.

## Technical note

OneLA is a Kuaishou serving-systems paper for OneRec-style generative recommendation, where each item is a short sequence of semantic IDs and the model must emit hundreds of candidates, so decoding uses very large beams (W up to 512) over a long shared prompt and a short generated suffix. With Gated DeltaNet linear attention every live beam would otherwise carry its own d_v by d_k recurrent state, making persistent capacity Theta(w*d_v*d_k) and forcing copies or recomputation every step because global beam selection reorders and duplicates beams; vLLM's FullState path materializes all of them and its ReplaySSM path treats each beam as an independent request and replays a potentially large prompt tail. OneLA instead keeps the post-prefill state S_ctx once per request and represents each beam as a chain of compact GDN Transition Records r_t = (alpha_t, delta_t, k_t) with delta_t = beta_t*(v_t - alpha_t*S_{t-1}*k_t), costing O(d_v + d_k) per step rather than O(d_v*d_k). Rather than rebuilding states, it performs projection replay: because a GDN step touches S_{t-1} only through S_{t-1}q_t and S_{t-1}k_t, two accumulators initialized from S_ctx are updated as u^(j) = alpha_j*u^(j-1) + delta_j*(k_j dot q_t or k_t), turning matrix work into vector work with replay depth bounded by the fixed SID length. A lightweight append-only ancestry index h_t(b,j) maps logical beam history to immutable physical GTR slots, so pruning, reordering and fan-out only copy indices. A fused kernel assigns each thread block a B_V value tile plus a beam group, loads the S_ctx tile once and reuses it across beams, keeping replay entirely on chip and writing back only the compact GTR. On a 0.8B Qwen3.5 model with 6 full-attention and 18 GDN layers at R=4, W=256, prompts of 1K and 5K and O=3 to 7, OneLA gives 1.54 to 2.46x end-to-end decode-forward speedups over the controlled FullState path and both vLLM paths. Across a 405-shape operator suite median speedups are 40.5x and 42.5x over vLLM and SGLang FullState, 17.5x over ReplaySSM, and 41.5x and 46.3x over FlashInfer and TensorRT-LLM, with up to 42.5x lower persistent recurrent-state capacity. At R=4, W=512 the recurrent path takes 0.0755 ms versus FullState's 3.00 ms at O=3 (39.7x), uses 36.3 MiB instead of 56.5x more, cuts state writes 127x, moves 161 MiB of DRAM traffic (76.9x less) and reaches 40.0 FLOP/byte arithmetic intensity. Max absolute output error against FP32 FullState is 4.88e-4. Caveat: this is purely an inference-efficiency result with no recommendation-quality metrics and no online A/B.
