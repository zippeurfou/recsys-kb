## Summary

Benchmarking Data Agents across the Full Data Intelligence Lifecycle":

1.  DAComp introduces a comprehensive benchmark (210 tasks) mirroring real-world enterprise data workflows, covering both data engineering (building complex SQL pipelines) and data analysis (open-ended business problem solving).
2.  The benchmark rigorously evaluates agents' performance using multi-metric execution for engineering tasks and LLM judges with rubrics for analysis tasks, revealing significant performance gaps, especially low success rates (<20%) in data engineering due to poor pipeline orchestration.
3.  Both engineering and analysis scores (averaging below 40%) highlight distinct capability limitations, demonstrating that current agents struggle with the full data intelligence lifecycle, and providing a realistic testbed to drive future autonomous agent development.

## Technical note

DAComp is a benchmark of 210 tasks covering the full enterprise data-intelligence lifecycle, spanning repository-level data engineering (designing/building/evolving multi-stage SQL pipelines on industrial schemas) and open-ended data analysis (strategic planning, exploratory coding, insight synthesis). Engineering tasks are scored with execution-based multi-metric evaluation, while open-ended tasks use a validated LLM-judge guided by hierarchical rubrics that reward multiple valid solution paths. Experiments show state-of-the-art agents falter, with data-engineering success rates under 20% and analysis scores below 40%, exposing pipeline-orchestration and open-ended-reasoning as distinct bottlenecks.
