## Summary

This paper addresses the challenge of predicting ad click-through rates (CTR), limited by sparse user data from ads but abundant from their richer organic feed interactions. It proposes deriving cross-domain semantic IDs (SIDs) specifically from this organic activity to enhance ad ranking models, finding that different SID sources yield varying prediction improvements measured in AUC gain. To make these SIDs practical for large-scale systems, the authors introduce RQ-FSQ, a quantization method minimizing storage while preserving predictive accuracy, and a Hierarchical Discrete Embedding module; cold-start analysis confirms this approach significantly improves ranking performance using sparse user data from organic interactions.

## Technical note

This LinkedIn paper derives cross-domain user Semantic IDs (SIDs) from dense organic feed activity to improve ads CTR prediction under sparse ad-interaction supervision. It establishes a behavioral-activity-richness principle: SID transfer quality scales monotonically with the amount of behavioral signal in the source, from profile text (+0.036% AUC) to activity-tuned LLaMA embeddings (+0.107%) to direct feed behavioral embeddings (+0.213%). RQ-FSQ pairs per-dimension finite scalar quantization with residual VAE quantization to discretize pre-trained embeddings while matching dense-embedding AUC at ~30x-280x smaller storage. A Hierarchical Discrete Embedding module encodes each K-level SID via prefix n-gram sparse tables trained end-to-end under the CTR objective, with cold-start gains reaching +1.522% for near-zero-history users on a production decoder-only Transformer ranker.
