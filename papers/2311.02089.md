## Summary

Current recommendation methods often rely on slow, training-free LLM inference or lack the ability to handle complex user interactions effectively. To address this, the paper introduces LlamaRec, a two-stage framework using LLMs specifically for ranking-based recommendation. It first uses a small sequential model to retrieve relevant items, then uses a carefully designed prompt and a novel verbalizer approach to efficiently rank these items using the LLM's logits, bypassing slow text generation. Experimental results show that LlamaRec achieves superior recommendation performance and efficiency compared to state-of-the-art methods on benchmark datasets.

## Technical note

LlamaRec is a two-stage (retrieve-then-rank) recommendation framework that makes LLM-based ranking efficient enough for real-time use. A small ID-based sequential recommender (LRURec, using linear recurrent units) retrieves the top-20 candidates from user history; these plus history are formatted into a prompt for a fine-tuned Llama 2 (7B, tuned with QLoRA). Rather than autoregressively generating item titles, it uses a verbalizer that maps candidate items to index letters and reads the LLM head's next-token logits over those letters, producing scores for all candidates in a single forward pass. This avoids beam search and long-text generation, cutting inference time and memory. On the ML-100k, Beauty, and Games benchmarks LlamaRec outperforms state-of-the-art baselines in both accuracy and efficiency.
