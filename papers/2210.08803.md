## Summary

Merlin HugeCTR is an open-source framework designed to accelerate GPU-based recommender system training and inference for click-through rate prediction, optimizing both processes through model-parallel embeddings and data-parallel neural networks.

It achieves high performance by integrating a GPU embedding cache with hierarchical storage, enabling rapid embedding lookups crucial for online inference, and was shown to significantly outperform PyTorch in MLPerf training benchmarks.

Furthermore, Merlin HugeCTR supports multi-node training and includes a hierarchical parameter server (HPS) for substantial speedups (5-62x) and latency reduction in inference compared to CPU-based systems, also offering deployment via the NVIDIA Triton server framework.

## Technical note

Merlin HugeCTR is an open-source, GPU-accelerated framework for click-through-rate model training and inference that uses model-parallel embedding tables and data-parallel dense networks. It offers localized, distributed, and hybrid sparse embedding layouts, an Embedding Training Cache for terabyte-scale on-demand and online/incremental training, multi-node training via NCCL, and mixed-precision (FP16/TensorCore) support. For inference, a Hierarchical Parameter Server (HPS) provides a 3-level cache (GPU HBM, CPU/Redis volatile DB, SSD persistent DB) to hold huge embedding tables and keep hot embeddings on-GPU. On the MLPerf v1.0 DLRM benchmark it achieves up to 24.6x speedup on a single DGX A100 over a 4x4-socket CPU PyTorch baseline, and HPS delivers 5-62x inference speedups over CPU baselines, with deployment via NVIDIA Triton and Keras-like Python/ONNX interfaces.
