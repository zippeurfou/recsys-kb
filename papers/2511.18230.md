## Summary

1.  Securing resource-constrained IoT devices against cyberattacks is challenging; this paper presents an edge-based Intrusion Detection System (IDS) addressing these limitations.
2.  The system integrates lightweight ML-based IDS models with LLMs at the edge gateway, using ML for detection and LLMs for generating detailed, human-readable threat analyses and recommendations.
3.  Evaluations show the system achieves high detection accuracy (up to 98%), provides actionable insights, and operates efficiently with low latency, minimal bandwidth, and energy consumption.

## Technical note

This paper proposes an edge-centric intrusion detection framework that pairs six lightweight ML classifiers (DT, KNN, RF, CNN, LSTM, CNN+LSTM) deployed on low-power gateways with pre-trained LLMs (GPT-4-turbo, DeepSeek-V2, LLaMA 3.5) for semantic reasoning. On CICIDS2017, classical models reach ~99% accuracy; upon anomaly detection, a compact normalized telemetry snapshot is sent via low-bandwidth API calls to LLMs using zero-shot, few-shot, and chain-of-thought reasoning to produce human-readable threat analyses and mitigations. Evaluated across DoS, DDoS, brute force, and port scanning, it maintains <1.5s latency, <1.2 kB prompts, and <75 J energy while improving interpretability.
