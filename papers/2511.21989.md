## Summary

This paper introduces a novel approach to improve cold-start item recommendations in traditional recommendation systems using Large Language Models (LLMs). It proposes a reinforcement learning framework where an LLM learns a policy to select specific user histories for generating synthetic interactions with cold-start items, aiming to optimize recommendation performance. Experiments on Amazon datasets show that this method significantly improves cold-start item recall and is presented as a scalable augmentation strategy.

## Technical note

This paper improves cold-start item recommendation by using an LLM to simulate a user and generate synthetic interactions for new items, then training a traditional two-tower recommender on the augmented data. Its key contribution is a reinforcement-learning policy, trained with a REINFORCE-style policy gradient in a contextual-bandit setup (binary select/not-select action per user), that chooses which users' full histories to feed the LLM so as to maximize post-augmentation cold-start performance. Providing entire user histories lets the LLM better emulate the user, and pairwise preference prompting over two cold-start items mitigates popularity bias. Experiments on Amazon Product Review datasets show substantial cold-start item recall gains and serving efficiency since LLM calls scale with users, not interactions.
