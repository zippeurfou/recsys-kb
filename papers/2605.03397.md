## Summary

Traditional POI retrieval methods often fail general map searches due to ambiguous user queries and difficulty understanding complex, context-dependent search intents. The paper introduces GenPOI, a generative framework that uses Large Language Models (LLMs) to model these complex intents by representing POIs as structured sequences incorporating both semantic and geographic context. Extensive experiments show GenPOI significantly outperforms existing methods on large-scale datasets, demonstrating its effectiveness in handling challenging map search queries.

## Technical note

GenPOI reframes POI retrieval for general map search as an LLM generative-retrieval task, unifying textual queries, geographic coordinates, user profiles, and historical behaviors into a single context sequence. It introduces Geo-Semantic POI Tokenization, encoding each POI into a compact discrete PID capturing both semantic attributes and geographic location so the LLM perceives 'what it is' and 'where it is'. A proximity-aware constrained generation strategy restricts the decoding space to guarantee validity and geospatial plausibility and prevent hallucinated POIs. Experiments on Tencent Map industrial data at 10M+ POI scale show GenPOI outperforms neural embedding and prior generative baselines on underspecified queries.
