## Technical note

IP-DiskANN (InPlaceUpdate-DiskANN) is the first proximity-graph ANNS algorithm to process each insertion and deletion in-place, avoiding the batch consolidation used by state-of-the-art FreshDiskANN to handle streaming updates. It solves the hard problem of deletions in singly-linked graphs without periodic edge cleanup, maintaining stable recall over long update sequences in both high- and low-recall regimes. Standard-benchmark experiments show better query throughput and update speed than batch consolidation and HNSW, targeting search, recommendation, and RAG vector indexes.
