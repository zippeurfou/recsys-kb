## Technical note

FlowTime proposes Continuous Generative Regression as a fourth watch-time-prediction paradigm, arguing direct regression suffers mean-collapse, ordinal regression suffers quantization error, and discrete generative regression suffers high latency. From a causal view it identifies user-item interaction patterns as structural confounders that make identical interests yield different watch-time distributions. FlowTime uses a one-step generative VAE (avoiding iterative denoising latency) plus a Flow-based Personalized Prior that warps a Gaussian prior into a history-conditioned manifold via normalizing flows to model multimodal distributions. It also releases TimeRec, the first open-source WTP library, and a personalization metric; offline experiments and online A/B tests show FlowTime beats SOTA methods.
