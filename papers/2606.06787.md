## Summary

Current large language models (LLMs), despite their promise as tool-using agents, struggle significantly with long-duration tasks due to inadequate memory capabilities.

Many existing memory solutions either focus solely on storing facts or rely heavily on procedural memory which doesn't effectively handle failures and scales poorly online.

The authors introduce AdMem, a novel unified memory framework that automatically integrates semantic, episodic, and procedural memories using a multi-agent system (actor, memory, critic) for generation, evaluation via rewards, merging, pruning, and adaptive retrieval.

## Technical note

AdMem is a unified, automatic memory framework for long-horizon tool-using LLM agents that integrates semantic, episodic, and procedural memory in a bi-level design combining short-term and long-term stores. It formalizes agent decision-making as a POMDP where the agent state is its memory, and uses a multi-agent architecture of actor, memory, and critic agents to generate memory, annotate rewards, and perform adaptive retrieval. Unlike prior procedural-memory work that merely replays past successes, AdMem's critic agent caches action scenarios, compares actual outcomes against expected outcomes the actor states in advance, and annotates procedural entries with guidance to target the critical steps agents typically fail, addressing credit assignment under sparse binary feedback. Long-term memory is scaled online through reward-based evaluation, merging, and pruning, improving robustness and success on long multi-turn tasks over baselines.
