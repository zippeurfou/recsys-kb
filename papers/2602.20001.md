## Summary

FairFS addresses biases in deep feature selection for recommender systems, specifically tackling layer bias, baseline bias, and approximation bias that lead to inaccurate feature importance estimation. The proposed method regularizes feature importance across all layers, introduces a smooth baseline feature, and uses an aggregated approximation technique to mitigate these issues. Experiments show FairFS effectively reduces these biases and achieves state-of-the-art performance in feature selection.

## Technical note

FairFS is a model-agnostic feature (field) selection framework for deep recommender/CTR models that identifies and mitigates three biases in feature-importance estimation: layer bias (gate-based methods ignore downstream non-linear layers), baseline bias (zero/mean baselines misclassify samples near the decision boundary), and approximation bias (first-order Taylor sensitivity error grows with distance to the baseline). It defines importance as the loss difference between informative and non-informative features, sparsifies sensitivity-based importance as a regularizer to account for all non-linear layers, derives two principles and a closed-form smooth baseline feature near the classifier decision boundary, and uses an integrated-gradients-style aggregated approximation over equidistant anchor points to drive approximation bias toward zero. Public-dataset experiments and an ads-platform A/B test show SOTA feature selection.
