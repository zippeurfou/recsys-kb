## Summary

1.  Visual document retrieval using Vision-Language Models (VLMs) struggles due to scattered crucial evidence across complex document layouts hindering effective embedding learning.
2.  ReAlign addresses this by using a VLM's reasoning ability to generate fine-grained, region-focused descriptions of query-relevant parts of a document page, serving as precise supervision signals.
3.  The retriever is trained using these descriptions to better align query semantics with specific document regions, leading to improved retrieval performance across various benchmarks and VLM backbones.

## Technical note

ReAlign improves VLM-based visual document retrieval by using a high-capacity VLM (Qwen2.5-VL-72B) to localize query-relevant bounding boxes and generate region-focused descriptions as fine-grained supervision. During training it adds a KL-divergence regularizer that aligns the ranking distribution induced by the region description with the ranking distribution induced by the original query (query distribution as teacher), on top of the standard InfoNCE contrastive loss with 63 in-batch negatives; the balance weight lambda=0.2 is optimal. Retrievers initialized from Phi3V-4B and Qwen2.5-VL-7B, trained with LoRA, gain ~2% NDCG on six benchmarks. Analysis shows improved embedding alignment/uniformity and higher attention-vs-relevance IoU, i.e. attention concentrates on evidence regions.
