## Summary

This paper addresses the challenge of evaluating podcast recommendations by proposing a Profile-Aware LLM-as-a-Judge system. It works in two stages: first creating natural language user profiles from listening history to capture interests and behaviors, then using these concise profiles with an LLM prompter for efficient pointwise/pairwise judgments matching human evaluations. The key benefit is that this profile-based approach provides interpretable context for the LLM assessment, reducing input complexity while improving evaluation performance compared to raw data methods.

## Technical note

This paper proposes a profile-aware LLM-as-a-Judge framework for offline evaluation of podcast recommendations, addressing exposure bias in offline metrics and the cost of A/B tests. Stage one distills a natural-language user profile (topical interests and behavioral patterns) from 90 days of listening history; stage two prompts an LLM with this compact profile plus candidate episode metadata to make pointwise (episode-fits-user) and pairwise (compare two ranked lists) judgments. Using profiles instead of raw histories reduces input complexity and improves interpretability. In a 47-participant study the profile-aware judge matched human judgments with high fidelity and met or beat a raw-history variant, enabling scalable pre-deployment model selection.
