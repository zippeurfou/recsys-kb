## Summary

1.  Existing automatic prompt optimization methods create task-specific prompts but lack generalizability and the ability to accumulate reusable knowledge.
2.  The paper introduces MemAPO, a framework that stores successful reasoning strategies and common error patterns in memory, allowing it to retrieve and apply this knowledge for new prompts.
3.  MemAPO improves over time through self-reflection and memory updates, leading to consistently better performance and significantly lower optimization costs compared to standard methods.

## Technical note

MemAPO reframes automatic prompt optimization (APO) from task-specific prompt search into generalizable, self-evolving experience accumulation for LLMs. It maintains a dual memory that distills successful reasoning trajectories into reusable strategy templates and abstracts incorrect generations into structured error/failure patterns. For a new query it retrieves both relevant strategies and failure rules to compose a prompt p = [p_Inst, p_Mem(q)] that encourages effective reasoning while discouraging known mistakes, updating memory through iterative self-reflection. Across diverse reasoning benchmarks and two backbones it outperforms baselines like TextGrad while cutting optimization cost (token/API usage) by roughly 57%, since it amortizes optimization via experience reuse rather than restarting per task.
