## Technical note

YOLOR (You Only evaluate Once) is a one-stage reranking method for Meituan that removes the General Search Unit (GSU) and keeps only the Exact Search Unit (ESU), eliminating the GSU-ESU inconsistency where high-value lists get filtered out. A Tree-based Context Extraction Module (TCEM) hierarchically aggregates multi-scale contextual features for list-level effectiveness, and a Context Cache Module (CCM) reuses features across candidate permutations for permutation-level efficiency. Experiments on public and industrial datasets validate performance, and YOLOR is deployed on the Meituan food-delivery platform.
