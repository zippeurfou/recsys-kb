## Summary

This paper addresses a key issue in recommender systems where two-stage reranking approaches sacrifice list-level effectiveness for efficiency by missing high-value options during the initial candidate filtering. They introduce YOLOR (You Only Evaluate Once Level Rerank), a novel one-stage reranking method designed to eliminate this trade-off, effectively replacing the traditional inefficient General Search Unit (GSU). YOLOR achieves both "list-level effectiveness" through hierarchical feature extraction and "permutation-level efficiency" via context caching, successfully deployed on Meituan's food delivery platform.

## Technical note

YOLOR is a one-stage listwise reranking method that removes the two-stage GSU/ESU search paradigm to eliminate the inconsistency problem where a coarse General Search Unit misses high-value lists. It uses a Tree-based Context Extraction Module (TCEM) to aggregate multi-scale contextual features across item subsequences for list-level effectiveness, and a Context Cache Module (CCM) that reuses cached context representations across candidate permutations for permutation-level efficiency. Training combines cross-entropy with a Group-BPR intra-list contrastive loss, and the ranking model is reused directly as the item-representation module for pipeline consistency. On Taobao Ad and Meituan datasets it improves AUC/GAUC over PRM, MIR, Edge-Rerank and PIER, traverses all 40,320 permutations within 50ms, and delivered +5.13% CTR and +7.64% GMV in a Meituan A/B test.
