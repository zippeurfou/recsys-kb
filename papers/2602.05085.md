## Summary

This paper introduces Locas, a parametric memory mechanism designed to integrate with transformer models for efficient test-time training and continual learning. Locas utilizes locally-supported FFN blocks, offering two variants (a simpler MLP version and a GLU-FFN version matching state-of-the-art models), and can be flexibly merged into model parameters. The authors emphasize that Locas requires principled initialization using model parameters, activations, or gradients for effective performance, including fast convergence and forgetting prevention, and demonstrate its ability to store context efficiently with minimal parameter overhead.

## Technical note

Locas is a locally-supported parametric memory that shares the FFN block structure of transformers so it can be merged into model parameters or offloaded, enabling efficient test-time training and continual learning. It reinterprets FFNs as soft look-up-table memories and offers two variants: Locas-MLP (two-layer MLP with closed-form step-wise-optimal initialization) and Locas-GLU (matching SOTA GLU-FFN, initialized via activation-guided parameter cloning into the FFN's principal subspace). A Non-Linear SVD compresses the memory to low latent dimension. On PG-19 whole-book LM and LoCoMo QA, Locas-GLU stores past context with as little as 0.02% extra parameters and minimal MMLU degradation, showing reduced catastrophic forgetting.
