## Summary

RNNs with Growing Memory":

1.  The paper addresses the high computational cost (quadratic complexity) of Transformers' growing memory capacity, which motivated exploring efficient recurrent alternatives like RNNs.
2.  It introduces Memory Caching (MC), a technique that allows RNNs to effectively grow their memory capacity with the sequence length by caching past hidden states, offering a flexible complexity-performance trade-off.
3.  MC variants significantly improve RNN performance on language modeling and long-context tasks, achieving competitive results close to Transformers, particularly in recall-intensive tasks, outperforming existing state-of-the-art RNN models.

## Technical note

Memory Caching (MC) enhances subquadratic recurrent sequence models by segmenting the sequence and caching each segment's compressed memory (hidden) state, letting each query attend to cached memories plus the online memory so effective capacity grows with sequence length at O(NL) cost, interpolating between RNN O(L) and Transformer O(L^2). Four aggregation variants are proposed: Residual Memory (summation), Gated Residual Memory with input- and segment-content-dependent gating (via similarity to mean-pooled segments) so it does not collapse to fixed memory, Memory Soup that averages cached memory-module parameters, and Sparse Selective Caching using an MoE-style router to pick relevant cached memories. It builds on the nested-learning / Miras attentional-bias view of memory as test-time optimization and validates on Linear Attention, Titans, and Deep Linear Attention across language modeling, long-context, and recall tasks, closing the gap to Transformers on in-context recall.
