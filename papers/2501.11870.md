## Summary

This paper addresses a key trade-off in recommendation systems: balancing efficient, lightweight embeddings for on-device use with capturing fine-grained semantic nuances previously overlooked. The authors propose a novel GNN-based recommender system architecture featuring both coarse- and fine-grained virtual nodes connected directly or indirectly to users and items as entities. This structure enables the model to learn varied levels of semantics effectively while keeping meta-embeddings sparse through specific initialization and activation methods, leading to superior recommendations compared to existing baselines.

## Technical note

Memory-constrained (e.g., on-device) recommenders use meta-embedding codebooks but only capture coarse-grained semantics, missing fine-grained nuance. This work (C2F-MetaEmbed) builds a GNN recommender where each user/item node links directly to coarse-grained virtual nodes and indirectly to fine-grained virtual nodes, enabling multi-grained semantic learning. Fine-grained meta-embeddings are made sparse via SparsePCA-based initialization and a soft-thresholding activation, and a weight-bridging update strategy matches each coarse meta-embedding to several fine-grained ones by semantic relevance. Experiments show gains in both accuracy and memory efficiency over lightweight-embedding baselines.
