## Summary

This paper addresses **Multi-Modal Cross-Domain Recommendation (MMCDR)**, where items have multiple types of information but user overlap between domains is minimal. Existing methods struggle due to ineffective item clustering across different modalities and inadequate knowledge transfer when most users are non-overlapped. To overcome these limitations, the authors propose a novel model called **SIEOUG**, which clusters similar items (reducing noise), uses collaborative filtering for recommendations, and facilitates knowledge sharing specifically between overlapped users. Empirical results on Amazon data show that SIEOUG significantly outperforms previous state-of-the-art models in this challenging setting.

## Technical note

SIEOUG addresses multi-modal cross-domain recommendation (MMCDR) where items carry text/image modalities and few users overlap across domains, causing data sparsity. It has three modules: a similarity item exploration module that builds a robust pair-wise item-item graph plus a sparse group-wise item hypergraph via a Gromov-Wasserstein metric to cluster similar items and denoise modalities; a user-item collaborative filtering module aggregating graph and hypergraph info with attention; and an overlapped user guidance module that performs guidance-based optimal user matching to transfer knowledge and reduce negative transfer. Using CLIP-derived visual and text features, it jointly exploits pair-wise and group-wise item similarity for the first time. Experiments on Amazon cross-domain tasks show SIEOUG significantly outperforms state-of-the-art MMCDR baselines.
