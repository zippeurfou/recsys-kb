## Summary

Multi-scenario multi-task recommendation (MSMTR) systems face challenges with complex architectures and information flow noise. To address these, the authors propose AutoIFS, a lightweight framework that decouples information units using low-rank adaptation for efficiency and includes an automatic selection network to prune irrelevant information flows. Extensive experiments on benchmarks and an online A/B test demonstrate that AutoIFS effectively improves model performance while reducing complexity.

## Technical note

AutoIFS addresses multi-scenario multi-task recommendation (MSMTR), where scenario-shared/specific and task-shared/specific units produce four relationship information flows that prior MoE-based models fuse indiscriminately with heavy parameter cost. It uses low-rank adaptation (LoRA) adapters per scenario/task to decouple the four information units for lightweight, flexible fusion, and adds an information-flow-selection network with a pruning mask to automatically drop irrelevant or harmful flows based on performance feedback. Experiments on two public benchmarks plus an online A/B test confirm improved CTR/CVR accuracy with reduced complexity.
