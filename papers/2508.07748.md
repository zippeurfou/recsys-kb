## Summary

(Abstract fallback)

Building universal user representations that capture the essential aspects of user behavior is a crucial task for modern machine learning systems. In real-world applications, a user's historical interactions often serve as the foundation for solving a wide range of predictive tasks, such as churn prediction, recommendations, or lifetime value estimation. Using a task-independent user representation that is effective across all such tasks can reduce the need for task-specific feature engineering ...

## Technical note

For the RecSys Challenge 2025 (Synerise Universal Behavioral Profiles), merges each user's heterogeneous events (buys, cart actions, page visits, search queries) into one chronological sequence and trains a GRU-based sequence autoencoder to reconstruct all categorical fields from a fixed-size latent vector, with teacher forcing and the user embedding injected at each decoder step. This task-agnostic embedding is combined in an ensemble with GPT-2-style next-event transformers (Next URL, Next product), iALS, LightFM, SmolLM2-135M text embeddings, and handcrafted features, using PCA plus unit-length normalization before concatenation into a 1066-dim vector. The GRU-AE alone was the strongest single model, and the ensemble scored 4.7504 sum / Borda 653 across six downstream tasks (churn, category/product propensity, and hidden conversion/new-product/price tasks), earning team ai_lab_recsys 2nd place overall and 1st on the academic leaderboard.
