## Technical note

Kuaishou's CardRewriter is a retrieval-augmented LLM framework for long-tail query rewriting on short-video platforms, where proprietary content (short videos, live streams, micro dramas) lies outside LLM pretraining. For each query it aggregates multi-source knowledge from top-k retrieved videos and open-domain documents into a concise, query-relevant knowledge card that guides the LLM to capture intent and produce effective rewrites. It is trained with SFT followed by GRPO using a reward system balancing query relevance and retrieval effectiveness. Offline experiments show substantial rewrite-quality gains, and online A/B testing yielded higher long-view rate and CTR plus reduced initiative query reformulation rate; deployed on Kuaishou since September 2025.
