## Summary

This paper addresses ContextGNN, a Graph Neural Network architecture designed for relational deep learning tasks like recommendation systems. While ContextGNN showed improved performance on real-world datasets, its application to standard static link prediction (personalized item recommendation) using benchmark data was less explored until now. The authors tackled this gap by integrating ContextGNN into the Elliot framework and conducting preliminary experiments against six state-of-the-art GNN-based recommenders on three standard datasets, finding similar trends but highlighting opportunities for improvement on traditional benchmark tasks.

## Technical note

This reproducibility-oriented paper integrates ContextGNN, a relational-deep-learning recommender, into the Elliot benchmarking framework (~50 models) to evaluate it on the traditional static link prediction / personalized item recommendation task. ContextGNN uses a hybrid scoring scheme: a pair-wise GNN score for items inside a user's k-hop subgraph and a two-tower score with a static item embedding matrix for exploratory items, fused via a learned MLP gate. Reproducing results on Gowalla, Yelp 2018, and Amazon Book against six GNN baselines (NGCF, DGCF, LightGCN, SGL, UltraGCN, GFCF) confirms ContextGNN beats older message-passing models but still trails advanced ones like UltraGCN and GFCF. The contribution is a ready-to-use tool to benchmark RDL recommenders reproducibly.
