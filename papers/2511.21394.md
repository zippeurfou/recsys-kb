## Summary

This paper introduces RIA, a unified end-to-end framework designed to improve listwise CTR prediction by integrating ranking and reranking processes. RIA combines four key components to model user behavior, item dependencies, and improve efficiency, allowing for better contextual knowledge transfer. It significantly outperforms existing methods on various datasets and has shown substantial improvements (+1.69% CTR, +4.54% CPM) in a deployed recommendation system.

## Technical note

RIA (Ranking-Infused Architecture) is a unified end-to-end framework that fuses pointwise ranking and listwise reranking for CTR prediction, addressing the combinatorial sparsity of rare item co-exposures and the representational gap from decoupled rerankers. It has four modules: a User and Candidate Dual-Transformer (UCDT) for fine-grained candidate-context interaction via HSTU plus target attention, a Context-aware User History and Target (CUHT) module with page-level self-attention and position-aware target attention over permutation-level session behaviors, a Listwise Multi-HSTU (LMH) for hierarchical cross-item dependencies, and an Embedding Cache (EC) for inference efficiency. Sharing representations across ranking and reranking, RIA beats SOTA on public/industrial data and delivers +1.69% CTR and +4.54% CPM in Meituan A/B tests.
