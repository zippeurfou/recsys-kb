## Technical note

SocRipple is a two-stage cold-start retrieval framework for video distribution on Meta's social platforms. Stage 1 seeds a new item to the creator's social followers for high-precision initial exposure; Stage 2 'ripples' outward via KNN search over stable pre-computed two-tower user embeddings using early engagers as anchors. Large-scale experiments show +36% cold-start item distribution while maintaining engagement rate, balancing new-item exposure against personalization.
