## Summary

Large Language Model (LLM) inference is hampered by memory bottlenecks from the Key-Value (KV) cache. The paper introduces "Kitty," a system for efficient 2-bit KV cache quantization. Kitty achieves nearly 8x KV memory reduction with minimal accuracy loss by using a novel "Dynamic Channel-wise Precision Boost" technique that selectively preserves critical channels at higher precision, along with system optimizations for efficient hardware execution.

## Technical note

Kitty is an algorithm-system co-design for 2-bit KV cache quantization that closes the accuracy gap where prior 2-bit methods (KIVI) degrade long-context reasoning. Its Dynamic Channel-wise Precision Boost ranks Key-cache channels by quantization sensitivity and keeps only a small fraction at 4-bit while compressing the rest to 2-bit; to keep layout coalesced it decomposes each mixed-precision Key page into two uniform 2-bit tensors. It adds a page-centric KV layout, Triton dequantization kernels, and a runtime pipeline avoiding scattered reads. Across seven tasks on Qwen3 and LLaMA3, Kitty cuts KV memory nearly 8x with negligible accuracy loss, enabling up to 8x larger batches and 2.1x-4.1x higher throughput.
