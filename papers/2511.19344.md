## Summary

Traditional continual learning methods rely heavily on constant access to labeled data, a unrealistic assumption for many real-world scenarios. This paper introduces **Annotation-Free Class-Incremental Learning (AFCIL)**, tackling the challenge of learning new classes from entirely unlabeled data arriving incrementally. To address this, the authors propose **CrossWorld CL**, a framework that leverages external world knowledge (via aligned ImageNet representations) as an auxiliary guide, enabling semantic understanding without supervision while preserving prior knowledge. Their method significantly outperforms existing baselines across multiple datasets, demonstrating the value of world knowledge in this challenging new paradigm.

## Technical note

The paper introduces Annotation-Free Class-Incremental Learning (AF-CIL), a paradigm where unlabeled data arrives sequentially and the learner must acquire new classes without supervision while avoiding catastrophic forgetting and stored exemplars. Its CrossWorld-CL framework injects external world knowledge by retrieving semantically related ImageNet classes for each downstream category and mapping downstream and ImageNet features through a cross-domain alignment strategy plus a novel replay strategy. This lets the model recover semantic structure without labels while preserving prior knowledge, unlike purely visual self-supervised methods (SimCLR, BYOL, MoCo, DINO) that struggle when task semantics shift. Across four datasets it surpasses CLIP baselines and existing continual and unlabeled-learning methods.
