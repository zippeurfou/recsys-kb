## Summary

Online platforms often struggle with near-duplicate items, negatively impacting user experience. Existing deduplication methods using MLLMs treat item representations as black boxes, ignoring crucial structural relationships (like primary vs. auxiliary elements) and leading to the "local structural collapse" problem. To address this, inspired by Feature Integration Theory, the paper introduces FITRep, an attention-guided, white-box framework that extracts hierarchical concepts, preserves structure during dimensionality reduction, and clusters items efficiently, achieving significant online performance improvements (+3.60% CTR, +4.25% CPM).

## Technical note

FITRep is a white-box, attention-guided item-representation framework for near-duplicate item deduplication that, unlike black-box MLLM embeddings, avoids 'local structural collapse' where items differing only in primary material get spuriously high similarity. Inspired by Feature Integration Theory, it has three stages: Concept-Hierarchical Information Extraction (CHIE) prompting an MLLM to extract dimension-specific hierarchical concepts encoded by a text encoder; Structure-Preserving Dimensionality Reduction (SPDR) via adaptive parameterized UMAP per concept dimension; and FAISS-Based Clustering (FBC) that applies per-dimension attention weights (plus a nonlinear angular quantity mapping) to assign each item a cluster id at ten-million-item scale. Deployed on Meituan's advertising system it yields +3.60% CTR and +4.25% CPM.
