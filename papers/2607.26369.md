## Summary

1.  The authors propose ClockRoPE, an enhancement to Rotary Position Embedding (RoPE) specifically designed for modeling temporal routines in sequential recommendation systems, addressing RoPE's limitations in capturing complex periodic distance correlations.
2.  Based on mathematical theory connecting attention modulation functions and Fourier transforms, they show that any such function can be approximated by random rotations derived from its own Fourier features.
3.  ClockRoPE leverages this principle using specific periodic modulation functions for rotation frequencies, leading to demonstrable improvements in engagement metrics during online tests and successful deployment in a production system.

## Technical note

ClockRoPE is a temporal position-encoding method for transformer-based sequential/generative recommendation that models user routines (daily and weekly periodicity), deployed in a production generative-retrieval system at a major video-sharing platform (Google). It rests on Random Fourier Rotations, a proof that any normalized continuous positive-definite attention-modulation function can be unbiasedly approximated by RoPE-style query/key rotations whose frequencies are sampled from that function's Fourier transform, and derives rotation frequencies from periodic cosine or periodic-Gaussian priors (symmetric or direction-aware folded). It adds no extra input features or model dimensions and complements standard RoPE (RoPE supplies recency decay, ClockRoPE supplies periodicity). Offline it improves MAP@1 up to +3.61%; online, RoPE+ClockRoPE lifts valued engagement +0.08% and cuts TPU serving cost 0.63%. The base model is generative retrieval feeding a downstream ranking model, so the retrieval-ranking cascade is retained.
