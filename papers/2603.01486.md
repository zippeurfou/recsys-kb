## Summary

1.  The paper addresses the challenge of accurately mapping ambiguous, context-sparse user queries (like "Wildflower") to the correct business category in multi-vertical marketplaces, where traditional classifiers fail and general LLMs can hallucinate unavailable options.
2.  The proposed solution, Agentic Multi-Source Grounding, overcomes these issues by grounding LLM inference in a staged catalog retrieval system and autonomously using web search for ambiguous queries, outputting ordered multi-intent sets instead of single labels.
3.  This system, featuring configurable disambiguation rules, significantly improves accuracy (+10.9pp over an ungrounded LLM baseline) and is deployed in production, serving over 95% of DoorDash's daily search queries, demonstrating a generalizable approach for resolving ambiguous intent at scale.

## Technical note

This DoorDash system addresses query intent understanding for a multi-category marketplace where short queries (e.g. 'Wildflower') are ambiguous across verticals. It grounds an LLM in two evidence sources: a staged catalog retrieval pipeline (ANN dense retrieval followed by weighted fuzzy re-ranking) and an agentic web-search tool invoked autonomously for cold-start queries. Rather than winner-takes-all classification, it emits an ordered dual-intent set resolved by a configurable pairwise disambiguation layer based on historical win rates. Deployed on >95% of daily search impressions, it gains +10.9pp over an ungrounded LLM and +4.6pp over the legacy BERT+LLM system.
