## Summary

1.  The current generation of web agents relies on brittle, low-level operations (like clicks) for task execution, leading to inefficiency and unreliability.
2.  To address this, the paper introduces "Web Verbs," a semantic layer of typed, documented functions representing stable web actions, providing a uniform interface for agents to discover, select, and compose reliable tasks.
3.  Web Verbs improve agent reliability, efficiency, and verifiability by offering stable interfaces, reducing complex tasks into simple calls, and enabling auditable workflows through typed contracts and verifiable traces.

## Technical note

This position paper argues that a reliable agentic web requires shifting from low-level interaction primitives (clicks, keystrokes, DOM manipulation) to typed actions exposed by a semantic layer. It proposes 'web verbs': typed, documented functions that expose a web operation with structured inputs/outputs, backed either by server-side Web APIs or maintained client-side workflows (e.g. Playwright), and carrying preconditions, postconditions, policy tags, and logging hooks. Verb-level composition lets agents synthesize concise programs with explicit control and data flow and produce checkable, reproducible execution traces, improving reliability, efficiency, and auditability over brittle low-level traces. It positions verbs as complementary to content-side efforts like NLWeb/Schema.org (what an agent knows) by defining what an agent can do, and closes with a call to action on standardization, developer tooling, and community processes. (Note: an agentic-web position paper, not recommender systems.)
