## Summary

This paper addresses challenges in generative recommendation using autoregressive models. Conventional methods suffer from a probability-reward mismatch and decoding issues leading to poor exploration and weak RL signals. The authors propose V-STAR, a framework combining value-guided sampling for better exploration and a sibling-relative advantage method for focused learning, which significantly outperforms existing techniques.

## Technical note

V-STAR addresses the probability-reward mismatch in RL fine-tuning of autoregressive generative recommenders over Semantic-ID prefix trees, targeting insufficient exploration and advantage compression from beam search. Value-Guided Efficient Decoding (VED) trains a prefix value function with semantic-aware dense TD supervision, then allocates a fixed decoding budget via a UCB-style score combining value and policy entropy to expand only decisive high-value/high-ambiguity prefixes. Sibling-GRPO computes group-relative advantages within sibling nodes under the same parent prefix, concentrating gradients on branching decisions and mitigating advantage collapse. On Amazon Industrial/Office it beats MiniOneRec (e.g., +4.0% HR@3) and yields +1.23% GMV in WeChat Channels online tests; inference reverts to standard beam search.
