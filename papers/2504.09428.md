## Summary

Online game friend recommendation systems need to effectively use diverse user features like images and text descriptions alongside complex friendship network structures for better suggestions. Existing methods fall short by ignoring higher-order social relationships or failing to properly learn relevance at specific feature types (modalities). To overcome these limitations, the authors propose FROG, an end-to-end model designed specifically to capture modality-aware user preferences against different features and both local and global friendship information.

FROG addresses three key shortcomings: it models high-order structural proximity beyond simple pairwise connections, learns relevance between users considering each feature type separately (modality-specific level), and captures detailed local and broad global user preferences across various data types. The paper concludes that FROG outperforms current techniques based on both offline experiments simulating different evaluation scenarios and real-world online deployment results at Tencent during actual game operations.

## Technical note

FROG is an end-to-end friend-recommendation model for Tencent online games that fuses multimodal user features (profile images via EfficientNet+MoCo, nicknames via a transformer encoder, and friendship-graph structure via GraphSAGE). Its Matching-Net learns modality-specific pairwise relevance between two users using attention-derived relevance vectors incorporating high-order topology, while a Local-Net and Global-Net (shared multimodal global attention) capture per-instance and population-level modality importance, combined in a Joint-Net trained with focal loss. On two Tencent game datasets FROG beats FM/DeepFM/AutoInt/GraFRank/EBR by up to 15.8% HR and 14.6% NDCG, and an online A/B test in an FPS game improved acceptance rate and interaction rate by 33.3% and 25.5%.
