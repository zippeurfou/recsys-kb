## Technical note

FROG is an end-to-end friend-recommendation model for online games at Tencent that fuses multi-modal user features (images, texts, in-game attributes) with friendship-graph structure, addressing prior methods that ignore high-order structural proximity or fail to model modality-specific preferences. It captures both local and global user preferences across modalities to rank potential friends, moving beyond proximity-only methods like Personalized PageRank and triadic closure. Offline evaluation and online deployment at Tencent demonstrate FROG's superiority over existing approaches; code is released.
