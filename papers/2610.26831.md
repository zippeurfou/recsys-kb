## Summary

Existing generative retrieval systems struggle to effectively and efficiently use diverse features found in large-scale search systems, often leading to irrelevant or conflicting evidence due to static feature injection methods. To overcome this, the authors propose Agentic Generative Retrieval (AGR), which dynamically integrates features by interleaving hierarchical Semantic ID (SID) generation with on-demand feature acquisition, guided by tool invocations. Experiments on industrial and public datasets, including online testing, demonstrate that AGR significantly improves retrieval quality by adaptively focusing on relevant features during generation.

## Technical note

Generative retrievers in Kuaishou Search inject heterogeneous features (intent, location, freshness, long behavior sequences) statically, which the authors show is neither request-adaptive (static injection lowers perplexity on feature-consistent requests but raises it on conflicting ones) nor level-adaptive across the coarse-to-fine RQ semantic-ID hierarchy, while inflating serving cost. Agentic Generative Retrieval (AGR) extends the vocabulary with tool and observation tokens so a 574M BART encoder-decoder decides at each SID step whether to invoke a tool and which feature to fetch, and injects only the returned observation token (categorical values, or a next-SID vote / attention summary over the user sequence) to steer constrained beam search; tool tokens are not fed back, so the decoder still consumes one token per step. Training trajectories insert a tool at the depth where the feature most sharply narrows the candidate set (a log-proportion information-gain criterion), retained only when the feature agrees with the target, followed by SID pretraining then tool-augmented fine-tuning with adaptive tool-token loss scaling. AGR beats TIGER, a distilled-teacher TIGER, UniSearch, GLASS and GEMs on Industry, Qilin, JDSearch and KuaiSAR (Recall@50 0.3264 vs 0.2863 TIGER, up to +14.0% recall and +19.7% MRR), outperforms static, gated and fixed-position injection ablations, and in a 7-day 10%-traffic online A/B at 35 ms latency improves relevance +0.205%, query reformulation rate -0.690% and search penetration +0.06%.
