## Summary

This paper addresses challenges in evaluating Conversational Recommender Systems (CRSs), particularly those using Large Language Models (LLMs) for user simulation. Existing methods struggle with adapting to new domains and accurately modeling users' dynamic preferences and subtle linguistic styles, limiting valid evaluation.

The authors propose AdaptSim, an LLM-based User Simulator incorporating automatic prompt generation and an open action mechanism to overcome these limitations. This allows for more realistic dialogue behaviour across different domains without manual effort while capturing diverse user responses through a "think-then-respond" strategy controlling language style.

Furthermore, AdaptSim introduces a novel Breadth-First Search (BFS)-based evaluation framework focusing on pairwise comparisons at the turn level. Experiments show that AdaptSim effectively generates realistic dialogues and provides reliable evaluations of CRS capabilities and robustness across multiple domains and LLMs.

## Technical note

AdaptSim is an LLM-based user simulator for evaluating Conversational Recommender Systems that targets three weaknesses of prior simulators: poor domain adaptability, coarse user modeling, and low evaluation validity. It uses automatic prompt generation/optimization plus an open action-generation mechanism to transfer across domains without manual prompt/action engineering, and a 'think-then-respond' controlled-text-generation strategy to reproduce dynamic preferences and subtle linguistic styles (formality, sentiment, conciseness). For evaluating CRSs it introduces a Breadth-First-Search-based, turn-level pairwise comparison framework probing both fundamental capabilities and robustness. Experiments across three domains and four LLM backbones show more realistic, diverse dialogues and more reliable CRS assessment.
