## Summary

This paper identifies three key limitations of current Large Language Model (LLM) based user simulators for evaluating Conversational Recommender Systems (CRSs): lack of domain adaptability, poor user modeling, and insufficient evaluation validity. To address these challenges, the authors propose AdaptSim, an adaptive system incorporating automatic prompt tuning and an open action mechanism to enhance flexibility across domains and improve realistic behavior simulation with fine-grained language control via a "think-then-respond" strategy. Extensive experiments demonstrate that AdaptSim generates realistic dialogues reliably, enabling effective evaluation of CRS capabilities and robustness by producing diverse user styles for comprehensive assessment using a novel BFS-based framework.

## Technical note

AdaptSim is an LLM-based user simulator for evaluating Conversational Recommender Systems, addressing weak domain adaptability, coarse user modeling, and invalid evaluation. It uses automatic prompt generation/optimization, an open action-generation mechanism, and a controlled 'think-then-respond' strategy for fine-grained linguistic-style control, plus a BFS-based turn-level pairwise comparison for CRS assessment. Experiments across three domains and four LLM backbones show more realistic, diverse dialogues and more reliable capability/robustness evaluation of CRSs.
