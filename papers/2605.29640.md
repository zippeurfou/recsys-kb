## Summary

Large Language Models face challenges managing long-term state due to limited context windows and existing memory systems being simplistic or task-specific. To address this, the authors propose the Memory Base paradigm and its implementation, VikingMem, a system built on VikingDB. VikingMem uses event/entity abstractions and temporal compression to selectively extract, evolve, and prioritize memories, significantly improving long-term memory retrieval effectiveness (up to 30% better) while maintaining low latency for interactive applications.

## Technical note

VikingMem is a Memory Base Management System for stateful LLM applications, built on the VikingDB vector engine and framed around three principles: selective extraction of high-value memories from low-signal raw streams, inherent statefulness/evolution, and a generalizable event-entity abstraction. Events are schema-constrained, timestamped episodic records extracted via a two-phase LLM segmentation with single-pass multi-type extraction (reducing tokens by ~(k-1)x for k memory types); entities are persistent materialized views updated by operators (SUM, MAX, AVG, COUNT, LLM_MERGE, TIME_COMPRESS) through aggregate expressions, expressible as SELECT OP(event) FROM Events WHERE filters GROUP BY keys. Temporal compression via topic-wise timelines and time-weighted recall consolidates and fades old memories, and retrieval adds multi-vector reranking. In production at ByteDance it cuts storage by up to 83.2% and P95 retrieval latency by 900ms, outperforming baselines by up to 30-38% in retrieval effectiveness.
