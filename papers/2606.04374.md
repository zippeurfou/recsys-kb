## Technical note

DSIRM (Discrete Semantic Identifier Relevance Model) repositions Semantic IDs from generative-retrieval targets into supervised discrete relevance features for e-commerce ranking, addressing the weakness of unsupervised SID quantization at capturing fine-grained attribute distinctions. It uses query-bridged contrastive quantization on the item side -- applying InfoNCE over query-item pairs within an RQ-VAE so similar SIDs are assigned to items co-occurring with similar queries -- and an autoregressive LLM on the query side to predict item SIDs from text for tail/ambiguous intents, with hierarchical prefix matching producing discriminative features that complement dense embeddings. On Tmall production data it improves offline AUC by +1.54% and, deployed via a hybrid architecture, lifts UCTR +0.13% and UCTCVR +0.25%.
