## Summary

This paper introduces Fuxi-MME, a framework addressing challenges in scaling sequential recommendation models. It combines a multi-embedding strategy that decomposes item embeddings and a Mixture-of-Experts (MoE) architecture for specialized item representation learning. Empirical results show that Fuxi-MME outperforms existing baselines on public datasets.

## Technical note

Fuxi-MME scales sequential recommendation by rethinking the embedding layer rather than only the model architecture, building on the Fuxi-Alpha backbone. It replaces the single monolithic item embedding matrix with several lower-dimensional sub-embeddings that each capture a distinct facet of item identity (category, brand, style), increasing expressiveness parameter-efficiently and mitigating embedding collapse. It also inserts a Mixture-of-Experts layer into the Fuxi block as an input-aware routing mechanism that adaptively transforms representations according to sequence context. The multi-embedding component is plug-and-play. On three public benchmarks the combination of expressive embeddings and adaptive experts sets new state-of-the-art results over competitive sequential baselines.
