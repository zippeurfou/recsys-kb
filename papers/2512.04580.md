## Summary

1.  Existing methods for securely distributing Large Language Models (LLMs) are either too slow, expensive, or lack built-in security features, hindering widespread deployment.
2.  This paper introduces CryptoTensors, a new file format built upon the popular Safetensors format, providing built-in confidentiality (encryption) and access control for model weights.
3.  CryptoTensors enables efficient, secure model distribution and deployment with minimal overhead and compatibility with existing frameworks, offering a practical solution for protecting sensitive LLM weights.

## Technical note

The paper introduces CryptoTensors, a secure file format for confidential distribution of closed-weight LLMs that extends the widely-adopted Safetensors format. It applies fine-grained, tensor-level encryption with unique data encryption keys per weight matrix plus embedded access-control policies, while preserving Safetensors features like lazy loading and partial deserialization and keeping a plaintext but signature-protected header. A proof-of-concept library is benchmarked across serialization and runtime scenarios and validated for compatibility with Hugging Face Transformers and vLLM, showing lightweight overhead for secure model execution.
