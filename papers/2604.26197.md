## Summary

LinkedIn developed the Hierarchical Long-Term Semantic Memory (HLTM) framework to address the challenges of building scalable, low-latency, and privacy-preserving long-term memory for its LLM-based Hiring Agent. HLTM organizes user data into a structured, hierarchical memory tree, enabling efficient ingestion, retrieval, and adaptation across different contexts. Deployment in LinkedIn's Hiring Assistant demonstrated significant improvements in answer correctness and retrieval efficiency, proving the effectiveness of the hierarchical approach.

## Technical note

HLTM (Hierarchical Long-Term Semantic Memory) is a production framework for industrial LLM agents that organizes noisy longitudinal behavioral data into a schema-aligned memory tree capturing semantic knowledge at multiple granularities, deployed in LinkedIn's Hiring Assistant. Unlike semantic-clustering hierarchies, its topology is aligned to business scopes (seats, projects) so retrieval can be restricted to appropriate subtrees, enforcing tenant isolation, clean deletion, and GDPR-style privacy. Memory nodes are built offline via data-driven preference extraction and hierarchical aggregation with each node bound to a stable business identifier for explicit provenance and observability, while serving uses hybrid embedding-based retrieval answered through in-context learning to keep the online path lean and low-latency. An adaptation loop mines historical query patterns to continuously refine memory content, and lossless incremental updates provide nearline freshness. Reported results include over 5% answer-correctness and over 10% retrieval-F1 improvements while advancing the query-vs-indexing latency Pareto frontier.
