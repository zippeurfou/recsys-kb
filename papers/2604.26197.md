## Technical note

HLTM (Hierarchical Long-Term Semantic Memory, LinkedIn) is an industrial long-term semantic-memory framework for LLM agents, deployed in LinkedIn's Hiring Assistant to personalize recruiter interactions from noisy longitudinal behavioral data. It addresses five production challenges (scalability, low-latency retrieval, privacy, adaptability, observability) by organizing textual data into a schema-aligned memory tree capturing multi-granularity semantic knowledge, enabling massively parallel lossless incremental ingestion, multi-view representations for lean online retrieval, privacy scoping aligned to business boundaries (seats/projects), and provenance via stable business identifiers bound to each node; a workload-feedback adaptation loop mines query patterns to refine content. Over six months in production, HLTM improves answer correctness by >5% and retrieval F1 by >10% while advancing the query-vs-indexing latency Pareto frontier over baselines like Mem0, GraphRAG, RAPTOR, and MemTree.
