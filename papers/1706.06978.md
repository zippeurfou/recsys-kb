## Summary

DIN introduces a target-aware local activation unit (attention of the candidate ad over the user behavior sequence) to build a candidate-conditioned user representation, plus mini-batch aware L2 regularization and the Dice activation for industrial-scale sparse CTR training.

## Technical note

DIN (Alibaba, KDD 2018) replaces mean/sum pooling of the user behavior sequence with a target-aware local activation unit: a small feed-forward net a(e_j, v_A) scores each historical item embedding e_j against the candidate ad v_A (inputs include e_j, v_A and their element-wise/out product), and the user vector is the weighted sum sum_j a(e_j,v_A) e_j, giving a candidate-conditioned user representation. Attention weights are deliberately NOT softmax-normalized so the summed magnitude encodes interest intensity. Two training tricks (mini-batch aware L2 regularization computed only over features present in the batch, and the Dice data-adaptive activation) enable billion-parameter sparse training; DIN gives ~6% RelaImpr AUC over the Embedding&MLP base on Alibaba and +10% online CTR.
