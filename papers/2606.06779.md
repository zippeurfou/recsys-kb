## Summary

This paper addresses the challenge of providing personalized recommendations for new product categories ("verticals") like grocery and retail on platforms such as DoorDash, which suffer from sparse user data. The authors propose using Large Language Models (LLMs) to bridge this gap by leveraging a hierarchical Retrieval-Augmented Generation (RAG) pipeline. This system synthesizes detailed features from existing rich verticals' user interaction data (like restaurant orders and search queries), capturing both long-term preferences and short-term intent, thereby enhancing recommendation quality in data-scarce areas.

## Technical note

This DoorDash paper attacks the cold-start problem in data-sparse verticals (grocery, retail) by transferring knowledge from data-rich verticals (restaurants) using LLMs as semantic feature engineers. A hierarchical Retrieval-Augmented Generation pipeline maps unstructured user restaurant orders and search queries to a four-level product taxonomy via cascaded inference, where high-confidence L1/L2 affinities constrain the search space for L3, mitigating hallucination; they concentrate on L2/L3 affinities and require a confidence score above 0.8 with temperature 0.1. Two feature classes are synthesized: a Long-Term Cross-Vertical Affinity Profile from order history and a Short-Term Intent Profile from recent searches, concatenated into the input of a production two-tower-retrieval plus Multi-Task Learning ranker (optimizing click, add-to-cart, purchase). GPT-4o-mini with prompt caching and just-in-time materialization cut LLM cost ~80%, and features are served via a daily batch to an online feature store.
