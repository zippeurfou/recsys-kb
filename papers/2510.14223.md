## Technical note

This LinkedIn paper fine-tunes a large causal language model (Meta's LLaMA 3) as a dual encoder to generate user (member) and content (item) embeddings from purely textual prompts for LinkedIn Feed retrieval, retrieving 2000 candidates from hundreds of millions within a few-millisecond latency budget. It consolidates disparate retrieval sources (inverted indices, collaborative filtering, two-tower EBR) into a single embedding-based system, details prompt design, scale fine-tuning with engagement supervision, and low-latency serving. A key finding is that quantizing numerical features in the prompt lets them be encoded into embeddings; online A/B tests showed substantial engagement gains, especially for newer members lacking network connections.
