## Technical note

This Amazon paper theoretically analyzes how collaboration arises in VAE-based collaborative filtering, showing it is governed by latent proximity: it derives a latent sharing radius specifying when an SGD update on one user reduces another's loss, with influence decaying as latent Wasserstein distance grows. With clean inputs VAE-CF exploits mainly local collaboration and under-uses global collaboration; it compares beta-KL regularization (tightens the information bottleneck but risks collapse) versus input masking (induces geometric contractions/expansions but causes neighborhood drift). It proposes an anchor regularizer aligning user posteriors with item embeddings to preserve identity while enabling global consistency, validated on Netflix, MovieLens-20M, and Million Song, and deployed on an Amazon streaming platform.
