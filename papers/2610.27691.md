## Summary

Modern industrial recommendation systems using generative models often struggle due to a mismatch in semantics between user action sequences and non-sequential features, limiting the Transformer's ability to effectively combine them. To address this, the paper introduces EASformer, an architecture that explicitly disentangles and aligns these different types of representations, creating a shared context space. This design allows for improved historical action retrieval and state-conditioned action prediction, and supports self-supervised learning by masking actions, leading to better offline and online ranking performance.

## Technical note

In token-based industrial generative ranking, history tokens mix environment context with the observed action while candidate-side non-sequential (NS) tokens carry the current context plus cross features but no action, so query-key dot products compare semantically mismatched objects. EASformer (Huawei app marketplace ads ranking) splits each history event into an Environment token (fields shared with the candidate, embedded in one aligned space) and an Action token, keeps a temporally staggered User State stream initialized from static user features and separate NS tokens, and stacks L=5 blocks that each (1) do temporal retrieval, attention computed only among Environment tokens whose map is shared to aggregate Action values into the candidate slot, (2) do spatial mapping, predicting the candidate action from the current environment and a Transformer-contextualized latest user state, (3) gate-fuse the two views and mix them with NS tokens through a TokenMixer. Disentangled actions also enable a Cloze-style masked-action auxiliary BCE loss (mask ratio 0.2, weight 1) that reuses the main prediction head. On a 25-day industrial benchmark EASformer reaches AUC 0.89411, +0.88% relative over the production HyFormer and above OneTrans, MTGR, MixFormer, UniMixer and LONGER paired with RankMixer, DCNv2 or Wukong; the lightweight EASformer- (D=128, history 500 vs HyFormer 1000) lifted eCPM by 1.26% and 3.94% in two online A/B scenarios.
