## Technical note

ColBERT-serve is a serving system for late-interaction retrievers like ColBERTv2 that supports many concurrent users on cheap, low-RAM servers where the index does not fit in memory. It applies memory-mapping to the compressed ColBERTv2 index (reducing RAM by over 90%), releases Python's GIL for parallel concurrent requests, and uses a multi-stage architecture where SPLADEv2 (via the PISA engine) generates top-200 candidates that MMAP ColBERTv2 re-ranks, minimizing costly disk page misses. A hybrid scoring step linearly interpolates z-normalized SPLADEv2 and ColBERT scores; the system serves up to 4 queries per second on a few GB of RAM while preserving or surpassing full in-memory ColBERTv2 quality on MS MARCO, Wikipedia, and LoTTE.
