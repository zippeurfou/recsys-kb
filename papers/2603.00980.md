## Summary

1.  Existing generative recommender models often treat user sequences as flat, ignoring their inherent hierarchical structure and facing computational inefficiencies due to noisy attention.
2.  To address this, the paper introduces HPGR, a novel framework with two stages: a structure-aware pre-training stage using Masked Item Modeling to learn rich item representations, and a preference-aware fine-tuning stage using sparse attention to focus computation.
3.  HPGR effectively captures hierarchical user behavior and improves computational efficiency, leading to state-of-the-art recommendation performance on large-scale datasets.

## Technical note

HPGR augments generative recommenders (HSTU) by rejecting the flat-sequence assumption and injecting hierarchical and preference structure. A structure-aware pre-training stage uses a Session Enhancement Module (intra- and inter-session transformers) with a session-based Masked Item Modeling objective to learn hierarchically-informed item representations. A preference-aware fine-tuning stage applies Preference-Guided Sparse Attention, treating the candidate as a query to restrict attention to the most relevant historical items, improving signal-to-noise and efficiency. On an APPGallery industrial dataset and online A/B test it beats HSTU and MTGR, with +1.99% eCPM uplift.
