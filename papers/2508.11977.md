## Technical note

TBGRecall (Taobao Generative Recall) adapts generative models to the retrieval stage, where returned candidate sets are unordered and token-wise autoregressive Next Token Prediction wrongly imposes intra-session item dependencies. It introduces Next Session Prediction (NSP): user sequences are partitioned into multi-session segments (session token followed by item tokens), item generation within a session is independent, and contrastive loss between context and positive/negative items replaces regressive loss, with session tokens driving ANN search at inference. Built on HSTU with multi-session prediction, token-specific networks, and stochastic partial incremental training (favoring data recency), it shows a scaling-law trend, beats SOTA, and lifts Taobao 'Guess You Like' transaction amount by 2.16%.
