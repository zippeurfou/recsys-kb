## Summary

A Generative Retrieval Model for E-commerce Recommendation Scenarios":

1.  **Problem:** Standard generative recommendation models face challenges in efficiently retrieving multiple relevant items simultaneously within a single request due to their autoregressive nature requiring sequential position.
2.  **Solution:** The authors propose TBGRecall, which integrates Next Session Prediction (NSP) and uses session-based input sequences (partitioned into sessions with item tokens), combined with specific training optimizations like limited data pre-training for better efficiency.
3.  **Result:** Experiments on benchmark datasets and a large-scale e-commerce dataset show that TBGRecall outperforms existing methods, demonstrates clear scaling benefits, and significantly improves the effectiveness of generative recommendation systems by leveraging recent data more effectively than volume alone.

## Technical note

TBGRecall is a generative retrieval model for e-commerce that fixes a mismatch between autoregressive next-token generation and the retrieval stage, where within-session candidates are unordered and should not depend on each other. It proposes Next Session Prediction (NSP), a session-wise autoregressive scheme built on HSTU that partitions user sequences into sessions (session token plus item tokens), replaces regressive loss with contrastive loss between context tokens and positive/negative items, and uses the session token to drive ANN retrieval at inference. Additions like multi-session prediction, a token-specific network, and stochastic partial incremental training improve accuracy and efficiency, emphasizing data recency over volume. It shows scaling-law trends, beats SOTA offline, and lifted Taobao 'Guess You Like' online transactions by 2.16%.
