## Summary

This paper introduces LoopMemGR, which addresses limitations in generative recommendation systems. Existing methods use only user history logs for prediction, ignoring past recommendations and their resulting feedback within a bounded input budget for Semantic IDs.

LoopMemGR proposes accumulating two types of data: standard behavior logs and a new *recommendation experience log* tracking previous recommendations and user feedback over time.

The system extracts relevant preference signals from these logs using three views (recency, frequency, global) to compress them into fixed-length "experience tokens," which are then used alongside the history log to improve generative recommendation performance.

## Technical note

Generative recommenders following the history-as-context paradigm discard system-side recommendation decisions after each request, creating an asymmetric memory in which the model recalls what the user did but not what it already recommended or explored. LoopMemGR maintains a per-user append-only recommendation experience log alongside the behavior log and compresses it with a Tri-View Memory Reader (TVMR): a recency view anchored on the M most recent deduplicated exposures, a frequency view whose queries are the top-M SID1 categories with a softplus category attention prior, and a global view of M learnable queries shared across users, fused by recent-anchored gated attention into a fixed M=16 experience tokens. All views share one cosine cross-attention read operator with RMSNorm, a constrained learnable temperature, an RMS magnitude cap and a learnable gate; training jointly optimizes the two-step SID generation loss plus a Rank-head ranking loss, with pairwise-cosine diversity regularizers L_Q and L_A on the global queries and their attention distributions. On a 21M-user / 270M-item / 26B-interaction industrial Taobao dataset using RankGR (Qwen2.5-0.5B-Instruct backbone, FORGE semantic IDs) as the base, LoopMemGR raises Click HR@20 from 11.64 to 20.43, Click HR@1000 from 54.00 to 68.41, and PV HR@1000 from 38.18 to 53.56. TVMR-16 beats BlockMean-16, AttnPool-16 and LONGER-16 at the same 16-token budget and retains at least 74.3% of the gain from serializing 1,000 raw experience entries, while dropping the diversity regularizers cuts Global-16 Click HR@20 from 17.29 to 14.31 and raises mean pairwise attention cosine from 0.09 to 0.25.
