We identify this phenomenon as semantic state sink, where recurring semantics over-occupy the recurrent state and bias subsequent readouts. ## Technical note

SinkRec addresses 'semantic state sink' in linear-attention long-sequence recommendation, where repetitive behaviors over-occupy the compressed recurrent state and bias readouts (e.g. recent travel behaviors dominating over target-relevant food signals in vanilla Gated DeltaNet). It is a memory-transition decoupled looped hybrid architecture: a Conditional Memory Module externalizes recurring local behavior windows into learnable residual-VQ codes, reinjects them, and exposes memory key-value pairs; a Temporal-Aware State-Relation Differential Gated DeltaNet (TDGD) uses that memory to suppress memory-covered updates before writing and remove memory-aligned responses at readout, reserving the recurrent state for dynamic transitions. On two public and one industrial dataset SinkRec outperforms strong baselines with fewer parameters at linear-time efficiency.
