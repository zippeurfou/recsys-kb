## Summary

Current LLM memory benchmarks are limited because they use static, unrealistic dialogues lacking long-term coherence and the diverse data streams (like emails) common in real-world interactions.

To address this, the authors introduce RHELM, a new benchmark featuring realistic, evolving dialogues built around detailed user profiles and a novel LOOP module, synchronized with heterogeneous external data sources.

Evaluation on RHELM shows that existing memory systems and retrieval methods still struggle significantly with the complex demands of long-term, real-world interactions, particularly handling multi-source data and context effectively.

## Technical note

RHELM is a benchmark for evaluating long-term memory in LLM personal assistants, built from 10 persona trajectories spanning a simulated year with 11,764 dialogue turns and 2,180 heterogeneous external sources (reports, journals, emails) totaling 500k-1M tokens per persona. A LOOP (plan-rollout-evolve-prune) module generates dialogues with dynamic temporal evolution and long-term coherence, synchronized with external data streams on the user's event timeline. The evaluation suite has 1,305 QA pairs across seven query categories (Fact, Temporal, Hallucination, Aggregation, Misleading, External Source, Mixed) mapped to 27 memory characteristics, including a novel Misleading category requiring implicit-state conflict detection. Experiments over full-context models, RAG methods, and memory frameworks show contemporary systems fail most on multi-source aggregation and real-world contextual reasoning.
