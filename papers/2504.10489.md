## Summary

This paper presents Roamify, an AI-powered Google Chrome extension designed for personalized itinerary planning using Large Language Models like Llama and T5 to generate customized travel plans based on user preferences. User surveys validated that individuals across all age groups prefer this AI approach over traditional methods for travel planning. The study highlights two key design aspects: D1 web-scraping for real-time destination information, enhancing the relevance of suggestions; and D2 integrating user needs with a recommendation system to adapt itineraries dynamically.

## Technical note

Roamify is an LLM-powered Chrome extension that generates personalized travel itineraries by combining up-to-date web-scraped destination content with user preference genres. Its four-stage pipeline collects data (user input or inferred from open browser tabs), extracts attractions via pattern recognition over numbered lists, summarizes content, and generates itineraries with LLMs such as Llama and T5. A recommendation component adapts the itinerary to user needs, and web scraping keeps suggestions current versus stale LLM training data. User surveys across age groups showed strong preference for the AI-assisted approach over traditional planning.
