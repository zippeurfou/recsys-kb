## Technical note

POEM (Partial-Order Enhanced Modeling) rethinks sequence construction for real-time retrieval by using the preceding ranking stage's real-time multi-task scores (predicted CTR, CVR, watch time) as supervisory signals, rather than only static chronological clicks. Per request it builds a partial-order structured sequence from the previous refresh's top-ranked candidates, grouped and sampled by a fused multi-objective rank-weighted quintuple, with a [CLS] token forming an instantaneous interest embedding refreshed every request. A hierarchical learning strategy treats system-preferred top items plus user feedback (long-play videos) as positives with graph-retrieved hard negatives under a margin-based pairwise loss. Deployed at Kuaishou, POEM achieved +0.249% and +0.213% average viewing time per user on KS Single Page and KS Lite Page.
