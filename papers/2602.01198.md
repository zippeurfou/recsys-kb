## Summary

This paper addresses the inefficiency of long Chain-of-Thought (CoT) reasoning in LLMs by introducing a state-transition framework. It models the reasoning process as transitions between states, using a linear attention mechanism to efficiently capture and utilize historical reasoning information, thereby reducing computational complexity from quadratic to linear. This approach not only significantly improves reasoning efficiency but also enhances model performance, mitigating issues like overthinking from noisy steps, as demonstrated across various datasets.

## Technical note

This paper reduces the inefficiency of long chain-of-thought LLM reasoning by modeling it as transitions between states rather than dependence on all prior steps. A linear-attention module compresses completed reasoning into a model state, so the next step is generated from only the current state and query, cutting complexity from quadratic to linear. The pipeline segments long CoT into low-dependency steps and annotates thinking types via MiniBatch K-means with 128 clusters, and trains only added parameters (linear attention plus special tokens) with LoRA, cutting training cost to ~47.7% of the base model. Beyond efficiency, correcting noisy steps in state space improves accuracy (+4.7 points on Qwen-2.5-1.5B).
