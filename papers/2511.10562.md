## Summary

1.  Existing satellite-based precipitation estimates are often inaccurate, particularly in data-sparse regions, due to reliance on single channels and calibration issues.
2.  This paper introduces Oya, a deep learning algorithm using geostationary satellite data and a two-stage U-Net approach to detect and estimate precipitation, addressing data imbalance issues.
3.  Oya, trained with high-resolution ground truth data and pre-training, achieves superior real-time global precipitation estimates compared to existing methods, offering improved monitoring and forecasting.

## Technical note

Oya is a real-time precipitation retrieval algorithm that uses the full visible and infrared (VIS-IR) spectrum from geostationary satellites, rather than single longwave-IR channels, to improve estimates especially in the data-sparse Global South. It uses a two-stage deep learning design with two U-Net models: one for rain/no-rain detection and one for quantitative precipitation estimation, explicitly addressing the strong class imbalance between rain and no-rain events. Models are trained on high-resolution GPM CORRA v07 ground truth and pre-trained on IMERG-Final retrievals to add robustness and reduce overfitting from CORRA's limited temporal sampling. Leveraging multiple GEO satellites for quasi-global coverage, Oya outperforms competitive regional and global precipitation baselines.
