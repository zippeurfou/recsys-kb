## Summary

This paper proposes Thought-Augmented Planning for LLM-Powered Interactive Recommender Agent (TAIRA) to overcome the limitations of existing systems in handling complex and diverse user intents expressed via natural language. TAIRA utilizes a multi-agent system with a manager agent that uses "Thought Pattern Distillation" – extracting high-level thoughts from expert experiences – to enhance its planning capabilities for decomposing user needs into subtasks. Experiments show TAIRA significantly outperforms existing methods, especially on challenging tasks and those requiring generalization, while the underlying code is publicly available for replication.

## Technical note

TAIRA is a thought-augmented multi-agent system for LLM-powered interactive recommendation that handles complex, ambiguous natural-language intents. A manager agent decomposes user needs and plans subtasks executed by executor agents, with planning strengthened by Thought Pattern Distillation (TPD), which extracts reusable high-level thought patterns from agent and human-expert experiences. The authors also build a user-simulation scheme to generate queries of varying difficulty. Across multiple datasets TAIRA significantly outperforms baselines like CoT and Reflexion, with larger gains on harder tasks and better generalization to novel scenarios.
