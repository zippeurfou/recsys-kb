## Summary

This paper addresses the challenge of balancing specialized music knowledge and tool integration in conversational recommendation systems. It introduces WeMusic-Agent, a framework combining knowledge internalization (using large music datasets) and agentic boundary learning (deciding when to use tools). The proposed model, WeMusic-Agent-M1, significantly improves conversational music recommendations, and the authors also created a new benchmark for evaluation using real-world data.

## Technical note

WeMusic-Agent is a training framework for LLM-based conversational music recommendation that balances internalized domain knowledge with agentic tool use. WeMusic-Base is built by continually pretraining Qwen2.5-32B on a 50B-token music corpus (using a dual reference model for quality reweighting and to prevent catastrophic forgetting), then SFT on multi-turn dialogue, and multi-objective GRPO with hybrid rewards for format, factuality, relevance, personalization, and diversity, plus self-distillation for list-wise recommendation. WeMusic-Agent-M1 then learns an agentic boundary via curriculum SFT and controllable RL to answer in-knowledge queries directly while calling search tools for out-of-knowledge ones. On a new WeChat Listen benchmark it outperforms much larger general-purpose LLMs on relevance, personalization, and diversity.
