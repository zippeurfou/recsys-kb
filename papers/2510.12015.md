## Summary

Large Language Models (LLMs) can now interact conversationally for personalized recommendations. Eliciting user preferences effectively through sequential clarifying questions is a key challenge when user history is limited. This paper introduces a novel two-stage method inspired by diffusion models to train LLMs specifically for asking these funnel questions, improving their ability to uncover user preferences.

## Technical note

This paper trains LLMs to ask effective sequential clarifying questions for preference elicitation in conversational recommenders, especially when user history is limited. It casts profiling as a discrete-diffusion process: a forward process takes a structured user profile ordered specific-to-general, generates an elicitation question per attribute, and incrementally removes information to 'corrupt' the profile; the reverse process fine-tunes an LLM to reconstruct the profile by asking questions, naturally yielding a funnel from general to specific queries. A separate LLM user simulator answers questions (or abstains) from the ground-truth profile to generate training data and evaluate reconstruction. Including both questions and answers in the profile state avoids repetitive queries; results show markedly improved elicitation and profile reconstruction.
