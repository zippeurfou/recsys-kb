Large Language Models (LLMs) have made it possible for recommendation systems to interact with users in open-ended conversational interfaces. In order to personalize LLM responses, it is crucial to elicit user preferences, especially when there is limited user history. ## Technical note

This paper trains LLMs to ask effective sequential clarifying questions for preference elicitation in conversational recommendation, especially for cold-start users with little history. It adapts a diffusion-model formulation: a forward process starts from a structured user profile, generates a clarifying question per profile field and incrementally removes information ('adds noise'), and a reverse process fine-tunes an LLM to 'denoise' by asking questions that reconstruct the full profile. Experiments show the method significantly improves the LLM's ability to elicit preferences and to naturally ask funnel questions that progress from general to specific.
