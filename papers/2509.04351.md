The dominant paradigm in image retrieval systems today is to search large databases using global image features, and re-rank those initial results with local image feature matching techniques. This design, dubbed global-to-local, stems from the computational cost of local matching approaches, which can only be afforded for a small number of retrieved images. ## Technical note

This Google paper proposes a Local-to-Global (L2G) image retrieval paradigm, inverting the conventional global-to-local pipeline. It uses efficient scalable local-feature search for the initial stage (capturing partial matches missed by global search), then a novel re-ranking stage that computes global features on-the-fly via multidimensional scaling (MDS) so embeddings respect the local-feature retrieval similarities and share information across shortlisted images. It sets new state-of-the-art results on the Revisited Oxford and Paris benchmarks.
