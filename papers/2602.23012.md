## Technical note

This work proposes a residual quantization (RQ)-based sequence learning framework for continuous value prediction (watch-time, LTV, GMV) that avoids the rigid parametric distribution assumptions of prior generative approaches for long-tailed data. It represents each target continuous value as a sum of ordered quantization codes predicted recursively from coarse to fine with diminishing quantization error, and adds a representation learning objective aligning the RQ code embedding space with the ordinal structure of target values. On public LTV and watch-time benchmarks and a large-scale online GMV-prediction experiment on an industrial short-video platform, it consistently outperforms SOTA with strong cross-task generalization.
