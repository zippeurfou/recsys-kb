Designing document identifiers (docids) that carry rich semantic information while maintaining tractable search spaces is a important challenge in generative retrieval (GR). Popular codebook methods address this by building a hierarchical semantic tree and constraining generation to its child nodes, yet their numeric identifiers cannot leverage the large language model's pretrained natural language understanding. ## Technical note

C2T-ID (Alibaba) converts semantic codebook paths into structured textual document identifiers for generative retrieval, balancing semantic expressiveness with tractable search space. It (i) builds a hierarchical clustering tree to assign each document a numeric semantic path, (ii) extracts high-frequency metadata keywords per cluster, (iii) replaces each numeric label with its cluster's top-K keywords joined by hyphens, and (iv) optionally applies two-level LLM semantic smoothing for fluency while preserving tree structure. On Natural Questions and Taobao product search, C2T-ID significantly outperforms atomic, semantic-codebook, and pure-text docid baselines.
