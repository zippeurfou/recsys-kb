## Summary

1.  Recommender systems need to capture complex feature interactions for better predictions, but scaling these models efficiently without increasing inference time has been challenging.
2.  To address this, the paper introduces Zenith, a ranking architecture that uses "Prime Tokens" and specialized modules (Token Fusion and Boost) to learn these interactions with significantly reduced runtime overhead.
3.  Zenith's efficiency allows it to scale better than existing methods, and its deployment on TikTok Live resulted in measurable improvements in click-through rate and user engagement metrics.

## Technical note

Scaling ranking-model capacity for feature interactions usually inflates inference latency and hits diminishing returns from brute-force layer/width scaling. Zenith projects sparse features into a few high-dimensional Prime Tokens, then applies a Token Fusion module (cross-network-style pairwise token interactions) and a Token Boost module (independent per-token refinement) to preserve token heterogeneity across layers. This design yields superior scaling laws with minimal runtime overhead. Deployed on TikTok Live at billion-user scale, A/B tests show +1.05% CTR AUC, -1.10% Logloss, +9.93% Quality Watch Session per User, and +8.11% Quality Watch Duration per User.
