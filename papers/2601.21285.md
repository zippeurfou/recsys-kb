## Technical note

Zenith is a scalable, efficient ranking architecture from TikTok Live that models complex feature interactions with minimal serving latency by treating a few high-dimensional 'Prime Tokens' (feature-category-grouped embeddings) as fundamental units. It uses a Token Fusion module (Retokenized Self-Attention and Tokenwise Multi-Head Self-Attention) to model cross-token interactions and a Token Boost module (Tokenwise SwiGLU and Tokenwise Sparse MoE) to refine each token independently, preserving token heterogeneity across layers for better scaling. Zenith shows superior scaling laws vs SOTA ranking models; online A/B tests achieved +1.05%/-1.10% offline AUC/logloss and +9.93% Quality Watch Session/User and +8.11% Quality Watch Duration/User.
