## Summary

This paper introduces **TopoGR**, a novel generative recommendation framework designed to overcome the limitations of current semantic ID-based recommenders. The core issue addressed is that existing systems treat discrete semantic IDs (SIDs) as independent symbols, ignoring their inherent structured relationships or "topology," which prevents capturing item similarity beyond exact SID overlap.

To tackle this, TopoGR uses **Binary SIDs** learned in a bit-decomposable way, enabling explicit Hamming distance geometry between items. This approach is applied during input feature generation (preserving Hamming proximity), supervised training (using topology-aware soft targets), and final reranking of recommendations (aligning candidates with binary prototypes).

Experiments across four benchmark datasets demonstrate that TopoGR consistently outperforms existing state-of-the-art recommendation baselines by effectively leveraging this Hamming space to better model item relatedness.

## Technical note

TopoGR fixes a structural mismatch in semantic-ID generative recommendation where tokenizers learn a structured code space but generators treat SID tokens as independent categorical symbols, reducing item relatedness to exact SID overlap. It introduces a Bit-Decomposable Quantizer (a lookup-free-quantization tokenizer with bit-compositional reconstruction) that yields Binary SIDs with explicit Hamming geometry, deterministically convertible to integer SIDs, and exploits topology at three stages: binary-SID input features, Hamming soft-target supervision (KL to a Hamming-distance-weighted distribution), and Hamming-consistent reranking of the candidate pool. It uses parallel multi-token SID prediction rather than autoregressive beam search. On four Amazon categories it beats item-ID and semantic-ID baselines (SASRec, TIGER, RPG, MHL, DiffGRM), e.g. about +24% N@5 over RPG on Toys and +19% on Sports, with especially large gains on cold-start/low-frequency items.
