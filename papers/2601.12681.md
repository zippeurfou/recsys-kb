## Technical note

HyFormer is a unified hybrid-transformer backbone from ByteDance that tightly integrates long-sequence modeling and heterogeneous feature interaction, replacing the dominant decoupled 'compress-then-fuse' pipeline (e.g., LONGER + RankMixer) that suffers from compressed, late, unidirectional fusion. It introduces global tokens as a shared interface and alternates two mechanisms: Query Decoding, where global query tokens attend over layer-wise key-value representations of long behavior sequences, and Query Boosting, which strengthens cross-query/cross-sequence interactions via efficient token mixing. HyFormer beats strong LONGER/RankMixer baselines under comparable parameters/FLOPs with superior scaling, and is fully deployed at ByteDance serving billions of users daily.
