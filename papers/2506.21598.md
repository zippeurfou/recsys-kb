## Technical note

This Amazon paper designs A/B tests for search-engine marketing where anonymized users prevent customer-level randomization and product/query splits violate SUTVA due to SERP interference (products co-appearing in the same auction). It leverages censored observational query-report data to construct bipartite (search query to product/text ad) and tripartite SERP interference networks, then applies a novel weighting function to build unipartite weighted projections whose clusters serve as randomization units. The design is demonstrated evaluating a new paid-search bidding algorithm, and the paper provides a SageMaker-based polyglot system architecture blueprint for the experimentation framework.
