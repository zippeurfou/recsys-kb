## Summary

AdaPLD (Adaptive Retrieval and Reuse for Efficient Model-Free Speculative Decoding) is an innovative system designed to accelerate text generation by reusing context without needing separate draft models. It overcomes two key limitations in existing methods: poor recall under surface-form variations and brittle single-span copying, by combining high-precision lexical matching with semantic similarity retrieval and generating branched reuse hypotheses for better reliability. This approach reduces the number of target-model forward passes required and achieves significant decoding speedups across various benchmarks.

## Technical note

AdaPLD is a training-free model-free speculative decoding method that improves both retrieval and draft construction to accelerate LLM generation without an auxiliary draft model. It identifies two limitations of reuse-based methods: lexically anchored retrieval has low recall under surface-form variation (a no-hit failure when the anchor token is absent), and deterministic single-span copying is brittle when retrieved context does not uniquely determine the continuation. AdaPLD keeps high-precision lexical matching as the default and invokes semantic-similarity retrieval only when lexical matching finds no candidates, expanding candidate reachability without losing exact-match precision. For reuse it constructs branched hypotheses over plausible next tokens rather than one copied span, achieving up to 3.10x decoding speedup across input-guided generation, code editing, and reasoning benchmarks.
