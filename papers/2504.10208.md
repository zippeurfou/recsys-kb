## Summary

This paper introduces a Generative Query Recommendation (GQR) framework that uses Large Language Models (LLMs) to overcome limitations in traditional search query suggestion methods, which rely heavily on potentially sparse or unreliable historical logs.

The core idea is twofold: first, unify different recommendation tasks under a single prompt framework leveraging LLM instruction-following; second, align the generated queries specifically with user feedback using a CTR (click-through rate) prediction model as a reward signal during training to maximize click probability and address cold-start issues.

## Technical note

GQR is a generative framework that unifies diverse query-recommendation tasks (query completion, suggestion, clarification) into a single LLM prompt template, using the model's world knowledge to overcome cold-start and long-tail sparsity in historical logs. To align generated queries with real user preferences, it trains a query-wise CTR predictor as a process reward model and applies list-wise preference optimization to maximize the click probability of the generated query list. It further aligns with proactive user intent by retrieving co-occurring user-initiated queries as side information when logs are available, plus a deployment workflow with periodic updates and exploration. Deployed across three scenarios in Baidu's conversational search, it achieves over 60% CTR improvement versus LLM baselines.
