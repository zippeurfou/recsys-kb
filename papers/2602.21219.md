## Technical note

GraSPeR (Graph-based Sparse Personalized Reasoning) enhances personalized LLM text generation for cold-start users with sparse interaction histories (where >95% of e-commerce/social users are cold-start). It first augments user context via a pretrained link predictor over the user-item graph to predict items the user would likely interact with, then generates reasoning-aligned synthetic texts for these simulated interactions to enrich context, and finally produces personalized outputs conditioned on both real and synthetic histories. Reasoning is explicitly incorporated in both the augmentation and generation stages to ensure alignment with user style. On three personalized-generation benchmarks GraSPeR significantly outperforms SOTA baselines under sparse context.
