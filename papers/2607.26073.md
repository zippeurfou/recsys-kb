## Summary

This paper addresses challenges in industrial generative retrieval for next Point-of-Interest (POI) recommendations, specifically tackling issues like redundant or colliding tokens and insufficient integration of diverse POI signals. It introduces Gwhere, an end-to-end framework combining SID generation with Large Language Model (LLM)-based recommendation tailored for mobility data. Experiments on public datasets demonstrate Gwhere's effectiveness, and its deployment in Alibaba's Amap service resulted in significant improvements (+5.83% P-CTR, +6.20% U-CTR) over the existing system.

## Technical note

Gwhere is an end-to-end LLM-based generative framework for next-POI recommendation deployed on Amap's homepage that explicitly replaces the traditional cascade retrieve-rank system with a single generative model. It first learns multi-modal Semantic IDs via a fully contrastive residual-quantization tokenizer (fusing text, image, spatial GraphSAGE, and ALS collaborative signals, replacing RQ-VAE reconstruction loss with an NT-Xent contrastive objective), then adapts a Qwen2.5 LLM through continued pretraining on spatio-temporal corpora, SFT, and Exposure-Aware Kahneman-Tversky Optimization (EAKTO), a KTO-style RL alignment on binary exposure/click logs with positive-reward anchoring and noisy-negative gating. Gwhere-7B beats SOTA GNPR-SID by up to 13.2% Acc@1 and a production cascade-ranking baseline by 14.8% Acc@1; the deployed 0.5B model's long-term A/B test shows +5.83% P-CTR and +6.20% U-CTR. UNIFIED/SINGLE-STAGE: it directly generates the recommended POI, folding candidate generation and ranking into one autoregressive generative model and skipping the recall to coarse-rank to fine-rank to re-rank cascade.
