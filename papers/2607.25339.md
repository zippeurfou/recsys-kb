## Summary

Generative recommendation models face challenges handling heterogeneous item attributes (like category or price) due to static Semantic IDs (SIDs) that don't adapt to user context. The SPARC framework dynamically routes information from different attribute fields through multiple slots based on contextual relevance before compressing into fixed-size tokens, thereby preserving more nuanced historical item interactions without increasing input length. Experiments demonstrate SPARC significantly improves recommendation performance over strong baselines by effectively retaining important contextual details during the compression phase.

## Technical note

SPARC is a lightweight context-conditioned compression front-end for semantic-ID generative recommendation that turns each multi-field historical interaction (SID plus category, brand, price, behavior type, timestamp) into a single backbone token via three stages: Field-wise Context Modeling, Context-aware Attribute Routing, and Sequence-level Token Consolidation, preserving SID identity while routing context-relevant side fields under a fixed token budget. Built on the RankGR generative-retrieval backbone, it enriches user history without increasing input length or changing the autoregressive target-SID objective. On industrial Taobao and Amazon Beauty/Toys it beats RankGR and generative baselines (TIGER, HSTU, FORGE), e.g. Taobao HR-click@20 0.1669 vs 0.1568 and roughly doubling Amazon Beauty HR@20 (0.0794 vs 0.0466). Ablations show context-conditioned compression beats stronger static compressors (MLP, QFormer, modulated), confirming gains come from context-conditioned retention rather than compressor capacity.
