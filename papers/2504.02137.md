## Technical note

Meta introduces Semantic ID prefix-ngram, a token parameterization on top of Semantic ID that replaces random hashing of item IDs (which causes embedding instability from contradictory-gradient collisions under high cardinality, impression skew, and ID drifting) with semantically meaningful collisions from hierarchically clustered content embeddings. It improves generalization, tail-item modeling, overfitting, and robustness to distribution shift, with outsized gains in attention-based models that contextualize user history. Productionized in Meta's ads ranking system, the features became top sparse features by importance, delivered a 0.15% online gain, and significantly reduced per-item prediction variance/instability.
