## Summary

Bridging Query Generation and Product Retrieval for E-commerce Query Recommendation":

Current e-commerce query recommendation systems primarily optimize individual queries, often resulting in high click-through rates but low downstream product conversion rates. This work proposes **QueryAgent-R1**, an innovative memory-augmented agentic framework that grounds query generation directly on inventory retrieval, allowing queries to be refined based on actual product alignment and user engagement with those products.

To achieve better recommendations, QueryAgent-R1 employs chain-of-retrieval optimization and introduces a consistency reward during reinforcement learning. It also features efficient memory abstraction for user profiling. The system's effectiveness was validated using newly constructed datasets and showed significant improvements in both query click-through rates and product conversion rates (+2.9% CTR, +3.1% CVR) in large-scale A/B tests on production platforms compared to existing methods.

## Technical note

QueryAgent-R1 is a memory-augmented agentic framework for e-commerce query recommendation that closes the generation-retrieval gap where recommended queries earn high click-through rate but low product conversion. It grounds query generation in real inventory retrieval so the agent validates and refines queries against retrieved products, formulating search-bar placeholder generation as chain-of-retrieval optimization over joint query-click and item-click probability. A consistency reward in the agentic RL process jointly optimizes query relevance and downstream engagement, and a memory abstraction module extracts an interest graph from users' long-term behavior for efficient profiling. The policy interleaves a Memory Tool and a Search Tool; on a production platform with tens of millions of daily active users it improves Query CTR by 2.9% and guided CVR by 3.1% in online A/B tests.
