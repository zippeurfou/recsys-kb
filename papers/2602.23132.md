## Technical note

FatsMB is a latent-diffusion framework for multi-behavior sequential recommendation (MBSR) that transfers preference generation 'From Behavior-Agnostic To Behavior-Specific' in a latent space, arguing that the asymmetric determinism between low-entropy behaviors and high-entropy items makes discriminative scoring unsuitable. A Multi-Behavior AutoEncoder (MBAE) with Behavior-aware RoPE (BaRoPE) builds a unified user latent preference space; a diffusion model then transfers behavior-agnostic preferences to target-behavior-specific ones, using Multi-Condition Guided Layer Normalization (MCGLN) as denoiser before decoding to item space. Experiments on real-world datasets show improved accuracy and diversity over discriminative MBSR baselines.
