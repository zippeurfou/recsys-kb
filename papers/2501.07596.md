## Technical note

Deep models contain 'incompatible parameters' that contribute minimally or negatively under specific data distributions; pruning only improves efficiency and output ensembling multiplies inference cost. Tencent proposes Compatibility-aware Knowledge Integration (CKI), which performs Parameter Compatibility Assessment (local-level parameter uncertainty from cross-model value variance plus global-level model information entropy over parameter histograms) and Parameter Splicing (hard vs soft weighted fusion) to merge multiple models trained under different conditions into one model with identical parameter count and zero added inference cost. Across recommendation datasets (Beauty, Music, Book, MovieLens; models like SASRec, BERT4Rec) and language tasks (SST-2), CKI beats Model A/B, pruning, averaging, and output ensemble on NDCG/HR (e.g. Beauty NDCG@5 0.1409 vs ~0.114 for base models), and the integrated model can serve directly or be fine-tuned for one epoch to improve further.
