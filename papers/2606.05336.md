## Summary

Personalization of large language models (LLMs) requires adapting their responses based on user interactions for tasks like recommendation or dialogue. Existing methods create personalized profiles using expensive, sparse labels from downstream tasks. This paper introduces BUMP, a self-supervised framework that trains profile generators by scoring them against held-out data via bidirectional ranking objectives using NDCG metrics and an LLM judge, eliminating the need for explicit task labels during training. BUMP shows competitive results on standard benchmarks like LaMP, matching or outperforming approaches relying on costly downstream annotation.

## Technical note

BUMP trains an LLM profile generator with GRPO using a self-supervised bidirectional in-batch ranking reward, requiring no downstream task labels. A frozen LLM judge scores each generated profile in a forward direction (profile-as-query ranks the user's held-out interactions above other users' items) and a backward direction (a held-out item-as-query ranks the user's profile above others'), each with multi-positive NDCG, and combines them into a dense per-rollout reward with position debiasing and a soft length penalty. Other users in the batch supply free negatives; BUMP+ adds embedding-based (BGE) hard-negative mining in both directions. On the LaMP benchmark a 4B Qwen3 policy matches or beats task-supervised rewards on 9/11 metric rows and outperforms Gemini-3-Pro on all rows, though raw history still wins on ROUGE-scored generation tasks.
