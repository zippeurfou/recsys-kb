## Technical note

This eBay system models transitional queries -- intermediate reformulations along a user's shopping journey -- rather than treating query rewriting as isolated source-target pairs. It mines structured query sequences (source query, transitional queries, converging queries) from eBay's interaction logs with an intent-consistency filtering step that uses representation learning over item interactions to keep intent coherent, then uses an open-source LLM with in-context learning to generate diverse, intent-preserving alternatives to the converging queries. These alternatives anchor the search results page into intent-clustered carousels (e.g. Related Searches), yielding measurable gains in conversion and engagement over the existing Related Searches module.
