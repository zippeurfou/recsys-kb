## Summary

1.  ReAct agents often produce shallow or redundant reasoning due to relying solely on internal judgment. This paper introduces Co-ReAct, a framework that uses rubrics as active step-level guidance during the agent's reasoning process to improve trajectory quality.
2.  Co-ReAct injects relevant rubrics into the agent's context at each decision point to guide its next action. To ensure reliable rubrics, the authors train a dedicated generator using a novel list-wise ranking objective (GRPO), optimizing against multi-judge consensus for better discrimination.
3.  Experiments show Co-ReAct consistently improves agent performance on reasoning benchmarks compared to standard ReAct and other baselines, across different model sizes, by leveraging rubrics as active collaborators rather than just evaluators.

## Technical note

Co-ReAct treats rubrics as active step-level collaborators inside a ReAct agent's reasoning loop rather than as passive post-hoc evaluators, injecting relevant rubrics into the agent context at each decision point to improve trajectory quality. To produce reliable rubrics it trains a dedicated generator with a list-wise ranking objective under GRPO, optimizing against multi-judge consensus for better discrimination. Experiments show consistent gains over standard ReAct and other baselines across reasoning benchmarks and model sizes. The work sits in the LLM-agent / reasoning space rather than recommendation.
