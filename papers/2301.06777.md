## Summary

Previous studies on self-attention recommenders often relied solely on offline metrics and standardized datasets, neglecting real-world industry applications and the crucial inclusion of side information like item/customer metadata, despite deep learning models' potential. This work addresses these gaps by presenting live experimental results demonstrating significant improvements in user retention (up to 30%) using reusable self-attention based recommenders in the fashion industry. Furthermore, it shares practical insights and learnings from building configurable systems for specific fashion use-cases, including outfit ranking, recommendation, and generation.

## Technical note

This industry talk from Zalando presents a single Transformer-based recommender reused across many fashion-inspiration use cases (outfit ranking, in-session recommendation, related items, personalized outfit generation) instead of separate end-to-end systems. Users are modeled as sequences of heterogeneous interactions (items, outfits, creators) of different types (click, wishlist, purchase), trained with a causal language modeling objective and a target mask so only chosen entity types contribute to the loss; outfit generation uses an encoder-decoder variant to learn fashion compatibility. Temporal recency inputs model sessions for long- and short-term interests, and cold-start users are served via static context and cross-entity interactions. Live A/B tests report engagement/retention gains up to ~130%, with a serving design coupling data processing to the model giving ~2x lower p99 latency and ~3x better scalability.
