Existing web-scale recommendation systems commonly use supervised learning methods that prioritize immediate user feedback. Although reinforcement learning (RL) offers a solution to optimize longer-term goals, such as in-session engagement, applying it at web scale is challenging due to the extremely large action space and engineering complexity. ## Technical note

RecoMind (Pinterest) is a simulator-based reinforcement learning framework for optimizing session-based goals like in-session engagement at web scale, where RL is hard due to the extremely large action space and engineering complexity. It uses a simulator built from recommendation logs to train RL policies that optimize longer-term in-session satisfaction rather than only immediate supervised feedback. The paper demonstrates effective optimization of session-based objectives at web scale, addressing challenges that standard supervised recommenders miss.
