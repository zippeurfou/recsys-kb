## Summary

Current LLM recommendation systems (LLM4Rec) often use shallow matching like humans think quickly (System 1), leading to inaccurate recommendations. The ThinkRec framework proposes shifting this approach by incorporating thinking steps, augmenting item data with summaries and guiding models through reasoning traces using keywords from user interactions. This allows the system to reason more deeply (System 2 style) before making a recommendation, resulting in more accurate and interpretable suggestions for users.

## Technical note

Existing LLM4Rec methods operate in an intuitive System-1 manner, matching items by superficial click-history similarity rather than reasoning through deeper behavioral logic, yielding shallow or wrong recommendations. ThinkRec shifts LLM4Rec toward System-2 reasoning via a thinking-activation mechanism that injects synthetic reasoning traces (distilled from QwQ) and jointly trains on binary recommendation labels (BCE) and reasoning explanations, plus item metadata keyword augmentation. It adds an instance-wise expert fusion mechanism that clusters users by latent collaborative features and dynamically fuses group-specific LoRA experts through a cosine-similarity gating over user embeddings. On ML1M, Yelp, and Amazon-Book it outperforms SOTA baselines (e.g. CoLLM) by ~7.96% average AUC and 56.54% METEOR, with cross-domain transfer retaining >90% performance and <10% inference latency overhead via a single fused-LoRA forward pass.
