## Summary

Current generative recommendation systems using Semantic IDs suffer from poor alignment between the ID space and generation space, and suboptimal quantization leading to semantic loss. To address these issues, the paper introduces DOS (Dual-Flow Orthogonal Semantic IDs), which employs a user-item dual flow framework to better align the spaces and an orthogonal residual quantization scheme to preserve semantics more effectively. The method is validated through extensive offline experiments and online A/B testing, demonstrating significant improvements, and has been successfully deployed in Meituan's mobile app for hundreds of millions of users.

## Technical note

DOS improves generative recommendation with Semantic IDs at Meituan by fixing two weaknesses: poor alignment between the ID space and the generation space, and semantic loss from suboptimal quantization. It introduces a user-item dual-flow framework that better aligns the semantic-ID space with the generation space, and an orthogonal residual quantization scheme that preserves more semantics than standard residual quantization. Extensive offline experiments and online A/B tests show significant gains. The method is deployed in Meituan's app serving hundreds of millions of users.
