## Summary

1.  Existing Mixture-of-LoRAs (MoL) models for LLM finetuning use learnable routing weights, which become imbalanced during training, limiting the effective number of LoRAs and hindering model expressiveness.
2.  The paper introduces ReMix, a novel router design that uses non-learnable routing weights to ensure all active LoRAs contribute equally, addressing the imbalance issue inherent in previous methods.
3.  To train this non-learnable router, ReMix employs an unbiased gradient estimator based on reinforcement learning (using the reinforce leave-one-out technique), enabling effective training and demonstrating significantly better performance than state-of-the-art methods using a similar number of activated parameters.

## Technical note

The paper diagnoses routing weight collapse in Mixture-of-LoRAs models: learned softmax routers concentrate nearly all weight on a single LoRA even when k>1 are activated, so the effective support size drops toward 1 and the extra LoRAs' compute is wasted, worsening as fine-tuning progresses. ReMix (Reinforcement Routing for Mixture-of-LoRAs) fixes this by using constant, non-learnable routing weights across active LoRAs so no adapter dominates, adding no inference cost. Because constant weights are non-differentiable, router training is recast as reinforcement learning with the supervised fine-tuning loss as negative reward and the router as policy, trained with an unbiased REINFORCE leave-one-out (RLOO) gradient estimator that reduces variance and scales with compute. Experiments show ReMix outperforms state-of-the-art PEFT baselines under matched activated-parameter budgets.
