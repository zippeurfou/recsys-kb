## Summary

This paper introduces CoeusBI, an advanced interactive Business Intelligence (BI) system at Baidu leveraging Large Language Models. Existing systems struggle with complex JOIN queries and wide schemas when generating SQL automatically for BI tasks using natural language interfaces.

CoeusBI employs a Dual-Agent Architecture to overcome these challenges: an offline View Generation Agent simplifies complex queries into single-view formats, and a dynamic Routing Agent handles multi-round dialogues by modifying or synthesizing representations before compiling dialect-agnostic SQL via a deterministic compiler.

The system features a Hierarchical Schema Linking module for efficient schema navigation with wide schemas. CoeusBI significantly improves query accuracy, token efficiency, and user satisfaction compared to current methods and is successfully deployed in production at Baidu, serving thousands of users daily.

## Technical note

CoeusBI is a deployed industrial NL2SQL business-intelligence system built around a Dual-Agent Architecture plus a Hierarchical Schema Linking module. An offline View Generation Agent uses error feedback to autonomously convert complex multi-table JOIN queries into simple single-view queries, eliminating manual semantic modeling; the Hierarchical Schema Linking module uses vector retrieval over views to scale to very wide schemas (up to ~219 columns per view). A Routing Agent evaluates dialogue context to either synthesize a new intermediate representation or modify an existing one for multi-round dialogues, then a deterministic, dialect-agnostic SQL compiler produces the final query to avoid LLM hallucination. It is deployed at Baidu across video, search, and advertising lines serving thousands of daily users, improving accuracy and token efficiency over baselines.
