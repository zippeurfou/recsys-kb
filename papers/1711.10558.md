## Summary

Current recommender systems often lack awareness of the user's actual intent, providing recommendations based solely on history without understanding the underlying reason for the request. This paper introduces an "Intent-Aware Contextual Recommendation System" designed to capture user activity within sessions, encode this activity, and factorize user-item interactions to score intent awareness. The system then combines these intent-aware representations with contextual information and standard ranking techniques to generate final recommendations, using feedback for model updates, and was shown to outperform baselines on real-world data.

## Technical note

The paper targets recommending business-analytics reports by inferring a user's session-level intent rather than relying on history alone. It builds a per-user navigation graph (a Markov model) for frequency-based signals, and separately models context by assembling report features into a sparse context tensor that is decomposed with PARAFAC2 to obtain low-dimensional latent factors. A Kalman filter enforces sequential dynamics on these latent factors, and users are clustered via k-means for group-based collaborative recommendations. Intent scores from the context model are combined with the Markov frequency model to produce top-k recommendations, and the approach beats baselines on real timestamped activity data.
