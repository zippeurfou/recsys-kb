## Summary

Generative Retrieval (GR) systems map queries to Semantic IDs (SIDs) for item retrieval, but existing methods struggle with the static nature of SIDs failing to capture dynamic user intent, leading to relevance issues, and suffer from slow inference due to beam-search decoding.

To overcome this, the authors introduce CHAP (Cross-component Hierarchical Semantic Alignment for Personalized Generative Retrieval), a framework that bridges the semantic gap by aligning query intent hierarchically with item representations, using both discrete SIDs and continuous semantic data.

CHAP further improves efficiency by replacing the multi-step beam-search decoder with a Residual Cascading Generation mechanism, allowing single-pass inference. Its effectiveness and practical value are demonstrated through extensive experiments on multiple datasets and online A/B tests.

## Technical note

CHAP is a personalized generative-retrieval framework from Meituan for local-life service search, attacking three gaps in TIGER-style GR: semantic IDs trained only on item content do not match dynamic query intent, GR rarely models user behavior sequences, and autoregressive beam-search decoding is too slow to serve. Stage one, Hierarchical Semantic Alignment, freezes an item-pretrained RQ-VAE codebook (depth L=3, size K=512) and trains the query encoder into it with three losses: Cross-Sample Alignment (a cross-commitment loss pulling the query residual r_q^l onto the target's selected code plus a cross-reconstruction loss forcing the target content d_t to be decodable from the query's quantized z_q), Hierarchical-Aware Contrastive Learning (InfoNCE between query and target partial quantizations accumulated to each depth l, enforcing coarse-to-fine agreement), and Soft Probability Distillation (KL from the frozen item-side soft code assignment to the query encoder's), combined as L_CSA + 0.01*L_HCL + 0.001*L_Distill. Stage two builds a dual-view sequence: each interaction contributes both an aggregated-codebook sparse vector and the raw language-model dense vector, and the decoder is initialized only from the query's dual representation so it must cross-attend back over history. Residual Cascading Generation then runs the Transformer decoder exactly once and offloads per-level code prediction to lightweight residual blocks h^(l+1) = ResBlock(Concat[h_dec_sparse, e_c^l]) + h^(l), with a dense head on Concat[h_dec_dense, z_hat]; M=50 candidate SIDs are sampled in parallel and scored by the product of temperature-normalized (tau=1.1) sparse log-probability and dense cosine similarity. Using BERT-base and T5-base (Chinese-BERT and mT5 for Chinese data) across ESCI-us, KuaiSearch, Amazon and a 10.1M-item / 3.09M-query industrial Local-Life set, CHAP sets SOTA against 14 baselines: on Local-Life R@10 0.5803 versus COBRA 0.5020, R@50 0.8085 versus 0.6057, MRR@10 0.3302 versus 0.2810; on ESCI-us R@10 0.1127 versus 0.0626 for DeepCT. Throughput is 78.9 QPS against 40.5 for the autoregressive ablation and 32.4 for COBRA. A 14-day A/B at 20 percent traffic served via NVIDIA Triton gave +0.77 percent UV-CTR, +2.09 percent UV-CXR and +2.98 percent pay orders. Stated limitations: the frozen item codebook blocks collaborative-signal updates to item representations, and only RQ-VAE-style hierarchical IDs were tested.

- w/o HSA: Replaces our trainable, aligned query encoder with a standard RQ-VAE encoder whose weights are strictly frozen after the item-side pre-training stage
- w/o $\mathcal{L}_{\mathrm{CSA}}$: Excludes the cross-sample alignment losses (both Cross-Commitment and Cross-Reconstruction), relying only on contrastive and distillation objectives
- w/o $\mathcal{L}_{\mathrm{HCL}}$: Removes the hierarchical-aware contrastive learning objective, eliminating the explicit multi-granular alignment penalty
- w/o $\mathcal{L}_{\mathrm{Distill}}$: Omits the soft probability distillation module that regularizes the fine-tuned encoder’s output distribution
- w/o Dense Refinement: Eliminates the dense continuous vector from both the input sequence and the generation target. The model relies entirely on discrete sparse SIDs for sequence modeling and ranking
- w/o Residual Gen. (Autoregressive): Replaces the lightweight layer-wise residual fusion mechanism with a standard flat autoregressive generation, forcing the heavy Transformer Decoder to execute sequentially for all $L$ layers
- w/o Self-Attention: Retains the residual cascading mechanism but structurally removes all Masked Self-Attention sub-layers within the Transformer Decoder, retaining only the Cross-Attention mechanism to interact with the encoded history
- w/o Decoder (Pooling + MLP): Entirely removes the Transformer Decoder. Instead, it relies on mean pooling over the encoder’s outputs to derive a static global context vector, which is then fed directly into the residual blocks for SID and dense vector prediction
- General: This segment is exactly the entire set of the Local-Life dataset. It encompasses the natural flow of daily user search traffic, reflecting the macroscopic ranking ability of the model across all scenarios
- Ambiguous: This segment comprises short, highly ambiguous queries with generalized intents (e.g., “Dinner”, “Nearby attractions”, “Weekend entertainment”). These queries typically map to a vast number of potential candidate items across multiple categories. Excelling in this segment rigorously tests the model’s Personalized Sequence Modeling capability, as accurate retrieval strictly requires deducing explicit user preferences from historical behaviors to disambiguate the broad intent
- ColdStart: This segment targets queries that exclusively lead to items introduced to the platform within the last 14 days. These items have extremely sparse or zero historical click logs. Standard generative models typically struggle on these data because they lack collaborative training signals for the new SIDs and fail to integrate dense representations for semantic fallback. This scenario directly evaluates the model’s pure zero-shot semantic matching capability
- LongTail: This segment focuses on queries whose historical interaction frequencies fall into the bottom 10% of the entire search logs (e.g., highly specific long-tail constraints, niche store names, or complex negated conditions). Similar to the ColdStart segment, standard GR models often exhibit poor performance on these data because they do not combine dense representations to capture precise textual semantics, falling back instead on memorized popularity bias. In contrast, excelling in this segment heavily relies on our model’s intrinsic Hierarchical Semantic Alignment (HSA) and dual-view design to accurately map complex linguistics (arXiv:2608.30553)
