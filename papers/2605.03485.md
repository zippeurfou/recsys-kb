## Summary

This paper introduces MHPR, a new benchmark designed to evaluate large vision-language models (LVLMs) on complex human-centric understanding tasks, which previous benchmarks largely ignored. MHPR provides diverse data formats (raw, SFT, RL, test) covering individual, multi-person, and human-object interactions, along with a tool (ACVG) for generating high-quality annotations. The authors show that using MHPR data, particularly SFT and RL data derived from challenging examples, significantly improves LVLM performance on perception and reasoning, even enabling smaller models like Qwen2.5-VL-7B to achieve near-parity with larger models.

## Technical note

MHPR is a benchmark for joint perception-reasoning over human-centric scenes across individual, multi-person, and human-object dimensions, evaluated on LVLMs. It introduces a four-tier data stack (Captioned Raw Data, SFT-D, RL-D, Test Data) and an automated caption/VQA pipeline (ACVG) that uses category-wise attribute decomposition, attribute-specific rewriting, and multi-model voting to reduce manual curation. RL-D is constructed via bad-case analysis on test errors to target difficult perception and reasoning instances. Training Qwen2.5-VL-7B on MHPR yields near-parity with much larger models, with format-aligned SFT improving instruction following and stability.
