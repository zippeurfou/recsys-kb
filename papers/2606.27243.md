## Summary

This paper introduces NOVA, a "verification-aware" agent framework designed to automate the complex process of evolving recommendation system architectures in production environments.

NOVA uses an architecture gradient derived from previous modifications and feedback to guide agents towards meaningful improvements, preventing failures by implementing cascaded checks that filter out invalid candidates early.

Deployed successfully in industrial advertising systems, NOVA significantly reduces silent failures compared to coding agents while achieving higher pass rates for complex tasks like structural upgrades (L2/L3), and demonstrably improves business metrics through successful architecture changes.

## Technical note

NOVA is a verification-aware agent harness that automates recommender architecture evolution in production ads systems. It represents each candidate as (model graph, structural hyper-parameters, feature config) and drives search with an SGD-inspired 'architecture gradient' that aggregates the prior modification, verification diagnostics, offline metric delta, and trajectory memory into weak-component, modification-direction, and forbidden-direction signals. A multi-stage verification cascade (structure semantics -> local executability -> offline AUC -> online impact) blocks 'silent failures'—runnable but structurally invalid candidates such as degenerated self-attention or removed sequence masking—recording failures as reusable forbidden directions. L1-L4 task levels route high-risk edits to human Copilot oversight; deployed online it improved GMV across three pCVR objectives (+1.25/+1.70/+2.02%) while cutting pCVR bias.
