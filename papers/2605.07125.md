## Summary

1.  The paper introduces a surprisingly simple graph-based heuristic for sequential recommendation that outperforms many complex generative models on standard benchmarks.
2.  This heuristic uses only local item transitions and item features, finding that datasets often contain "shortcut structures" (like low-branching or feature-smooth transitions) that make accurate next-item prediction easy using simple methods.
3.  The authors conclude that strong performance on these benchmarks can sometimes be achieved via simple shortcuts, not necessarily through advanced modeling, calling for more careful benchmark selection and analysis in the field.

## Technical note

This paper audits sequential-recommendation benchmarks with an intentionally simple, training-free graph heuristic: from only the last one or two interacted items it retrieves candidates from a few-hop item-transition graph and ranks them by item-feature similarity with a small direct-edge bonus. Despite having no sequence encoder, generative objective, or learned user representations, it matches or beats modern generative recommenders, e.g., +38.10% and +44.18% NDCG@10 on Amazon Sports and CDs. The authors attribute this to three shortcut structures: low-branching local transitions, feature-smooth transitions, and limited dependence on long histories. Across 14 datasets the heuristic stays competitive on 10, arguing that standard benchmarks may be shortcut-solvable and calling for capability-aligned benchmark selection.

- Sem-NN ranks candidate items according to their pretrained language-model embedding similarity to the anchor item, serving as a content-based lower bound
- ID+Sem combines ID-Last and Sem-NN by integrating collaborative item-transition signals with semantic item similarity
- LightGCN  simplifies GCN-based collaborative filtering by retaining only linear neighborhood aggregation and using layer-averaged embeddings as the final representation. For fair comparison with sequential baselines, we apply the same propagation rule on a global item-item transition graph constructed from training sequences. We also leverage the item text embeddings as the node features
- SR-GNN  models each session as a directed graph and uses a gated graph neural network to capture complex item transitions. It then combines global session preference and current interest with attention for next-item recommendation
- SASRec  is a Transformer-based sequential recommender that models user interaction histories with causal self-attention and predicts the next item by matching the sequence representation with item embeddings
- HSTU  is a generative sequential recommender that reformulates ranking and retrieval as sequential transduction tasks. It encodes user actions into a unified sequence and uses efficient hierarchical sequential transduction units for long-sequence recommendation modeling
- TIGER  is a generative retrieval framework for sequential recommendation. It represents each item with a short discrete semantic ID produced by an RQ-VAE  tokenizer trained on item content embeddings, and trains an encoder–decoder Transformer to autoregressively generate the semantic ID of the next item
- LETTER  improves the RQ-VAE tokenizer by introducing collaborative-filtering alignment with SASRec  embeddings and a codebook-diversity loss to alleviate codebook collapse and semantic ID collisions
- CoFiRec  extends the RQ-VAE tokenizer with a hierarchical design that separately quantizes textual views and collaborative signals into semantic IDs, which are then used by a TIGER-style encoder–decoder generator
