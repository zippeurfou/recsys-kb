## Technical note

PerSRec (from Meta/FAIR) is an efficient sequential-recommendation method that compresses long user interaction histories into learnable 'personal expert' tokens, which are combined with recent interactions to generate recommendations, avoiding the sub-optimality of disconnected sampling/clustering two-stage methods and the quadratic cost of transformers. The compression is a plug-in applicable to existing transformer-based recommenders including HSTU and HLLM. Extensive experiments across multiple SOTA architectures show it reduces computational cost significantly while matching or exceeding accuracy; code is open-sourced (facebookresearch/PerSRec).
