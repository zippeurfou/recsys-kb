Large language models (LLMs) have recently been adopted for recommendation by framing user preference modeling as a language generation problem. However, existing latent reasoning approaches typically represent user intent with a single latent vector, which struggles to capture the inherently multi-faceted nature of user preferences. ## Technical note

FLR (Factorized Latent Reasoning, Meituan) improves LLM-based sequential recommendation by decomposing latent reasoning into K disentangled preference factors rather than a single monolithic latent vector that entangles multi-faceted user intent. A lightweight multi-factor attention module iteratively refines a latent thought representation where each factor attends to distinct aspects of the interaction history, factors are dynamically aggregated via a gating module, and orthogonality, attention-diversity, and sparsity regularization objectives enforce non-redundant, interpretable specialization. FLR further integrates GRPO to perform reinforcement learning directly in the factorized latent reasoning space (no token-by-token path sampling). Across multiple benchmarks FLR consistently beats strong baselines while improving robustness and interpretability.
