## Summary

Dynamic In-Context Learning for Automated Brick Schema Classification":

Building Management Systems face integration challenges due to non-standardized data points and the large complexity (936 classes) of the Brick schema. To address this, researchers propose **Brick-DICL**, a novel two-stage dynamic in-context learning framework that uses RAG-based components (**metadata-RAG** for domain knowledge and **class-RAG** for narrowing options) to automatically classify BMS metadata into relevant Brick classes. This approach, coupled with multi-LLM filtering, significantly improves classification accuracy while drastically reducing manual verification effort, making it generally applicable and efficient for creating interoperable building systems.

## Technical note

Brick-DICL is a two-stage dynamic in-context learning framework for mapping non-standardized building management system (BMS) metadata points to Brick schema classes, addressing the 936-class space and LLMs' limited domain knowledge. Stage one uses a metadata-RAG that embeds and indexes points in a vector database to retrieve top-K correctly-classified similar examples for the LLM's initial prediction; stage two uses a class-RAG that retrieves the most relevant candidate Brick classes to narrow the classification space. A multi-LLM filtering mechanism compares predictions across models, flagging low-confidence or discrepant cases for human review to reduce manual verification effort. Evaluated on two building datasets, it improves classification accuracy and efficiency over baselines and is presented as the first dynamic ICL approach for Brick classification.
