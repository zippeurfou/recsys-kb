Video personalization, which generates customized videos using reference images, has gained significant attention. However, prior methods typically focus on single-concept personalization, limiting broader applications that require multi-concept integration. ## Technical note

Movie Weaver is a tuning-free multi-concept video personalization diffusion model that weaves multiple reference images (face, body, animal) into one video while avoiding identity blending. It introduces anchored prompts—unique text tokens ([R1], [R2]) injected after each concept description to bind each concept to its specific reference image—and concept embeddings that add a uniform per-image embedding to encode reference-image order (since cross attention is order-agnostic). It requires only input modifications (no architectural or per-identity tuning) and outperforms prior methods in identity preservation and overall quality via an automatic data-curation pipeline.
