## Summary

SkillOS addresses the challenge of LLM-based agents learning from past interactions by introducing an experience-driven reinforcement learning (RL) system. It pairs a frozen agent executor with a trainable skill curator that updates an external SkillRepo based on accumulated experiences. SkillOS uses composite rewards and trains on grouped task streams to learn complex long-term skill curation policies, enabling agents to self-evolve more effectively and efficiently than existing methods.

## Technical note

SkillOS is an experience-driven RL recipe that pairs a frozen agent executor (retrieves skills via BM25 and acts) with a trainable skill curator that inserts, updates, and deletes Markdown skills in an external SkillRepo. To supply learning signal for delayed, indirect feedback, training instances are groups of skill-related tasks solved sequentially, so skills distilled from earlier tasks are evaluated on later related ones. The curator is optimized with GRPO under a composite reward combining downstream task success, function-call validity, LLM-judged skill quality, and a compression term that penalizes verbatim trajectory copying. On ALFWorld, WebShop, and single-turn reasoning (AIME24/25, GPQA), an 8B curator beats memory-free and strong memory baselines and generalizes across executor backbones including Gemini-2.5-Pro.
