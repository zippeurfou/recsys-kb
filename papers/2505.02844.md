## Summary

This paper addresses CTR prediction in recommender systems, where models are typically updated incrementally using new data and historical subsets. However, feature embeddings can become outdated ("stale") when corresponding features are absent from recent updates, leading to performance degradation for samples containing them. The authors propose FeSAIL (Feature Staleness Aware Incremental Learning), which combats this by adaptively replaying examples with stale features through a sampling algorithm prioritizing recency and frequency in a sliding window, along with a regularization mechanism refining embedding updates based on staleness scores. Experiments show that their method significantly outperforms state-of-the-art alternatives using standard deep learning models like DNN/DIN/DCN across benchmark datasets.

## Technical note

FeSAIL addresses the feature-staleness problem in incrementally-trained CTR models: when features are absent from recent incremental data their embeddings go stale and become incompatible with updated high-level layers, degrading AUC on later samples. It proposes staleness-aware sampling (SAS), which fills a fixed-size reservoir with samples covering as many low-staleness features as possible, formulated as a maximum weighted coverage problem and solved greedily with a 1-1/e approximation guarantee. A staleness-aware regularization (SAR) mechanism then controls how strongly stale embeddings are updated to avoid overfitting long-absent low-frequency features. Instantiated on a general deep CTR model, FeSAIL achieves about 1.21% average AUC improvement over state-of-the-art incremental-learning baselines across four datasets.
