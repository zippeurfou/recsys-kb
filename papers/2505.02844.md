Click-through Rate (CTR) prediction in real-world recommender systems often deals with billions of user interactions every day. To improve the training efficiency, it is common to update the CTR prediction model incrementally using the new incremental data and a subset of historical data. ## Technical note

FeSAIL (Feature Staleness Aware Incremental Learning) addresses the feature staleness problem in incrementally updated CTR prediction models, where feature embeddings become stale and incompatible with updated high-level layers when their features are absent from recent incremental data, degrading AUC on samples with stale features. It introduces a staleness-aware sampling algorithm (SAS) that uses a fixed-size reservoir and solves a maximum weighted coverage problem greedily (1-1/e approximation) to efficiently replay stale samples, plus a staleness-aware regularization (SAR) for fine-grained control of embedding updates. On four benchmark datasets FeSAIL achieves ~1.21% average AUC improvement over state-of-the-art incremental learning methods for CTR prediction.
