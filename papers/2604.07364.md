## Technical note

This eBay paper presents a training-free, character-level retrieval framework for alphanumeric identifiers (MPNs, SKUs, model codes) that are sparse, non-linguistic, and brittle under tokenization and typos, where lexical and dense-embedding retrieval fail. Each alphanumeric sequence is encoded as a fixed-length binary vector enabling efficient nearest-neighbor retrieval via Hamming distance (e.g. Multi-Index Hashing / HNSW), with an optional edit-distance re-ranking stage to refine precision under latency guarantees. Used as a low-latency candidate generator / related-query suggester, it is interpretable, has a small memory footprint, and delivers significant business-metric gains in an A/B test.
