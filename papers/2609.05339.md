## Summary

This paper investigates how an agent's memory retains accuracy after a model upgrade. It compares four memory types: verbatim long-context, chunked RAG, compressed notes, and normalized knowledge graph. The study found that structured KG-fixed memories transfer reliably, while compressed NOTES memories are highly model-dependent and show significant accuracy degradation. Key recommendations for reliable memory migration involve direction-specific testing, embedding isolation, and storing the original source history.

## Technical note

A LinkedIn-affiliated controlled study of whether an LLM agent's persistent memory store survives a model upgrade; this is an agent-memory reliability paper and not a recommender-systems paper, though it is directly about retrieval and embedding migration. Four memory formats are compared under matched budgets: LC-RAW full transcript, RAG chunks over a single-stage dense retriever (bge-large-en, cosine top-k=8, no reranker or lexical search), model-written NOTES capped at 128 KiB, and a fixed-schema subject-predicate-object knowledge graph. The workload is 48 synthetic histories with randomized answer codes and 160 exactly scored questions each, written and read by Llama-3.1-8B-Instruct and Qwen2.5-7B-Instruct-1M, with four hypotheses and a 5-point action threshold locked in a signed Git tag before data collection. KG-fixed is essentially writer-independent (swap delta +0.0004 +/- 0.0020, own-store accuracy 0.845 Llama and 0.988 Qwen) while NOTES is strongly model-coupled and asymmetric: Qwen-written notes lift Llama by +9.91pp but Llama-written notes cost Qwen -13.28pp, so the symmetrized contrasts H1 (-1.47pp) and H4a (-1.51pp) hide a real failure. Upgrading bge-large-en v1.0 to v1.5 with a 50/50 mixed index captures only +4.96pp of the +11.90pp full-re-embed gain and fails silently because both models emit 1024-dim vectors (H2 supported at +6.95pp). Diagnostic decomposition attributes 80% (0.467 +/- 0.014 of a 0.584 deficit) of NOTES loss to the writing stage and 81% (0.364 +/- 0.012 of 0.450) of RAG loss to retrieval misses, with RAG surfacing the needed evidence only about 60% of the time. Store-only NOTES repair never reaches 90% of own-store performance in any of 48 cases, while raw-history repair succeeds in 34 of 48 for Qwen at roughly $0.76 median cost and 0 of 48 for Llama because every attempt hits the output-token limit; RAG re-embedding recovers all 96 cases at about $0.013 each. Caveats: two sub-10B models, one cross-family migration direction pair, scripted synthetic histories, and the pre-registered bootstrap was run only after the t-tests.
