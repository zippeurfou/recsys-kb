## Summary

(Abstract fallback)

Inspired by scaling laws and large language models, research on large-scale recommendation models has gained significant attention. Recent advancements have shown that expanding sequential recommendation models to large-scale recommendation models can be an effective strategy. Current state-of-the-art sequential recommendation models primarily use self-attention mechanisms for explicit feature interactions among items, while implicit interactions are managed through Feed-Forward Networks (FFNs)....

## Technical note

FuXi-alpha is a scalable recommendation transformer that improves on HSTU by better modeling feature interactions and temporal/positional information. It introduces an Adaptive Multi-channel Self-attention (AMS) layer that separately models temporal, positional, and semantic features (rather than adding them to attention weights) and a Multi-stage FFN to strengthen implicit feature interactions that HSTU underemphasizes. Offline it outperforms existing models with performance improving as model size grows, and an online A/B test in the Huawei Music app raised average songs played per user by 4.76% and listening duration by 5.10%.
