## Summary

(Abstract fallback)

Cross-domain recommendation is a core problem in content-to-e-commerce platforms. Its objective is to leverage user interactions with content to infer potential purchasing intent on the e-commerce side, thereby enhancing conversion rates and commercial value. However, in real industrial scenarios, cross-domain recommendation faces multiple challenges: significant semantic gaps exist between different domains, and user cross-domain behavior sequences are often massive in scale and rich in noise. ...

## Technical note

Atomic Intent Reasoning (AIR) is an LLM-driven cross-domain recommendation framework for Kuaishou's content-to-e-commerce scenario that keeps LLM semantic reasoning under millisecond latency by moving inference offline. Offline, LLMs distill user events, attributes, and item descriptions into atomic behavior-intent units stored in an intent knowledge base; online, the system retrieves and composes cached atomic intents without invoking LLMs, giving roughly a 400x throughput gain over real-time LLM calls. It builds a unified user intent tree with target-aware semantic retrieval to extract compact high-evidence intents from long noisy multi-scenario histories, fused via multi-head attention for CTR prediction and ranking. It reaches SOTA on public benchmarks, and a Kuaishou E-commerce A/B test shows +3.446% GMV plus gains in paid orders, GPM, and OPM.
