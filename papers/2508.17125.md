## Summary

(Abstract fallback)

In large-scale recommender systems, ultra-long user behavior sequences encode rich signals of evolving interests. Extending sequence length generally improves accuracy, but directly modeling such sequences in production is infeasible due to latency and memory constraints. Existing solutions fall into two categories: (1) top-k retrieval, which truncates the sequence and may discard most attention mass when L >> k; and (2) encoder-based compression, which preserves coverage but often over-compress...

## Technical note

Kuaishou's VQL is an end-to-end context-aware Vector Quantization Attention framework for ultra-long user behavior modeling that beats top-k retrieval (TWIN, ETA) and encoder compression (MIMN) approaches. Its key-only quantization compresses only attention keys while keeping values intact, provably yielding attention-weight error independent of sequence length L and enabling L-free cached inference; multi-scale grouped VQ across attention heads further suppresses error, and a separable temporal kernel injects context query-free. On KuaiRand-1K, KuaiRec, and TMALL, VQL consistently outperforms strong baselines with higher accuracy and substantially lower inference latency.
