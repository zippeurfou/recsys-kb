## Summary

This paper introduces a new cold start recommendation model that integrates contrastive learning to overcome performance degradation due to scarce interaction data by dynamically adjusting feature weights and effectively fusing user attributes, item meta-information, and contextual features.

The core technique involves an adaptive feature selection module assigning dynamic importance to key features combined with a multimodal fusion mechanism for integration, while the contrastive learning component enhances robustness and generalization through positive/negative sample pairs.

Experiments on MovieLens-1M show that this model significantly outperforms traditional methods like Matrix Factorization and DeepFM in recommendation metrics (HR, NDCG, MRR, Recall), especially during cold starts.

## Technical note

This paper proposes a cold-start recommendation model combining contrastive learning with adaptive multimodal feature fusion to counter data sparsity for new users/items. It maps user and item features to a shared space via encoders, uses an attention-based adaptive feature-selection module to weight feature dimensions, and applies an InfoNCE contrastive loss over interacted (positive) vs non-interacted (negative) user-item pairs, plus a GCN module to mine implicit high-order user-item relationships; the total loss adds contrastive and cross-entropy recommendation terms. On MovieLens-1M under a cold-start split it beats Matrix Factorization, LightGBM, DeepFM, and AutoRec (HR 0.556, +10.7% over DeepFM), with ablations confirming each module and a learning-rate sensitivity sweet spot at 0.005.
