## Summary

This paper introduces Sparse Layer Sharpness-Aware Minimization (SL-SAM), designed to improve the efficiency of the Sharpness-Aware Minimization (SAM) algorithm used for fine-tuning machine learning models. SL-SAM tackles SAM's high computation cost by dynamically selecting only parts of the model layers for the critical parameter perturbation and update steps during each iteration, treating this selection as a multi-armed bandit problem. Experiments demonstrate that SL-SAM achieves performance comparable to standard methods while significantly reducing the number of active parameters during computation, making it a much more efficient fine-tuning technique.

## Technical note

SL-SAM injects adaptive layer-wise sparsity into both the perturbation (gradient-ascent) and update (gradient-descent) steps of Sharpness-Aware Minimization, activating only a subset of layers per iteration to cut SAM's doubled gradient cost. Layer selection is framed as a multi-armed bandit problem, using each layer's gradient norm as a reward signal via an EXP3-style distribution update to balance exploration and exploitation. The authors prove an O(T^-1/4) convergence rate matching vanilla SAM. On DeiT/RoBERTa/Llama-3.2-3B fine-tuning, SL-SAM activates as few as 21-47% of parameters per pass while matching baseline accuracy and cutting wall-clock time up to ~25%. An extension couples the sparse layer selection with single-step S2-SAM for further savings.
