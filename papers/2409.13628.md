## Summary

1.  The paper addresses the challenge of accurately extracting attributes for beauty product recommendations, which is currently unreliable.
2.  It introduces an end-to-end supervised learning system using a novel energy-based implicit model architecture, specifically analyzing product ingredients, significantly improving accuracy, explainability, and the ability to adapt to new attributes.
3.  Validated on a large e-commerce dataset, the system demonstrates how ingredient-based attribute extraction enhances the explainability of beauty product recommendations, making them more trustworthy for users.

## Technical note

Presents BT-BERT, an energy-based implicit model for extracting beauty-product attributes (5 skin types, 11 concerns, 17 preferences) from product ingredients and title, motivating explainable beauty recommendation. The architecture is a BERT encoder whose final feed-forward layer is removed so logits are read directly from last-layer self-attention over a query attribute concatenated with ingredients/title, framing extraction as implicit (query-conditioned) rather than an explicit fixed-class classifier. On an expert-annotated skincare catalog it reaches 0.964 accuracy / 0.987 precision, beating an explicit bge-base classifier and a fuzzy-search baseline, and stays robust in low-data regimes (drops <1.25% at 1/8 data) via implicit augmentation from pairing each product with all 33 attributes. The implicit design allows adding new attribute labels by fine-tuning on the full dataset without replacing a classifier head, and attention tokens surface the specific ingredients (e.g., salicylic acid for acne) that justify predictions.
