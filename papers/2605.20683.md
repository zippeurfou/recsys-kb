## Technical note

This Amazon paper studies token compression for transformer cross-encoder document rerankers, which are costly because they process long query-document sequences at inference. Existing token compression aggregates tokens in the initial embedding layer to reduce the effective token count, and this work proposes layer-wise token compression that compresses progressively across layers rather than only at the input. The approach reduces reranking computation while aiming to preserve ranking quality on information-retrieval benchmarks such as MS MARCO.
