## Technical note

This paper studies the Continuous K-Max combinatorial multi-armed bandit with weak value-index feedback (each round select K arms, observe only the max value and its arm index), capturing ad selection, distributed computing, and server scheduling. It proposes DCK-UCB, combining adaptive discretization with bias-corrected confidence bounds to handle discretization error, non-deterministic tie-breaking, and biased partial-observation estimation, proving the first sublinear O~(T^{3/4}) regret for general continuous distributions. For exponential distributions under full-bandit feedback, MLE-Exp achieves near-minimax-optimal O~(sqrt(T)) regret via maximum-likelihood estimation.
