## Summary

This paper introduces DFGR, a Dual-Flow Generative Ranking Network for recommendation that uses raw user behavior sequences directly, eliminating the need for extensive manual feature engineering common in DLRM models.

DFGR employs a dual-flow mechanism by duplicating and splitting the sequence into real and fake flows based on action authenticity. It then innovates within the self-attention QKV module to define interactions between these flows.

Experiments show DFGR outperforms existing baselines (including DLRM) and state-of-the-art models like Meta's HSTU, while also being more efficient in training and inference compared to other architectures.

## Technical note

Meta's HSTU-based generative ranking (MetaGR) interleaves item and action tokens, doubling sequence length and causing quadratic self-attention overhead plus heterogeneous, unbalanced tokens. DFGR duplicates each user sequence into a real flow (true action types) and a fake flow (placeholder action types) that share weights; the fake flow computes attention using keys/values from the real flow's hidden states so each token sees full history without leaking its own action label, and loss is computed only on the fake flow, keeping one token per interaction. A session-aware cross-triangle mask zeros attention within the same session to avoid intra-session leakage during parallel scoring. DFGR reaches ~2x MetaGR training complexity and 4x inference speedup, and on RecFlow, KuaiSAR, and industrial TRec it beats DLRM, MetaGR, DIN, DIEN, DCN, and DeepFM (0.31%-1.2% AUC gains over MetaGR), while exhibiting a scaling-law relationship between compute and G-AUC.
