## Summary

(Abstract fallback)

Making deep learning recommendation model (DLRM) training and inference fast and efficient is important. However, this presents three key system challenges - model architecture diversity, kernel primitive diversity, and hardware generation and architecture heterogeneity. This paper presents KernelEvolve-an agentic kernel coding framework-to tackle heterogeneity at-scale for DLRM. ## Technical note

KernelEvolve is an agentic kernel-coding system from Meta that automatically generates and optimizes low-level compute kernels for heterogeneous AI accelerators (NVIDIA/AMD GPUs and Meta's MTIA) powering ads ranking, which deploys >1500 multi-stage retrieval/ranking models serving hundreds of trillions of inferences daily. It targets the combinatorial explosion of operators x hardware platforms x generations that makes manual kernel development infeasible, using LLM agents to synthesize hardware-specific implementations. Reported Triton kernels achieve up to ~2x speedups over torch.conv1d/conv2d on production tensor shapes. (Infra paper, tangential to core recsys modeling.)
