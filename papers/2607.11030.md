## Summary

1. Existing e-commerce search systems use Multimodal Large Language Models (MLLMs) fine-tuned with single collaborative signals to generate item features for ranking, which underutilizes multimodal data's potential.
2. To overcome these limitations and improve efficiency, researchers propose MMRM, a unified Multiplex Multimodal Representation Model that integrates multiple diverse collaborative signals using a shared backbone structure during inference.
3. MMRM generates comprehensive "multiplex" item representations by simultaneously learning from various input modalities (text, images etc.), and it further enhances user behavior modeling within ranking models. It has been shown to be effective through extensive experiments and is successfully deployed in JD.com's search engine.

## Technical note

E-commerce ranking methods that fine-tune MLLMs on a single collaborative signal and then treat multimodal embeddings as ordinary item features underutilize heterogeneous signals and user-behavior modeling. MMRM (initialized from Qwen3-VL-4B) aligns an MLLM with four graph-derived collaborative signals - search q2i click plus behavior i2i click/cart/order - using a shared backbone with task-specific [SEARCH]/[CLICK]/[CART]/[ORDER] tokens and per-task projection MLPs, trained with per-task contrastive loss using cross-task in-batch and hard negatives (GradCache to scale batch size), producing four disentangled multiplex item embeddings in one forward pass. Downstream, task-specific user representations are derived by soft-search (SIM) over behavior sequences with multi-head target attention (multi-head DIN) and fused via MMoE for CTR/ACR/CVR towers. MMRM beats single-task and Vanilla-Multi baselines on F1@5/NDCG@5, and SIM_soft(MMRM[ALL]) improves GAUC on all three tasks (CTR 0.6866->0.7037); deployed in JD e-commerce search with an online A/B lift of +0.42% UCTR, +0.37% UACR, and +0.35% UCVR.
