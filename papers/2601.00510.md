## Technical note

This eBay work proposes a semantic projection system for search query categorization in real-world hierarchical e-commerce taxonomies, complementing demand-based methods. It adapts chain-of-thought (CoT) reasoning with an LLM to navigate the taxonomy from root to leaf, integrating query semantics and taxonomy details to produce precise, interpretable query-to-category mappings that enrich and de-bias demand-based signals. To scale to millions of queries at low latency it proposes two approaches (the second more scalable); evaluations report large relative aggregation-level gains in categorization metrics over baselines.
