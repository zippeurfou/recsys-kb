## Summary

Existing AI tools for code editing often struggle with balancing accuracy and efficiency across large projects, being either too localized or lacking project-wide capability. This paper introduces TRACE, a novel system that improves upon this balance by combining two methods: neural-based induction for semantic edits and tool-based deduction for syntactic edits. TRACE specifically learns when to use each approach and enhances the neural model's performance through a new editing representation.

## Technical note

TRACE predicts project-wide subsequent code edits by interleaving a neural model that handles semantic edits (induction) with IDE tools such as rename-refactoring and use-def linting that deduce syntactic edits. A learned classifier decides when to invoke the deterministic IDE tools versus the neural editor, and a fine-grained edit representation boosts neural edit-location and edit-generation quality. Against CoEdPilot, GrACE, and CCT5 it improves edit location by 43.76% and edit generation by 11.16%, and beats Cursor's acceptance rate by 6.15% in an interactive simulation. A 24-participant user study shows TRACE excels at cross-file global edits and surfaces concerning user behavior around handling false tool predictions.
