## Summary

This paper addresses the challenge of recommending new ("cold-start") videos by using metadata as a starting point, since traditional methods rely heavily on user watch history. The proposed solution uses a two-tower model: one tower learns user representations from their history, while the other learns video representations from diverse metadata sources like text, categories, and images. Key contributions include demonstrating the model's feasibility, exploring different metadata types and an attention mechanism to effectively combine them, and showing improved recommendations for both new and existing items using proprietary Amazon data.

## Technical note

Adopts a two-tower model for video recommendation where a user tower encodes watch history and a video tower learns item representations from heterogeneous metadata, enabling recommendation of cold-start titles that lack watch history. The item tower fuses categorical features, TF-IDF-weighted word2vec synopsis embeddings, a pretrained ResNet cover-art embedding, and (for warm items) an ID embedding, combined by an attention layer that adaptively weights each modality. On proprietary Amazon Prime Video data, attention-based fusion beats direct concatenation and single-metadata models for warm-start recommendation, and for cold-start titles both variants greatly beat random, with the ID-free model performing best on precision/recall (since attention over-weights the ID when present). Analysis shows categorical features receive the highest attention weights and cover art the lowest.
