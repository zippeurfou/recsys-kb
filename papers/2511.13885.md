## Summary

Dense retrieval, used in e-commerce search, often relies on embedding models, but current methods using LLMs still depend on complex offline training with hard negatives, limiting model performance and iteration speed.

To overcome this, the authors introduce TaoSearchEmb, a multi-objective reinforcement learning framework. It eliminates the need for offline hard negatives by dynamically retrieving top-K candidates during training and uses an LLM reward model for real-time feedback.

The system optimizes embedding representations using RL with multi-objective reward signals, improving semantic generalization and query relevance, especially for complex searches, as demonstrated through effective offline and online experiments.

## Technical note

TaoSearchEmb (Retrieval-GRPO) is a multi-objective reinforcement-learning framework for dense retrieval in Taobao e-commerce search that eliminates costly offline hard-negative mining. After an SFT stage using InfoNCE with in-batch plus global negatives, it dynamically retrieves top-K candidates per query during training and uses a relevance LLM as a real-time reward model. Rewards fuse LLM relevance scores, product-quality scores, and multi-way exclusivity into a multi-objective signal optimized with GRPO, which mitigates the multi-task 'seesaw effect'. This improves semantic generalization on complex long-tail queries and has been deployed at scale.
