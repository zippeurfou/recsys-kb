## Summary

Traditional Business Intelligence systems struggle with Exploratory BI due to static schemas, high costs, and lack of reusability. This paper introduces ExBI, a novel system using a hypergraph model and operators to enable dynamic schema evolution and materialized view reuse, addressing these limitations. ExBI employs sampling-based algorithms with accuracy guarantees, demonstrating significant performance improvements (up to 146x faster than Neo4j and 230x faster than MySQL) while maintaining high accuracy (average error rate 0.27%) on LDBC datasets.

## Technical note

ExBI is a BI system for iterative exploratory analysis that replaces rigid star/snowflake schemas with a hypergraph data model built on a property-graph abstraction, exposing Source, Join, View, DrillDown, RollUp, Slice, and Dice operators to support dynamic schema evolution and reusable intermediate views. The Source operator performs induced subgraph matching (including non-existence semantics) which is intractable exactly at scale, so ExBI adapts the FaSTest algorithm for uniform match sampling and uses stratified group sampling for the Join operator. It provides end-to-end statistical guarantees for unbiased COUNT and SUM estimation, decoupling execution logic from storage. On LDBC datasets it reports average speedups of 16.21x over Neo4j and 46.67x over MySQL with only 0.27% average COUNT error.
