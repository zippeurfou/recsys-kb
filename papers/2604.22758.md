## Technical note

RedParrot accelerates natural-language-to-DSL translation for business analytics at Xiaohongshu by bypassing a costly multi-stage LLM pipeline (>30s, >26000 tokens/query) with a query semantic cache. It normalizes queries into structural 'query skeletons', matches new requests via an entity-agnostic embedding model trained with contrastive learning, and uses heterogeneous RAG (DSL config, column values, domain knowledge) to handle unseen entities. On six enterprise datasets it achieves 3.6x average speedup and 8.26% accuracy improvement; on Spider-DSL and BIRD-DSL benchmarks it boosts accuracy by 34.8% over in-context-learning baselines. Note: this is an NL-to-DSL/analytics paper, only tangentially a recsys paper.
