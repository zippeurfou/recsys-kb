## Summary

The paper introduces a framework to evaluate and compare different advanced Retrieval-Augmented Generation (RAG) approaches, including GraphRAG and Agentic RAG, specifically on semi-structured knowledge bases by implementing nine standardized scenarios.

Key findings include demonstrating token-efficient context management methods for these complex systems through novel representations and agent loops, reducing usage significantly (19%-53%). They also identify a "retrieval-generation gap," where simply retrieving more information does not guarantee improved generation quality, suggesting over-reliance on retrieval-oriented metrics can be misleading.

Ultimately, the research provides data-driven insights into optimizing RAG for production systems and clarifies when simpler document-based retrieval might suffice versus employing powerful hybrid or agentic solutions.

## Technical note

This paper introduces an evaluation framework with nine standardized RAG scenarios (Regular, GraphRAG, Modular, Agentic) over the semi-structured STaRK-Prime precision-medicine knowledge base (129K entities, 8.1M KG relations), evaluated end-to-end (LLM answer + selected entity IDs) with Hit@1/5, R@20, MRR using Claude 3.7 Sonnet. Empirically, simpler document RAG augmented with 1-hop relations and autonomous agentic RAG with minimal tools outperform elaborate GraphRAG (predefined-KG-only scores poorly), challenging assumptions about advanced retrieval. A three-fold context-optimization method (relation-grouped graph representation reducing O(n)->O(1) tokens for multi-relation pairs, session-level subgraph/document deduplication, and a hybrid ReAct-ReWOO batch retrieval loop) reduces token usage 19-53%. The reinvested token budget exposes a 'retrieval-generation gap': expanded retrieval (higher recall-of-retrieval before generation) does not proportionally improve answer quality, indicating retrieval-oriented metrics overstate advanced-retrieval benefits.
