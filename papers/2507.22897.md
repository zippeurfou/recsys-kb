## Technical note

RecUserSim is an LLM agent-based user simulator for evaluating conversational recommender systems (CRS) with enhanced realism, diversity, and explicit rating output. It comprises a profile module for realistic diverse personas (with conflict resolution), a memory module tracking interaction history and discovering unknown preferences, a core action module inspired by Bounded Rationality theory for fine-grained decisions, and a refinement module for output control. Experiments show it produces diverse, controllable, high-quality dialogues even with smaller base LLMs, and its generated ratings are highly consistent across different base LLMs, making it useful for CRS evaluation.
