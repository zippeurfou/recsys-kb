## Summary

This paper addresses the challenge of evaluating conversational recommender systems (CRS), which require multi-turn interactions but are hard to test thoroughly. They propose RecUserSim, an LLM-based user simulator designed for realism and diversity by incorporating modules like profile generation, memory tracking, bounded rationality-driven actions, and response refinement. Experiments show that RecUserSim generates diverse dialogues effectively and provides consistent explicit ratings useful for quantifying CRS performance across various scenarios.

## Technical note

RecUserSim is an LLM agent-based user simulator for evaluating conversational recommender systems (CRS), aiming for realism, diversity, and explicit quantitative ratings. It comprises four modules: a profile module (with conflict resolution) for diverse personas, a memory module tracking history with an unknown-preference-excitation mechanism, a Bounded-Rationality-inspired action module implementing a three-tier Rating-Action-Response process, and a tool-augmented refinement module aligning output language to the persona. Experiments show it generates diverse, controllable, high-quality dialogues even with smaller base LLMs, and its ratings are consistent across base LLMs. It was deployed to evaluate Huawei's Celia Food Assistant.
