## Summary

CTR prediction often uses multimodal data, but directly using continuous embeddings isn't optimal. The paper introduces RQ-GMM (Residual Quantized Gaussian Mixture Model), which discretizes embeddings into semantic IDs using probabilistic modeling and residual quantization. This approach significantly improves codebook utilization and reconstruction accuracy, leading to a 1.502% Advertiser Value gain over baselines and being fully deployed for daily recommendations.

## Technical note

RQ-GMM discretizes multimodal item embeddings into semantic IDs for CTR prediction, replacing hard-clustering quantizers like VQ-VAE, RQ-VAE, and RQ-KMeans that suffer from codebook collapse and poor boundary reconstruction. It models each residual level as a diagonal-covariance Gaussian Mixture Model, using soft posterior assignment to capture distributional structure and uncertainty, then selecting the highest-posterior component's mean for the residual update. Parameters are learned level-by-level with the EM algorithm directly on original embeddings (no encoder-decoder), with hard assignment for residual propagation to match inference. This two-stage discretize-then-train recipe decouples multimodal semantic extraction from preference modeling and mitigates convergence mismatch, yielding better codebook utilization and reconstruction and a 1.502% Advertiser Value gain in production A/B tests.
