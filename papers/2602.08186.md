## Summary

The paper addresses the challenge of inferring complex join relationships between database tables using only available metadata, a crucial task often hindered by limited data access. It observes that these relationships, represented as sparse adjacency matrices, also exhibit a low-rank structure. Based on this, the authors formulate the problem as a low-rank matrix completion task and introduce Nexus, an end-to-end solution combining iterative matrix completion with Large Language Models to refine predictions, significantly outperforming existing methods and offering a fast, practical approach.

## Technical note

The paper introduces join graph inference from metadata alone—recovering the adjacency matrix of equi-join (PK/FK) relationships across a table collection without accessing data values, for privacy-constrained enterprise/lakehouse settings. An empirical study of ~6K real-world schemas shows join graph matrices are consistently highly sparse (98% density < 0.02) and low-rank (95% normalized rank < 0.3), motivating formulating inference as low-rank matrix completion with terms aligning entries to pretrained-model/LLM likelihoods plus a sparsity regularizer. To counter poor priors, Nexus uses an Expectation-Maximization algorithm alternating low-rank completion with LLM-based refinement of join-candidate probabilities via dynamic column entity-type annotation and semantic-compatibility checks. Nexus significantly outperforms baselines (including value-accessing ones) on four datasets and offers a fast mode with up to 6x speedup.
