## Summary

This paper addresses e-commerce information overload by proposing a meta-hybrid recommender system that dynamically selects the best-performing recommendation algorithm for each user session based on their contextual and preferential data.

The core idea is using machine learning to predict which underlying recommender (like collaborative or content-based) will yield the most accurate results for an individual user at that specific moment, aiming for personalized performance.

Offline evaluations on standard datasets demonstrate this approach can theoretically improve recommendation precision by 20-50% compared to fixed methods in terms like nDCG and RMSE; however, achieving optimal real-world performance remains difficult due to limited available user information.

## Technical note

The paper proposes a meta-hybrid recommender that treats recommender-algorithm selection as a per-user classification problem: a Random Forest / XGBoost classifier trained on a user context model (contextual, preference, and demographic attributes) predicts which candidate recommender (Baseline, Co-Clustering, Slope One, SVD, KNN, LightFM, content-based) will yield the best nDCG for each recommendation request. Evaluated on MovieLens-1M and Yelp with PCA-reduced feature vectors, the theoretically optimal meta-hybrid outperforms all single methods by 20-50% on nDCG/RMSE, but the trained classifier fails to reach that ceiling (does not beat Slope One / LightFM) because standard stored user information is insufficient. Genre variance and rating count were the most predictive context features; the approach is also ~60x more costly to train.
