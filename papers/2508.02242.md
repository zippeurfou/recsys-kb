## Technical note

CAVE (Kuaishou) is a personalized Consumption-Aware list Value Estimation framework for re-ranking, correcting the generator-evaluator paradigm's mismatch between estimated list generation value and actual consumption value when users exit before consuming the full list. It models list consumption value as the expectation over sub-list values weighted by per-position user exit probability, decomposing exit into an interest-driven component (learned from feedback) and a stochastic component modeled with a Weibull distribution. The authors release three real-world list-wise benchmarks from Kuaishou; offline experiments on these plus two Amazon datasets and online A/B tests show CAVE consistently outperforms state-of-the-art re-ranking baselines.
