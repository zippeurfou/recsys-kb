## Summary

This paper introduces DynaIP, a plugin designed to enhance personalized Text-to-Image (PT2I) generation. It addresses key challenges like balancing the accuracy of concepts from a reference image with adherence to the text prompt, retaining fine-grained details, and supporting multiple subjects, by leveraging existing state-of-the-art diffusion models. DynaIP utilizes the inherent decoupling learning in these models and introduces a dynamic strategy and hierarchical feature fusion module to improve concept preservation, prompt following, and scalability. Extensive experiments confirm that DynaIP significantly outperforms prior methods in PT2I tasks.

## Technical note

DynaIP is a plugin for multimodal diffusion transformers (MM-DiT) that improves zero-shot personalized text-to-image generation without test-time fine-tuning. It observes that MM-DiT inherently decouples reference-image features across dual branches, with the noisy-image branch capturing concept-specific information and the text branch concept-agnostic information; a Dynamic Decoupling Strategy removes the concept-agnostic interference at inference to better balance concept preservation and prompt following and enable multi-subject scaling. A Hierarchical Mixture-of-Experts Feature Fusion Module exploits CLIP's multi-layer features via layer-specific experts and a routing mechanism to recover fine-grained detail and control visual granularity. Experiments on single- and multi-subject tasks show it outperforms prior adapter-based methods without additional multi-subject training data.
