## Summary

COPE addresses the issue of Large Language Models (LLMs) providing generic responses by proposing a framework for continual personalization using sparse user feedback. It achieves this by assigning each user a learnable embedding and integrating self-evaluation within the model to generate proxy rewards, enabling optimization even without explicit user input. Experiments show COPE outperforms existing prompt-based and static training methods and remains complementary to retrieval-augmented techniques.

## Technical note

RLHF-aligned LLM assistants give homogenized answers, prompt-based personalization eats context, and trained personalization stays static after training, so COPE continually personalizes an assistant whose users give explicit feedback only sparsely. Each user gets a learnable embedding of 10 virtual tokens prepended to the input (about 1.2e-5 of Qwen3-1.7B's parameters per user), and each round of an Interact-Collect-Optimize loop sums gradients from three objectives in one on-policy update. SFT preference capture trains only the user embedding to predict the user's textual feedback, PPO self-evaluation calibration trains the embedding and the LLM to predict the user's coarse 0 to 3 score with an exact-match plus distance reward, and PPO response optimization trains only the LLM on a completeness-gated reward that uses the real score when feedback exists and the self-predicted proxy score otherwise, with a KL penalty (beta=0.01) to the initial policy. On PersonaLens with 256 simulated users over 17 domains and a chronological protocol (51 optimization interactions per user, then held-out tasks), COPE scores 4.58, 4.69, and 4.74 out of 10 at feedback probabilities 0.25, 0.5, and 0.75, versus 2.36 for the base model and, at p=0.75, 3.69 for profile-augmented prompting and 4.69 for a trained profile-prompt baseline, while COPE plus BM25 retrieval-augmented prompting reaches 5.08 to 5.36. Dropping both self-evaluation and SFT cuts the score from 4.69 to 3.36, the proxy rewards track user scores (Pearson 0.81 in training, 0.71 held out, 72.63% pairwise agreement), and COPE scales to Qwen3-8B (5.49) and Llama-3.1-8B (5.16), keeps IFEval, GSM8K, and MMLU within one standard deviation, recovers from simulated preference shifts, and wins 76.92% of decisive blinded human comparisons against the trained profile baseline.
