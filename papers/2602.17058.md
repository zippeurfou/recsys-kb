## Summary

1.  The paper addresses the challenge of accurately predicting long-term value (LTV) for short videos during the ranking phase, tackling issues like position bias, ambiguous attribution between videos, and limitations in capturing long-term engagement.
2.  The authors propose a framework with three key components: a PDQ module for position-robust normalization, a multi-dimensional attribution module to learn nuanced inter-video influences, and a cross-temporal author modeling module for long-term creator-driven engagement.
3.  Evaluated offline and online, the framework significantly improves LTV metrics while maintaining trade-offs with short-term goals, and has been successfully deployed at billion-scale in Taobao's production recommendation system.

## Technical note

Presents a ranking-stage long-term value (LTV) framework for short-video recommendation with three modules: Position Debias Quantile (PDQ), which normalizes slide-time labels via per-page-group quantile regression to remove position bias without architectural changes; a learnable multi-dimensional attribution that weights contextual, behavioral, and content signals (author, category, v2v, multimodal) and trains attributed slide time with a Tweedie+MSE hybrid loss for zero-inflated targets. A cross-temporal author-value module builds censoring-aware day-level targets with exponential decay over a 7-day window, trained via dual-stream co-training with stop-gradient. Implemented as task augmentation on an existing multi-task ranker with target attention and SENet-based embedding fusion, deployed on Taobao serving 23M users with online CTR/engagement gains.
