## Summary

Generative retrieval using transformers shows promise but lacks the scalability and flexibility needed for industry-scale recommendation systems like Pinterest's, which require handling vast data and multiple metrics.

To address these limitations, the authors propose PinRec, incorporating two key innovations: outcome-conditioned generation allows explicitly balancing business goals (e.g., number of saves) with user exploration; multi-token generation enhances output diversity while optimizing retrieval performance.

Experiments demonstrate that PinRec successfully balances relevance, diversity, and efficiency at Pinterest's scale, delivering tangible positive user impact and marking a significant advancement in applying generative models rigorously to large commercial recommendation systems.

## Technical note

PinRec is Pinterest's unified generative-retrieval model serving home feed, search, and related pins, addressing prior GR limits: separate per-surface models, next-item-only prediction, and objective misalignment. It pretrains a transformer decoder on cross-surface user activity (dense OmniSage/OmniSearchSage embeddings rather than collapse-prone semantic IDs, retrieved via Faiss ANN) then fine-tunes per surface with impression-only hard negatives; outcome-conditioned generation emits one embedding per target action so budgets can trade off business goals, and autoregressive multi-token generation tracks evolving intent. Offline it beats SASRec, PinnerFormer, TIGER, and HSTU (multi-step AR gives up to +71% recall on related pins); online A/B tests show +3.88% search saves and gains across surfaces, with strong zero-shot retrieval for ads/queries at low latency.
