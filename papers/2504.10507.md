## Technical note

PinRec is Pinterest's first web-scale unified generative retrieval model serving home feed, search, and related pins, pretrained on cross-surface user activity sequences then fine-tuned per surface on impression data. It introduces outcome-conditioned generation to target surface-specific objectives (saves, outbound clicks, session depth) and generates multi-step Pin-token sequences autoregressively to track within-session intent shifts, unlike single-objective GR systems like TIGER and HSTU. Offline and online results show balanced performance/diversity/efficiency, with up to +71% recall from multi-step generation and +4% search saves, plus disclosed low-latency serving infrastructure.
