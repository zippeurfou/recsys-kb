## Technical note

Meta's Behavior-based User Segmentation (BUS) reformulates attribute-based recommendation as a listwise learning-to-rank problem, using a tree-based data structure that hierarchically partitions users by categorical attributes guided by product-specific engagement. A greedy algorithm optimizes NDCG during tree construction and a novel 'regress' operator filters irrelevant attributes via loss signals; social-graph connection-based segments improve fairness/robustness. Deployed serving billions of users daily, BUS improves music ranking and email-notification delivery timing, claimed the first listwise LTR framework for tree-based recommendation integrating categorical attributes at industrial scale, particularly for cold-start users.
