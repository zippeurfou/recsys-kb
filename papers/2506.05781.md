Semantic ID-based recommendation models tokenize each item into a small number of discrete tokens that preserve specific semantics, leading to better performance, scalability, and memory efficiency. While recent models adopt a generative approach, they often suffer from inefficient inference due to the reliance on resource-intensive beam search and multiple forward passes through the neural sequence model. ## Technical note

RPG (Recommendation with Parallel semantic ID Generation) from Meta enables long, expressive semantic IDs (up to 64 tokens vs the typical 4) by generating all tokens in parallel with a multi-token prediction loss instead of autoregressive token-by-token beam search. Items are tokenized into unordered long semantic IDs via optimized product quantization, and at inference a graph connecting similar semantic IDs guides iterative propagation-based decoding to avoid the sparse invalid-ID space and retrieve top-K efficiently. Scaling semantic ID length to 64 lets RPG outperform generative baselines by an average of 12.6% on NDCG@10 while also improving inference efficiency.
