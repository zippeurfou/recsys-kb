## Summary

SlimPer addresses the issue of large transformer models becoming inefficient with long user histories due to scaling intermediate tensors. It proposes compactifying recommendation systems by reformulating personalized ranking and replacing token-level processing with queryable <user, item> relevance scores. This allows deeper understanding without proportional compute or memory growth, unifies different feature types, improves interpretability via attention, and increases user engagement in large-scale deployments like Instagram Reels and Feed.

## Technical note

Argues Transformer-style rankers inherit a per-token autoregressive premise misaligned with discriminative recommendation, forcing large intermediate tensors that scale with sequence length. SlimPer reframes personalized ranking as iterative refinement of a fixed-size <user,item> knowledge base: each layer runs Select (all-modality QKV attention over raw user-side tokens) then Match (explicit dot-product relevance against multifaceted templates) then Refine, giving O(N) per-layer cost that decouples model depth from history length, and it extends request-only optimization (ROO) across all user-side modalities. It unifies sparse, dense, and sequence features in a single backbone (MLP, QKV attention, RMSNorm) and is intrinsically interpretable via attention attribution. Deployed on Instagram Reels and Feed, SlimPer improves Normalized Entropy by -0.51% to -1.05% across engagement tasks with +11% QPS and 9-18% memory reduction, scales to 10k+ events, and delivered an A/B topline roughly 10x a typical statistically significant launch.
