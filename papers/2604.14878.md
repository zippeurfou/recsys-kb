## Summary

A Preference-Oriented Generative Framework for Large-Scale Recommendation":

1.  The paper introduces GenRec, a generative recommendation framework addressing three key challenges in scaling large language models for industrial recommendation systems: inconsistent outputs, high encoding costs for long sequences, and misalignment with user preferences.
2.  GenRec tackles these issues using three main techniques: Page-wise NTP training for denser gradients, an asymmetric Token Merger to compress input sequences while preserving detail, and GRPO-SR, a stable RL training method using group policy optimization and hybrid rewards.
3.  Evaluated over a month on JD.com, GenRec significantly outperformed the existing system, achieving 9.5% more clicks and 8.7% more transactions in production traffic.

## Technical note

GenRec is a preference-oriented generative retrieval framework deployed on the JD App using a single decoder-only architecture over Semantic IDs derived from Qwen2.5-VL embeddings discretized by RQ K-means. Its Page-wise NTP objective supervises over an entire interaction page (ordered/clicked/exposed items) rather than each item, giving denser gradients and resolving the one-to-many label ambiguity caused by pagination requests. An asymmetric linear Token Merger compresses multi-token SIDs in the prompt (~2x shorter input) while decoding stays at full SID resolution for fine-grained retrieval. GRPO-SR pairs Group Relative Policy Optimization with NLL regularization and hybrid rewards (dense reward model plus relevance gate) to curb reward hacking, yielding 9.5% more clicks and 8.7% more transactions in month-long online A/B tests.
