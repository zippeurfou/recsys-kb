## Technical note

This Google paper adapts Barlow Twins self-supervised learning to user sequence modeling, using data augmentations tailored to user sequences and a redundancy-reduction loss that enforces statistically independent embedding components without negative sampling. This removes the reliance on large negative-sample batches that contrastive learning and dual encoders require, enabling effective representation learning with small batches and limited labels. On MovieLens-1M/20M and Yelp, the method beats the widely-used dual-encoder trained for next-item prediction by 8%-20% accuracy across three downstream tasks, and naturally avoids trivial constant embeddings.
