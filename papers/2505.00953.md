## Summary

This paper addresses the challenge of user sequence modeling in recommendation systems, where labeled training data for learning effective user representations is often scarce. It proposes adapting the Barlow Twins SSL method by incorporating specific augmentation techniques to learn better representations from unlabeled historical interaction sequences. The key contribution is demonstrating this adaptation's effectiveness at reducing reliance on extensive negative sampling and outperforming a standard dual encoder model significantly across different downstream tasks using datasets like MovieLens-1M, 20M, and Yelp.

## Technical note

The paper adapts Barlow Twins self-supervised learning to user interaction-sequence modeling to avoid the large negative-sample batches that contrastive/dual-encoder methods require. Two independent augmentations (random masking, segment masking, permutation) of each sequence batch are passed through weight-shared branches, and a Barlow Twins loss drives the cross-correlation of the projected embeddings toward identity, learning statistically independent components without negatives. Using a simple 1D-CNN encoder, the pretrained representation is transferred to downstream tasks (next-item prediction, sequence-level classification). On MovieLens-1M/20M and Yelp it outperforms a dual-encoder baseline by 8%-20% in accuracy, is robust to small batch sizes, and avoids trivial constant embeddings.
