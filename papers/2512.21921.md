## Summary

Towards Automated Product Poster Generation and Optimization":

1.  The paper introduces AutoPP, an automated system designed to create and optimize online product posters without human intervention, addressing the laborious task of manual creation and optimization.
2.  AutoPP's generator uses basic product information and a unified design module to automatically create posters by integrating background, text, and layout, while an optimizer then systematically refines the design elements based on online Click-Through Rate (CTR) feedback.
3.  Supported by a large dataset called AutoPP1M, the system achieves state-of-the-art results in both offline evaluation and real-world online performance, demonstrating effective automated poster generation and optimization.

## Technical note

AutoPP is an end-to-end pipeline for automated product poster generation and CTR optimization requiring only basic product info. The generator uses a unified design module to jointly reason over background, text, and layout, then an element rendering module encodes elements into condition tokens with decomposed self/cross-attention (MM-DiT blocks) for controllable diffusion generation. The optimizer collects fine-grained CTR feedback via systematic single-element replacement and applies Isolated Direct Preference Optimization (IDPO) to attribute CTR gains to individual elements. Backed by the million-poster AutoPP1M dataset with feedback from >1M users, it achieves SOTA offline and online results.
