## Summary

Large language models (LLMs) are becoming key components in recommender systems due to their capabilities, but they typically only handle discrete text tokens. This limitation exists despite recommendation systems relying heavily on numerical and dense embedding features derived from user and item data. The authors propose "soft-token fusion," a framework that converts these non-textual feature values into the LLM's own representation space before processing, enabling better use of all available signals.

This approach involves creating specific tokens for numerical and embedding features within a standard two-tower retrieval model architecture using shared parameters with the language tower. The paper introduces an interaction-based fusion module designed to refine these heterogeneous soft tokens prior to their insertion into the LLM's input sequence alongside text tokens, enhancing the combined representation.

Experiments on Amazon recommendation datasets demonstrate that incorporating numerical and embedding features via this soft-token method significantly improves retrieval performance compared to baselines using only textual data. Furthermore, refining these feature tokens through the interaction module proves more effective than simply concatenating them directly into the LLM input without refinement.

## Technical note

This work bridges LLM recommenders (which consume discrete text tokens) with the continuous numerical and dense embedding features of industrial pipelines via a soft-token fusion framework: dense embedding features (pooled Qwen3-4B prompt encodings) and numerical features (price, Fourier-encoded) are compressed by separate Q-Former adapters into fixed-length soft tokens, then refined by an interaction-based Transformer fusion module before insertion into a shared-parameter Qwen3-0.6B two-tower retrieval encoder trained with in-batch-negative contrastive loss. On Amazon Beauty/Sports/Toys both soft-token streams help, but direct concatenation of heterogeneous tokens is unreliable (sometimes below text-only), while interaction-based fusion is best, e.g. Toys R@5 0.0600 to 0.0695 over text-only and beating TIGER (0.0521), with R@10 gains over TIGER on all three datasets. Ablations favor Q-Former over MLP and Fourier over tokenizer numeric encoding. It is a retrieval-only LLM two-tower model, not a unified retrieval-plus-ranking pipeline.
