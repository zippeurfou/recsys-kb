## Summary

This paper introduces **Comparative Counterfactual Explanations for Recommendation (CoCountER)** to address the problem of generating accurate explanations in recommendation systems using counterfactual reasoning.

Existing methods often produce factual inaccuracies by minimizing changes needed to reverse recommendations, relying on an aggregated decision boundary score.

CoCountER instead creates counterfactual data through **soft swap operations** specifically designed to explain why one item is recommended over another arbitrary comparative item pair. The effectiveness of this novel approach was empirically validated.

## Technical note

CoCountER produces explanations for recommendations via counterfactual reasoning but fixes factual inaccuracies of reduction-based methods (e.g. CountER) that push aggregated aspect scores to a decision boundary rather than per-aspect. It defines a differentiable soft 'swap' operation that exchanges aspect values between an explaining item and a reference item, sigmoid-gated so it is trainable by gradient descent under an L1 sparsity plus margin-ranking objective that reverses the pair's relative ranking. Aspects whose swap crosses 0.5 form the comparative explanation, and the method degenerates to reduction-based explanation as a special case. Experiments on three Amazon review datasets (aspects extracted with Sentires) show more faithful explanations than matching-based (EFM, A2CF) and reduction-based baselines.
