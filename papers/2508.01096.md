## Technical note

Pinterest presents a structured product-attribute extraction system from e-commerce webpages built on Visual Page Representation (VPR), a compact representation fusing structural (DOM), visual (style/layout), and text modalities per visible HTML node. VPR lets simple XGBoost models classify page type and extract attributes (price, title, image) more accurately than much larger GPT-based LLMs. The system processes over 1,000 URLs/second on CPU and is ~1000x more cost-effective than the cheapest GPT alternative, feeding Pin representations that drive recommendation and search.
