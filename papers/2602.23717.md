## Summary

This paper addresses the challenge of improving Airbnb's booking conversion rates by using machine learning to recommend search filters. It introduces a novel framework that directly targets lower-funnel conversions by suggesting specific filters to guests. The system was successfully deployed, resulting in incremental booking lifts validated through A/B testing.

## Technical note

Airbnb builds a machine-learning system that recommends search filters (facets) rather than end listings, explicitly targeting lower-funnel booking conversions instead of upper-funnel filter engagement. The framework introduces a Filter Conversion Rate metric and a decision framework keyed on FCR variability across filters and queries, plus a problem decomposition and training-example construction that ties filter selection to eventual uncanceled bookings. The productionized system handles cold-start bootstrapping (zero-to-one) and stringent serving latency with a scalable, extensible architecture, and powers multiple UI surfaces (recommended-for-you panel, amenities section, filter bar). Deployment drove incremental booking-conversion lifts validated by online A/B tests, with an ablation confirming the conversion-oriented design choices; the approach is positioned as domain-agnostic for marketplaces using filters/facets.
