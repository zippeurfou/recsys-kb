## Summary

With the rapid growth of user historical behavior data, user interest modeling has become a prominent aspect in Click-Through Rate (CTR) prediction, focusing on learning user intent representations. However, this complexity poses computational challenges, requiring a balance between model performance and acceptable response times for online services. ## Technical note

LREA (Low-Rank Efficient Attention) is an attention mechanism for modeling entire long-term user behavior sequences in CTR prediction without the information loss of top-K filtering (SIM) or low-precision attention (ETA, SDIM, TWIN). It applies low-rank matrix decomposition at the sequence-length level and a tailored loss to preserve attention capability while cutting computation, and uses matrix absorption plus pre-storage at inference to meet online latency constraints. Extensive offline and online experiments show LREA outperforms state-of-the-art long-sequence CTR approaches while remaining efficient for online serving.
