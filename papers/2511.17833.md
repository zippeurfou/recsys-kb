## Summary

Debugging, particularly resolving RTL assertion failures, is a major cost in hardware verification, but standard LLMs often lack the precise, reusable debugging expertise needed. To address this, the paper introduces GROVE, a hierarchical framework that organizes debugging knowledge into an LLM-managed tree. GROVE learns from past cases to build and iteratively refine this tree of knowledge items with applicability conditions, then uses it to guide LLMs in finding and applying relevant fixes efficiently. Evaluated against assertion failures, GROVE consistently improved LLM performance in generating correct fixes.

## Technical note

Grove is a hierarchical knowledge-management framework for RTL assertion-failure debugging that distills reusable debugging expertise into an LLM-organized knowledge tree with explicit applicability conditions per node. Training uses a parallel, gradient-free loop where an LLM proposes JSON edit scripts (insert/update/move/deprecate), with per-item validation via a model checker (Jasper) accepting only non-degrading knowledge. At test time a budgeted snapshot-and-zoom protocol retrieves a small applicable knowledge set to augment prompts. On SVA-Eval, Grove improves pass@1 by +12.0% (LLaMA-3) and +6.6% (o3-mini) over zero-shot, beating flat RAG and global-memory baselines; ablations confirm applicability conditions, iterative zoom, and validation each matter.
