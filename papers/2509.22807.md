## Technical note

Recommenders trained on implicit feedback (clicks) misalign with real user preferences because clicks do not reflect true satisfaction. MTRec models the user as an agent in a user-centric MDP and introduces a learned mental reward model that quantifies internal satisfaction, inferred from behavioral data via inverse reinforcement learning. Because mental rewards are stochastic, they propose Quantile Regression Inverse Q-Learning (QR-IQL), a distributional IRL variant that maps state-action pairs to a reward distribution; the learned reward then provides complementary supervision to guide standard recommendation models toward real preferences. Experiments on two public datasets improve AUC and NCIS across several backbones, and deployment on an industrial short-video platform yielded a 7% increase in average user viewing time.
