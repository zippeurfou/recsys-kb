## Summary

1.  Recommender systems face the challenge of incorporating vast historical user behavior data effectively, as existing parameter-centric methods lack the needed scalability and flexibility.
2.  To address this, the paper introduces D2K, a data-centric framework that explicitly stores and retrieves "ternary knowledge" (user-item-context interactions) learned from old data, making it directly usable by *any* recommendation algorithm.
3.  D2K uses a Transformer encoder to create this retrievable knowledge and an adaptation unit to apply it to new data, demonstrating significantly improved recommendation performance across various algorithms on standard datasets.

## Technical note

D2K addresses preserving knowledge from old recommendation logs by converting historical data into a retrievable key-value knowledge base rather than storing it implicitly in model parameters (parameter-centric), which suffers catastrophic forgetting and poor scalability. It stores ternary user-item-context cross features as keys, encoded into 'direct' knowledge vectors by a Transformer-based encoder, and a personalized knowledge adaptation unit generates target-sample-specific MLP weights to adapt the global knowledge before injecting it into any backbone (DeepFM, DIN, DCNv2). On the AD and Eleme datasets, D2K improves AUC by 1.35-2.90% over the best baselines and even beats training on all data (Fixed Window (A)). Ablations show the adaptation unit is essential and average-pooling knowledge updates outperform recent-priority.
