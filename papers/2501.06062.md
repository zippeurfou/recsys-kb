In many practical natural language applications, user data are highly sensitive, requiring anonymous uploads of text data from mobile devices to the cloud without user identifiers. However, the absence of user identifiers restricts the ability of cloud-based language models to provide personalized services, which are essential for catering to diverse user needs. ## Technical note

Addresses learning a personalized cloud LLM over anonymously uploaded text without user identifiers. The proposed IDfree-PL framework has each device maintain a user-specific distribution (Beta for non-identifiability, or multi-dimensional Gaussian for high misattribution) and dynamically samples user embeddings via the reparameterization trick while freezing the LLM, breaking the one-to-one user-embedding mapping to preserve anonymity. On Sentiment140/Amazon-Kindle/Reddit with GPT2, T5, and Bart backbones, IDfree-PL improves inference accuracy by up to 5.69% over cloud-without-ID and averages +1.2% over on-device personalization while adding only ~0.01s latency (up to 43x faster than on-device serving). A tunable Gaussian variance trades privacy for accuracy (e.g., var=0.3^2 gives 70.9% misattribution at 1.23% accuracy cost).
