## Summary

This paper compares two agentic data retrieval systems: one using semantic metadata (schema.org) and another relying solely on Large Language Models (LLMs) to search the web. The study finds that while the metadata-based "Semantic Agent" retrieves data with significantly higher precision and better adherence to FAIR principles, the "Baseline Agent" using unstructured retrieval covers more ground but often retrieves lower-quality or non-data pages. The conclusion is that semantic metadata provides crucial structure and reliability for execution-oriented autonomous workflows, despite unstructured retrieval offering broader coverage.

## Technical note

This paper compares two agentic data-retrieval systems on the same architecture: a Baseline Agent searching billions of open-web documents via general web search, and a Semantic Agent operating over 90 million schema.org-marked dataset records from Google Dataset Search. An LLM-as-a-judge pipeline mapped to the FAIR principles rates retrieved assets on semantic relevance, accessibility, and computational utility, using NTCIR-16 Data Search queries. The Semantic Agent achieves 44.9% higher precision for metadata-rich registries, 46.6% higher precision for pages with machine-readable downloads, and 65.7% higher overall precision for FAIR-compliant datasets, whereas the Baseline Agent suffers Last-Mile Utility failures, landing on prose-heavy pages (20.1%) and portal landing pages (8.5%). The Baseline Agent covers 40% more questions, so the study concludes unstructured retrieval supports broad exploration but structured semantic ecosystems remain indispensable for reliable execution-oriented autonomous workflows.
