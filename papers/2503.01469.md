## Technical note

HeterRec is a Heterogeneous Information Transformer for scalable sequential recommendation that improves item representations by tokenizing each item's heterogeneous features (categorical, numerical, multimodal via quantized cluster IDs) into a flattened heterogeneous token sequence through a Heterogeneous Token Flatten Layer. A Hierarchical Causal Transformer applies token-level then item-level causal attention (with a learnable time-gap representation) to capture fine-grained cross-item and cross-feature patterns, and a Listwise Multi-step Prediction (LMP) loss with token- and item-level tasks aids learning; it is deployed in a two-tower EBR retrieval stage trained with contrastive learning. Offline and online experiments show superior performance and better scaling than concatenation-based TSR models.
