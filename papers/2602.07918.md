## Summary

AI agents are vulnerable to Indirect Prompt Injection (IPI) attacks, where malicious commands in untrusted content trick the agent. Existing defenses often over-protect, slowing down the agent even without attacks. This paper introduces CausalArmor, a selective defense that uses causal attribution to determine if an untrusted segment disproportionately influences a user's request, triggering targeted sanitization only when necessary, thereby matching aggressive defenses' security while improving performance and explainability.

## Technical note

CausalArmor detects indirect prompt injection by computing leave-one-out (LOO) attributions at privileged decision points, measuring the marginal log-probability support each untrusted span versus the user request contributes to a candidate action. A successful injection appears as a 'dominance shift' where an untrusted span's attribution exceeds the user request's, triggering targeted sanitization of only that span plus retroactive chain-of-thought masking of poisoned reasoning steps. This selective, batched design avoids always-on sanitization, resolving the over-defense dilemma while matching aggressive defenses' security. The authors prove that margin-based attribution sanitization yields an exponentially small upper bound on malicious-action probability, and validate on AgentDojo and DoomArena.
