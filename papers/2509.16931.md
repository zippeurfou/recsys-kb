## Technical note

TARQ (Taobao/Alibaba) brings Target Attention into the latency-critical pre-ranking stage for the first time by approximating it with Residual Quantization. Using a teacher-student design over a two-tower backbone, the online student (RQ-Attention Net) computes attention scores between user behaviors and a shared quantized codebook, assembled via fast index lookup, while an offline Target-Attention teacher supervises training; a Codebook Alignment objective mitigates codebook collapse (utilization 59%->98%). Offline experiments and large-scale Taobao A/B tests show significant ranking gains, and it is fully deployed serving tens of millions of daily active users.
