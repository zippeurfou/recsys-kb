## Summary

Researchers introduced **MobilityBench**, a new benchmark designed to evaluate LLM-based route-planning agents in realistic, real-world scenarios. This benchmark is built from anonymized user queries and includes a **deterministic API-replay sandbox** for reproducible testing, along with a multi-dimensional evaluation protocol. Using MobilityBench, they found that current LLM agents perform adequately on basic tasks but struggle significantly with preference-constrained route planning, highlighting an area needing improvement.

## Technical note

MobilityBench is a scalable benchmark for evaluating LLM-based route-planning agents in real-world mobility scenarios, built from large-scale anonymized user queries from Amap across 350+ cities covering point-to-point, multi-waypoint, multimodal, and preference-aware routing. To handle non-deterministic live mapping APIs, it introduces a deterministic API-replay sandbox that caches routing and POI responses so identical inputs yield identical verifiable outputs, ensuring reproducibility. Its multi-dimensional evaluation protocol centers on outcome validity with complementary assessments of instruction understanding, planning, tool use, and efficiency, using objective criteria beyond LLM-as-judge. Findings show agents handle basic retrieval and route planning but struggle with preference-constrained planning, highlighting gaps in personalized mobility. Benchmark/eval paper, not a recommender model.
