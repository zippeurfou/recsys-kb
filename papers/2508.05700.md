## Summary

Modern recommendation systems rely heavily on large embedding tables to store intricate interaction details between diverse entities like users and items in Pinterest's ad system.

Initial attempts to train these embeddings from scratch yielded neutral performance, so a novel multi-faceted pretraining scheme was developed by combining several algorithms to enrich the table significantly.

This effective solution led to tangible improvements online: it achieved a 1.34% reduction in Cost Per Click (CPC) and boosted Click-Through Rate (CTR) by 2.60%, while also implementing a CPU-GPU hybrid serving system to overcome memory constraints, maintaining neutral latency during deployment.

## Technical note

Integrating large embedding tables into Pinterest ads ranking initially gave neutral metrics because table information overlapped with existing pretrained Pin/user/item embeddings. The authors propose a multi-faceted pretraining scheme combining User-Pin contrastive learning and large-scale heterogeneous knowledge graph embedding, which provide orthogonal gains and enrich the tables before fine-tuning in CTR and CVR ranking models. To serve tens of billions of parameters under tight GPU memory, they build a CPU-GPU hybrid serving system that hosts tables on external CPU clusters with INT4 post-training quantization and early/parallel embedding fetching for neutral latency. Online it achieved a 1.34% CPC reduction and 2.60% CTR increase.
