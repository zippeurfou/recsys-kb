## Summary

This paper compares dense retrieval and generative retrieval methods for sequential recommendations, noting that while dense retrieval requires significant memory for large item pools, generative retrieval offers scalability but lacks performance understanding. To address this, the authors introduce LIGER, a hybrid model that integrates dense retrieval into the generative framework. LIGER effectively combines the strengths of both approaches, improving cold-start recommendations and demonstrating better efficiency and effectiveness than either method alone in small-scale benchmarks.

## Technical note

This paper provides a fair, controlled comparison of sequential dense retrieval versus generative retrieval for sequential recommendation and proposes LIGER, a hybrid unifying the two. Dense retrieval stores an embedding per item and ranks via inner product (O(N) storage/compute), while generative retrieval (as in TIGER) encodes items as RQ-VAE semantic IDs and predicts the next item via beam search with only O(t) learnable embeddings. On small-scale academic benchmarks with matched inputs, dense retrieval outperforms generative retrieval, which notably struggles with cold-start items (near-zero recall). LIGER applies dense retrieval to re-rank a small candidate set produced by the generative module, retaining generative retrieval's minimal storage while closing the performance gap and improving cold-start recommendation.
