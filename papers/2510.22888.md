## Technical note

MGFRec targets reasoning-based LLM recommenders that reason only in language space, which over-interpret user interests and drift away from real items. It performs multiple rounds of grounding during inference to keep the LLM's reasoning aligned with the actual item space, and adds a user agent that provides feedback at each grounding step so the model better recognizes and adapts to user interests. Experiments on three Amazon review datasets show incorporating multiple groundings plus feedback is effective, underscoring the value of reasoning within the real item space rather than the language space.
