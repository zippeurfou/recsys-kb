## Summary

This paper introduces the first federated implementation of Collaborative Filtering, a method for personalized recommendations. It addresses growing user privacy concerns by leveraging the Federated Learning paradigm, where users keep their data locally and only share model updates with a central server. The study demonstrates that this approach maintains recommendation accuracy comparable to traditional methods while significantly enhancing user privacy.

## Technical note

This work presents the first Federated Collaborative Filter (FCF), federating matrix-factorization collaborative filtering so that user data never leaves the client device. The item-factor matrix (master model) is held on the server while each user's user-factor matrix stays local; clients compute gradient updates for the item factors from their own implicit-feedback data and send only those gradients back for aggregation. The authors derive a federated SGD update for the standard implicit-feedback CF model. On MovieLens and an in-house dataset, FCF achieves accuracy statistically indistinguishable from standard centralized CF, showing privacy can be enhanced with no loss in recommendation performance.
