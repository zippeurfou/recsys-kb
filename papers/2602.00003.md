## Technical note

A coarse-grained Mixture-of-Experts framework for cross-border e-commerce search relevance orchestrates heterogeneous open-source LLMs (Qwen, Gemma, Sailor2) as experts rather than scaling a single monolithic model, exploiting complementary regional/language strengths without expensive pre-training. Unlike token-level MoE, it routes entire queries to specialized experts (best via end-to-end hard routing) and uses an Information-Preserving Concatenation Fusion strategy, arguing that preserving distinct expert embedding manifolds beats weighted-average fusion which causes destructive interference. On six Southeast Asian markets it improves AUC by 0.72 points over a dense baseline with the same active parameters while reaching 13.72 QPS (+9% throughput).
