## Summary

This paper presents an offline reinforcement learning framework designed to optimize SLAM throughput control in warehouses, addressing system congestion by dynamically adjusting throttling. The core approach uses a history-informed state representation and balances maximization with downstream stability through intelligent action abstraction. Empirical results show that using CQL policy within this framework significantly improves system health (22.97%) and reduces average throttling duration (3.18%).

## Technical note

This work formulates warehouse SLAM (Scan/Label/Apply/Manifest) throttling as an MDP solved with algorithm-agnostic offline RL (BCQ, CQL, TD3+BC) trained on de-identified 15-minute-interval logs (65,088 train / 21,510 test via temporal split). The state augments current observations with multi-step upstream (pick/pack) history aligned to transit lags; the discrete multi-machine action space (cardinality M^N) is collapsed to an N-dim continuous space via time-weighted averaging, then mapped back at inference. The reward blends normalized upstream backlog rate and downstream congestion with tunable weights, and downstream-weighted policies are most stable. Evaluation combines model-free immediate-reward regression, long-horizon Fitted Q Evaluation, and a model-based DeepKoopmanWithAR simulator (reducing 8-step WAPE from 52.31% to 22.25%). CQL is strongest, improving FQE by 22.97% and reducing throttling duration by 3.18%, and it scales best with data.
