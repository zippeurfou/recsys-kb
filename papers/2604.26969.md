## Technical note

AgenticRecTune (Google Discover) is a self-evolving multi-agent LLM framework that automates system-level configuration optimization of multi-stage recommender pipelines (pre-ranking, ranking, re-ranking), where fusion weights and score adjustments must be recalibrated after any model change but the overall system is sparse and non-differentiable. It coordinates five specialized agents built on Gemini — Actor (proposes configuration candidates), Critic (filters suboptimal proposals), Online (autonomously runs A/B tests and collects results), and Insight+Skill (a self-evolving Skillhub that summarizes historical experiments, extracts task mechanics, and updates skills for the next round). By operating directly in live experiments it navigates the online Pareto front across competing metrics (engagement, diversity, long-term retention), removing manual tuning; effectiveness is demonstrated by multiple successful production launches on Google Discover.
