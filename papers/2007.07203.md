## Summary

This paper introduces Deep Retrieval (DR) as a solution for efficiently retrieving top relevant items in large-scale recommendation systems. Instead of using approximate nearest neighbor search in Euclidean space, DR learns a discrete latent space directly from user-item interaction data, where the latent codes represent items and are optimized alongside other model parameters. The system retrieves top candidates using beam search over this learned structure, achieving sub-linear computational complexity and demonstrating superior performance compared to traditional ANN methods both empirically and in a production setting.

## Technical note

Deep Retrieval (DR) learns a retrievable index structure directly from user-item interaction data instead of the two-step 'learn inner-product model then apply ANN/MIPS' approach, avoiding the Euclidean-space assumption. Items are encoded into a discrete latent space represented by a KxD matrix, where each item maps to one or more paths of length D over {1..K}; the item-to-path mapping is a model parameter learned jointly with the neural network via an EM-type algorithm, with a penalization term preventing path collapse. Retrieval is done by beam search over the structure, achieving sub-linear complexity, and a multi-path multiple-to-multiple encoding captures multi-aspect item properties while avoiding the leaf-node data-scarcity of tree-based methods (TDM/JTM). DR matches brute-force accuracy on MovieLens-20M and Amazon Books and, deployed at the scale of hundreds of millions of items, beats a well-tuned ANN baseline on live engagement metrics.
