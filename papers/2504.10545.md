## Summary

1.  Researchers developed a hybrid recommender system called HSTU-BLaIR, combining an existing generative model (HSTU) with a new lightweight text embedding technique.
2.  This approach uses BLaIR to inject semantic information from item descriptions into the generator, improving recommendations without needing computationally expensive embeddings like those provided by OpenAI's large models.
3.  Despite being trained on smaller data and having fewer parameters, HSTU-BLaIR significantly outperformed a baseline HSTU model using domain-specific text features (BLaIR) and performed nearly as well as the large OpenAI embedding method on standard e-commerce datasets, demonstrating good efficiency for recommendation applications.

## Technical note

HSTU-BLaIR augments the HSTU generative sequential recommender with BLaIR, a lightweight (125M) contrastive text encoder pretrained on Amazon reviews, to inject semantic item signals cheaply. Each item's fixed BLaIR text embedding is projected and added element-wise to its trainable ID embedding before the HSTU encoder, and text-aware local negative sampling adds semantic structure to negatives without changing the sampling distribution. On three Amazon Reviews 2023 subsets and the disjoint Steam dataset, HSTU-BLaIR beats plain HSTU on all metrics and outperforms an HSTU variant using OpenAI's much larger text-embedding-3-large on 22 of 24 comparisons, with gains up to 77% NDCG@10 over SASRec on sparse Office Products. A learnable gating fusion surprisingly underperformed simple addition.
