## Summary

SAFE-Cascade presents an interactive system designed to reduce costs in chart question answering by selectively using powerful Vision-Language Models (VLMs). It first extracts text via OCR and generates a provisional answer from a lightweight language model before deciding if a VLM is needed through a learned router. This approach achieves comparable accuracy to always-using-VLM baselines but significantly lowers estimated costs while providing user-transparent insights into the reasoning process and allowing cost threshold adjustments.

## Technical note

SAFE-Cascade is a cost-adaptive chart-QA system that runs OCR (Azure Document Intelligence) plus a text-only LLM (gpt-5-mini) to produce a provisional answer, then uses a Random Forest router over inference-time features (OCR length/density, question flags, question-OCR overlap, answer indicators, latency) to decide whether to escalate to a VLM (gemini-2.5-flash-image). The router emits an escalation probability compared against a tunable threshold (theta=0.3), performing modality routing rather than only model routing or abstention, and exposes OCR evidence, provisional answer, routing probability, decision, final answer, and estimated cost/latency in an interactive interface. On a 375-example held-out ChartQA split it reaches 69.1% unified accuracy at 73.1% VLM invocation vs 67.7% at 100% for full-VLM, matching full-VLM within statistical uncertainty while cutting VLM calls 26.9% and estimated cost 9.3%. Learned routing is essential: text-only reaches 25.3% and a heuristic cascade 37.3%, and a lower threshold trades higher VLM usage for fewer missed escalations.
