## Summary

1.  Existing sequential recommendation models struggle with efficiently updating using incremental learning due to high memory costs from replay buffers or ineffective removal of outdated information via regularization.
2.  To address these challenges, the paper introduces SA-CAISR, a novel stage-adaptive and conflict-aware framework that operates without a replay buffer, using only the old model and new data.
3.  SA-CAISR dynamically identifies and removes conflicting, outdated knowledge using a Fisher-weighted screening mechanism, achieving significantly better recommendation accuracy (improving Recall@20 by 2.0%, etc.) while drastically reducing memory usage (97.5%) and training time (46.9%) compared to existing methods.

## Technical note

The paper tackles incremental sequential recommendation, where replay-based updates are costly and privacy-invasive while regularization-based methods fail to discard outdated or conflicting knowledge. It proposes SA-CAISR, a buffer-free stage-adaptive and conflict-aware framework using only the old model and new data, with a Fisher-weighted knowledge-screening mechanism that estimates parameter-level conflicts on new data and selectively masks obsolete parameters while preserving compatible historical patterns. It combines cross-entropy for new-knowledge acquisition with an InfoNCE-based consistency loss to retain valid historical signals. On four datasets SA-CAISR improves Recall@20 by 2.0% on average while cutting memory usage 97.5% and training time 46.9% versus the best baseline.
