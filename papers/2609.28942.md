## Summary

Existing value alignment methods for LLMs typically use static user profiles, failing to account for how value importance changes depending on the context. This paper introduces BaCVA, a Bayesian Context-aware Value Alignment method that models static personal values as priors and dynamically infers context-dependent preferences (posteriors) by integrating these priors with scenario-specific value salience. BaCVA uses a dual-view personalization module to learn these varying preferences more accurately and efficiently than previous approaches.

## Technical note

Inference-time personalized value alignment methods condition an LLM on the same static user value profile for every prompt, even though which values matter shifts with the situation. BaCVA, motivated by Lewin's Field Theory, treats the user's Schwartz value profile and a scenario value-salience distribution as priors and infers context-specific posterior values by variational inference, with a value-regression likelihood plus KL terms to both priors. GPT-5-nano estimates scenario salience from a population-aligned universal response, and a dual-view module on Qwen3-8B (Q-LoRA, Adam, lr 5e-3) mixes a scenario-anchored posterior (scenario logits plus a personal residual) with a person-anchored posterior (profile logits plus a context residual) through an LLM-computed, context-aware gate. On PRISM it reaches MAE 0.728, Spearman 0.700, and 81.72% pairwise accuracy versus 0.952, 0.638, and 71.68% for the strongest baseline, ValuesRAG, on GOOD it cuts MAE from 2.261 to 1.118, it beats training-time RLHF and MORLHF (48.92% and 53.41% accuracy), and ablations show each view, the gate, and the KL prior terms contribute. It also needs less training data, degrades less on held-out cold-start users, holds across value extractors, backbones (37.9% lower MAE than ValuesRAG on Llama3-8B), and value systems (Moral Foundations, a 301-dimension Daily-Dilemma taxonomy), and an end-to-end variant with soft-prompt value conditioning and a DPO-style generator loss gives the best downstream personalized responses (MAE 0.3776, accuracy 0.7996).
