## Summary

Vector-augmented analytical queries, like those used in RAG systems combining tables and vector search, suffer from inefficient execution due to inaccurate cardinality estimation for the vector search parts. This paper introduces Exqutor, a novel cardinality estimation framework designed specifically to improve this accuracy. Exqutor uses exact methods when vector indexes are present and a smart sampling approach otherwise, demonstrating significant performance improvements (up to 10,000x faster queries) when integrated into popular databases.

## Technical note

Exqutor is a pluggable query-optimizer framework that improves cardinality estimation for vector-augmented analytical queries (VAQs) that combine vector similarity search with relational filters, joins, and aggregates in RAG-style pipelines. When vector indexes (HNSW, IVF) are available it uses Exact Cardinality Query Optimization, running ANN searches during planning on only the embedding tables and reusing results at execution to avoid overhead; otherwise it uses adaptive sampling with momentum-based feedback and learning-rate scheduling to tune sample size against Q-error. The authors also build the first analytics benchmark extending TPC-H and TPC-DS with embedding columns to evaluate VAQ optimization. Integrated into pgvector, VBASE, and DuckDB, Exqutor delivers speedups up to four orders of magnitude.
