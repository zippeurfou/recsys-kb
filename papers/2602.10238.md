## Technical note

KVP (KV Policy, Apple) reframes LLM KV-cache eviction as a reinforcement learning ranking problem — ordering cached tokens by predicted future utility for decoding — replacing backward-looking heuristics (recency, past attention) that are indirect proxies and incompatible with FlashAttention. It trains a distinct lightweight per-head RL agent on pre-computed generation traces using only key and value vectors (no queries, attention scores, or architecture changes), with a holistic reward evaluating the ranking quality across all cache budgets. On RULER (long-context) and OASST2-4k (multi-turn dialogue) across two model families KVP significantly outperforms strong heuristic baselines, and zero-shot on LongBench/BOOLQ/ARC it generalizes out-of-distribution and to longer contexts.
