## Technical note

MemoryOS is a memory operating system for AI agents that addresses fixed context windows and weak long-term memory, applying OS-inspired memory management via four modules (Storage, Updating, Retrieval, Generation) over three tiers: short-term, mid-term, and long-term personal memory. Short-to-mid updates use a dialogue-chain FIFO principle while mid-to-long updates use a segmented paging (heat-based) strategy, enabling hierarchical integration and dynamic updating of user preferences. On the LoCoMo long-conversation benchmark with GPT-4o-mini it improves F1 by 49.11% and BLEU-1 by 46.18% on average over baselines, improving contextual coherence and personalized memory retention.
