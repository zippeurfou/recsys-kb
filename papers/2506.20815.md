## Technical note

This paper presents a dynamic context-aware prompt recommendation system for domain-specific LLM applications (e.g., cybersecurity copilots). It combines contextual query analysis, retrieval-augmented knowledge grounding over a skill/data-source knowledge base, hierarchical skill organization, and a two-stage hierarchical reasoning process for adaptive skill ranking, then synthesizes a meta-prompt using predefined and adaptive templates with few-shot exemplars. Experiments on real-world security datasets show high usefulness and relevance validated by automated and expert evaluations.
