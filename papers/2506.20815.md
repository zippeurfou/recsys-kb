## Summary

This paper addresses the challenge of crafting high-quality prompts for domain-specific Large Language Model (LLM) applications. It introduces a novel system that dynamically recommends relevant prompts by analyzing context, retrieving grounding knowledge from external sources, organizing skills hierarchically, and adaptingively ranking them based on behavioral telemetry. Experiments show this approach significantly improves prompt quality with both automated metrics and expert evaluations across various domains.

## Technical note

The paper tackles crafting high-quality prompts for domain-specific LLM copilots (focused on security operations). It proposes a pipeline that parses the user query, grounds it via RAG over a skill/knowledge repository, organizes skills hierarchically for two-stage plugin-then-skill selection, ranks candidates using a predictive model trained on behavioral telemetry, and synthesizes meta-prompts with predefined/adaptive templates plus few-shot examples. A hybrid GPT-4o + Markov configuration cuts cost while addressing cold-start, since the Markov model infers popular skills without LLM calls. On 784 sessions / 12,432 suggested prompts, the full GPT-4o pipeline reached ~88.4% automated usefulness and >96% expert-rated usefulness.
