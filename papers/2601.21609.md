## Summary

Existing agentic recommender systems often model user preferences based on sparse, noisy interactions and neglect real-time, mutual influences, leading to less accurate recommendations. To address these limitations, the authors propose RecNet, a self-evolving framework that proactively propagates real-time preference updates across users and items using two phases. The first phase integrates and dynamically routes these updates, while the second phase optimizes propagation strategies through feedback and multi-agent reinforcement learning principles, using LLMs for credit assignment. Extensive experiments demonstrate that RecNet effectively models preference propagation, improving the performance of recommender systems.

## Technical note

Existing agentic recommenders update preferences only on explicit, sparse, noisy user-item interactions and ignore real-time mutual influence among users and items. RecNet is a self-evolving preference propagation framework with a forward phase where router agents integrate and dynamically propagate real-time preference updates to the most relevant agents, plus a personalized reception mechanism using a message buffer and an optimizable rule-based filter memory for selective assimilation. Its backward phase simulates multi-agent reinforcement learning, using LLMs for credit assignment, gradient analysis, and module-level optimization to continuously evolve propagation strategies. Experiments across scenarios show RecNet effectively models preference propagation and improves recommendation performance.
