## Summary

This paper proposes a new approach to large-scale recommendation using two-tower models by formulating it as session-level sequential decision making, specifically training with off-policy reinforcement learning (REINFORCE) on pre-collected data. Unlike previous methods relying on myopic supervised objectives like next-item prediction, the authors introduce multi-step importance weight approximation enabled by autoregressive feedback modeling during training and evaluation. Furthermore, they present a test-time scaling procedure that simulates future user engagement to select recommendations maximizing predicted long-term return without updating the policy itself, demonstrating superior performance in terms of cumulative session reward on an offline dataset while being competitive with standard metrics.

## Technical note

Generative retrievers are typically trained with next-item prediction, which does not optimize long-term user satisfaction. This work casts recommendation as session-level sequential decision-making and trains an autoregressive generative retriever with off-policy REINFORCE on logged Yambda-5B data, introducing a multi-step (K-factor) importance-weight approximation instead of prior one-step off-policy correction. It trains a user feedback (reward) model to enable doubly-robust off-policy evaluation for the sequential setting and a multi-step, feedback-model-based test-time scaling that rolls out candidate trajectories and selects the recommendation with the highest predicted discounted return. The RL agent beats next-item and next-positive baselines on off-policy session-return estimates (DR 0.6306 vs 0.6046) while preserving recall@100, and more inference-time roll-outs monotonically raise model-based long-term return. The discussion frames a shared-backbone model plus test-time scaling as an inference-time reranker, a path toward a unified generative recommender rather than a classical cascaded system (aspirational, not the paper's implemented method).
