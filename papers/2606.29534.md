## Summary

This paper introduces PreferenceASR as a novel ASR benchmark addressing gaps between human expectations for output formatting and existing standard tests or normalizers that ignore specific user instructions. The dataset is constructed using LLM-assisted methods combined with human verification from various sources, featuring diverse examples focusing on four key preference dimensions: normalization rules, entity recognition, disfluencies handling, and text case consistency. Evaluating models shows significant ranking shifts depending on the applied preferences, demonstrating how traditional benchmarks fail to capture these important differences in ASR performance.

## Technical note

Preference-ASR (Nvidia) is a test set measuring whether ASR systems, especially SpeechLLMs, follow natural-language formatting preferences that standard WER-against-fixed-references and blanket normalizers erase. It targets four preference categories—normalization (TN vs ITN for numbers, symbols, URLs), entities (with injected false-positive names to measure confabulation), disfluencies, and case—drawn from seven open-source corpora whose annotation conventions are shown to be inconsistent. Construction uses a two-stage LLM-assisted pipeline (category classification, then instruction/reference generation) bracketed by manual verification, and evaluation uses a preference-aware normalizer that selectively skips normalization steps matching the active instruction for fair WER. Benchmarking four models shows rankings shift across preference types, exposing quality differences that traditional evaluation obscures.
