## Summary

This paper addresses the challenges of developing and deploying a vast number of machine learning models in recommendation systems, like those used in advertising. The authors propose the Standard Model Template (SMT), a framework using standardized, reusable components to build adaptable models. Their empirical study shows that SMT significantly improves model performance (0.63% cross-entropy gain), drastically reduces engineering time (92% faster iterations), and increases the rate at which new model techniques can be adopted (6.3x throughput), challenging the need for diverse model designs.

## Technical note

The Standard Model Template (SMT) is a template-driven ML development framework for Meta's large ads-ranking model fleet, addressing the combinatorial O(n*2^k) cost of independently propagating k techniques across n per-model architectures. SMT defines six reusable, composable templates differentiated by paradigm (two-tower vs single-tower, early-stage efficiency vs late-stage performance) and feature-interaction type, splitting work into Template Iteration (validate a technique once at template level, O(k)) and Model Iteration (instantiate models from templates, O(n)), reducing overall complexity to O(n+k). A Multi-Model Optimization component uses Bayesian optimization across representative models to find globally-optimal hyperparameters. A production study over four development cycles reports a 0.63% average cross-entropy improvement at neutral serving capacity, 0.86% cumulative online lift, 92% reduction in per-model engineering time, and 6.3x higher technique-adoption throughput, challenging the view that diverse objectives require diversified model designs.
