## Summary

(Abstract fallback)

Sequential recommendation, a critical task in recommendation systems, predicts the next user action based on the understanding of the user's historical behaviors. Conventional studies mainly focus on cross-behavior modeling with self-attention based methods while neglecting comprehensive user interest modeling for more dimensions. In this study, we propose a novel sequential recommendation model, Pyramid Mixer, which leverages the MLP-Mixer architecture to achieve efficient and complete modeling...

## Technical note

Pyramid Mixer is ByteDance's MLP-Mixer-based sequential recommendation model that replaces O(n^2) self-attention with an all-MLP architecture for efficient, comprehensive user-interest modeling across behaviors and features. It performs cross-behavior and cross-feature mixing in parallel, stacks mixer layers hierarchically in a pyramid to capture multi-scale/multi-period temporal interests from short- to long-term, and integrates low-rank decomposition for efficiency. Online A/B tests show +0.106% user stay duration and +0.0113% user active days, and the model is deployed in production demonstrating scalability.
