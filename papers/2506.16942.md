## Summary

1.  Existing sequential recommendation models primarily use self-attention mechanisms to model cross-behavior user interests but neglect modeling across multiple feature dimensions and periods (time).
2.  The authors propose Pyramid Mixer, which utilizes an MLP-Mixer architecture specifically designed for multi-dimensional, multi-period interest modeling by learning interactions between different behaviors, features, and time scales in a pyramid structure.
3.  Extensive experiments show that this approach significantly improves recommendation performance (+0.106% stay duration, +0.0113% active days) compared to conventional methods, both offline and online (A/B test), and has been successfully deployed on an industrial platform demonstrating its effectiveness and scalability.

## Technical note

Self-attention sequential recommenders model cross-behavior relations but neglect cross-feature mixing and scale poorly due to O(n^2) cost. Pyramid Mixer uses an all-MLP MLP-Mixer architecture to model user interests comprehensively via cross-behavior and cross-feature user-sequence mixing, with mixer layers stacked in a pyramid for cross-period temporal interest learning at multiple time cycles. This yields linear complexity suitable for large industrial deployment. Online A/B tests show +0.106% user stay duration and +0.0113% user active days, and the model is deployed in production.
