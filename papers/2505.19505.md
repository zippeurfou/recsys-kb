## Technical note

HiT-LBM (Kuaishou) uses LLMs to model lifelong user behavior for recommendation, addressing LLM context-length limits and uneven attention over long sequences. It combines Chunked User Behavior Extraction (CUBE), which splits lifelong behavior into chunks and learns interest and interest-evolution cascadingly, with Hierarchical Tree Search for Interests (HTS), which generates candidate interests via best-of-N hierarchical expansion scored by a Sequence Rating Model and Point Rating Model to combat cascading error accumulation and hallucination. Temporal-Ware Interest Fusion (TIF) encodes and temporally fuses the extracted interests into a representation embeddable in any recommender. Experiments on two public datasets plus online industrial tests show it surpasses state-of-the-art methods.
