## Technical note

GLASS injects long-term user interests into generative recommendation via two modules over hierarchical Semantic IDs. SID-Tier maps long-term interactions into a unified interest vector and exploits the compact SID codebook to compute cross features that enhance generation of the first SID token; semantic hard search then uses the generated coarse-grained sid1 as a dynamic key to retrieve relevant historical behaviors, fused via adaptive gated fusion to recalibrate fine-grained tokens and counter error accumulation. Data sparsity in the search is addressed with semantic neighbor augmentation and codebook resizing. On TAOBAO-MM and KuaiRec, GLASS outperforms SOTA generative recommendation baselines.
