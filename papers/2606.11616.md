## Summary

1.  Real-world machine learning datasets often contain mixed errors (label, feature, or spurious correlation), which existing debugging tools fail to effectively diagnose and correct together. The challenge is identifying both problematic samples and their specific error types for targeted repair.
2.  To address this limitation, the authors propose DeMix, a framework that simultaneously diagnoses sample-level errors and predicts their type by analyzing influence vectors – multi-dimensional measures showing how each training sample affects model predictions across all validation examples.
3.  They treat data debugging as a multi-label classification task using these influence vectors, employing an intervention strategy to help the classifier learn distinct "rationales" for different error types. Experiments show DeMix significantly outperforms existing methods in identifying errors and improves downstream model performance after repair.

## Technical note

DeMix debugs training data with mixed error types by both detecting erroneous samples and classifying their error type (label error, feature error, spurious correlation). Its key insight is that different error types induce distinct patterns in the influence vector, the full vector of per-validation-sample influence scores, which disentangles error clusters that stay mixed in raw feature space. It casts debugging as multi-label classification, encoding each influence vector with a Set Transformer (permutation-invariant over the unordered validation set) and decoding with MLP heads, trained on controlled synthetic error injection. Because influence vectors depend on the validation subset and model instance, an intervention-based invariant-representation strategy (contrastive loss over resampled validation subsets and consistency loss over a model ensemble), motivated by the information bottleneck, extracts configuration-stable error signatures. Across 11 tasks including recommender systems and LLM alignment it improves debugging F1 by 22.61% and repaired-model performance by 9.32%.
