## Summary

This paper introduces a modular LLM framework for detecting price outliers in retail, moving beyond simple classical threshold methods. The system treats price outlier detection as a reasoning task, processing product prices through three stages: relevance classification, relative utility assessment, and reasoning-based decision. This approach achieves high accuracy (over 75% agreement with human auditors) and outperforms other LLM techniques, while being flexible for different use cases.

## Technical note

This modular agentic LLM framework reframes retail price-outlier detection as an explainable reasoning task rather than a statistical threshold problem. Candidate neighbor products are retrieved with CLIP-style contrastive product embeddings via cosine nearest-neighbor search, then three sequentially coordinated LLM agents process the target: (i) a Relevance Agent classifies price-relevant substitutes using disjunctive comparability questions, (ii) a Relative Utility Agent reasons over price-influencing attributes (brand, size, features), and (iii) a Reasoning-Based Decision agent aggregates evidence into an explainable high/ambiguous/not-high judgment. It attains 76.3% agreement with human auditors and a 7.8% false-discovery rate, outperforming zero-shot and retrieval-based LLM baselines, with ablations on neighbor count, price padding, and attribute selection showing tunable accuracy/agreement trade-offs.
